## 0.3.0：人物事件优先与条件式方法融合（2026-09-20）

镜头先形成可讲述的事件：人物想推进什么、阻力或信息怎样抵达、行动与听说如何影响对方、结束留下什么；摄影机和声光用足够执行的精度承载它。压缩的是参数清单、重复定位和装饰，不是人物过程、对白接收、动作路径/接触/反馈或余态。没有摄影与表演字数比例、动作数量或固定短语配额。

- **持续的活人感**：人物入镜后已有做事、听看、持物或支撑的行为底流，刺激改变它的节奏与状态；不是关键拍点才动一下，也不是每秒眨眼、忙乱小动作或全员同步反应。既定静止、隐眼、非人结构和局部白模素材增补保留各自边界。
- **ACTING 的有条件吸收**：目标、阻力、策略与潜台词驱动当场行动；习惯按性格与触发使用；声线身份与当场表达分开。系列角色档案仅在需要时内部复用，不新增必填角色卡或最终栏目。
- **CINEDANCE 的有条件吸收**：实际首帧站位、接触锚点、世界方位与目光分开、光学可见结果、参考职责与当前上下文隔离。没有引入固定 FOV/景深套餐、光学短语配额、重复 LENS LOCK、重复素材标签、英文十二栏或生成期终检。方法主张不当作平台性能事实。
- **动作与声音**：战术原因→发起→路径→接触/避让→反馈→新状态保全；已有疲劳、伤侧、握力和人物优先目标持续起作用。对白跨切、说话中运镜和句中听者反应仍是同一事件，逐字原文不重复、不改派给画内听者。
- **真实按需知识链**：新增 [角色行为与动作叙事参考库](references/cinema/角色行为与动作叙事参考库.md)，从问题路由、微表演和动作模块进入相关完整章节，不每轮加载全套知识；源码资料不整篇复制为运行指令。

保留中文六部分、时码、一镜连续段落、光影/现场声尾句、独立花括号逐字台词、每素材绑定一次、4–30秒与单段优先；导演—编译分域和已有用户锁继续有效。更新 [雨夜走廊](references/model/shot-prose-example.md)，新增 [对白声桥、非人动作及静止完整样例](references/model/character-event-examples.md)。维护测试只证明可检测的格式、链接、时序与逐字原文不变量，人物质量依独立行为试跑，实际成片仍待生成验证；不增加运行时自检。

## 核心架构

1. **导演域**决定拍什么、为何这样拍：戏点、视点、调度、表演、机位、剪辑、节奏、声音、动作美学。
2. **动作执行域**按需补齐：战术因果、方向、路径、接触、惯性、逐拍时间、环境反馈和连续状态。
3. **L1 锁定门**冻结创意：用户锁与确认版优先，编译时不二次导演。
4. **编译域**只做语义保真翻译：模型事实、对白语法、素材职责和原生分镜表达。
5. **活人感表演基线**：持续的做事、听看、身体和物件关系贯穿镜头，在具体刺激处变化并留下余态；不同人物按各自策略与接收时机行动，按可见性取舍，不堆表情部位。
6. **人物事件与叙事织合**：先把人物意图、行动/对白互动与结果设计成连续事件，再用精炼而足够执行的摄影信息承载。机位、构图、运镜和光学结果不是正文主体或新增字段清单；技术去赘述，因果不缩水，白模参考也不替代人物过程。

尺寸与走位采用正向空间约束：让已锁定比例、共同空间参照、承托接触、动作和构图共同成立；先修正文冲突，再编译，避免靠结尾否定句补救。规则按需读取 [正向空间约束](references/model/positive-spatial-constraints.md)；无字幕、无BGM等简短交付限制保留，用户明确要求的文字或音乐优先。这是编写策略，非对模型采样机制的保证。

微表情专项按需读 [微表情与细微表演指导](modules/micro-performance.md)：从人物目标、公开策略与剧情触发，选择当前机位能读到的细微反应，再衔接前后状态。默认融入连续镜头，不固定四部位、百分比或逐帧配额；设计表按需单独交付，明确保存或导出时生成 Markdown 文件。

普通对话明确交谈对象与眼神落点；移开视线有动机、新落点及承接，而非随机飘移或僵硬全程对视。导演设计主动组织有因果的视听层次：观看位置、空间构图、景别距离、动静/焦点、节奏和声音互补；固定长镜也可通过画内调度与声场呈现变化，不靠技法配额增加复杂度。

镜头取舍兼看事件与表达价值：不新增情节的光影、反射、前景、声音也可深化人物、潜台词和情绪距离。编译保留具体载体与有意藏露，角色看谁不等于观众必须看清眼睛；不把象征解释当提示词，也不逐镜加暗示或固定冷暖含义。复用现有知识库与字段，不新增运行步骤。

## 0.2.1：设计判断与开放表演

输入分镜有实质叙事/技术冲突时，先按 [设计判断](modules/design-judgment.md) 实读相关知识、指出受影响镜头与后果、给出最小改法；涉及用户锁则等选择，已接受同一取舍直接继续。无问题不增加确认或检查报告。明确获准的局部修正直接做，不把简单选择推给用户。

自主设计在选方案时考虑构图、光学、信息可读性、剪辑、声画与表演相容性；视听丰富来自有动机的关系和节奏。用户只给关键动作时，开放表演按相关正文补注意力、微反应与余态；纯转写/素材增补/全锁表演不擅改。短焦浅景深、同景别反打与有意遮挡不是自动错误。

本次不新增最终自检、固定代理或写表流程，不改五部分格式与知识正文。文本指导与维护验证不等于穷尽复杂错误或模型成片保证。

## 0.2.0：五部分连续镜头元模板

1. `【风格】`：摄影机/成像目标，胶片或数字质感，必要的画幅与色彩基线。
2. `【素材绑定】`：各来源只一次规范引用与职责；无参考时写“无外部参考素材”。
3. `【本段戏剧任务】`：原有处境→新处境，经明确动作或转折推进→观众应感到的关系、情绪或后续行动结果。
4. `【本段情绪总控】`：主情绪——节奏与温度；一句反面情绪排除。
5. `镜头N｜M:SS-M:SS`：每镜一整段可想象的自然语言，摄影机参数、构图、运镜与从起点到结束的表演连在一起；段末必有`光影：`与`现场声：`句。可选独立`台词：角色说{逐字原文}`行。

光影同时写如何作用和镜内怎样随实际人物/水/风/烟/光源变化；稳定条件写稳定，不凭空增加实体。现场声收1–3种真实声源，不放BGM。每镜写景别、焦段、相对机位方位/高度、平仰俯、主体位置与大致占幅、已有前中后景、运镜起点/路径/速度/终点、人物动作/视线/微表演和首尾体态。

新建设计相邻切镜换焦段且换景别、主体偏心、非主体侧由已有实体占位；用户锁、确认L1及一镜到底优先。这是当前所选写法，不把它固化为影视库的通用定律，也不为换焦段机械增加切镜。上镜末态与下镜起态连续，最后0.5秒直接在末镜正文收束。普通对话目光与对手对齐，心理不透明和有意遮眼按创意保留。

当前完整主模板：[六部分元模板](references/model/nine-layer-schema.md)；已填范例：[雨夜走廊三镜](references/model/shot-prose-example.md)。旧文件名仅兼容引用。每个生成段一个代码围栏，末镜现场声/台词即结束；旧通用栏、本段情节、尾卡、分散技术表和散文内重复逐字对白均退出当前输出。无额外自检与字数门槛。

0.2.0 的格式升级保持当时的44份影视专项及184份大师重编正文；0.2.2另作定向内容回补。清洗脚本不是常规验证步骤，不为模板改动重新导入知识。

## 已确认合同

- 单段生成时长：4–30 秒。
- 单一连贯场景默认只生成一个 segment；一个 segment 内可以包含多个镜头和多次剪辑。
- 只有用户明确要求多段，或用户给定时长/锁定事件的最低必要时长确实超过 30 秒时，才启用 `SEQUENCE` 和段间交接。
- 单段图片、视频、音频参考素材合计最多 50 个。
- 段首与段尾各保留 0.5 秒稳定区。
- 对白与旁白以中文双引号嵌入镜头正文，明确人物/旁白/设备声源，不独立列行。
- 表演默认在引号外；长对白确需定位中途变化时才插入 `【非发声表演说明】`，移除说明后实际原文含标点逐字不变。这是本地写作约定，不是模型控制保证。
- 素材占位符按类型分别编号：`@image1`、`@video1`、`@audio1`。
- 每个素材占位符在整段正式提示词中只出现一次，统一放在 `【素材绑定】`；同一素材的多项职责与作用范围合并。无素材也保留此节，写“无外部参考素材”。
- 本地路径、文件名、URL、上传标签和平台原始 ID 不进入正式提示词。
- 人物可见且承担镜头变化时，镜头正文优先保留视线/注意力落点，并按需要选择最有证据力的自然表演载体；微表情按景别和因果启用，不做固定配额。

其余数值能力、平台字段与保证性行为不作推断。

## 使用

在 Codex 中调用：

```text
$seedance-2-5-director-compiler
把这段剧本设计成 12 秒镜头，并编译成 Seedance 2.5 提示词……
```

常用任务模式：

- `CREATE_AUTO`：同轮给出 L1 和原生分镜提示词。
- `DIRECTOR_CHECKPOINT`：先确认 L1，再编译。
- `COMPILE`：把已有锁定分镜原样编译。
- `SEQUENCE`：在明确多段或用户给定时长/锁定事件的最低必要时长超过 30 秒时，设计段间状态接口。
- `OPTIMIZE`：保留创意结构，只优化提示词。
- `DIAGNOSE`：定位最早根因并返回最小替换块。

### 已有提示词接入 Blender 白模视频

提供原成片提示词与白模预演视频，进入轻量 `OPTIMIZE`：识别代理颜色与角色的对应，保留原角色/场景等素材及规范编号，只增补一次视频引用。白模提供空间、站位、粗走位、构图和摄影机路径的依据；原分镜继续保留运镜表达、连贯叙事、微表情与小动作、动作细节、对白、声音和特效。只适量压缩重复的静态空间说明，粗模动作和识别色不会自动成为最终表演与外观要求。

详细规则位于 [白模参考接入](references/model/previs-reference.md)，仅在这类输入时读取。无需先制作工程交接包或重做 L1；单纯接入参考跳过导演取材与动作重设计，真正重设计仍按需读相关影视库和大师作品。

动作模式：

- `NARRATIVE`：文戏与普通运动。
- `ACTION_LITE`：单次攻击、闪避、碰撞、抓取、跌落或追逐拍。
- `ACTION_FULL`：持续战斗、兵器、1vN、重武器、超能力或密集弹道。

## 知识路由

每次包含镜头设计或重设计时：

- 读取影视索引；
- 实际读取 1–3 个与当前问题相关的影视专项：单一问题读 1–2 个，真正跨域时读 2–3 个；
- 读取大师索引；
- 实际完整读取至少一部相关大师作品；
- 把作品方法转化为具体镜头决定。

当本段重点是表演、活人感、视线关系、微反应或角色小动作时，专项读取优先包含 `表演细节参考库` 与视线/调度/表演弧线中的一项，仍遵守 1–3 项的按需上限；动作因果为主时先保留动作专项，再补最贴合的一项表演或视线专项。

纯编译、语法修复和模型字段诊断会跳过导演取材。普通单场景在内存中完成，不创建项目状态、读取日志或交付包。

知识库存量：

- 45 份影视专项；
- 67 份大师方法论；
- 117 份大师作品分析；
- 67 个大师目录。

`KNOWLEDGE-MANIFEST.yaml` 保存当前229份知识正文的字节数与 SHA-256；`MIGRATION-MANIFEST.yaml` 保留历史初次迁移快照，目标哈希不是回补后现值。当前库存、历史迁移和语义审阅范围分开记录，文件数和哈希不代表全部细节等价。

手动维护知识后用 `node scripts/refresh-knowledge-manifest.mjs --write` 刷新当前哈希，脚本不改正文。历史 `clean-knowledge.mjs` 对标有 `curated-manual` 的库默认阻止写入，避免把回补案例再次删掉；只有经过差异审阅的主动重新导入才使用显式 `--allow-legacy-rewrite`。两种脚本都不在生成提示词时运行。
