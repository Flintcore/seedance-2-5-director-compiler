# 镜头衔接与连续性参考库

连续性不是要求所有切换都平滑，而是让观众知道切点前后发生了什么。写实连续、时间省略、匹配剪辑和故意跳切都成立；区别在于断裂是否可读、是否服务表达。

## 一、五类连续锚

| 连续锚 | 切点两侧共享什么 | 适用 |
|---|---|---|
| 动作 | 同一动作相位、受力或结果 | 起身、开门、挥击、落地、递物 |
| 方向 | 世界方向与屏幕方向的对应 | 行走、追逐、视线、弹道 |
| 空间 | 人物、物件与固定锚的关系 | 对话、群像、复杂动作 |
| 视线 | 谁看哪里、下一镜揭示什么 | 发现、反应、主客观切换 |
| 声音 | 同一声源或声场跨过切点 | J-cut、L-cut、动作声桥 |

一个切换无需同时满足五类。选择最能让观众理解当前戏剧关系的锚。

## 二、状态向量

切点前后只追踪活跃状态：

- 人物和物件实例数；
- 世界位置与画面位置；
- 朝向、视线、遮挡和距离；
- 姿态、重心、接触、左右手与道具归属；
- 动作相位、速度、旋转和未消散的动量；
- 伤势、污渍、湿度、破坏、碎片和烟尘；
- 光源、天气、环境活动和持续声源；
- 摄影机位于轴线哪一侧。

上一镜的退出状态成为下一镜的进入状态。只更新镜间真实发生的变化；若有跳时或跳空，明确新的时间和状态。

## 三、动作衔接

切在动作中时：

1. 上一镜建立动作起因和开始相位；
2. 切点保留尚未完成的方向或受力；
3. 下一镜从同一相位继续，而非重新起势；
4. 接触、落地、反作用和恢复在某一侧被完整交代；
5. 道具、手位和身体平衡随动作传递。

也可在动作完成后切，但下一镜需以完成后的后果为起点。错误不在“动作后切”，而在下一镜把人物重置到无关状态。

### 常见传递

| 动作 | 上一镜退出 | 下一镜进入 |
|---|---|---|
| 开门 | 手压把手，门页开始转动 | 同一手位和开门方向继续，人物跨门槛 |
| 挥击 | 支撑脚、转体和武器路径已建立 | 同一路径到接触或被格挡 |
| 跳跃 | 离地、上升或越障相位明确 | 同一速度方向进入顶点、下降或落地 |
| 倒地 | 重心已被夺走、身体开始下沉 | 同一受力方向继续，以接触和恢复结束 |
| 递物 | 物件归属与手部路径清楚 | 交接完成，或拒收导致原持有人收回 |

## 四、世界方向与屏幕方向

世界方向描述人物在场景中的真实移动；屏幕方向描述其在画面中向左、向右、向深处或向镜头移动。换机位时两者可能重新映射。

- 先建立固定空间锚和人物路线；
- 同一追逐或攻击链保持屏幕方向可读；
- 方向改变要让观众看见转身、绕障、反弹或轴线重建；
- 需要越轴时，可让人物或摄影机穿过轴线、使用中性正面镜头，或以明确空间全景重建；
- 故意方向混乱应绑定主观失衡，并在关键结果前恢复必要信息。

180 度法则和 30 度法则是可读性工具，不是跨类型禁令。跳轴、近角跳切和重复构图只要形成可辨的表达，都可成为风格。

## 五、位置、景别与构图

- 人物从画面一侧跳到另一侧，需要角色移动、摄影机移动或轴线变化的证据；
- 景别变化应改变观众读取层级：空间、身体、表情或细节；
- 同主体接切时，可通过明显机位变化、明显景别变化、动作连续或有意跳切避免无意义抖动；
- 固定物件、门窗、柱体和地平线可帮助观众重建位置；
- 占屏比例变化需符合摄影机距离、焦距或人物路径。

匹配构图可以连接不同时间和地点，但要让观众知道它是意义联系，不是假装同一空间。

## 六、视线连续

视线关系包含：

- 观看者位置与朝向；
- 视线目标是否在画内；
- 下一镜目标出现于哪个方向；
- 目标与观看者之间的高度和距离；
- 观看发生时两者是否真的可见；
- 反应是即时、延迟还是被压住。

对话正反打中，视线方向、眼高和轴线共同维持关系。故意不匹配可表现疏离、错认、监视或主观不可靠，但需要明确的叙事收益。

## 七、声音衔接

### J-cut

下一镜的声音提前进入，先改变观众预期，再改变画面。

### L-cut

上一镜声音延续，允许台词、情绪或环境跨过视觉切点。

### 动作声桥

同一脚步、引擎、呼吸、武器余振或物件声跨镜持续，使动作和空间保持一体。

声音连续需追踪声源、位置、遮挡、距离、变化趋势和停止点。环境声突然重置会让同一空间产生断裂感。

## 八、动作与多人连续

动作切换需携带：

- 当前施压者与其他人的位置；
- 角色的支撑脚、受伤侧、呼吸和疲劳；
- 武器握法、路径、碰撞后的振动或变形；
- 未完成的冲量、跌落、旋转、滑移或回弹；
- 环境破坏和新障碍；
- 摄影机所在轴线侧与下一镜屏幕方向。

1vN 中即使镜头暂时聚焦局部交锋，也要让其他对手的位置在空间或声音上可追踪。下一位对手进入主压力前，应有路线和机会来源。

## 九、合法断裂

| 手法 | 观众需知道什么 | 用途 |
|---|---|---|
| 时间省略 | 中间过程被有意省去 | 压缩重复劳动、旅程或等待 |
| 跳切 | 同一动作或构图中的时间被切走 | 躁动、轻快、疏离、主观断裂 |
| 匹配剪辑 | 形状、动作或声音连接不同状态 | 主题联想、时间跳跃、身份对照 |
| 轴线破坏 | 空间方向被有意打乱 | 心理失衡、关系断裂、冲击 |
| 硬切到新状态 | 场景或时间发生明确变化 | 反差、喜剧、惊吓、信息重置 |

合法断裂让观众感到“剪辑在表达”；无意断裂让观众只感到人物、物件或动作凭空跳变。

## 十、跨段接口

分段生成时，段尾选择可复现状态：

- 构图和人物实例清楚；
- 姿态、朝向、手位、道具和伤势稳定；
- 继续运动时写清相位、方向和动量；
- 环境破坏、天气、光线与持续声源已更新；
- 下一段开头先复现，再推进新变化。

动作接触、台词落点和关键反应不应被截在含混相位。确需在进行中跨段时，上一段退出与下一段进入使用同一状态向量。

## 十一、常见失败

| 失败 | 后果 | 修正 |
|---|---|---|
| 下一镜重新起势 | 动作重复或跳帧 | 从同一相位继续 |
| 画面方向反转却没有证据 | 地理混乱 | 展示转向、绕障或重建轴线 |
| 道具换手、伤势或破坏重置 | 因果被抹去 | 传递活跃状态 |
| 切换只改变角度 | 镜头没有新意义 | 改变信息、距离、视点或保留原镜 |
| 反应镜与视线不匹配 | 人物像看向错误对象 | 校准位置、眼高与方向 |
| 同场环境声重启 | 空间连续中断 | 携带声源和变化趋势 |
| 把所有跳切都视为错误 | 风格空间被压缩 | 判断观众是否读懂省略与意图 |

## 十二、协同入口

- 视点体系与镜头运动：决定摄影机认知位置和轴线。
- 角色调度与走位：建立世界位置、路径和权力空间。
- 动作设计与动作执行：传递接触、受力、惯性和多人压力。
- 切镜时机学：选择信息、动作、情绪或反应切点。
- 声音叙事：建立声源、声音桥和主客观声场。
- 角色与场景设定：维护身份、道具、环境与跨段状态。
