## 01｜把人物经历、讲述选择与画面实现分开

**机制（跨课综合重构）。** 分镜既不是人物行为的逐项记录，也不是运镜名词的拼接。它在三层间作选择：人物经历了什么；创作者要观众经历其中哪一部分；用何种画面和声音实现。角色已知的事、导演展示的事、摄影机所在位置不是同一概念。这是连接后续课程的设计框架，不是总览课逐条讲授的三层定义。

| 子知识与选择条件 | 执行方式 | 易误用的反例 |
|---|---|---|
| 形式丰富却说不清这一拍的经历 | 先用事件句说清“谁在什么处境中尝试什么、受到什么影响”，再决定分享发现、等待、执行、结果或余波 | 先选环绕，再给人物编一个转身理由 |
| 同一事件存在多种合理拍法 | 分别比较角色的感知范围、观众信息和画面位置：贴近角色不必占据他的眼位，旁观机位也可只交付他此刻知道的事实 | 把贴近、共情、POV、近景当同义词 |
| 学一个案例以迁移到新场景 | 提取“问题—条件—选择—所保留的经验”；保留具体条件，再尝试不同形式 | 把某片的视点数量、颜色或路线复制为所有戏的标准 |
| 某一局部手法与整个场面的效果矛盾 | 回到人物事件和观看重点重选实现手段；允许前后决定互相校正 | 固定按一条工序从头走到底，后面的空间证据也不再改前面的镜头决定 |

**短案例与证据。** 总览课没有提供独立逐镜案例，而将后续分镜放在人类的感知、反馈、体验基础上；其价值是确定分析对象。后面的普通行走说明：事件不复杂，导演选择仍可精确。**文稿例证；**不把行业优越性、情绪必然共鸣或神经科学归因当成已证实规律。

**接续。** 已有目标、策略和行为过程见[角色行为与动作叙事参考库](../角色行为与动作叙事参考库.md)第一、二、八节；表达信息与新事件的区别见[信息素控制参考库](../信息素控制参考库.md)“核心概念”。本章补的是三层选择之间的联系，不另建人物设定。

**来源：** 总览的直接主张与学习定位见 A01:L10–24、B19:L10–24；替代眼位见 A08:L12–14 / B26:L12–14，经历者与讲述者见 A09:L32–36 / B27:L34–40，精神探索见 A10:L61–69 / B28:L61–69。三层区分及局部决定往返修正是据这些课程重构的迁移方法，非第一课原有清单。

## 02｜从 A 到 B：先决定保留哪些节点，再组织路线

**机制。** 一次进入、离开或旅行可以同时交付目标、空间、时间压力与人物状态。把世界中的行程分成有作用的节点，再设计人物与摄影机怎样使这些节点可见；不是先让人物多拐几次弯。

| 子知识与选择条件 | 执行方式 | 易误用的反例 |
|---|---|---|
| 普通入场既要交代环境又要开始行动 | 明确出发处、目的处、必经障碍或入口；让新对象在靠近、转向、遮挡解除或跨门时出现 | 为展示场景而要求人物无目的绕行 |
| 想用横向与纵深转换增加观看变化 | 同时区分世界路线、画面轨迹和摄影机观察方位；转换可来自人、机或双方 | 画面里由纵深变横向，就认定演员在地上走了同形折线 |
| 类似路线需要不同紧迫感 | 保留必须读懂的启动、通过节点和到达；压缩无事路程，或缩短回看与前进的间隔 | 只加倍步速；删掉关键门、障碍或选择后仍宣称空间清楚 |
| 较长旅行需要分段与时间压缩 | 人物观察、近处状态、沿途目的物可把旅程划成“仍在路上—接近—到达”；选择哪个节点承担时间跳跃 | 任意插脸便跨过未知风险，或把一切过路镜都当废镜 |
| 对白跨越几个行程节点 | 话语与行走、让路、回看或进入继续共同发生；画面更换不让说话与任务重启 | 每到一镜就停下说完整句，再从原地重新起步 |
| 采用连续长镜而非切镜 | 在镜内依然安排目的、节点、前后景和观看交接；不切只改变实现方式 | 把长镜等同于均匀跟拍，忽略中途关系变化 |

**短案例与证据。** 《群鸟》的街道入店与《谍影重重》的入场，都可由进入地点这一简单任务组织；后者通过压缩非关键步数、调整跟随与节点交代，产生不同紧迫感。舟车路程中的人物观察既传状态又分隔行程；《荒野猎人》案例说明节点组织也可发生在长镜内部。**文稿例证**，不据转写中的字母或镜数重建精确轨迹。

**条件界限。** 如果此次选择就是让观众经历行程中的劳动、犹豫、依恋或风险，应保留对应过程；也可有意隐藏过程，以到达结果引发疑问，但那是改变叙述策略，不是无损压缩。连续时间掩护移动与明确时间省略的差别见[05](#stage-05)。

**接续。** 真实站位、朝向、轴线侧与移动后位置更新，接[角色调度与走位参考库](../角色调度与走位参考库.md)第十一节；时间与状态证据接[镜头衔接与连续性参考库](../镜头衔接与连续性参考库.md)第七节。世界位置是依据，画面位置由实际机位推导，不冻结为永远在画面同一侧。

**来源：** A02:L13–37、L52–90；B20:L12–36、L40–62。A02:L19–21 / B20:L18–20 转写为 C 的位置，1299 第02课 03:54 画内字幕可见“L型或者说是Z型的运动”（2026-09-28 审计静帧，本次复看）；只确认该处字形，不据此还原地面路线。其它 L/Z/C 异文逐处保留待核，另一局部字形范围见[08](#stage-08)。

## 03｜镜内注意交接：摄影机可以被事件带走

**机制。** 长镜中的观看中心可以从人物交给另一人、物体运动、环境活动或空间后果。摄影机并非只能服从主人公的行走；但离开原中心仍需要清楚的观看去向。

| 子知识与选择条件 | 执行方式 | 易误用的反例 |
|---|---|---|
| 原人物只负责带观众进入更大的事件 | 让他的经过、视线或附近事件引出下一个对象；原人物继续其行动，即使暂时在画外 | 人物一出画就被当成消失，或摄影机无理由巡视 |
| 非人运动可自然吸引观看 | 用纸张、经过的物体、声源、遮挡或群体活动完成注意交接；具体说明前对象到后对象的可见联系 | 把“拟人化镜头”写成抽象风格，不交代它注意到了什么 |
| 空间本身承载当前感受 | 人物离开后可留看环境，随后返回、交给新人物或结束于后果；不预设每次都回到主角 | 凡偏离必回接；以回接手续覆盖已完成的场景意义 |
| 初入陌生机构、迷宫或宏大场面 | 让转折、重复路径、遮挡和相似区域产生复杂体验；只交代当前行动需要的局部关系 | 要观众感到迷失，就任意改变出口、目标或人物位置 |
| 长镜跨多个注意段落 | 标清交接触发、谁继续做什么以及新中心承担什么；强度随前后关系变化 | 给每个人均匀分配露面时间，或给每段硬加一次运镜 |
| 穿行中的小事件可划分阶段 | 以动作完结、门闭合或小插曲形成短暂收束，再随下一任务启动人物或摄影机运动 | 每逢门都停一次；把“收束再启动”当成所有动作须完成才切的规则 |

**短案例与证据。** 《赎罪》海滩长镜中，人物先引导，周边行动和纸张等对象接过观看，人物暂时出画后场景经验仍在继续。《至暗时刻》的机构穿行则不以完整平面图为唯一目标，而使规模与复杂路径被经历；其中小情节、门闭合与运动重启也为穿行标出节奏段落。**文稿例证**；没有从转写独立确认纸张与摄影机每一条精确轨迹，门的例子也不据此量化停顿时长。

**条件界限。** 如果观众此刻要判断谁挡住出口、哪条路线可行，局部空间关系仍须可用；整体含混不等于行动因果含混。持续旁观或完全静止也可成立，不以注意转换次数衡量镜内内容。

**接续。** 视线、移动与摄影机引导这几种交接通道，接[视点体系与镜头运动地基](../视点体系与镜头运动地基.md)第四节；人物出画后的生活与接触状态接[角色行为与动作叙事参考库](../角色行为与动作叙事参考库.md)第三、六、七节。切走可发生在一句话或一个动作中间，只要保留需要的声源、动作与状态承接。

**来源：** A03:L12–32；B21:L12–34。

## 04｜感知、反馈与心理节奏：重复不只交付新事实

**机制。** 人物的观看可以把观众限制在他的认识范围，也可持续显示“这件事对他仍有分量”。应分开感知到了什么、如何接收、是否形成判断，以及这次关注如何延续；这些是功能差别，不是必须逐级晋升的表情强度表。

| 子知识与选择条件 | 执行方式 | 易误用的反例 |
|---|---|---|
| 需要观众分享角色的发现或认识限制 | 用已建立的目光、朝向、声音、空间关系或相邻镜组明确观看归属；严格眼位画面只展示该角色此刻可见的范围 | 把角色未见的事写成他的实见；或认为每次都须新拍看—物—脸三镜 |
| 一次事实交代不足以表达持续关注 | 返回对象、返回观看者，或保持一次持续看；改变距离、停留和前后关系，使重要性逐渐被感到 | 把同一次凝视编成反复转头重看；按看几遍换算爱意强度 |
| 持续关注用于亲近、紧张或不安 | 保留已建立的对象与情境压力，再决定重复是否加强预期、迟疑或向往 | 认为重复主观只适合爱情，或重复天然产生恐惧 |
| 单次较长观察就是本拍的经历 | 让对象、限制和人物处境足以支撑时间；持续时值也可呈现审视、等待或疏离 | 镜头越长情绪必越浓；高情绪必用高浓度POV |
| 从陌生环境检索进入对手交流 | 先按人物需要检索物件、出口或陌生人；交流建立后可转为关系观看，再在认真接收时回到受限观看 | 开头客观、中段主观、结尾作者视点的固定分配 |
| 探索跨入不同房间，途中过程不是重点 | 用门、出入画或先见空场再见人物，给出相邻空间的接续；必要时将探索分成逐层发现的几个部分 | 连续两个纵深画面便判重复；省略房内过程后让出口与人物来向无因改变 |
| 需要人物反馈，但单独面部反应多余 | 让停步、改看、手上动作、退让或继续执行承载接收；是否另切反应取决于观众需要读到什么 | 反馈只等于脸；没有情绪特写就认定人物没收到刺激 |

**短案例与证据。** 《群鸟》船上持续观看被反复返回的镜序加强，所增加的不必是新事件，而可能是关注强度；同类组织放进不安探索，又服务不同经验。《了不起的盖茨比》用于比较重逢注视，《至暗时刻》用于比较单次较长观察，《西北偏北》用于比较陌生环境检索。均为**文稿例证**，不是已核实的情绪剂量公式。

**层级界限。** 本章的感知与接收功能，和[05](#stage-05)的镜组/节拍组织、[06](#stage-06)的行动反馈回合分别回答不同问题。源文稿没有足够可靠的“四层反馈”编号定义，故不据课程标题造出四级标准。主观拍法的价值也不依靠未经核实的镜像神经元因果说明。

**接续。** 观看归属、注意落点与机位态度接[视点体系与镜头运动地基](../视点体系与镜头运动地基.md)第一、二、五节；重复能否深化人物理解接[信息素控制参考库](../信息素控制参考库.md)第二节。稳定机位不自动破坏主观性，一场持续单一认识范围也可有强烈内部变化。

**来源：** A04:L10–30、L34–56；B22:L11–31、L35–59。

## 05｜镜组、节拍与叙事权重：多人不是平均分镜

**机制。** 段落组织一段有方向的进程；节拍说明当前关系、行动或注意发生了什么变化；镜组把观看、位置、执行、反馈等画面相互解释。它们不是等额容器：一个镜头可完成多个相容功能，一拍也可由不同镜组协同。

| 子知识与选择条件 | 执行方式 | 易误用的反例 |
|---|---|---|
| 复杂场面中镜头零散 | 先复述每段、每拍在做什么，再安排观察组、关系组、行动组怎样接续；不要先按角度命名节拍 | 三段各三拍、每拍三镜；把一个表情就命名成完整节拍 |
| 一群人共同关注，但某个人更重要 | 先建立共同准备/观看，随后通过靠近、反馈或个体视点收束到特定人物 | 所有人依次同样一镜，叙事权重平均化 |
| 镜组中的位置关系需要更新 | 目标经过、站位变化、群体转为个人时补必要关系；已清楚的关系可继续依赖 | 每个主观组前都插一张全景，或永远省掉定位 |
| 观察、交谈、认真听取互相转换 | 随人物参与方式改变观看组织；主观和客观可以在同一段中反复切换 | 把视点类型当场景一次性标签 |
| 人物起身后超出原画幅 | 选择切到容纳新关系的画面，或随动作重构图；前者可强调节点，后者可保留过程体验 | 起身一定切景别；或为追求连续一律跟着升机 |
| A 到 B 的移动中，接收者反应本身有价值 | 保留出发意图—有关系的接收者—到达近处；中段用反应而非无关插入 | 插一张任意人脸就把角色送到远处，忽略途中障碍和状态变化 |
| 限制观看本身是压力 | 将窗口、阻挡身体、角色已知秘密与对方接近连起来，让压力来自真实关系 | 仅以近景或遮挡标签声称压迫成立 |

**时间条件。** 连续时间内用反应掩护移动，实际路程和反应期间须相容。明确省略了一段时间，则被省略时长无须等于插入镜时长，但出发、到达、关键持物/接触和必要时间跳跃要可理解。隐藏途中事件以待后揭示，也要维持世界因果；这与无意漏拍不同。

**覆盖条件。** 只有选择“用接收者反应覆盖移动”时，才需要这位与行动有关系的接收者；短距离移动也可在关系镜内直走、跟随、预置到达位置，或作明确省略。先选本拍值得经历的关系，再选覆盖，不为补齐一种镜组而增设接收者。

**短案例与证据。** 《西西里的美丽传说》的群体准备、共同观看、收束到一个男孩、对象经过/离开，说明主观组与其他镜组怎样共同形成节拍。**文稿例证。**《至暗时刻》车厢中可见丘吉尔起身、儿童反应、丘吉尔在近处重入画，支持短距离移动被反应覆盖。**局部画面核验：1299 第05课 18:46–19:28 的采样窗；SRT cue 247–265。**课程有长时间定格，不从该窗口计算原片移动耗时或反应镜长。

**接续。** 相邻画面怎样相互解释，接[蒙太奇与组接意义库](../蒙太奇与组接意义库.md)“库里肖夫效应”；省略及连续状态接[镜头衔接与连续性参考库](../镜头衔接与连续性参考库.md)第七节；听者接收时点接[角色行为与动作叙事参考库](../角色行为与动作叙事参考库.md)第四节。

**来源：** A05:L11–35、L49–65；B23:L10–40、L42–52。

<a id="stage-06"></a>
## 06｜反馈回合：按重点展开，不按五步配五镜

**机制。** 发现问题、接收影响、形成选择、执行行动、出现结果，可作为检查行动因果的不同功能；行动内部又可区分启动、过程、到达。它们可以同镜共存、由动作隐含、局部省略或跨镜展开，镜头数不由功能数决定。

| 子知识与选择条件 | 执行方式 | 易误用的反例 |
|---|---|---|
| 行为突然发生，观众读不出缘由 | 查人物接收了什么，以及下一步如何受影响；用目光、声音、行为调整或关系给足必要前因 | 每次出手都先补眼神、皱眉和蓄势 |
| 人物从本能应激转为有目的应对 | 区分身体自动避让与识别局面后的策略；让下一步路径或目标改变显出选择 | 所有躲避都被描述成完整思考，拖慢紧迫行动 |
| 几个回合相邻，容易雷同 | 分别强调发现、艰难执行或结果；让后一个回合提出前一个尚未解决的问题 | 每回合等量补齐所有阶段，或每次只拍最后成功 |
| 决策已由行为明示 | 直接进入行动，或在同镜内用表演完成接收与改变；观众需要经历选择的代价/压力/性格时再展开 | 只有重大决定值得看；普通选择一律略过 |
| 行动只是更大过程的中转 | 保留通向下一步的必要状态，结果可隐含或稍后出现；重要因果与接触不因中转而丢失 | 每个动作都另给一次完成镜，或省略后让持物和位置无因改变 |
| 多个角色拥有主动性 | 分别写清各自目标、已知信息和行动后果；主角、配角、对手均可发起回合 | “只有主角主动”；所有人只等主人公行动才反应 |
| 多线行动需要交织 | 先理解每条线独立的因果，再选择在哪个未完成点切走；返回时保留其位置、知识和状态，或明确时间已前进 | 固定 ABAB 次数、等长交替或每次越剪越短；回来总从头演 |
| 动作段持续高密度 | 用有内容的接收、重新定位、喘息或结果确认形成标点；反应可发生在动作中 | 宣称反应永远比动作重要，或把喘息镜当每段必备空格 |

**短案例与证据。** 《西北偏北》飞机袭击从被动避让到主动寻找出路，几个回合先后突出发现、执行和结果；《群鸟》店内可由一次表演承载完整过程，反证五功能需要五镜。跑车动作可直接显示决定；嫉妒者与特工的例子说明对手也有主动性。《红色通缉令》用于分析碎片化行动仍需启动、位置证据和反馈标点。均为**文稿例证**，未将原片精确切点或镜数作为已核数据。

**执行界限。** 省略的是观众可推断或有意暂不获知的环节，而非世界因果。人物受伤、物件损坏、手持物变化、移动到达均需有成立的原因；后续镜头继续承受这些状态。展开选择也不等于必须拍脸，身体、目标改变和行动方式可以说出同样信息。

**接续。** 压力下的动作选择与接触后果，接[角色行为与动作叙事参考库](../角色行为与动作叙事参考库.md)第五、六节；多线并置接[蒙太奇与组接意义库](../蒙太奇与组接意义库.md)第一节，取其关系逻辑，不采用固定交替次数与递减时长。

**来源：** A06:L10–40、L42–52、L58–70；B24:L11–43、L45–53、L59–75。

<a id="stage-07"></a>
## 07｜运动组接：让持续任务穿过不同观看方式

**机制。** 人物跨场的连续感可以来自任务、期限、身体状态、方向和认识范围的共同延续。匹配方向只是其中一种连接；每段环境都应对当下行动或观看有作用。

| 子知识与选择条件 | 执行方式 | 易误用的反例 |
|---|---|---|
| 地点不断变化，但事件需要保持推进 | 保留人物为何去下一处、期限如何迫近、身体还承担什么；在交接处选择最有用的关系 | 靠连续向右走掩盖目的地与任务断裂 |
| 空镜交付持续压力或处境 | 钟表可反复提醒时间，天气、颜色、空间活动可维持世界；其作用来自已建立的故事关系 | 每次换场必拍钟，或所有空镜都只能解释地点 |
| 路线需由不同观看方位连接 | 纵深跟随后横向出画、同方向动接动、前后覆盖、出入画或先见环境后见人，按所需信息选择 | 把它们当固定六招的顺序表；为了不同强行换路线 |
| 方向衔接已可读，还要比较运动的收放 | 方向与运动幅度分轴判断：同向运动可从大幅活动接到小幅活动，也可作其它有作用的变化；先辨变化来自人物、摄影机还是画面内的相对位移 | 同方向就默认同幅度；把“大动接小动”变成每次动接动的必需次序 |
| 相邻画面同景别仍有新作用 | 让方向、目标、阻碍或位置证据承担变化；景别与机位差异服务辨识，不为轮换而轮换 | 同尺度一律判重复；同方向一律判连贯 |
| 想插一个特写 | 明确观众为何此刻必须注意这一细节；它应支撑当前选择、警戒、状态或后果 | 因物件好看便放大，令观众期待一条并不存在的线索 |
| 人物警觉，周边环境也是他的任务 | 中景、跟随或环绕可同时保持人物与潜在风险；第三方观看可建立他被注意的关系 | 警觉必拍眼神特写；环绕只表达“高级” |
| 跑停之间要接上下一步 | 停下可承担疲劳、观察、反馈和重新决定，后续出发带着新目标 | 把停顿当掉速，删去后人物无因改道 |

**短案例与证据。** 《疾速追杀3》前段以持续期限、街道/室内穿行、第三方注视及停下观察，保持同一任务又改变观看方式。钟表并非纯装饰；警觉人物的中景可保留他需要留意的环境。A07:L27 / B25:L66 还将“动接动，大动接小动”并提，支持方向之外另看运动幅度；该实例究竟比较人物还是摄影机运动及其速度仍待连续画面核对，不补精确运动描述。**文稿例证**；“至少六种”是课程口述概括，未据不完整编号补造第六定义。

**接续。** 方向、动作与空间承接接[镜头衔接与连续性参考库](../镜头衔接与连续性参考库.md)第二至五节；场间关联接[蒙太奇与组接意义库](../蒙太奇与组接意义库.md)第四节。先保住世界关系，再由新机位推导投影；正面/背面覆盖的画面方向差异须按真实路线理解，不机械要求屏幕上的箭头永远不变。

**来源：** A07:L11–37；B25:L11–21、L60–74。B25 较长的影片原声/译文不等于多出相同比例的方法。

<a id="stage-08"></a>
## 08｜快慢分层与相对运动：切换、行动和经验时间分别设计

**机制。** 人物行动速度、关键事实抵达速度、覆盖更换密度、观众需要经历的身体/心理时间可以不一致。摄影机又可先于、跟随、等待或离开人物，使世界路线与画面路径产生不同关系。

| 子知识与选择条件 | 执行方式 | 易误用的反例 |
|---|---|---|
| 需要交付角色此刻接收的信息，但严格眼位不便 | 用相邻目光、朝向与场景关系建立归属，再给有助理解的非眼位画面；明确它是认识对应，不冒称精确眼位 | 角色看到的车流，只能以眼睛高度和轴向呈现 |
| 动作中的选择、结果或战术变化值得强调 | 切换在需要改变注意处发生；启动、执行、接触、受力、结果可按理解需要连贯或有意省略 | 没有操作阶段或注意变化也机械地逐动作换角度；靠光效和脸部切换替代身体因果 |
| 相邻动作需要区分准备与核心呈现 | 可在准备转核心动作、情绪升级、人物调度方向或观看方位改变处选择切点；比较仅换景别与同时换角度分别让观众更看清什么 | 把准备—核心动作强制拆成两镜；一转向就切；把局部动作对等同跨段伏笔兑现 |
| 一次互动的两端要怎样分配注意 | 比较同一关系画面内显示行动与结果，或用单人覆盖分别交付两端；后者仍需保留双方位置、作用方向与结果联系 | 关系镜天然更清楚，或单人镜天然更紧张；分切之后省掉理解因果所需的联系 |
| 受伤等状态推动换场 | 由已发生问题导出下一任务；到达后继续携带伤情、疲劳和持物 | 受伤只是上一场装饰，到诊所后无因恢复 |
| 不同地点需要成为同一世界 | 用既定颜色、时间母题和声场关联，同时允许地点差异；设计任务来自故事而非调色方案 | 抄示例蓝黄红，替代去往此地的因果 |
| 身体操作较慢，但心理压力高且过程值得经历 | 基本保留操作过程，让关系画面、手部、物件与面部覆盖跟随相邻操作阶段和警戒需要，以较密切换组织紧张；若过程不是重点，另可省略非关键环节压缩事件时间 | 把密覆盖一律当作无意义切角；把常规动作慢等同高帧率慢动作；用快切弥补根本没拍清的阶段 |
| 密切换之后进入专注判断，再兑现结果 | 准备或操作可密；听辨、瞄准或准确判断时可稳住观看，让专注本身成立；关键结果再按前面的期待选择强调 | 从头到尾同样密；把稳住只当观众休息；一律加固定停顿或强制用近景兑现 |
| 相邻镜需让注意迅速交接 | 让上一镜关键观看对象的屏幕落点，与下一镜首先要读的对象处在相近画面位置，减少重新搜寻；再依据意图决定维持、偏移或转移 | 把屏幕注意落点等同世界位置、视线轴或物理运动方向；要求主体永远居中 |
| 要让观众经历难以迅速解决的争斗 | 保留抵抗失败、调整、继续用力、身体与环境接触；一个关系角度可承载多个变化 | 长镜里只摆姿势；少切天然真实，多切天然虚假 |
| 角色路线不复杂，但观看需要变化 | 同时设计摄影机与人物：谁先打开空间，谁重新入画，距离和横向/纵深关系怎样交接 | 要演员在地上走出 L 或 Z；只记人走位不记摄影机 |
| 出画意味着阶段完成或下一阶段启动 | 结合画面范围、任务与下一镜判断“离开此处”还是“进入下一行动”；可用较大关系交付离场 | 向某侧出画永远等于回归、失败或放逐 |
| 前面设下的动作/细节将在后面起作用 | 让准备、使用和后果对应，以目标与状态承接实现兑现 | 任意加一个近景便称伏笔，不在后续行动中起作用 |

**短案例与证据。** 取物段在完整关系、躯干、手部和脸之间变化，动作是连续的常规手部任务，并非高速身体行动；支持“较密覆盖与较慢任务并存”。**局部画面核验：1299 第08课 19:16–19:32 采样窗；SRT cue 376–385。**陈列通道搏斗样本可见纠缠、身体下降/起身、压向柜体、落地及重新接触，支持保留身体代价；其中仍有角度变化，并非一镜到底。**局部画面核验：21:25–21:45；SRT cue 427–440。**两者均不据课程时长计算原片镜数或动作速度。

**本次补足的文稿机制与局部校注。** A08:L48–52 / B26:L48–54 连续讨论慢操作的密覆盖、专注时稳住、结果再强调，三者共同构成段内节奏而非互相排斥；“快”可来自过程内覆盖增加，并非只能省略过程。追者与被追者的正背向画面在课程中还用来说明屏幕注意落点相近（A08:L46–48 / B26:L46–48），不因此要求世界运动方向相同。A08:L28–32 / B26:L28–32 的准备—核心动作、情绪升级与纵横调度转换是并列切点候选；“成线”按语境暂释为“呈现”，原词仍待原声核定。

1299 第08课 **15:38** 画内字幕为“单人镜头 中枪”，支持关系覆盖与单人分切的文稿对照，B26:L40 的“带着”不另立术语；**21:12** 画内字幕为“这一枪啊 一定要给个近景强化一下”，仅确认该实例的结果强调方式，A08:L52 / B26:L54 的“静静”不解释成第二次静止。两张均为 2026-09-28 审计静帧，本次复看；静帧不证明整段动作、切点与时长。专注时稳住来自前句文稿，与结果用近景是两个决定。

**相对调度的核证范围。** 马厩段可见摄影机先经过栏位与前景，人物再由深处进入、靠近并横向通过；这使“人机共同组织纵深/横向”有可见依据。**局部画面核验：第08课 26:00–26:24，26:09–26:12 加密采样。**26:12 后有重放；画内原字幕 **26:17–26:23 明确为“Z型”“L型运动以及Z型运动”**，对应 TXT/SRT 部分写成 C。此历史采样只确认该范围的 L/Z；本次另复看的第02课 03:54 见[02](#stage-02)，两者均不扩展成所有课程同名词已校，亦未重建精确俯视 Z 形几何。

**接续。** 时间与表演、镜内/镜间组织接[节奏与时长编排库](../节奏与时长编排库.md)“二·六”；具体切换候选接[切镜时机学](../切镜时机学.md)的同步、提前、延后与预期错位概念，不把动作完成百分比或延后秒数当情绪刻度；接触锚和身体后果接[角色行为与动作叙事参考库](../角色行为与动作叙事参考库.md)第五、六节。

<a id="stage-09"></a>
## 09｜聚焦与感知空间：按当前认识打开环境

**机制。** 导演选择当前什么最值得被观察，再用人物的行动、视觉与其它感知打开空间。聚焦首先是注意选择，不等于光学拉焦，也不等于每一次注视都需切一镜。

| 子知识与选择条件 | 执行方式 | 易误用的反例 |
|---|---|---|
| 空旷直线追逐缺少建筑转折 | 用前后关系、正侧观看、距离缩短、追者占画增大及过程代价组织变化 | 为符合字母模型临时加弯路；只拍出发和到达，删掉本来重要的逼近过程 |
| 跟拍看似稳定 | 分开人物相对画面的稳定与摄影机在世界中的位移；背景、遮挡和距离仍会变 | 将“相对固定”理解为摄影机世界坐标不动 |
| 过程需要被具体经历，或身体局部能直接交付行动证据 | 眼看什么、手如何用力或松开、脚落向哪里，各按注意、执行、决定与处境选用；局部可独立承担关键证据，也可在面部解释过多时接过表达 | 只有面部表达不足才用身体细节；眼/手/脚各对应一个固定心理含义 |
| 场面重点从共同任务转向某个人 | 关系画面保留共同劳动；冲突或理解改变时靠近相应人物，必要时再回关系 | 每场固定从全景推近；结束必拉远 |
| 空间通过探索而被认识 | 行动打开路线/遮挡，视觉选出对象，其它感知提示画外；逐处给与当前任务相关的信息 | 先拍全地图才准开始，或每扇门都必须被展示 |
| 当段重点是居所、制度或生活条件，人物只是带路媒介 | 借已有日常路径逐区经过，机位可先在下一空间候场，待人物进入后再交给下一区域；空间的累积显出规模、层级或生活方式 | 每个空间恰好一机位；为炫示布景新增绕行；强加主角情绪抢走环境重点 |
| 声音把注意引向画外 | 决定声源是否需要现身：可以转向揭示，也可保留不可见威胁或期待；人物只按实际接收到的声音行动 | 听到声音就必须下一镜拍声源 |
| 需要练习导演观察 | 复述注意为何从人转到物、从局部转到整体，再比较用切镜、重构图或声音完成 | 将日常眼睛移动次数当分镜次数公式 |

**短案例与证据。** 直线追逐通过追者接近与画面关系变化成为过程戏，而非字母路线例外；眼、手、脚的局部可直接强化奔跑的过程和细节，不只是面部表演的补救。《为黛西小姐开车》以日常下楼带观众逐区经过，环境展示是当段重点：住宅范围和生活条件由空间累积显出，人物情绪不是必需中心。《群鸟》的相关示例又让机位先在室内或走廊等待人物进入，分段打开不同空间；相近形式因情境而改变作用。共同清洁转为关注女主人的反应，显示景别随关注重点改变。魔法空间的行走、观看、细节与画外声音交替扩展认识。均为**文稿例证**，不据文字还原实际房屋平面图，也不把课堂镜数变成拍摄配额。

**条件界限。** 探索、悬念可保留整体地图的未知；追逐战术和多人协作若依赖某个距离或通路，则先使那部分关系可读。叙述者展示的信息可比角色更多，但应分别保存，不能因为观众看过就使人物知道。

**接续。** 选择注意对象接[视点体系与镜头运动地基](../视点体系与镜头运动地基.md)第一、四节；世界空间与画面投影接[角色调度与走位参考库](../角色调度与走位参考库.md)第十一节；信息延迟接[信息素控制参考库](../信息素控制参考库.md)第三节。

<a id="stage-10"></a>
## 10｜揭示、尺度与预期：观众认识不等于人物认识

**机制。** 导演可以安排先见局部还是整体、等待哪个方向的出现、何时扩大或缩小关系，以及观众是否看见角色想知道却尚未感知的事。揭示次序的价值在改变理解或感受，不只是藏东西再亮相。

| 子知识与选择条件 | 执行方式 | 易误用的反例 |
|---|---|---|
| 到陌生地点时需要提出问题 | 从有作用的细节、观看者、位置逐层打开；若小空间一眼足够，则整体判断后直接关注局部 | 所有地点都分三步揭示，或所有地点都先大全景 |
| 人物走向另一人，有多种覆盖可选 | 比较跟移动者、先给目标、从目标一侧看、旁观或俯视：哪种最能交付当下关系与注意 | 人物一动就默认跟拍；目标不漂亮就认为没价值 |
| 相同动作在大小空间中意义不同 | 将人物尺度、环境范围和前后画面相比较，判断体现难度、自由、孤立还是其它关系 | 人小景大自动孤独；放大画面就自动壮阔 |
| 已展示环境，后面的更大空间仍需被重新感到 | 可先收束到手、脸或局部，再打开更大的关系，让相邻尺度反差产生顿挫；比较直接延续大景的另一种体验 | 景别只能一路渐近，或每次大全景前都机械插一张特写 |
| 希望观众形成一个随后修正的预期 | 先用构图留空、方向、物体关系或声音真正建立预期，再从另一处或另一层揭示有意义的信息 | 没有先建立期待就称反转；每场强行误导 |
| 先见局部能让后来的整体改写理解 | 选择鞋、背影、物件或画面边缘时，让随后整体回答此前的问题，并保留必要身份/位置线索 | 为悬念把所有关系都藏掉，揭示后仍不知为何重要 |
| 对峙中的强度与关系发生转折 | 紧处可突出局部接收，介入、缓解或新关系出现时扩大画面；也可保持原尺度观察变化 | 对峙必近景、解决必全景，强制一套景别弧线 |
| 人物希望确认遮挡之后、可见范围之外或周边环境的相关风险 | 可给观众看人物尚未获知的隐藏事件，也可只展开他担忧、检索或希望确认的周边区域；分别保留实见、怀疑与观众获知，随后反应依据真实到达的信息 | 精神探索必有远处隐藏者；把区域展示当风险已证实；把导演跨空间展示写成角色突然获得远处知识 |
| 预期得到兑现而非推翻 | 保留期待成真、关系确认、危险兑现的体验；意外不是唯一收益 | 观众猜到就一律无趣，强改事件以制造意外 |

**短案例与证据。** 《坠入》从儿童相关细节到观看与所在空间逐层展开；《后翼弃兵》的较小地下室可较快完成总体认识，说明两者条件不同。吉他与画面空处引导方向预期，而人物从另一处显现、再揭开更多在场者，体现揭示的层级组织；鞋、背影、世界的顺序用于先提问题再给整体。均为**文稿例证**，不把具体构图预期视为已逐帧证明的唯一读法。

**精神探索的两个分支。** 课内监视例可让观众看见角色想确认却尚未看见的另一处事件；《银翼杀手》例则在发现数字后担心暴露，周边区域成为精神扫描对象（A10:L61–69 / B28:L61–69）。1299 第10课 **25:58** 静帧可见人物仍在庭院全景，字幕指称“这个区域”是精神探索领域；这是 2026-09-28 审计静帧，本次复看，只支持区域展示，不据此断定整段没有监视者或补出连续环顾轨迹。两分支均不替人物确认尚未获得的事实。

**执行界限。** 信息差改变谁何时知道，不免除门、通路、朝向、接触、持物和时间推进的真实关系。心理探索超出角色感知范围时，属于讲述选择，不擅自赋予角色超感知能力。课末仅布置观看的练习没有详细解说，不据片名补造方法结论。

**接续。** 视觉、信息和因果延迟接[信息素控制参考库](../信息素控制参考库.md)第三节；邻接画面互相解释接[蒙太奇与组接意义库](../蒙太奇与组接意义库.md)“库里肖夫效应”；真实空间与注意对象分离接[角色行为与动作叙事参考库](../角色行为与动作叙事参考库.md)第六节。
