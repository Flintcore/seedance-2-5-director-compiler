# 导演判断总纲：把知识组织成选择

本组将五合一课程的68课主题（96份对应转写）转为平台中立的导演方法，不是另一套镜头格式或工具配额。各专题保留方法、执行条件、案例机制与反例，供当前问题按章读取；原有专项的技术细目和大师作品继续使用。

## 先决定观众怎样经历，再选摄影方案

**人物处境与真实应对 → 观众应经历什么 → 信息何时通过谁到达 → 人物感知、反应与行动 → 可行动的关系空间 → 摄影机、光色与声音的组织 → 镜内、镜间、场间的节奏。**

这是综合理解的依赖关系，不是必须顺序完成七份表格。一场戏往往来回调整几项；某处已经锁定就沿用。先讲得清“人在做什么以及为何改变”，再决定怎样让观众看见、听见或暂时无从判断；观看也可以持续深化而不增加事件。

镜头组是此处的基本意义单位：先按[镜头组四问](../戏点选择与主镜框架法.md#镜头组四问摄影选择的上游)形成剧本信息、由此产生的观众情绪、对白/表演塑造的人物及整组观看落点，再明确叙事视角、知情范围和情感距离，选择调度与摄影/光声。单镜职责从整组承接，不把每镜局部漂亮等同整体有效；铺垫、暗示、延迟及有意未解仍按组级意图保留。这些结论沿现有导演前导和镜头字段表达，不新增分析表或审查环。

### 区分六种常被混用的决定

- **注意对象**是此刻重点看谁/什么；**观察位置**是摄影机在哪里；**信息权限**是观众与角色谁先知道；**叙述立场**是如何陪伴或审视。它们可以变化但不是同义词。
- **创作策略**如误导、叙述、暗示、次要人物入口，与主观/第三方/全知等视角分类属于不同问题。借他人引入主角并不自动增加全知信息。
- **人物彼此距离、观众的观看距离、身体投影面积、画面中的可活动领地**分别设计。远处小人物可控制更大领地，大前景身体也可被挤在边缘。
- **刺激—处理—行为后果**是因果关系，不是五步五镜。思考可显在即时行动中，也可被有意保留；表演不是只加面部形变。
- **身体速度、摄影机速度、切换密度、人物情绪与观众张力**分开决定。快打不借理解之名逐招停住；静观也不等于等演员不动。
- **内容观察范围**的背景/关系/个体与**剪辑组织尺度**的全片/场景/镜头是两套分类；一镜可有多个相容功能，分类不产生镜数要求。

### 案例怎样改变本场决定

当泛原则已有、仍不知怎样选择时，读相应案例的“原处境—选择次序—观看结果—另一条件下为何不同”，再落实到当前已允许的动作、空间和声音；不复制片名风格词或把案例重演进新故事。这是阅读与取舍方法，不新增表格、汇报步骤或固定产出。

- 日常任务里的掩饰逐渐失效，或镜面观看转到真人：取[立场与任务18](创作立场与关系表达.md#core-18)；任务本来存在才借其变化表达，不给人物强加招牌动作。
- 关系镜都长得一样：取[不公平与均衡谈判09–10](创作立场与关系表达.md#core-09)、[同职业不同空间11](创作立场与关系表达.md#core-11)；分隔、对称和背景含义由具体关系决定。
- 色彩像不变滤镜，人物与环境被同时一键变色：取[分层演变16](创作立场与关系表达.md#core-16)；声音退出、人物放松与观众压力错位取[情绪与张力18](镜组节奏与跨场组织.md#edit-18)，混合情绪转场取[双重过渡16](镜组节奏与跨场组织.md#edit-16)。
- 旅程省略后像瞬移、快动作碎而无因果、冲击没有释放空间：分别取[边界与中段02](感知反馈与相对调度.md#stage-02)、[追逐反馈06](感知反馈与相对调度.md#stage-06)、[力量与尺度08](感知反馈与相对调度.md#stage-08)；这是不同问题，按需选取而非三节全读。
- 都是奔跑却想产生不同体验，或推拉运镜只剩标签：取[运动与体验15](观看距离与运动光影.md#view-15)、[拉与观察位置11](观看距离与运动光影.md#view-11)；结果如何由个体传到群体取[局部与集体释放04](观看距离与运动光影.md#view-04)。强调前后怎样留出落差取[强调与复位05](镜组节奏与跨场组织.md#edit-05)，文字细节如何改变观看粒度取[细节粒度08](镜组节奏与跨场组织.md#edit-08)。

范围链接落在起始节；只读当前问题涉及的相邻节，不把范围视为固定套餐。当前问题未解决，继续读直接相关章节而非为了少读硬停。

## 旧库与课程共同使用的具体边界

以下校准已发现的绝对口径，保留其背后的有效方法，而非否定旧库：

| 原口径容易导致的错误 | 保留的方法与适用条件 |
|---|---|
| POV必抖、每次成对；单视点必平；作者观察限定次数 | 用可推断的看/对象/反应建立认知归属；已建立关系可省显式配对，稳定观察可成立，严格眼位仍守实际可见范围 |
| 先把旧动作或台词完成再转移 | 允许动作匹配、句中切听者与注意接管，保住动作相位、原声源和连续话语，不把切画面当发声重起 |
| 人人每场必须走位；横向方向固定寓意 | 看位置改变如何影响目标、权利与观看；有意义静止保留，世界方位明确后再推画面投影，左右不自动代表善恶/困难 |
| 情绪变化必运镜/摄影机先于表演、贴脸必慢、作者镜必须返回 | 先保人物真实应对再选观看手段；可静观、快速侵入或保持远距，也可以把注意交给后果并在那里结束 |
| 每次动作都在某个百分比切；反应镜固定配额 | 切点依动作辨识、接触/反应、注意转移和节奏；保留状态承接，不靠统一百分比、秒数或镜数证明力度 |
| 快切等于快打；长镜天然真实 | 真实设计出攻防、调整、受力与后果，持续见证和短促切换各按本回合目的选择 |
| 米兰达固定仰拍、安迪固定俯拍；俯仰永远代表同一种强弱 | 以具体镜组的心理接收、观察关系和前后差异解释；[对白覆盖19](镜组节奏与跨场组织.md#edit-19)及《穿普拉达的女王》已保留反向条件，不把人物身份当恒定机位 |
| 《布达佩斯大饭店》只能糖果色，自然色/去饱和均属风格失败 | 糖果色可作可辨基线，危险、轻盈与重返后的消退可形成变奏；取[色彩16](创作立场与关系表达.md#core-16)和该作品正文，不把配色示意当全片测量或禁令 |
| 暖善冷恶、暗强亮弱、长焦必浅、广角必深 | 情绪解释需人物与前后文，光学需距离/画幅/焦点等条件；物理参数和符号联想分层 |
| 声画永不重复；无音乐等于静音；创意转场更高级 | 声画可互补、强化或反衬；音乐退出时仍可有现场声；硬切、连续桥与鲜明断裂均按叙事功能选择 |
| 平行线固定AB次数、时长一律递减、每场景别向内压 | 组织等待、汇合、对比、同尺度持续及复现变义；结构跟事件和体验，不跟固定分配表 |

这些解释优先于同一知识体系中未经限定的审美配额；它们不撤销已确认的项目选择。空间尺寸、遮挡、支撑、接触、同一时刻的物件所属和人物知情状态仍是实在条件；明确时间省略、梦境、非写实世界须有设计依据，不以艺术意图替偶然矛盾兜底。

## 证据与迁移

各课案例按课堂分析保留，观察、讲者解读、制作史实、教学重建和未核转写分别看待。2026-09-28已对当前68主题及96版本完成全文/对应异文复读，并核对部分原课字幕；这不等于全量原音原画认证。转写同词可能共错，原稿中的异常对白和时码不作精确台词、表演节拍或镜长底本。

只有重学源稿、引用课例原句、核术语或判定具体案例事实时，按需查[课程来源与勘误](课程来源与勘误.md)的对应项；日常设计沿本页进入方法正文，不新增溯源流水线。原片字幕确认只及所列位置，未决词留在证据层，不用猜测补入创作。音乐具体音色、入点与连续运动没有核听/观看就不冒称实证。

课程方法用于决定“拍什么、怎样组织”，既有专项用于细化“怎样执行”，大师作品用于比较具体场景如何取舍。三者互补，课例短述不替代需要时的完整作品研究。本组不要求新增角色、对白、事件、道具、天气或未确认世界设定。
