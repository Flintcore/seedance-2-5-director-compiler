# 人物视线与目光设计参考库

视线把注意力、关系和空间连接起来。设计重点不是给每个目光标角度，而是明确人物看什么、是否看得见、为何此刻看、谁注意到这道视线，以及视线之后做什么。

## 一、视线的五个要素

1. **起点**：哪位人物，以何种身体姿态发出视线。
2. **落点**：具体人物、物件、出口、声源或空间位置。
3. **可见性**：无遮挡、被遮挡、通过反射、只见局部或完全不可见。
4. **动机**：寻找、确认、回避、请求、挑战、监视或告别。
5. **后果**：视线是否触发对视、走位、切镜、移焦或行动。

含糊的“看向远处”应被改成可观察落点，除非未知本身就是戏剧目的。

## 二、头、眼与身体的协调

- 眼睛先动、头部稍后：突然察觉或隐蔽观察。
- 头部先转、眼睛迟到：机械执行、疲劳或注意力尚未跟上。
- 眼与脸朝向目标、身体仍朝别处：心理已转向，行动尚未完成。
- 身体朝目标、眼睛回望：准备离开但仍被关系牵住。
- 只用余光：不愿暴露关注，适合权力、恐惧和监视。
- 完整转身：确认目标足以改变当前行动。

视线幅度应服从距离、人物习惯和当下风险。

## 三、对视的关系语义

| 关系 | 对视方式 | 可能效果 |
|---|---|---|
| 平等试探 | 双方短暂相接又各自移开 | 保留空间，不急于定胜负 |
| 权力压迫 | 一方持续看，另一方被迫回应或避开 | 谁控制结束对视很关键 |
| 亲密确认 | 先共同看物件，再相互看 | 共享记忆或默契先于语言 |
| 欺骗 | 过度维持或刻意避开 | 需结合人物常态判断 |
| 关系破裂 | 一方寻求目光，另一方拒绝 | 拒绝本身成为行动 |
| 危险识别 | 双方目光锁定后身体改向 | 视线进入战术与空间因果 |

不要把“持续对视”自动解释为亲密或威胁。

## 四、视线揭示

### 4.1 先拍人物，再揭示落点

观众先看见反应，再跟随目光发现对象。适合悬念、敬畏、恐惧和人物先于观众知道信息。

### 4.2 先拍对象，再看人物发现

观众预先知道信息，随后等待人物察觉。适合危险、误会和同情。

### 4.3 同镜揭示

通过移焦、摇镜、人物入画或反射，让视线与落点在连续空间中建立。适合强调因果和避免切断表演。

### 4.4 拒绝揭示

只保留人物视线和反应，不给出落点。适合未知、主观崩塌或延迟信息，但后续必须决定是否回收。

## 五、视线接力

多人场面可以用视线接力组织注意力：

1. 声音或动作触发第一人；
2. 第一人的视线指向第二人或物件；
3. 第二人的反应重新分配群体注意力；
4. 某个未看的人形成反差或秘密；
5. 行动从新的注意力中心开始。

群体不必整齐地同时转头。不同察觉速度、利益关系和遮挡会产生更可信的层次。

## 六、空间与连续性

- 建立人物、落点和摄影机所在轴线。
- 正反打中，目光方向应让观众理解双方相对位置。
- 人物跨越轴线或摄影机换侧时，用移动、共同入画或中性镜重建关系。
- 通过镜面、玻璃或监控观看时，明确人物实际面对方向与影像中的方向。
- 视线离画方向会制造期待；下一镜若不回应，应有明确的延迟或反预期目的。
- 多段连续场景要继承人物最后的视线落点、头身相位与尚未完成的反应。

## 七、视线与景深

- 浅焦可暂时隔离人物与所看对象，适合延迟揭示。
- 移焦让观众沿人物认知路径从一个落点转向另一个落点。
- 深焦允许观众同时比较观看者与被观看者，适合权力和秘密。
- 遮挡可让人物看见观众看不全的对象，或反过来。

焦点变化应由注意力和信息变化驱动。

## 八、视线与表演

视线不是独立动作。它与呼吸、手部、距离和发声结合：

- 看向对方前先收住正在做的事，说明注意力被夺走；
- 说话时看物件而不看人，让物件承担真实话题；
- 目光接触后恢复日常动作，可以替对方保留体面；
- 战斗中视线先确认路线、武器和第三方，再触发身体转向；
- 受伤或疲劳会缩短视觉搜索范围并降低反应精度。

## 九、常见失真与修正

| 失真 | 原因 | 修正 |
|---|---|---|
| 目光没有明确对象 | 落点只写“远处”或“某处” | 指定空间锚、物件或人物部位 |
| 眼睛看一处，身体无故朝另一处 | 头眼身关系未设计 | 说明这是过渡相位还是故意隐瞒 |
| 所有人同步转头 | 忽略察觉顺序和利益差异 | 按声源、遮挡和关系安排接力 |
| 正反打方向混乱 | 缺少轴线与双方站位 | 先建空间，再决定越轴是否有意义 |
| 每次视线都切对象 | 剪辑过度解释 | 在关键揭示才切，其他时刻允许观众推断 |
| 对视只有情绪没有结果 | 关系没有变化 | 让一方移开、靠近、让位、说话或行动 |

最终判断：视线是否把人物的注意力转化成空间和行动，而不是只给脸部增加一个动作。

## 十、对白中的目光交涉与落点执行

日常交流以实际受话者为默认注意对象，而不是持续盯摄影机。直接交流可写“看着对方的脸说完前半句”；边做事边谈时，明确手上任务、看向对方的触发和转回任务的时机。自然眨眼保留，无须规定注视时间占比。

一条可用的关系链：她抬眼寻求回应，他仍看手里的文件；她停止解释、转去收拾杯子，他这时才抬眼看她。意义在双方错过与重新分配主动权，先移开目光的人不必然弱势。听者可以先看说话者，再因一句话确认第三人的反应；若第三人尚未听懂，反应就应落后于知情者。

区分三种可见性：角色能否看见目标、摄影机能否看见目标、观众能否读到角色的眼睛。目标可以在画外，眼睛也可以被帽檐或反光遮住；设计仍需明确实际落点。过肩反打时，受话者脸通常在镜头旁的某处，直视镜头只用于已确定的主观或直面观看设计。跨镜需继承最后所看对象和转头阶段，不用模糊“眼神游移”替代一次有原因的注意转移。
