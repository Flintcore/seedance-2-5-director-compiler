# 角色调度与走位参考库

调度是人物目标在空间中的形状。人物移动、停下、转身、让路、占位或保持不动，都应改变距离、权力、视线、可达路径或观众理解。表演是微观身体层，调度是宏观空间层，两者由同一动机驱动。

## 一、先建立可行动空间

在设计走位前，明确：

- 入口、出口、门窗、走廊、楼梯和可穿越区域；
- 桌、床、车辆、栏杆、掩体等会阻挡或引导动作的物件；
- 人物进入时的世界位置、朝向和正在做的事；
- 谁能看见谁，哪些视线被遮挡；
- 哪些位置具有权力、隐私、危险或逃生意义；
- 镜头结束时必须继承的空间状态。

空间不是背景图。任何重要走位都要经过真实路径，并考虑障碍、距离和身体转向。

## 二、三种坐标同时成立

### 2.1 世界坐标

人物在场景中的真实位置，例如“门内侧”“餐桌靠窗端”“车尾右侧”。世界坐标不随摄影机换位而改变。

### 2.2 画面坐标

人物在当前构图中的左、中、右与前、中、后景位置。它由摄影机所在轴线一侧、焦距和机位决定。

### 2.3 关系坐标

人物相对他人或关键物件的关系，例如“挡在孩子与门之间”“比对手更接近枪”“仍在亲密边界之外”。关系坐标直接服务戏剧。

换机位时先保世界与关系坐标，再重新计算画面坐标。不要为了维持画面左右而扭曲人物真实位置。

## 三、调度的主要动机

| 动机 | 空间表现 | 可能代价 |
|---|---|---|
| 接近 | 缩短距离、进入共同区域、共享物件 | 暴露自己、越过边界 |
| 回避 | 侧身、绕开、转向任务或保持障碍 | 可能失去出口或信息 |
| 压迫 | 占据中线、出口、高位或对方行动路径 | 需要承担更直接的冲突 |
| 保护 | 身体进入威胁与他人之间 | 自身路线受限 |
| 观察 | 保持距离、利用遮挡或高低差 | 信息不完整、介入较慢 |
| 逃离 | 目光与身体先转向出口，再移动 | 会暴露恐惧或放弃目标 |
| 诱导 | 故意让出位置或开放一条路线 | 对手若不跟随，计划失效 |
| 照料 | 靠近并完成实际任务 | 亲密可能与语言态度冲突 |

移动必须由触发产生：台词、声源、物件变化、他人靠近、危险出现或人物决定。

## 四、距离与关系

- **亲密距离**：适合照料、威胁、秘密和身体控制；进入必须有许可、突然越界或明确冲突。
- **对话距离**：保留完整身体反应和物件互动，适合多数关系场面。
- **公共距离**：强调制度、表演性和难以接近。
- **分隔距离**：门框、桌、玻璃、栏杆或人群把心理边界变成物理边界。

距离变化比静态距离更有意义。谁先靠近、谁退、谁不动，以及变化后是否恢复，都会定义关系。

## 五、轴线与屏幕方向

### 5.1 建轴

轴线可来自人物之间、人物与目标之间或主要运动方向。建立镜应让观众理解关键位置，不要求展示全部空间。

### 5.2 守轴

在同一侧拍摄可保持目光和运动方向稳定。正反打时，双方视线应在画面中相向，除非刻意制造断裂。

### 5.3 重建轴

人物或摄影机移动改变关系时，可通过以下方式重建：

- 同镜看见人物跨过旧轴；
- 摄影机在运动中经过中性位置；
- 用正面或背面中性镜暂时消除左右关系；
- 先给新空间建立镜，再进入新的正反打。

### 5.4 有意义的越轴

越轴可以表现关系翻转、主观失衡或安全秩序破裂，但必须让观众先拥有旧关系，并在越轴后获得新的可读锚点。纯粹为变化角度而越轴只会制造方位错误。

## 六、调度与摄影机

### 固定摄影机

让人物穿越构图、改变前后景或进入离开边界。适合见证、仪式、尴尬和空间权力变化。

### 跟随

摄影机与人物共同移动，强调任务路线与主观陪伴。跟随距离和侧别应由观众与人物的关系决定。

### 反向运动

人物逼近而摄影机后退，会维持距离并延长压力；摄影机逼近静止人物，则让观众主动进入其状态。两者含义不同。

### 重新构图

人物视线、起身、坐下或他人入画可以触发摇移、升降或焦点变化。摄影机调整应回应关系变化，而不是抢先替人物制造情绪。

## 七、多人场面

多人调度先分层：

- 当前行动中心；
- 能改变局势的次要人物；
- 尚未介入但提供反应或威胁的人；
- 群体环境与通行路径。

通过三角关系、前中后景、视线接力和行动差异保持可读性。不要让所有人同时朝同一方向、做同一反应，也不要为了平均展示而逐个给镜头。群体位置随联盟和目标变化重新组织。

## 八、静止与静息层

人物不移动时仍有空间行为：

- 保持或拒绝某个距离；
- 身体朝向与目光朝向不一致；
- 手停在未完成动作上；
- 重心准备前进、撤退或支撑伤处；
- 呼吸、衣料、环境风和周围人物继续变化；
- 不让路、不坐下或不接物本身构成选择。

静止应有动机，不需要为了“电影感”强加走位。

## 九、动作场面的空间调度

动作场面先建立：

- 各方起点、目标、出口与危险区；
- 掩体、武器、障碍和高低差；
- 谁控制中线、距离和视野；
- 每一轮交手后谁换位、受限或失去路线；
- 群战中的局部目标与离画威胁。

动作执行模块会展开逐拍方向和惯性；导演调度负责确保这些动作服务人物策略与空间戏剧。

## 十、跨镜与跨段连续

每次切换保留：

- 人物世界位置与画面侧别；
- 身体和头部朝向；
- 正在进行的动作相位；
- 速度、重心和未消散动量；
- 手持物、伤势和环境损伤；
- 最后视线落点与谁已察觉什么。

若下一镜故意改变其中一项，必须在镜内给出可见原因。

## 十一、常见失效

| 失效 | 根因 | 修正 |
|---|---|---|
| 人物无故走来走去 | 移动没有目标或触发 | 让走位改变距离、路线、物件或权力 |
| 只有脸部表演 | 空间没有参与关系 | 用座位、出口、障碍和物件建立宏观行为 |
| 换机位后左右漂移 | 混淆世界与画面坐标 | 先锁世界位置，再投影到新构图 |
| 对白按发言轮次切 | 忽略听者与关系变化 | 让切点跟随理解、反应和动作 |
| 群像像排练队形 | 所有人共享同一目标和节奏 | 分配不同注意力、任务和介入时机 |
| 站桩恐惧导致过度走位 | 把运动当质量 | 保留有动机的静止与受阻动作 |
| 越轴只为视觉变化 | 没有关系翻转 | 守轴，或先设计能被观众读懂的重建过程 |

最终判断：人物是否因为想要某件事而占据这个位置，并在场面结束时留下新的空间关系。
