# 角色调度与走位参考库

调度是人物目标在空间中的形状。人物移动、停下、转身、让路、占位或保持不动，都应改变距离、权力、视线、可达路径或观众理解。表演是微观身体层，调度是宏观空间层，两者由同一动机驱动。

## 一、先建立可行动空间

在设计走位前，明确：

- 入口、出口、门窗、走廊、楼梯和可穿越区域；
- 桌、床、车辆、栏杆、掩体等会阻挡或引导动作的物件；
- 人物进入时的世界位置、朝向和正在做的事；
- 谁能看见谁，哪些视线被遮挡；
- 哪些位置具有权力、隐私、危险或逃生意义；
- 镜头结束时必须继承的空间状态。

空间不是背景图。任何重要走位都要经过真实路径，并考虑障碍、距离和身体转向。

## 二、三种坐标同时成立

### 2.1 世界坐标

人物在场景中的真实位置，例如“门内侧”“餐桌靠窗端”“车尾右侧”。世界坐标不随摄影机换位而改变。

### 2.2 画面坐标

人物在当前构图中的左、中、右与前、中、后景位置。它由摄影机所在轴线一侧、焦距和机位决定。

### 2.3 关系坐标

人物相对他人或关键物件的关系，例如“挡在孩子与门之间”“比对手更接近枪”“仍在亲密边界之外”。关系坐标直接服务戏剧。

换机位时先保世界与关系坐标，再重新计算画面坐标。不要为了维持画面左右而扭曲人物真实位置。

## 三、调度的主要动机

| 动机 | 空间表现 | 可能代价 |
|---|---|---|
| 接近 | 缩短距离、进入共同区域、共享物件 | 暴露自己、越过边界 |
| 回避 | 侧身、绕开、转向任务或保持障碍 | 可能失去出口或信息 |
| 压迫 | 占据中线、出口、高位或对方行动路径 | 需要承担更直接的冲突 |
| 保护 | 身体进入威胁与他人之间 | 自身路线受限 |
| 观察 | 保持距离、利用遮挡或高低差 | 信息不完整、介入较慢 |
| 逃离 | 目光与身体先转向出口，再移动 | 会暴露恐惧或放弃目标 |
| 诱导 | 故意让出位置或开放一条路线 | 对手若不跟随，计划失效 |
| 照料 | 靠近并完成实际任务 | 亲密可能与语言态度冲突 |

移动必须由触发产生：台词、声源、物件变化、他人靠近、危险出现或人物决定。

## 四、距离与关系

- **亲密距离**：适合照料、威胁、秘密和身体控制；进入必须有许可、突然越界或明确冲突。
- **对话距离**：保留完整身体反应和物件互动，适合多数关系场面。
- **公共距离**：强调制度、表演性和难以接近。
- **分隔距离**：门框、桌、玻璃、栏杆或人群把心理边界变成物理边界。

距离变化比静态距离更有意义。谁先靠近、谁退、谁不动，以及变化后是否恢复，都会定义关系。

## 五、轴线与屏幕方向

### 5.1 建轴

轴线可来自人物之间、人物与目标之间或主要运动方向。建立镜应让观众理解关键位置，不要求展示全部空间。

### 5.2 守轴

在同一侧拍摄可保持目光和运动方向稳定。正反打时，双方视线应在画面中相向，除非刻意制造断裂。

### 5.3 重建轴

人物或摄影机移动改变关系时，可通过以下方式重建：

- 同镜看见人物跨过旧轴；
- 摄影机在运动中经过中性位置；
- 用正面或背面中性镜暂时消除左右关系；
- 先给新空间建立镜，再进入新的正反打。

### 5.4 有意义的越轴

越轴可以表现关系翻转、主观失衡或安全秩序破裂，但必须让观众先拥有旧关系，并在越轴后获得新的可读锚点。纯粹为变化角度而越轴只会制造方位错误。

## 六、调度与摄影机

### 固定摄影机

让人物穿越构图、改变前后景或进入离开边界。适合见证、仪式、尴尬和空间权力变化。

### 跟随

摄影机与人物共同移动，强调任务路线与主观陪伴。跟随距离和侧别应由观众与人物的关系决定。

### 反向运动

人物逼近而摄影机后退，会维持距离并延长压力；摄影机逼近静止人物，则让观众主动进入其状态。两者含义不同。

### 重新构图

人物视线、起身、坐下或他人入画可以触发摇移、升降或焦点变化。摄影机调整应回应关系变化，而不是抢先替人物制造情绪。

## 七、多人场面

多人调度先分层：

- 当前行动中心；
- 能改变局势的次要人物；
- 尚未介入但提供反应或威胁的人；
- 群体环境与通行路径。

通过三角关系、前中后景、视线接力和行动差异保持可读性。不要让所有人同时朝同一方向、做同一反应，也不要为了平均展示而逐个给镜头。群体位置随联盟和目标变化重新组织。

## 八、静止与静息层

人物不移动时仍有空间行为：

- 保持或拒绝某个距离；
- 身体朝向与目光朝向不一致；
- 手停在未完成动作上；
- 重心准备前进、撤退或支撑伤处；
- 呼吸、衣料、环境风和周围人物继续变化；
- 不让路、不坐下或不接物本身构成选择。

静止应有动机，不需要为了“电影感”强加走位。

## 九、动作场面的空间调度

动作场面先建立：

- 各方起点、目标、出口与危险区；
- 掩体、武器、障碍和高低差；
- 谁控制中线、距离和视野；
- 每一轮交手后谁换位、受限或失去路线；
- 群战中的局部目标与离画威胁。

动作执行模块会展开逐拍方向和惯性；导演调度负责确保这些动作服务人物策略与空间戏剧。

## 十、跨镜与跨段连续

每次切换保留：

- 人物世界位置与画面侧别；
- 身体和头部朝向；
- 正在进行的动作相位；
- 速度、重心和未消散动量；
- 手持物、伤势和环境损伤；
- 最后视线落点与谁已察觉什么。

若下一镜故意改变其中一项，必须在镜内给出可见原因。

## 十一、常见失效

| 失效 | 根因 | 修正 |
|---|---|---|
| 人物无故走来走去 | 移动没有目标或触发 | 让走位改变距离、路线、物件或权力 |
| 只有脸部表演 | 空间没有参与关系 | 用座位、出口、障碍和物件建立宏观行为 |
| 换机位后左右漂移 | 混淆世界与画面坐标 | 先锁世界位置，再投影到新构图 |
| 对白按发言轮次切 | 忽略听者与关系变化 | 让切点跟随理解、反应和动作 |
| 群像像排练队形 | 所有人共享同一目标和节奏 | 分配不同注意力、任务和介入时机 |
| 站桩恐惧导致过度走位 | 把运动当质量 | 保留有动机的静止与受阻动作 |
| 越轴只为视觉变化 | 没有关系翻转 | 守轴，或先设计能被观众读懂的重建过程 |

最终判断：人物是否因为想要某件事而占据这个位置，并在场面结束时留下新的空间关系。

## 十二、基本身体动作的执行层次

从既定空间和人物体能出发，选择动作真正需要的过程。下列是动作设计选项，不是每次出镜的部位清单；身体差异、伤势、服装与角色风格会改变次序和幅度。

| 动作 | 可落实的起势、传力与落定 | 人物差异可以放在哪里 |
|---|---|---|
| 启步 | 承重脚支撑，重心向去向转移，另一脚迈出；步态建立后手臂和衣料跟随 | 决断者先看清目标再直接迈步，犹豫者可只移重心而暂不离地 |
| 停步 | 最后几步吸收前行动量，支撑脚接地，躯干和手臂的余摆随后收住 | 赶到的人可脚已停而呼吸未平；装作从容的人先收住身体再开口 |
| 日常转身 | 注意先转向目标，头、肩、躯干和脚步分层跟进，也可由任务先带动身体 | 回头但脚仍朝出口是尚未决定留下；转完后重新对准对方才是完整回应 |
| 警觉转身 | 声源或目击触发快速定位，躯干跟上，脚步重新组织支撑，衣摆保留滞后 | 熟练者边转边确认路线；受限者先护住物件或伤处，不共用一个回头动作 |
| 沉重转身 | 躯干近整体地转，头肩分离较少，足部换位承接重心 | 沉重可以来自疲劳、负重、谨慎或形式化表演，不直接等于悲伤 |
| 坐下 | 到达椅前，确认座面，转至可坐方向，屈髋屈膝下降，接触后重量转交座面 | 有人扶扶手，有人不用手；身体落定后是否调整衣物或座位由需要决定 |
| 起身 | 脚掌获得支撑，重心前移，腿伸展带起躯干；扶手或大腿只在需要时提供辅助 | 起了一半又坐回会暴露犹豫；急起的人也要实际离开座面并恢复平衡 |
| 蹲下、弯腰拾物 | 区分降低全身重心与髋部折叠；手到达物件、建立抓握，再带重量起身 | 膝髋活动范围、另一手支撑、负重大小改变动作；拾取与直身可有不同节奏 |

固定的关节角度、步速与完成秒数不通用于所有身体。真正保留的硬条件是：重心变化有支撑或明确失衡过程，接触对象处于可达位置，手在握住后才带动物件，动作结束后的支撑与持物进入下一镜。

## 十三、双人关系如何在走位中推进

- **边走边谈**：先确定谁认路、谁迫使对方跟上。说话者可短暂转头看听者，再看路；听者的看人、避障和脚步各有节奏。并排、错半个身位和门口先后次序可改变控制关系，步伐同步也可用于熟悉、训练或仪式，不把不同步当通则。
- **逼近与回避**：一人接近后，另一人通过退步、侧身、障碍或保持不动选择边界。关键转折可是一方再次靠近、对方这次没有退，而非所有对峙都逐步贴脸。
- **带领与追随**：路线由谁决定，另一人何时因门、转角、楼梯或迟疑拉开距离；通过真实路宽安排前后，不凭心理标签指定步距。
- **擦肩与回看**：先给相向路线，在最近处让肩身与通行空间相容；相认可发生在接近时、擦过时或事后回头，三者交付不同信息。
- **协同搬运**：两人各有接触点和承重，起抬、转向、过门、放下共同改变物件姿态。轻微失配可显示陌生或紧张，熟练合作也可以整齐；桌子倾斜应来自实际两端高度变化。
- **高低交换**：站立者蹲至坐者附近可减少俯视差，也可能更具侵入性；上台阶、让出座位、占住出口的意义由行为和关系决定。人物脚位、高差和目光俯仰仍需同时成立。

入画、出画先是空间事件：从摄影机后方进入会与观众共享去向；走入纵深会改变可见尺度；遮挡后离开会留下未知。向左或向右没有跨文化、跨场景固定的善恶或时间含义，先服从已建立的目的地和屏幕方向。

## 十四、长镜群像的三层活动

将宏观走位、身体任务、静息状态分开考虑，但只呈现本镜读得到的层。需要自然生活感的静镜可以让呼吸、承重、视线或手上任务随处境继续，而不是循环抖动。屏息、专注凝住、睡眠或风格化静止都有自己的条件。

深焦群像中，让重要配角拥有可辨的当前任务、注意对象和介入触发。例如前景人物解释时，中景同伴整理被递来的文件，后景守门者先听见门外动静才回望；主角说出名字后，同伴手上的文件停在半途。背景保持较低权重，直到戏需要它接管注意；共享突发声、舞蹈或军礼可以同步反应，平常生活则按各自所知和位置错时。
