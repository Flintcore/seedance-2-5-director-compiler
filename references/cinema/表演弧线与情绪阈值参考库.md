# 表演弧线与情绪阈值参考库

表演弧线描述人物如何维持常态、受到压力、跨过阈值并进入新状态。阈值不是统一强度数字，而是人物原有控制方式失效的具体时刻。

## 一、四个阶段

### 1. 常态

建立人物平时如何说话、呼吸、移动、处理物件和保持距离。没有常态，观众看不出后续偏差。

### 2. 扰动

触发进入感知，人物先出现轻微偏离：动作中断、视线滞留、改口、重心变化或习惯动作加快。

### 3. 阈值

人物原有策略无法继续，必须爆发、承认、撤退、麻木、改变目标或做出不可逆行动。阈值应由累积压力和明确触发共同造成。

### 4. 余波

人物尝试恢复，但新状态已留下：声音改变、距离不同、物件归属变化、身体受限或关系无法回到原位。

短场可以压缩阶段，长场可以反复扰动与恢复，但变化逻辑仍需可追溯。

## 二、阈值类型

| 类型 | 跨越条件 | 可见结果 |
|---|---|---|
| 信息阈值 | 证据足以推翻原有理解 | 视线、任务或话语策略改变 |
| 关系阈值 | 对方越过不可接受边界 | 距离、称呼、接触或退出发生变化 |
| 身体阈值 | 疲劳、疼痛、缺氧或伤势超过控制 | 姿态、动作范围和呼吸改变 |
| 道德阈值 | 人物决定承担原先拒绝的代价 | 行动不可逆，表情可保持克制 |
| 时间阈值 | 等待、期限或重复行为终于失效 | 节奏突然中断或行动启动 |
| 群体阈值 | 旁观者、权威或联盟改变局面 | 群体视线与站位重新组织 |

## 三、递进不是放大

可通过不同维度推进：

- 控制成本上升：人物需要更多动作维持平静；
- 选择减少：出口、借口或盟友逐步失去；
- 公开策略改变：玩笑变解释，解释变沉默；
- 身体任务失效：倒水洒出、扣子扣错、步伐停下；
- 与他人节奏错位：一方已经放松，另一方仍紧绷；
- 注意力收窄或扩散：从观察全场到只锁定一个对象。

情绪峰值也可以表现为突然安静、动作缩小或停止抵抗。

## 四、复合情绪

复合情绪不是两张表情同时叠加，而是目标冲突在时序中显现：

- 想笑又不该笑：嘴角启动，眼睛先检查他人，随后压回；
- 想留下又必须走：身体朝门，手仍停在共同物件上；
- 愤怒同时害怕：语言进攻，重心却保留退路；
- 松一口气又感到羞耻：呼吸释放后避开目光；
- 爱与怨并存：照料动作继续，称呼和距离却变冷。

让观众看到两种冲动如何争夺同一身体。

## 五、多人表演弧

多人场面不要同步升级。分别设计：

- 谁先察觉；
- 谁最需要维持表面秩序；
- 谁误读他人的变化；
- 谁在阈值到来前仍执行日常任务；
- 谁的反应成为另一人的新触发；
- 场面结束时谁恢复、谁停留在余波中。

关系弧可以由节奏同步、错位、距离缩短、位置互换或共同静止表现。

## 六、表演与摄影

- 关键变化若发生在身体与空间中，优先保留中景或双人镜。
- 近景用于需要区分控制和泄露的时刻，不按情绪强度自动靠近。
- 固定摄影可让观众见证完整转变；跟随可贴近人物正在执行的目标。
- 切镜可落在触发、理解、控制失败或对方反应，取决于观众位置。
- 光线和音乐只能支持表演，不替人物完成转变。

## 七、余韵

余韵应回答“阈值之后，什么再也回不到原样”。可落在：

- 人物不再使用原来的称呼；
- 物件被留下、收回、损坏或转交；
- 两人恢复日常动作，但距离改变；
- 人物尝试说话却选择沉默；
- 身体恢复呼吸，某个伤势仍限制动作；
- 环境继续运行，与人物的新状态形成反差。

余韵持续多久由理解完成决定，不套固定秒数。

## 八、作品锚点

- 《海边的曼彻斯特》：人物通过回避、停顿和无法完成的社会动作表现创伤阈值。
- 《婚姻故事》：争吵由策略改变和控制失败升级，峰值后仍保留关系余波。
- 《一次别离》：每次新信息都改变人物公开策略和道德位置。
- 《花样年华》：长期克制让极小偏差成为重要转折。
- 《燃烧女子的肖像》：观看、被观看与共同任务逐步改变亲密关系。

## 九、常见失效

| 失效 | 根因 | 修正 |
|---|---|---|
| 情绪只按强度升级 | 没有策略和选择变化 | 改变控制方式、信息或空间关系 |
| 峰值突然出现 | 常态与累积不足 | 先建立人物如何维持自己 |
| 所有人同时爆发 | 缺少独立目标 | 安排错位反应和相互触发 |
| 复合情绪变脸来回切 | 没有行动冲突 | 让两种目标争夺同一动作 |
| 高潮后立即恢复 | 状态没有记忆 | 保留身体、物件和关系余波 |
| 摄影和音乐代替表演 | 人物行为缺少证据 | 回到触发、控制和行动结果 |

阈值成立的标准是人物不得不换一种方式继续，而不是表情变得更大。
