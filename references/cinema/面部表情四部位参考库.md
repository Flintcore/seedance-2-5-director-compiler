# 面部表情四部位参考库

面部细节只在观众需要区分人物控制、泄露和转变时使用。眉、眼、鼻与嘴相互影响，但无需每次全部描述；景别、表演风格和人物习惯决定可见程度。

## 一、眉部

- 内眉抬起可伴随悲伤、请求或无助；
- 双眉下压可伴随集中、防御或愤怒；
- 单眉变化适合怀疑、试探或讽刺；
- 眉部不动而其他部位变化，可表现刻意控制。

眉形没有唯一情绪含义，需要结合视线与嘴部。

## 二、眼部

- 上眼睑抬起与眼白增多会提高警觉感；
- 下眼睑收紧可表现集中、怀疑或压住情绪；
- 眨眼中断、加快或延迟，常显示注意力和控制变化；
- 泪水、湿润与泛红属于身体过程，不应自动等同哭泣；
- 焦点落点、对视时机和移开方式比抽象“眼神”更有信息。

## 三、鼻与中面部

- 鼻翼扩张常与呼吸、用力、愤怒、恐惧或欲望相连；
- 鼻梁与上唇附近的收紧会改变厌恶、疼痛和压抑感；
- 中面部动作幅度通常较小，适合近景中的控制破裂；
- 呼吸原因必须成立，避免把鼻翼变化当通用强情绪标记。

## 四、嘴、下颌与喉部

- 嘴唇压紧、微启、撤回微笑或句尾失去支撑，都可显示话语控制；
- 下颌绷紧与放松显示行动准备或压力释放；
- 吞咽、喉结和起音受阻能连接内在压力与发声；
- 不对称嘴角可能是讽刺、忍笑、疼痛或神经性反应；
- 真诚、敷衍与掩饰由剧本及表演过程建立，不凭单个面部动作判断真实内心。

## 五、组合逻辑

有效组合先有触发，再有主部位变化，其他部位只提供支持或矛盾：

- 人物听到坏消息：视线停住是主变化，下颌随后绷紧，嘴部维持礼貌；
- 人物试图撒谎：声音继续，眨眼与吞咽出现偏离，手部可能同步自我安抚；
- 人物看懂对方但不揭穿：眼神短接后移开，嘴部不回应，恢复日常动作；
- 人物决定反击：视线锁定、呼吸重置、下颌放松后身体进入行动。

不要把多个高强度细节同时堆在同一瞬间。

## 六、时序

面部变化常包含察觉、尝试控制、泄露和恢复。谁先动取决于人物：

- 训练有素者可能先压住嘴部，眼睛稍后泄露；
- 冲动者身体和嘴部先反应，随后才意识到后果；
- 疲惫者反应较慢，恢复也不完整；
- 关系亲密者能读懂极小偏差，陌生人需要更明显证据。

时序由触发和人物控制力决定，不套固定延迟。

## 七、景别与光线

- 全景主要读姿态和头部方向，微表情不是关键信息载体；
- 中景可读脸部整体、手和身体配合；
- 近景适合看控制破裂和视线变化；
- 极近特写只在单一细节不可替代时使用；
- 侧光、逆光、遮挡和浅景深会改变哪些部位可见，应与叙事目标协调。

## 八、常见失效

| 失效 | 原因 | 修正 |
|---|---|---|
| 眉眼鼻嘴全部排满 | 用数量替代人物意图 | 选择一个主部位和必要支持 |
| 每种动作固定一种情绪 | 忽略情境 | 用触发、目标和后果解释 |
| 微表情承担全景关键信息 | 景别不可读 | 改用姿态、走位或必要近景 |
| 表情从静止直接跳到峰值 | 缺少察觉与控制 | 加入转变过程或保留余波 |
| 所有人表情方式相同 | 缺少人物习惯 | 建立各自的控制与泄露模式 |
| 面部与身体互不相关 | 表演被拆成部位 | 让呼吸、重心和行动共同变化 |

面部细节的价值在于区分这一位人物在这一刻如何控制自己。

## 九、小幅面部动作如何接进一句话

可从“先有反应、随即管理”与“维持表面、稍后松开”两类时序里选取：眉梢抬起想反问，又慢慢放平；眼皮稍抬以确认受话者，随后视线回到正在做的事；嘴唇微启但让对方先说，等听完才起音；含着的笑仍在，嘴角先松一点，声音才变软。这里的先后比毫米数、固定延迟更有表演价值。

面部器官动作不是测谎或内心诊断：视线回避、吞咽、眨眼、鼻翼变化都可能来自环境、身体任务或习惯；瞳孔受照度和生理状态等影响，不作为演员随意精确执行的情绪按钮。明确需要辨别细小面部形态时，按需读下节已核验的动作参照；普通表演设计仍使用实际可见、可自然表演的动作。

## 十、AU / FACS 动作参照（条件取用）

FACS 描述可观察的面部动作，AU 是动作形态参照，不是情绪、真诚或谎言的译码表。先从已给剧本确定人物策略，再选择可见动作；不从眨眼、鼻翼或一个微笑反推真实人物内心。下表是常用动作的简释，供创作辨形，不替代正式 FACS 编码训练或完整手册。

| 编号 | 可观察动作 |
|---|---|
| AU1 | 内侧眉部抬起 |
| AU2 | 外侧眉部抬起；单侧设计另说明左右 |
| AU4 | 眉部下压并向中间靠拢 |
| AU5 | 上眼睑抬起 |
| AU6 | 脸颊抬起 |
| AU7 | 眼睑收紧 |
| AU9 | 皱鼻 |
| AU12 | 嘴角向上、向外牵拉 |
| AU15 | 嘴角下压 |
| AU23 | 唇部收紧、变窄 |
| AU24 | 双唇压合 |
| AU25 | 双唇分开 |
| AU26 | 下颌下落 |
| AU45 | 眨眼；次数和时机另用事件描述 |

**容易混淆的动作**：鼻翼随吸气扩张不等于皱鼻；嘴唇轻颤不等于唇部收紧；双唇微分也不证明下颌下落。咬唇、咬紧牙关先按各自可见动作描述，不自动附带唇收紧。外眉单侧抬起需要说明侧别；回到原态、连续两次和轻重程度不是新增 AU 编号。视线落到谁、何时回视仍由具体世界目标和事件定义，AU 不替代视线设计。

AU6 只说明脸颊参与，有无 AU6 都不是笑容真诚与否的证明。角色真诚、敷衍或掩饰来自剧本及整条表演过程，不靠编号定性。部位同时激活也不保证自然：与发声、呼吸、姿势、光线和可见范围一起设计。
