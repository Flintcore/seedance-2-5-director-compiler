# 角色与场景设定参考库

本库负责把故事中的人物和空间变成可拍、可连续、可辨认的视觉事实。设定不是字段越多越好；只固定会改变身份、叙事、调度或连续性的特征。

## 一、设定的三个证据层

| 层级 | 含义 | 处理 |
|---|---|---|
| Visible | 输入素材或文本直接可见、可知 | 原样保留，不用推断覆盖 |
| Inferred | 可由时代、职业、动作和环境合理推出 | 作为设计选择，保持克制并标明依据 |
| Missing | 会影响镜头但当前没有答案 | 选择最少承诺的方案，或在影响核心因果时向用户确认 |

参考素材只承担声明的职责。人物图可定义身份外观，场景图可定义空间与材质，动作视频可定义运动特征；任何素材都不会自动创建另一个人物或继承无关内容。

## 二、角色设定维度

### 身份锚

- 年龄阶段与生活痕迹；
- 体型、身高关系和轮廓；
- 脸部几何、发型、肤质、可见标记；
- 服装轮廓、层次、材质、磨损和适配方式；
- 随身物、职业工具或关系物件；
- 姿态基线、步态、惯用手和动作习惯；
- 声音、语速、口音与呼吸特征；
- 社会身份、当下目标和不能被他人看见的欲望。

### 连续状态

每段只追踪会变化的部分：

- 在场的物理实例数量；
- 空间位置、朝向、视线与遮挡；
- 手中或身上的物品及归属；
- 衣物开合、湿度、污渍、伤口、汗和血的位置；
- 当前姿态、重心、动作相位与动量；
- 知道了什么、误解了什么、情绪控制处于何种阶段。

### 景别分配

- 远景优先轮廓、颜色块、位置关系和步态；
- 中景优先服装层次、手部行为、姿态和物件；
- 近景优先眼神、皮肤、呼吸、嘴部与细小伤痕；
- 特写只强调当前戏剧证据，不重复整份角色档案。

## 三、场景设定维度

### 空间骨架

- 场所类型、时代、地理与用途；
- 可走区域、门窗、通道、层高和高差；
- 固定锚点、前中后景、遮挡与视线通道；
- 世界方向、屏幕方向和关键对象之间的距离；
- 人物可完成动作的真实路径与安全边界。

### 物质与时间

- 主要材质及其反光、吸光、摩擦和破坏方式；
- 光源来源、方向、软硬、色温关系和变化；
- 天气、空气、尘雾、水汽与环境运动；
- 时段、季节、使用痕迹和社会秩序；
- 环境声、画外活动和空间混响；
- 会在本场变化的物件与状态。

### 场景身份锚

选择少数一眼可辨、跨镜稳定的要素，例如：

- 一条独特轴线；
- 一个不可移动的建筑特征；
- 一组稳定的光源关系；
- 一种主材质与磨损方式；
- 一个与人物关系绑定的物件；
- 一种具有叙事作用的背景活动。

空间锚必须进入调度或构图。仅罗列装饰不会增强连续性。

## 四、人物与空间的关系

角色设定和场景设定需共同回答：

1. 谁拥有中心、出口、光源或高地？
2. 谁需要绕过谁，谁能直接穿越空间？
3. 哪个物件在人物之间传递权力或信息？
4. 空间如何限制身体、声音和视线？
5. 转折发生后，人物与空间的关系有何不可逆变化？

例如，“狭小厨房”只有在桌角阻断接近、油烟遮住视线、冰箱声吞掉低语或门口被某人占据时，才成为戏剧空间。

## 五、跨镜与跨段连续性

建立一份轻量状态向量，包含：

- 人物 ID 与实例数；
- 位置与朝向；
- 视线与接触；
- 道具归属与状态；
- 服装、伤痕和环境痕迹；
- 动作相位与动量；
- 主光、天气和持续声源。

每次切换只更新实际发生变化的项。上一段退出状态应能成为下一段进入状态；若发生跳时、换装、空间跳跃或叙事断裂，明确把变化作为新的场景事实。

## 六、身份与真实感

- 独特性来自结构和生活逻辑，不来自无关装饰堆叠。
- 职业应通过工具使用、姿态、磨损位置和空间熟练度显现。
- 服装需适应动作、天气和社会身份；美术选择要有使用痕迹。
- 脸部一致性依赖稳定几何、发型轮廓、标记和光线关系，不能只写“同一个人”。
- 场景真实感来自因果：水会留下湿痕，灰尘会被脚步扰动，破坏会改变后续路径。
- 群像中先确定每人的功能、轮廓和位置，不为背景人物编写同等密度的档案。

## 七、常见失败

| 失败 | 后果 | 修正 |
|---|---|---|
| 所有维度都逐镜重复 | 信息拥挤，真正变化被淹没 | 全局固定身份锚，镜内只写活跃状态 |
| 只有素材编号，没有职责 | 身份与动作继承混乱 | 明确每项素材定义什么、排除什么 |
| 场景只有气氛词 | 调度没有落点 | 建立门窗、轴线、距离和遮挡 |
| 每镜重新描述外观 | 容易漂移且拖慢编译 | 统一身份锚，按景别调用可见特征 |
| 伤痕、湿度、道具在切点重置 | 连续性破裂 | 将状态写入退出与进入接口 |
| 为“丰富”增加新饰品或背景人物 | 实例与美术失控 | 新元素必须服务戏剧或空间功能 |
| 把推断写成用户事实 | 锁定层被污染 | 区分 Visible、Inferred、Missing |

## 八、协同入口

- 角色调度与走位：把空间骨架转为路径和权力关系。
- 景别、机位与焦距：决定哪些设定特征真正可见。
- 光影与色彩：固定场景身份和人物可读性。
- 物理交互与破坏：更新材质和道具状态。
- 镜头衔接与连续性：传递跨镜、跨段状态向量。
