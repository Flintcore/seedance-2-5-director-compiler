# 运镜设计参考库

运镜是摄影机在空间和时间中的叙事选择。先决定观众为何移动、跟随谁、何时开始、在哪里结束，再选择轨迹与技术。静止摄影机同样是有效选择。

## 一、运镜的六个锁

1. **叙事动机**：陪伴、追踪、揭示、逼近、退让、重新组织关系或体验失衡。
2. **主体与参照**：摄影机相对谁移动，背景中什么证明运动。
3. **起始状态**：景别、机位、人物位置、动作相位和当前焦点。
4. **触发点**：哪句台词、哪个视线、动作或声源启动运动。
5. **路径与速度变化**：方向、曲线、加减速以及与人物节奏的关系。
6. **终止状态**：运动为何停下，结束时观众获得什么新关系或信息。

缺少终点的运动容易变成无目的漂移。

## 二、基础运动

### 推近

改变观看距离，适合进入决定、发现、压迫或亲密。推近不等于“情绪更强”；它应在终点揭示新的表演、物件或关系。

### 拉远

把人物重新放回环境，适合显示代价、孤立、真相范围扩大或关系无法挽回。拉远也可从私密时刻恢复为公共视点。

### 横移

保持与主体相对距离，同时展示路线、障碍和空间层次。横移适合陪伴行走、揭示并列关系或让前景遮挡产生节奏。

### 摇镜

摄影机原地转向，适合跟随视线、声源、快速事件或在有限空间中重新分配注意力。摇镜速度应服从触发和目标距离。

### 升降

改变人物与空间结构的关系。升起可逐步揭示地形、群体或后果；下降可进入人物、物件或地面危险。高度变化不自动代表权力变化。

### 环绕

改变背景、侧别和人物关系，可用于决心形成、两人权力交换或空间封闭。环绕前后要明确轴线如何保持或重建。

### 跟随

摄影机维持人物的任务路线和身体节奏。可从前方后退、侧面平行、背后跟进或在人物间接力，不同位置决定观众是被带领、陪伴还是追赶。

### 手持

手持不是随机抖动。它的呼吸、步频、惯性和修正动作应来自摄影者或人物的身体处境。可表现现场性、危险、亲近和失控，也可保持克制。

## 三、摄影机与人物的关系

| 关系 | 观众感受 | 设计重点 |
|---|---|---|
| 同速陪伴 | 与人物共享任务 | 保持距离与路线可读 |
| 摄影机领先 | 被引向人物即将面对的空间 | 终点必须有信息或压力 |
| 摄影机落后 | 人物离开观众或难以追上 | 保留方向和障碍 |
| 人物逼近、摄影机后退 | 压力持续但距离暂时不变 | 退路与停止原因 |
| 摄影机逼近静止人物 | 观众主动进入人物状态 | 避免用运动替代表演 |
| 摄影机不动、人物穿越 | 空间先于人物，强调见证 | 构图内的进入、遮挡和离开 |

## 四、速度与节奏

速度不是固定数值，而是相对于人物动作、镜头尺度和戏剧节拍：

- 匀速产生稳定、程序性或不可避免感；
- 加速表示信息追赶、危险逼近或控制丧失；
- 减速把注意力交给细节、决定或阻力；
- 突然停止可让观众撞上一个事实；
- 延迟启动让人物先行动，摄影机随后选择跟随；
- 反向运动会改变原有关系，适合转折。

复杂动作需要更清楚的空间参照；情绪细节需要足够稳定的观看时间。

## 五、复合运镜

复合运镜不是把多种技术串起来，而是让关系分阶段变化。常见结构：

- 跟随人物进入空间，随后停止，让人物独自继续；
- 推近某人，再由其视线触发横移或摇镜揭示对象；
- 环绕改变双方侧别，终点形成新的权力构图；
- 从低位升起，由局部动作过渡到全局后果；
- 先拉远显示孤立，再让前景人物进入改变关系。

每次转向或换轨都需要触发。若去掉一段运动不损失意义，就删去它。

## 六、长镜头内的运动

长镜头可由摄影机运动、人物调度、焦点、遮挡和声音共同分段。摄影机不需要持续移动：

- 开始时保持观察，让行动自然发生；
- 当人物目标改变时，选择跟随或留在原地；
- 新人物或声源出现时重新构图；
- 临界动作前可减速或停止；
- 结果发生后让人物离开或把空间留在画面中。

固定段落和运动段落的对比常比持续复杂轨迹更有力量。

## 七、动作场面的运镜

- 先用能读懂的景别和机位建立路线、目标与危险区。
- 跟随应服务追逐方向和身体动量，不在接触瞬间无故绕到另一侧。
- 手持强度与人物速度、地面和危险同步。
- 关键命中可由摄影机保持见证、随受力方向短促响应，或留在防守者反应上；选择由动作美学决定。
- 群战在全局关系与局部节点之间切换，不让摄影机平均巡视所有人。
- 奇观运动必须保留人物、建筑或地形作为尺度参照。

逐拍方向和惯性由动作执行模块展开，导演运镜负责观看立场与空间可读性。

## 八、转场与接力

- 人物出画方向可在下一镜得到运动接力。
- 相似形状、颜色、动作或声源可触发匹配转场。
- 前景遮挡可自然隐藏切点，但前后空间和运动需要连续。
- 鞭摇可连接突发注意力或时空跳跃，必须有清楚起因与落点。
- 声音先行或延后能改变切镜关系，不要求画面与声音同时结束。

## 九、光学与物理边界

- 焦距改变空间压缩、边缘畸变和运动感，不能只当景别参数。
- 摄影机越接近主体，轻微运动越显著，也更容易暴露路径不稳。
- 长焦跟随需要更稳定的目标与对焦，广角贴近会夸张速度和距离。
- 轨道、稳定器、肩扛、手持、车载和航拍各有真实惯性与高度限制。
- 运动模糊、快门感和景深应与运动目的协调，不用技术效果掩盖方位。

## 十、作品锚点

- 《好家伙》：跟随路线让人物进入权力世界，空间发现与角色体验同步。
- 《人类之子》：运动维持连续危险和道德见证，不让剪辑卸掉压力。
- 《花样年华》：缓慢横移、遮挡与重复路线承载未说出口的关系。
- 《大象》：走廊跟随建立人物时间线和空间交叉。
- 《闪灵》：稳定跟随把建筑秩序转化为心理威胁。
- 《谍影重重》：手持与快速修正来自现场压力，同时保留任务方向。

## 十一、常见失效

| 失效 | 原因 | 修正 |
|---|---|---|
| 每镜都在慢推 | 把运动当默认质感 | 让戏剧变化决定是否移动 |
| 随机手持 | 抖动没有身体来源 | 同步步态、地面和人物危险 |
| 环绕只为炫技 | 背景变化不改变关系 | 设计侧别或权力在终点发生变化 |
| 长镜持续绕场 | 没有内部段落 | 用触发、停顿和重新构图组织 |
| 跟拍看不懂路线 | 缺少入口、出口和参照物 | 先建立空间，运动中保留方向锚 |
| 复合运动堆叠 | 每段都没有独立任务 | 只保留不可替代的关系变化 |
| 运动结束无新信息 | 终点未设计 | 先锁终帧，再反推路径 |
| 摄影替人物制造情绪 | 表演和行动太弱 | 让人物先产生真实变化 |

最终判断：摄影机为何在这一刻离开原位，以及它停下时观众比之前多理解了什么。
