# 特效真实感引擎

本库讨论影视特效如何参与叙事、摄影和表演。所谓真实感，不等于把一切做成现实世界已有的样子，而是让观众相信画面中的能量、材质、尺度和后果遵守同一套世界规则。

## 一、可信特效的六个支点

### 1. 动机光

发光体必须改变附近表面的亮度、色温、阴影和反射。光的影响应随距离、遮挡和材质变化：皮肤呈柔和反射，金属出现方向明确的高光，粗糙墙面形成扩散色染。若特效在移动，环境光也应沿运动路径变化。

### 2. 重量与次级运动

重量来自启动、加速、制动和落定的差异，而非单纯慢动作。大型物体先积累力量，再带动衣物、尘埃、碎屑或水面；轻质能量可以快速转向，但仍要对空气、头发和悬挂物产生可见扰动。次级运动稍晚于主动作发生，形成因果层次。

### 3. 摄影机见证

摄影机位置决定特效是否具有尺度。远景负责交代范围和空间关系，中景负责人物与现象的互动，近景负责接触、材质和表演反应。镜头震动、曝光变化或焦点偏移只能来自画内事件对摄影机的实际影响，不应成为通用装饰。

### 4. 介质与空气

光束、热浪、冲击、飞行和爆炸需要经过空气、烟、雾、雨、尘或水时留下传播证据。介质会改变边缘清晰度、颜色、速度感和可见距离，也会让前后景共享同一事件。

### 5. 材质响应

特效必须根据接触对象改变表现。木材沿纹理断裂，混凝土先崩角再粉化，金属先屈曲后撕裂，玻璃形成裂纹网络后脱落，湿地面保留反光和飞溅。不同材质不能共享同一种碎片、烟尘和回弹方式。

### 6. 后果留存

事件结束后，世界不能立即复原。余光、烟尘、残火、积水、凹痕、碎屑、人物呼吸和听觉余震都是后果。后果既确认力量，也为下一镜提供连续状态。

## 二、两条美学路线

| 路线 | 目标 | 主要方法 | 适用场景 |
|---|---|---|---|
| 物理写实 | 让异常现象像真实拍摄所得 | 实景光源逻辑、克制规模、明确接触、真实材质、有限摄影机反应 | 科幻悬疑、灾难、近身超能力、写实奇幻 |
| 图形化风格 | 让夸张现象服从统一视觉法则 | 稳定的形状语言、色彩层级、节奏重复、轮廓控制、象征性运动 | 神话、武侠、动画化真人影像、梦境、仪式场面 |

两条路线都要求内部一致。图形化并非免除物理因果，而是把因果转化为节奏、形状、色彩和空间压力。

## 三、常见特效族的设计重点

### 能量与力场

- 先确定能量从哪里产生、向哪里传播、何时衰减。
- 用附近表面反光、空气扰动和人物遮挡确认空间位置。
- 接触瞬间区分吸收、反弹、穿透、切割和爆裂，它们应产生不同后果。
- 持续存在的力场需要边界、厚度感和内部状态。稳定区、边缘与受击点不必同亮；冲击应从接触位置向周围传播，再按材料或世界规则衰减、回弹或失效。
- 两股能量持续相抵时，交界位置要随力量变化移动，并把反作用传给施力者、地面和周围介质。胜负通过交界推进、姿态和环境后果被看见，不只靠一方变亮。
- 能量刃或高温束接触实体时，先确定是热切割、冲击、穿透还是表面烧蚀；不同机制产生不同断面、熔融、碎屑、烟与声音。
- 冲击波主要靠传播前沿经过空气、尘、水、衣料、植被和松散物的先后反应显形。响应强度随距离、遮挡和介质改变，不能整片环境同时运动。

### 火焰与爆炸

- 爆炸由闪光、压力波、火焰、烟尘和碎片组成，各层速度不同。
- 人物反应受距离、遮蔽物和朝向影响；近距离先承受压力，远距离可先见光后闻声。
- 爆炸之后保留烟尘流向、火点、落屑和空间损伤，不以一次明亮火球结束。

### 水、雨与液体

- 先建立水体体积、流向、黏度和重力方向。
- 接触人物时让衣料吸水、皮肤反光、发丝黏连，地面形成积水和反射。
- 大水体的尺度来自前中后景速度差、漂浮参照物和声音低频，而非只靠浪高。

### 烟、雾与尘

- 烟雾应受热源、风向、障碍物和人物运动影响。
- 用密度分层保留可读性：关键动作发生处需要轮廓或逆光窗口。
- 尘土是碰撞和破坏的后果，起点、扩散方向与落定位置必须可追溯。

### 生物、变形与再生

- 先确定骨架、关节和质量如何改变，再设计皮肤、毛发或甲壳的表面变化。
- 变形需要中间状态；每一步都应影响重心、姿态、呼吸和服装。
- 恐怖感常来自熟悉身体结构被有秩序地改变，而非无规则堆叠细节。

### 全息影像与界面

- 明确投射源、观看角度、遮挡关系和交互方式。
- 让光线影响手指、脸部或桌面，但强度服从场景主光。
- 界面信息只保留剧情需要的层级，避免让装饰抢走人物行动。

### 东方奇幻与武侠能量

- 先从人物身法、兵器路径或呼吸节奏中产生视觉形态。
- 能量运动要延续动作方向和发力链，不能与身体动力相互脱节。
- 山水、风、尘、布料、竹叶、水面或建筑成为力量的环境见证，让抽象招式落入具体空间。

### 位移、重力与时空变化

这类特效的重点不是能量外观，而是身体或物体如何改变位置，以及世界怎样证明这种改变。

- **飞行与推进**：先确定升力或推力来源、加速度、转向和制动。起飞会改变脚下尘土、积水、植被或松散物；掠行留下气流、介质扰动和声场变化；急转与停下会把负荷传给身体、服装、载具或周围结构。
- **超高速运动**：先区分连续跑过空间、主观时间拉伸与真正的瞬间跳变。连续运动需要可追踪路径，沿途物体按经过次序响应；若周围时间被相对放慢，雨滴、碎片、声场和摄影机也要服从同一时间关系。
- **传送门与空间折叠**：门两侧是两个真实空间，光、空气、声音、遮挡和景深可彼此穿越。身体通过边界时保留前后部分的连续几何，进入前的方向与动量应在另一侧得到结果，除非世界规则明确改变它。
- **重力操控**：先定义力场中心、方向和作用范围。人物重心、悬浮物姿态、液体表面和微小尘粒应服从同一场；异常重力可以违背日常方向，但内部不能各自随意运动。
- **瞬移**：瞬移没有连续路径，因此离开点和到达点是两个不同的空间事件。离开会改变原位置的空气、尘与遮挡，到达会挤开新位置的介质；人物朝向、姿态、持物和动量是否继承必须由世界规则决定并跨镜一致。
- **尺寸变化**：比例变化会同时改写景深感、纹理尺度、声场、空气阻力、地面承载和人物与日常物件的关系。若世界保留质量或动量，需要看见相应后果；若采用另一套规则，应先建立并持续遵守。

### 机械、能量与材质变形

变形不是两个完整造型之间的瞬间替换，而是触发点、传播前沿、中间态和完成态组成的过程。

- **机械展开与装甲成型**：说明零件从哪里来、沿什么结构展开、如何绕过关节并完成连接。尚未闭合的区域应能看见支撑、缝隙和运动方向；完成后的重量、活动范围、声音与反光随新结构改变。
- **流体或纳米组装**：流动前沿具有黏度、表面张力和附着路径，已成型区与仍在流动区呈现不同材质。汇流、分叉、绕行和固化要服从身体曲面与关节运动，不把成型当作表面贴图擦除。
- **能量汇聚与实体化**：环境可先出现风向、静电、微粒、声压或光照变化，随后能量从分散态汇聚成边界清楚的对象。实体形成时要结算重量、握持、反作用和周围介质的释放。
- **材质相变**：石化、金属化、冰晶化或其他相变应有可追踪前沿和半转换区域。新表面出现后立即改变反射、透光、摩擦、柔韧性和动作负荷，不能只换颜色纹理。
- **生物变形与再生**：骨架、软组织、表皮、毛发、服装和重心按因果顺序改变。再生从明确边缘或内部结构推进，完成后仍保留血流、湿度、肤色、活动能力和人物反应等连续状态。
- **可逆与中断**：若变形能逆转或被打断，中间态必须有自己的受力、可动范围和脆弱点；下一镜从实际停止的位置继续，而不是重新播放完整过程。

## 四、CG 材质与解算层

以下是影视特效工艺中的通用判断维度，不是固定参数或现成造型。只读取画面实际包含的材质与模拟类型，并让它们共享本场光线、天气、尺度和运动条件。

| 对象 / 解算 | 可信证据 | 常见失真 |
|---|---|---|
| 皮肤、蜡、玉等半透明材质 | 次表面散射让薄处在逆光下透出内部色，厚处更实；表面油脂高光与内部透光分层 | 均匀自发光、蜡质塑料感、透光方向与主光无关 |
| 毛发与皮毛 | 发束有层级，根部受身体带动，发梢滞后；湿毛结缕、贴身并改变高光 | 每根独立乱动、轮廓沸腾、湿度不改变形态 |
| 布料 | 褶皱沿重力、关节和受力点传播，不同厚度有不同坠感、回弹与余荡 | 贴身冻结、穿透身体、薄纱与厚呢共享一种运动 |
| 金属与拉丝表面 | 环境反射随角度移动，拉丝材质出现沿纹理延展的各向异性高光；磨损、氧化和变形遵守制造结构 | 统一银色高光、像涂银塑料、反射中没有本场环境 |
| 湿表面与水膜 | 水膜增强并拉长反射，水滴受重力汇聚，干湿边界和低洼积水可见 | 全面镜面化、水珠固定不动、湿痕在切镜后消失 |
| 粒子系统 | 每个粒子受重力、气流、湍流和碰撞影响，尺寸、寿命和轨迹存在有因的分布；发光粒子影响附近介质 | 同速同向、整齐生成、无来源消失、发光却不照亮周围 |
| 流体 | 表面张力、黏度、体积、折射和飞溅共同决定形态；水、黏液、油与熔融物拥有不同断裂和流动方式 | 所有液体像同一种薄水、无附着、无二次飞溅或残留 |
| 刚体破坏 | 裂纹从受力和结构弱点传播，碎块按质量与初始受力走不同轨迹，内部结构与断面随后暴露 | 物体均匀炸开、碎块同速、断面无结构、落地前消失 |
| 烟、火与体积介质 | 热量驱动上升和翻卷，风改变整体方向，密度从核心向边缘过渡；内部光照随火源和遮挡变化 | 整团平移、边缘硬且恒定、烟与火互不影响、尺度没有参照 |

## 五、镜头内的因果组织

一个复杂特效镜头可按四个问题组织，而不是堆叠视觉名词：

1. **规则**：观众先看见现象的来源、边界或尺度。
2. **接触**：力量与人物、物件或空间发生明确接触。
3. **响应**：光、材质、空气、声音和表演按先后关系回应。
4. **余波**：镜头结束时留下可延续的物理与心理状态。

若场面规模很大，先用一个可比较的参照物建立尺度，再进入局部接触。若场面强调人物体验，先让人物察觉异常，再揭示全貌；特效的出现顺序应服从观众视点。

## 六、声音与特效的共同重量

- 低频表现体量与空间压力，高频瞬态表现断裂、穿刺和碎屑。
- 声音到达时间受距离和介质影响，远处事件可先见光、后闻声。
- 突然抽掉环境声可表现冲击后的主观听觉，但必须与人物状态相连。
- 持续能量需要稳定底噪和细节变化，避免每一秒都处于同一响度。

## 七、作品锚点

- 《阿凡达》：生物发光与环境光相互作用，奇观始终嵌入生态规则。
- 《少年派的奇幻漂流》：数字生物的重量通过水面、船体、视线和空间反应被共同确认。
- 《降临》：异常现象依靠尺度、雾、声场和克制摄影建立可信压力。
- 《银翼杀手 2049》：全息角色的光色和尺度服务关系，而不是独立展示技术。
- 《怪形》：变形过程保留材料感、中间状态和表演反应，使身体恐怖可触。
- 《拆弹部队》：冲击波以尘土、碎石、衣料和主观感知表现力量传播。

引用作品时只提取与当前场景相关的方法，并根据本片世界规则重新设计，不复制表面造型。

## 八、常见失败与修正

| 失败 | 根因 | 修正方向 |
|---|---|---|
| 特效像贴在画面上 | 缺少遮挡、环境光和景深关系 | 让现象进入真实空间层次并改变附近表面 |
| 规模很大却没有重量 | 缺少启动、参照物和次级反应 | 建立尺寸参照，延迟环境响应，保留余波 |
| 动作华丽但看不懂 | 来源、路径或接触点不清 | 用视点、轮廓和时间顺序恢复因果 |
| 角色与奇观互不相干 | 表演和调度未受事件影响 | 让察觉、躲避、失衡和恢复进入同一动作链 |
| 所有材质同一种破坏 | 未区分结构与受力方式 | 按纹理、韧性、脆性和连接点设计损伤 |
| 画面持续高强度 | 缺少建立与释放 | 在规则、接触、峰值和余波之间形成节奏差 |

最终判断只有一句：特效是否改变了人物、空间和下一刻的状态。若没有，它只是覆盖在镜头上的装饰。
