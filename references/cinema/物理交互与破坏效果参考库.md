# 物理交互与破坏效果参考库

本库服务导演域：判断材料如何受力、破坏如何改变空间、人物如何承受后果，以及摄影机应站在哪里见证。逐拍接触、方向、速度、惯性和连续状态由动作执行模块展开。

## 一、物理事件的因果链

任何交互先建立五个环节：

1. **施力来源**：人体、武器、车辆、压力、火、风、水或结构自重。
2. **接触几何**：接触点、角度、受力面积、支撑点和运动方向。
3. **材料响应**：弯曲、压缩、拉伸、滑移、开裂、穿透或回弹。
4. **次级传播**：碎片、粉尘、液体、振动、声音和附近物体的延迟反应。
5. **留存后果**：损伤、残留物、人物行动受限、路线变化和下一镜状态。

省略中间环节会让破坏像凭空出现；省略后果会让力量失去重量。

## 二、固体材料

### 2.1 玻璃

- 受尖锐集中力时，裂纹从接触点放射并形成小块脱落。
- 受大面积冲击时，整片先弯曲或震颤，再形成更广裂纹网络。
- 钢化玻璃倾向碎成较小颗粒，普通窗玻璃会出现较大锐利碎片。
- 碎片方向受冲击方向、框架约束和重力共同影响；框中通常保留残片。

### 2.2 陶瓷

- 陶瓷脆而少弯曲，裂缝迅速贯穿，形成大小不均的尖锐碎片。
- 空心杯碗破裂时，内容物先受容器加速，随后沿缺口和惯性泼出。
- 釉面碎片与内部粗糙断面有不同反光。

### 2.3 混凝土与石材

- 表面先崩角、剥落和粉化，强冲击才形成贯穿裂缝或块体脱落。
- 钢筋混凝土破坏后可露出弯曲钢筋，结构不会像无支撑石块整齐散开。
- 裂纹会沿薄弱界面、已有损伤和支撑关系传播。

### 2.4 木材

- 木材沿纹理劈裂，断口有长短不一的纤维与尖刺。
- 横向冲击可让板材弯曲、连接点拔出或铰链先失效。
- 湿木更重、更韧；干木更易碎裂并产生细屑。

### 2.5 金属

- 薄金属先凹陷、起皱和撕裂，厚金属更多表现屈曲、刮擦与连接点失败。
- 刀刃、弹体或车辆碰撞留下的形状与受力路径一致。
- 火花只在适当的高速摩擦、切削或电气条件下出现，不是所有碰撞的默认反应。

### 2.6 塑料与复合材料

- 硬塑料可形成白化应力纹、尖裂或局部凹陷。
- 柔性塑料会拉伸、折皱和回弹，破口边缘受制造纹理影响。
- 夹层材料破坏时应显示各层不同响应，而不是同质碎裂。

### 2.7 布料、纸张与绳索

- 布料先被拉紧，张力沿纤维和缝线传播，再从薄弱处撕开。
- 纸张受湿后变重、黏连和卷曲；干纸撕裂产生轻小纤维。
- 绳索断裂会释放已储存的张力，末端向相反方向甩回。

### 2.8 冰与冻结表面

- 薄冰受局部压力先出现放射裂纹，再形成不规则塌落。
- 厚冰裂缝传播较慢并伴随低频结构声，水会从裂缝或破口上涌。
- 冰面摩擦低，人物恢复平衡和物体滑移都会延长。

### 2.9 人体与生物组织

人体反应先作为表演、特技、化妆和特效共同完成的材料行为来判断，不以固定受伤等级代替具体受力。

- 软组织会在接触点先压缩、拉伸或错动，随后力量才传到躯干和整体重心。接触面积越小，局部变化越集中；面积越大，整体位移和失衡通常更明显。
- 肌肉紧张、关节角度、支撑脚、护具和衣物会改变力量路径。已经绷紧的身体、松弛的身体和主动卸力不能共享同一种反应。
- 突然受力时，躯干、头部、四肢、发丝和衣物存在惯性先后；末端通常晚于重心变化。后续护痛、呼吸、支撑方式、视线和动作范围应延续这一结果。
- 倒地是连续接触过程：失去支撑、身体旋转或折叠、某一部位先触地、其余部位继续运动，再由地面材质决定滑移、回弹或停住。人物不会无过程地直接变成平躺姿势。
- 皮肤、脂肪、肌肉、骨骼与软骨具有不同的压缩、弯曲和支撑作用。画面只需呈现当前景别能读到、且对动作结果有意义的层次，不把解剖细节当装饰。
- 生物或怪兽要先定义皮肤、鳞片、甲壳、软体、骨架和关节的结构。受力、变形与破损沿既定结构传播；不同物种不能共用一套橡胶式形变。
- 组织、伤口、污渍、肿胀、湿度、服装破损和活动限制都是连续状态。切镜后保留它们的位置、方向和发展阶段，除非时间跳跃或治疗在剧情中明确发生。

## 三、液体

液体表现由体积、黏度、表面张力、容器形状、速度和落差共同决定。

| 类型 | 主要特征 | 摄影重点 |
|---|---|---|
| 水、酒精、清茶 | 流动快，薄膜和小滴容易分离 | 飞溅起点、透明折射、地面扩散 |
| 牛奶、咖啡、汤 | 更能显示连续液片与挂壁 | 容器边缘、衣物吸收、颜色污染 |
| 蜂蜜、机油、糖浆 | 拉丝、延迟流动、厚重附着 | 接触后的持续变形和残留 |
| 影视血液 | 具有黏度、表面张力和不透明度；会滴落、流淌、飞溅、转印、稀释和逐渐失去湿亮 | 来源与方向、表面附着、服装吸收、干湿阶段和跨镜连续 |
| 油漆 | 遮盖底色、形成滴挂与不透明飞点 | 表面污染图案与后续脚印、手印 |
| 泥浆 | 液体与颗粒共同运动，落地后堆积 | 重量、飞块和人物行动受限 |
| 泡沫 | 体积大但质量轻，破裂和消散明显 | 边缘、光泽和附着变化 |

泼洒后应保留湿痕、滴落、脚印、反光或衣料重量变化。液体不能在接触后消失。

### 血液作为影视流体与连续状态

- **先定来源机制**：喷出、持续流淌、单滴坠落、物体擦带和接触转印是不同事件。方向来自伤口位置、接触运动、身体姿态和重力，不默认向四周均匀扩散。
- **再定运动形态**：流动中的液体沿皮肤、衣料、道具和地形的最低可达路径移动；飞溅受冲击方向控制；液滴离开表面后受表面张力收拢，撞击后按角度与材质形成不同边缘和拖尾。
- **区分承接表面**：硬质光滑表面更容易保留液滴、反光和流痕；粗糙或多孔表面会吸收并扩散；织物沿纤维和褶皱渗透、加重并可能转印到其他物体。
- **保留状态变化**：湿润阶段高光较明显，随后反光减弱、颜色和边缘发生变化；与水、雨、泥或清洁动作混合后，透明度、流动性和污染范围会改变。具体颜色由灯光、材质和整体调色共同决定。
- **记录转移链**：血迹从身体转到手、衣物、地面、武器、车辆或他人时，每一次接触都留下方向和所有权证据；清理只改变实际被擦拭、冲洗或遮盖的区域。
- **跨镜连续**：记录来源位置、主要流向、覆盖范围、干湿阶段、附着表面和新增转印。后一镜从前一镜的实际状态继续，不能重置、镜像或无因扩大。

血液的画面强度由故事、视点和作品尺度决定；物理知识只负责让已选择呈现的内容具有来源、材料行为和连续后果。

## 四、爆炸与冲击

爆炸不是单一火球，而是传播顺序不同的现象：强光、压力、火焰、烟、碎片和结构响应。导演先决定观众距离与遮挡，再选择看见哪些层。

- **近距离主观体验**：先出现曝光和身体失衡，听觉可短暂受损，画面保留呼吸与方向迷失。
- **中距离见证**：可看清压力对尘土、窗户、衣料和人物姿态的传播。
- **远距离尺度**：用建筑、车辆、树木或地形作为参照，声音与画面允许存在距离差。
- **室内爆炸**：压力受墙面、门窗和走廊引导，出口附近响应更强。
- **定向爆破**：碎片与破口集中在预设方向，其他区域仍受震动影响。

爆炸后的烟尘、火点、结构损伤、掉落物和人物听觉状态必须进入余波。

## 五、碰撞

### 5.1 人体与环境

- 先确认人物哪一部位接触，身体其余部分如何继续运动。
- 墙面、栏杆、桌面或地面会改变旋转、折叠和落地方向。
- 疼痛不只在命中瞬间；护痛、呼吸、支撑方式和动作范围会在后续持续。

### 5.2 车辆

- 碰撞前先建立车辆方向、速度差、道路摩擦和可能逃生路线。
- 车体先在接触区变形，随后整体偏航、旋转或翻滚。
- 乘员、玻璃、悬挂、轮胎和散落物响应时间不同。
- 翻滚结束后保留车轮转动、液体泄漏、报警声、烟尘和人物方位混乱。

### 5.3 坠落

- 高度、姿态、落点材料和缓冲物决定后果。
- 轻物先受空气影响，重物路径更稳定；碎片可能晚于主体落定。
- 落地之后的反弹、塌陷、尘土和结构声确认重量。

## 六、自然破坏

### 树木

树干先弯曲或局部开裂，纤维撕裂与树冠惯性不同步。倒向受风、坡度、切口和冠幅影响，枝叶在接触地面后继续振动。

### 山体与泥石流

先出现局部落石、裂缝或表土滑移，再形成更大质量运动。前缘、主流和尾部速度与材质不同，沿途会裹挟树木、车辆和建筑碎片。

### 地震

不同结构具有不同振动频率。悬挂物、小物件和门窗先提供细节证据，随后墙面、梁柱和地面损伤升级。摄影机反应取决于它是固定设备、手持见证还是人物主观。

### 风暴与洪水

风通过植被、布料、雨线、漂浮物和声场显形；水通过流向、深度参照、漂浮物速度和对建筑的持续压力显示规模。

## 七、火焰与烟

- 火焰依赖燃料、氧气、风向和表面形状，不同材料燃烧颜色与烟量不同。
- 火焰向上发展但会沿可燃路径横向传播；热量改变附近空气、皮肤、金属和塑料。
- 烟先沿顶面和通道积聚，逐步降低可见度并影响人物姿态与呼吸。
- 灭火后仍有蒸汽、余烟、积水、焦黑表面和结构不稳定。

## 八、粒子与碎片

碎片群应有大小分布、不同初速度、相互碰撞与落定。粉尘受空气和重力影响，密度会随距离和时间变化。粒子首先是力量传播的证据，其次才是视觉层次。

常见失真包括：

- 所有碎片同速同向；
- 尘土在空中冻结或突然消失；
- 碎片穿过人物与墙面；
- 破坏区域干净无残留；
- 次级物体比主冲击更早响应；
- 材质不同却共享同一种断裂和声音。

## 九、摄影选择

- **远景**：确认规模、传播路径和空间后果。
- **中景**：同时保留人物动作、接触点和环境响应，是多数物理事件的核心景别。
- **近景**：用于材料细节、关键接触或人物反应，不替代空间建立。
- **固定机位**：让力量通过画内变化自行证明，适合大尺度或突发事件。
- **跟随机位**：让观众经历路线与失衡，需保留方向参照。
- **切点**：可在接触前制造预期、在接触瞬间强调冲击，或留到后果完成再切；选择取决于戏剧目的。

最终判断是：事件是否改变人物可做的事、空间可走的路以及下一镜必须继承的状态。
