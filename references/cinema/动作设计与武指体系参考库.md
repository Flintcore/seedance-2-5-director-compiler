# 动作设计与武指体系参考库

本库只负责动作美学：人物为何这样打、观众从什么视点观看、身体与空间呈现何种风格。战术因果、逐拍时间、方向、接触、惯性和连续状态由动作执行模块负责。

## 一、动作先表达人物

动作段落围绕人物目标改变或持续争夺戏剧事实；一组连招可共同推进一项，不要求每一击都增加事件：

- 人物目标：逃脱、保护、夺取、拖延、试探或压制；
- 关系：优势易手、信任破裂、牺牲发生或身份暴露；
- 身体：疲劳、伤势、恐惧、技术和道德边界显现；
- 空间：出口、掩体、高地、距离或障碍的控制权改变；
- 主题：暴力被呈现为荣耀、劳动、混乱、代价、荒诞或悲剧。

先写动作前后的关系差，再选择招式和摄影机。若删掉打斗后故事状态不变，动作通常只是装饰。

## 二、七种动作美学家族

| 美学家族 | 身体逻辑 | 摄影机态度 | 节奏与声音 | 代表参照 |
|---|---|---|---|---|
| 写意飞天 | 身体摆脱日常重力，姿态舒展，运动路径具有书法性 | 展示完整轨迹与空间层次 | 滞空与突进交替，衣料、风和兵器声参与 | 程小东体系、《新龙门客栈》 |
| 硬桥硬马 | 脚下有根，腰胯传力，攻防拆解清楚 | 中近景和全身镜兼顾技术与受力 | 接触明确，恢复和疲劳可见 | 袁和平体系、《卧虎藏龙》的地面交锋 |
| 超常仙侠 | 身体、能量与环境遵循一套世界规则 | 先建立尺度与规则，再展示奇观 | 蓄势、释放、对抗和余波有层次 | 徐克、程小东等写意动作传统 |
| 动画化夸张 | 拉伸、停顿、形变和图形节奏优先 | 构图与剪辑强调关键姿态 | 冲击前后的节拍反差明显 | 《雾山五行》《一人之下》 |
| 战术射击 | 目标、掩体、视线、弹药和队形驱动行动 | 跟随受训视点，保持地理可读 | 武器与空间声学承担压力 | 迈克尔·曼《盗火线》 |
| 现代 CQB | 近距离决策、切角、控制与环境利用 | 距离贴近但关键接触仍清楚 | 短促、实用、错误代价直接 | 《疾速追杀》、执法训练影像 |
| 港式连续特技武打 | 短打、摔投、腾跃与地形机会连接，身体喜剧或残酷并存 | 按攻击线、触点、后果与新威胁连续转交观看，可连续拍也可切 | 连招压迫与有目的的局部节奏反差，材质后果持续 | 洪家班、袁家班等动作风格参照 |

这些家族是选择入口，不是混搭清单。通常选一条主家族，再因人物或场景加入一个有限对照。例如，战术写实中的一次失控近身，可以借港式短打的环境利用，但仍服从人物训练与现实代价。

### 港式连续特技：组合、地形与观看

**动作逻辑**：
- 既包含近距离、高频率的拳脚膝肘短打，也包含跨桌、蹬墙、翻转、绊扫、摔投、滑行等身体特技；不把港式动作缩成双方站在原地交换拳头。
- 连招利用已有运动状态：闪避形成的侧位接肘膝，接住冲势的转胯接摔投，落地的屈膝接扫腿，踢击后的转身接下一侧威胁。前一击的收回、防守或失衡可以同时成为下一击的起势，不逐招停稳、喘气、重新摆架。
- 一组组合可以共同压垮同一个防守、夺取同一位置或打开同一通道；无需每一拳都新增剧情转折。动作信息来自技术变化、身体轮廓、受力差异和空间推进。
- 受击者承接连续压力：护臂被压开、肩胯被打偏、脚步被夺走、滑撞物件或借势脱离，各有原因；在明确僵直、失衡或被控制时可暂时失去主动权，不为“全员在动”强塞随机动作。

**招式库引用范围**：
- 短打：冲拳、勾拳、肘击、低扫、膝撞、侧踹。
- 摔投：过肩摔、抱摔、绊摔、拖转与落地承接。
- 体技：翻转、旋踢、跨越、借墙改变高度、低位滑行；以已建立的支点、落点与承重关系串联，不只列动作名称。
- 环境动作：长凳既是跨越支点也可成为阻挡物，桌下提供低位通道，楼梯改变高低位，柱子和钢板承接受力；环境先提供动作机会，再留下对应后果。

**摄影承接**：
- 大景别读清完整身体、攻击路线、支点与落点；小景别用于接触、护架破开或受力后果。大小变化服务动作信息，不机械规定每打一击都切近景。
- 连续跟拍沿行动路径移动、绕开障碍、重构新的威胁方向；不先设计漂亮环绕，再让人物停下来等摄影机。一个连续长镜也可以高密度、快节奏，多镜剪辑同样可以承接惯性。
- 多人压力可重叠：前一人仍在滑撞或倒地，另一人已从另一侧逼近；镜头优先交代正在成为威胁的人，通过明确路径避免人物排队入场或突然换位。

**教学片段：连接机制，不是固定套路**
陈默侧身让开陈武的来拳，陈默留在陈武外侧，陈默的肘部随转胯压入陈武护架；陈武上身折下、脚步失衡时，陈默抓住陈武肩部把冲势转成摔投，陈武沿湿地滑撞钢板。陈默尚未停稳，赵齐已从侧面伸手逼近，陈默借落地屈膝的低位扫开赵齐的支撑，随即起身跟进赵齐失衡后露出的角度。陈武撞出的钢板闷响与余振继续存在，积水沿陈武和赵齐的落点散开，摄影机跟住陈默转向，让下一次接触仍落在可见空间里。

## 三、人物动作指纹

为主要人物建立稳定但可发展的动作指纹：

- **训练来源**：专业训练、街头经验、仪式传统、天赋或毫无经验；
- **首要目标**：制伏、杀伤、逃跑、保护、拖延或证明自己；
- **距离偏好**：保持远距、抢入内线、利用高差或贴近控制；
- **风险态度**：精确保守、以伤换位、冲动、欺骗或耐心等待；
- **身体限制**：伤势、疲劳、年龄、服装、地面和武器重量；
- **道德边界**：哪些手段会用，哪些即使失败也不用；
- **压力变化**：计划被打破后，动作是变得简单、失控还是更冷静。

动作指纹应从选择和结果中可见，不靠招式名称说明；既定人物惯性不是擅加擦下巴、轻蔑笑等招牌习惯的理由。

## 四、动作段落的戏剧弧

常见结构可按场景压缩或重排：

1. **空间与规则建立**：观众知道出口、障碍、人物位置和危险来源；
2. **第一次试探**：双方暴露技术、距离偏好或信息差；
3. **压力升级**：旧方法失效，空间或身体条件恶化；
4. **策略转变**：人物利用新信息、环境或牺牲改变局面；
5. **结果落地**：胜负之外，关系、伤势、位置或道德代价发生变化；
6. **余波**：呼吸、姿态、破坏和声音让结果停留。

动作高潮不一定是最大破坏，也可以是人物第一次拒绝出手、失去武器、暴露恐惧或选择保护他人。

## 五、空间与道具

场景需提供可读的行动条件：

- 出入口、通道宽度、柱体、车辆、楼梯、高差与盲区；
- 哪些表面可滑、可碎、可反弹、可遮挡或可承重；
- 道具归属、重量、长度、开启方向和使用痕迹；
- 观众能否知道人物为何此刻看见或错过威胁；
- 环境变化是否在后续持续影响路径。

环境作为战术条件时，改变距离、视线、平衡、路线或控制权；作为强度反馈时，真实受力与持续损伤即使不改变下一步战术，也有感知价值。无具体支撑、接触或后果的道具花活才会徒增复杂度。

### 环境破坏作为强度信息

环境和道具的损伤既可改变战术，也可单独承担强度感知。利用已建立的完整状态或可辨识的形状作参照，把实际交锋造成的凹陷、弯折、碎裂、位移与余振留在同一空间；后续画面中的损伤痕迹和前后对照，可以让观众感到冲击之重、压力之密与场面付出的代价，即使这一损伤没有另造剧情转折。

按类型、材质、接触与已定结果选择明显或内敛的反馈，保留轻重差异；不是每击都自动破坏、每次破坏都扩大，也不是按碎片数量衡量精彩。写清已有物件的受力点、作用方向和材料响应，而非接触后凭空出现与场地无关的碎片。损伤影响路线、支撑或视线时，后续行动承接新条件；只承担感知时，仍可作为人物行动中的前景、背景、短促材质声和余振持续存在，不必停下交锋逐件展示。

已定关键物件、建筑状态与破坏范围保持；不为强调激烈度擅加新道具、伤情、坍塌或剧情结果。完整无损的空间同样可以通过身体受力、物件震动与声音表现猛烈交锋，环境破坏是表达选择，不是动作场面的合格门槛。

## 六、摄影机的五种动作态度

### 战术见证

摄影机保持地理与因果清楚，让观众理解选择。适合专业战斗、群战、追逐和复杂空间。

### 身体共感

摄影机接近呼吸、重心和受力，让观众感受疲劳、恐惧或疼痛。关键接触前后仍需恢复方向锚。

### 图形奇观

用轮廓、颜色、轨迹和大尺度构图呈现超常或动画化动作。先让观众知道规则，再允许画面抽象。

### 道德凝视

保持距离或延长后果，不替暴力制造快感。适合残酷、战争、惩罚和不可逆伤害。

### 喜剧观察

构图稳定、人物严肃执行，笑点来自计划与身体结果的偏差。切点要给反应和后果留下时间。

同一段可在转折处改变摄影机态度，但每次变化需对应人物视点或戏剧结果。

## 七、打击感与重量

重量来自完整证据链，而非单独的震屏、慢动作或音效：

- 发力前身体如何建立支撑；
- 运动路径是否符合武器与关节；
- 接触点是否清楚；
- 双方如何承受反作用；
- 衣物、道具、表面和环境如何响应；
- 人物如何恢复、失衡或改变策略；
- 声音是否体现材质、距离与余振。

导演先决定暴力的感受：干净、笨重、残酷、华丽、荒诞或超然。动作执行模块再把这个选择落实为逐拍因果。

## 八、多人动作的可读性

群战的规模感不等于所有人同时抢镜。导演层需要：

- 明确当前观众跟随谁；
- 让前景、中景、背景各承担不同压力；
- 通过障碍、距离、队形和视线形成局部冲突；
- 让未交手的人仍有可见目标和位置；
- 每次压力交接都改变主角选择；
- 群体结果在空间中留下痕迹。

可读性来自压力传递，而不是固定次数或机械轮流。

## 九、动作与表演

- 专业者在高压中可能动作更简洁，错误更少；
- 外行会迟疑、闭眼、抓错位置或过度用力；
- 伤者会保护受伤侧、改变呼吸和重心；
- 愤怒不必等于动作更大，也可能导致视野变窄和策略失误；
- 恐惧可表现为逃跑、冻结、服从、攻击或过度计划；
- 动作结束后的第一反应往往比胜负姿势更能定义人物。

表演状态需贯穿准备、接触和恢复，不能在动作开始时消失。

## 十、大师与作品路由

| 问题 | 优先作品 | 提取重点 |
|---|---|---|
| 载具追逐与方向 | 乔治·米勒《狂暴之路》 | 视线轴、速度层次、中心构图、因果接力 |
| 写实枪战与专业主义 | 迈克尔·曼《盗火线》 | 战术目标、真实声学、动静两极 |
| 群战与天气空间 | 黑泽明《七武士》 | 队形、地理、风雨、角色动作指纹 |
| 武侠身体与关系 | 李安《卧虎藏龙》 | 克制、轻重、人物欲望进入招式 |
| 双雄枪火与情义 | 吴宇森《喋血双雄》 | 对位、牺牲、慢动作的情绪重音 |
| 空间化枪战 | 杜琪峰《枪火》 | 站位、等待、静止与突发、群体视线 |
| 战争主观临场 | 斯皮尔伯格《拯救大兵瑞恩》 | 任务线、主观听觉、混乱中的信息控制 |
| 功夫喜剧 | 周星驰《功夫》 | 严肃执行、停顿、升级与视觉偏差 |
| 持续长镜动作 | 卡隆《人类之子》 | 镜内视点接力、前中后景因果 |

选定后读取具体作品正文，提取动作与人物、空间、摄影机之间的关系，不复制镜头表面风格。

## 十一、常见失败

| 失败 | 后果 | 修正 |
|---|---|---|
| 先选招式再找剧情 | 动作与人物无关 | 从目标、代价和关系变化出发 |
| 所有人同一动作风格 | 角色不可辨 | 建立训练、距离、风险和道德指纹 |
| 环境只作背景 | 动作悬浮 | 让障碍、材质和出口改变选择 |
| 用震屏代替接触 | 力量没有来源 | 建立支撑、传力、受体和余波 |
| 群战机械轮流 | 对手像等待指令 | 组织压力、隔离和位置持续性 |
| 全程同一强度 | 没有升级与释放 | 建立基线、转折和后果 |
| 动作中表演消失 | 人物变成替身 | 让伤势、恐惧、技术和选择贯穿 |
| 美学家族无条件混搭 | 世界规则和节奏互相冲突 | 确立主家族，仅为关键人物差异有限借用 |

## 十二、交给动作执行模块

导演层锁定以下内容：

- 戏剧目标与结果；
- 人物动作指纹；
- 主动作美学家族；
- 摄影机态度与节奏形状；
- 空间锚、环境作用和关键物件；
- 暴力的情绪与道德视角。

动作执行模块据此补齐战术选择、逐拍时间、方向、路径、接触、惯性、反馈和段尾状态。最终镜头描述不附加第二套动作格式。
