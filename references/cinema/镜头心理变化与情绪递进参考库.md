# 镜头心理变化与情绪递进参考库

本库处理人物内心如何跨镜发展。情绪弧不是强度数字的升降，而是人物对事件的理解、控制方式和行动选择发生变化。每个转折都需要触发、反应和新状态。

## 一、先锁心理命题

设计一场戏前，明确：

- 人物进入时相信什么；
- 人物想从对方或环境得到什么；
- 哪个事实、动作或沉默会挑战这一信念；
- 人物如何抵抗、误读或掩饰；
- 离开时人物知道了什么、决定了什么，或失去了什么。

情绪词只做索引。真正可拍的是目标、注意力、身体控制、距离与行为变化。

## 二、基础弧线

| 弧线 | 内在机制 | 典型可见变化 |
|---|---|---|
| 累积 | 同一压力不断获得新证据 | 动作缩短、注意力收窄、控制成本上升 |
| 崩塌 | 人物维持的解释逐步失效 | 话语减少、姿态失去支撑、习惯动作停止 |
| 反转 | 一个触发重写人物理解 | 先有察觉，再有控制失败或行动改向 |
| 摇摆 | 两个目标都不能放弃 | 前进与撤回、靠近与回避交替出现 |
| 麻木到恢复 | 人物从关闭感知重新进入关系 | 先对环境产生微弱反应，再恢复选择 |
| 表面稳定、内部泄露 | 公开策略与真实状态冲突 | 声音、手部、视线或物件动作出现裂缝 |

一场戏可以组合弧线，但应有一条主导变化。

## 三、跨镜递进方法

### 3.1 同向累积

新镜头不是把同一表情拍得更近，而是增加压力来源或减少人物选择。可以依次改变：

- 信息：从猜测到证据；
- 空间：退路变少、距离缩短、遮挡消失；
- 关系：对方从回避到逼问、从相信到怀疑；
- 身体：从可控制的小动作到行动受阻；
- 时间：重复行为被打断，等待变成期限。

### 3.2 触发式转弯

转弯包含三个可见节点：

1. 人物感知到触发；
2. 原有行为短暂停顿或偏离；
3. 人物以新策略继续行动。

触发可以是台词、物件、声源、视线、他人动作或空间发现。反应速度由人物经验、注意力和是否试图掩饰决定，不套固定延迟。

### 3.3 表里分裂

公开行为维持礼貌、职业或权威，身体细节却泄露真实压力。设计时让外在策略和泄露信号分别承担信息，并决定谁能看到：

- 观众看到、对手没看到，会产生共情或悬念；
- 对手看到、观众稍后理解，会产生权力变化；
- 所有人都看到但没人点破，会形成潜台词压力。

### 3.4 观众与人物的信息差

- **观众先知道**：镜头先交代威胁或秘密，再观察人物尚未察觉的行动。
- **人物先知道**：先拍人物反应，延后揭示其视线落点或信息来源。
- **同步知道**：用同一视点和连续动作让发现与反应不可分割。

选择哪种信息关系，决定切点、景深和反应镜的位置。

## 四、心理变化的视听载体

| 载体 | 适合表达 | 使用边界 |
|---|---|---|
| 视线 | 察觉、回避、请求、判断 | 需要清楚落点与可见性 |
| 手与物件 | 犹豫、控制、归属、记忆 | 物件必须真实参与行动 |
| 距离与走位 | 权力、亲密、防御、离开 | 保持空间和轴线可读 |
| 呼吸与声音 | 压力、释放、说不出口 | 不与夸张面部表情重复 |
| 景别与机位 | 观看距离和观众立场变化 | 由戏剧变化触发，不做机械递进 |
| 景深与遮挡 | 隐瞒、发现、孤立、关系重组 | 焦点变化应有认知动机 |
| 光色与环境 | 世界如何回应人物状态 | 不替代具体表演与行动 |

同一变化通常由一个主载体和一个辅助载体完成。载体过多会显得被设计。

## 五、多人物关系弧

多人场面既有个人弧，也有关系弧。重点追踪：

- 谁掌握话题、空间中心、出口或关键物件；
- 谁在观察谁，谁拒绝回应；
- 谁先改变距离、姿态或语气；
- 某人的变化是否被另一人看见并利用；
- 场面结束时联盟、误解或权力是否改变。

常见关系结构：

| 结构 | 变化方式 |
|---|---|
| 逼近与退缩 | 一方不断占据空间，另一方退路逐步减少 |
| 同步崩塌 | 两人从对立动作转向共享节奏或共同静止 |
| 一人泄露、一人旁观 | 旁观者的微小反应决定是否介入 |
| 权力互换 | 站位、视线、物件控制和话语节奏一起变化 |
| 假性和解 | 公共动作恢复秩序，私下动作保留裂缝 |
| 错位情绪 | 一人已转向，另一人仍停留在上一状态 |

## 六、暂停与余韵

暂停不是预设秒数，而是完成一次观众理解所需的时间。有效暂停中至少有一项仍在变化：呼吸、目光、手部受阻动作、环境声、物件余震或空间里的他人反应。

常见功能：

- 冲击后让人物暂时失去行动语言；
- 抉择前让两个目标同时可见；
- 沉默中确认双方都懂但不说；
- 高潮后让结果进入身体和空间；
- 用空镜或缺位构图承接人物离开后的影响。

切点应落在理解完成或新问题形成之后，而不是情绪刚出现就切走。

## 七、常见失效与修正

| 失效 | 根因 | 修正 |
|---|---|---|
| 平静后直接暴怒 | 缺少触发或控制破裂过程 | 增加可观察触发与短暂抵抗 |
| 每镜只是表情更大 | 把递进当强度加码 | 改变信息、空间、关系或行动策略 |
| 崩溃很强却不动人 | 观众没见过人物维持什么 | 先建立其日常控制与损失对象 |
| 和解太轻 | 冲突后果被一次拥抱抹去 | 保留物件、距离或视线中的余震 |
| 情绪一直同一档 | 场面没有新理解 | 加入转弯、暂停、误读或目标切换 |
| 摄影替人物表演 | 推近、音乐和光线包办情绪 | 先找到具体行为证据，再决定摄影 |
| 多人同时同幅度反应 | 角色没有独立目标 | 按信息位置与关系分别设计反应 |

## 八、作品锚点

- 《东京物语》：情绪不靠逐级放大，而在日常动作、礼貌与沉默中积累。
- 《婚姻故事》：争吵的升级来自目标变化、误读和控制失败，不只是音量。
- 《花样年华》：表面秩序与内部欲望长期错位，重复空间承载心理变化。
- 《一次别离》：信息差和道德立场让每次反应都重新定义关系。
- 《燃烧》：延迟揭示和不确定反应让观众参与人物的心理推断。

借鉴作品时说明它解决了哪一种心理转换，并把方法落实到当前场景的触发、表演、调度或切点。
