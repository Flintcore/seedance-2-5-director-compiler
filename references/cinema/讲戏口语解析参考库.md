# 讲戏口语解析参考库

创作者常用感受、比喻和现场黑话表达意图。导演需要保留原始动机，把模糊词拆成可选择的观看关系、表演、调度、摄影、声音和节奏；有歧义时并列解释，不擅自把一句口语升级成另一场戏。

## 一、解析顺序

1. 找出创作者最在意的观众感受；
2. 找出必须保留的人物、动作、台词、物件和结果；
3. 判断口语描述的是创作目标、镜头手段还是结果反馈；
4. 列出可能的多种影视含义；
5. 选与故事、空间和前后镜最一致的实现；
6. 仅补齐完成该意图必需但尚未说明的维度。

## 二、常见口语的多义性

| 口语 | 可能含义 | 需要判断 |
|---|---|---|
| “来个牛的镜头” | 记忆点、复杂调度、奇观、关键表演或反预期 | 这镜承担转折还是只需好看 |
| “有张力” | 距离压力、信息差、时间压力、权力不对等 | 威胁来自谁，观众知道多少 |
| “节奏快点” | 更早进入事件、减少重复、动作更紧、切点提前 | 问题是镜头时值还是信息没有推进 |
| “慢一点” | 留反应、保持真实时间、延迟揭示、增加余韵 | 哪个变化值得观众经历完整过程 |
| “孤独一点” | 人景比例、缺席、声场、关系断开或动作无人回应 | 人物是独处还是在人群中孤立 |
| “高级一点” | 形式克制、因果准确、材质可信、场景特异 | 当前最像套话的是哪一维 |
| “电影感” | 观看立场、光源逻辑、调度、景别和节奏统一 | 不先跳到宽画幅、浅景深或慢动作 |
| “真实一点” | 表演、物理、空间、对白或照明更可信 | 用户指出的失真发生在哪一层 |
| “狠一点” | 决策更绝、后果更重、声音更近或动作更直接 | 不自动等同更多暴力或更快剪辑 |
| “美一点” | 构图、光色、人物状态或关系更动人 | 美是否会削弱危险与人物处境 |

## 三、从感受到导演选择

### “孤独”

可选择远距固定观察、群体中无视线回应、共享空间却不同焦平面、离画声源不回应人物，或人物完成一个本应由两人共同完成的动作。选择取决于孤独来自空间、关系还是记忆。

### “压迫”

可来自出口被占、距离持续缩短、低天花与长焦压缩、对方保持静止而人物不断调整，或声音先于威胁进入。不要把压迫简化为仰拍。

### “浪漫”

可来自共同任务、视线接力、动作节奏逐渐同步、为对方保留空间，或一个物件的共享历史。光晕和慢动作只有在关系已经成立后才有价值。

### “燃”

先建立困难与代价，再让人物选择超出常态的行动。空间规模、群体反应、声音动态和动作后果共同支持释放，不以快切和配乐替代。

### “悬疑”

决定谁知道什么、观众与人物的信息差、被遮挡对象和揭示顺序。暗光只是环境选择，不是悬疑本身。

## 四、保留用户锁

- 用户指定的动作、机位、台词、时长、人物位置和结尾状态属于设计边界。
- 技术补全用于让其可拍、连续和清楚，不改变动机。
- 若一个口语选择存在明显代价，在设计稿中给出具体影响与最小调整。
- 用户确认的版本覆盖早期推断；后续补全围绕确认版继续。

## 五、对白口语

创作者说“他这里说一句……”时，先区分：

- 逐字台词还是意思概要；
- 画内对白、画外对白、旁白或电话声；
- 哪位人物发声；
- 谁听见，谁没有听见；
- 台词前后的动作与反应；
- 是否允许润色。

逐字内容保持原样。若只是意图概要，先在导演设计中说明台词功能，再决定是否需要具体文本。

## 六、反馈语言的根因定位

| 反馈 | 可能根因 |
|---|---|
| “不像电影” | 观看立场不明、镜头无动机、光源或空间不连续 |
| “太平” | 戏点没选中、关系没变化、切点错过触发 |
| “太乱” | 目标、方向、层级或声音主次不清 |
| “不够感人” | 观众没建立关心、表演没有行为证据、余韵被切掉 |
| “动作没劲” | 起势、接触、受力和后果没有形成因果 |
| “看不懂” | 主体、空间、视线或状态变化缺少锚点 |
| “像模板” | 选择没有绑定本场人物、物件和空间 |

反馈先定位最早根因，再改动最小范围。

## 七、输出导演决定

解析结果应变成具体选择：

- 观众位置与视点；
- 主镜及必要连接镜；
- 人物调度与表演证据；
- 摄影机起点、触发和终点；
- 光色与声音职责；
- 进入、变化与退出状态。

不把口语逐字替换成技术术语堆叠。翻译是否成功，取决于创作者原本想要的观众感受是否更清楚地出现。
