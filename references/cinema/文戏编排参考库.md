# 文戏编排参考库

文戏的推进单位不是台词句数，而是关系变化。对白、潜台词、静默、表演、物件、空间和声音共同推动人物从一个关系状态进入另一个状态。

## 一、七个可选阶段

| 阶段 | 戏剧任务 | 可见设计 | 常见误区 |
|---|---|---|---|
| 建立 | 让观众读懂空间、人物关系和常态 | 位置、距离、正在做的事、谁拥有节奏 | 用说明性对白介绍一切 |
| 试探 | 人物测试能说多少、能靠多近 | 视线接触、绕开问题、递物或拒收 | 双方直接说出真实意图 |
| 暗潮 | 潜台词开始泄露 | 物件使用异常、停顿变长、位置改变 | 只加表情，不改变关系 |
| 转折 | 新信息或决定改变场景方向 | 一方停止配合、进入中心、拿走关键物 | 用提高音量代替转折 |
| 峰值 | 场景最核心的情绪或权力结果落地 | 语言、动作、沉默或空间选择达到不可逆点 | 默认所有文戏都需爆发 |
| 余震 | 让人物承受刚才发生的事 | 延迟反应、收回视线、未完成动作 | 结果刚出现就立即切走 |
| 空间回声 | 让空位或环境保留关系痕迹 | 离场路径、空椅、未动的杯子、持续声源 | 装饰性空镜与前戏无关 |

七阶段是分析工具，不是每场分析清单。短场可只保留建立、变化和结果；长场可以反复试探、撤回，再进入真正转折。

## 二、五个导演维度

### 潜台词

区分三层：

- 人物真正想得到或避免什么；
- 这一意图如何从表演、物件、空间或声音泄露；
- 观众此刻比人物知道更多、相同还是更少。

### 静默

静默让信息被接收、决定被看见或后果停留。持续时间由可读变化决定，不套固定占比或秒数。详见《静默时刻与留白设计参考库》。

### 表演渐变

不要把情绪压成一个标签。选择一条顺序明确的渐变，例如：

视线避开 -> 手上动作放慢 -> 吞咽 -> 重新对视 -> 决定说谎。

细节数量服从景别和人物习惯；关键是变化有因果。

### 物件行为

物件可承担：

- 权力：谁递、谁让对方等待、谁拥有或归还；
- 关系：共同使用、保留、拒收或损坏；
- 秘密：遮挡、藏匿、反复确认；
- 时间：磨损、位置变化、使用痕迹；
- 转折：物件一旦移动，关系状态随之改变。

### 空间几何

人物间的距离、朝向、遮挡和路径就是关系：

- 正面对峙强调直接冲突；
- 并排可表示共谋、亲密或共同注视；
- 背对或错位适合隐瞒和无法相见；
- 一人占出口、中心或光源可形成权力；
- 多人围桌时，座次、空位和谁能自由起身比桌型本身更重要。

## 三、对白场面的镜头逻辑

先确定每一段话改变什么，再选择摄影机位置：

1. 谁在掌控交流节奏；
2. 观众应该观察说话者、听者还是两者之间的空间；
3. 台词最重要的落点发生在说出时还是听见后；
4. 哪一次切换改变了信息或权力；
5. 哪些反应适合同框，哪些需要单独隔离；
6. 何时保持不切比反打更有压力。

反应镜不是固定配额。说话者隐藏真实意图时，听者可能更重要；说话者终于失控时，保留说话者可能更有力。每次切换都要说明观众获得了什么新关系。

## 四、六种常见情境

### 求助

- 求助者目标：获得帮助同时保住尊严；
- 掌权者目标：规定求助的代价；
- 设计重点：等待、物件礼仪、距离变化、谁先打破沉默；
- 参照：《教父》Bonasera 开场，缓慢靠近不是气氛装饰，而是权力逐步吞没空间。

### 告别

- 双方目标：完成离开，同时阻止真正想说的话泄露；
- 设计重点：未完成动作、短暂对视、物件交换、离场后的空位；
- 参照：《花样年华》楼道、《小偷家族》海边。

### 谎言

- 说谎者目标：维持表面常态；
- 听者目标：判断是否继续相信；
- 设计重点：常态动作出现细微偏差，反应可以延迟；
- 参照：《迷魂记》中身份表演与观看关系。

### 表白或暧昧

- 目标冲突：接近欲望与社会、道德或自我保护同时存在；
- 设计重点：接近和撤回交替，物件作为中介，视线不完全同步；
- 参照：《花样年华》。

### 决断或顿悟

- 目标：让观众看见“决定形成”，而不是只听见决定结果；
- 设计重点：收到信息、内部重组、可见微变、随后行动；
- 参照：《教父》餐厅戏、《降临》。

### 克制死亡

- 目标：让身体变化、旁观者反应和继续生存的压力同时成立；
- 设计重点：生命迹象、触碰、声音视点、空间后果；
- 参照：《人类之子》Julian 中弹、是枝裕和的临终与家庭段落。

类型高潮中的爆发死亡属于另一种美学，不应从克制案例机械推导。

## 五、文戏节奏

文戏的密度来自微观变化，不来自背景元素堆叠。可选择四种倾向：

| 倾向 | 适用 | 镜内动力 |
|---|---|---|
| 凝视 | 求助、决断、死亡余震 | 表演和空间压力持续变化 |
| 缓慢 | 家庭、暧昧、怀旧 | 生活动作与潜台词并行 |
| 常速 | 试探、隐瞒、谈判 | 信息与反应交替推进 |
| 紧张 | 揭穿、摊牌、关系崩塌 | 话语权、位置和切点快速转移 |

节奏可以在一场中转档。真正的转折应改变呼吸、镜长、声场或空间关系，而非只让演员说得更快。

## 六、长对话的景别与空间弧

长对话如果一直在同一组正反打中来回，会把关系拍平。可按戏剧推进建立压缩弧：

- 开始用同框或较宽景别交代社会关系；
- 试探阶段保留桌面、门口或第三人的影响；
- 暗潮阶段通过遮挡、焦点或轻微位置变化分离人物；
- 转折时改变摄影机所属的一方，或首次进入更近景别；
- 峰值是否特写由人物是否暴露真正意图决定；
- 结尾可重新拉开，显示关系已经无法回到开场。

景别变近不等于情绪必然升级。退到远景也可表达疏离、失败、监视或人物被空间吞没。

## 七、群体文戏

多人场景先分配四类功能：

- 发起当前问题的人；
- 控制规则或资源的人；
- 通过反应改变观众理解的人；
- 可能打断、泄密或转移权力的人。

调度时追踪注意力流：谁看谁、谁假装没看、谁通过物件或离席改变阵营。背景人物无需持续活动；一次停止动作往往比不停忙碌更能显示异常。

## 八、声音与对白

- 每句逐字台词需绑定说话者、时间与口型目标；
- 说话前的动作和听者反应属于镜头设计，不放进台词本身；
- 画外声需有空间来源；
- 环境与音乐避免重复台词已经表达的情绪；
- 重叠对白只在人物关系需要抢夺、回避或亲密熟悉时使用；
- 关键句之后优先保留后果，而不是立即补解释。

## 九、大师案例路由

| 问题 | 作品 | 提取机制 |
|---|---|---|
| 求助与权力 | 科波拉《教父》 | 等待、空间侵入、礼仪物件 |
| 暧昧与错过 | 王家卫《花样年华》 | 重复路径、遮挡、音乐与未完成动作 |
| 家庭与生活流 | 是枝裕和《小偷家族》 | 重叠行为、低调反应、空间共同使用 |
| 社会关系与群像 | 杨德昌《一一》 | 远近关系、框中框、观察距离 |
| 持续空间中的危机 | 卡隆《人类之子》 | 长镜内视点和关系连续变化 |
| 身份表演与观看 | 希区柯克《迷魂记》 | 观看者控制、形象塑造、信息差 |
| 说话与沉默的权力 | 《继承之战》 | 打断、重叠对白、座次和羞辱 |

先通过大师索引找到具体作品并阅读正文，再把机制针对当前人物和空间变形。

## 十、常见失败

| 失败 | 后果 | 修正 |
|---|---|---|
| 把文戏等同于对白 | 画面没有关系变化 | 给空间、物件、听者和沉默分配任务 |
| 反应镜按固定比例添加 | 剪辑机械 | 只在反应改变理解时切换 |
| 微表情被写成数量任务 | 表演像动作清单 | 设计有因果的渐变顺序 |
| 每场都用缓推和浅景深 | 风格单一且缺乏动机 | 从视点、权力和空间决定摄影机 |
| 克制等同于低声和不动 | 戏剧不可读 | 让控制与泄露同时发生 |
| 所有关系峰值都爆发 | 高潮被透支 | 根据人物和类型选择内敛、仪式或爆发 |
| 物件只作装饰 | 信息拥挤 | 只保留参与行为或主题的物件 |
| 结尾没有余震 | 台词落地后情绪立即消失 | 保留动作结果、空位或持续声源 |

## 十一、协同入口

- 潜台词与言外之意：建立公开语言与真实意图的差。
- 静默与留白：设计信息接收和余震。
- 表演分寸：校准可见强度和转档。
- 视线与调度：组织关系和注意力。
- 节奏与切镜：确定何时保留、何时切换。
- 声音叙事：绑定对白、环境、音乐政策和声音桥。

## 十二、六种情境的行为展开示范

以下为教学重建，只在对应人设和戏剧情境成立时取用；不复制原库中的固定镜长、表情配额或电影逐秒断言。

| 情境 | 从公开任务长出表演 | 摄影与声音可关注什么 |
|---|---|---|
| 求助 | 求助者把申请材料推到桌边，对方未接；他把卷起的纸角压平，仍等待被允许继续说 | 同框的材料距离、谁打破停顿、接收动作是否发生，比固定低头或低声更具体 |
| 告别 | 归还钥匙时手停在对方掌心上方，听完最后一句才松开；对方接住后没有立刻收进口袋 | 接触与松手、离开路径、留者继续握着的物件；也允许直接拥抱或直白告别 |
| 隐瞒 | 人物照常分餐，听到敏感名字时漏给自己一份，随后自然补上并继续看着询问者 | 看观众是否已知真相，决定让异常显眼还是只供回看；不把回避视线当必备证据 |
| 暧昧 | 一人把伞向对方倾，自己的肩留在雨里；对方先看见湿肩，再调整伞柄与他共持 | 共同物件改变距离和视线；温暖色光、浅景深和停顿都不是必选项 |
| 决断 | 手已碰到门把却停住，听见屋内一声呼唤后，松开门把转身走回 | 决定由实际行动确认；正面反应、背影和手部都可成立，无需逐部位表情清单 |
| 失去之后 | 旁观者继续做刚才照料的动作，直到手中物件已无处递去，才停下来确认对方 | 受阻的日常动作和环境继续运行产生落差；爆发、克制或迟钝由人设决定 |

一段话可以跨镜不断：先拍说话者如何试探，句中切到听者已经明白却仍维持手上任务，再在下一句改变物件归属。镜头正文描述谁在听、何时转变，台词语法与时间安排交由现有输出模块，不在知识层另立格式。
