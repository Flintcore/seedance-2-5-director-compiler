# 光影设计参考库

光影设计同时决定可见性、形体、空间层次、时间天气和观看态度。光型没有固定情绪；同一种光在不同光源动机、曝光、反差、色彩、场景材质和人物行为中可以产生相反含义。先确定本场整体亮暗基调、亮区范围与显露或隐藏需求，再选择光型，不是先把脸照清再压暗环境。

## 一、光影设计的基本变量

| 变量 | 直接改变的画面结果 | 需要结合的条件 |
|---|---|---|
| 光源方向 | 面部与物体哪些平面被看见，阴影落向哪里 | 人物朝向、机位、动作路径、场景结构 |
| 光源尺寸与距离 | 阴影边缘、皮肤与材质的过渡 | 光源相对主体的视角尺寸，而非灯具名称 |
| 主辅光关系 | 明暗反差、阴影信息和观看压力 | 曝光、显示介质、肤色、服装与背景亮度 |
| 色彩关系 | 光源身份、时间、阵营与材质偏色 | 实际光谱、白平衡取向、混合光和后期流程 |
| 光源动机 | 观众是否相信光来自画内或画外的房间灯、日月光、屏幕、火或环境反射 | 光源位置、遮挡、衰减和人物运动，不要求光源本体入画 |
| 空气介质 | 远近层次、光路可见度、对比和色彩衰减 | 粒子性质、密度、光束方向、观察方向和曝光 |
| 时间变化 | 光斑移动、亮度起伏、色彩和阴影长度变化 | 日照、天气、实景灯具、火焰、车辆与人物遮挡 |

灯具位置本身不等于含义。意义来自“谁被允许看清、谁被隐藏、光是否与人物行动同步，以及变化发生在何时”。

## 二、常见光型关系

| 光型关系 | 可见结果 | 常见叙事用途 | 主要风险 |
|---|---|---|---|
| 逆光与轮廓光 | 主体边缘与背景分离，面部可能保留暗部 | 登场、隔离、匿名、空间深度、天气显示 | 只剩漂亮轮廓，丢失本场确需的行动或表演信息 |
| 顶部来光 | 眼窝、帽檐和下颌阴影加深，地面成为受光面 | 建筑灯、审讯灯、正午日照、权力空间 | 自动把人物拍成反派，忽略真实光源 |
| 低位来光 | 阴影方向偏离日常经验，面部结构重新组织 | 地面灯、火、屏幕、机械装置、异常环境 | 无动机的恐怖化和面部失真 |
| 侧光 | 明暗沿形体分区，纹理和轮廓更明显 | 窗边、门缝、舞台侧光、关系分隔 | 把半明半暗机械等同双重人格 |
| 正面来光 | 面部信息充分，纹理与体积可能被压平 | 公开陈述、时尚肖像、闪光灯、主观直面 | 缺少形体或让背景失去层次 |
| 硬光 | 阴影边界清楚，高光集中，表面纹理突出 | 日照、裸灯、聚光、暴露与图形化 | 反差超过叙事需要，细节不可读 |
| 柔光 | 阴影过渡宽，皮肤与材质起伏较平缓 | 阴天、窗纱、反射、贴近人物的观察 | 无差别磨平空间和人物状态 |
| 体积光 | 光路因介质散射而可见，空间被分层 | 雾、烟、尘、水下、舞台与工业环境 | 介质无来源、光束方向与光源矛盾 |

## 三、逆光与轮廓分离

逆光从主体后方或侧后方进入镜头。它可以描出头发、衣物、雨雪、尘雾和透明材质，也可能让人物面部落入暗部。

### 可用的导演决定

- 需要观众先认出姿态而非身份时，让轮廓先于面部信息出现。
- 需要人物与明亮出口、窗或天空发生关系时，让光源成为空间目标。
- 本场明确需要读面部表演时，再按现场条件用环境反射、人物转身或有依据的侧面补光恢复所需信息；表演也可由声音、身形和停走承载，不因写了微表情就自动补脸。
- 需要保持匿名或疏离时，允许暗部持续；保留理解本场所必需的行动或声源，不要求全身轮廓和所有物件都被照亮。

逆光并不自动浪漫或英雄化。冷硬的工业出口、车灯和审讯室玻璃也能形成威胁；意义取决于人物面向光还是被光吞没。

## 四、顶部与低位来光

顶部来光常来自正午太阳、吊灯、走廊灯、厂房或舞台。它强调地面、肩部和头顶，并可能遮住眼睛。低位来光常来自火、桌灯、屏幕、地面设备或反射面，会改变熟悉的面部阴影方向。

### 设计条件

- 光源在场景中有位置，阴影方向应随人物移动和转身变化。
- 人物眼睛是否可读是叙事选择：隐藏可以延迟理解，恢复可见则能形成关系变化。
- 低位光若来自屏幕或火焰，亮度、颜色与闪动应影响手、衣物和附近表面。
- 俯视或仰视机位会改变受光面积；打光需与最终机位共同判断，而不是脱离镜头设定。

顶部来光也可以是平静日常的厨房灯，低位来光也可以是壁炉边的亲密光源。不要由方向直接推导人物道德属性。

## 五、侧光、正面光与形体

侧光通过明暗交界塑造形体，适合表现窗、门、走廊和人物之间的空间分区。正面光提供较完整的面部信息，也能制造被审视、被拍照或主动直面观众的感觉。

### 关系设计

- 两人被同一侧光覆盖，可显示共享环境；被不同方向或不同色彩的光分开，可显示处境差异。
- 人物走过明暗边界时，身份、态度或可见信息可在同一镜头内改变。
- 正面光与暗背景结合时，脸可能像证词一样被单独呈现；与明亮环境结合时则可保持开放和平等。
- 半边脸明暗分割只是形体结果。只有剧情已经建立秘密、选择或关系冲突时，它才可能承载相应含义。

## 六、硬光与柔光

硬光和柔光描述阴影过渡，不等于画面“强”或“温柔”。光源相对主体越小、越远，阴影通常越清楚；相对尺寸越大或经过扩散、反射，过渡通常越宽。

### 硬光的可见特征

- 强调皱纹、汗水、灰尘、织物和建筑纹理；
- 产生清楚的图形阴影和遮挡关系；
- 人物或物件移动时，阴影变化更容易被读到；
- 高反差条件下可能牺牲眼神、肤色或暗部动作。

### 柔光的可见特征

- 保留面部渐变并弱化局部纹理；
- 让多个反射面共同构成环境亮度；
- 适合连续调度，因为人物离开精确位置后变化较缓；
- 如果缺少方向、层次与负补光，空间会变平。

选择软硬首先看光源条件、材质和人物运动，再看场景希望暴露还是保护哪些信息。

## 七、经典人像光型

### 蝴蝶光

主光接近人物正前上方，鼻下出现居中的小阴影，双颊较均衡。它与旧好莱坞肖像和摄影棚控制有关，但可用于任何性别与角色。背景、服装、镜头距离和人物是否直视摄影机会改变其含义。

### 伦勃朗式侧上光

主光位于人物侧前上方，阴影侧脸颊保留由鼻影与面颊受光形成的小块亮面。亮面是否出现取决于脸型、转头和光源尺寸，不应被当成固定角度配方。

### 三点布光关系

三点布光描述主光、辅光和轮廓分离之间的职责，不要求三盏灯都存在：

| 职责 | 画面作用 | 可替代来源 |
|---|---|---|
| 主光 | 建立主要方向、形体与曝光依据 | 窗、太阳、实景灯、反射或人造灯 |
| 辅光 | 控制阴影信息与反差 | 天光、墙面反射、地面反射、主动补光 |
| 轮廓分离 | 让主体与背景在亮度或色彩上分开 | 逆光、背景亮区、雾、服装与背景反差 |

自然主义场景可以省略辅光或轮廓光；叙事所需的可读性不等于所有五官、暗侧纹理和黑衣细节始终可辨。不因主角身份、服装颜色或微表情要求自动补齐三点布光，已定的剪影、失光与融入背景仍应保留。

## 八、自然光与混合光

### 天光

开阔天空提供大面积环境光，其方向、色彩和反差受云层、太阳位置、建筑反射、地面颜色与开口大小影响。阴天可能柔和但并非无方向；蓝天阴影和城市峡谷也会产生明显色偏。

### 直射日光

太阳是方向明确的远距离光源。画面呈冷暖何种关系，取决于时段、大气、白平衡取向、反射环境和曝光；日光的标称色温不等于画面必然呈现某一种颜色。

### 月光与暗夜外景
- 月光可形成高位斜向照明，云层、屋檐和树影改变它落在哪些区域；月亮、照明器材都可以留在画外。明确来源是月光时，不为解释冷色亮面而凭空改成檐下工作灯或路灯。已有真实灯光或其它夜景条件则照实际情境选择，不把所有夜外景统一为月光。
- 自然暗夜先保住整体低照度与大片暗区。被月光擦到的额颊、肩线或地面只是相对暗处较亮，不等于绝对亮如日间；偏冷的色调也不等于高饱和蓝灯洗脸。电影化暴露多少面部细节由创作目标决定，没有夜景必须看清双眼、每寸皮肤或每条黑衣褶皱的要求。
- 人物出屋时，室内灯的溢光随距离、转向和遮挡衰减；屋檐下可以先暗，走到无遮蔽处才得到月光。人物回头不自动获得正面主光，受光仍由既定月光方向决定。

### 实景混合光

窗外天光、室内灯、屏幕、火焰和广告牌同时存在时，应决定哪一来源支配人物，哪些来源只在局部留下色彩或高光。混合光可以保留真实冲突，也可以通过换灯、遮光、反射和后期分离整理层次。

白平衡是对光源的解释，不是情绪按钮。它需与摄影机、记录格式、监看、肤色和后期色彩流程共同确定。

## 九、空气介质与体积光

可见光路来自空气中粒子对光的散射。是否形成清楚光束同时取决于：

- 粒子的性质、浓度、分布与运动；
- 光源是否集中、方向是否明确；
- 光束方向与摄影机观察方向的关系；
- 背景亮度、曝光、镜头耀斑和动态范围；
- 空间尺度以及光在介质中的衰减。

| 介质状态 | 常见画面结果 | 连续性要求 |
|---|---|---|
| 空气较清 | 主要看见受光表面，光路不突出 | 远景对比和能见度服从天气与尺度 |
| 少量尘、水汽或薄雾 | 方向性强的光可能出现细微路径，远景略软 | 粒子需有来源，运动受风和热影响 |
| 分层雾气 | 空间前后层次明显，光束边缘随浓度变化 | 人物穿行会扰动局部密度 |
| 浓雾 | 远景对比下降，近处光源可能形成光晕 | 曝光、能见度和相邻镜头密度保持连续 |
| 翻涌烟尘 | 光路、遮挡和颜色持续变化 | 火源、碰撞、通风与沉降决定流向 |

介质越浓并不简单等于光越柔或光束越清楚。浓度过高可能让光在到达主体前已显著衰减；清楚光束常需要方向明确的光与合适的观察关系。

## 十、曝光、材质与肤色

- 先确定本场亮暗基调与真正需要显露的高光、暗部信息，再决定反差；不同摄影机和记录介质可承受的范围不同。暗夜中局部亮面是相对暗处突出，不等于绝对亮如日间，暗侧信息不作保底。
- 深色皮肤、浅色服装、金属、玻璃、湿表面和烟雾对光的响应不同，不能共用同一“亮度足够”判断。
- 镜面高光显示光源位置与尺寸，漫反射显示受光面的颜色与形体；两者需要分别观察。
- 人物从一个光区走到另一个光区时，曝光变化、瞳孔适应和背景关系可以成为叙事事件。
- 相邻镜头的亮度、阴影方向和色彩可以有意改变，但变化需要时间、机位、光源或视点依据。

## 十一、作品锚点

- 《教父》：人物眼部信息的控制与室内动机光共同塑造权力距离；方法重点是“允许观众看见多少”。
- 《花样年华》：走廊、门框与实景灯把人物限制在局部光区，光影与空间阻隔共同作用。
- 《银翼杀手2049》：大尺度环境光、雾尘和色彩分区建立空间身份；体积光服从建筑和天气。
- 《公民凯恩》：高反差、深焦空间与建筑阴影共同组织多人权力关系，光不是孤立装饰。
- 《情书》：雪地、窗光和室内反射在不同时间状态中保持克制的人物可读性。

作品参照用于理解光与场景的关系，不把某种光型固定为某种情绪或类型。

## 十二、常见失效

| 失效 | 根因 | 修正方向 |
|---|---|---|
| 每场都用漂亮逆光 | 轮廓效果替代戏剧判断 | 先决定面部信息、光源位置与人物目标 |
| 半脸暗自动表示秘密 | 把形体结果当人物标签 | 让秘密先由行动和关系建立 |
| 柔光覆盖所有人物 | 只追求肤质 | 恢复方向、负补光和背景层次 |
| 为解释光源增设可见灯具 | 把动机光源等同画内发光物 | 保留有依据的画外来源与光路，不强迫灯具入画 |
| 夜景人脸始终明亮、暗侧全可读 | 把表演可读当全脸可见的硬目标 | 保整体暗度与随行动失光，必要表演由声音、身形和局部显露承载 |
| 体积光没有介质来源 | 只复制视觉风格 | 建立雾、尘、烟、水汽及其运动原因 |
| 混合光随机变色 | 光源身份与色彩流程不清 | 固定主要来源，并让局部色偏服从空间 |
| 相邻镜头阴影跳向 | 灯位或人物朝向未连续 | 追踪光源、机位、动作和时间变化 |
| 亮度足够但道具不可读 | 高光、反射或景深抢走信息 | 调整光源角度、表面处理、焦点和背景关系 |

最终判断是：光影是否让人物、空间、材质和时间以本场需要的顺序被看见，并在变化后留下可读后果。

## 十三、光的变化挂在什么实体上

| 变化来源 | 可见过程 | 连续性边界 |
|---|---|---|
| 人物穿过固定光区 | 先有肩、脸或手进入光，再随转向显出不同面 | 灯的位置不随反打镜像；用新机位重新判断哪边脸受光 |
| 人物或门页遮光 | 光路被实际截住，受光面形成对应移动暗区，离开后恢复 | 遮挡物、光源和承接面要能连成遮光关系 |
| 水面反射 | 水纹改变反射方向，墙面或脸上亮斑随波纹游移 | 亮斑不是独立飘动的光源；没有反射路径时选其他载体 |
| 车窗、橱窗反光 | 移动的外景反射层与玻璃内的人脸交叠，视差和亮暗让遮蔽变化 | 反射不等于影子；保持玻璃位置、观看角度和两侧亮度关系 |
| 风吹纱帘或树叶 | 透光量、阴影边缘随实体改变，面部时隐时现 | 风向同时影响附近衣料和环境中实际受风的物件 |
| 火或屏幕亮度变化 | 光源变化先改写附近受光面，再由材质形成不同高光或色染 | 并非全场同亮同暗；距离、遮挡、曝光和主光会限制影响 |

正确的限制应保留：在普通写实成像中，光、遮挡和反射需有几何来源；没有散射或发光机制的空间，不凭空显示实体光柱。另一方面，“薄尘一律不见光束”“浓雾只能柔光”“同一能见度以外所有物体一律消失”都是过度硬化。观察角度、粒子与照度、物体自身亮度以及局部光路会改变结果。

教学重建：同一走廊中，来访者站在门口暖光可读区，屋内人只露出顶侧光下的下颌，眼睛留在阴影里；来访者说到关键处，门页轻合，暖光在其颊侧收窄。暗示来自双方可见程度和边界变化，不需再解释谁善谁恶，也不强制给阴影人物补眼神光。

## 同场光位、人物塑形与反打连续性

先在真实场景内确定光源，再从每个机位判断它照到了什么、留下什么未照亮。光位不是“摄影机左边”这种随反打变动的坐标，而是画外房间里的灯、窗洞、月光方向、天空可见范围或已有灯具在世界中的位置与光路。设计记录保留来源、照射范围与遮挡、冷暖、软硬、相对强弱，以及人物和背景哪些部分显露、哪些留暗；这不要求每个部分都有独立照明。只写“电影感、伦勃朗、丁达尔”尚未形成布光方案。

**动机光源、画内发光物和实际拍摄灯具分开理解**：动机光源解释故事世界里的光从哪里来，可在画外；画内实景灯只是可能被拍到的物件，并非光源成立的证明门槛；实际拍摄灯具可以在画外模拟既定来源，未见幕后证据时不把推测写成原片事实。没有灯具入画不构成错误，也不为交代光源增设一盏可见灯或让摄影机刻意拍灯。

**光场稳定不等于脸的曝光恒定**：先保留本场整体亮暗、亮区占比与暗处的性质，再推导人物进入、穿过和离开光区的变化。灯位不变时，脸可以从明到暗，眼睛可以失去高光，半边脸、黑衣或局部轮廓可以融入背景。叙事可读不等于所有五官和暗侧纹理始终可辨；暗处的表演可由头身朝向、停走、距离、声音与呼吸承担。自然低照度场景不为呈现全部微表情自动加辅光、轮廓光或提亮曝光；已定高调、舞台或美化照明则按其目标执行。

### 人脸：侧上塑形不等于每个角度都贴同一块亮斑

采用伦勃朗式塑形时，让已定侧前上方主光建立亮侧和暗侧，鼻影与面颊阴影相接，阴影侧眼下可形成小三角亮面。只有本场确需暗部表演可读且现场条件相容时，才以辅光或环境反射控制暗部；不为了保留三角亮斑、两只眼睛或面部纹理把暗面填平。光源尺寸、人物脸型及朝向共同决定结果，不以固定灯具百分比或一个角度数保证光型。柔光也可有明确方向和体积，并非只能得到大平光。

角色转头、侧身或摄影机反打后，三角亮面可能收窄、消失或不在当前可见侧。保持世界光源位置，重新描述此刻实际看见的亮面、鼻影、眼窝与轮廓；不要为了每镜都见相同三角而让主光绕着摄影机走。有意剪影、顶光藏眼、已批准的正面光与现场光条件仍各有用途，具体项目的默认光型不变成所有电影的唯一正确照法。

### 背景：光束、色光与人物层次分别安排

需要丁达尔效果时，给出实际来源与光路（例如画外窗洞、月光或已有灯具）、入射方向、尘雾或水汽的所在区域与运动来源、光束经过的建筑和落点；按当前取景选择是否看见光束，不强迫光源本体或全部轮廓入画。介质不够或视向不合适时，以墙面光斑和受光层次表现来源，而不是在清透空间平添实体光柱。背景束光不必把整张脸照平，粒子扰动也不等于灯具移动。

色彩按光源分配：例如西墙高窗的冷白光塑造人物，北墙红色灯牌只染近旁背景，桌上暖灯照亮手与桌沿。色光相遇的区域、物件反射及遮挡需相容，反打不把红蓝两盏光对调。单个色温数不代表整场所有光的颜色，更不自动规定红蓝效果光的实际色相。

### 机位换了，变化的是观察关系

换机位时沿同一光场重看：当前画面哪一侧亮、哪一侧暗，哪块窗光或灯色落在前中后层，人物或门页移动造成什么遮挡与显露。相邻镜头的屏幕亮侧可变化，灯在世界中的位置仍相同；人物穿过光区、光源真实移动或亮灭时，变化则由对应事件承担。连续跟拍同样服从此规则：人物走位服务关系与行动，而非站到预设亮点表演；摄影机退让、随转、背跟或停在门口，不要求人物每次回头都有同样亮的正脸。通用光场记一次，逐镜交代与当前脸、动作或背景有关的受光结果；既不把所有光学设定逐镜复抄，也不让逐镜画面只剩抽象风格名。

设计方法补充：2026-11-14—15，依据既有光型、光场与实体变化知识整理，补明画外动机光源、暗夜曝光与调度中的失光；模型专属段间切口、默认光型和最终文字格式由使用方执行合同规定。本节不新增电影通用角度配额、采样保证或器材实测结论。
