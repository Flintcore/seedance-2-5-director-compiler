# 光影设计参考库

光影设计同时决定可见性、形体、空间层次、时间天气和观看态度。光型没有固定情绪；同一种光在不同光源动机、曝光、反差、色彩、场景材质和人物行为中可以产生相反含义。

## 一、光影设计的基本变量

| 变量 | 直接改变的画面结果 | 需要结合的条件 |
|---|---|---|
| 光源方向 | 面部与物体哪些平面被看见，阴影落向哪里 | 人物朝向、机位、动作路径、场景结构 |
| 光源尺寸与距离 | 阴影边缘、皮肤与材质的过渡 | 光源相对主体的视角尺寸，而非灯具名称 |
| 主辅光关系 | 明暗反差、阴影信息和观看压力 | 曝光、显示介质、肤色、服装与背景亮度 |
| 色彩关系 | 光源身份、时间、阵营与材质偏色 | 实际光谱、白平衡取向、混合光和后期流程 |
| 光源动机 | 观众是否相信光来自窗、灯、火、屏幕或环境反射 | 光源位置、遮挡、衰减和人物运动 |
| 空气介质 | 远近层次、光路可见度、对比和色彩衰减 | 粒子性质、密度、光束方向、观察方向和曝光 |
| 时间变化 | 光斑移动、亮度起伏、色彩和阴影长度变化 | 日照、天气、实景灯具、火焰、车辆与人物遮挡 |

灯具位置本身不等于含义。意义来自“谁被允许看清、谁被隐藏、光是否与人物行动同步，以及变化发生在何时”。

## 二、常见光型关系

| 光型关系 | 可见结果 | 常见叙事用途 | 主要风险 |
|---|---|---|---|
| 逆光与轮廓光 | 主体边缘与背景分离，面部可能保留暗部 | 登场、隔离、匿名、空间深度、天气显示 | 只剩漂亮轮廓，表演不可读 |
| 顶部来光 | 眼窝、帽檐和下颌阴影加深，地面成为受光面 | 建筑灯、审讯灯、正午日照、权力空间 | 自动把人物拍成反派，忽略真实光源 |
| 低位来光 | 阴影方向偏离日常经验，面部结构重新组织 | 地面灯、火、屏幕、机械装置、异常环境 | 无动机的恐怖化和面部失真 |
| 侧光 | 明暗沿形体分区，纹理和轮廓更明显 | 窗边、门缝、舞台侧光、关系分隔 | 把半明半暗机械等同双重人格 |
| 正面来光 | 面部信息充分，纹理与体积可能被压平 | 公开陈述、时尚肖像、闪光灯、主观直面 | 缺少形体或让背景失去层次 |
| 硬光 | 阴影边界清楚，高光集中，表面纹理突出 | 日照、裸灯、聚光、暴露与图形化 | 反差超过叙事需要，细节不可读 |
| 柔光 | 阴影过渡宽，皮肤与材质起伏较平缓 | 阴天、窗纱、反射、贴近人物的观察 | 无差别磨平空间和人物状态 |
| 体积光 | 光路因介质散射而可见，空间被分层 | 雾、烟、尘、水下、舞台与工业环境 | 介质无来源、光束方向与光源矛盾 |

## 三、逆光与轮廓分离

逆光从主体后方或侧后方进入镜头。它可以描出头发、衣物、雨雪、尘雾和透明材质，也可能让人物面部落入暗部。

### 可用的导演决定

- 需要观众先认出姿态而非身份时，让轮廓先于面部信息出现。
- 需要人物与明亮出口、窗或天空发生关系时，让光源成为空间目标。
- 需要读表演时，用环境反射、侧面补光或人物转身逐步恢复面部信息。
- 需要保持匿名或疏离时，允许暗部持续，但仍保留动作轮廓和关键物件。

逆光并不自动浪漫或英雄化。冷硬的工业出口、车灯和审讯室玻璃也能形成威胁；意义取决于人物面向光还是被光吞没。

## 四、顶部与低位来光

顶部来光常来自正午太阳、吊灯、走廊灯、厂房或舞台。它强调地面、肩部和头顶，并可能遮住眼睛。低位来光常来自火、桌灯、屏幕、地面设备或反射面，会改变熟悉的面部阴影方向。

### 设计条件

- 光源在场景中有位置，阴影方向应随人物移动和转身变化。
- 人物眼睛是否可读是叙事选择：隐藏可以延迟理解，恢复可见则能形成关系变化。
- 低位光若来自屏幕或火焰，亮度、颜色与闪动应影响手、衣物和附近表面。
- 俯视或仰视机位会改变受光面积；打光需与最终机位共同判断，而不是脱离镜头设定。

顶部来光也可以是平静日常的厨房灯，低位来光也可以是壁炉边的亲密光源。不要由方向直接推导人物道德属性。

## 五、侧光、正面光与形体

侧光通过明暗交界塑造形体，适合表现窗、门、走廊和人物之间的空间分区。正面光提供较完整的面部信息，也能制造被审视、被拍照或主动直面观众的感觉。

### 关系设计

- 两人被同一侧光覆盖，可显示共享环境；被不同方向或不同色彩的光分开，可显示处境差异。
- 人物走过明暗边界时，身份、态度或可见信息可在同一镜头内改变。
- 正面光与暗背景结合时，脸可能像证词一样被单独呈现；与明亮环境结合时则可保持开放和平等。
- 半边脸明暗分割只是形体结果。只有剧情已经建立秘密、选择或关系冲突时，它才可能承载相应含义。

## 六、硬光与柔光

硬光和柔光描述阴影过渡，不等于画面“强”或“温柔”。光源相对主体越小、越远，阴影通常越清楚；相对尺寸越大或经过扩散、反射，过渡通常越宽。

### 硬光的可见特征

- 强调皱纹、汗水、灰尘、织物和建筑纹理；
- 产生清楚的图形阴影和遮挡关系；
- 人物或物件移动时，阴影变化更容易被读到；
- 高反差条件下可能牺牲眼神、肤色或暗部动作。

### 柔光的可见特征

- 保留面部渐变并弱化局部纹理；
- 让多个反射面共同构成环境亮度；
- 适合连续调度，因为人物离开精确位置后变化较缓；
- 如果缺少方向、层次与负补光，空间会变平。

选择软硬首先看光源条件、材质和人物运动，再看场景希望暴露还是保护哪些信息。

## 七、经典人像光型

### 蝴蝶光

主光接近人物正前上方，鼻下出现居中的小阴影，双颊较均衡。它与旧好莱坞肖像和摄影棚控制有关，但可用于任何性别与角色。背景、服装、镜头距离和人物是否直视摄影机会改变其含义。

### 伦勃朗式侧上光

主光位于人物侧前上方，阴影侧脸颊保留由鼻影与面颊受光形成的小块亮面。亮面是否出现取决于脸型、转头和光源尺寸，不应被当成固定角度配方。

### 三点布光关系

三点布光描述主光、辅光和轮廓分离之间的职责，不要求三盏灯都存在：

| 职责 | 画面作用 | 可替代来源 |
|---|---|---|
| 主光 | 建立主要方向、形体与曝光依据 | 窗、太阳、实景灯、反射或人造灯 |
| 辅光 | 控制阴影信息与反差 | 天光、墙面反射、地面反射、主动补光 |
| 轮廓分离 | 让主体与背景在亮度或色彩上分开 | 逆光、背景亮区、雾、服装与背景反差 |

自然主义场景可以省略明显的辅光或轮廓光；关键是人物在动作范围内仍保持叙事所需的可读性。

## 八、自然光与混合光

### 天光

开阔天空提供大面积环境光，其方向、色彩和反差受云层、太阳位置、建筑反射、地面颜色与开口大小影响。阴天可能柔和但并非无方向；蓝天阴影和城市峡谷也会产生明显色偏。

### 直射日光

太阳是方向明确的远距离光源。画面呈冷暖何种关系，取决于时段、大气、白平衡取向、反射环境和曝光；日光的标称色温不等于画面必然呈现某一种颜色。

### 实景混合光

窗外天光、室内灯、屏幕、火焰和广告牌同时存在时，应决定哪一来源支配人物，哪些来源只在局部留下色彩或高光。混合光可以保留真实冲突，也可以通过换灯、遮光、反射和后期分离整理层次。

白平衡是对光源的解释，不是情绪按钮。它需与摄影机、记录格式、监看、肤色和后期色彩流程共同确定。

## 九、空气介质与体积光

可见光路来自空气中粒子对光的散射。是否形成清楚光束同时取决于：

- 粒子的性质、浓度、分布与运动；
- 光源是否集中、方向是否明确；
- 光束方向与摄影机观察方向的关系；
- 背景亮度、曝光、镜头耀斑和动态范围；
- 空间尺度以及光在介质中的衰减。

| 介质状态 | 常见画面结果 | 连续性要求 |
|---|---|---|
| 空气较清 | 主要看见受光表面，光路不突出 | 远景对比和能见度服从天气与尺度 |
| 少量尘、水汽或薄雾 | 方向性强的光可能出现细微路径，远景略软 | 粒子需有来源，运动受风和热影响 |
| 分层雾气 | 空间前后层次明显，光束边缘随浓度变化 | 人物穿行会扰动局部密度 |
| 浓雾 | 远景对比下降，近处光源可能形成光晕 | 曝光、能见度和相邻镜头密度保持连续 |
| 翻涌烟尘 | 光路、遮挡和颜色持续变化 | 火源、碰撞、通风与沉降决定流向 |

介质越浓并不简单等于光越柔或光束越清楚。浓度过高可能让光在到达主体前已显著衰减；清楚光束常需要方向明确的光与合适的观察关系。

## 十、曝光、材质与肤色

- 先确定需要保留的高光和暗部信息，再决定反差；不同摄影机和记录介质可承受的范围不同。
- 深色皮肤、浅色服装、金属、玻璃、湿表面和烟雾对光的响应不同，不能共用同一“亮度足够”判断。
- 镜面高光显示光源位置与尺寸，漫反射显示受光面的颜色与形体；两者需要分别观察。
- 人物从一个光区走到另一个光区时，曝光变化、瞳孔适应和背景关系可以成为叙事事件。
- 相邻镜头的亮度、阴影方向和色彩可以有意改变，但变化需要时间、机位、光源或视点依据。

## 十一、作品锚点

- 《教父》：人物眼部信息的控制与室内动机光共同塑造权力距离；方法重点是“允许观众看见多少”。
- 《花样年华》：走廊、门框与实景灯把人物限制在局部光区，光影与空间阻隔共同作用。
- 《银翼杀手2049》：大尺度环境光、雾尘和色彩分区建立空间身份；体积光服从建筑和天气。
- 《公民凯恩》：高反差、深焦空间与建筑阴影共同组织多人权力关系，光不是孤立装饰。
- 《情书》：雪地、窗光和室内反射在不同时间状态中保持克制的人物可读性。

作品参照用于理解光与场景的关系，不把某种光型固定为某种情绪或类型。

## 十二、常见失效

| 失效 | 根因 | 修正方向 |
|---|---|---|
| 每场都用漂亮逆光 | 轮廓效果替代戏剧判断 | 先决定面部信息、光源位置与人物目标 |
| 半脸暗自动表示秘密 | 把形体结果当人物标签 | 让秘密先由行动和关系建立 |
| 柔光覆盖所有人物 | 只追求肤质 | 恢复方向、负补光和背景层次 |
| 体积光没有介质来源 | 只复制视觉风格 | 建立雾、尘、烟、水汽及其运动原因 |
| 混合光随机变色 | 光源身份与色彩流程不清 | 固定主要来源，并让局部色偏服从空间 |
| 相邻镜头阴影跳向 | 灯位或人物朝向未连续 | 追踪光源、机位、动作和时间变化 |
| 亮度足够但道具不可读 | 高光、反射或景深抢走信息 | 调整光源角度、表面处理、焦点和背景关系 |

最终判断是：光影是否让人物、空间、材质和时间以本场需要的顺序被看见，并在变化后留下可读后果。
