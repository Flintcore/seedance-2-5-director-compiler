# 景深与焦点叙事决策库

景深决定观众能同时比较多少空间层，焦点变化决定注意力何时从一个对象转向另一个对象。先锁认知任务，再选焦距、光圈、距离和对焦方式。

## 一、景深的五种叙事功能

| 功能 | 画面关系 | 适用问题 |
|---|---|---|
| 孤立 | 主体清楚，环境退后 | 亲密、脆弱、主观收窄 |
| 比较 | 多层同时清楚 | 权力、秘密、多人反应、空间因果 |
| 隐藏 | 对象存在但暂不可读 | 悬念、误认、延迟揭示 |
| 转移 | 焦点在镜内改变 | 发现、视线接力、关系重组 |
| 失去 | 主体离开焦平面或焦点无处落 | 失控、缺席、认知断裂 |

景深不是每镜需要变化的装饰。保持一致可以建立稳定观看规则，改变则应对应认知变化。

## 二、影响景深的因素

- 光圈越开，景深通常越浅；
- 景深与焦外模糊受焦距、对焦距离、光圈和取景条件共同影响；透视压缩首先来自较远的观察位置，不由焦距或靠近单独制造；
- 主体与背景距离越大，分离越明显；
- 传感器、画幅与光线条件也会影响结果；
- 对焦速度、呼吸效应和运动会改变焦点转移的质感。

参数服务空间和表演，不追求孤立的精确数字。

## 三、浅景深

浅景深适合限制观众信息、贴近人物或让背景先作为压力存在。设计时确认：

- 主体眼睛、手或物件中哪一处必须清楚；
- 背景虚化后是否仍保留方向和身份线索；
- 人物移动是否会离开焦平面；
- 关键动作是否因过浅焦点变得不可读；
- 相邻镜的空间是否仍能被理解。

浅景深不是“电影感”默认值。对白、群像和复杂动作常需要更多空间信息。

## 四、深焦

深焦允许观众同时观察前中后景，适合：

- 不同人物掌握不同信息；
- 背景事件改变前景关系；
- 观众需要自行选择注意力；
- 权力由空间距离和位置决定；
- 长镜头内多层调度。

深焦画面仍需通过光、运动、色彩和构图排序注意力，避免所有层同权。

## 五、移焦

移焦是镜内的认知切换。完整设计包括：

1. 起始焦点和观众当前理解；
2. 触发焦点变化的视线、声音、动作或新信息；
3. 焦点经过哪些层；
4. 终点对象及其带来的新关系；
5. 人物是否注意到同一对象。

快移焦可表现突然察觉，缓慢移焦可让观众逐步发现或等待理解。速度由认知过程决定，不套固定时长。

## 六、焦点与信息差

- 观众焦点跟随人物视线：与人物同步发现。
- 焦点先移到威胁、人物尚未察觉：观众先知道。
- 人物看见但焦点留在其反应：延迟给出对象。
- 前景说话者虚化、背景听者清楚：让反应成为当前信息。
- 焦点停在空位或离开的人留下的物件：让缺席成为主题。

焦点不必总跟说话者。

## 七、运动与对焦

- 人物朝镜头移动时，焦点变化应与速度和路线协调。
- 横向移动更容易保持焦平面，但背景关系仍在变化。
- 跟拍中可维持人物清楚，让背景运动显示路线；也可允许短暂失焦表现主观失衡。
- 动作场面优先保证目标、接触和路径可读，不用极浅景深遮掩因果。
- 多人物换位时，决定焦点是跟随主角、接力给对手，还是保持深焦见证。

## 八、焦外空间

焦外不等于不存在。颜色、轮廓、运动和声音仍能产生期待。有效焦外信息：

- 人物能辨认、观众暂时不能确认的身影；
- 即将进入焦点的威胁或关系对象；
- 作为情绪压力存在的群体、城市或环境；
- 与清楚主体形成颜色、形状或运动对比的层。

若焦外对象承担关键因果，应在适当时刻恢复可读性。

## 九、作品锚点

- 《公民凯恩》：深焦让前中后景的权力与行动同时成立。
- 《花样年华》：浅焦与遮挡限制观看，也让人物被环境包围。
- 《大白鲨》：焦点与空间压缩共同把察觉转化为身体冲击。
- 《寄生虫》：多层空间和清楚背景让阶级关系进入同一画面。
- 《银翼杀手 2049》：浅焦与宏大环境交替，塑造人物孤立与世界尺度。
- 《一次别离》：多人关系需要足够景深，让观众自行判断。

## 十、常见失效

| 失效 | 原因 | 修正 |
|---|---|---|
| 所有镜头都极浅景深 | 把虚化当高级感 | 按信息与空间任务选择 |
| 移焦没有触发 | 只展示技术 | 让视线、声音或动作启动变化 |
| 焦点在说话者和听者间机械跳 | 按台词轮次对焦 | 跟随理解和关系变化 |
| 背景虚化后空间丢失 | 缺少建立与方向参照 | 先建立位置，保留轮廓或声源 |
| 深焦画面无中心 | 多层信息同权 | 用光、运动和构图排序 |
| 动作中失焦遮住接触 | 景深与运动冲突 | 增加容错并保持关键路径清楚 |
| 参数很精确但认知不清 | 技术先于叙事 | 回到起点、触发和终点 |

最终判断：焦点是否在正确时刻把观众带到这场戏最重要的关系上。

## 十一、把焦点变化写成可拍的认知过程

三种常用路径各有条件，不是必须完成的曲线：

- **深到浅的收束**：先让同桌人物和门口关系一起可读，随后在更近的覆盖镜里孤立沉默者。若在同镜内改变可接受清晰范围，需要说明变焦、光圈、机位或主体距离等实际变化；单纯转动对焦环不会自动把所有背景都抹掉。
- **浅到较深的揭示**：原来只读脸部，随后用拉远、取景变宽、调度或合理的景深变化让处境进入画面。仅移焦到背景会把清楚对象换过去，并非同时让前后都清晰。
- **浅到移焦再浅的接力**：前景正在签字的手先清楚，听到名字后笔停，焦点移到更远处的听者；画面暂留其决定是否开口的反应，前景说话仍可延续。

左右并排、距离镜头近似相同的两人通常处于近似同一对焦距离；“从左脸横向移焦到右脸”本身并不成立为普通移焦。可以用人物前后错位、摇移、构图或切镜转移注意。离轴像场、特殊镜头和分区成像另按具体光学方案处理。

硬条件保留在关系层：焦点实际落在要读的距离，关键目标在景深、尺寸和遮挡条件下可辨。深焦与空气透视分开判断；薄雾降低远景反差不是失焦，增加景深也不会让被实体挡住的内容显现。
