# 表演细节参考库

表演细节用于把人物目标、控制方式和变化变成可观察证据。它不是逐镜配额，也不是情绪词典。选择能支持当前人物状态、关系、情绪质感或行动的细节；生活基线和含蓄余态也有价值，不以新增剧情信息作为唯一门槛。

## 一、选择顺序

1. 人物此刻在做什么现实任务；
2. 人物想让别人相信什么；
3. 身体哪里最可能泄露真实状态；
4. 谁能看见这份泄露；
5. 泄露后关系或行动如何改变。

景别决定细节尺度。全景依靠姿态、距离和节奏；近景才适合眼、嘴、手指与呼吸的微小变化。

## 二、眼与视线

- 视线先到、头部后到：突然察觉或试图隐藏注意力。
- 头部转向、眼睛仍停留：身体准备离开，心理尚未离开。
- 对视后主动移开：可能是让步、保护、羞耻或结束挑战。
- 目光越过对方看出口：把逃离置于当前交流之上。
- 反复确认同一物件：焦虑、依恋或风险评估。
- 眨眼节奏变化：控制受到扰动，但需结合触发与其他动作判断。

视线要有明确目标或明确的失神状态；落点可以在画外。抽象的“望向远方”若没有空间或注意依据，通常难以提供关系信息。

## 三、嘴、下颌与声音

- 嘴唇微启后闭合：话语形成又被撤回。
- 下颌短暂绷紧：人物在压住动作或话语。
- 吞咽与起音受阻：身体先暴露压力。
- 微笑出现得太晚或消失得太快：社交表演与真实反应错位。
- 句尾变轻、吞字或改口：人物正在重新计算风险。
- 声音维持平稳而呼吸变浅：公开控制仍在，身体成本上升。

避免给每种动作绑定唯一情绪。

## 四、手与物件

- 伸手后停住、改变抓握或收回：决定尚未完成。
- 把物件摆正、擦拭、折叠：以秩序动作控制内部混乱。
- 握持变紧、指节失去血色：压力进入身体，但不自动等同愤怒。
- 桌下动作与桌面动作不一致：公开形象与真实状态分裂。
- 触碰旧物、饰品或伤处：记忆、自我安抚或确认身份。
- 交接动作的速度、朝向和是否松手：信任、权力和归属。

手部细节要与物件连续性一致。

## 五、姿态、重心与距离

- 重心前移表示准备进入行动，后移表示保留退路或拒绝接近。
- 脊柱突然挺直可能是恢复控制、迎战或伪装脆弱。
- 身体朝向与脸部朝向分离，会显示礼貌留下但行动已转向。
- 坐下、起身、占据门口或让出座位都会改变权力空间。
- 受伤或疲劳应改变支撑脚、动作幅度和恢复方式。
- 静止时仍可通过肌肉张力、呼吸和目光保持生命感。

## 六、呼吸与节奏

- 吸气是准备，屏息是受阻，呼气可表示释放、放弃或重新控制。
- 急促呼吸需要身体原因；强情绪、奔跑、疼痛和恐惧的呼吸形态不同。
- 动作节奏可从完整变为短促、从连续变为断裂，或从忙乱突然停止。
- 角色习惯节奏被打破，常比新增夸张动作更能显示变化。

## 七、多人表演

- 不让所有人物同时做同幅度反应；按谁先察觉、谁有利害关系分别设计。
- 主要人物的动作可由旁观者视线或让路得到确认。
- 群体中有人继续原任务，会让突发事件更真实，也能形成层次。
- 两人关系变化可通过距离、共同节奏、物件交接和谁先恢复日常动作表现。

## 八、表演弧

细节应形成前后关系：

- 建立人物的常态动作；
- 触发让常态短暂偏离；
- 人物试图恢复或掩饰；
- 控制成功、失败或转化为新行动；
- 结果留在姿态、距离、物件或声音中。

同一个细节重复时，其含义应因情境或归属变化而改变。

## 九、常见失效

| 失效 | 根因 | 修正 |
|---|---|---|
| 皱眉、抿嘴、握拳同时出现 | 用细节数量替代意图 | 选最能泄露人物策略的一项 |
| 所有人都以同样方式紧张 | 忽略角色目标与社会能力 | 为每人选择不同控制方式 |
| 微动作在全景中承担关键信息 | 景别不支持可读性 | 改用姿态、走位或必要的近景 |
| 表演持续升级 | 没有克制、转弯与余波 | 让人物尝试恢复控制或改变策略 |
| 细节没有触发 | 动作像随机装饰 | 把它放在具体信息或对方动作之后 |
| 特写替代空间关系 | 只看脸，不看关系 | 回到双人镜、物件和距离变化 |

表演细节的目标是精确，不是密集。

## 十、从细节词汇到人物动作的示范

以下是可替换的教学重建，不是情绪对应密码；从已给人物动机中挑选，不额外编造秘密。

| 已建立的处境 | 可演的连续变化 | 结束时留下什么 |
|---|---|---|
| 礼貌接待中听到冒犯 | 手上倒水先放慢，抬眼看向说话者，嘴角的礼貌弧度稍晚才收住 | 水壶放回原处，下一句起音比之前更清楚、更有边界 |
| 想挽留但只谈日常 | 手已把对方的外套递出，听到离开时间后停了一下，再继续递到对方可接位置 | 松手晚于动作预期，随后视线仍跟着外套离开 |
| 努力保持专业的担心 | 先确认对方脸色，再看他扶着的手臂；伸手欲帮却在对方退开时收住 | 手转去扶门，帮助意图转成不冒犯的行动 |
| 奔走后强装平静 | 站稳再开口，前半句气息够，句尾需要补一次吸气 | 肩颈逐渐落定，呼吸恢复比表情更慢 |
| 刚决定不再争辩 | 原先敲桌的指尖停下，看着对方听完，手掌平放后收回自己的物件 | 身体转向离开路线，眼睛最后才离开对方 |

手部词汇可以更具体：摩挲杯沿、捻平纸角、握住后又松一点、指尖试探接触、交接时仍保留一根手指。是否出现由角色习惯与物件状态决定，不把握拳、青筋、颤抖和泪光叠成“有表演”。被脸部遮挡的情绪可经呼吸、衣料、重心、物件接触或对手的注意显示，未被拍到的细小肌肉变化只作演员准备，不挤入画面描述。
