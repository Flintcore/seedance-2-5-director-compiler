# 机位技术规格与成像条件参考库

本库说明机位、镜头、画幅、焦点与曝光参数如何共同形成可见结果。技术选择以具体摄影机、镜头、主体尺度、空间、运动、光线、记录格式和放映条件为依据，不提供跨项目通用的焦段、光圈、ISO、白平衡或角度档位。

## 一、技术变量的依赖关系

摄影结果来自多项变量共同作用：

**画面结果 = 摄影机位置 + 朝向与高度 + 画幅/传感器 + 镜头视角 + 对焦距离 + 光圈与光量 + 主体运动 + 快门关系 + 光源与记录流程。**

其中：

- **摄影机位置**决定近大远小和物体之间的透视关系；
- **镜头焦距与画幅**共同决定当前机位能收进多宽的视野；
- **景别**由主体尺寸、摄影机距离、焦距和画幅共同决定；
- **景深**由光圈、焦距、对焦距离、画幅和观看条件共同决定；
- **运动模糊**由主体/摄影机运动、帧率与曝光时间关系共同决定；
- **噪点和高光余量**依赖摄影机感光结构、增益策略、曝光和记录格式；
- **画面冷暖**来自光源光谱、环境反射、白平衡取向和后期色彩流程。

任何单一参数都不能脱离这些条件直接等同情绪或“电影感”。

## 二、机位坐标

机位可用四组相对关系描述：

| 关系 | 需要说明的内容 | 可见结果 |
|---|---|---|
| 高度 | 摄影机相对人物眼睛、身体、物件或建筑的位置 | 地面/天空比例、身体形变、遮挡和视线关系 |
| 水平位置 | 正面、侧前、侧面、背面或关系轴上的位置 | 面部可读性、身体方向、人物左右和观看态度 |
| 距离 | 摄影机与主体及各层空间的实际距离 | 透视比例、空间压缩感、调度范围和亲近程度 |
| 朝向 | 镜头光轴指向何处，是否倾斜或偏离主体 | 地平线、垂直线、画框边界和空间重心 |

先描述相对关系和画面结果，再在已知场地与设备下测出实际数值。

## 三、垂直机位

### 高于主体

摄影机升高后，地面、桌面、路线和群体分布通常更容易进入画面；人物头顶与肩部面积增加，面部下半部可能被压缩或遮挡。

**适用判断**：

- 需要同时看见人物与其可走路径、障碍或群体位置；
- 需要从照料者、监控者、建筑或高处人物的视点观看；
- 需要把身体动作变成平面图形或显示人物被空间包围。

它不自动表示人物弱小。高位也可以表现掌控地图、观察儿童、展示劳动流程或制造喜剧秩序。

### 接近主体视线

摄影机接近人物视线高度时，垂直透视较少成为注意中心，面部、视线和背景关系更自然地竞争观看。

平视可以显得平等，也可以因正面距离、凝视和静止而具有审讯感；含义取决于观看者是谁以及人物是否回应镜头方向。

### 低于主体

低位机位让天空、天花、建筑高度和身体下部占比增加，近处部位与远处部位的比例会随距离差异改变。

**适用判断**：

- 观看主体位于地面、座位、低处设备或倒地状态；
- 需要显示人物与高处结构、出口、招牌或威胁的关系；
- 需要让脚步、障碍和上方动作进入前景。

低位不自动表示威严。它同样可以表达受限、躲藏、儿童视点、物件视点或身体失衡。

### 顶部机位

接近垂直向下时，人物和环境趋向平面图形，路线、重复动作和群体几何更突出。顶拍可用于程序、舞蹈、劳动、喜剧、暴力后果或抽离观看；情绪由前后语境和画内行动建立。

## 四、水平机位

### 正面

正面机位让脸、身体正面和对称关系更清楚。它可用于公开陈述、表演展示、直接对峙、人物主动面对观众，或冷静的类型化构图。

### 侧前方

侧前方同时保留面部和身体朝向，适合人物与对手、物件或出口之间的关系。角度由需要看见的两侧信息决定，不依赖固定度数。

### 正侧面

侧面强调轮廓、并行运动、距离和人物之间的线性关系。面部细节减少时，身体姿态、路径和声音需要承担更多信息。

### 背面

背面保留人物所面对的空间并限制面部读取。它可形成跟随、延迟身份、孤独或共同观看，也可让观众先看见人物尚未反应的威胁。

### 越肩与双人关系

越肩不是固定肩部占比或固定焦段。前景人物应提供立场、距离、遮挡或反应价值；主体与前景的清晰关系由叙事重点、对焦距离、镜头视角和空间条件共同决定。

## 五、摄影机位置与透视

透视描述画面中近远物体的相对大小和汇聚关系，主要由摄影机位置决定。

### 位置变化的结果

- 摄影机靠近主体时，近处部位相对放大，前后景尺寸差增大，运动视差更明显；
- 摄影机远离主体时，近远比例差减小，人物与背景看起来更接近同一平面；
- 改变高度会重新组织地面、天花和物体遮挡；
- 横向移动会改变前景遮挡和背景相对位置，即使景别不变也会改变空间意义。

### 焦距常见误解

在摄影机位置不变时，换镜头主要改变取景范围和放大率；所谓“广角夸张透视”或“长焦压缩空间”，通常还包含为了保持相似景别而移动摄影机的结果。因此，讨论透视时应同时说明机位是否改变。

## 六、焦距、画幅与视角范围

焦距只有与画幅或传感器尺寸一起讨论才有明确视角意义。同一焦距在不同画幅上会覆盖不同范围；不同镜头设计还会改变畸变、呼吸效应、最近对焦、耀斑、反差和边缘表现。

| 相对视角 | 常见可见结果 | 选择条件 | 风险 |
|---|---|---|---|
| 较宽 | 收入更多环境，近距离运动视差明显，边缘更容易拉伸 | 需要人物与空间同时可读，或摄影机受场地限制 | 为求宏大贴得过近，人物和建筑变形 |
| 中等 | 主体与环境比例较平衡，调度和面部都可保留 | 需要自然观察或多人关系 | 把“中性”误当无观点 |
| 较窄 | 取景范围收紧，远处背景更容易被选取，摄影机常需退远 | 需要隔离主体、压缩多层关系或远距离观察 | 背景运动与空间地理变得难读 |

“人眼视角”不是一个固定焦距。人类视觉包含双眼、眼球运动、周边视觉和注意选择，镜头只能在特定画幅与观看距离下形成某种主观近似。

## 七、景别与摄影机距离

景别描述主体在画框中占据的范围，而不是摄影机的固定米数。同一距离可因主体大小、焦距和画幅得到不同景别，同一景别也可由不同机位与镜头组合得到不同透视。

### 景别选择的技术后果

- 近景若由摄影机靠近获得，面部和前后部位比例变化更明显；
- 近景若由较远机位和较窄视角获得，背景关系更集中，摄影机与表演保持更大距离；
- 全景需要兼顾人物轮廓、脚下空间和动作路径，焦点与曝光不能只服务脸部；
- 多人景别要根据人物间最大距离和调度范围预留画框空间；
- 关键物件的可读性取决于尺寸、对比、焦点、运动和停留，不由摄影机距离单独保证。

## 八、光圈与景深

光圈改变进入镜头的光量和景深，但结果同时受焦距、对焦距离、画幅、镜头成像、显示尺寸和观众可接受清晰度影响。

### 相对开大光圈

- 景深通常变浅，焦点偏移更容易被看见；
- 暗光下可增加曝光，但高光、镜头像差和对焦容错需要重新评估；
- 人物移动或多人不同平面时，跟焦难度增加；
- 背景虚化程度还取决于主体与背景距离、焦距和画幅。

### 相对收小光圈

- 景深通常增加，多层空间更容易保持可读；
- 需要更多光量或调整其他曝光变量；
- 过度收小可能引入衍射，实际阈值依赖镜头、画幅和输出尺寸；
- 深焦不自动建立视觉层级，仍需构图、光和运动引导。

摄影镜头常以 T 值描述实际透光量，以 f 值描述几何孔径关系；两者不应在未知镜头条件下假定完全相同。

## 九、焦点设计

### 对焦距离

对焦点决定清晰平面的位置。人物走位、摄影机运动和镜头呼吸会改变画面构图及清晰关系。

### 移焦

移焦把观看权重从一个平面交给另一个平面。成立时需要旧对象、新对象和转移触发；速度由观众识别负担、表演节拍和跟焦能力决定。

### 深焦与分区焦点

多层同时清晰适合比较关系、伏笔和空间后果，但主体仍需通过光、运动、声音或调度被优先看见。特殊光学方案应通过实拍测试确认边界和过渡，不把效果名称直接等同叙事意义。

## 十、帧率、曝光时间与运动质感

帧率决定时间采样，单帧曝光时间或快门角关系决定每帧内积累多少运动模糊。最终感觉还受播放速度、主体速度、运动方向、镜头视角、摄影机运动和显示设备影响。

| 目标结果 | 变量倾向 | 代价与条件 |
|---|---|---|
| 自然连续的运动模糊 | 让曝光时间与播放帧率保持常规关系 | 快速横移和近景掠过仍可能模糊过多 |
| 更锐利、断续的动作边缘 | 缩短单帧曝光时间 | 需要更多光，运动可能显得生硬 |
| 更长的拖影 | 延长单帧曝光时间 | 细节和动作相位可能不可读 |
| 升格慢动作 | 以更高采样记录并按目标速度播放 | 需要足够光量、数据率和动作设计支持 |
| 欠采样或跳跃感 | 改变采样或播放关系 | 连续性和观众方向感更难维持 |

慢动作、锐利快门或拖影没有固定情绪用途。它们应服务动作可读性、主观感受或时间结构，并与声音和剪辑共同设计。

## 十一、曝光与感光策略

曝光由场景照度、镜头透光、曝光时间、感光增益和记录介质共同形成。监看亮度不等于记录信号已获得足够曝光。

### ISO 与增益

- 标称 ISO 和基础感光策略随摄影机而异；部分摄影机具有多套原生增益路径；
- 提高增益可能提升监看亮度，也会改变噪点、高光余量、色彩和暗部质感；
- 降低增益并不自动更干净，欠曝后提亮可能比正确曝光产生更多噪点；
- 胶片感光度、数字摄影机 EI/ISO 与后期推拉需按各自流程理解。

因此没有跨机型通用的日景、夜景或运动上限。应根据摄影机测试、波形/假色、肤色与关键材质、高光保护和后期目标确定。

### 动态范围与曝光分配

- 决定哪些高光可以剪切、哪些暗部需要保留动作；
- 观察人物肤色、深色服装、窗外和发光物能否同时满足叙事；
- 烟、雾、玻璃、金属和湿表面会改变局部高光与反差；
- 调整光源和反差通常比单纯改变增益更能控制画面关系。

## 十二、白平衡与色彩关系

白平衡决定记录系统如何解释光源，不是固定的冷暖预设。现场光源可能具有不同光谱，即使标称色温相近，也会在肤色和材质上产生不同结果。

### 决定条件

- 主导光源及其光谱质量；
- 天光、实景灯、火、屏幕和霓虹之间的混合关系；
- 摄影机色彩科学、滤镜、记录格式与监看变换；
- 希望保留、校正或强化的光源差异；
- 后期调色是否需要保持中性参考和匹配多机位。

相邻镜头的白平衡可以保持，也可以因时间、地点、视点或光源改变而变化。连续性的依据是光源和叙事状态，不是任何镜都锁死同一数值。

## 十三、特殊机位的条件

### 荷兰角

倾斜画框会改变地平线、垂直线和重力预期。倾斜程度由场景几何、人物姿态、前后镜差异和可读性决定；它可表现主观失衡、图形动势、喜剧或世界结构，不只服务恐惧。

### POV

主观视点通过身体高度、运动、遮挡、视线和声场建立。镜头视角应接近角色当下的注意范围，而不是固定模仿某个“人眼焦段”。稳定、手持、长焦或广角都可成立，只要与角色状态和空间条件一致。

### 越肩

前景肩部的面积、清晰度和位置由关系强度、遮挡价值、焦点和切换连续决定。过大的前景可能造成压迫或信息遮蔽，过小则失去立场感。

### 极高、贴地与封闭机位

安装位置受安全、承重、运动路径、镜头最近对焦、遥控和照明条件限制。技术可行性需与画面职责共同判断，不能由情绪标签直接选择。

## 十四、机位与运动安全边界

- 先确认摄影机、演员、车辆、吊挂、轨道和特效的运动包络；
- 镜头最近对焦、遮光斗、稳定系统和机身尺寸会限制狭小空间机位；
- 高速、低位或贴近动作的机位需要保护距离、替身、遥控或防护结构；
- 反射、屏幕刷新、频闪光和滚动快门需通过实际设备测试；
- 多机位拍摄要协调轴线、灯位、反射、曝光和互相穿帮。

这些约束会改变可用机位，应在导演构想进入实拍方案时显式纳入。

## 十五、参数测试与连续记录

精确参数只有在已知设备和场景中才有意义。摄影测试应保留：

- 摄影机、记录格式、画幅与监看变换；
- 镜头型号、对焦距离、光圈/T 值和滤镜；
- 主体与摄影机位置、景别及背景距离；
- 光源类型、照度关系、曝光工具读数和感光策略；
- 帧率、曝光时间关系、运动速度和播放方式；
- 白平衡取向、混合光来源与后期处理说明。

测试记录用于复现画面结果，不作为其他项目的普适参数表。

## 十六、从画面结果反推技术选择

| 希望观众看见的结果 | 优先调整 | 同时观察 |
|---|---|---|
| 人物与环境关系更强 | 摄影机位置、视角范围、景深和调度 | 边缘变形、背景抢权、空间方向 |
| 面部与背景更分离 | 机位距离、焦距/画幅组合、光和焦点 | 透视变化、跟焦、头部运动空间 |
| 多层行动同时可读 | 调度层次、景深、光和声音 | 视觉中心、曝光、动作遮挡 |
| 运动更有重量 | 路径、接触、摄影机距离和曝光时间关系 | 方向、运动模糊、反作用与余波 |
| 主观感更强 | 身体高度、观看范围、遮挡、运动和声场 | 角色不可能看见的信息、晕动与连续性 |
| 空间更压缩 | 摄影机退远后重构取景、选择背景层次 | 调度距离、遮挡和地理可读性 |
| 道具信息更清楚 | 尺寸、对比、焦点、光源反射和停留 | 文字方向、手部遮挡、前后镜归属 |

最终原则：先定义需要出现的可见结果，再依据真实设备、空间和动作选择参数。技术数字是测试所得的项目数据，不是情绪词典或跨场景标准。
