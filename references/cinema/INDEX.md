# 影视知识库索引

本索引只服务导演域：找戏点、设计镜头、调度表演、控制节奏、声音、动作和视觉。平台事实与最终提示词结构由独立编译域管理。

## 使用规则

每次包含新镜头设计、重设计或导演审阅的任务：

1. 先读本索引，把 Brief 归结为 1-3 个导演问题。
2. 从下方选择 1-3 个专项，实际读取与问题相关的完整章节；单一问题通常 1-2 个，跨域问题才扩到 2-3 个。
3. 再读 `../masters/INDEX.md`，选择并通读至少一部具体作品全文。
4. 把借鉴写成“具体方法 → 本场变形 → 镜头 ID”，而不是列阅读记录。

纯编译锁定 L1、只改语法或字段时跳过本库。

原理查询与执行细节按当前问题选择章节，不因知识库变厚就扩大默认读取量。下列专项在原正文后保留可落地展开；已有内容解决问题时无须重复读它们，涉及相应缺口时则实际读取，不只看表中摘要。

| 实际问题 | 同一知识文件内的细节入口 |
|---|---|
| 启步、停步、转身、坐起或协作动作像机械模型 | `角色调度与走位参考库.md` 第十二至十四节：身体阶段、支撑、双人关系与静息群像 |
| 前景只是装饰、暗示被抹掉、纵深层次无法想象 | `构图设计参考库.md` 第十三至十五节；`光影设计参考库.md` 第十三节 |
| 表演只剩标签、复合情绪乱跳、对话目光无落点 | `表演细节参考库.md` 第十节；`表演弧线与情绪阈值参考库.md` 第十节；`人物视线与目光设计参考库.md` 第十节 |
| 反打接不上、句中反应或移焦执行含混 | `镜头衔接与连续性参考库.md` 第十三节；`切镜时机学.md` 第十一节；`景深与焦点叙事决策库.md` 第十一节 |
| 复合运镜只有术语、机位缩写有歧义 | `超详细运镜规格参考库.md` 第十二节；`机位情绪决策参考库.md` 第十节 |
| 文戏缺少可演的行为、停顿缺少对象 | `文戏编排参考库.md` 第十二节；`潜台词与言外之意设计参考库.md` 第十一节；`静默时刻与留白设计参考库.md` 第九节 |
| 物理特效同质化、材质与声源缺少过程 | `物理交互与破坏效果参考库.md` 第十节；`特效真实感引擎.md` 第九节；`声音与音效叙事决策库.md` 第十一节 |

技术与因果的必要条件、已确认设计契约、审美经验的区别见 `分镜设计知识库_十三讲.md` 的“实作补充”。专项示范标为教学重建，不作为影片真实逐镜记录或平台保证。

## 快速任务路由

| 任务 | 建议起点 |
|---|---|
| 从剧本找重点、搭整段骨架 | `戏点选择与主镜框架法` + `分镜设计知识库_十三讲`，再按空间或节奏补一项 |
| 对白权力戏、暧昧、关系转折 | `文戏编排参考库` + `潜台词与言外之意设计参考库` + 表演/调度项 |
| 表演过满、情绪跳变、缺少反应 | `表演弧线与情绪阈值参考库` + `表演分寸场景映射库` + `表演细节参考库` |
| 活人感、视线关系、小动作、角色站桩 | `表演细节参考库` + `人物视线与目光设计参考库` + `角色调度与走位参考库` |
| 机位和运镜没有叙事动机 | `视点体系与镜头运动地基` + `机位情绪决策参考库` + 运镜/构图项 |
| 节奏拖沓、切点错误、长镜失焦 | `节奏与时长编排库` + `切镜时机学` + 连续性/蒙太奇项 |
| 镜头专业但平庸、缺招牌记忆点 | `创意镜头与记忆点设计库` + `反平庸案例库` + `大师层视觉语言` |
| 悬疑、恐怖、静默、信息遮蔽 | `类型片镜头语法库` + `声音与音效叙事决策库` + 光影/留白项 |
| 追逐、碰撞、武戏、超能力 | `动作设计与武指体系参考库` + `速度与力量量化标准` + 物理/特效项 |
| 多段人景漂移、方位或动作断裂 | `镜头衔接与连续性参考库` + `角色与场景设定参考库` + 调度/视点项 |

路由只是候选。导演任务至少实读一项，最终组合保持 1-3 项，并让每一项都改变一个具体导演决定。
