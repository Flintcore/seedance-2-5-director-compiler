# 表演分寸场景映射库

本库用于判断人物该把情绪放到多大、放在哪里，以及何时让克制转为爆发。分寸是戏剧关系，不是百分比：同一个动作在不同人物、类型和叙事阶段中会有不同强度。

## 一、五种表演状态

| 状态 | 外在特征 | 适用条件 | 主要风险 | 作品参照 |
|---|---|---|---|---|
| Deadpan | 语调平直、动作精确、人物严肃对待荒诞 | 风格化喜剧、制度荒诞、刻意疏离 | 离开风格语境后显得木讷 | 韦斯·安德森《布达佩斯大饭店》 |
| 极致内敛 | 情绪藏在视线、呼吸、停顿与细小接触里 | 尊严、秘密、临终、高手对峙、不可言说的关系 | 缺少可读变化时会失去戏 | 是枝裕和《小偷家族》、黑泽明《七武士》久藏 |
| 自然克制 | 清楚可读但不过度展示，身体与声音留有余地 | 日常文戏、家庭关系、告别、试探、暧昧、决断 | 把“克制”误写成完全静止 | 王家卫《花样年华》、科波拉《教父》 |
| 古典戏剧化 | 姿态、节奏和目光经过组织，关键点允许明确抬升 | 古典悬疑、史诗、仪式、类型高潮前的蓄势 | 与写实手持语法混用会失真 | 希区柯克《迷魂记》、斯皮尔伯格《拯救大兵瑞恩》 |
| 外放爆发 | 声音、身体和空间关系同时突破常态 | 恐惧突现、屠杀高潮、战场死亡、长期压抑后的释放 | 提前使用会透支高潮 | 《怪形》狗笼变身、《寄生虫》生日派对 |

默认从自然克制出发，再根据人物习惯、类型契约和本段转折调整。爆发必须有此前积累和此后余波；Deadpan 必须由整部作品的喜剧语法支持。

## 二、三十类场景映射

### 文戏与关系

| 场景 | 建议状态 | 变化设计 | 参照 |
|---|---|---|---|
| 日常对话 | 自然克制 | 用做事、停顿和错位视线承载关系 | 《小偷家族》围桌 |
| 求助或恳求 | 自然克制 | 求助者控制体面，掌权者用等待掌握节奏 | 《教父》Bonasera 开场 |
| 告别或离别 | 极致内敛到自然克制 | 让未说出口的内容落在物件交换与离场路径 | 《花样年华》楼道、是枝海边戏 |
| 谎言或隐瞒 | 极致内敛 | 说谎者管理视线和手部，被骗者延迟反应 | 《迷魂记》Madeleine 的表演层次 |
| 表白或暧昧 | 自然克制 | 接近与撤回交替，避免一次性交代情绪 | 《花样年华》 |
| 决断或顿悟 | 极致内敛 | 决定发生在一句话之前，动作结果发生在之后 | 《教父》餐厅戏 |
| 克制死亡 | 极致内敛 | 生命迹象逐步减少，旁观者先失语再行动 | 《人类之子》Julian 中弹后的凝视 |
| 爆发死亡 | 古典戏剧化到外放爆发 | 只在类型和叙事峰值允许，随后迅速抽空 | 《拯救大兵瑞恩》关键死亡 |
| 怀旧或思念 | 极致内敛 | 当前动作与记忆痕迹并置，不靠说明性台词 | 《花样年华》 |
| 师徒关系 | 自然克制 | 权力通过示范、纠正和沉默交接 | 《七武士》 |
| 家庭日常 | 自然克制 | 多人行为重叠，矛盾藏在生活流程中 | 《小偷家族》 |
| 浪漫亲密 | 极致内敛到自然克制 | 距离、触碰许可和呼吸节奏比宣言更重要 | 王家卫、是枝裕和 |

### 动作与冲突

| 场景 | 建议状态 | 变化设计 | 参照 |
|---|---|---|---|
| 高手对峙 | 极致内敛 | 减少预备动作，让判断和重心变化成为威胁 | 《七武士》久藏对决 |
| 一击决胜 | 内敛蓄势后瞬时爆发 | 爆发短，结果和恢复长 | 《七武士》久藏一招制敌 |
| 群体混战 | 多档并置 | 主线人物保持清楚，群体恐慌形成压力背景 | 《七武士》雨战 |
| 静态威慑 | 极致内敛 | 用占位、朝向、武器线和环境运动增加压力 | 黑泽明的风与尘 |
| 初次施暴 | 自然克制转僵硬 | 技术不熟练、动作有迟疑，结果让人物改变 | 《教父》Michael 第一次开枪 |

### 类型片

| 场景 | 建议状态 | 变化设计 | 参照 |
|---|---|---|---|
| 怪物突现 | 外放爆发 | 安静基线被一次不可逆事件打破 | 《怪形》狗笼变身 |
| 恐怖蓄势 | 极致内敛 | 人物努力维持常态，异常从边缘渗入 | 《怪形》南极基地 |
| 跟踪 | 古典戏剧化或自然克制 | 跟随者控制身体，被跟者的微小偏航制造疑问 | 《迷魂记》跟踪段 |
| 心理崩塌 | 古典戏剧化到爆发 | 摄影机和表演共同越过稳定阈值 | 《迷魂记》钟楼 |
| 战场常态 | 自然克制 | 专注任务和生存，反应被环境压力压缩 | 《人类之子》战场长镜 |
| 战场突变 | 爆发后失神 | 先处理冲击，再让听觉和动作恢复 | 《拯救大兵瑞恩》 |
| 末日或反乌托邦 | 自然克制 | 人物已习惯异常世界，真正私密事件才撬动情绪 | 《人类之子》 |
| 黑色喜剧升级 | 克制到戏剧化再到爆发 | 每次升级都改变权力关系，不只增加音量 | 《寄生虫》 |
| 风格化喜剧 | Deadpan | 人物守规则，构图和事件制造笑点 | 《布达佩斯大饭店》 |
| 第一人称灾难 | 不整齐的真实反应 | 呼吸、失焦、犹豫和错误判断保留业余性 | 《科洛弗档案》 |
| 宇宙庄严 | 极致内敛 | 人物让位于尺度、时间和声音 | 《2001：太空漫游》 |
| 非线性母性 | 自然克制 | 情绪由跨时信息重组，而非当场宣告 | 《降临》 |
| 权力交接 | 自然克制到古典戏剧化 | 通过空间中心、等待和仪式动作完成地位转移 | 《教父》 |

## 三、可读情绪的五个载体

1. **面部渐变**：视线落点、眨眼节奏、下颌、鼻翼、嘴角和吞咽依次变化。避免把多个夸张信号挤在同一瞬间。
2. **身体阻力**：动作是否被人物压住、延迟或做到一半。重心变化通常比挥手更有信息。
3. **声音控制**：音量只是变量之一；语速、断句、气息、重音和句尾处理更能体现关系。
4. **沉默与反应**：给人物接收信息的时间。反应可以先发生在呼吸和视线，再发生在动作。
5. **物件接触**：握紧、放下、擦拭、整理、递交或拒收，使抽象情绪产生物理结果。

五个载体不需同时出现。选择最贴合人物习惯和景别的两三个，并让它们沿时间发生变化。

## 四、分寸转档的因果

表演状态变化应回答四个问题：

- 什么新信息或行动触发变化？
- 人物先试图压住什么？
- 哪个可见信号最先泄露变化？
- 转档之后，人物与空间或他人的关系发生了什么不可逆改变？

常见有效弧线：

- 内敛蓄势 -> 短促爆发 -> 动作余波；
- 自然克制 -> 被迫恢复礼貌 -> 私下失控；
- Deadpan 常态 -> 一个极小破绽 -> 迅速复位；
- 群体外放 -> 主角突然安静，形成注意力反差。

## 五、常见错配与修正

| 错配 | 后果 | 修正方向 |
|---|---|---|
| 日常对话持续瞪眼、挥臂、抬高音量 | 关系缺少层次 | 把冲突移到停顿、视线和手边任务 |
| 求助者从开场就崩溃 | 权力差无处升级 | 先维持体面，让失败逐步侵蚀控制 |
| 告别用长篇解释完成 | 余韵被说尽 | 让离场、未完成动作或物件承载结尾 |
| 决断与宣言同时发生 | 观众只听见结论 | 先拍决定形成，再让语言确认结果 |
| 高手对决持续大动作 | 技术和危险感下降 | 缩短准备，强调距离、重心和一次有效接触 |
| “克制”被执行为完全不动 | 情绪不可读 | 设计细微但方向明确的连续变化 |
| 每个角色以相同强度反应 | 群像扁平 | 按目标、信息量和社会身份分配不同反应 |

## 六、与其他知识库协同

- 潜台词与言外之意：决定人物为何压住或转移表达。
- 人物视线与目光：决定关系焦点和信息差。
- 表演细节：提供可见的微动作选项。
- 静默与留白：决定反应何时有空间发生。
- 文戏编排：决定表演变化在段落中的位置。
- 动作设计：决定爆发之后的受力、惯性与恢复；表演库只负责动作的情绪意义。

实际设计时需回到所选大师作品的具体场景，提取关系机制，再针对本场人物、空间和类型做变形。
