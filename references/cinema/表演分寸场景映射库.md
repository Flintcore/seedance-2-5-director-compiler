# 表演分寸场景映射库

本库用于比较人物的表演能量、表达通道和策略如何适配当前关系。角色行为已清楚、分寸仍有疑难时取相关章节；先沿人物目标与对手接收选择做法，再选择幅度。细微、直接、热烈、冷面与爆发皆可成立，大小、速度、音量与静默比例本身不决定优劣。

## 一、五种表演状态

| 状态 | 外在特征 | 适用条件 | 主要风险 | 作品参照 |
|---|---|---|---|---|
| Deadpan | 表面平直、认真执行任务，微小差异仍承载接收 | 荒诞喜剧、疏离、防御、权力或不协调感 | 把冷面等同没有注意对象的木讷 | 韦斯·安德森《布达佩斯大饭店》 |
| 极致内敛 | 表达被抑制或延迟，目标、注意与行动仍持续 | 当前策略需要隐藏意图、保持礼仪或专注观察 | 按年龄、身份或高手标签自动选用 | 是枝裕和《小偷家族》、黑泽明《七武士》久藏 |
| 自然直接 | 根据处境行动、回应与调整，可安静也可轻快热烈 | 日常任务、亲密接续、坦率诉求或关系交锋 | 将自然缩成轻声、微笑和小动作 | 王家卫《花样年华》、科波拉《教父》 |
| 戏剧化表达 | 声音、姿态与节奏选择鲜明，仍有对象和行动逻辑 | 公开说服、仪式、争执、风格化喜剧或类型场面 | 每句都强调，或仅凭摄影风格判定不相容 | 希区柯克《迷魂记》、斯皮尔伯格《拯救大兵瑞恩》 |
| 外放爆发 | 某个或多个通道强烈变化，持续影响行动与关系 | 主动施压、狂喜、失控、压力突破、喜剧或动作能量 | 与对象和处境无关，或爆发后状态清零 | 《怪形》狗笼变身、《寄生虫》生日派对 |

状态不是质量等级或默认档。根据已有处境、人物习惯、目标与类型语体选择；段落可以从强烈状态直接开始，接住已存在的压力而非另造前置蓄势。冷面也可用于非喜剧场面。作品参照是原库的检索线索，借鉴具体关系机制，不据片名把整场分档。

## 二、三十类场景映射

### 文戏与关系

| 场景 | 分寸的选择依据 | 变化设计 | 参照 |
|---|---|---|---|
| 日常对话 | 诉求、任务与关系可支持安静或热烈 | 从说话、做事和对方接续中读到关系，不预设慢聊 | 《小偷家族》围桌 |
| 求助或恳求 | 体面、交易、直接请求或哭求各有筹码 | 看求助方式如何影响对手，不以哭泣本身判错 | 《教父》Bonasera 开场 |
| 告别或离别 | 坦率表达、挽留、催促离开或掩饰留恋 | 物件交接、原对白与离场路径共同承载接收 | 《花样年华》楼道、是枝海边戏 |
| 谎言或隐瞒 | 收敛、过分热情、抢先解释或执行可信任务 | 让说法、行为和听者判断形成关系，不固定躲眼或泄密 | 《迷魂记》Madeleine 的表演层次 |
| 表白或暧昧 | 明确邀请、玩笑掩护或试探边界 | 根据对方接收继续、接近或撤回，不统一吞吐低语 | 《花样年华》 |
| 决断或顿悟 | 行动发起、终止、转向或公开宣告 | 思考与说话、动作可以同步，重点是选择怎样影响后续 | 《教父》餐厅戏 |
| 克制死亡 | 极致内敛 | 生命迹象逐步减少，旁观者先失语再行动 | 《人类之子》Julian 中弹后的凝视 |
| 爆发死亡 | 救助、否认、愤怒或悲痛的对象与身体条件 | 强烈反应有实际作用与余态，群体不必同步 | 《拯救大兵瑞恩》关键死亡 |
| 怀旧或思念 | 回忆怎样干扰当前注意、任务和关系 | 可轻快复述或突然失措，静默与慢速不自动等于回忆 | 《花样年华》 |
| 师徒关系 | 指导、挑战、维护权威或给予自主 | 示范、纠正、接话或沉默按双方既有习惯选择 | 《七武士》 |
| 家庭日常 | 各自任务、习惯与当前接收 | 多人行为可重叠、插话或争执，不将亲属身份等同温柔 | 《小偷家族》 |
| 浪漫亲密 | 信任、游戏、照料或直接欲求 | 身体和语言可自然同步，含蓄与坦率均有作用 | 王家卫、是枝裕和 |

### 动作与冲突

| 场景 | 分寸的选择依据 | 变化设计 | 参照 |
|---|---|---|---|
| 高手对峙 | 战术、距离、身体能力和动作风格 | 专注可与大幅快速身法同在，不把高手等同少动慢打 | 《七武士》久藏对决 |
| 一击决胜 | 突发或蓄势按已有局势选择 | 接触、结果和余势按戏点分配时长，不固定长恢复 | 《七武士》久藏一招制敌 |
| 群体混战 | 多档并置 | 主线人物保持清楚，群体恐慌形成压力背景 | 《七武士》雨战 |
| 静态威慑 | 极致内敛 | 用占位、朝向、武器线和环境运动增加压力 | 黑泽明的风与尘 |
| 初次施暴 | 熟练度、压力与既有选择 | 迟疑、冒进或过度集中按处境发生，结果影响下一行动 | 《教父》Michael 第一次开枪 |

### 类型片

| 场景 | 分寸的选择依据 | 变化设计 | 参照 |
|---|---|---|---|
| 怪物突现 | 威胁、经验与现场任务 | 惊叫、僵住、迎击或回避分别有对象，避免齐刷刷反应 | 《怪形》狗笼变身 |
| 恐怖蓄势 | 持续日常、调查或假装镇定 | 观众可比人物先知，人物能量不由气氛词自动决定 | 《怪形》南极基地 |
| 跟踪 | 古典戏剧化或自然克制 | 跟随者控制身体，被跟者的微小偏航制造疑问 | 《迷魂记》跟踪段 |
| 心理崩塌 | 当前感知、身体与应对失效 | 摄影变化与表演可强化或对照，不自动配同幅表情 | 《迷魂记》钟楼 |
| 战场常态 | 任务、生存压力与经验 | 低外显或直接喊令均可，判断与行动可重叠 | 《人类之子》战场长镜 |
| 战场突变 | 冲击、命令、呼救与救援的差别 | 按身体条件持续应对，失神不是必经阶段 | 《拯救大兵瑞恩》 |
| 末日或反乌托邦 | 生存经验和当前具体关系 | 麻木、幽默与热烈都可存在，不以世界类型统一压低表达 | 《人类之子》 |
| 黑色喜剧升级 | 克制到戏剧化再到爆发 | 每次升级都改变权力关系，不只增加音量 | 《寄生虫》 |
| 风格化喜剧 | Deadpan | 人物守规则，构图和事件制造笑点 | 《布达佩斯大饭店》 |
| 第一人称灾难 | 不整齐的真实反应 | 呼吸、失焦、犹豫和错误判断保留业余性 | 《科洛弗档案》 |
| 宇宙庄严 | 极致内敛 | 人物让位于尺度、时间和声音 | 《2001：太空漫游》 |
| 非线性母性 | 自然克制 | 情绪由跨时信息重组，而非当场宣告 | 《降临》 |
| 权力交接 | 自然克制到古典戏剧化 | 通过空间中心、等待和仪式动作完成地位转移 | 《教父》 |

## 三、可读情绪的五个载体

1. **面部与注意**：视线、眼睑、下颌等通道随当前任务与接收变化，可同时或先后发生；不以部位数量衡量层次。
2. **身体行动**：人物推动、维持、压住或终止什么；重心、幅度与速度服从任务和身体条件。
3. **声音行动**：音量、起音、语速、气息、重音和轮次怎样影响听者，而非单纯更轻或更响。
4. **接收与反应**：理解可以发生在继续做事、回应或发声期间，停顿与沉默按实际作用选择。
5. **物件接触**：握紧、放下、擦拭、整理、递交或拒收，使抽象情绪产生物理结果。

先确定本拍最重要的作用与对手回应，再选择摄影机读得到的载体。必要信号充分即可，背景行为保持自然持续，不按载体数量、幅度或静默比例填满时间。

## 四、分寸转档的因果

表演状态变化应回答四个问题：

- 什么新信息或行动触发变化？
- 人物继续、改变或放弃哪种策略？也可直接表达而无需压住。
- 哪个可见/可听变化让观众理解应对，或怎样有意保留内心？
- 新状态如何影响随后行动与关系？不要求每次都产生不可逆转折。

常见有效弧线：

- 内敛蓄势 -> 短促爆发 -> 动作余波；
- 自然克制 -> 被迫恢复礼貌 -> 私下失控；
- Deadpan 常态 -> 一个极小破绽 -> 迅速复位；
- 群体外放 -> 主角突然安静，形成注意力反差。

同样可采用公开催促中即时接收反驳、真诚信任中的迅速接续，或兴奋状态里持续完成任务。上述是不同机制的候选，不是所有场景先压抑再释放的路线。

## 五、常见错配与修正

| 错配 | 后果 | 修正方向 |
|---|---|---|
| 对白强度反复增加却不回应对手 | 策略与接收缺少变化 | 调整说话行动及回应；有对象的直接、热烈表达照留 |
| 开场崩溃没有已有处境或身体依据 | 表现与当前事实脱节 | 接上已知压力与诉求；依据充分时直接进入强烈状态 |
| 告别只有说明而无人接收 | 行动与关系缺少后果 | 保留原对白，让交接、离场与回应承担实际作用 |
| 宣言没有影响正在做的事或对手 | 选择只剩标签 | 将既定语言与行动及接收连起来，先后或同步按设计 |
| 高手大动作没有距离、支撑或攻防后果 | 只剩摆姿与幅度 | 补足路线、接触与接续；小幅或大幅由类型与战术决定 |
| “克制”被执行为完全不动 | 情绪不可读 | 设计细微但方向明确的连续变化 |
| 每个角色以相同强度反应 | 群像扁平 | 按目标、信息量和社会身份分配不同反应 |

## 六、与其他知识库协同

- 潜台词与言外之意：决定人物公开表达、转移或隐藏什么，以及怎样影响对手。
- 人物视线与目光：决定关系焦点和信息差。
- 表演细节：提供可见的微动作选项。
- 静默与留白：决定反应何时有空间发生。
- 文戏编排：决定表演变化在段落中的位置。
- 动作设计：决定爆发之后的受力、惯性与恢复；表演库只负责动作的情绪意义。

实际设计时需回到所选大师作品的具体场景，提取关系机制，再针对本场人物、空间和类型做变形。
