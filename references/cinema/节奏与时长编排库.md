# 节奏与时长编排库

节奏来自观众处理信息、等待结果和承受情绪的方式，不等于镜头越短越有力。镜长、镜内变化、切点、表演停顿、动作速度和声音密度共同组成段落曲线。

## 一、镜长的叙事含义

| 镜长倾向 | 观众体验 | 适用设计 | 风险 |
|---|---|---|---|
| 瞬时镜头 | 冲击、断裂、只来得及抓住一个特征 | 惊吓、碰撞、主观碎片、快速联想 | 信息尚未辨认就被切走 |
| 短镜头 | 推进、压迫、选择变少 | 追逐、争执、步骤清晰的动作链 | 每镜功能相同会机械 |
| 中等镜长 | 信息与反应均衡 | 常规叙事、空间建立、对话推进 | 景别和切点无变化时趋平 |
| 长镜头 | 持续、观察、等待、空间因果 | 调度、表演、悬念、沉浸、不可中断事件 | 镜内关系不变会停滞 |
| 极长镜头 | 仪式、真实时间、道德凝视 | 慢电影、持续困境、复杂空间行动 | 只为炫技会抢走戏剧焦点 |

数值只在对具体成片、素材或动作速度进行测量时使用。创作先判断观众需要多久看懂、多久开始不安，以及等待本身是否有意义。

## 二、四种段落曲线

### R1 渐密

镜头或镜内事件逐步缩短间隔，适合逼近、暴露和控制权收紧。每次加速都应由新阻力或新信息触发。

### R2 渐疏

高潮后延长停顿和镜长，适合后果、哀悼、震惊与重新理解。画面减少事件，但关系或状态仍持续变化。

### R3 松紧交替

较长观察与较短冲击交替，适合悬疑、恐怖、谈判和追逐。对比让观众在预期与意外之间摆动。

### R4 断崖变化

在一个明确节点从密集骤然转为持续，或从稳定骤然碎裂。适合不可逆转折。突变之前必须建立足够清楚的节奏基线。

## 三、类型基线

类型提供起点，不提供镜数配额：

| 类型或场景 | 常见节奏重心 | 何时偏离 |
|---|---|---|
| 动作 | 因果清楚、方向可读、冲击后有恢复 | 为展示技术、空间或重大后果而延长 |
| 悬疑 | 延迟答案，交替给予线索和反应 | 真相出现时突然压缩或拉长 |
| 恐怖 | 稳定基线、等待、异常的间隔 | 威胁突现后用碎裂或主观持续 |
| 喜剧 | 建立、预期、偏差、反应的精确间隔 | 尴尬喜剧常把反应拖长 |
| 家庭文戏 | 允许重叠行为和未说完的话 | 权力翻转时收紧切换 |
| 浪漫 | 接近、撤回、凝视和环境余韵 | 错失或确认时改变既有呼吸 |
| 广告或展示 | 信息层级清楚，关键形象获得停留 | 情绪故事可减少展示切换 |
| 史诗 | 尺度建立与人物反应互相校正 | 危机内部可临时压缩 |
| 慢电影 | 持续观察、环境时间和细微变化 | 微小事件因稀缺而成为节奏峰值 |
| 纪录感 | 服从事件发生与观察位置 | 证据或伦理焦点出现时改变距离 |

## 四、剪辑承载与镜内承载

同一段叙事信息可以通过两条路径交付：

- **剪辑承载**：每个镜头交付一个清楚变化，靠镜头关系推进。
- **镜内承载**：通过人物调度、摄影机运动、移焦、遮挡揭示、光线变化和声场变化，在持续镜头中推进。

选择依据：

1. 戏剧是否依赖真实时间连续；
2. 空间关系是否需要观众自行观察；
3. 反应与动作是否必须同框；
4. 切换是否增加新视点或只是在掩盖镜内空洞；
5. 摄影机运动是否有明确起因、路径和终点。

长镜头不是静止镜头。人物目标、关系、构图压力或声音焦点必须持续变化。固定镜头也可以依靠表演和环境运动成立。

## 五、切点判断

切点优先落在以下位置：

- 新信息刚被观众识别之后；
- 人物决定已形成、行动尚未完成之时；
- 视线或动作给下一镜提供方向；
- 权力关系翻转；
- 声音提出下一空间或下一事件；
- 观众预期已建立，切换可以制造偏差；
- 保持当前镜头会比切换更有压力时，选择不切。

每次切换需至少改变视点、信息、距离、时间或情绪关系之一。若只是换角度重复同一内容，优先保留原镜或重新设计调度。

## 六、停顿与留白

停顿的价值取决于其前后的状态差：

- 信息落地后，让听者完成接收；
- 行动前，让观众预见代价；
- 冲击后，让身体和空间显露后果；
- 告别后，让空位成为新的构图事实；
- 喜剧偏差后，让人物反应完成笑点；
- 恐怖揭示前，让环境基线暴露异常。

停顿内仍应有可观察内容，例如呼吸改变、视线转移、远处声音、未完成动作或空间压力。纯粹把时长拉长不会自动产生留白。

## 七、声音与节拍

节奏可以由配乐、画内音乐、脚步、呼吸、滴答、机器循环、对白断句或静默组织。音乐是否使用由项目决定。

- 同步切点强调确定、力量或喜剧精度；
- 刻意错拍制造不安、笨拙或失控；
- 声音先于动作建立期待；
- 动作先于声音可制造主观冲击或距离感；
- 重复节拍中的一次缺席往往比持续加密更醒目。

## 八、分段生成中的节奏

分段边界首先是戏剧和连续性问题：

- 每段只承担一个主要变化；
- 段尾选择可复现的构图、姿态、动量和声源状态；
- 下一段开头复现该状态后再继续推进；
- 不把动作接触、台词落点或关键反应截断在不清楚的相位；
- 需要跳时或跳空时明确把断裂作为设计，而非伪装成连续。

平台允许的单段时长不在本库规定；影视库不据此推导镜数。

## 九、Cut Test

对每个镜头问：

1. 观众在何时拿到本镜唯一的新东西？
2. 早一点切会丢失什么？
3. 晚一点切会新增压力、余韵或理解，还是只增加等待？
4. 留在同一镜头能否通过调度或声音继续变化？
5. 下一镜为何必须从那个视点开始？

若前后两个镜头可互换且意义不变，节奏结构通常尚未建立。

## 十、常见失败

| 失败 | 表现 | 修正 |
|---|---|---|
| 用镜数下限替代节奏 | 每段被均匀切碎 | 回到戏点和观众处理时间 |
| 静止就强行加运镜 | 摄影机抢戏 | 给静止明确的构图或表演理由 |
| 长对白一律切反应 | 对话变成机械乒乓 | 让权力变化决定是否切、切给谁 |
| 动作只追求快 | 方向、接触和结果读不清 | 在关键准备、接触或恢复处给足可读时间 |
| 全段持续加速 | 失去对比 | 插入释放、延迟或一次持续观察 |
| 段尾随机停止 | 下一段状态难复现 | 把边界落在清楚的动作相位和构图状态 |

## 十一、协同入口

- 切镜时机学：精确判断单个切点。
- 静默时刻与留白设计：设计停顿内部内容。
- 信息控制：判断新信息是否真的推进当前问题。
- 动作设计：用因果、接触、惯性和恢复决定动作节奏。
- 声音叙事：用声场变化连接或打断画面节奏。
