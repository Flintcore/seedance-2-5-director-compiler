# 声音与音效叙事决策库

声音设计先决定观众听见谁的世界，再决定使用环境、动作、人声、音乐或静默。音乐政策由用户和项目决定；物理声源、同期声与配乐都是可选材料，不存在跨项目的全局禁令。

## 一、声音的六种叙事功能

| 功能 | 设计问题 | 常用手段 | 例子 |
|---|---|---|---|
| 空间定位 | 声源在哪里，距离与遮挡如何 | 方位、混响、直达声、墙体滤波 | 门外脚步先建立走廊深度 |
| 时间组织 | 场景从何时开始、何时结束 | 声音桥、持续声、突停、节拍变化 | 列车声跨切到下一地点 |
| 信息差 | 谁先听见，谁尚未知道 | 画外声、延迟显源、主观过滤 | 观众先听到地下室异响 |
| 情绪压力 | 什么声音让人物无法保持常态 | 低频、重复声、逼近声、过度清晰的细声 | 钟表声在等待中逐渐凸显 |
| 动作证据 | 接触是否有材质、重量和距离 | 起音、冲击、摩擦、余振、空间回声 | 金属撞击后护栏持续颤鸣 |
| 主题记忆 | 什么声音可跨场景改变含义 | 声音母题、同声异义、缺席 | 童谣先温暖，后变成威胁 |

声音无需重复画面。画面已经说明动作时，声音可补空间、主观感受、画外因果或情绪反差。

## 二、意图到声音策略

| 戏剧意图 | 声音策略 | 避免 |
|---|---|---|
| 亲密 | 缩近呼吸、衣料和轻微接触，压低远处环境 | 把所有细节等量放大 |
| 孤独 | 让人物声源小而空间尾音长 | 用连续情绪提示代替空间 |
| 悬念 | 先建立稳定底噪，再让一个声源偏离常态 | 每秒添加新异响 |
| 恐惧 | 延迟显源，利用遮挡和主观听觉收窄 | 威胁一出现便铺满所有频段 |
| 权力 | 掌权者占据清晰、稳定、近距离的声场 | 仅靠提高音量表示地位 |
| 羞耻 | 放大近距离身体声，压低公共空间 | 用解释性对白说出感受 |
| 失控 | 有意破坏此前节奏与声场边界 | 从开场就保持最大强度 |
| 庄严 | 留出动态余量，让单一声源拥有完整衰减 | 堆叠过多同时竞争的声音 |
| 黑色幽默 | 正经声场与荒诞事件保持距离 | 用笑声或夸张提示替观众判断 |

## 三、客观声与主观声

**客观声**保持空间可定位性，适合建立环境、连续动作和多人关系。
**主观声**服从某个人物的身体与注意力，常见变化包括高低频滤波、耳鸣、呼吸前置、远声衰减、时间拉伸和瞬时静默。

切换主观声必须有视点依据：

1. 先让观众知道当前听觉主体；
2. 用一次事件触发听觉改变；
3. 主观处理持续服务人物状态；
4. 回到客观声时给出可感知的恢复点。

爆炸后的耳鸣、潜水中的低通和惊恐时的近距呼吸都只是手段。若人物并未进入相应身体状态，则不应套用。

## 四、动态曲线与节奏

先建立声音基线，再设计偏离：

- **渐强**适合逼近、聚集和不可逆压力；
- **骤停**适合失去、发现和注意力重置；
- **密到疏**让动作结束后留下心理余波；
- **疏到密**让多个因果逐渐汇合；
- **稳定重复后错拍**适合制造预感；
- **先声后画**适合提前抛出问题；
- **画先声后**适合让结果晚一步击中观众。

动态变化以可辨的戏剧节点为依据。不要为了“丰富”而让所有声源持续运动。

## 五、拟音与材质

同一动作可因材质和演奏方式产生不同情绪：

| 动作 | 脆弱 | 威胁 | 克制 | 荒诞 |
|---|---|---|---|---|
| 放杯 | 瓷沿轻碰、短促余振 | 重落、桌面低频共鸣 | 杯底缓慢摩擦后停 | 过分精确的清脆一声 |
| 关门 | 门锁未完全咬合 | 门框震动、金属回弹 | 手扶门页缓慢闭合 | 轻巧关门后物件连续掉落 |
| 脚步 | 不均匀、犹豫、鞋底拖擦 | 稳定逼近、低频清楚 | 停顿多于步数 | 与庄重空间不协调的轻快鞋声 |
| 呼吸 | 吸气失败、气息短 | 近距稳定、压迫他人 | 有意压住吐气 | 事件再荒谬也保持平直 |

动作声至少明确声源、材质、接触方式与余振。重击的重量不仅来自起音，还来自受体、环境和随后短暂的听觉空洞。

## 六、对白、画外声与音乐

- 对白的清晰度服从戏剧关系：秘密、距离和遮挡可以改变质感，但逐字内容仍需可辨时应优先保证。
- 画外人物必须有明确空间来源；镜外声音不自动绑定画内口型。
- 环境人声需要说明是可辨台词、含混群声还是纯氛围。
- 音乐若由项目确定，要说明来源、进入点、退出点、与动作或画面的关系。
- 画内音乐可同时承担空间道具和节拍；画外配乐可承担结构与主题。两者切换要明确。
- 不使用音乐也应是场景判断，例如《老无所依》以环境和动作声维持道德冷感，而非通用规则。

## 七、声音桥

| 类型 | 用途 | 判断 |
|---|---|---|
| J-cut | 下一场声音提前进入 | 先改变观众预期，再改变画面 |
| L-cut | 上一场声音延续 | 让情绪、信息或因果跨过切点 |
| Match sound | 相似声音连接异地或异时 | 两个声音需有主题或动作关系 |
| Hard cut to silence | 强制注意力重置 | 前后动态差必须有戏剧理由 |
| Continuous ambience | 维持同一空间 | 环境条件、距离和声场方向要连续 |

## 八、大师锚点

- 科波拉《教父》：办公室外婚礼与室内低声谈判形成权力和空间对照。
- 科恩兄弟《老无所依》：稀少配乐让风、脚步、机械和远处声源承担悬念。
- 库布里克《2001：太空漫游》：呼吸、机械循环与音乐并置，分别承担身体、系统和宇宙尺度。
- 科波拉《现代启示录》：主观声、直升机旋翼和音乐互相转化，连接心理与战争机器。
- 大卫·林奇：电流、低频和不明机械声让日常空间出现潜意识裂缝。
- 阿方索·卡隆《人类之子》：长镜内的环境声与画外威胁维持空间连续和信息层级。
- 王家卫《花样年华》：歌曲、环境声与重复动作共同形成记忆结构。

使用锚点前需读取对应作品正文，提取其声音机制并针对本场改造，而非复制声音清单。

## 九、常见失败

| 失败 | 原因 | 修正 |
|---|---|---|
| 所有声源同样响、同样近 | 空间层级消失 | 设前中后景与遮挡 |
| 画面发生什么，声音只重复什么 | 信息浪费 | 让声音补画外、主观或后果 |
| 每个情绪点都加音乐 | 观众判断被代替 | 选择少数结构节点，保留动态余量 |
| 重击只有一声“砰” | 缺少材质和惯性 | 补受体、环境反馈和余振 |
| 画外台词没有声源 | 口型与身份易混 | 明确角色、位置、时间和是否画外 |
| 连续段环境声突然重置 | 空间或时间穿帮 | 把尾声状态交给下一段 |
| 声音一直渐强 | 曲线失去对比 | 在转折后释放、抽空或换主导声源 |

## 十、协同入口

- 镜头衔接与连续性：处理跨切声音状态。
- 动作设计：提供接触点、材质、受力和余振。
- 静默与留白：判断何时降低或撤掉声源。
- 文戏编排：绑定对白、听者反应和潜台词。
- 类型片镜头语法：校准类型的声音契约。
