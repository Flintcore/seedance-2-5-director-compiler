# 构图设计参考库

构图决定观众先看什么、人物与空间是什么关系，以及画面在变化前后如何重新获得平衡。规则只是起点；真正的选择来自戏剧中心、观看距离、运动方向和即将发生的变化。

## 一、构图前的四个问题

1. 当前唯一视觉中心是什么？
2. 画面中哪些信息必须同时可见，哪些可以延迟？
3. 人物受到哪一种空间力量：边界、空白、另一人物、物件或运动方向？
4. 镜头结束时构图会因什么动作或理解改变？

如果所有元素权重相同，观众不知道该看哪里。

## 二、视觉权重

视觉权重来自：

- 明暗与色彩对比；
- 面孔、眼睛和人体方向；
- 运动与突然静止；
- 尺寸、锐度和离摄影机距离；
- 画框边缘、透视线和重复图形；
- 叙事上已被建立的重要物件。

让主要权重服务当前戏点。次要信息可以通过暗部、虚化、遮挡或位置退后，但仍需在回收时有机会被看见。

## 三、平衡与不平衡

### 平衡

对称、三角、居中和左右呼应可表达秩序、平等、仪式、封闭或被控制。平衡不自动等于和谐；过度稳定也能制造不安。

### 不平衡

人物偏置、重量集中在一侧、视线空间不足或空白压迫可表达等待、威胁、排斥和关系倾斜。不平衡应指向戏剧问题，而不是随意把主体贴边。

### 破坏与恢复

最有意义的是平衡发生变化：新人入画打破对称，人物离开留下空位，物件被移走改变重心，或摄影机重构后形成新的关系。

## 四、常用组织方式

### 4.1 三分关系

三分位置提供稳定但不僵硬的起点。人物朝向一侧时通常保留视线空间；故意压缩视线空间可表现受阻、回避或危险逼近。

### 4.2 居中与对称

适合权力、仪式、机械秩序、喜剧精确和角色被系统吞没。轻微偏离、背景异常或人物动作不同步能让秩序出现裂缝。

### 4.3 对角线与三角

对角线支持运动、冲突和不稳定；三角构图适合三人权力关系、秘密联盟与视线接力。三角顶点和距离变化可显示谁掌握场面。

### 4.4 框中框

门、窗、镜、栏杆、家具和人群形成第二边界。它可以隔离、窥视、保护或压迫。边界应来自真实空间，并影响人物行动或可见性。

### 4.5 负空间

空白可等待某人进入、承载缺席、显示人物渺小或让威胁保持不可见。空白需要方向与期待；没有潜在信息的空白只是浪费。

### 4.6 反射与多平面

镜面、玻璃、水面和屏幕可让不同空间、身份或时间同框。先决定哪一层是主信息，并避免叠影破坏人物和动作可读性。

## 五、纵深

前、中、后景不是装饰层，而是注意力和行动层：

- 前景遮挡制造窥视、接近或空间真实；
- 中景承载主要人物和行动；
- 后景可提供威胁、反应、伏笔或世界运行。

人物跨层移动时，构图应重新组织视觉中心。深焦适合同时比较多层关系，浅焦适合暂时限制认知。

## 六、人物构图

### 单人

决定头顶空间、视线空间、身体是否完整、环境保留多少。近景强调控制细节，全身景强调姿态和空间选择，远景强调人物被世界包围或支配。

### 双人

双人镜能显示距离、共同物件、谁占中心和谁更接近出口。过肩镜应保留前景人物的存在价值，而非只做模糊边框。

### 三人及群像

按当前关系组织层级，而不是平均排队。让不同人物拥有不同动作、视线和景深位置。联盟、排斥和权力改变时，队形随之改变。

### 缺位

空椅、空床、未使用的餐具或画面中刻意保留的位置，可以让不在场人物支配关系。缺位必须被在场人物的行为确认。

## 七、物件构图

物件只有在影响行动、归属或理解时成为视觉中心。常用关系：

- 人物与物件同框，显示谁拥有或无法触及；
- 物件位于两人之间，成为关系边界；
- 先建立物件在背景，后通过动作或焦点改变权重；
- 物件离开原位置后留下空痕，确认不可逆变化；
- 手部与物件的接触细节用于交接、拒绝或损坏。

避免无动机的产品式孤立特写。

## 八、运动中的构图

动态构图需要稳定参照和变化目标：

- 人物进入时给出可预期的运动空间；
- 摄影机跟随时决定主体在画面中的稳定程度；
- 突然停下、改变方向或被遮挡可触发重新构图；
- 环绕会改变背景与权力关系，需保持轴线可读；
- 长镜头内部通过人物入画、出画、移焦和重心转移形成构图段落。

不要为了保持“漂亮画面”而阻止人物完成真实动作。

## 九、画幅与边界

- 宽画幅适合横向关系、景观和多人调度，也会让孤立人物周围的空白更强。
- 较窄画幅强化垂直身体、门窗和压迫感，也限制横向逃生空间。
- 头顶、脚下和运动方向的余量由动作决定，不用固定百分比。
- 有意截断身体可以制造逼近与不完整感，但关键动作部位必须可读。
- 画框外空间通过视线、声音和进入方向继续存在。

## 十、心理构图与类型

| 戏剧需求 | 构图倾向 | 风险 |
|---|---|---|
| 权力稳定 | 居中、对称、低位结构 | 变成空洞威严 |
| 关系疏离 | 障碍、分层、负空间 | 人物反应不可读 |
| 亲密形成 | 共享画面、距离缩短、共同物件 | 过早浪漫化 |
| 威胁未知 | 离画空间、遮挡、背景层 | 信息隐藏过头 |
| 群体压力 | 重复图形、长焦压缩、多层视线 | 群像同质化 |
| 主观失衡 | 倾斜、边缘、反射错位 | 形式抢戏 |
| 日常真实 | 功能性空间、自然遮挡、开放构图 | 缺少视觉中心 |

类型提供倾向，不替代当前场景判断。

## 十一、作品锚点

- 《东京物语》：低位固定构图让日常空间与人物礼节共同发声。
- 《花样年华》：门框、走廊和前景遮挡把关系压入有限空间。
- 《寄生虫》：高度、楼梯、窗和纵深把阶级关系变成空间结构。
- 《布达佩斯大饭店》：对称与正面调度建立秩序，也让秩序的破裂更明显。
- 《燃烧》：远景、空白和多层空间维持不确定性。
- 《教父》：人物在暗部、门框和群体构图中的位置显示权力转移。

## 十二、常见失效

| 失效 | 根因 | 修正 |
|---|---|---|
| 每镜都按同一构图公式 | 把规则当风格 | 让关系和动作触发构图变化 |
| 每场都追求壁纸画面 | 美感与戏剧脱节 | 把视觉权重还给戏点和表演 |
| 群像动作整齐一致 | 忽略独立目标 | 分配不同视线、任务和反应时机 |
| 遮挡成为默认装饰 | 没有观看动机 | 只在窥视、隔离、延迟揭示时使用 |
| 主体贴边却无压力 | 不平衡没有方向 | 让空白承载威胁、缺席或运动期待 |
| 构图漂亮但不能切 | 未考虑动作与连续性 | 预留出入画、视线和下一镜关系 |
| 环境层次抢过人物 | 所有元素同权 | 用光、焦点、运动和色彩重新排序 |

最终判断：构图是否让观众以正确顺序看见这场戏的关系变化。

## 十三、前景遮挡的六种具体用途

| 用途 | 物理实现 | 设计时真正要确定的关系 |
|---|---|---|
| 纵深分层 | 近处肩背、桌沿或植物与中远景发生视差 | 前景是什么、距镜头多近、是否需要清楚、它引导到谁 |
| 受限观看与亲密 | 门缝、窗纱、玻璃或人群之间的观看窗口 | 观众站在哪一侧，人物知道被看吗，窗口给了多少情感接近 |
| 框中框与隔离 | 门洞、窗框、栏杆在主体周围形成真实边界 | 边界是否影响人物路径或心理距离，开合或越界怎样改变关系 |
| 延迟揭示 | 行人经过、门页打开、烟尘被风带走，显露后方目标 | 遮住哪条信息，由谁或什么解除，露出后留多久才能读懂 |
| 压迫与不安 | 近处大面积暗物挤窄主体可见空间 | 压力来自哪个实体，关键行动仍从何处可见，信息遮蔽是否有意 |
| 现场观看质感 | 合理的过肩、雨滴、玻璃反光和擦过的路人 | 遮挡符合摄影机实际位置，而不是平空贴一层模糊边框 |

透明度、虚实与运动来自材料和成像关系：不透明门框真实挡住后物，纱帘以透射和遮蔽共同成像；玻璃可同时反射外侧与透出内侧，雨滴依附玻璃并受重力移动。近前景虚化取决于对焦和距离，固定一个光圈值并不保证同一种遮挡效果。镜面反射的位置要由机位、镜面朝向和被反射物共同推导。

遮住眼睛或让反光划过脸可以表达受限、记忆或疏离，即便基础事件不变仍有表达价值；只要保住本镜需要的动作轮廓，不应为了“看清”自动擦除暗示。也无需每镜加遮挡：通透、正面直视和干净背景同样可承载坦诚、暴露、孤立或仪式。

## 十四、构图演变的操作方式

- **维持主体的移动**：跟随时人物在画幅中的位置大致稳定，背景滑动证明路线；它表达陪伴或追赶，不必强制重新分配权力。
- **开放转封闭**：人物走入门框深处，或两名已有角色从两侧进入，真实可行动区域逐渐收窄；结尾让观众看见新的边界。
- **封闭转开放**：门被推开、前景人退开或人物走出遮挡，释放之前压住的视线空间；固定墙体只因机位改变而移出取景，不自行滑走。
- **层次接管**：原后景人物走近，先以动作或声音吸引注意，再由焦点和构图交给他；前景原主角如何让位要有路径。
- **平衡破坏**：一人离开、拿走桌面中心物件、偏离对称座次，原来均衡的画面留下具体空位。重建平衡也可以显示强行恢复秩序。
- **聚散**：依次入画与离画改变画面密度，声音和剩余人物动作可保留刚才的热闹痕迹。

建筑线条不会因人物转头自动改方向；人物视线改变的是注意引导，真实透视线改变要来自机位或几何变化。

## 十五、关系朝向与多层叙事

面对面、桌角 L 形、半侧相向、并肩共视、偏开朝向和背对背都可以使用。分别想清身体面向、眼睛所看目标及双方脚位，别用一个“夹角”代替三件事：面对面和背对背的朝向向量都可能相反，但位置和可见脸部完全不同。转向共同物件可以把对抗变成合作，也可能只是共同逃避话题。

需要交代环境与事件的镜头，可让前景人物的肩背形成窗口，中景通路保留可达路线，远景建筑给出世界尺度，更深处的运动或声源形成预期。没有固定层数；每层是已存在的实体或可穿行区域。若远处线索此刻需要读懂，就给它足够大小、清晰度、对比和观看时间；若只需“那里有东西”，轮廓和运动即可先建立。空旷处也可以表达距离、空气与孤立，不强求塞入额外物件。
