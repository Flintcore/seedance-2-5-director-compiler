# 色彩调性参考库

电影色彩不是情绪标签的换皮，而是光源、材质、美术、服装、肤色、曝光和后期共同形成的叙事关系。先确认颜色在世界中从哪里来、由谁看见、要区分什么，再选择色相结构与调色方法。同一种色彩关系可以产生相反含义；含义取决于场景上下文和变化过程。

## 一、六种色相关系

| 关系 | 色彩结构 | 适合解决的问题 | 成立条件与代价 |
|---|---|---|---|
| 单色 Monochromatic | 一个主色相，以明度、饱和度、材质和色温细差建立层次 | 统一地点身份、仪式或主观世界；让少量异色成为事件 | 需要用明暗、质感和空间深度防止主体与背景粘连 |
| 类似色 Analogous | 使用色轮上相邻色域 | 表现同一环境中的自然过渡、时间连续或群体归属 | 相邻色相区分弱，人物可读性要靠明度、冷暖微差和材质承担 |
| 互补色 Complementary | 使用色轮相对的两端，理论夹角约为 180° | 分离人物与环境、两种光源、阵营或空间层 | 不自动等于冲突；面积、亮度和饱和度若同强，会互相争抢 |
| 分裂互补 Split-Complementary | 主色与其互补色两侧形成三色关系 | 在保留分离度时容纳第三人物、物件或光源 | 三色需要明确主次，不能平均铺满画面 |
| 三角色 Triadic | 色轮上三组大致等距的色域 | 组织群像、多空间或多重叙事职责 | 依赖稳定的重复与分配；颜色过多而无归属会变成装饰噪声 |
| 冷暖关系 | 以相对冷暖区分光源、距离、时段或对象 | 建立前后景、室内外、身体与环境、现实与记忆的差异 | 冷暖是相对关系，不是固定情绪；先服从真实光源、肤色和材质 |

色轮角度只描述色相关系，不直接描述戏剧意义。实际画面还受亮度、饱和度、曝光、反射、相邻色和观看媒介影响。

## 二、颜色从哪里进入画面

### 场景与美术

墙面、家具、土地、植物、天气和使用痕迹提供大面积基色。场景色应先说明地点、时代和社会条件，再承担象征。一个反复出现的空间若改变颜色，需要有时间、光源、损耗或人物介入作为原因。

### 服装、肤色与物件

- 服装色可区分人物、显示归属或记录状态变化，但要与肤色和背景保持足够分离。
- 关键物件可用局部色成为注意锚；它的出现、转手、污染、褪色或缺席比“固定代表某种情绪”更有叙事价值。
- 肤色是连续性基准之一。风格化色染仍要保留面部结构、血色变化和不同光源之间的逻辑。

### 光源与反射

实际灯具、窗光、火、屏幕、霓虹和特效光会把颜色投到人物与环境。颜色必须随距离、遮挡、入射角和材质改变：金属产生方向性反射，皮肤形成较柔的色染，粗糙表面扩散，湿表面增强反射。若看不到可信来源，可选择让颜色成为明确的主观或图形化规则，而不是伪装成自然光。

### 后期调色

调色负责统一、分离和引导，不应凭空改变美术与光线的因果。先保护肤色、关键物件、光源方向和镜间连续，再调整整体对比、饱和度、色偏和局部层次。

## 三、常见处理方法及其条件

| 方法 | 画面结果 | 适用条件 | 风险 |
|---|---|---|---|
| 青橙分离 | 暖肤色或暖光与较冷环境分开 | 场景本就存在冷暖来源，或项目建立了稳定的双色规则 | 不分场景套用会让肤色塑料化、阴影发脏 |
| 漂白旁路式处理 | 饱和度下降、对比和颗粒感上升，材质边缘更硬 | 需要突出磨损、曝光压力或纪录质感，且暗部仍保留必要信息 | 黑位堵塞、肤色失真、所有场景变成同一粗粝表面 |
| 日光夜景 | 以曝光、天空、阴影方向和受光关系把日景组织成夜景 | 拍摄条件支持可控天空与明确月光方向，动作仍需可读 | 只压暗加蓝会保留日照证据，人物像贴在背景上 |
| 限定色域 | 减少主要色相，让少数颜色反复承担身份或结构 | 美术、服装、灯光和后期从前期共同设计 | 只在后期抽色会损伤肤色、材质和地点差异 |
| 高调关系 | 整体明亮、阴影开放、反差较低 | 场景需要显露空间和表演细节，光源面积与环境反射支持 | 不等于轻快；若缺少局部层次，人物会扁平或失去视觉中心 |
| 低调关系 | 暗部占比大、局部光源决定可见信息 | 隐藏、等待、权力控制或夜间空间确实需要限制观看 | 不等于悬疑；暗部无细节、无动机光会只剩欠曝 |
| 复古褪色 | 饱和度、黑位、颗粒、偏色和材质共同产生年代感 | 与影像载体、时代美术或人物记忆的观看方式一致 | 单纯加黄或褪色会把不同年代和地点做成同一滤镜 |
| 霓虹与高饱和夜景 | 多种实景彩光在湿表面、玻璃、烟雾与皮肤上发生混合 | 城市光源、招牌、屏幕或舞台设备真实存在并参与调度 | 色源无空间位置、所有表面同色发亮，会失去景深与材质 |
| 水墨与低饱和东方体系 | 以墨色层次、留白、材质渗化和少量色锚组织画面 | 媒介、场景、美术和运动都接受图形化规则 | 把国风缩减为灰画面或统一青色，会丢失气韵、材质与叙事差异 |

这些方法可以组合，但每一项都要说明它改变的是光源、材质、空间层次、时间感还是观看媒介。组合后若无法指出主色来源与叙事职责，应先减少处理层。

## 四、条件性色彩叙事

| 戏剧任务 | 可用的色彩关系 | 必须先判断 |
|---|---|---|
| 区分人物、阵营或空间 | 为各方分配可重复识别的局部色、光源或材质色，并在同框时保持层级 | 颜色是否来自服装、场景、光源或主观规则；是否与肤色和背景冲突 |
| 引导注意 | 让关键对象在明度、饱和度、色温或邻接色上形成局部差异 | 观众是否已经理解该颜色；差异是否比其他区域更强但不过度暴露 |
| 表现关系变化 | 让两人的颜色逐渐共享、互相污染、交换位置，或在同一光源下仍保持差异 | 变化由接近、分离、物件转手、光源变化还是立场转变造成 |
| 标记记忆、时间或主观视点 | 保留一个跨时空色锚，同时改变对比、材质、曝光或环境色 | 转换是否有视点依据；回到客观世界时是否存在可辨的颜色桥 |
| 暴露危险或异常 | 让正常色彩秩序出现局部偏离、传播、闪烁或污染 | 异常从哪里开始、谁先察觉、影响哪些表面、结束后留下什么 |
| 表现权力转移 | 让控制场景主光、背景色域或关键色锚的人发生变化 | 权力是否真的改变了人物位置、照明权限、物件归属或空间使用 |
| 表现失去与缺席 | 保留原有颜色所在的位置、物件或光源，但改变承载者、强度或响应 | 该颜色此前是否被建立；缺席是否影响人物行动而非只做象征 |
| 制造反讽 | 让公共空间的色彩秩序与人物行为或后果不一致 | 反差是否来自真实情境，是否尊重事件的实际重量 |

色彩变化应沿场景因果发生。悲伤可以处在暖色家庭空间，危险可以发生在高调白昼，亲密也可以被冷光建立；关键是光色如何改变人物、空间和观众的信息，而不是为情绪匹配固定色卡。

## 五、动作与特效的颜色连续

1. **先定来源**：能量、武器、车辆、火、界面或环境光各自有明确颜色来源；同一来源跨镜保持可识别。
2. **再定传播**：颜色沿动作路径、空气介质、反射面和接触点传播，不能只贴在特效轮廓上。
3. **区分功能**：角色识别、阵营区分、蓄力阶段、接触峰值和余波可使用不同层级，但不必为每个动作换一种颜色。
4. **用变化表现状态**：亮度、面积、饱和度、闪烁频率、边缘清晰度和环境染色都能表示能量变化；具体选择服从世界规则，不把某个色相固定为强弱等级。
5. **保留后果**：灼痕、余光、烟尘色染、湿地反射、服装污染和人物视适应应进入下一镜连续状态。
6. **保证同框可读**：多方特效同时出现时，优先确保来源、路径和接触可分辨，再追求色彩丰富度。

## 六、阴影与高光色偏

- 阴影色来自环境填充、天空、墙面反射和曝光，不是任意涂色；高光色来自主光、实景灯或发光现象。
- 冷环境填充与暖主光可以分离人物和空间；暖环境反射与冷主光同样成立，只要现场来源和材质支持。
- 同一色温覆盖阴影与高光会强化统一感，但要依靠明度、质感和局部反射保留结构。
- 有色实景灯可在人物移动时改变脸部与服装色染；变化的起止位置应与灯具和遮挡对应。
- 中性基底配少量彩色高光适合保护肤色和物件本色；大面积彩色阴影则会显著改变空间归属和观看态度。
- 不同空间或时间可以有不同阴影/高光关系，但切换时应通过门窗、声场、动作、曝光适应或明确的叙事断裂建立过渡。

## 七、色彩设计路径

1. **确认世界来源**：时间、天气、建筑、服装、实际灯具和发光现象提供哪些颜色。
2. **确定戏剧职责**：颜色用于身份、空间、注意、时间、记忆、危险、关系还是视点。
3. **建立主次**：决定主导色域、辅助关系和少量色锚，不按固定面积或饱和度比例填充。
4. **保护人物与材质**：检查肤色、服装、金属、湿表面、透明材质和烟雾如何受色光影响。
5. **设计变化**：为每次明显转色写出触发、传播、人物反应和新状态。
6. **建立颜色连续表**：记录跨镜必须一致的光源色、服装色、关键物件、污染、余光和主观视点边界。
7. **在运动中检查**：人物穿越不同光区、摄影机改变角度或特效移动时，颜色关系是否仍有来源和空间层次。

最终判断不是“这个情绪该用什么颜色”，而是“哪一种颜色关系能让当前人物、空间和变化更清楚，并且它为何在这一刻成立”。
