# Blender 白模预演参考接入

只在已有成片提示词需要增补 Blender 粗模预演视频时读取本文件及 [素材职责](reference-assets.md)。这是 `OPTIMIZE` 的参考增补，不是让 Seedance 生成白模，也不是重做分镜。原提示词直接作为创意基线；无需补造 L1、Blender 工程、manifest、哈希清单或交接包。

**原提示词决定故事、运镜表达、具体表演、动作与特效；白模为同一设计补充空间、站位和镜头依据；原角色图与场景图继续决定正式外观和美术。** 这是提示词中的参考职责，不是对生成结果逐帧一致的保证。

## 识别并对应已有设计

- 先保留原提示词、逐字对白和已有素材映射，再查看实际提供的视频。按镜头变化和辨认需要读取画面及运动过程；静帧可支持颜色和站位判断，运动方向、遮挡变化和运镜轨迹需要时间上的证据。无需固定抽帧密度，也无需从头重做导演设计。
- 将代理颜色、轮廓、体型、所在位置和跨镜运动轨迹，与原分镜中的角色及用户说明对应起来。用户明确给出的颜色对应优先；颜色只标识代理身份，不定义正式服装、肤色或美术。同色角色可结合位置或外形区分，同一角色跨镜保持同一名称。
- 实际视频观察与用户明确提供的对应说明可以作为依据，文件名或单凭颜色的猜测则保持待确认。若素材暂未读取或角色映射有歧义，只询问影响绑定的最小缺口；可用用户确认的对应说明或关键画面继续，不声称看到了未观察的运动。待确认事项留在正式提示词之外。

## 选择性继承，而非照搬粗动画

| 来源 | 本流程中的职责 |
|---|---|
| 白模预演 | 当前段的场景布局、人物相对站位、粗略走位路径、前后景关系、遮挡、镜头顺序、构图与摄影机路径，为原分镜提供可视化依据 |
| 原提示词 | 本段戏剧任务、完整故事与镜头叙事、原运镜描述、焦距等有效技术信息、视线、微表情、情绪、自然小动作、呼吸、动作过程与惯性/接触/反馈、逐字对白、声音、特效和画面质感 |
| 原角色/服装/道具参考 | 已命名角色与物品的最终外观、脸、服装和细节，不新增代理角色或另一具身体 |
| 原场景参考 | 场景正式美术、材质、色彩与原有视觉特征；空间布局按本轮明确交给白模的范围处理，保留其他已锁定事实 |

白模的平移、僵硬姿态、空白表情、简化打斗、示意性停顿和不完整接触只代表粗略调度。成片在对应空间与镜头组织内完成原提示词的细表演和动作设计；视频未呈现的微动作、对白、声音或特效仍保留。识别色、代理几何、测试标记和临时材质是预演辅助信息，最终形象沿用正式参考。

只有用户明确要求时，才将视频中的精确动作节拍、接触瞬间或逐帧时序作为锁定要求；视频总时长和机械步频本身不自动覆盖原提示词的段长与动作内部节奏。保留原分镜的切点和时间关系，按对应镜头使用视频；额外测试片头、静帧停留或其他段落只属于素材范围，不自动拆出新的生成段。

原运镜文字与白模应表达同一个设计。遇到实质冲突，如角色对应不明、推进方向相反、镜头顺序不同，或时长差导致原事件放不下，先指出具体镜头及差异，按用户本轮指示与已确认设计处理；权属仍未确定时只确认该差异，再输出无歧义的完整提示词。粗模缺少细表演本身不是冲突。避免静默覆盖原稿，或把两种矛盾设计混成第三种设计。

## 接入现有素材绑定行

按 [素材占位符规则](reference-assets.md) 保留已有图、视频、音频的规范编号、顺序、职责和绑定对象。只追加新来源；若是同一视频，合并到原视频项。单个白模视频即使包含多个镜头，也只占一个素材引用，在整份正式提示词中只出现一次。

将“代理对应哪个角色、参考哪些空间/镜头关系、哪些细节沿用原分镜与正式参考”合并在该视频的绑定项里。镜头正文继续使用故事角色名称；路径、文件名、内部映射表和未确认编号留在内部。

上方职责表用于内部取舍，不逐项转写成长串锁定或排除声明。原稿已有的段长、切点、稳定区、走位过程和表演细节保留在原位置，素材项无需再复述；通常概括为“具体表演、动作与特效按下方分镜，正式外观沿用原参考”即可。只在本次确有歧义时增加针对性说明，而不是把所有粗模缺陷和保护规则列一遍。

下面仅示意新增项：假设原稿尚无视频参考，且用户已确认红色代理是女主、黄色是粑粑星人、蓝色是大胃袋星人；实际颜色与编号按输入决定，而非套用示例。

```text
@video1=本段白模预演参考：红色代理对应女主，黄色代理对应粑粑星人，蓝色代理对应大胃袋星人；参考其中的场景布局、人物站位与走位、构图及摄影机路径。角色外观与场景美术沿用原有参考，具体表演、动作细节、对白与特效按下方分镜完成；代理颜色仅用于识别角色。
```

这段接到现有 `─ 素材绑定：` 行，不替换其他素材，也不另开白模字段、角色映射区或第二套提示词格式。只写本次素材需要的职责说明，不复制整份规则。

## 轻量修订与交付

保留原稿的光影与摄影机画面质感、本段戏剧任务、情节、镜头顺序、运镜、表演、对白、动作、特效和结尾。可以适量压缩视频已经清楚展示且文字重复的静态几何信息；仍保留帮助当前镜头独立可读的动态空间锚点、触发、动作过程、联动反应和切换因果。即使引用了视频，镜头正文仍应让人看懂完整画面，避免缩成“动作与运镜都参考视频”。

压缩范围不包括每镜的景别、焦段、摄影机相对主体的方位与高度、平仰俯，以及运动或固定状态；依照 [原生分镜的完整要素](nine-layer-schema.md) 简短保留在本镜，避免只剩“同机位”或“参考白模”。原稿或可明确承接的镜头参数优先，缺失信息按锁定事实处理，视频目测不冒充精确焦距测量。

默认返回同一格式的一份完整修订提示词；只有用户只要新增项或替换块时才局部交付。本分支按需读取素材与编译规则，既有动作戏也无需重新展开动作母机或全套多角色流程。用户明确要求重设计时，再按现有知识路由读取相关影视与大师正文。普通参考增补在内存完成，不附加日志、读库报告或最终自检。
