# 补充语法样例：人物声桥与动作边界

编译以[运行 SOP](../../modules/prompt-writing-sop.md)和本场设计为准。以下为既有自拟样例的手册写法修订，仅在需要对应语法分支时读取，不定义另一套文风。角色行为方法来自 [角色行为与动作叙事参考库](../cinema/角色行为与动作叙事参考库.md)，成稿形式服从 [七块主模板](nine-layer-schema.md)。它们不是固定人物习惯、镜数或参数配方，也不是已生成视频。结构测试验证格式、时长、引用和逐字原文；人物策略、视听可读性与成片效果另需独立审读或真实生成验证。

## A. 对白中运镜，原句跨切，听者继续做事 · 12秒

设计前提：阿宁在核对夜班收据，陈砚想让她相信自己离开时灯仍亮着；她掌握的收据记录与“昨晚”冲突，决定给他一次重想的机会。两句原文锁定为“我昨晚离开的时候，那盏灯还亮着。”与“你再想想。”；第一句由陈砚说出，在“我昨晚离开的时候，”之后切到阿宁听后半句，阿宁不代说。陈砚的稳重声线不是本场永远平稳的表达指令。

```text
【本段目标】
12秒一条生成，两个镜头。办公室里，陈砚想让阿宁相信离开时灯还亮着；阿宁手里的收据与这番说法冲突，阿宁不当面戳破，留下收据让陈砚重新想。自然数字影像，2.39:1，柔和窗光。先横移靠近，后固定听答，语气客气却有压力。

【参考绑定】
@image1 = 阿宁身份与服装；@image2 = 陈砚身份与服装；@image3 = 办公室长桌、窗和入口的布局与材质。人物站姿和参考取景不继承。@audio1 = 陈砚的音色与口音，不带入录音原词和背景声。图片仅作全能参考，不作为首帧、尾帧或静帧。

【空间】
长桌南北两侧各坐一人，阿宁在北、陈砚在南，窗在西墙。收据在阿宁手边，杯子在陈砚面前，摄影机留在桌东侧。

【环境】
西窗光照着纸页和两人的侧脸，阿宁身后是文件柜，办公室里只有低微通风声。

【时间线】
【0:00-0:04.5】镜头1 桌侧双人中景。
35mm，摄影机在桌东侧、胸高平视，阿宁在画右归拢收据，陈砚在画左扶着杯柄。摄影机沿桌侧缓缓向阿宁移近。陈砚扫一眼纸堆，抬眼迎着阿宁说：“我昨晚离开的时候，”阿宁正把一张收据送回纸堆，听到“昨晚”，手停在半途，目光仍留在陈砚脸上。硬切到镜头2，陈砚的话不断。

【0:04.5-0:12】镜头2 阿宁中近景。
65mm，摄影机在阿宁左前1/4、眼高固定，阿宁偏右，陈砚扶杯的手留在左前缘。阿宁仍握着那张收据，陈砚从画外继续说：“那盏灯还亮着。”阿宁听完，把收据单独压在纸堆上，客气地说：“你再想想。”阿宁望着陈砚，指尖压住收据。陈砚刚提起的杯子又落回桌上，手指松开杯柄。阿宁没再追问，等陈砚回答。

【声音】
无BGM（无配乐）。通风声持续，纸张摩擦与杯底轻碰按动作发生。陈砚沿参考音色，第一句话跨切连续；阿宁客气但不退让。

【不可出错】
收据由阿宁整理并单独留下；陈砚的后半句由陈砚画外说出；本段不揭示陈砚是记错还是隐瞒。无字幕、无文字叠加。
```

这里第一句按真实切点分成两镜各自听到的原文；两部分按序拼回完整原句，后镜点名陈砚画外续说，不由画内听者代说。听者的停手依据已到达的信息，而非提前知道后半句。摄影机运动发生在讲话中，人物与声音没有因此等待镜头停稳。

## B. 无对白的救援动作，已有伤侧影响选择，非人沿自身结构反应 · 10秒

设计前提：四轮圆壳机器人没有人脸，有壳顶搬运把手；林遥左踝已有扭伤。缓坡走廊上一辆失控运货车正从西向东滑来，林遥只想把机器人拉进北侧设备凹位，避开直行车道；不新增伤情、破坏或台词。一个连续镜头看懂路线、接触与结果。

```text
【本段目标】
10秒一条生成，一个连续镜头。工业走廊，运货车失控滑来，林遥想把圆壳机器人拉进北侧凹位。林遥左踝受伤，只能借护栏和右腿使力。写实金属质感，2.39:1，常速，固定全景看清拉拽和车道。

【参考绑定】
@image1 = 林遥身份、服装和已定左踝包扎；@image2 = 圆壳机器人的四轮、圆壳与顶上把手；@image3 = 缓坡走廊、护栏和设备凹位的布局与材质。只继承以上职责，不继承拼版和站姿；图片不作为首帧、尾帧或静帧。

【空间】
走廊从西向东下坡，北墙有护栏和带低门槛的设备凹位。林遥站在机器人北侧，右手抓护栏，左手扶壳顶把手。运货车从西向东滑来。

【环境】
顶灯照亮金属地面和凹位入口，车道与门槛清楚可见。

【时间线】
【0:00-0:10】镜头1 走廊全景。
28mm，摄影机在走廊南侧、腰高轻俯固定，西侧车道留在画左，林遥和圆壳机器人在画右，凹位在北墙。车轮声逼近，林遥看向西侧，把右脚挪进凹位，右臂借护栏撑住，左手拽着壳顶把手向北后方拉。圆壳机器人转动前轮，贴地划弧退出车道；后轮碰到门槛卡了一下，林遥被带得往前一倾，抓护栏的手猛地收紧，受伤的左脚只轻轻跟过去。圆壳机器人轮组继续驱动，后轮爬过门槛，圆壳晃了一下落稳。运货车擦着凹位前方滑过，向画右远去。林遥这才松下拉拽的力，左手仍搭着圆壳，右手扶住护栏，重量留在右腿上，喘着气看车远去。同一个连续镜头，中间不剪切。

【声音】
无对白、无BGM（无配乐）。滑车轮声从西侧逼近再向东侧远去，后轮磕槛声、轮组驱动声，林遥用力后的喘息。

【不可出错】
林遥左踝伤情保持，右腿主要承重；圆壳机器人以四轮行动，没有人脸；运货车沿原车道通过，机器人留在凹位。无字幕、无文字叠加。
```

动作原因、发起、转向路径、接触、受阻反馈和新状态都留在一镜中。伤侧来自给定前提并持续影响承重；机器人通过轮组与壳体反馈表达，不凭空出现人脸或人类呼吸。

## C. 锁定静止、藏眼与无参考素材 · 4秒

设计前提：用户明确要求一个完全静止的背影等待镜头，不补人物小动作、不展示脸、不加对白。此例说明持续生命感不覆盖明确静止与心理不透明设计。

```text
【本段目标】
4秒一条生成，一个固定镜头。夜间走廊，门外人物停在门前，手搭着把手却没有开门，保留是否进去的疑问。低调写实影像，2.39:1，安静、不露面。

【参考绑定】
无外部参考素材。

【空间】
门外人物背对摄影机站在关着的门前，右手搭着门把，脸朝门板。

【环境】
顶灯给外套肩部勾出窄亮边，门框和墙面留在暗里。

【时间线】
【0:00-0:04】镜头1 门外背影中景。
50mm，摄影机在门外人物正后方、胸高平视，三脚架固定。背影偏左，右侧留门板和门框。门外人物的右手停在门把上，整镜维持这个姿势，门把始终没拧下去。摄影机不动，肩上的窄亮边也静止，脸藏在背影另一侧。

【声音】
无对白、无BGM（无配乐），远处通风机低声持续。

【不可出错】
门保持关闭；门外人物全程背对摄影机、保持原定静止。无字幕、无文字叠加。
```

人物的世界目标清楚，但观众继续得不到面部心理信息。结构测试接受这份短而静的设计，不按动作数量或“表演占比”判劣。
