# 完整维护样例：人物过程、声桥与动作边界

以下均为自拟文本样例，只在学习/维护对应写法时读取。角色行为方法来自 [角色行为与动作叙事参考库](../cinema/角色行为与动作叙事参考库.md)，成稿形式服从 [六部分主模板](nine-layer-schema.md)。它们不是固定人物习惯、镜数或参数配方，也不是已生成视频。结构测试验证格式、时长、引用和逐字原文；人物策略、视听可读性与成片效果另需独立审读或真实生成验证。

## A. 对白中运镜，原句跨切，听者继续做事 · 12秒

设计前提：阿宁在核对夜班收据，陈砚想让她相信自己离开时灯仍亮着；她掌握的收据记录与“昨晚”冲突，决定给他一次重想的机会。两句原文锁定为“我昨晚离开的时候，那盏灯还亮着。”与“你再想想。”；第一句由陈砚从第2秒说到第6.5秒，跨第4.5秒的切镜，阿宁不代说。陈砚的稳重声线不是本场永远平稳的表达指令。

```text
【风格】
自然数字电影质感，2.39:1，柔和窗光保留纸张与肤色层次，安静办公室的近距离交谈。

【素材绑定】
@image1=阿宁外观与服装；@image2=陈砚外观与服装；@image3=办公室长桌、窗和入口的空间与材质，不沿用参考取景；@audio1=陈砚已锁音色与口音，当场气息和重音按说话策略表达，不带入参考原词和背景声。

【全局约束】
同一白天办公室，阿宁坐长桌北侧，陈砚坐南侧，窗在西墙；桌上已有收据与陈砚的杯子，收据始终由阿宁整理。无字幕，无BGM。

【本段戏剧任务】
阿宁从听陈砚说明离开时间，转入抓住说法与收据的矛盾，并通过暂留一张收据和请他重想推进交涉；结尾陈砚停止伸手拿杯，解释的主动权转到阿宁手里。

【本段情绪总控】
礼貌里的压力——手上动作不断，问话留有空隙；是让对方自己修正，不是当面爆发指控。

镜头1｜0:00-0:04.5
35mm双人中景，摄影机在桌东侧、胸高平视。起始画面中，阿宁坐在画右、陈砚坐在画左，两人上身约占画高三分之二，桌角是前景，西窗留在后景；首0.5秒两人已经隔桌坐定，阿宁边归拢收据边看着陈砚听，陈砚右手松扶杯柄，身体微向她靠近。摄影机在原侧缓缓向阿宁移近，不越过二人连线。陈砚先看一眼她正在整理的纸，随后抬眼对她；陈砚从0:02开始说：“我昨晚离开的时候，那盏灯还亮着。”他想把离开时的情况说得确定些；这次发声跨镜头1—2连续至0:06.5。阿宁一开始仍将收据逐张送回纸堆，听到他提及昨晚的信息，正向纸堆送的那只手停在桌面上方，眼神仍留在他脸上；他继续往下说，没有因这一下停顿重新起句。镜尾她保持这张尚未归堆的收据，他的右手仍扶着杯柄；随后硬切到阿宁，陈砚的同一句话继续。光影：西窗光沿两人侧脸和纸页持续，纸张停下后页上亮面不再移动，没有新增光源。现场声：低低的通风声持续，纸页摩擦在她停手时停住。

镜头2｜0:04.5-0:12
65mm中近景，摄影机在阿宁左前1/4（桌东南侧）、眼高平视固定。起始画面中，阿宁上身偏右、约占画高三分之二，纸页在下部，陈砚扶杯的手留在左前缘，背后是北墙文件柜；她仍握着没有归堆的收据，继续听陈砚从桌对面说完后半句，说话声与目光对象没有因切镜改变。她等信息说完，把这张收据压到纸堆最上面，阿宁才在0:07.5—0:08.8以仍然客气的口吻对他说：“你再想想。”目光没有离开对方的脸。陈砚的手原本开始提杯，察觉她把纸单独留下，便把杯底重新落稳，手指从杯柄上松开；阿宁没再追问，指尖还压着那张收据，留给他回答的时间。最后0.5秒两人维持这个交接后的状态：她等，他的手停在杯旁，纸仍在她手下。光影：窗光继续照住阿宁侧脸与纸面，落杯和手指松开只改变局部遮影，宏观光线保持稳定。现场声：通风声跨切延续，杯底轻触桌面后归于安静。
```

这里第一句只绑定一次完整原文；跨切属于声音时间关系，不是要求画内听者张嘴。听者的停手依据已到达的信息，而非提前知道后半句。摄影机运动发生在讲话中，人物与声音没有因此等待镜头停稳。

## B. 无对白的救援动作，已有伤侧影响选择，非人沿自身结构反应 · 10秒

设计前提：四轮圆壳机器人没有人脸，有壳顶搬运把手；林遥左踝已有扭伤。缓坡走廊上一辆失控运货车正从西向东滑来，林遥只想把机器人拉进北侧设备凹位，避开直行车道；不新增伤情、破坏或台词。一个连续镜头看懂路线、接触与结果。

```text
【风格】
写实工业空间，2.39:1，稳定观察中保留重量和接触感，不加戏剧化速度变化。

【素材绑定】
@image1=林遥外观、服装及已定左踝包扎；@image2=圆壳机器人外形、四轮和壳顶把手，沿机械结构行动；@image3=走廊缓坡、北墙护栏及设备凹位的地理与材质。

【全局约束】
走廊东西向、缓坡向东，北侧有带低门槛的设备凹位和固定护栏；林遥左踝已有扭伤，右腿主要承重。圆壳机器人无眉眼嘴，四轮可转向驱动。运货车沿车道向东滑行。无对白，无字幕，无BGM。

【本段戏剧任务】
林遥从与机器人同处滑车路径，进入把它拉进北侧凹位避让的处境；她借护栏与右腿支撑完成拉拽，机器人自身驱轮越槛，车通过后她仍受伤侧限制而没有立即松开支撑。

【本段情绪总控】
紧迫而清楚——先让开路径，再消化负荷；是有目的地护住同伴，不是炫技翻滚。

镜头1｜0:00-0:10
28mm全景，摄影机在走廊南侧、腰高轻俯拍固定。起始画面中，林遥与机器人偏右、合占约半幅，北墙凹位在他们身后，西侧车道留在画左纵深，手、轮和脚都清楚可见。首0.5秒林遥已经站在机器人北侧，右手抓住护栏，左手扶着壳顶把手，左脚轻点地面，视线沿走廊看向西面的滑车。车轮声逼近，她先把右脚向凹位里挪稳，右臂借护栏支撑，左手将把手向北后方拉；机器人受拉后转动前轮，身体随轮子划弧退出车道，而非整壳被提起。后轮碰到低门槛时拉力短暂卡住，她的身体被带回一点，抓护栏的手收紧，左脚只跟着轻移，没有突然改用伤腿猛蹬；机器人轮组继续驱动爬过门槛，壳体轻晃后落稳。运货车沿原车道从他们面前滑向东侧，没有撞上二者。林遥这才放松拉把手的力，左手仍搭在机器人壳顶，右手继续承着护栏，胸背随着刚才用力后的呼吸慢慢起伏。最后0.5秒机器人四轮都在凹位内，她主要压在右腿上，目光跟着离开的车确认路径已经让开，支撑关系不重置。光影：已有顶灯沿壳体与手臂形成连续亮面，机器人滚进凹位时北墙遮住一部分顶光，身体遮影随实际移动变化。现场声：运货车轮声从西侧逼近再向东侧远去，机器人后轮磕槛与驱动声对应越槛过程，林遥用力后的呼吸留在近处。
```

动作原因、发起、转向路径、接触、受阻反馈和新状态都留在一镜中。伤侧来自给定前提并持续影响承重；机器人通过轮组与壳体反馈表达，不凭空出现人脸或人类呼吸。

## C. 锁定静止、藏眼与无参考素材 · 4秒

设计前提：用户明确要求一个完全静止的背影等待镜头，不补人物小动作、不展示脸、不加对白。此例说明持续生命感不覆盖明确静止与心理不透明设计。

```text
【风格】
低调写实成像，2.39:1，暗部保留走廊墙面层次，保持安静距离。

【素材绑定】
无外部参考素材

【全局约束】
同一夜间走廊，人物背对摄影机站在关闭的门外；人物姿态和摄影机按设计全程静止，脸与眼睛始终不可见。无对白，无字幕，无BGM。

【本段戏剧任务】
人物已经停在门外并保持等待，通过始终未拧动的门把与闭门关系延续尚未行动的处境；结尾继续保留是否进门的疑问。

【本段情绪总控】
克制的悬置——停在决定之前；是有意保持的不透明，不是解释内心或渲染惊恐。

镜头1｜0:00-0:04
50mm中景，摄影机在人物后方、胸高平视固定。起始画面中，背影偏左、上身约占画高三分之二，右侧门框与门板承住画面，脸和眼睛不进入可见范围。首0.5秒人物已背对摄影机站在关闭的门外，右手停在门把上，身体与头均朝向门；这个等待姿态延续至最后0.5秒，既不拧把也不转头。摄影机留在原处，不补手势、抖动或露出表情来解释迟疑。光影：走廊已有顶灯在外套肩部形成稳定窄亮边，门与墙面的明暗关系保持不变。现场声：远处通风机的低声持续，门把未动所以没有额外金属声。
```

人物的世界目标清楚，但观众继续得不到面部心理信息。结构测试接受这份短而静的设计，不按动作数量或“表演占比”判劣。
