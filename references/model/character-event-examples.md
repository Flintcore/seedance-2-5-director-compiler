# 完整维护样例：人物过程、声桥与动作边界

以下均为自拟文本样例，只在学习/维护对应写法时读取。角色行为方法来自 [角色行为与动作叙事参考库](../cinema/角色行为与动作叙事参考库.md)，成稿形式服从 [七块主模板](nine-layer-schema.md)。它们不是固定人物习惯、镜数或参数配方，也不是已生成视频。结构测试验证格式、时长、引用和逐字原文；人物策略、视听可读性与成片效果另需独立审读或真实生成验证。

## A. 对白中运镜，原句跨切，听者继续做事 · 12秒

设计前提：阿宁在核对夜班收据，陈砚想让她相信自己离开时灯仍亮着；她掌握的收据记录与“昨晚”冲突，决定给他一次重想的机会。两句原文锁定为“我昨晚离开的时候，那盏灯还亮着。”与“你再想想。”；第一句由陈砚说出，在“我昨晚离开的时候，”之后切到阿宁听后半句，阿宁不代说。陈砚的稳重声线不是本场永远平稳的表达指令。

```text
【本段目标】
12秒，一条连续生成。
阿宁从听陈砚说明离开时间，转入抓住说法与收据的矛盾，并通过暂留一张收据和请陈砚重想推进交涉。
阿宁：阿宁掌握的收据记录与陈砚的说法有冲突，阿宁想让陈砚重新想清楚，维持客气、给陈砚修正的余地，而非立刻指控。
陈砚：陈砚想让阿宁相信离开时灯仍亮着，陈砚先用确定的说法争取认可；察觉阿宁把收据单独留下后，陈砚的从容被打断。
结尾陈砚停止伸手拿杯，观众感到解释的主动权转到阿宁手里；本段仍未判定陈砚是记错还是隐瞒。
礼貌里的压力——手上动作不断，问话留有空隙；是让陈砚修正说法，不是当面爆发指控。
自然数字电影质感，2.39:1，柔和窗光保留纸张与肤色层次，安静办公室的近距离交谈。

【参考绑定】
@image1=阿宁外观与服装；@image2=陈砚外观与服装；@image3=办公室长桌、窗和入口的空间与材质，不沿用参考取景；@audio1=陈砚已锁音色与口音，当场气息和重音按说话策略表达，不带入参考原词和背景声。
本段采用全能参考；图片仅提供上述身份与场景依据，不作为首帧、尾帧或拼版静帧。

【空间】
同一白天办公室，阿宁坐长桌北侧，陈砚坐南侧，窗在西墙；桌上已有收据与陈砚的杯子，收据始终由阿宁整理。

【环境】
西墙窗光持续照着长桌、纸页与两人侧脸；办公室保持安静，收据与杯子是已有物件。

【时间线】
【0:00-0:04.5】镜头1
35mm双人中景，摄影机在桌东侧、胸高平视。起始画面中，阿宁坐在画右、陈砚坐在画左，阿宁与陈砚上身约占画高三分之二，桌角是前景，西窗留在后景；阿宁与陈砚已经隔桌坐定，阿宁边归拢收据边看着陈砚听，陈砚右手松扶杯柄，身体微向阿宁靠近。摄影机在原侧缓缓向阿宁移近，不越过阿宁与陈砚的连线。陈砚先看一眼阿宁正在整理的纸，随后抬眼对阿宁；陈砚迎着阿宁的目光说：“我昨晚离开的时候，”陈砚想把离开时的情况说得确定些；这部分在本镜说出，余句跨切延续。阿宁一开始仍将收据逐张送回纸堆，听到陈砚提及昨晚的信息，正向纸堆送的那只手停在桌面上方，眼神仍留在陈砚脸上；陈砚继续往下说，没有因这一下停顿重新起句。镜尾阿宁保持这张尚未归堆的收据，陈砚的右手仍扶着杯柄；随后硬切到阿宁，陈砚的同一句话继续。西窗光沿阿宁与陈砚侧脸和纸页持续，纸张停下后页上亮面不再移动，没有新增光源。低低的通风声持续，纸页摩擦在阿宁停手时停住。

【0:04.5-0:12】镜头2
65mm中近景，摄影机在阿宁左前1/4（桌东南侧）、眼高平视固定。起始画面中，阿宁上身偏右、约占画高三分之二，纸页在下部，陈砚扶杯的手留在左前缘，背后是北墙文件柜；阿宁仍握着没有归堆的收据；桌对面的陈砚以同一声音从画外承接前镜继续说：“那盏灯还亮着。”阿宁继续听，说话声与目光对象没有因切镜改变。阿宁等信息说完，把这张收据压到纸堆最上面，阿宁才以仍然客气的口吻对陈砚说：“你再想想。”阿宁的目光没有离开陈砚的脸。陈砚的手原本开始提杯，察觉阿宁把纸单独留下，便把杯底重新落稳，手指从杯柄上松开；阿宁没再追问，指尖还压着那张收据，留给陈砚回答的时间。镜尾阿宁与陈砚维持这个交接后的状态：阿宁等，陈砚的手停在杯旁，纸仍在阿宁手下。窗光继续照住阿宁侧脸与纸面，落杯和手指松开只改变局部遮影，宏观光线保持稳定。通风声跨切延续，杯底轻触桌面后归于安静。

【声音】
无BGM；办公室原有低微环境声连续，纸张和杯子的局部声音随原动作发生。陈砚声线沿参考，阿宁的回应按当镜的客气压力表达；跨切仍是陈砚同一句发声。

【不可出错】
收据由阿宁整理，单独留下的仍是原收据；陈砚的请求/解释由陈砚说出，续句不交给阿宁；本段不判定记错或隐瞒；无字幕。
```

这里第一句按真实切点分成两镜各自听到的原文；两部分按序拼回完整原句，后镜点名陈砚画外续说，不由画内听者代说。听者的停手依据已到达的信息，而非提前知道后半句。摄影机运动发生在讲话中，人物与声音没有因此等待镜头停稳。

## B. 无对白的救援动作，已有伤侧影响选择，非人沿自身结构反应 · 10秒

设计前提：四轮圆壳机器人没有人脸，有壳顶搬运把手；林遥左踝已有扭伤。缓坡走廊上一辆失控运货车正从西向东滑来，林遥只想把机器人拉进北侧设备凹位，避开直行车道；不新增伤情、破坏或台词。一个连续镜头看懂路线、接触与结果。

```text
【本段目标】
10秒，一条连续生成。
林遥从与圆壳机器人同处滑车路径，进入把圆壳机器人拉进北侧凹位避让的处境；林遥借护栏与右腿支撑完成拉拽，圆壳机器人的轮组驱动越槛，车通过后林遥仍受伤侧限制而没有立即松开支撑。
紧迫而清楚——先让开路径，再消化负荷；是有目的地护住同伴，不是炫技翻滚。
写实工业空间，2.39:1，稳定观察中保留重量和接触感，不加戏剧化速度变化。

【参考绑定】
@image1=林遥外观、服装及已定左踝包扎；@image2=圆壳机器人外形、四轮和壳顶把手，沿机械结构行动；@image3=走廊缓坡、北墙护栏及设备凹位的地理与材质。
本段采用全能参考；图片仅提供上述身份与场景依据，不作为首帧、尾帧或拼版静帧。

【空间】
走廊东西向、缓坡向东，北侧有带低门槛的设备凹位和固定护栏；林遥左踝已有扭伤，右腿主要承重。圆壳机器人无眉眼嘴，四轮可转向驱动。运货车沿车道向东滑行。

【环境】
既有顶灯照着金属走廊和北侧凹位，地面与护栏保持原材质。林遥和圆壳机器人的受光随实际遮挡改变。

【时间线】
【0:00-0:10】镜头1
28mm全景，摄影机在走廊南侧、腰高轻俯拍固定。起始画面中，林遥与圆壳机器人偏右、合占约半幅，北墙凹位在林遥与圆壳机器人身后，西侧车道留在画左纵深，林遥的手脚与圆壳机器人的轮组都清楚可见。林遥已经站在圆壳机器人北侧，右手抓住护栏，左手扶着壳顶把手，左脚轻点地面，视线沿走廊看向西面的滑车。车轮声逼近，林遥先把右脚向凹位里挪稳，右臂借护栏支撑，左手将把手向北后方拉；圆壳机器人受拉后转动前轮，壳体随轮组划弧退出车道，而非整壳被提起。圆壳机器人的后轮碰到低门槛时拉力短暂卡住，林遥的身体被带回一点，抓护栏的手收紧，左脚只跟着轻移，没有突然改用伤腿猛蹬；圆壳机器人轮组继续驱动爬过门槛，壳体轻晃后落稳。运货车沿原车道从林遥与圆壳机器人面前滑向东侧，没有撞上林遥与圆壳机器人。林遥这才放松拉把手的力，左手仍搭在圆壳机器人壳顶，右手继续承着护栏，胸背随着刚才用力后的呼吸慢慢起伏。镜尾圆壳机器人四轮都在凹位内，林遥主要压在右腿上，目光跟着离开的车确认路径已经让开，支撑关系不重置。已有顶灯沿圆壳机器人的壳体与林遥的手臂形成连续亮面，圆壳机器人滚进凹位时北墙遮住一部分顶光，林遥与圆壳机器人的遮影随实际移动变化。运货车轮声从西侧逼近再向东侧远去，圆壳机器人后轮磕槛与驱动声对应越槛过程，林遥用力后的呼吸留在近处。

【声音】
无对白，无BGM；脚步、轮组、拉拽与滑车的局部声按接触与距离发生，不另造拟声对白。

【不可出错】
林遥右腿主要承重，左踝限制继续存在；圆壳机器人沿四轮和壳顶把手机械结构行动；运货车沿既定车道向东通过；无字幕。
```

动作原因、发起、转向路径、接触、受阻反馈和新状态都留在一镜中。伤侧来自给定前提并持续影响承重；机器人通过轮组与壳体反馈表达，不凭空出现人脸或人类呼吸。

## C. 锁定静止、藏眼与无参考素材 · 4秒

设计前提：用户明确要求一个完全静止的背影等待镜头，不补人物小动作、不展示脸、不加对白。此例说明持续生命感不覆盖明确静止与心理不透明设计。

```text
【本段目标】
4秒，一条连续生成。
门外人物已经停在门外并保持等待，通过始终未拧动的门把与闭门关系延续尚未行动的处境；结尾继续保留是否进门的疑问。
克制的悬置——停在决定之前；是有意保持的不透明，不是解释内心或渲染惊恐。
低调写实成像，2.39:1，暗部保留走廊墙面层次，保持安静距离。

【参考绑定】
无外部参考素材

【空间】
同一夜间走廊，门外人物背对摄影机站在关闭的门外；门外人物姿态和摄影机按设计全程静止，脸与眼睛始终不可见。

【环境】
走廊顶灯给外套肩部留下稳定窄亮边，门与墙面明暗关系保持；背景安静。

【时间线】
【0:00-0:04】镜头1
50mm中景，摄影机在门外人物后方、胸高平视固定。起始画面中，门外人物的背影偏左、上身约占画高三分之二，右侧门框与门板承住画面，脸和眼睛不进入可见范围。门外人物已背对摄影机站在关闭的门外，右手停在门把上，身体与头均朝向门；这个等待姿态贯穿整镜，既不拧把也不转头。摄影机留在原处，不补手势、抖动或露出表情来解释迟疑。走廊已有顶灯在外套肩部形成稳定窄亮边，门与墙面的明暗关系保持不变。远处通风机的低声持续，门把未动所以没有额外金属声。

【声音】
无对白，无BGM；保留原走廊环境底声与本镜已定静默，不添加解释性声源。

【不可出错】
门保持关闭，门把尚未拧动；门外人物保持背对摄影机；原定静止与心理不透明持续；无字幕。
```

人物的世界目标清楚，但观众继续得不到面部心理信息。结构测试接受这份短而静的设计，不按动作数量或“表演占比”判劣。
