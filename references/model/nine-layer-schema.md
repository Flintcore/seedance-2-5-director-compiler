# 五部分连续镜头元模板 · 0.2.0

本文件是正式提示词格式的唯一主模板；历史文件名仅兼容引用。正式成稿采用五部分，不再装配九层、通用约束栏、本段情节、头锁或收尾卡。这是本 skill 的创作与交付约定，不当作已验证的模型切镜机制。

本文件只定义排版，不替代导演选择。输入分镜有新发现的实质目标/技术矛盾时，先沿 [设计判断](../../modules/design-judgment.md) 处理必要取舍；无问题或取舍已接受才沿当前设计编译，不新增最终自检。

## 正式骨架

一个连贯的4–30秒场景放在一个代码围栏里，其中可以有多个摄影机镜头。尖括号为填写说明，正式成稿替换为本段具体内容。

```text
【风格】
<摄影机/成像目标，胶片或数字质感，必要的画幅与色彩基线。无字幕，无BGM。>

【素材绑定】
@image1=<角色外观职责>；@image2=<场景空间与美术职责>。

【本段戏剧任务】
本段完成的核心变化是：<角色>从<原有处境>进入<新的处境>，并通过<明确动作或转折>完成推进；结尾观众应理解或感受到：这一变化对<人物关系、情绪或后续行动>产生了<具体结果>。

【本段情绪总控】
<主情绪一句话>——<节奏与温度>；<一句反面排除，明确这种表演与观看体验是什么、而非什么>。

镜头1｜0:00-0:06
<景别、焦段，摄影机相对明确主体的方位/高度/平仰俯；主体位于画幅哪一侧、约占多少，前中后景由哪些实体构成。从起幅沿什么路径以什么速度运动到什么落幅，或固定保持什么。人物以什么体态开始，关注谁或什么，事件怎样触发动作、表情、听说与同场反应，最后停在什么体态和关系；环境怎样响应，必要视效怎样发生。以上织成一整段连续画面。>光影：<此刻光源从哪里作用于谁/什么部位，数秒内因人物/水/风/烟/光源等实体变化怎样改变；静态条件则交代受光关系持续稳定>。现场声：<1–3种当前世界真实声源及其先后、远近或余响，无BGM>。
台词：<说话者与必要时机>说{逐字台词}

镜头2｜0:06-0:12
<本镜完整摄影机信息、构图、运镜和连贯表演；起点承接上一镜结束的世界位置、体态、持物、视线和动作相位，交代本镜结束体态。若为末镜，将最后0.5秒可复现的状态直接写在这里。>光影：<本镜受光关系及有实体原因的变化或稳定>。现场声：<本镜真实声源与延续状态>。
```

## 五部分的职责

1. **风格**负责全段成像目标与胶片/数字质感，需要时写画幅、调色与简短交付开关。摄影机型号是画面目标，不宣称视频实际由该机拍摄。无字幕、无BGM为默认开关，后来明确的文字/声音用户锁优先。
2. **素材绑定**固定保留。没有外部素材时写“无外部参考素材”，随后可交代必要的人物/场景设定，不伪造占位符。有素材则每个实际来源只出现一次规范占位符，职责合并；增补原稿保留编号。图片、视频、音频合计最多50份。原貌/服装/场景/预演/音色分别分工，见 [reference-assets.md](reference-assets.md)。静态设定不代替镜头内正在发生的空间关系。
3. **本段戏剧任务**保留上面的因果定义，讲本段实际完成的核心变化与观众落点，不复述参数，不引入其他生成段内容。
4. **本段情绪总控**贯穿全段：主情绪、节奏与温度，加一句有方向的情绪对照，例如“是屏住气的靠近，不是冲上去的对峙”。这是用户要求的表达边界，不延伸为画面错误、尺寸和身体部位的负面词清单。
5. **镜头序列**承担具体叙事。标题只有编号与起止时间，首镜从0:00开始、镜间连续、末镜结束于总时长。每镜一整段自然语言，技术与表演在同一画面链上；`光影：`、`现场声：`各成句并在段末。独立台词行可选，紧随其后。

## 完整分镜的要素

**摄影机参数＋运镜＋叙述性动作表演构成完整分镜。** 单看本镜能想象谁在哪里、看什么、动作怎样展开、关系怎样改变、最后留下什么。

- **景别与焦段**分别写清；焦距不自动决定景别。真实变焦与移动摄影机分开表达。
- **机位**明确相对于哪个角色、物品或场景，写前/后/左/右的1/4、正侧面、后侧3/4等方位和高度。人物自身左右与画面左右分开；高度是机身位置，平视/仰拍/俯拍是光轴方向。过肩机位与真正交谈对象分开定位。
- **构图**写主体画幅位置与大致占比、实体前中后层次、视线空间与焦点。占比服务成像，不增设像素审计；只描述实际入画层次，不为凑三层另造道具。
- **运镜**交代起点→路径→速度→终点与画幅变化；固定镜写固定起幅/落幅及镜内调度。承接机位仍保留本镜必要定位，不只写“同上”“按白模”。人物转身后相对观察方位可能改变，不机械重复标签。
- **表演**从起点体态、持物与关注目标开始，经已有触发、动作过程、微反应及同场联动落到结束体态。观察、暗示、留白也成立，不为凑变化新增事件。目光落到真正交谈对象，回避/走神有既定动机；按景别选细节，不逐镜堆眉眼嘴。
- **连续状态**前镜的结束世界状态就是后镜的开始状态：手位、朝向、脚步重心、接触和未完成动量不在切镜中重置。换视点可改屏幕投影，不改真实位置和视线目标。获准的跳时/跳空有明确转换。首末各0.5秒可读、可复现；持续运动可停在可接续相位，不强制冻结。

## 新建设计的镜头组风格

本次用户要求作为CREATE/重设计的具体创作合同执行：**相邻切镜换焦段，也换景别**，如中景转特写或全景；主主体采用偏心构图，非主体一侧由场内已有墙面、肩膀、门框等具体实体与纵深承接，不只写抽象空白。换焦段不替代景别变化、轴线和动作匹配，不因数字变化就声称剪辑自然。

这是当前所选写法，不改写影视库关于对称、正反打或长镜的通用判断。明确用户锁与确认L1优先；纯COMPILE/微调保留已定机位、居中设计及焦段，不偷偷重导演。一镜到底保持连续，不为相邻变化制造切镜或拆生成段。全面重设计才将本组约束用于新的镜头选择。

## 光影与现场声

每镜`光影：`同时写**此刻如何作用**与**镜内如何变化**。将光源、方向、受光部位、人物间反差、遮挡或反射写成可见关系。光的移动依附人物遮挡、水纹、烟尘、灯具等已有实体；稳定条件直接写受光关系稳定，不凭空加风、水、烟、频闪。机位变化只改观察关系，门下缝隙仍在门底，闭门/墙后物体按真实遮挡呈现。

稳定描述针对光源与宏观明暗关系；人物说话、眨眼、轻动仍会自然改变局部小阴影，不把固定光线写成每一处阴影全程冻结。有意藏眼、暗面、反射遮脸保留。角色目光目标与观众可见的眼部信息分开，不补光、转脸或加手势揭开已锁定的心理不透明，也不用“象征创伤”替代可拍载体。

每镜`现场声：`收1–3种本段世界实际声源，写来源与发生关系，不用BGM承担紧张/煽情。机位距离可改变响度、清晰度和混响，声源自身节律只因源头变化而改变。显式锁定静默时写清成立的静默，不造声源凑数。台词单列，不重复进声音清单；锁定旁白不冒充环境声。更晚的明确配乐要求在风格中声明例外，不塞进现场声。

## 独立台词行

用户确认`台词：宋佳说{逐字台词}`。花括号只放实际说出的原文，说话者、语气、时机、画内/画外/设备来源在外。正文交代何时开口、听者在做什么、话音落下怎样反应；逐字文本只在独立台词行出现一次。多人对话按发生顺序写，必要的“随后/与前句重叠/在某动作时”放在括号外；复杂时可用多条台词行，每句有说话者和落点。

无对白省去该行。旁白写`台词：旁白{逐字旁白}`；画外和设备声音保留来源，不绑定可见人口型。跨切同一句保留一个有范围说明的台词锚点或按原文连续切分，拼回完整原句，不在两镜重复全文。详见 [dialogue-binding.md](dialogue-binding.md)。

## 保真与轻量交付

只压缩语义重复措辞；动态锚点、光影/反射等表达关系按本镜理解需要保留。内部可用IR与动作合同，正式输出不含字段表、风险项、读库记录、字数/镜头配额、自检和额外尾卡。末状态写在末镜正文，提示词结束于末镜现场声或台词行。

完整范例见 [shot-prose-example.md](shot-prose-example.md)，仅在学习/维护写法或需范例时读取，普通每轮不额外加载。
