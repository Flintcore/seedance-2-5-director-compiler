# Seedance 2.5 原生分镜提示词格式

本文件保留 `seedance-agent-2-5` 已验证的成片写法：通用设定先行，镜头只保留编号和时间码，随后用一行技术声明和一段按画面发生顺序组织的自然语言。文件名保留为兼容路径；正式提示词不再输出九层区块。

## 输出顺序

单一连贯场景默认只输出一个生成片段；一个生成片段可以包含多个镜头块、动作节拍和剪辑。只有通过生成段边界闸门时，才为多个生成片段分别输出以下顺序，并将每段放进独立的代码围栏：

1. `【通用约束栏 · 本 segment 共享】`
2. `【本段戏剧任务】`（本版唯一新增区块）
3. `【本段情节】`
4. 连续的 `【镜头N】| M:SS-M:SS` 镜头块
5. `【收尾约束】`

镜头块按时间顺序连续排列。头锁、元信息、风险预判、衔接卡、时间线卡、参考图权重和执行检查表属于内部设计或旧格式，不进入成片提示词。

## 正式模板

```text
【通用约束栏 · 本 segment 共享】
─ 素材绑定：@image1=角色或场景参考图（内容描述）· @video1=动作或运镜参考（内容描述）· @audio1=角色或环境声音参考（内容描述）
─ 光影色彩风格：{影像载体、摄影机画面质感、画幅、景深、光源方向、色彩关系、空气质感和环境声底；按需要写}
─ 角色外观：{没有足够素材锚定时，写当前片段可见角色的外观与状态}
─ 场景外观：{当前片段需要稳定的空间、材质、天气和光源事实}

【本段戏剧任务】本段完成的核心变化是：{角色}从{原有处境}进入{新的处境}，并通过{明确动作或转折}完成推进；结尾观众应理解或感受到：这一变化对{人物关系、情绪或后续行动}产生了{具体结果}。

【本段情节】{用大白话概括本段从开始状态到结束状态的事件变化，不复述镜头技术}

【镜头1】| 0:00-0:03
{有切镜方式时先写切镜声明；接着用一句短技术声明写景别、镜头、俯仰和机位位置。}
{从当前画面构图和人物关系开始，按“触发→动作过程→联动反应→对白/声音落点→运镜与焦点→结果和下一切点”的自然时间顺序织成一段可直接想象的连续叙事。人物可见且承担本镜变化时，先交代视线或注意力落点与时机，再按需要用最能读懂的自然行为或面部微反应承接；按景别取舍，不堆面部部位。对白写成角色ID说{逐字台词}，音效写成<具体音效>，音乐写成（背景播放具体音乐），都放在实际发生处。}

【镜头2】| 0:03-0:06
{切镜/技术声明（需要时）}
{以本镜新增事件为主，同时保留本镜可视化所需的动态关系、上一镜结果、必要位置和动作相位；只省略不影响理解的静态事实。}

{继续添加镜头块，直到本段结束。}

【收尾约束】{最后0.5秒的稳定构图、人物/道具状态、动作相位和声音尾；只写已确认的生成约束。}
```

## 镜头级连续画面叙事

镜头块是一个可独立想象的视觉事件单元，不是把 `image_action`、`staging`、`performance`、`sound` 和 `transition` 逐项排成字段清单。编写时先在内部形成一条连续画面链，再把各字段织回同一段自然语言：

`当前构图与空间关系 → 触发 → 主动作过程 → 同场联动或反应 → 对白/声音发生处 → 运镜与焦点跟随 → 结果、落幅与下一切点`

这是一条软顺序，不要求每镜机械填满每一项；只有锁定设计里确有对应触发、动作或反应时才写出该事件，观察、停留或连续状态镜头就写清当前进行中的状态、注意力和张力，不凭空增添剧情。要求读者只看当前镜头正文，就能还原谁在哪里、正在看什么、事件怎样被触发（若有）、动作怎样完成（若有）以及镜头结束后留下什么。通用栏和本段摘要负责导航，具体动作、反应、对白位置、空间关系和切换动机必须落在对应镜头正文。人物左右/前后位置、视线目标、持物、动作相位和仍在发生的背景联动属于动态锚点，按理解需要重复；已经稳定且本镜不影响理解的外观、光色或技术基线才适合压缩。

同一空间和机位可以用“此时、同时、看到后、就在这时、随后”等连接词承载连续节拍。观察或停留镜头可以明确写出动作、声音或注意力仍在持续、此处不切；切镜只有在视点、信息、关系、表演/注意力状态或动作中心真正改变时才发生，并在正文中写出切换前的结果与切换后的首个可见状态。

## 填写规则

- 通用栏只放当前片段共享的事实；按需保留行，不为凑字段填空。没有参考素材时直接省略 `素材绑定` 行。
- `【本段戏剧任务】` 是新增的语义入口，标题后直接接一条完整因果句：角色从原有处境进入新的处境，由明确动作或转折完成推进，并交代结尾观众应理解或感受到的关系、情绪或后续行动结果。把 `objective/turn/audience_landing` 压成这一条可拍、可验证的段内变化，不写分析过程、评分或检查结论。
- `【本段情节】` 标题后直接接正文，只讲当前片段的起点、变化和终点，不写上一段、下一段或内部编号。
- 镜头标题只用编号和起止时间。景别、焦距、俯仰、距离、机位、切镜方式和运镜写在镜头块的技术声明或连续散文中，不另开抽象标签。
- 镜头正文采用连续的大白话：先立构图和动态关系，再把触发、动作过程、表演、联动反应、对白/声音、运镜、焦点和落幅写成一条因果叙事。按画面发生顺序组织，不拆成一串字段；动态锚点按需重述，静态基线只在本镜有变化或确实影响理解时重述。人物承担戏点时，优先保留注意力/视线锚点，并按需要带出最有证据力的自然表演载体；远景用姿态、距离、朝向和节奏承载，近景才在有因果时加入面部微反应。
- 视点和情绪通过谁在看谁、机位高度、距离、遮挡、构图和运动体现，不打印“旁观者/审视”等 L1 态度标签。
- 动作模式的战术因果、方向、接触、惯性、逐拍时刻和反馈全部织入对应镜头正文，不另起动作格式。
- 花括号内只放逐字对白或旁白：`角色ID说{逐字台词}`、`旁白{逐字旁白}`。语气、口型、位置、听者反应和声音来源写在花括号外。
- 片段时长保持 `4-30s`；第一镜从 `0:00` 开始，最后一镜结束于总时长。首 `0.5s` 与末 `0.5s` 保持可复现状态，用户明确设计冲击或断裂时按设计表达。
- 图片、视频、音频参考合计最多 `50` 个。去重后按媒体类型和首次出现顺序编号：`@image1`、`@video1`、`@audio1`。
- 每个素材占位符只在通用栏的 `素材绑定` 行出现一次；同一素材的职责、内容描述和作用范围合并在该行。镜头正文使用语义名称，不再次写占位符。
- 素材行不写本地路径、文件名、URL、上传标签或平台原始 ID。占位符只是便于用户替换的工作记号，不表示平台已经完成绑定。
- `【收尾约束】` 标题后直接接正文，是段级排除和结尾状态的唯一归位处：在项目确有需要时集中写字幕、叠加文字、水印、音乐或其他排除项，同时写最后0.5秒的稳定状态。正式提示词到此结束，不追加自检、评分、报告、读库记录或过程说明。

## 内容归位

| 内容 | 正式提示词位置 |
|---|---|
| 素材职责和一次性占位符 | `【通用约束栏】` 的 `素材绑定` 行 |
| 光影、色彩、摄影机画面质感 | 通用栏对应自然语言行 |
| 当前片段的核心变化 | `【本段戏剧任务】` |
| 当前片段的事件概括 | `【本段情节】` |
| 每镜画面、表演、机位、运镜、对白和声音 | 对应 `【镜头N】` 块 |
| 结尾稳定状态和已确认约束 | `【收尾约束】` |

编译器内部仍可使用 Director IR、连续性状态向量和动作合同；这些是推理材料，不复制到正式提示词。
