# 六部分连续镜头元模板 · 0.5.10

本文件是正式提示词格式的唯一主模板；历史文件名仅兼容引用。正式成稿采用六部分，恢复简短的【全局约束】，不恢复九层、旧通用约束表、本段情节、头锁或收尾卡。这是本 skill 的创作与交付约定，不当作已验证的模型切镜机制。

本文件只定义排版，不替代导演选择。输入分镜有新发现的实质目标/技术矛盾时，先沿 [设计判断](../../modules/design-judgment.md) 处理必要取舍；无问题或取舍已接受才沿当前设计编译，不新增最终自检。

## 正式骨架

一个连贯的4–30秒场景放在一个代码围栏里，其中可以有多个摄影机镜头。尖括号为填写说明，正式成稿替换为本段具体内容。

```text
【风格】
<摄影机/成像目标，胶片或数字质感，必要的画幅与色彩基线。>

【素材绑定】
@image1=<角色统一名称与外观职责>；@image2=<场景空间与美术职责>。

【全局约束】
<只写本段共用且已成立的场景/时空、角色身份与外观、相容的尺寸比例、固定场景几何和声音/字幕要求；需要时加开场空间基准：谁相对桌、门等实体站在哪里、朝向谁、持有什么，只约定开场，后续随已写走位更新；明确例外注明作用范围。用角色/场景语义名称，不重复@。默认无字幕、无BGM，明确用户要求优先；确无额外共用条件时写“无额外全局约束。”。>

【本段戏剧任务】
<本段通过什么行动或转折，从什么处境进入什么处境；有意维持原状时说明延续的关系或疑问。>
<按需补入真正影响本段表演的角色目标、顾虑或认知、应对策略及变化。简单场景与前句自然合并；不同立场需要分清时，用角色统一名称分行讲戏，不逐人填表。>
<结尾观众应理解或感受到的关系、情绪或后续行动结果，以及有意保留的不确定。>

【本段情绪总控】
<主情绪一句话>——<节奏与温度>；<一句反面排除，明确这种表演与观看体验是什么、而非什么>。

镜头1｜0:00-0:06
<焦段><景别>，<摄影机相对主体的方位、高度、俯仰及固定/运动起势>。起始画面中，<谁/什么位于画幅哪里、大致占幅与必要纵深，人物起点体态、视线、持物/接触及已经在做的事；从本机位明确可见的初始构图>。<按时间连贯展开人物动作、表情与对手反应；有对白时写成：角色以既定语气说：“本镜实际听到的连续原文片段”；情绪与动作默认在引号外。运镜/焦点的路径、速度和落点随事件发生，保留接触、阻力及环境反馈>；<本镜结束体态、持物与注意力落点，以及确有下一镜时的已定切镜衔接>。光影：<此刻光源怎样作用于人物/环境，随已成立实体如何变化或保持稳定>。现场声：<1–3种真实声源及先后、远近或余响，无BGM>。

镜头2｜0:06-0:12
<本镜焦段><景别>，<本镜相对机位、高度与俯仰，简洁说明固定或运动起势>。起始画面中，<从本镜新视点看见的主体与空间；承接前镜世界位置、体态、持物/接触、注意力、行动或未说完的话>。<人物持续做事/听看，接收刺激后作出相容变化；若承接前镜对白，点名原说话者与画内/画外来源，在本镜写出实际续说的连续原文片段，声音不因切镜重起；运镜与行为同步展开>；<结束状态与需要的镜间衔接；若为末镜，将结束时的余态收在这里，不引入下一镜>。光影：<本镜受光关系及有实体原因的变化或稳定>。现场声：<本镜真实声源与延续状态>。
```

## 六部分的职责

1. **风格**负责全段成像目标与胶片/数字质感，需要时写画幅与调色。摄影机型号是画面目标，不宣称视频实际由该机拍摄。交付开关集中到全局约束，不在两栏重复。
2. **素材绑定**固定保留。没有外部素材时写“无外部参考素材”，不伪造占位符；共用人物/场景事实另入全局约束。有素材则每个实际来源只出现一次规范占位符，职责合并；增补原稿保留编号。图片、视频、音频合计最多50份。原貌/服装/场景/预演/音色分别分工，见 [reference-assets.md](reference-assets.md)。静态设定不代替镜头内正在发生的空间关系。
3. **全局约束**固定保留为简短自然语言，只提炼已有用户要求、确认设计与素材事实中本段共用的条件：场景/时空、身份外观、相容的实体尺寸、固定场景几何、字幕及声音交付要求；明确例外写出适用范围。无字幕、无BGM为默认开关，后来明确的文字/声音用户锁优先；保留剧情内既定文字与声源。无额外条件则写“无额外全局约束。”，不凑条目、不造设定。此栏用语义名称，不重复素材占位符；不是新增L1锁表或头锁区，也不是身体错误负面词表。
4. **本段戏剧任务**同时交代本段核心变化、相关角色的动机心理与策略、观众落点，是给模型的简洁导演讲戏，不限一句。保留剧本与确认设计中会影响本段行动、说听、注意力或关系变化的目标、顾虑、认知与表里差异；有心理转折时交代触发与方向，不只贴情绪标签。简单关系可合并为自然段；多个立场确有区别时按角色统一名称分行，不要求全员出现或逐项填写，不设字数配额。无需心理说明的纯环境、简单动作或有意不透明段落可只保留已定事件与观看意图。具体边界见下方，不另加顶层栏目。
5. **本段情绪总控**贯穿全段：主情绪、节奏与温度，加一句有方向的情绪对照，例如“是屏住气的靠近，不是冲上去的对峙”。这是用户要求的表达边界，不延伸为画面错误、尺寸和身体部位的负面词清单。
6. **镜头序列**承担具体叙事。标题只有编号与粗略起止时间，首镜从0:00开始、镜间连续、末镜结束于总时长；标题作剪辑预算，不承诺模型精确切点，不向正文细分秒数。每镜一整段自然语言，技术与表演在同一画面链上；`光影：`、`现场声：`各成句并在段末。逐字对白直接嵌入人物开口处，以中文双引号包住，情绪与动作默认在引号外；无独立台词行。

全局栏归纳共享条件，也可用简短开场空间基准标明人物相对门、桌、通道的初始站位、朝向及关键持物/接触。此基准只约定开场；实际走位、接触、视线、动作相位和状态变化仍在对应镜头完整叙述，必要锚点可以自然重述。固定的是已有世界几何与明确连续条件，不是人物整段脚位和画面占比；坐下、靠近、交接或变形按已定事件及作用范围展开。正文的比例、承托与构图须共同成立，全局尾句不能修补互相冲突的描述。旧稿的共用设定从风格/素材说明中最小迁移到这里，素材职责仍留素材绑定，事件仍留镜头；不为填栏扩写故事或重跑读库。

### 戏剧任务中的心理与逐镜表演

此栏回答角色为什么行动、想从谁那里得到什么；情绪总控回答整段观看体验的节奏与温度，不要求所有角色同一种情绪。镜头正文仍让当下的行动、语气、视线、听说接收及结果连贯发生，关键意图可以就地自然带出；段级讲戏不替代镜内过程，也不逐镜重抄全套心理。动机不必一一译成眨眼、抿嘴等部位指令，更不因此延长镜头或放慢动作。

只沿用剧本、用户讲戏和确认设计的依据：角色的希望、怀疑或误判仍属于角色认知，不升级成世界事实；角色在后面才得知的信息不提前指导当前反应。表面策略与真实感受可有落差，给模型说明心理不等于让观众看穿心理。尚未揭露且本段表演不需要的秘密留在设计层；必要的隐藏动机则与已定表面策略、藏露程度一起表达，不新增心虚、坏笑或闪躲来泄密。未知内心保持留白，不为丰富补写身世、创伤、秘密或招牌习惯。

这里只承接确认内容，纯编译不另造动机；缺失信息只有在实质影响设计时才沿已有判断流程处理，不加心理确认轮、独立人物卡或最终自检。模板是写作约定，不宣称模型理解或表演效果已被验证。

## 角色统一名称与动作归属

正式提示词以素材绑定和用户设定中的同一角色名称贯穿全段：绑定“小明”后，每个新句、跨镜起态和发声提示继续写“小明”，不换成“他/她/它/自己/对方/前者/后者”等人物代指，也不轮换成“男主”等别名。多个素材服务同一角色时沿用同一名称；无姓名者沿用用户已给的稳定称谓，未知身份保持“门外人物”等既定称谓，不杜撰姓名或输出内部角色编号。

- 不只明确主语：视线落点、交谈对象、动作接受者，以及手脚、武器、持物、呼吸和画外声音的归属都点到对应角色；机位、光影和现场声中同样沿用统一名称。例如“小明看向小雨。小明握住小雨的右手”，不让“小明握住自己的手”或“看向对方”承担关键绑定。
- 同一句中已点名且主体不变的连续谓语可以共享主语，如“小明抬手，握住门把，推开门”；转到另一角色就重新点名。多人动作列出参与者或沿用已定义且成员明确的群体名称，不用含混的“他们”掩盖参与范围。实体、倒影、影子与屏幕形象仍区分为“小明”“小明的倒影”等，不因姓名化合并成一个实体。
- 实际逐字对白、旁白与画面文字保留原有“我/你/他/自己”等用词；只改引号外的叙述归属。新增的 `【非发声表演说明】` 是指令而非台词，也使用角色统一名称；原文确实要念出的括号文字仍逐字保留。姓名化不改说话人、不替换原词、不重分已锁跨镜片段。
- 名称重复不等于素材重复：`@imageN/@videoN/@audioN` 仍只在素材绑定出现一次，正文直接写名称。若原材料的指代本身存在实质歧义，先定位待确认归属，不擅自指定动作主体。

这是编译时直接采用的写法，不增加姓名表、字段、整库禁词扫描或生成后的自检；教学讲解中的泛称不是最终提示词。

## 完整分镜的要素

**设计以人物事件为重点，成稿以摄影参数和起始画面开头。** 正文顺序是“摄影参数开头 → 起始画面 → 连续人物事件与运镜 → 结束状态及必要切镜衔接”。先让读者确定从哪里看、第一眼看到什么，再跟随人物做事、听说与反应；摄影开头保持简明，主体篇幅仍用来讲清人物过程。它们在同一自然段内，不拆字段表，也不要求逐镜照抄“起始画面中”这几个字。有意静止、空镜与延迟揭示沿已定设计写可见内容；长镜和末镜保持自己的收束。没有摄影/表演字数比例、微动作数量或固定短语配额。

- **景别与焦段**分别写清；焦距不自动决定景别。真实变焦与移动摄影机分开表达。
- **机位**明确相对于哪个角色、物品或场景，写前/后/左/右的1/4、正侧面、后侧3/4等方位和高度。人物自身左右与画面左右分开；高度是机身位置，平视/仰拍/俯拍是光轴方向。过肩机位与真正交谈对象分开定位。
- **构图**写主体画幅位置与大致占比、实体前中后层次、视线空间与焦点。占比服务成像，不增设像素审计；只描述实际入画层次，不为凑三层另造道具。
- **运镜**交代起点→路径→速度→终点与画幅变化；固定镜写固定起幅/落幅及镜内调度。承接机位仍保留本镜必要定位，不只写“同上”“按白模”。人物转身后相对观察方位可能改变，不机械重复标签。
- **表演**从正在持续的做事、听看、支撑或持物开始，明确已有目标/策略如何在刺激处变成动作、听说互动和同场反应，再落到余态；人物不在关键拍点之间冻结。目光落到真正对象，回避/走神沿既定动机；按可见性与身体结构取舍，隐眼、非人、空镜或有意静止保持各自设计，不硬加眉眼嘴。
- **连续状态**前镜的结束世界状态就是后镜的开始状态：手位、朝向、脚步重心、接触和未完成动量不在切镜中重置。换视点可改屏幕投影，不改真实位置和视线目标。获准的跳时/跳空有明确转换。开场与结束状态可读、可接续，不分配固定停留时值；持续运动按相容相位接续，不强制冻结。

## 镜内事件时序与构图承接

**正文不用秒来排班。** 镜头标题只留粗略时长安排；正文、光影/现场声句及非发声表演标注不写“第几秒开始”“0:02–0:03做什么”“首末0.5秒”或定长微动作。用实际触发串联：“听到名字时”“这句话由试探转为坚持”“手碰到门把后”“重击落下，摄影机随受力方向跟进”。对白按原词、语义停连与情绪变化落位，动作、运镜、光声按实体因果和先后/同时关系展开；不把秒表改成逐拍配额，也不为去掉秒数删除有意义的停顿。

内部L1的时长估算、已测源音画时间码、剪辑工程和Blender关键帧仍可保留精确时间，仅作工具/设计依据；编译时转为事件关系，不把时钟指令抄进正文。原对白、画面文字或实际计时器里的时间数字属于剧情内容，逐字保留；焦段、机位方位、快门曝光时间和必要空间尺寸也照常保留，它们不是动作执行的秒数排班。读到知识库的历史注视时长/表演配额时，提取其因果用途，不移植成正文时值。

**构图从世界状态推导，不用画面左右代替真实站位。** 前镜结束世界状态 → 新机位、朝向与取景 → 本镜起始构图。明确实际入画的人/物在哪一侧、谁前谁后、遮住什么、看向谁，以及承接的动作相位；只写本镜相关可见关系，不凑三层或固定占比。切镜只改变观看，人物继续占据已有世界位置；走位、转身、交接或损坏已经发生，就继承更新后的状态，不跳回开场基准。画外人物仍存在于既定位置。

同侧轴线通常维护关系方向的可读性，不等于人物永远在同一屏幕坐标。双人同框的左右相对次序，与单人反打的偏心摆位是不同问题；取景与观察方向改变时，依据真实几何重新描述，不以复制“始终画左”代替推导。

## 新建设计的镜头组风格

本模板负责把导演已经选择的摄影方案写清，不从排版反向规定相邻焦段、景别或主体位置。新设计沿 [镜头导演法](../../modules/shot-design.md#按观看需要选择镜头组) 根据主导信息、表演和空间关系选择覆盖。

同焦段/同景别反打、中心或偏心构图、持续观察和动作中切换均可按用途选择。焦段与景别分别表达，保持真实位置、轴线、动作相位和关注对象可理解；参数变化本身不是剪辑成立的依据。动作的触点、受力与后果按 [动作设计](../../modules/action-design.md) 保持连续，运动可以穿越画心。

明确用户锁与确认L1优先；纯COMPILE/局部格式微调保留已定机位、构图及焦段。一镜到底保持连续，不为变化制造切镜或拆生成段。六部分、摄影开头与逐镜自然段的书写格式保持。

## 光影与现场声

每镜`光影：`同时写**此刻如何作用**与**镜内如何变化**。将光源、方向、受光部位、人物间反差、遮挡或反射写成可见关系。光的移动依附人物遮挡、水纹、烟尘、灯具等已有实体；稳定条件直接写受光关系稳定，不凭空加风、水、烟、频闪。机位变化只改观察关系，门下缝隙仍在门底，闭门/墙后物体按真实遮挡呈现。

稳定描述针对光源与宏观明暗关系；人物说话、眨眼、轻动仍会自然改变局部小阴影，不把固定光线写成每一处阴影全程冻结。有意藏眼、暗面、反射遮脸保留。角色目光目标与观众可见的眼部信息分开，不补光、转脸或加手势揭开已锁定的心理不透明，也不用“象征创伤”替代可拍载体。

每镜`现场声：`收1–3种本段世界实际声源，写来源与发生关系，不用BGM承担紧张/煽情。机位距离可改变响度、清晰度和混响，声源自身节律只因源头变化而改变。显式锁定静默时写清成立的静默，不造声源凑数。台词在正文发声位置出现，不重复进声音清单；锁定旁白不冒充环境声。更晚的明确配乐要求在全局约束中声明例外及作用范围，不塞进现场声。

## 正文内联对白

当前用户约定是：`宋佳抬眼看着大胃袋星人，语气放缓地说：“逐字原文”`。实际对白在开口位置以中文双引号包住，与动作、视线、听者反应处于同一段自然叙述。情绪、表情、动作和语气默认在引号外，短对白保持干净；长对白也不是自动加标注的理由。

只有长对白内部确有需要准确定位的停顿、情绪转折或重要动作时，才用条件子例这样的写法：`角色说：“前半段原文，【在这里停顿，笑意收住，后半句语气转冷】后半段原文。”`。`【】` 内只放非发声的表演说明，移除它后的实际台词须与锁定原文（含标点）逐字一致。不设字数阈值、不逐句套表情、不嵌套标注；原台词本来就有引号或书面标记时先保留其原文意义，不把原词误当指令删掉。

无对白不增加占位。多人发声逐次明确角色与发生时机，不为切换说话者强制切镜；旁白、画外与设备声写明真实来源，不绑定给画内听者的嘴。普通引文如纸条写着“请关门”属于画面文字，不自动读出。跨切同一句按实际切点分配连续原文，各镜都在正文写出本镜实际听到的片段并明确原声源；后镜仅写“声音继续”不足以代替续句，首镜也不预写后镜词。片段按序拼回完整原句（含标点），不为切镜新增停顿、省略号或句号；声音与表演连续，听者只回应已听到的内容。单镜边说边运镜保持同镜发声，无需人为拆句。详见 [dialogue-binding.md](dialogue-binding.md)。

这些标点是本地写作与维护约定，替代此前独立行与花括号格式；不是平台字段或生成效果保证。

## 保真与轻量交付

示例中的6秒镜头标题仅示意时码格式，不是默认镜长、最短镜长或快打的单招时长。因果可跨多个短镜头成立；对白自然发声时间、交锋动作密度、运镜速度和必要的意义停留各按本场分配。结构范例中的缓慢、静止和余韵不自动迁到高速动作。

只压缩语义重复措辞；动态锚点、光影/反射等表达关系按本镜理解需要保留。内部可用IR与动作合同，正式输出不含字段表、风险项、读库记录、字数/镜头配额、自检和额外尾卡。末状态写在末镜正文，提示词结束于末镜现场声句。

完整范例见 [雨夜走廊](shot-prose-example.md) 与 [对白声桥/非人动作](character-event-examples.md)，仅在学习/维护写法或需范例时选择相应例子，普通每轮不额外加载。范例和维护测试展示文本结构，不证明模型生成效果。
