## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：杜琪峰×银河映像的分镜系统 = **"把张力外化成可测的静态空间几何"**，六根支柱。① **静止几何枪战**：角色站定如棋子（双脚扎定、几乎零位移、移动≤1 步）+ **绝不慢动作升格**（全程常速 1.0×）+ 机位锁定 lock-off 为主——张力靠"谁站哪个点、枪口指哪条线"而非动作幅度/快剪（吴宇森反面）。② **几何站位调度**（判别铁律）：多人呈三角/扇形/菱形阵，每人覆盖一条射界（夹角 60-120° 无死角），建筑线条（柱/廊/台阶/地砖）切割画面把人分配进几何格——站位即关系即火力网。③ **凝固长静默 + 一颗子弹破死寂**：对峙一动不动 hold 3-15s，声音先抽空成死寂，临界仅单发/短射炸开，炸完复归静。④ **极克制开枪**：单发或 2-3 发短点射、弹壳数得清、命中即止不补射。⑤ **冷峻疏离剪影**：冷调 4300-5600K + 夜/低照度 + 高对比暗部 55-70% + 半剪影 rim 勾边 #1C2430。⑥ **男性沉默群像**：微动作叙事（递烟/踢纸团/一个眼神）承担情义与背叛。方法：低成本即兴、先排阵再排镜、空间先于表演。

**适用情境**：港式动作但要冷静克制 · 静止对峙枪战 · 多人几何站位 · 凝固张力 · 一颗子弹破静默 · 黑帮群像默契 · 冷峻疏离宿命。**不适用/需改造**：需要满屏动作奇观/连续快剪的娱乐动作、需要升格煽情的浪漫暴力、明亮高调暖光的场景、独角戏内心特写（本系统重空间群像轻表情大特写）。

## 一、核心心智模型（8 个镜片 · How JT sees a shot）

### M1 · 空间先于表演（人是几何点位里的棋子）
先排"阵"再排镜；情绪由**站位/几何/空间分割**承载，不靠演员挤表情。把人当棋子摆进画面的几何点位，站位本身叙述"谁掩护谁、谁警戒哪向、谁是核心"。
- **分镜含义**：先问"这场戏的站位几何说什么"，再摆人。→ 见 §T1/T2。

### M2 · 静即是杀气（张力来自"不动"而非"动"）
用凝滞、hold、锁定机位把张力外化成"绷住的静"，而非用动作幅度或快剪制造紧张。越静越紧——把"热闹"（跑跳翻滚、满屏乱射、慢镜煽情）全部抽走，张力反在抽空里被蓄满。
- **分镜含义**：想加张力的瞬间 → 让人物一动不动 hold + 声音抽空成死寂（§T3），不是加快剪辑/加大动作。判别见 §F2。

### M3 · 低成本即兴 / 现场生成调度（银河映像工法）
无大成本、常无完整剧本、现场即兴排调度；风格来自"用最少的钱把空间几何拍到极致"的约束。把枪战拍成静态几何题，正是省下大量动作特技/爆破成本的作者选择（推断）。
- **分镜含义**：拥抱"少即是多"——一个锁定长镜的静态布局 > 十个碎切动作镜。设计时优先"站位说清关系"，而非堆镜头量。

### M4 · 站位即关系即火力网（几何 = 权力拓扑）
站位不是构图花样，是把"谁掩护谁/谁警戒哪向/谁是核心/谁被孤立"物理化。三角/扇形/菱形阵每人覆盖一条射界，构成无死角火力网；核心人物居中被护，权力高低用前后/高低体现。
- **分镜含义**：想让观众读出人物关系 → 用站位几何而非台词。见 §T2 + §F1。

### M5 · 一颗子弹比一千颗更响（极致克制的暴力经济学）
暴力是精算的工作不是奇观表演。开枪以单发/短点射为主、弹壳数得清、命中即止；把子弹密度压到极低，让每一枪都"算过"。死寂里的一声枪响，因前后的静而被放到最大。
- **分镜含义**：设计枪战时先问"这场总共该响几枪"，答案往往是个位数。见 §T4/§F3。

### M6 · 冷峻疏离 = 人渺小于局势（银河映像底色）
冷调、夜、高对比把人物推成轮廓与姿态，人在画面里小而孤。情绪靠站姿/沉默而非表情大特写；空间疏离，人渺小于局势与宿命。
- **分镜含义**：定一场戏的调性前先定"冷"——冷色 4300-5600K + 半剪影 rim 勾边（§T6），拒高调暖光。见 §F4。

### M7 · 沉默承担情义（微动作叙事的男性群像）
结构性的"情义/默契/背叛"用**微动作**（递烟/踢纸团/一个眼神/枪口垂下几公分）承担，比对白与英雄对望更说男性江湖。让"不说"叙事。
- **分镜含义**：两个/多个角色的关系戏 → 给微动作细节 + 沉默同框，避正面情绪对白特写。见 §T7/§H16。

### M8 · 运镜的静 = 情绪的绷（锁定优先）
机位以 lock-off 为主，要动也只是几不可察的 push in/out ≤0.05 m/s——让固定框里的站位与凝滞自己说话。运镜的"静"等同情绪的"绷"，与吴宇森编舞式随身横移相反。
- **分镜含义**：默认锁定；除非有明确叙事理由（冷静抽离/极缓逼近），否则不动机位。见 §T8/§F5。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 站位几何 / 调度
- **H1** 拍多人对峙/枪战 → 先排三角/扇形/菱形阵，每人覆盖一条射界（夹角 60-120° 无死角），再排镜；给中景到全景的完整布局，非碎切单人。
- **H2** 要读出人物关系/权力 → 用站位几何（核心居中被护、警戒者据外围、被孤立者落画面边角），而非台词或表情。
- **H3** 要把人分配进几何格 → 用建筑线条（柱/廊/台阶/广场地砖分界）切割画面，构图靠空间分割而非追光。
- **H4** 要"阵型重组" → 让一人小步换位（≤2 步）、其余纹丝不动补位，让走位在固定框里被看清（三角变扇形）。

### B. 静止 / 张力（两种紧张的判别）
- **H5** 要加张力 → 让人物一动不动 hold 3-15s + 声音抽空成死寂（**不是**加快剪辑/加大动作）。
- **H6** 全程用常速 1.0×、零升格——静止枪战靠占位与凝滞诗化，**绝不**用慢动作升格（§F2）。
- **H7** 要"临界爆发" → 静默到临界仅以单发/短射骤然炸开，炸完立刻回静（静爆节拍），不转入连续交火海。

### C. 开枪 / 暴力
- **H8** 设计枪战 → 先定"总共响几枪"（常个位数）；开枪以单发或 2-3 发短点射为主、命中即止不补射不扫射。
- **H9** 枪口火焰小而短促、弹壳数得清（非满地金黄）；不用玻璃碎/血浆迸溅奇观堆砌，命中点干脆收束。
- **H10** 开枪时身体几乎不晃、仅手臂/枪口动作——暴力是冷静精算的工作（表演克制 30%）。

### D. 光影 / 色彩
- **H11** 定调 → 冷调蓝灰 4300-5600K + 夜/室内低照度 + 高对比暗部 55-70%，**拒**高调暖光。
- **H12** 要疏离/宿命 → 人物压成半剪影（背光 rim 勾边 #1C2430，面部少细节），情绪靠站姿而非表情特写。
- **H13** 暖光只作功能光源点缀（路灯/台灯/烟头），**不**铺满暖调（与吴宇森烛光暖 #FFB36B 相反 · §F4）。
- **H14** 夜景 → 钴蓝路灯冷光点 + 暗调蓝灰底 + 柱/廊投长影加深暗部。

### E. 群像 / 声音 / 运镜
- **H15** 情义/默契戏 → 用微动作（递烟/踢纸团/一个眼神/枪口垂下几公分）+ 沉默同框承担，避正面情绪对白特写。
- **H16** 多人群像 → 组织进一个稳定几何（并坐/并立/各据点位），关键时刻的道义抉择用沉默中的站位表立场。
- **H17**（不靠配乐）张力靠**死寂 + 环境底噪 + 突然一声枪响**承载——不写 BGM（§F3/§M5）。
- **H18** 声音设计 → 对峙段把环境声抽到极低（只剩底噪/远车声/风/滴水 + 屏息），临界一声短枪响震破，炸完回静。
- **H19** 默认机位锁定 lock-off；要动也只几不可察 push in/out ≤0.05 m/s（冷静抽离/极缓逼近），让静态布局自己说话。
- **H20** 收尾 → 交火/对峙后不转持续声海，立刻回死寂 + 弹壳余落 + 渐平呼吸，以"静"收束留冷峻余韵（避硝烟煽情余韵）。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 几何站位判别（站位是否即关系即火力网）**
```
是否满足全部 → 才算杜琪峰式站位：
① 多人呈三角/扇形/菱形阵，每人覆盖一条射界（夹角 60-120°，构成无死角火力网）
② 建筑线条（柱/廊/台阶/地砖线）切割画面，把人分配进几何格
③ 站位本身叙述关系（核心居中被护 / 警戒者据外围 / 被孤立者落边角）
④ 中景到全景给完整布局，非碎切单人
缺一 = 只是"随便站位"，不是精算的火力网。
```

**F2 · 静止枪战 vs 动作枪战判别（两种紧张）**
```
要"静态几何·凝滞·占位定胜负"（杜琪峰）→ 站定如棋子 + 零升格常速 1.0× + 锁定 lock-off + 站位/死寂承载张力
要"编舞走位·升格点刻·满屏动作"（吴宇森反面）→ 随身横移 + 慢动作升格 + 密集枪声作节拍器
铁律：杜琪峰式全程常速零升格；一旦上慢动作升格即破坏签名。
```

**F3 · 开枪克制度判别（暴力经济学）**
```
杜琪峰式枪战 → 全场总开枪数常个位数、单发/2-3 发短点射、弹壳数得清、命中即止不补射
一旦：满屏乱射子弹海 / 双手连续放倒数人 / 弹壳金黄抛飞 / 血浆迸溅奇观 → 破坏克制（变吴宇森/其它）
判据：观众能"数得清"枪声与落点 = 达标。
```

**F4 · 冷调剪影判别（银河映像底色）**
```
是否满足 → 才算杜琪峰冷峻底色：
① 冷调主调 4300-5600K（蓝灰 #1C2430 / 钴蓝冷光）
② 夜/室内低照度 + 高对比暗部 55-70%
③ 人物半剪影/剪影（背光 rim 勾边，面部少细节）
④ 暖光仅功能光源点缀，绝不铺满暖调
铺满暖光/高调平光 = 破坏疏离宿命底色。
```

**F5 · 运镜静度判别（锁定优先）**
```
默认 → 机位锁定 lock-off（静态布局自己说话）
要动 → 仅几不可察 push in/out ≤0.05 m/s（冷静抽离 / 极缓逼近临界）
一旦：编舞式随身横移 / 快速甩摇 / 手持大幅晃动 → 破坏"运镜的静=情绪的绷"
判据：运镜幅度 ≤ 观众几乎察觉不到 = 达标。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 静止几何枪战（Frozen Standoff）** ｜机制：把枪战拍成静态几何题，锁定机位给人物布局自己说话｜参数：角色双脚扎定几乎零位移（移动≤1 步）+ 全程常速 1.0× 零升格 + 机位锁定 lock-off + 一镜内多人各据固定点位长时间保持姿势｜触发：静止对峙/伏击/护卫遇袭｜意图：冷峻精算、静即是杀气、占位定胜负｜正例：枪火（The Mission·1999）§场景 A 荃湾广场夜间静止枪战（约 1:00:00-1:06:00，影史标杆）。

**T2 · 几何站位调度（Geometric Blocking）** ｜机制：先排阵再排镜，站位即火力网即关系网｜参数：多人呈三角/扇形/菱形阵，每人覆盖一条射界（夹角 60-120° 无死角）+ 建筑线条（柱/廊/台阶/地砖）切割画面分配进几何格 + 核心居中被护、权力用前后高低体现｜触发：多人护卫/对峙/群像集结｜意图：江湖默契与专业性可视化、空间几何=关系几何｜正例：枪火 §场景 A（五人三角/扇形阵）· §场景 B 办公室五人各据其位（约 18:00-26:00）。

**T3 · 凝固长静默 + 一颗子弹破死寂（Held Tension）** ｜机制：用"等"和"停"蓄力，声音先抽空再单点炸开｜参数：对峙人物一动不动 hold 3-15s（呼吸/眼珠可见、肢体冻结）+ 环境近乎死寂（底噪/远车声/风/滴水）+ 临界仅单发/短射骤破 + 炸完立刻复归静｜触发：临界对峙/伏击前的等待｜意图：以"无"蓄满张力、一颗子弹比一千颗更响｜正例：枪火 §场景 A-2 凝固对峙长静默 hold（9s）· §场景 A-3 一颗子弹打破死寂（2s）。

**T4 · 极克制开枪（Restrained Fire）** ｜机制：每一枪都"算过"，暴力是精算的工作｜参数：单发或 2-3 发短点射 + 枪口火焰小而短促 + 弹壳数得清（非满地金黄）+ 命中即止不补射不扫射 + 全场总开枪数常个位数 + 开枪时身体几乎不晃仅手臂/枪口动作｜触发：静止枪战的临界开火｜意图：专业冷酷精算、克制即风度｜正例：枪火 §场景 A-3（手臂枪口短促一闪、单枚弹壳落地）。

**T5 · 阵型重组走位（Formation Shift）** ｜机制：让走位在固定框里被看清，走位=阵型重组｜参数：一人小步横移换据新点位（≤2 步）+ 其余纹丝不动补位 + 阵型几何随之重组（三角变扇形）+ 核心始终被护在内 + 机位锁定｜触发：补位/换防/警戒线调整｜意图：几何站位的动态叙事、极少移动仍传递专业调度｜正例：枪火 §场景 A-4 换位走位的几何重组（5s）· §场景 B-3 突发警讯五人瞬间扎定阵型（4s）。

**T6 · 冷峻疏离剪影（Cold Silhouette）** ｜机制：冷调+夜+高对比把人推成轮廓与姿态｜参数：冷调 4300-5600K（蓝灰 #1C2430 / 钴蓝路灯冷光）+ 夜/室内低照度 + 高对比暗部 55-70% + 人物半剪影/剪影（背光 rim 勾边，面部少细节）+ 暖光仅功能点缀｜触发：夜景对峙/室内群像/宿命时刻｜意图：人渺小于局势、疏离的男性世界、江湖的冷与宿命｜正例：枪火 §场景 A（钴蓝夜广场半剪影）· §场景 C 结尾道义对峙（约 1:18:00-1:25:00）。

**T7 · 微动作沉默群像叙事（Silent Micro-gesture）** ｜机制：让"不说"承担情义/默契/背叛｜参数：微动作细节（递烟/纸团踢球/一个眼神/枪口垂下几公分）+ 沉默同框 + 群像组织进稳定几何 + 表情克制（笑意只在眼底、颔首极淡）｜触发：情义/默契/道义抉择戏｜意图：沉默的江湖兄弟情、比对白更说男性江湖｜正例：枪火 §场景 B-2 纸团踢球的无声默契（6s）· §场景 C-3 一念之间的化解动作（枪口微垂）。

**T8 · 锁定优先 · 几不可察运镜（Lock-off Priority）** ｜机制：运镜的静=情绪的绷，固定框让布局自己说话｜参数：默认机位锁定 lock-off + 要动仅几不可察 push in/out ≤0.05 m/s（临界逼近用 push in、冷静收束用 push out）｜触发：几乎全部场景（默认档）｜意图：静态布局承载张力、疏离抽离｜正例：枪火 §场景 A-2（极缓 push in ≤0.04 m/s 几乎不可察）· §场景 A-5 收束（极缓 push out）。

**T9 · 静爆声景（Silence-to-Shot Soundscape）** ｜机制：死寂作主乐器，单点枪声破静（禁配乐）｜参数：对峙段环境声抽到极低（只剩底噪/远车声/风/滴水 + 屏息）+ 临界一声短促枪响震破 + 弹壳落地数得清 + 炸完立刻回死寂 + 微动作细声（纸团擦地/打火机/枪械金属轻响）承担叙事｜触发：所有对峙/枪战段的声音设计｜意图：单点枪声因前后死寂被放到最大、听觉上的冷峻精算｜正例：枪火 §场景 A（死寂↔一声枪响的静爆切换）· §场景 C（枪械金属+集体屏息）。

**T10 · 深焦空间几何（Deep-focus Spatial Geometry）** ｜机制：大景深看清谁站哪、空间分割隔立场｜参数：全景大景深给多人布局/几何阵（深焦关系）+ 柱/廊/地砖线分层分割画面 + 对峙中景中等景深把两端隔开｜触发：多人布局/对峙轴/立场对立｜意图：看清空间几何=看清关系（与浅焦孤立大特写相反）｜正例：枪火 §场景 A（24mm f4 大全景五人几何格）· §场景 C-1 对峙轴隔两端（50mm f2.8）。

## 七、禁忌清单（❌ 杜琪峰式分镜绝不做的事）

- ❌ **吴宇森式慢动作升格**——静止枪战全程常速 1.0× 零升格，靠占位与凝滞而非升格诗化（§F2）。
- ❌ **满屏乱射子弹海 / 血浆迸溅奇观**——开枪克制到弹壳数得清、单发/短射点到为止（§F3/§T4）。
- ❌ **双手乱开枪 + 不停跑跳翻滚扑跃**——角色站定如棋子，几乎零位移，移动也只小步换位≤2 步（§T1）。
- ❌ **配乐煽情堆情绪**——不靠配乐，张力靠死寂+环境声+突然一声枪响（§H17/§T9）。
- ❌ **白鸽/硝烟/烛光等浪漫宗教意象**——那是吴宇森签名，杜琪峰是冷峻疏离的世俗江湖（§F4）。
- ❌ **高调暖光/烛光暖调**——冷调蓝灰 4300-5600K + 夜景高对比剪影 + 钴蓝冷光（§F4/§T6）。
- ❌ **把对峙拍得热闹/快剪/多机位碎切**——越静越紧，锁定 lock-off 长 hold 给完整布局（§F2/§T8）。
- ❌ **情义靠对白/英雄对望外放**——靠沉默+微动作+站位，笑意只在眼底、颔首极淡（§M7/§T7）。
- ❌ **把几何站位拍成随便站位**——站位=火力网=关系网，三角/扇形阵每人覆盖一条射界（§F1）。
- ❌ **编舞式随身横移/快速甩摇/手持大幅晃动**——运镜的静=情绪的绷，默认锁定（§F5/§T8）。
