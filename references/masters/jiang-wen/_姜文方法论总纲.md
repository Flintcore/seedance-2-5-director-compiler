> **用途**：生成模型「分镜设计」知识库顶层调用文件。调用语法示例：`[大师参照：姜文方法论总纲.md §T1 机锋对切 + masters/jiang-wen/让子弹飞.md §场景 A]`

## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：姜文的分镜系统 = **"用凌厉节奏和机锋把男性能量与隐喻拧成一场狂欢"**，六根支柱。① **节奏即智力**：对话戏也快切（1–2.5s/镜），切点卡在台词"包袱"上，正反打如枪战对切——快=狠=聪明，反寡淡（≠文艺长镜）。② **台词与画面双关**：连珠炮机锋（双关/政治寓言），每句一切，画面常与台词构成反讽或隐喻错位（说的与拍的不同一层）。③ **雄性荷尔蒙调度**：三足鼎立三角站位 + 鸿门宴饭桌环绕 + 大开大合肢体，权力靠空间几何与仰俯角承载。④ **暴力美学**：凌厉枪战快切（1–1.5s）+ 关键瞬间选择性升格（48–60fps）+ 血火实体爆发，干脆不拖泥。⑤ **逆光/高反差记忆滤镜**：日光逆光勾金边 + 高反差暖调（土黄/红符号），过曝的阳光=被美化的记忆（推断）。⑥ **气势大全景**：马拉火车/城楼群像/列阵，对称权力构图 + 强节奏声源驱动。母题→镜头：权力→仰俯角+三角；煽动→振臂+群众面孔积累蒙太奇；记忆→逆光过曝+升格。

**适用情境**：动作喜剧/民国西部、智斗对峙、饭局对决、群像煽动、雄性能量、商业类型、快节奏、隐喻双关、青春记忆。**不适用/需改造**：静观文艺、极简留白、慢节奏冷调、需要客观中立记录、寡淡台词的日常——它的凌厉与荷尔蒙是反静观的。⚠️ 大开大合 75% 仅限暴力/煽动顶点，日常对话仍按克制档。

## 一、核心心智模型（8 个镜片 · How Jiang Wen sees a shot）

### M1 · 节奏即智力（快 = 狠 = 聪明）
姜文把剪辑速度当作角色智力的外化：对话戏不靠长镜凝视，而靠**快切把机锋当子弹打**。切点不是随意的，卡在台词的"包袱/机锋"落点上。
- **分镜含义**：一场智斗戏 → 先问"机锋落点在哪一拍"，切点对准它；镜头短（1–2.5s）本身就是"这人反应快"的表演。→ 见 §T1/§H1。

### M2 · 台词与画面的双关（说的 ≠ 拍的）
台词层与画面层刻意不在同一语义面：台词说 A，画面拍 B，二者相乘出反讽或隐喻。台词是政治寓言的载体，画面是它的"障眼法/反证"。
- **分镜含义**：上机锋台词时，画面**不必**直给台词内容，可给一个反讽物/隐喻物/从容假笑，让言外之意在错位里发酵。→ 见 §M8/§T2/§H6。

### M3 · 空间即权力（几何承载博弈）
人物权力等级不靠台词点明，靠**站位几何 + 仰俯角 + 谁在中心**承载。三足鼎立=三角构图；鸿门宴=饭桌环绕；上位者被仰拍，夹缝者被略压。
- **分镜含义**：拍多方博弈 → 先定权力三角/等级，再用机位仰俯与构图位置落实，而非让演员喊。→ 见 §T3/§F1/§H7–H9。

### M4 · 雄性能量是可调度的物理量（大开大合 vs 克制）
男性荷尔蒙不是演员挤出来的，是**肢体幅度 + 声量 + 调度大小**的物理量，且分档：日常对峙克制（戏剧化 55–65%），只在暴力/煽动顶点放到大开大合（75%）。
- **分镜含义**：能量要"憋着放"——大部分镜克制，顶点才炸；全程 75% 反而廉价。分档判别见 §F2。

### M5 · 暴力要痛快不要拖（凌厉 + 选择性升格）
暴力的美学是"干脆利落 + 荒诞",靠**凌厉快切（1–1.5s）**给痛快，只在一两个关键瞬间上**升格（48–60fps）**做强调，其余全速。血火用实体爆发。
- **分镜含义**：一段动作 → 默认快切全速，挑 1 个"奇观/死亡/脱轨"瞬间升格，不要整段慢。判别见 §F3。

### M6 · 逆光/高反差是记忆的滤镜
过曝的阳光、逆光金边、高反差暖调不是打光失误，是**把画面"记忆化/美化"**的手段（尤指青春/回望题材）——现实被阳光洗成灿烂。（此归因为推断，见 §九）
- **分镜含义**：拍回忆/青春/被美化的过去 → 逆光过曝 + 暖调高反差；拍当下残酷 → 可反向压暗或转黑白。见 §T5/§H11。

### M7 · 气势靠大全景列阵 + 对称权力构图
史诗感与群体能量靠**大全景 + 列阵/对称构图**承载：马拉火车、城楼群像、密集人群。对称=秩序/权威，群众涌动=画面内部运动（机位可锁定）。
- **分镜含义**：要"magnitude/气势" → 拉大全景 + 对称 + 让运动发生在画面内部（群众/马队），机位反而可静。见 §T6/§H10。

### M8 · 煽动能量靠"一人对多人"的仰俯落差 + 面孔积累
煽动/起义的能量顶点用**仰拍单人（权威）↔ 俯拍群众（规模）**的落差，加上**群众面孔快切积累蒙太奇**（从麻木到激动的渐变）来累积，最后以红符号/手臂上举收束。
- **分镜含义**：拍一人点燃群体 → 仰拍煽动者 + 俯拍群众 + 面孔积累蒙太奇 + 上举象征收束四段式。见 §T7/§H14/§H15。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 节奏 / 剪辑（节奏即智力）
- **H1** 拍智斗对话 → 快切 1–2.5s/镜，密集正反打如枪战对切，切点卡在台词"包袱/机锋"落点上（不是均匀切）。
- **H2** 拍动作/枪战 → 更碎 1–1.5s/镜 + 反应镜穿插，节奏比对话更急。
- **H3** 要"男性魅力/雄辩快感" → 台词驱动镜头（每句机锋一切），让对切频率本身传达"你来我往"。
- **H4**（反寡律）任何一场戏若出现 >4s 的静止无信息镜 → 姜文式判定为"泄气"，须加内部运动/反应镜/机锋或缩短（§F4）。

### B. 台词与画面双关（说 ≠ 拍）
- **H5** 台词是政治寓言/双关 → 语速偏快铿锵，画面给"似笑非笑/从容假笑"的近景，让潜台词在表情与台词的落差里发酵。
- **H6** 要反讽 → 台词说 A、画面拍与 A 矛盾的 B（隐喻物/反证物/无辜表情），二者相乘出言外之意（§M2）。
- **H7** 夹缝角色（左右逢源者）反应镜 → 眼神快速左右瞟 + 略缩身位 + 略暗光，喜剧化 65%（§F1 权力等级）。

### C. 空间 / 权力调度
- **H8** 三方博弈 → 三角站位 + 圆桌/饭桌环绕 + 极缓 dolly 环绕半步（暗示暗流），中全景 35mm。
- **H9** 上位者/权威 → 仰拍 15–25° + 居中或高位；夹缝者 → 平视略压 + 略缩。
- **H10** 要"暗流涌动"的对峙 → 机位极缓 dolly/微动（不静死也不乱动），把张力压在缓慢里。

### D. 暴力 / 升格
- **H11** 一段枪战/动作 → 默认凌厉快切全速 + 手持微抖 1–2°/s + 枪口焰橙，只挑 1 个关键瞬间升格。
- **H12** 关键暴力奇观（脱轨/死亡/爆炸）→ 升格 48–60fps + 碎片方向一致 + 实体飞溅，2s 左右，非整段慢（§F3）。
- **H13** 英雄劫后登场 → 逆光勾轮廓 + 烟尘 + 缓 push-in + 仰拍 15° + 从容点烟（痞气），戏剧化 55%。

### E. 色彩 / 光影 / 气势 / 煽动
- **H14** 拍气势大全景 → 24mm f8 + 对称/列阵 + 让运动发生在画面内部（马队/群众涌动），机位可锁定或缓 tracking 侧跟。
- **H15** 煽动顶点 → 仰拍单人振臂（权威）+ 俯拍 30° 群众列阵（规模）+ 群众面孔快切积累蒙太奇 + 手臂/红绸上举 crane up 收束（四段式）。
- **H16** 浓烈暖调 → 民国土黄 + 红色符号（红绸/灯笼/血）作权力/暴力信号点 + 油灯暖光 3000K，中高饱和，暗部 50%。
- **H17** 拍记忆/青春/被美化的过去 → 逆光过曝 + 高反差暖调金边（记忆滤镜，推断 §M6）。
- **H18** 拍当下残酷/荒诞恐怖 → 反向压暗或转黑白高反差（与记忆暖调对立，用作情感开关）。
- **H19**（禁 BGM 替代）姜文重度依赖磅礴配乐驱动节奏 → 生成模型 禁配乐，改用**马蹄/枪声/鼓点/呐喊/脚步**等物理声源承载节奏（§H1 的切点仍卡在声源节拍上）。
- **H20** 群像觉醒 → 面孔积累蒙太奇 1s/镜连切，表情从麻木到激动渐变，戏剧化 60%。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 权力等级判别（谁被仰、谁被压）**
```
上位者/权威 → 仰拍 15–25° + 居中/高位 + 光足勾脸
对等博弈方 → 平视对切 + 对称位（A 偏左 / B 偏右）+ 同光
夹缝者/弱势 → 平视略压 + 略缩身位 + 略暗光 + 喜剧化 65%
铁律：权力靠几何+仰俯承载，禁靠台词点明。
```

**F2 · 能量分档判别（克制 vs 大开大合）**
```
日常对峙 / 机锋对话 → 戏剧化 55–65%（克制档，靠节奏与眼神）
暴力爆发 / 煽动顶点   → 大开大合 75%（例外档，仅限顶点）
铁律：全程 75% = 廉价；能量必须"憋着放"，顶点才炸。
```

**F3 · 升格 vs 全速判别（暴力两种速度）**
```
一段动作默认 → 凌厉快切全速 1–1.5s/镜（给痛快）
挑 1 个关键奇观/死亡/脱轨瞬间 → 升格 48–60fps ~2s（给强调）
铁律：整段升格 = 拖沓失焦；升格是点缀不是底色（§M5）。
```

**F4 · 反寡判别（节奏是否泄气）**
```
任一镜 > 4s 且无内部运动 / 无反应 / 无机锋 / 无奇观 → 判定"泄气"
处理：加画面内部运动 / 插反应镜 / 补机锋台词 / 缩短镜长
（姜文式 = 每秒高信息密度，反寡典范）
```

**F5 · 双关错位判别（台词与画面是否同层）**
```
台词层说 A：
  画面也拍 A（同层）        → 直白，非姜文式双关
  画面拍反讽物/隐喻物 B     → 双关成立（推荐 · 言外之意在错位里）
  画面拍从容假笑/似笑非笑    → 潜台词发酵（推荐）
铁律：机锋台词的画面不必是台词内容的图解。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 机锋对切（快切智斗）** ｜机制：密集正反打，切点卡台词机锋落点｜参数：50mm f2.8 平视 locked-off，1.5s/镜，A 偏左 / B 偏右对称对切，油灯暖光勾脸暗部 50%｜触发：智斗/对峙/你来我往｜意图：快切=智力狠劲、机锋如枪战｜正例：让子弹飞 §场景 A 鸿门宴（张麻子 A-2 ↔ 黄四郎 A-3 对切）。

**T2 · 似笑非笑甩机锋** ｜机制：台词铿锵双关 + 表情从容假笑，潜台词在落差里发酵｜参数：50mm f2.8 平视近景，叼烟/举杯，语速偏快，戏剧化 60%，locked-off 1.5s｜触发：政治寓言/双关台词｜意图：言外之意的回味、雄辩魅力｜正例：让子弹飞 §A-2 张麻子机锋、§A-3 黄四郎绵里藏针回击。

**T3 · 三足鼎立饭桌调度** ｜机制：三方三角站位 + 饭桌环绕 + 极缓 dolly 暗流｜参数：35mm f4 平视微俯，圆桌三方鼎立，油灯暖光 3000K 中心亮，极缓 dolly 环绕半步｜触发：三方博弈/鸿门宴对决｜意图：雄性博弈张力、三足不稳定｜正例：让子弹飞 §场景 A 饭桌三方全景（A-1）。

**T4 · 夹缝反应镜** ｜机制：弱势方左右逢源，身位略缩光略暗｜参数：50mm f2.8 平视，两强之间，眼神快速左右瞟，喜剧化 65%，locked-off 2s｜触发：多方博弈中的中间人｜意图：夹缝求生的喜剧张力、权力等级可视化｜正例：让子弹飞 §A-4 汤师爷夹缝反应。

**T5 · 逆光劫后登场** ｜机制：逆光勾轮廓 + 烟尘 + 缓推｜参数：50mm f2.8 仰拍 15°，日光逆光勾金边，烟尘土黄，缓 push-in 2.5s，从容点烟痞气，戏剧化 55%｜触发：英雄登场/劫后余生/回望｜意图：气势 + 记忆化美化（推断）｜正例：让子弹飞 §B-4 劫后烟尘中的张麻子。

**T6 · 气势大全景列阵** ｜机制：大全景 + 对称/列阵 + 内部运动｜参数：24mm f8 平视/俯拍 30°，主体占中段，缓 tracking 侧跟或 locked-off，运动发生在画面内部（马队/群众涌动）｜触发：史诗开场/群体规模/权力秩序｜意图：magnitude 气势、群体能量｜正例：让子弹飞 §B-1 马拉火车大全景、§C-2 城下群众列阵。

**T7 · 煽动四段式（仰俯落差 + 面孔积累）** ｜机制：仰拍单人权威 → 俯拍群众规模 → 面孔快切积累 → 上举象征收束｜参数：仰拍 20–25° 单人 35mm f4 + 俯拍 30° 群众 24mm f8 + 面孔 50mm f2.8 快切 1s/镜 + crane up 收束｜触发：煽动/起义/能量顶点｜意图：一人点燃满城的累积能量｜正例：让子弹飞 §场景 C（C-1 城楼→C-2 群众→C-3 面孔→C-4 红绸上举）。

## 七、禁忌清单（❌ 姜文式分镜绝不做的事）

- ❌ **用拖沓长镜/静观留白拍对话**——对话戏也须快切卡机锋，>4s 无信息即泄气（§F4）。

- ❌ **整段暴力升格**——升格是单点点缀，底色是凌厉全速快切（§F3/§M5）。
- ❌ **画面直图解台词**——机锋台词该配从容假笑/反讽物，让双关在错位里发酵（§F5）。
- ❌ **用台词点明权力等级**——权力靠站位几何 + 仰俯角承载，不靠喊（§F1/§M3）。
- ❌ **气势大全景把运动全交给机位乱动**——运动该发生在画面内部（马队/群众），机位可静（§T6）。
- ❌ **霓虹冷调/极简寡淡台词**——姜文是浓烈暖调 + 连珠炮机锋，冷调寡淡违背签名（§T9）。
