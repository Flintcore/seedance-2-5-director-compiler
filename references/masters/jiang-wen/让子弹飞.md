## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. 凌厉高速剪辑（Rapid-Fire Editing）

- **物理参数**：对话戏快切 1-2.5s/镜 + 机锋你来我往如枪战对切 + 切点卡在台词的"包袱"上 + 动作戏更碎（1-1.5s）
- **物理实现**：密集正反打 + 反应镜穿插 + 节奏卡台词
- **情感意图**：亢奋、机锋、不给观众喘息 · 台词的"快"=智力的"狠"

### 2. 连珠炮机锋台词（Rapid Witty Dialogue）

- **物理参数**：双关/隐喻/反讽密集 + 你来我往的对仗 + 政治寓言双关 + 语速偏快铿锵
- **物理实现**：台词驱动镜头切换（每句一切）
- **情感意图**：智斗的快感 · 言外之意的回味 · 雄辩的男性魅力

### 3. 雄性荷尔蒙三足对峙调度（Macho Tripartite Standoff）

- **物理参数**：三方势力（张麻子/黄四郎/汤师爷）三角站位 + 鸿门宴式饭局对决 + 大开大合的男性肢体能量 + 对峙时的权力空间几何
- **物理实现**：三角构图 + 饭桌环绕调度 + 站位权力等级
- **情感意图**：雄性博弈的张力 · 三足鼎立的不稳定

### 4. 暴力美学（Stylized Violence）

- **物理参数**：凌厉枪战（快切 + 枪口焰）+ **升格慢动作点缀**（48-60fps 仅关键瞬间）+ 血与火的爆发 + 干脆利落的死亡
- **物理实现**：实拍枪战 + 选择性升格 + 实体火药
- **情感意图**：暴力的痛快与荒诞 · 不拖泥带水

### 5. 浓烈暖调（Saturated Warm Palette）

- **物理参数**：民国土黄 #B8923E + 鹅城灰砖 #6B5D4F + 红色符号（红绸/灯笼/血 #C41E3A）+ 油灯暖光 3000K + 饱和度中高
- **物理实现**：暖调调色 + 实景土墙 + 红色点缀
- **情感意图**：民国的厚重与荒诞 · 红色的暴力与权力符号

### 6. 大全景气势构图 + 强节奏驱动（Epic Wide Shots & Rhythmic Drive）

- **物理参数**：大全景列阵（马拉火车/城楼群像/列队）+ 对称权力构图 + 久石让磅礴配乐驱动节奏（⚠️ AIGC 视频生成不写配乐 → 用马蹄/枪声/鼓点等物理声源替代）
- **物理实现**：大场面调度 + 节奏卡点
- **情感意图**：史诗气势 · 群体能量的magnitude

## 四、设计维度与适用边界

| 原则 | 姜文式体现 |
|------|-----------|
| **商业片节奏** | ⭐ **凌厉快切 1-2.5s/镜**（对话戏也快切 · 华语商业节奏典范）|
| **表演分寸** | 戏剧化 55-65% 为主 + 暴力/煽动顶点大开大合 75%（**男性能量例外 · 但日常仍须克制**）|
| **场景过渡 / 蒙太奇** | 积累蒙太奇（群众面孔）+ 台词驱动对切 |
| **色彩** | 浓烈暖调（民国土黄 + 红色权力/暴力符号）|
| **运镜** | 强运镜为主（缓 dolly 暗流 / push 登场 / crane 释放 / 手持枪战）· 三足对峙调度 |
| **声音（禁 BGM）** | ⚠️ 久石让磅礴配乐是其灵魂，但 **AIGC 视频生成不写配乐 → 用马蹄/枪声/鼓点/呐喊等物理声源替代节奏驱动** |
| **禁止无聊** | ⭐ 荷尔蒙满溢 · 每秒高信息密度 · 反寡典范 |

> **适用边界**：姜文语法适合**动作喜剧 / 民国西部 / 智斗对峙 / 群像煽动 / 商业类型**。**不适合**静观文艺 / 极简留白 / 慢节奏——它的凌厉与荷尔蒙是反静观的。⚠️ 大开大合 75% 仅限暴力/煽动顶点，日常对话仍按克制档。
