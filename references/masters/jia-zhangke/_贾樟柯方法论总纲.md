> **定位**：导演级方法论（跨作品 · 非单片拉片）——抽出贾樟柯可迁移的"分镜操作系统"，供逐镜设计查表调用。
> **用途**：生成模型「分镜设计」知识库顶层调用文件。调用示例：`[大师参照：贾樟柯方法论总纲.md §T2 远观退几步 + masters/jia-zhangke/站台.md §场景 B]`

> **一手语料**：贾樟柯访谈（Senses of Cinema 2001 · NYFF62 · Metrograph）· 余力为(Yu Lik-wai)摄影 · 调研时间 2026-07
> **红线**：只收"能直接摆机位/调色/写 prompt"的硬知识——不收"苍凉/悲悯/时代记忆"这类形容词空话。每张卡片必带**机制+参数+触发条件+情感意图+正例**五件套。可信度分级见 §九。

## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：贾樟柯的分镜系统 = **"用长镜静观 + 纪实质感 + 环境变迁，把小人物放进历史里"**。① **长镜静观引擎**：单镜 60-90s+ 保留真实时间（"keeps time intact"），默认固定、动是例外，留 ⅓-½ 时长给"无事发生"，人出画后多停 2-5s。② **远观引擎**：机位退远、"退几步去观察"而非贴近（小武 face-to-face → 站台 retreat），人物占画面 1/4-1/3、置下角、大景深，人物在环境里渺小。③ **纪实引擎**：实景（县城/拆迁工地/KTV）+ 素人晋语去戏剧化 + available 光灰调（"I like grey"·teal-green+gray-blue 低饱和）+ 同期声（喇叭/广播/施工）配乐克制 + 16mm 颗粒/DV 家庭录像感；手持只用于焦虑/偷窃/人群压迫。④ **变迁引擎**：拆迁废墟破洞框城 + 镜内远楼坍塌，人 5-25% 环境 75%+，极缓横移"从人身上 pan 走停在江/废墟"移交主角权；超现实一笔（火箭楼升空/UFO）用远景平静+不解释+无配乐呈现，收尾帧 hold 原构图 3-5s。画幅即时代（山河故人 1.33→1.85→2.35 每跳宽一档=情感疏离度）+ diegetic 流行歌书挡。

**适用情境**：现实主义、时代变迁、小人物、拆迁/城市化、纪实质感、静观长镜、方言地方。**不适用/需改造**：强情节类型片、快剪动作、棚拍奇观、英雄叙事（贾偏静观+小人物+环境）。

## 一、核心心智模型（8 个镜片 · How Jia sees a scene）

### M1 · 长镜静观保真实时间
长镜头保留真实时间。贾原话："**What I like most in a long take is that it preserves real time, it keeps time intact.**"
- **分镜含义**：默认固定长镜、动是例外；留 ⅓-½ 给"无事发生"；人出画后多停 2-5s。→ 见 §T1/F2。

### M2 · 远观 = 观察而非贴近
机位退远去"观察"。贾原话："In *Xiao Wu*, we were like **conversing face to face** but in *Platform* we had to **retreat a few steps backwards to observe** the conversation."
- **分镜含义**：要交谈/亲密→贴近；要观察/时代/环境→退几步，人占画面 1/4-1/3、置下角、大景深。→ 见 §T2/F1。

### M3 · 环境是主角
变迁/拆迁的环境才是真正的主角。贾被称"自安东尼奥尼以来最会把人物放进风景里的作者"。
- **分镜含义**：把环境立为主角 → 从人身上 pan 走、停在江/废墟（移交主角权）；人 5-25%、环境 75%+、禁特写。→ 见 §T3/T4。

### M4 · 纪实质感
非职业演员 + 实景 + available 光 + 同期声 + 胶片/DV 颗粒。余力为："hiding the camera or appropriating **guerrilla film-making** techniques… similar to documentary film styles."
- **分镜含义**：实景 + 素人晋语去戏剧化 + 灰调 available 光 + 同期声（喇叭/广播/施工）配乐克制。→ 见 §T5/T6。

### M5 · 灰调（家乡的颜色）
贾原话："**I like grey. It represents the color of my hometown, the color of the north of China…**"
- **分镜含义**：low-saturation 冷灰绿（teal-green + gray-blue）、flat contrast、欠曝、不打银边、雾霾/江雾能见度低。→ 见 §T5。

### M6 · 超现实是现实的一部分
贾原话："**Surrealism is a part of realism**" / "surrealism is a crucial part of China's reality… the speed of these changes has had an unsettling, surreal effect."
- **分镜含义**：超现实一笔用"若无其事"的写实拍法呈现（远景+不解释+无配乐+低频），反而更超现实。→ 见 §T7/F4。

### M7 · 流行文化 = 时代锚 + 情感
流行歌/媒介是时代的刻度与情感载体，且几乎全 diegetic（画内源声）。
- **分镜含义**：靠"那年大家都在听它"的历史重量承载情感；首尾同一首歌+同一动作书挡闭环。→ 见 §T8。

### M8 · 画幅 = 时代 / 疏离
画幅比随年代变宽，标记时间跳跃与情感疏离。
- **分镜含义**：每跳一代画幅宽一档（1.33→1.85→2.35）+ 人物留白大一档（画幅宽=情感疏离度）。→ 见 §T9/F5。⚠️ 此模式（山河故人）**放弃长镜静观**，别与 §M1-M2 混用（见 §F6）。

## 二、决策启发式（20 条 if-then）

### A. 长镜 / 静观 / 距离
- **H1** 要保真实时间/静观 → 长镜 60-90s+（一镜到底整场戏 2-4min）·默认固定·动是例外。
- **H2** 判别"太快"→ 镜头能被"感到在动"就太快；留 ⅓-½ 时长给"无事发生"。
- **H3** 人出画 → 镜头不追、多停 2-5s 在空景（等待/死时间）。
- **H4** 要"观察"而非"贴近" → 机位退远、人占画面 1/4-1/3、置画面下角、大景深、"街对面"感。
- **H5** 要亲密/交谈 → 才贴近（小武式 face-to-face·拍摄比 3:1）；要时代/群像 → 退远（站台式·4-5:1）。

### B. 环境 / 变迁
- **H6** 把环境立为主角 → 极缓横移从人身上 pan 走、停在江/废墟（移交主角权）；人 5-25%、环境 75%+、禁特写。
- **H7** 拆迁质感 → 半拆楼破洞框住背景城市天际线（洞=接景画/假天幕），人贴一角，背景镜内变化（远楼坍塌 hiccupping ash）。
- **H8** "消失中的地方" → 墙上手绘红漆水位数字（156.5 米）标未来淹没线；拍"已消失"只给平静水面+渡轮（缺席即主体）。
- **H9** 走向巨物（大坝）→ 人缩到 5-10%（近不可见）；日常穿行废墟 → 15-25%。

### C. 纪实 / 质感
- **H10** 纪实 → 实景（县城主街/拆迁/KTV/录像厅）+ 素人晋语去戏剧化（小动作代台词·分寸克制 30-50%）。
- **H11** 光 → available（阴天散射/灰白天空/室内荧光白炽混光）·低饱和冷灰绿·欠曝·不打银边。
- **H12** 手持 → 只用于焦虑/偷窃/人群压迫（晃动=情绪）；旁观/静观段用固定大景深长镜。
- **H13** 声音 → 同期声为主（汽车喇叭/收音机广播/电视/高音喇叭政策广播/施工/KTV 流行歌），配乐克制。
- **H14** 介质 → 16mm 强颗粒暗部厚 / 消费级 DV 4:3 家庭录像感 / 早期 HD 缓慢横移；按年代与质感选。

### D. 超现实 / 流行 / 画幅
- **H15** 写实里插超现实一笔 → 满足 D1-D5（低频≤3+远景+机位若无其事+不给惊呼+不解释无配乐）；否则破功。
- **H16** 超现实收尾帧 → 介入物消失后 hold 原构图 3-5s + 一个纹丝不动的日常物（晾衣绳衬衫）坐实"什么都没发生"。
- **H17** 流行歌 → 全 diegetic（迪厅/耳机/喇叭画内源声）；首尾同一首歌+同一动作书挡闭环（Go West 排火车舞↔雪中独舞）。
- **H18** 媒介梯度 → 公共（迪厅/录像厅）→ 私人（耳机/翻译软件），与画幅变宽同向 = 时代前进即孤独。
- **H19** 标记时代跳跃 → 画幅每跳一代宽一档（1.33→1.85→2.35）+ 留白大一档（画幅宽=情感疏离度）。
- **H20**（模式互斥）画幅+流行片（山河故人）**镜头会动、有剪辑、有近景**——勿套长镜静观模式（§F6）。

## 三、判别公式（6 个 · 可测 · 当 要点）

**F1 · 贴近 vs 远观**
```
要交谈/亲密 → 贴近（小武式 face-to-face·拍摄比 ~3:1）
要观察/时代/环境 → 退几步远观（站台式·人占 1/4-1/3·下角·大景深·拍摄比 ~4-5:1）
```

**F2 · 固定 vs 动**
```
默认固定 locked-off；动是例外
动 = 极缓匀速横移（慢到近不可察）· 动机三选一：建人-环境关系 / 让主体滑出画框镜头续走 / 从人 pan 到废墟移交主角权
"镜头能被感到在动 = 太快"
```

**F3 · 手持 vs 锁定**
```
手持 → 焦虑 / 偷窃 / 人群压迫（晃动 = 情绪·非常态）
锁定 → 旁观 / 静观 / 大景深长镜（常态）
```

**F4 · 超现实不破功（D1-D5·缺一即破）**
```
D1 频率极低（全片 ≤3·彼此远隔）  D2 远景（物小而远·不占满）
D3 机位若无其事（禁追/推/变焦/甩） D4 不给惊呼反应（主体不看或淡看）
D5 不解释·无戏剧化配乐（仅同期声；收尾镜可破例配乐）
破功 = 落差被"强调"；不破功 = 落差被当常态吞下
```

**F5 · 画幅 → 时代（山河故人）**
```
1.33:1 (Academy/4:3) → 早期/DV 档案感·高饱和通透
1.85:1               → 中期·雾霾灰浊
2.35:1 (或 2.39)     → 晚期/未来·冷合成工业
铁律：每跳一代画幅宽一档 + 人物留白大一档（画幅宽度 = 情感疏离度）
```

**F6 · 模式判别（长镜静观 vs 画幅流行）**
```
小武 / 站台 / 三峡好人 → 长镜静观模式（固定·远观·真实时间·灰调纪实）
山河故人             → 画幅+流行模式（镜头会动·有剪辑·有近景·画幅即时代）
⚠️ 两模式别混：给山河故人套"固定远观长镜"= 错
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 长镜静观（4 型）** ｜机制：单镜保留真实时间｜参数：远观单人死时间(ELS·人1/4-1/3·下角·锁定 60-90s·0剪辑·人出画停2-5s) / 极缓横移扫环境(60s-4min) / 一镜到底整场(2-4min·小空间对角取纵深) / 情绪脸部长镜(40-50s·唯一"近"例外)｜触发：静观/真实时间｜意图：让时间完整·观众自己看｜正例：站台、小武。

**T2 · 远观退几步（人小下角）** ｜机制：机位退远去观察｜参数：人占画面 1/4-1/3·置下角·大景深·"街对面"感·长/中长焦｜触发：时代/环境/群像｜意图：人渺小于历史｜正例：站台(retreat to observe)。

**T3 · 环境移交主角权** ｜机制：从人 pan 走停在环境｜参数：极缓匀速横移·从人身上离开·定在江/废墟·人 5-25% 环境 75%+·禁特写｜触发：立环境为主角｜意图：环境才是主角｜正例：三峡好人。

**T4 · 破洞框城** ｜机制：半拆楼破洞框背景城市｜参数：前景遮挡(裸钢筋/半塌梁/砖堆/破墙缺口)作 occluding frame·洞框天际线·人贴一角·背景镜内变化(远楼坍塌扬尘)｜触发：拆迁质感｜意图：变迁即景框｜正例：三峡好人。

**T5 · 纪实灰调质感** ｜机制：实景+available光+胶片/DV颗粒｜参数：实景(县城/拆迁/KTV)·素人晋语·灰调 low-sat 冷灰绿(teal-green+gray-blue)·欠曝不打银边·16mm颗粒/DV家庭录像感·同期声｜触发：现实主义｜意图："家乡/中国北方的颜色"｜正例：小武。

**T6 · 手持=情绪（非常态）** ｜机制：晃动作情绪标记而非常态｜参数：手持仅用于焦虑/偷窃/人群压迫；旁观段固定大景深长镜｜触发：焦虑/挤压瞬间｜意图：晃=心乱｜正例：小武扒窃/人群。

**T7 · 超现实介入 4 要素 + 收尾帧** ｜机制：写实框里若无其事插超现实｜参数：介入物(火箭楼升空/UFO/走钢丝)·远景平静·禁追推变焦·主体不看·无配乐·频率≤3；收尾帧 hold 原构图 3-5s+纹丝不动日常物(晾衣绳衬衫)｜触发：变迁的超现实感｜意图：把落差当常态吞下｜正例：三峡好人。

**T8 · diegetic 流行歌书挡** ｜机制：画内源声流行歌作时代锚｜参数：全 diegetic(迪厅/耳机/喇叭)·配乐克制·首尾同歌+同动作闭环(Go West 排火车舞↔雪中独舞)·媒介公共→私人｜触发：时代/情感｜意图："那年大家都在听"的历史重量｜正例：山河故人。

**T9 · 画幅即时代** ｜机制：画幅比随年代变宽｜参数：1.33(早/DV高饱和)→1.85(中/雾霾灰)→2.35(晚/冷工业)·每跳宽一档+留白大一档=情感疏离度｜触发：跨年代叙事｜意图：画幅宽=越来越疏离｜正例：山河故人。

**T10 · 淹没符号 / 缺席即主体** ｜机制：用符号标记"即将/已消失"｜参数：墙上手绘红漆水位数字(156.5米)·横线；拍"已消失"只给平静水面+水草+渡轮(缺席即主体)｜触发：消失中的地方｜意图：时间的物证｜正例：三峡好人。

## 七、禁忌清单（❌ 贾樟柯式分镜绝不做的事）

- ❌ **静观段用快剪/追推变焦**——默认固定、动是例外（M1/F2）。
- ❌ **该远观时贴脸特写**——时代/环境戏要退远、人小（M2/F1）。
- ❌ **让环境只当背景板**——环境是主角，要 pan 走移交主角权（M3/H6）。
- ❌ **打银边/高饱和暖金/棚拍光**——要 available 灰调冷绿（M5/H11）。
- ❌ **超现实一笔配戏剧化配乐/给惊呼反应/近景强调**——破功（M6/F4）。
- ❌ **流行歌当非 diegetic 配乐大铺**——应画内源声、靠历史重量（M7/H17）。
- ❌ **给山河故人套长镜静观模式**——它是画幅+流行+动镜片（M8/F6）。
- ❌ **伪造机型/焦段/DV 品牌规格**——来源普遍不给，按倾向描述（见 §九）。
