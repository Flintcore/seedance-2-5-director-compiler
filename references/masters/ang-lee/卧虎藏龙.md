## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. **轻功诗意武打（Poetic Wire-fu）**

- **物理参数**：吊威亚轻功 + 竹林梢头借力漂浮 + 飞檐走壁 + 武打动作如舞蹈般流畅优美 + 升格点缀 + 长镜展示完整动作
- **物理实现**：威亚吊拍 + 武术编舞 + 流畅运镜跟随 + 不快剪（让动作完整展示）
- **情感意图**：武打是诗意的舞蹈与情感表达 · 不是血腥而是美

### 2. **东方留白意境（Oriental Negative Space）**

- **物理参数**：大量留白 + 山水画式构图（前景/中景/远景的层次 + 大面积天空/水/雾）+ 意境优先于动作密度 + 静中有动
- **物理实现**：山水画构图法 + 留白 + 意境营造
- **情感意图**：东方美学的含蓄与意境 · 言有尽而意无穷

### 3. **山水画长镜（Landscape Long Shot）**

- **物理参数**：大远景把人放进青绿山水/竹海/沙漠/屋顶 + 人渺小诗意 + 缓慢运镜 + 自然景观为主体
- **物理实现**：实景山水 + 渺小化构图 + 缓慢 pan/dolly
- **情感意图**：人在天地山水中的渺小与诗意 · 武侠的江湖意境

### 4. **情与武交融（Emotion through Combat）**

- **物理参数**：招式的进退攻防即情感的试探/压抑/欲望 + 武打节奏对应情感节奏 + 眼神与招式互文
- **物理实现**：武打编排服务情感 + 进退即心理
- **情感意图**：武打是礼教压抑下情感的外化与释放

### 5. **青绿水墨色调 + 自然光柔（Ink-green & Soft Light）**

- **物理参数**：青绿水墨 #6B7A5A + 竹海绿 + 沙漠土黄 + 自然光柔和 + 中低饱和 + 水墨晕染感
- **物理实现**：自然光 + 青绿调色 + 山水水墨质感
- **情感意图**：东方水墨画的诗意与古典

### 6. **谭盾大提琴配乐 + 含蓄克制表演（Eastern Score & Restraint）**

- **物理参数**：谭盾大提琴（马友友）东方配乐 + 表演含蓄克制 30-50%（礼教压抑下的暗涌）+ 眼神戏 + 隐忍
- **物理实现**：东方配乐烘托 + 演员含蓄内敛
- **情感意图**：礼教压抑下的情感暗涌 · 含而不发

## 三、镜头语法 DNA（What makes this work）

1. **轻功诗意武打（wire-fu）**：吊威亚 + 竹林梢头借力漂浮 + 飞檐走壁 + 动作如舞蹈般流畅，长镜完整展示不快剪——武打是诗意的舞蹈与情感表达，不是血腥（区别于黒澤写实武戏、朴赞郁暴力美学）。
2. **东方留白意境**：大量留白 + 山水画构图层次 + 意境优先于动作密度——东方美学的含蓄，言有尽而意无穷。
3. **山水画长镜**：大远景把人放进青绿山水/竹海/屋顶，人渺小诗意——武侠的江湖意境。
4. **情与武交融**：招式的进退攻防即情感的试探/压抑/欲望，眼神与招式互文——武打是礼教压抑下情感的外化。
5. **青绿水墨色调 + 自然光柔**：青绿 #6B7A5A + 水墨晕染 + 柔和自然光——东方水墨画的诗意古典。
6. **谭盾大提琴配乐 + 含蓄克制**：东方配乐烘托 + 表演含蓄 30-50%（礼教压抑暗涌）——含而不发。
7. **张扬↔压抑的对比**：竹林对决的含蓄 ↔ 客栈群战的张扬释放——情感在武打中的两极。
