# 亚利桑德罗·伊纳里图方法论总纲 · 伪一镜到底 · 自然光 · 超广角贴身沉浸（Alejandro G. Iñárritu's Transferable Shot-Design System）

> **定位**：导演级方法论（跨作品 · 非单片拉片）——归纳伊纳里图（Iñárritu × 摄影 Emmanuel "Chivo" Lubezki / 早期 Rodrigo Prieto）跨作品中反复出现的沉浸、连续与在场方法。
> **主证据片**：《荒野猎人》The Revenant (2015) · 《鸟人》Birdman (2014) · 《爱情是狗娘》Amores Perros (2000)。
> **一手语料**：Lubezki(摄影) ARRI/ASC 访谈 · Chris Haarhoff(斯坦尼康) British Cinematographer · Gregor Tavenner(跟焦) · Rodrigo Prieto(《狗娘》摄影)。

## 索引摘要（用于快速匹配，不替代正文）

**核心 DNA**：伊纳里图的分镜系统 = **"让观众在场、不许剪、不许打灯"** 的三台引擎。① **缝合长镜引擎（stitched oner）**：单 take 目标 8–15min，换空间靠连续运镜（穿门/绕柱/跟走）而非硬切=**"调度即剪辑"**；隐藏切点只藏在四类"眼睛读不清"处——甩摇入运动模糊 / 仰摇到暗顶夜空 / 前景遮挡擦过 / 同构图冻帧对齐（+个别 VFX morph）；《鸟人》全片伪一镜，《荒野猎人》营地遇袭连走~90min。② **自然光引擎（Lubezki Rule）**：《荒野猎人》全片零电影灯，唯太阳+火光；每天仅约 90min 可用软光窗口（高纬冬季太阳躲山后=整天魔幻时刻），正午硬光不拍改排练；按季节顺序实拍、按"太阳位=山后低角散射"记场而非钟点，跨镜锁色温（阴影偏蓝 H≈210°）；夜火戏唯一例外=灯泡接调光器打"恒定光垫"让真火照常闪。③ **超广角贴身引擎（wide-immersion）**：12–18mm(S35)/24mm(Alexa65) 极广角推到最小对焦≈38cm 贴脸，同框装下情绪+整个环境；哈气飘进镜头前元件糊/畸变边缘="感到冷/在场"；T5.6 求大景深、球面 2.40:1、现场无柔光滤镜(DI 里再改)；镜头前有血/雪/呼吸直逼。运镜三态混用：手持(Lubezki 亲操)/斯坦尼康/Technocrane，一操作员一 take 到底不换手，一镜一颗定焦，机身窄轮廓去遮光斗贴演员穿缝；走位·灯·跟焦·机四方约第 15 条同步到峰值。

**适用情境**：沉浸求在场、长镜炫技需藏切、自然光/荒野/生存、贴身主观 POV、多线交织(《狗娘》=机位距离编码分线)。**不适用/需改造**：常规多机对话正反打、需精确布光造型、快剪蒙太奇（伊纳里图是"连续在场"，不是"切割节奏"）。

## 一、核心方法

### M1 · 调度即剪辑（Blocking-as-Editing）
一个长镜内换空间靠连续运镜（穿门、绕柱、跟走、升降），运镜路径承担剪辑功能。伊纳里图要"一个 POV、不切、体验被袭"(《荒野猎人》营地遇袭)。
- **分镜含义**：单镜叙事 >90 秒且需换空间时，用连续运镜代替剪辑；切点是"逼不得已才藏"，不是节奏工具。→ 见 §T1/T2/F1。

### M2 · 隐藏切点藏进"读不清"处（Hidden Cut in the Illegible）
缝合点只落在眼睛读不清画面的瞬间：甩摇入运动模糊(最主力)/仰摇到暗顶夜空/前景遮挡擦过/同构图冻帧对齐。Lubezki[原话·转述 ARRI]缝合越靠广角越好藏（景深深、边缘畸变掩接缝）。
- **分镜含义**：切点绝不落在清晰静止的中景对话上=穿帮。宁可让镜头"路过一个暗区/糊区"再接。→ 见 §T2/F1。

### M3 · 自然光铁律（Lubezki Rule）
《荒野猎人》全片只用自然光源：太阳(day)+月光/火把/篝火(night)，零人工灯——唯一例外一场篝火戏。Lubezki[原话·Variety]："The idea of using natural light came because we wanted the audience to feel…that this stuff is really happening."（"你在景里看到的灯就是打这场戏的灯"·《鸟人》用实用光泡）。
- **分镜含义**：光源=实用光/自然光；别用需要藏的地灯。要 360°自由走→提感光减灯。→ 见 §T4/T5/F2。

### M4 · 光稀缺→长镜（Scarcity Drives the Long Take）
《荒野猎人》每天仅约 90min 可用软光；演员整天排练、光对了那一小段窗口内一次交付。→ 长镜/极少 take **不是风格选择，是光逼的**。
- **分镜含义**：把"按光的连续性组织拍摄、单场记录时长必须短"当硬约束；同一场次日同一钟点接拍锁色温。→ 见 §H10/F2。

### M5 · 超广角同框装下情绪+环境（Emotion & Context in One Frame）
用极广角（12–18mm）而非中长焦切来切去。Lubezki[引述]："very wide lenses that allowed us to show all the context...at the same time as we can show emotion and be close to the actors."
- **分镜含义**：情绪特写与整个环境（背景雪崩/森林/城市）压进一格；弃变形宽银幕（贴不了那么近、景深不够）。→ 见 §T3/F3。

### M6 · 镜头前元件即"在场证明"（Lens as Membrane）
贴到能拍见嘴唇发紫+呼出的白气，让哈气飘进镜头前元件糊住/畸变画面。Lubezki[引述]："the breath sometimes even hangs into the lens and distorts the image...It's almost like feeling his life."
- **镜头作用**：呼吸、雪、血或唾沫逼近并沾染镜头前元件，会把寒冷、危险和身体在场感直接传给观众。→ 见 §T3/F3。

### M7 · 同步峰值排演芭蕾（Synchronized-Peak Ballet）
连绵跟随=摄影机、演员、灯组、跟焦四方"同时到达峰值"。Haarhoff[原话·British Cinematographer]："我们都在第十五条左右才进入状态……这是一种舞蹈，所有人都想在同一瞬间到达峰值(peak all at the same moment)。"
- **分镜含义**：Haarhoff 描述《鸟人》复杂跟随镜常到约第 15 条才让摄影、演员、灯组与跟焦共同进入状态；这是该制作流程的观察，不是固定拍摄配额。grip 与灯组须在画外随走位抬灯、挪 gel。→ 见 §T7/H8。

### M8 · 景随机走（Space Built for the Move）
空间为运镜路径定制，不是反过来。美术按操作员脚掌尺寸加宽楼梯、窄拐角多留余量让斯坦尼康走得过去(《鸟人》)；伊纳里图不用故事板/previs，把演员马道具搬进真景"找到语言"(《荒野猎人》)。
- **分镜含义**：改景不改镜——若空间不够走位，加宽路径而非改镜头设计。失败诊断三变量：blocking/机位/节奏。→ 见 §T8/H9/F5。

## 二、镜头决策启发式

### A. 缝合长镜 / 隐藏切点
- **H1** if 要伪一镜过渡两场戏 → then 切点设计在下列之一：甩摇入运动模糊 / 仰摇到暗顶夜空 / 人物擦过前景遮挡 / 进门穿黑帘；宁可镜头"路过暗区糊区"也别硬切。
- **H2** if 单镜叙事 >90 秒且需换空间 → then 用连续运镜（穿门/绕柱/跟走）代替剪辑，调度承担剪辑（M1）。
- **H3** if 缝合点找不到暗部/运动/前景 → then 用同机位同焦距冻结一帧做 matched-frame 对齐，或补 VFX morph（末位手段）。
- **H4** if 缝合点要好藏 → then 让接点尽量落在广角段（景深深、边缘畸变掩接缝）（M2）。
- **H5** if 单镜时长目标 → then 锁 8–15min（多数 ~10min，最长 ~15min）；演员台词零失误否则整条报废。

### B. 自然光 / 布光
- **H6** if 想减灯让机器 360°自由走 → then 提 EI 到 ~1200、开到 ~T2、全实用光源(灯泡/窗光/火光)，别用需要藏的地灯。
- **H7** if 高纬/太阳低角度(冬季) → then 把"短开口散射光"当"整天魔幻时刻"用，别追直射硬光；正午烈日直射=不拍，改排练。
- **H8** if 一场戏拍不完当天 90min 窗口 → then 次日同一钟点(如都 16:30)接拍锁色温连续（M4）。
- **H9** if 夜火戏脸部曝光在风里乱跳 → then 火堆四周布一圈灯泡接调光器打"恒定光垫"，让真火照常在风中闪（唯一人工光例外）。
- **H10** if 生存/荒野题材求"真的在发生" → then 按季节顺序实拍(秋→冬)、按"太阳位=山后低角散射"记场而非钟点、跨镜统一冷蓝阴影。

### C. 超广角 / 贴身
- **H11** if 要"同时装下情绪+环境" → then 用 12–18mm(S35)/24mm(Alexa65) 广角，而非中长焦切来切去（M5）。
- **H12** if 要观众"感到冷/在场" → then 贴到拍见嘴唇发紫+呼出白气，让哈气飘进镜头前元件糊住画面（M6）。
- **H13** if 主观 POV(如熊袭) → then 机位贴角色视点，拍成一镜到底假象(实为多段 VFX 缝合)，血/爪痕/唾沫/雪直逼并沾镜头。
- **H14** if 贴脸广角下要不跳切 → then 用"弹性镜头"：从客观广角走进主观近景再走出，人物入画即成主体(《鸟人》走廊段)。
- **H15** if 贴脸求大景深+crisp → then 开到最小 T5.6、球面镜 2.40:1、现场不加柔光/扩散(DI 里再改)、弃变形宽银幕。

### D. 运镜物理 / 走位调度
- **H16** if 手持长镜要在两演员间穿窄缝 → then 用小机身(ALEXA M 类)+极简无遮光斗窄轮廓+单颗 18mm；别上大装配。
- **H17** if 一个长镜要跨越大高度差(楼上→楼下) → then 别切，用 Libra/稳定头做连续起降当单条运镜。
- **H18** if 长镜跟快语速+快步演员(如 Keaton) → then 操作员倒退快走跟拍、平台/楼梯由 grip 抢进抢出；节奏由演员定，机器别拖慢戏。
- **H19** 复杂手持跟随镜若早期 take 尚未同步 → 先诊断摄影、演员、灯组与跟焦哪一环未到峰值，再继续排演或调整 blocking；《鸟人》约第 15 条进入状态只作流程观察（M7）。
- **H20** if 拍 360°动作伏击(仿《荒野猎人》) → then 三态混用(手持/斯坦尼康/Technocrane)、实时演、按 blocking→机位→节奏三变量迭代重拍，别指望一条过。

### E. 多线交织（《狗娘》Prieto 路数 · 见 §九纠错）
- **H21** if 多线剧本要观众不看字幕分辨"谁的故事" → then 每条线 = {固定机位距离 + 固定色温 + 固定时间态} 三元组恒定，绝不混用（两线机位距离雷同=交织失败）。
- **H22** if 多线交汇的车祸/爆炸/枪击 → then 一次实拍 + N 机位包围(正/侧/主观/远)(《狗娘》9 机位)，而非分次补拍，保证跨线剪辑光影/碎片/血迹连戏。

## 三、条件性判断

**F1 · 伪一镜成立（缝合长镜）**
```
伪一镜成立 = (单take ≥8min)
 ∧ (切点全落在 运动模糊|暗部/夜空|前景遮挡|同构图冻帧)
 ∧ (光源 = 实用光/自然光，非藏灯)
 ∧ (换空间靠运镜/升降，非硬切)
任一项 false → 只是"长镜头炫技"，非缝合体系。
反例：切点落在清晰静止的中景对话上 = 穿帮，失真。
```

**F2 · 自然光窗口（90 分钟判别）**
```
正午 13:00 烈日直射 → 大气/气氛 = 0 → 不拍，改排练
太阳落到山背后(约16:30) → 画面变"蓝、更冷、神秘" → 开拍
高纬冬季 = 太阳一天数次躲山后 → 短开口散射光当"整天魔幻时刻"
同场跨天接拍 → 锁同一钟点(色温连续)
基线：native ISO 800(Alexa65)；上推 1200 ASA 换景深；EI≈1200 / T2 夜外景减灯
（阴影 HSV：H≈210° 偏蓝 / 低饱和 / 中低明度 · 色温 4000–5500K → 推断，见 §九）
```

**F3 · 超广角贴身（是不是这套）**
```
超广角贴身 = (焦距 ≤18mm S35 / ≤24mm 大画幅)
 × (机-人距 ≤~40cm，近景推到最小对焦≈38cm)
 × (镜头前有 呼吸/血/雪/畸变)
 × (长镜头推进而非切)
 × (自然光 + 大景深 T5.6 + 球面 2.40:1 + 无柔光滤镜)
多项同时成立时此风格；若用变形宽银幕镜或中长焦定切 → 不是。
```

**F4 · 同步峰值连绵跟随**
```
成立连绵跟随 = (单take 一操作员到底·中途不换手)
 ∧ (一镜一颗定焦·主力 18mm/14mm)
 ∧ (机身窄轮廓无遮光斗·贴演员)
 ∧ (走位·灯·跟焦·机 四方同步峰值·排演至 ~15 条)
 ∧ (跨空间靠运镜/Libra 升降·非硬切)
反例：中途换操作员接力 / 一镜内频繁变焦 / 上大遮光斗全套附件挤不进演员间 = 失真。
※ "第15条""不换手"是流程描述非硬指标；不同条之间手持版/斯坦尼康版分别拍（见 §九）。
```

**F5 · 长镜失败三变量诊断（重拍决策）**
```
一条长镜没过 → 逐项查：
 blocking 走位错？→ 改走位
 camera position 机位错？→ 改机位
 tempo 节奏错？→ 改节奏
三者任一错则整条重来（《荒野猎人》伏击段约重拍 4 次·每条~90min）。
空间不够走位 → 改景不改镜（加宽楼梯/拐角留余量）。
```

**F6 · 多线机位距离编码（《狗娘》分线）**
```
每条线 = {固定机位距离, 固定色温, 固定时间态} 三元组恒定：
 底层线 → 极特写 face-fills-frame + 偏蓝 + 过去
 中产线 → 中景 mid-distance + 偏暖 + 当下
 流浪线 → 大远景 long shot + 偏蓝 + 未来
两条线机位距离雷同 → 交织失败，观众迷路。
```

## 四、技法卡片

**T1 · 缝合长镜 stitched oner** ｜机制：单 take 换空间靠连续运镜代替剪辑·"调度即剪辑"｜参数：单 take 8–15min(多数~10)·广角为主·台词零失误否则整条报废｜触发：需一镜跨多空间叙事·求不间断在场｜情感意图：观众"被关在戏里"不许喘·连续压迫｜正例：《鸟人》全片剧院后台迷宫穿行。

**T2 · 隐藏切点 hidden cut** ｜机制：接点藏进眼睛读不清处｜参数：六类掩蔽——甩摇入运动模糊(主力)/仰摇到暗顶夜空/前景遮挡擦过/同构图冻帧对齐/VFX morph/甩到黑；接点尽量落广角段｜触发：真拍不完一条·必须缝｜情感意图：让"多镜"骗成"一镜"·不破沉浸｜正例：《鸟人》Riggan 穿内衣过时代广场=同构图+人群遮挡缝合。

**T3 · 超广角贴脸 wide close-in** ｜机制：极广角推到最小对焦贴脸·情绪+环境同框·镜前元件沾呼吸血雪｜参数：12–18mm(S35)/24mm(Alexa65)·机-人距≈38cm·T5.6 大景深·2.40:1 球面·无柔光滤镜·哈气糊镜畸变边缘｜触发：求"在场/感到冷"·主观沉浸｜情感意图：把观众塞进角色皮肤里·体感寒冷与生命｜正例：《荒野猎人》熊袭主观(贴视点广角+血喷镜)；雪崩近景=Alexa65+24mm 特写 Leo 同框纳背景雪崩。

**T4 · 全自然光 natural-light-only** ｜机制：零电影灯·唯太阳+火光·实用光即戏光｜参数：native ISO 800·夜外 EI≈1200/T2·数字非胶片吃住冬季天空渐变·色温整天变故单场时长短｜触发：生存/荒野·求"真的在发生"｜情感意图：纪实质地·让观众信这是真实经历｜正例：《荒野猎人》全片森林雪原白天戏(低角散射"整天魔幻时刻")。

**T5 · 90 分钟窗口调度 magic-window** ｜机制：按光的连续性组织拍摄·光稀缺逼出长镜｜参数：每天约 90min 可用软光·正午硬光不拍改排练·按季节顺序实拍·按太阳位记场非钟点·次日同钟点接拍锁色温｜触发：高纬冬季/太阳低角·外景自然光｜情感意图：跨镜色温统一·季节推进真实感｜正例：《荒野猎人》整片外景排期(可整天等光·光对了只拍 1 小时)。

**T6 · 火光恒定光垫 fire cushion** ｜机制：真火乱跳时布恒定底光稳脸曝光｜参数：火堆四周灯泡接调光器(dimmer)·恒定暖光~2200K(H≈25–35°橙红)压过闪烁黑暗低谷·不压火高光跳动·真火照常在风中闪｜触发：夜外篝火戏·风中火焰忽明忽暗｜情感意图：脸可读又保留真火生命感｜正例：《荒野猎人》夜营篝火戏(全片唯一人工光例外)。

**T7 · 同步峰值跟随 sync-peak follow** ｜机制：摄影/演员/灯/跟焦四方同时到峰值·一操作员一 take 到底｜参数：中途不换手·一镜一颗定焦（《鸟人》主力 18mm）·机身窄轮廓无遮光斗贴演员穿缝·充分排演·跟焦徒手不看监视器；Haarhoff 所述约 15 条是单片流程观察｜触发：连绵手持/斯坦尼康长镜｜情感意图：无缝流动·观众随角色被拖着走｜正例：《鸟人》走廊后台=Haarhoff 斯坦尼康倒退快走跟 Keaton 快语速快步。

**T8 · 三态混合运镜 three-mode rig** ｜机制：一长镜内在手持/斯坦尼康/Technocrane 三态间切换造连续假象·景随机走｜参数：手持=Lubezki 亲操(紧/主观/窄缝)·斯坦尼康=较宽较客观·Technocrane 伸缩炮=大幅位移；不用故事板搬真景找语言·失败三变量诊断｜触发：360°动作伏击/大空间连续穿行｜情感意图：动作风暴中不眨眼咬住·卷入感｜正例：《荒野猎人》开场 Arikara 伏击(360°动作风暴实时穿行、沿河溃退、连走~90min、重拍~4 次)。

**T9 · 弹性镜头 elastic lens** ｜机制：镜头从客观广角走进主观近景再走出·人物入画即成主体｜参数：18mm·广角近景配镜头光晕软化降反差·不跳切完成客观↔主观切换｜触发：贴脸广角下需切换视角而不硬切｜情感意图：观众视点被无缝拉进/推出角色内心｜正例：《鸟人》走廊弹性长镜(主观走廊穿行切到客观 Riggan 入画)。

**T10 · 多线机位距离编码 distance-coded threads** ｜机制：每条叙事线用固定机位距离+色温+时间态编码·不看字幕可分辨｜参数：极特写/偏蓝/过去 · 中景/偏暖/当下 · 大远景/偏蓝/未来；交汇点一次实拍 9 机位包围｜触发：多线/hyperlink 叙事·三阶层交织｜情感意图：三个世界"焊"进同一危险城市肌理·命运交叉｜正例：《爱情是狗娘》三线(Octavio 极特写/Valeria 中景/El Chivo 大远景)+车祸 9 机位缝合。【注：此片 DP=Prieto，非 Lubezki，见 §九】

## 七、风格偏离与失真风险

- ❌ **缝合切点落在清晰静止的中景对话上**——必穿帮，切点只藏运动模糊/暗部/前景遮挡/同构图（M2/F1）。
- ❌ **长镜换空间用硬切**——应靠连续运镜/升降，调度即剪辑（M1/H2）。
- ❌ **自然光戏里用需要藏的地灯**——光源须实用光/自然光，唯火戏可加"恒定光垫"（M3/H6/H9）。
- ❌ **正午烈日直射硬拍**——高纬冬季等太阳躲山后的软光窗口，硬光时段改排练（H7/F2）。
- ❌ **贴身沉浸用变形宽银幕镜或中长焦定切**——用 12–18mm 球面广角推进，弃 anamorphic（M5/H15/F3）。
- ❌ **贴脸广角还硬跳切**——用弹性镜头客观↔主观走进走出，不切（M6/H14/T9）。
- ❌ **一 take 中途换操作员接力 / 一镜内频繁变焦 / 上大遮光斗全套附件**——挤不进演员间、破连续（F4/H16）。
- ❌ **复杂长镜尚未诊断同步问题就仓促定妆**——摄影、演员、灯组与跟焦需要共同到达峰值；《鸟人》约 15 条的说法是该片制作观察，不是通用配额（M7/H19）。
- ❌ **空间不够走位就改镜头设计**——应改景不改镜(加宽路径)（M8/H9/F5）。
- ❌ **多线用雷同机位距离**——每线固定{距离+色温+时间态}三元组，否则观众迷路（H21/F6）。
- ❌ **把《狗娘》说成 Lubezki 摄影/纯自然光**——该片 DP=Prieto，大量人工光+practicals（见 §九）。

## 九、来源与证据边界

**可直接引用（高置信 · 一手转述有直接引语）**：
- Lubezki[原话·Variety]：选自然光动机 "We wanted to make a movie that was immersive and visceral. The idea of using natural light came because we wanted the audience to feel…that this stuff is really happening."
- Lubezki[原话·ARRI]：《鸟人》夜外景 "EI≈1200 ASA, 光圈≈T2"、"你在景里看到的灯就是打这场戏的灯"(全实用光泡)。
- Lubezki[引述]：超广角 "very wide lenses that allowed us to show all the context...at the same time as we can show emotion and be close to the actors."
- Lubezki[引述]：镜前哈气 "the breath sometimes even hangs into the lens and distorts the image...It's almost like feeling his life."
- Lubezki[引述·AC 2016]：雪崩 "Alexa 65 on a little crane arm with the 24mm lens to get a close-up on Leo and incorporate the landscape in the background."
- Lubezki[原话·Tribeca]：《荒野猎人》伏击失败三变量 "blocking / camera position / tempo 错了、拍了 4 次"。
- Haarhoff[原话·British Cinematographer]：一操作员到底不换手 / 主力 18mm Leica / 加宽楼梯让斯坦尼康过 / "第十五条左右才进入状态……peak all at the same moment" / Libra head 做高度过渡。
- Lubezki[转述·NoFilmSchool]：90 分钟窗口 "at 1pm bright sunshine…nothing of interest；at 4.30pm sun behind a mountain…bluer and colder"。
- Prieto/《狗娘》[原话·asharperfocus 二次核对]：三线机位距离编码 "single face fills the screen"(Octavio)/"middle distance where most tv shows are photographed"(Valeria)/"a lot of long shots as he prowls the city"(El Chivo)；"staged it only once, but he used nine cameras"。

**关键纠错 / 需注明（防张冠李戴）**：
- ⚠️ **《爱情是狗娘》DP = Rodrigo Prieto，非 Lubezki**（Lubezki 首次与伊纳里图合作是《鸟人》/2014）。该片变焦=Prieto 用 Angenieux 25–250mm；且该片**大量人工光+practicals**，非纯自然光。**自然光铁律是《荒野猎人》(Lubezki)的做法，勿套到《狗娘》**。
- ⚠️ **技法非伊纳里图独创**：长镜头(希区柯克《夺魂索》1948)/自然光(《巴里·林登》)/超广角鱼眼/离场暴力/day-for-night 均早于其存在——本纲写"标志性运用/集大成"，**绝不写"发明/首创/鼻祖"**。
- ⚠️ **"take 中途绝不换手"** 是《鸟人》Haarhoff 原话，指**同一条内**不接力；**不同条**之间手持版/斯坦尼康版会分别拍，别误读成全片一人一镜。
- ⚠️ **"第 15 条进状态"** 是 Haarhoff 对流程的描述，非硬性规定，勿当作"必须拍 15 条"参数。
- ⚠️ **自然光"唯一例外"** 指《荒野猎人》篝火戏一处；《鸟人》本就是城市实用光(灯泡/管灯)片，不属"自然光铁律"范畴。

**参数不确定（标"约"/推断 · 勿伪造为一手规格）**：
- **隐藏切点总数**：公开有 16 / 28 两种计数(取决于是否含微接点与片头片尾)，**无伊纳里图官方定数** → 存疑。
- **《鸟人》逐场焦距 mm 清单**：仅知镜头品牌(Leica Summilux-C + Master Prime)与主力 18mm，**逐场焦距查不到** → 勿编造单场 mm。
- **Alexa 65 占比**：各源打架——Codex 说 ≈13%，ARRI/另一源说 ≈40% → 存疑，勿写死。
- **S35 广角(12–18mm)最小对焦距离**：仅 24mm(Alexa65)口径确认 ≈15 英寸(≈38cm)；S35 广角更近但无确切数值 → 存疑。
- **帧率 / 快门角度**：《荒野猎人》《鸟人》主源(AC/Codex/Variety)**均未列** shutter angle 与 fps 具体值 → 判定常规 24fps/180° 但**未见证据确认** → 存疑，勿伪造非标值。
- **自然光色温/阴影 HSV(4000–5500K / H≈210° 偏蓝)**：据 "bluer/colder/4:30pm" 文字反推 → **推断**，非实测色卡/LUT；分镜可用作倾向，勿当精确 LUT。
- **火光恒定层色温(~2200K / H≈25–35°)**：据 "cushion of constant light" 描述与火色物理反推 → **推断**；dimmer 由 Variety 提，PetaPixel 未提。
- **雪面当反光板/补光**：物理上雪是高反照率天然反光面几乎必然被利用，但**未检索到 Lubezki 一手明确说"用雪做 bounce/fill"** → **推断/存疑**，勿写成 Lubezki 原话。
- **"血/唾沫上镜头前元件"具体到哪一格**：未见 Lubezki 一手确认"血上镜"；"呼吸糊镜"有直接引述可信，"血/唾沫上镜"多为熊袭段落 → **推断**。
- **斯坦尼康 sled/arm/vest 型号**：Haarhoff 受访未点名(勿编造如"Steadicam Ultra2")；仅确认 Libra head 用于高度过渡。
- **Technocrane 用于伏击段的镜次占比**：三态混用为受访转述，逐镜分配无公开清单 → 查不到。
- **《狗娘》各线焦段具体 mm 值**：仅知 25–250mm 变焦范围 + "short focal length" 定性，逐线 mm 一手查不到；bleach-bypass vs 全银盐保留确切工艺出处为商店页/博客(非一手)→ 存疑。
