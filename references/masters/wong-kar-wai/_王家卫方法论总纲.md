> **用途**：生成模型「分镜设计」知识库顶层调用文件。调用语法示例：`[大师参照：王家卫方法论总纲.md §T1 step-printing + masters/wong-kar-wai/堕落天使.md §场景 A]`

## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：王家卫×杜可风的分镜系统 = **"把主观情绪外化成可测的影像质感"**，四根支柱。① **情绪时间引擎**：step-printing（6fps 降格 + 180°快门 + 光学印片每格×4 + frame sampling 硬复制帧）把物理时间拧成主观时间——主体凝滞、背景强方向拖尾，用于擦肩/等待/暴力/离别（≠丝滑升格）。② **两种孤独的镜头分工**（判别铁律）：超广 6.8mm 贴脸（<0.3m·边缘径向拉伸·面部畸变）= 躁动疏离；长焦压缩 = 隐忍被困——**同一基调内不可混用**。③ **遮挡即情感**：前景遮挡（遮 30–60%·障碍强失焦·主体落缝隙实焦）+ 框中框 + 栏杆=牢笼。④ **色彩即情绪坐标**：默认无红、红一出=越界；霓虹=脏底+纯色点；黑白↔彩色=情感开关；冷暖 70/30 对位。母题→镜头：时间焦虑→钟表 ECU+慢门；错过→母版镜头锁角度焦段微差变奏；未完成→人出画后空镜滞留 2–3 拍。方法：无剧本即兴、将错就错（过期胶片→黑白）。

**适用情境**：都市情感/文艺、主观时间、暧昧疏离、霓虹夜、逼仄空间、错过与重复、抽象化暴力/武打。**不适用/需改造**：需要清晰动作可读性的商业动作（step-print 反可读性）、需要客观中立记录的题材、明亮均匀高调打光的场景。

## 一、核心心智模型（8 个镜片 · How WKW/Doyle sees a shot）

### M1 · 构图先于表演（人是空间里移动的物）
先定框、再放人；情绪由**机位/景框/空间**承载，不靠演员挤表情。Doyle 原话："The Wong Kar-wai style is to change a **situation** rather than a performance… It's **people moving in space**."（Reverse Shot · 高）
- **分镜含义**：先问"这场戏的空间/景框说什么"，再摆人。→ 见 §T3/T4。

### M2 · 情绪时间 ≠ 物理时间
用 step-printing / 慢门把主观时间外化成可见的运动质感（拖影 + 顿挫），而非用表演说"我恍惚了"。
- **分镜含义**：主观时间膨胀的瞬间 → 上 step-print（§T1），不是慢镜抒情就行——要"信息更少的顿挫感"，不是"信息更多的丝滑"。判别见 §F2。

### M3 · 现场生成风格 / 将错就错
无完整剧本、即兴拍摄；风格来自现场约束（可用光、胶片缺陷）。Doyle："**If it's not on the negative, it won't be in the film**… It's like **jazz**… a jam session."（VICE·高）；胶片出错→"foggy in color"→干脆改黑白（春光乍泄）。
- **分镜含义**：拥抱不完美质感（过期胶片偏色、可用霓虹、手持微抖）作为美学，而非追求干净。设计时允许"缺陷即风格"。

### M4 · 色彩即情绪坐标
颜色是情绪的量化坐标，不是装饰。Doyle："up to *In the Mood for Love*, there's **no red** in Wong Kar-wai's films."（Reverse Shot·高）→ 红是被保留的"越界/欲望"信号色。
- **分镜含义**：定一场戏的主导色前先定情绪坐标（越界=红 / 压抑=黑白 / 躁动=脏绿脏黄）。见 §T7/T8 + §F4。

### M5 · 遮挡即情感（偷窥/压抑/囚禁）
前景遮挡、框中框、栏杆不是构图花样，是把"偷窥感/压抑/囚禁"物理化。
- **分镜含义**：想让观众"隔着什么看" → 前景放遮挡物；想"囚禁" → 前景放栅格。占比决定强度（§F3）。

### M6 · 广角 vs 长焦 = 两种孤独
超广贴脸 = 物理贴近⇄心理畸变疏离（躁动）；长焦压缩 = 远观、被空间困住（隐忍）。二者是**相反签名**。
- **分镜含义**：先定这场的孤独是"躁动"还是"隐忍"，再选镜头族。判别铁律见 §F1。

### M7 · 重复与错过（母版镜头变奏）
结构性的"错过/重复"用**同一母版镜头**（锁角度+焦段+配乐）跨场景复用、只做微差变奏来表达，让观众潜意识识别"又一次"。
- **分镜含义**：两场戏是重复/错过关系 → 复用母版镜头，改光/雨/距离/服装。见 §T5/F5。

### M8 · 声画错位（画外音 = 内心与外部分离）
第一人称画外音独白配"单人框 + 空镜/背影/浅景深"，声音（内心）与画面（外部）刻意不同步、不同框。
- **分镜含义**：上画外音时，画面**不要**给正面情绪特写、不要与他人同框——让内心与世界分离。见 §T9。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 情绪时间 / 运动质感
- **H1** 要主观时间膨胀（擦肩/等待/暴力/离别）→ step-print：6fps + 180°快门 + 印×4 + frame sampling 硬复制帧；主体相对凝滞 + 背景强方向拖尾；短促插入（数秒），与常速/定格交替。
- **H2** 拖影量不够 → 降帧率（3fps×8 更极端）或加大单格曝光（快门趋 360°，但易过糊）；慢速主体几乎不拖，需主体或背景有明确运动。
- **H3** 要"丝滑唯美慢" → 用升格（高帧率慢放），**不要** step-print（二者视觉相反，见 §F2）。

### B. 镜头族选择（两种孤独）
- **H4** 情绪=躁动/贴近却隔阂 → 超广 6.8mm 贴脸（机位 <0.3m，边缘径向拉伸，面部畸变）。
- **H5** 情绪=隐忍/克制/远观被困 → 长焦压缩 + 前景遮挡（如花样年华）。
- **H6**（铁律）同一情绪基调内**不可混用**超广畸变与长焦压缩——会破坏签名一致性（§F1）。

### C. 遮挡 / 构图
- **H7** 要偷窥/压抑 → 前景放遮挡物（门框/窗棂/珠帘/植物/人群/家具）贴镜头、强失焦、遮 30–60%，主体落在缝隙里实焦。
- **H8** 要情感囚禁 → 前景放栅格（窗棂/床栏/铁栏），主体被"关"在格后。
- **H9** 要困住/孤立 → 框中框（门/窗/走廊/镜二次切割画面）。
- **H10** 要疏离/分裂 → 拍镜中的人 / 玻璃倒影（间接看 + 成双）。

### D. 色彩 / 光影
- **H11** 要"越界/欲望/危险"的信号 → 引入红（平时保持无红，红一出即有意义）。
- **H12** 霓虹夜景 → 脏底（脏绿脏黄暗部）+ 纯色点（招牌/灯管），**不是**整体拉高饱和。
- **H13** 要"回不去/压抑" vs "当下激情"的对照 → 黑白 ↔ 彩色开关切换（春光乍泄）。
- **H14** 现场光不足 → 用可用光/霓虹当情绪色块 + 开大光圈浅景深抠主体，**不打平光**；接受偏色/颗粒。
- **H15** 冷暖对位 → 主色 70 / 对比色 30，反打时两侧分冷暖。

### E. 母题 / 时间 / 叙事
- **H16** 拍时间焦虑 → 钟表 ECU + 慢门；对白报出精确时刻的当下即插钟面/表特写。
- **H17** 拍"到期/倒计时" → 可计数的日常物蒙太奇（罐头到期日 / 买满 N 罐）。
- **H18** 结构是"错过/重复" → 母版镜头（锁角度+焦段+配乐）跨场景复用，只改光/雨/距离（§F5）。
- **H19** 上画外音独白 → 单人框 + 空镜/背影/浅景深，声画错位，拒与他人同框（§M8）。
- **H20** "未完成的爱"留白 → 人出画后空镜滞留 2–3 拍 + 前景遮挡 + 门/窗/镜框中框，避正面情绪特写。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 超广 vs 长焦判别（两种孤独）**
```
情绪 = 躁动 / 贴近却隔阂 / 被空间吞没 → 超广 6.8mm 贴脸（<0.3m·径向拉伸·面部畸变）
情绪 = 隐忍 / 克制 / 远观被困       → 长焦压缩 + 前景遮挡
铁律：同一情绪基调内不混用（签名相反）。堕落天使=超广派 / 花样年华=长焦派。
```

**F2 · step-print vs 升格判别（两种慢）**
```
要"信息更少·顿挫·抽象"（暴力/主观混乱/擦肩）→ step-print（降格 6fps + 复制帧 + frame sampling 硬拷）
要"信息更多·丝滑·抒情唯美慢"                 → 升格（高帧率慢放，frame blending 柔混）
二者视觉相反：step-print 是一顿一顿的涂抹，升格是连续顺滑。
```

**F3 · 前景遮挡占比判别**
```
遮 < 1/3   → 无窥视味（只是前景装饰）
遮 1/3–1/2 → 偷窥感（推荐区间）
遮 > 1/2   → 强压抑 / 囚禁
障碍必须强失焦、主体落在缝隙里实焦，否则变成挡脸穿帮。
```

**F4 · 红色判别（信号色纪律）**
```
王家卫默认调色板 = 无红（黄/绿/蓝/黑白为主）
一旦引入红 → 必须是"越界/欲望/危险"的有意义信号镜，不可随意铺红
（红满屏 = 破坏纪律，红失去信号价值）
```

**F5 · 母版镜头变奏判别（重复/错过）**
```
两场戏是"重复/错过/宿命轮回"关系 → 锁定【机位角度 + 焦段 + 配乐】完全相同
只允许改变：光线 / 雨 / 距离 / 服装 / 时间
目的：让观众潜意识识别"又一次"，无需台词点明
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · step-printing 抽帧拖影** ｜机制：降格拍(单格长曝→拖影)+光学印片每格复制 N 次(离散顿挫)｜参数：6fps+180°快门(1/12s)→印×4→24fps；frame sampling 硬复制帧(非 blending 柔混)｜触发：擦肩/等待/暴力/离别/主观混乱｜意图：物理时间→主观时间、人群中孤立主角｜正例：重庆森林(人群凝滞)、堕落天使(暴力)、东邪西毒(武打)。

**T2 · 6.8mm 贴脸超广** ｜机制：超广角+贴脸机位→面部径向拉伸畸变｜参数：Century Tegéa 9.8mm+广角转接→等效 6.8mm(S35)；机位<0.3m；边缘径向拉伸(非鱼眼弯线)｜触发：要"物理贴近⇄心理疏离"的躁动亲密｜意图：亲密与疏离同框的悖论｜正例：堕落天使全片。

**T3 · 前景遮挡** ｜机制：隔实景障碍拍主体｜参数：障碍贴镜头+强失焦+遮 30–60%，主体落缝隙实焦，平视/略低，主体不看镜头｜触发：偷窥/压抑/隔阂｜意图：把"隔着什么看"物理化｜正例：花样年华(招牌/门框)、堕落天使。

**T4 · 框中框 / 栏杆囚笼** ｜机制：门窗走廊镜二次切割 / 前景栅格｜参数：门窗框占边缘、主体居中缝隙；栅格(窗棂/床栏)前景失焦覆盖｜触发：困住/孤立/情感囚禁｜意图：景框=牢笼｜正例：春光乍泄(铁床栏)、阿飞正传。

**T5 · 母版镜头变奏** ｜机制：同一镜头跨场景复用+微差｜参数：锁角度+焦段+配乐，改光/雨/距离/服装｜触发：重复/错过/宿命结构｜意图：潜意识"又一次"｜正例：花样年华楼道擦肩、阿飞正传。

**T6 · 钟表时间实体化** ｜机制：把抽象"时间"变成可拍的物｜参数：钟表/手表 ECU + 慢门 + 对白报精确时刻同步插入｜触发：时间焦虑/到期/一分钟朋友｜意图：让"时间"成为在场的角色｜正例：阿飞正传(1960.4.16 15:00)、重庆森林(罐头到期)。

**T7 · 黑白↔彩色情感开关** ｜机制：色彩有无=情感状态切换｜参数：黑白段(回不去/压抑) ↔ 浓饱和彩色段(当下激情)，硬切非渐变｜触发：今昔对照/情感闪回｜意图：色彩本身叙事｜正例：春光乍泄。

**T8 · 脏底霓虹** ｜机制：暗脏底色+纯色霓虹点｜参数：脏绿脏黄暗部(暗部 60–70%)+招牌纯色高光点，开大光圈浅景深｜触发：都市夜/疏离躁动｜意图：霓虹=情绪色块非照明｜正例：堕落天使、重庆森林夜。

**T9 · 画外音声画错位** ｜机制：内心独白 vs 外部画面刻意不同步｜参数：单人框+空镜/背影/浅景深，声画不对位，拒他人同框｜触发：第一人称内心戏｜意图：内心与世界分离｜正例：重庆森林、堕落天使、阿飞正传。

**T10 · 长焦压缩隐忍** ｜机制：长焦压缩空间+前景遮挡｜参数：长焦(压缩纵深)+前景障碍虚化，主体被"夹"在层次间｜触发：隐忍/克制/欲言又止｜意图：与超广躁动相反的"憋"｜正例：花样年华（与堕落天使 §T2 互为反面）。

## 七、禁忌清单（❌ 王家卫式分镜绝不做的事）

- ❌ **在同一情绪基调里混用超广畸变与长焦压缩**——签名互斥（§F1）。
- ❌ **把 step-print 当"丝滑慢镜"用**——它是顿挫涂抹，不是升格抒情（§F2）。
- ❌ **随意铺红**——红是保留的越界信号色，铺满即失效（§F4）。
- ❌ **霓虹整体拉高饱和**——应脏底 + 纯色点，否则廉价（§T8/H12）。
- ❌ **前景遮挡物是实焦、或遮住主体脸**——障碍必须失焦、主体落缝隙实焦（§F3）。
- ❌ **画外音时给正面情绪大特写 / 与他人同框**——破坏声画错位的分离感（§M8）。
- ❌ **把光打平、追求干净**——放弃可用光/偏色/颗粒就丢了质感（§M3/H14）。
- ❌ **用台词点明"又一次/错过"**——该用母版镜头变奏让观众潜意识识别（§F5）。

## 九、来源与诚实边界（Doubt-Log · 引用前先看这里）

- Doyle："change a **situation** rather than a performance… people moving in space."（Reverse Shot / Interview Mag）
- Doyle："**If it is not on the negative, it won't be in the film**… like **jazz**… a jam session."（VICE）
- Doyle："prepare like crazy and then you just throw all that stuff away… like a **martial artist** preparing for the fight."（Working with WKW 原声）
- Doyle："We **fucked up with the film stock**. It was old… **foggy in color**."（Reverse Shot）→ 春光乍泄黑白段来历。
