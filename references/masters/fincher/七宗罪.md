## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. **bleach-bypass 去饱和绿暗脏调（Silver-Retention Grime）**

- **物理参数**：银盐保留工艺 · 低饱和 + 暗部 ≥65% + 黄绿灰 #4A4B3E 主调 + 高对比 + 脏感颗粒 + 黑色浓重
- **物理实现**：bleach-bypass 冲印（保留银盐）→ 暗部加深、饱和降低、颗粒变粗、脏感
- **情感意图**：整个世界像一块发霉的湿抹布 · 道德的腐烂被显影成画面的腐烂

### 2. **几乎全片持续雨（Endless Rain）**

- **物理参数**：90% 段落在下雨 + 湿街反光 + 雨打窗 + 霓虹在雨幕中晕开 + 潮湿质感（直到结尾沙漠才放晴）
- **物理实现**：人工雨 + 湿景 + 反光控制
- **情感意图**：无处可逃的压抑 · 雨是这座城市的常态绝望 · 放晴=厄运降临的反讽

### 3. **暗部手电探照（Flashlight in Darkness）**

- **物理参数**：黑暗公寓不开顶灯 + 手电光束切割黑暗 + 光只照到局部（脸/物/线索）+ 大量画面在暗里 + 光束里的尘埃
- **物理实现**：实用手电 + 极少补光 + 故意欠曝
- **情感意图**：观众与侦探一样"只能看到光照到的局部" · 黑暗里永远有看不见的东西 · 探查即恐惧

### 4. **钨丝暖点 vs 冷暗底（Warm Practicals in Cold）**

- **物理参数**：廉价台灯/吊灯钨丝暖点 2800-3200K 扎在去饱和冷暗底里 + 暖点小而孤立
- **物理实现**：实用暖光源 + 冷调环境
- **情感意图**：廉价的、无力的暖 · 在腐烂世界里微弱的人性残光

### 5. **缓慢累积 dread + 突发惊吓交替（Slow-Burn + Shock）**

- **物理参数**：大段缓慢勘查推进（缓推/稳定跟）累积压迫 + 突发刺破（懒惰尸体诈活）+ 节奏张弛
- **物理实现**：缓慢运镜累积 + 关键点突切/突动
- **情感意图**：恐惧主要靠累积（dread）· 偶尔突发刺破让累积更可怕

### 6. **反高潮冲击 + 表演双轨（Anti-Climax & Restraint↔Burst）**

- **物理参数**：永雨城市 → 结尾刺眼空旷沙漠（视觉断裂）+ "盒子"反高潮 + 表演冷峻克制 40% ↔ 沙漠爆发 90%
- **物理实现**：场景/光的极端反差 + 表演分寸两极
- **情感意图**：把高潮做成"反高潮"——最大的冲击是平静里揭示的不可逆

## 三、镜头语法 DNA（What makes this work）

1. **环境即主角**：bleach-bypass 去饱和绿暗 + 永雨，让城市本身成为压迫的来源——天气与质感先于剧情制造绝望。
2. **只照局部的手电探照**：黑暗里光只照到局部 = 观众与侦探一样"看不见的永远更可怕"；探查即恐惧。
3. **暖点的无力**：廉价钨丝暖点孤立在冷暗里 = 腐烂世界里微弱无力的人性残光。
4. **slow-burn 为主、突发为辅**：恐惧主要靠缓推累积 dread，偶尔（懒惰诈活）突发刺破，让累积更可怕。
5. **暗示 > 展示**：罪案最骇人处常不直给（盒内不给观众看），靠表演与联想承载冲击。
6. **精密稳定运镜**：Fincher 招牌的微妙 dolly + 无瑕疵机位（与社交网络同源），冷峻控制感。
7. **反高潮视觉断裂**：永雨暗城 → 结尾刺眼空旷沙漠，光与空间的极端反差完成最冷的反高潮。

## 四、声音/音乐设计 DNA

1. **持续雨声床**：几乎全片的雨成为底噪，潮湿压抑无处不在。
2. **Howard Shore 低沉压抑**：不安低频 + 克制 · 不抒情。
3. **实验性片头声画**：NIN 重混 + 刮痕影像 + 极端特写手写日记 = 进入凶手的扭曲心理。
4. **死寂↔突发**：勘案死寂 ↔ 诈活骤响的对比。
5. **图书馆暖段反差**：少数暖场（Bach + 图书馆）与全片冷暗形成喘息反差。

## 五、表演分寸 DNA

按表演分寸 4 级：

- **本片主导分寸级别**：冷峻克制 40-50%（勘案/推断）↔ 沙漠爆发 90%（Mills 崩溃 · 合法例外：极端创伤）；John Doe 死寂平静 20%（更冷）
- **演员代表性表演细节**：Somerset 冷静嗅不祥 / Mills 急躁→崩溃嘶吼 / John Doe 平静里的得逞 / 勘案掩鼻屏息

## 八、本作"禁忌"清单（不要做什么）
