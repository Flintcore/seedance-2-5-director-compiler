## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：吴宇森的分镜系统 = **"把暴力仪式化为英雄浪漫的芭蕾"**，五根支柱。① **双枪暴力芭蕾**（双手各持一枪 + 身体编舞走位[滑铲/转身/侧扑/前滚] + 弹壳/玻璃碎/血浆作可见"节拍粒子" · 单镜连续放倒多人 · 靠连贯走位非快剪）。② **升格只点关键刻**（判别铁律）：仅对击杀/中弹/对望/白鸽"那一刻"升格 0.25–0.5×（约 48–96fps 拍→24fps 放），与常速枪战形成节拍对比——**全程升格 = 变 MV，失效**。③ **白鸽 vs 暴力双对位**：纯白羽翼 + 暗调硝烟同框、枪响即惊飞、常配升格 = 纯洁/救赎与杀戮并置（吴宇森天主教信仰签名）。④ **双枪 Mexican standoff 极近对峙**（枪口≤0.5m 互指 + 静默 2–5s + 第三方打破 = "John Woo Standoff"）。⑤ **双雄镜像惺惺相惜**：对称正反打（给一方什么景别/焦段/光位就给对方镜像同款）+ 轴线由对立转同向 = 结盟可视化。空间：教堂烛光暖调 #FFB36B + 十字架/圣母/彩窗 = 罪与救赎的圣殿。这是浪漫化、男性情义的暴力诗，不是写实纪录。

**适用情境**：港式动作 · 暴力美学 · 枪战编舞 · 慢动作升格 · 双雄情义 · 罪与救赎 · 教堂枪战 · Mexican standoff 对峙 · 浪漫化牺牲。**不适用/需改造**：需要法医级写实动作的战争/纪录题材、需冷峻零浪漫的冷调犯罪、明亮均匀高调平光、无情感重量的纯爽片奇观、单手随意射击的写实枪械戏。

## 一、核心心智模型（8 个镜片 · How Woo sees a shot）

### M1 · 暴力是编舞，不是纪录
射击 = 舞蹈。先问"这段枪战的走位/节拍是什么"，再摆枪。身体走位（滑铲/转身/侧扑/前滚）与击发同步，单镜内连续放倒多人。
- **分镜含义**：给中景到全景承载连贯走位，不靠快剪堆砌数量。→ 见 §T1/§F2。

### M2 · 暴力必须有情感重量（壮烈 + 哀伤）
每一次击杀/牺牲不是奇观，是命运仪式。血浆/中弹/倒地都为"壮烈"或"哀伤"服务，不追求法医真实。
- **分镜含义**：给死亡以重量 → 关键刻升格 + 前置道德代价（如误伤无辜）。见 §M3/§T2。

### M3 · 时间可被拧慢，只在"那一刻"
主观时间膨胀用升格（高帧慢放的丝滑延长），只点击杀/中弹/对望/白鸽的瞬间，与常速形成节拍对比。
- **分镜含义**：升格是"点睛"不是"底色"。判别见 §F2（吴宇森的慢=丝滑升格，与王家卫 step-print 的顿挫涂抹相反）。

### M4 · 纯洁与暴力必须同框对位
白鸽（纯洁/灵魂/救赎）与硝烟/血浆并置——吴宇森本人称白鸽象征和平与纯洁、源自其天主教信仰（Far Out · 高）。
- **分镜含义**：想让暴力有救赎重量 → 引入白鸽振翅穿越枪战画面；纯白 vs 暗调的颜色 + 象征双对位。见 §T3/§F3。

### M5 · 敌我是一体两面（镜像）
对立双雄（如杀手 ↔ 警察）互为镜像：同款风衣墨镜造型 + 对称正反打（给一方什么就给对方镜像同款）。男性情义凌驾立场。
- **分镜含义**：两个对手是"同一种人" → 对称正反打 + 造型同款。见 §T5/§F5。

### M6 · 空间轴线 = 关系状态
构图轴线直接叙述人物关系：相向/互指轴 = 对立；并肩/背靠背同向轴 = 结盟。轴线转变 = 关系转变可视化。
- **分镜含义**：结盟瞬间把构图从对立轴转同向轴，无需台词。见 §T6/§F4。

### M7 · 对峙是凝滞的仪式（静爆结构）
生死天平用极近 Mexican standoff 拍成静止画面：枪口≤0.5m 互指 + 静默 beat + 第三方闯入打破。张力靠"无声"蓄满，再爆发。
- **分镜含义**：对峙先静（枪声归零、只剩屏息/环境声）再爆——静爆节奏。见 §T4/§H。

### M8 · 空间即道德背景（教堂/宗教意象）
教堂作为终局战场：烛光暖调 + 十字架/圣母/彩窗反复入框 + 硝烟成光柱（God ray）。罪与救赎主题的空间外化——杀手在神的注视下赴死。
- **分镜含义**：要"救赎/审判"的道德重量 → 把战场设进教堂，宗教道具入框作背景。见 §T7。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 暴力编舞 / 走位
- **H1** 要枪战有"舞"感 → 双手各持一枪 + 身体编舞走位（滑铲/转身/侧扑/前滚翻）+ 每次击发同步抛壳；中景到全景给连贯走位，单镜连续放倒多人。
- **H2** 要暴力有可见"节拍" → 弹壳金黄抛物线 0.3–0.6m + 玻璃中弹蛛网→碎裂 + 血浆背向迸溅 0.5–1.2m + 枪口火焰橙黄，作可见"节拍粒子"。
- **H3** 别用快剪堆数量 → 动作连贯靠走位承载，快剪碎剪会毁掉编舞的优雅（§F2）。

### B. 升格 / 时间
- **H4** 关键击杀/中弹/对望/白鸽"那一刻" → 升格 0.25–0.5×（约 48–96fps 拍、24fps 放）+ 持续 1–3s；弹壳/血浆/羽翼在慢速中悬浮拉长。
- **H5** 要更极端的凝固悲剧（如误伤/牺牲） → 升格趋 0.25×（约 96fps）+ 锁定机位。
- **H6**（铁律）升格**只点关键刻**，不全程——全程升格 = 失去节拍对比、变 MV（§F2）。
- **H7** 吴宇森的"慢"是**丝滑升格**（frame blending 柔混连续），**不是** step-print 顿挫涂抹（与王家卫相反）。

### C. 白鸽 / 意象
- **H8** 要救赎/纯洁对位 → 教堂/室内常驻白鸽群，枪响即惊飞、慢速振翅穿越枪战画面上半。
- **H9** 白鸽必须有意义 → 只配教堂/升格/关键刻用；乱撒当装饰会失效（§F3）。
- **H10** 要颜色+象征双对位 → 纯白羽翼 + 暗调硝烟/血浆同框，白 vs 暗高对比。

### D. 对峙 / 双雄
- **H11** 要生死天平凝滞 → 双枪 Mexican standoff：枪口距对方头/胸 ≤0.5m + 一左一右对称 + 静默 beat 2–5s + 第三方闯入打破。
- **H12** 对峙静爆 → 对峙时枪声归零、只剩屏息/海浪/枪械金属轻响蓄张力，再爆发（§M7）。
- **H13** 对手互相辨认 → 对称正反打（OTS 越肩 A→B 与 B→A 两机位镜像 · 同焦段/同景别/同光位）。
- **H14** 双雄造型 → 同款风衣/墨镜，强化"一体两面"（§M5）。

### E. 空间轴线 / 光影 / 色彩
- **H15** 结盟瞬间 → 构图轴线从对立（相向/互指）转同向（并肩/背靠背），空间叙述关系（§F4）。
- **H16** 背靠背并肩 → 各朝相反方向双枪戒备构成对称轴心，缓慢 orbit 环绕 0.15 m/s 强化二人一体。
- **H17** 要"罪与救赎"道德背景 → 战场设进教堂，十字架/圣母/彩窗入框，硝烟成光柱 God ray。
- **H18** 教堂调色 → 烛光暖 #FFB36B 2400–2900K 大量点光摇曳 + 暗部 50–60% + 圣像彩窗微透冷光（暖暗高对比，非平光）。
- **H19** 欲望/暴力场（夜总会等） → 暖红琥珀 #C8783C 3000K + 舞台追光 + 烟雾散射 + 暗部 50%。
- **H20** 对峙/疏离场 → 偏冷自然光 4800K + 侧窗光 + 暗部 45%（与暖调救赎场对位）。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · "是否算吴宇森式枪战"判别（暴力芭蕾五件）**
```
需同时满足 ≥4：① 双手持枪 ② 身体编舞走位（非站桩射击）
③ 弹壳/玻璃碎/血浆可见"节拍粒子" ④ 单镜连续放倒多人（走位承载非快剪）
⑤ 关键刻升格点睛
缺双枪 = 港式写实枪战；缺编舞走位 = 站桩爽片；缺升格 = 无仪式感。
```

**F2 · 升格纪律判别（点刻 vs 全程 / 升格 vs step-print）**
```
升格只点【击杀/中弹/对望/白鸽】那一刻（1–3s）→ 与常速枪战节拍对比 ✔
全程升格 → ❌ 变 MV、失去对比
吴宇森"慢" = 丝滑升格（高帧慢放·连续柔混）≠ 王家卫 step-print（降格顿挫涂抹）
```

**F3 · 白鸽有效性判别（意象纪律）**
```
白鸽 = 纯洁/救赎信号，必须满足：① 配教堂/室内神圣空间 或 关键升格刻
② 与硝烟/血浆同框对位（白 vs 暗高对比） ③ 枪响即惊飞、慢速穿越画面
三者缺一 → 沦为随机装饰、失去象征价值（红线）。
```

**F4 · 轴线关系判别（对立 vs 结盟）**
```
构图相向轴 / 互指枪口 = 对立、试探、敌我
构图同向轴 / 并肩 / 背靠背 = 结盟、信任、一体
关系转变 → 让轴线从对立转同向，无需台词点明
```

**F5 · 双雄镜像判别（一体两面）**
```
两个对手是"同一种人" → 对称正反打：给 A 什么【景别+焦段+光位】就给 B 镜像同款
造型同款（风衣/墨镜）+ 英雄对望长 beat
目的：让观众读出"惺惺相惜"，情义凌驾立场
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 双枪暴力芭蕾** ｜机制：把射击当舞蹈编排｜参数：双手各持一枪同时射击 + 身体编舞走位（滑铲/转身/侧扑/前滚）+ 击发同步抛壳（弹壳金黄抛物线 0.3–0.6m）+ 中景到全景连贯走位、单镜连续放倒多人｜触发：主角于枪林弹雨中立威/突围｜意图：暴力仪式化为残酷的优雅、从容与悲壮｜正例：喋血双雄 §场景 B 夜总会双枪暴起（masters/john-woo/喋血双雄.md §B-2）、辣手神探茶楼/医院长镜枪战（库外·代表性）。

**T2 · 升格诗化击杀** ｜机制：仅对"那一刻"升格 · 与常速节拍对比｜参数：升格 0.25–0.5×（约 48–96fps 拍→24fps 放）+ 持续 1–3s + 弹壳/血浆/碎玻璃慢速悬浮拉长 + 风衣/窗帘慢速翻飞 + frame blending 柔混（非 step-print）｜触发：关键击杀/中弹/牺牲/对望｜意图：把杀戮提升为命运仪式、壮烈又哀伤｜正例：喋血双雄 §B-3 枪口火焰灼伤珍妮致盲升格 0.25×、§A-4 小庄中弹升格 0.3×（喋血双雄.md）。

**T3 · 白鸽 vs 暴力对位** ｜机制：纯洁意象 + 暗调暴力同框｜参数：教堂/室内白鸽群 · 枪响即惊飞 + 白色羽翼在暖光中划过画面上半 + 常配升格 0.4× + 与硝烟/血浆同框（白 vs 暗高对比）｜触发：教堂枪战/救赎主题/关键刻｜意图：纯洁/灵魂/救赎与杀戮并置（吴宇森天主教签名）｜正例：喋血双雄 §A-2 双枪开火 + 白鸽惊飞升格、§A-5 白鸽掠过硝烟（喋血双雄.md）；变脸/断箭亦见白鸽（库外）。

**T4 · 双枪 Mexican standoff** ｜机制：把生死天平拍成静止仪式｜参数：两人各持枪互指对方头/胸 + 枪口≤0.5m 极近 + 一左一右对称构图 + 静默凝滞 beat 2–5s + 偶配升格 + 第三方闯入打破｜触发：双雄试探/信任临界/背叛边缘｜意图：生死天平的凝滞、信任与背叛的临界（"John Woo Standoff"）｜正例：喋血双雄 §C-1 海边屋双枪互指（喋血双雄.md §C-1）；英雄本色/辣手神探反复运用（库外·标志性）。

**T5 · 双雄对称正反打镜像** ｜机制：对手拍成一体两面｜参数：OTS 越肩正反打（A→B 与 B→A 两机位镜像）+ 同焦段/同景别/同光位 + 造型同款风衣墨镜 + 英雄对望长 beat｜触发：敌对双雄相互辨认/道义认同｜意图：敌我是"同一种人"、情义凌驾立场｜正例：喋血双雄 §C-2 互指枪口正反打镜像、§C-4 弹尽对望会心（喋血双雄.md）。

**T6 · 轴线对立→同向（结盟可视化）** ｜机制：构图轴线叙述关系｜参数：对峙=相向/互指对立轴 → 结盟=并肩/背靠背同向轴；转身时轻微横移随二人｜触发：敌对双雄由对立转结盟｜意图：空间关系转变 = 人物关系转变，无需台词｜正例：喋血双雄 §C-3 警匪并肩转向同敌双枪齐射（喋血双雄.md §C-3）。

**T7 · 背靠背双雄并肩** ｜机制：同向对称轴心 + 环绕｜参数：二人背靠背各朝相反方向双枪戒备构成对称轴心 + 缓慢 orbit 环绕 0.15 m/s + 烛光/光圈住二人｜触发：双雄并肩赴死/共同御敌｜意图：贴背默契与信任、二人一体｜正例：喋血双雄 §A-3 教堂背靠背双枪（喋血双雄.md §A-3）；英雄本色续作亦见（库外）。

**T8 · 教堂救赎空间** ｜机制：宗教空间外化罪与救赎｜参数：教堂内景 · 烛光暖 #FFB36B 2400–2900K 大量点光摇曳 + 十字架/圣母像/彩窗剪影 + 暖暗高对比（暗部 50–60%）+ 硝烟成光柱 God ray｜触发：终局枪战/赎罪/在神注视下赴死｜意图：暴力的圣殿、道德背景｜正例：喋血双雄 §A-1 教堂烛光全景 + 白鸽栖息（喋血双雄.md §A-1）。

**T9 · 静爆对峙节奏** ｜机制：静默蓄张力→爆发｜参数：对峙段枪声归零、只剩屏息/环境声（海浪/风）/枪械金属轻响 2–5s → 第三方或一方动作触发瞬间爆发常速枪战｜触发：Mexican standoff / 决战前的凝滞｜意图：以"无声"蓄满张力、爆发更有落差｜正例：喋血双雄 §C-1 海边屋对峙静默（喋血双雄.md）；辣手神探对峙（库外）。

**T10 · 暖色点光暴力场** ｜机制：暖色情绪块 + 高对比暗部（非平光）｜参数：欲望场=暖红琥珀 #C8783C 3000K + 舞台追光 + 烟雾散射 + 暗部 50%；救赎场=烛光暖 #FFB36B；对峙场=偏冷 4800K 侧窗光 + 暗部 45%（三场色温对位）｜触发：夜总会/教堂/海边屋等不同情绪场｜意图：色彩即情绪场坐标（欲望/救赎/疏离）｜正例：喋血双雄 §B-1 夜总会暖红、§A 教堂烛光、§C 海边屋偏冷（喋血双雄.md）。
