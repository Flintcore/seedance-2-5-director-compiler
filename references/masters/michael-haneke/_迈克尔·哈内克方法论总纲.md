# 迈克尔·哈内克(Michael Haneke)方法论总纲

> 导演级·跨作品·非单片拉片。焦点：固定机位静观长镜 · 离场暴力(暴力在画外) · 冷峻中远景疏离(拒特写) · 自然光无配乐 · 打破第四面墙元电影。
> 合作摄影师：**Christian Berger**(Benny's Video / 71 Fragments / 钢琴教师 / Caché / 白丝带 / Happy End，6 片) · **Jürgen Jürges**(Funny Games 1997) · **Darius Khondji**(Funny Games U.S. 2007)。
> 标注规则贯穿全文：**[原话]**=当事人逐字直引 · **[转述]**=可靠影评/行业刊转述 · **[推断]**=编者综合观测，无一手规格。

---

## ⓿ 索引摘要 · 超浓缩 DNA(≤300字)

摄影机是**监控器，不是叙事者**。默认 `locked-off tripod`，全程 0 运镜，眼平 ~1.5m[推断]，单镜 3–10 分钟实时不切。景别锁 **MS→ELS**，人占画高 ≤1/3，空间>人;**特写是稀缺资源，只留给"打破第四面墙"，绝不用来安慰情绪**(哭戏特写=Haneke 骂的"pornography of emotions")。暴力**推出画框**：只给画外枪声/尖叫 + 事后空镜(尸体不在焦点,前景放血溅电视机)。光=**单一主光方向**(Berger:"Nature never uses several lamps"),CRLS 反射柔光,单灯 ≤1200W,光比 1:7–1:10,保留硬阴影塑形拒全局柔化。**0 条 non-diegetic 配乐**(Haneke:"I never use scores"),音乐只在画内有声源时存在;环境声(苍蝇/麦浪/脚步)+ 沉默是素材。黑白=彩负拍摄后期去色,S=0,高反差深黑。元电影:ECU 直视镜头 + 恶意眨眼压在暴行前一刻 + 遥控倒带撤销观众的宣泄。判据:一场戏一颗定焦,靠亮度→锐度引导视线,不靠推拉。

## 一、核心心智模型(8个)

### MM-1 · 摄影机=监视器,不是叙事者(The Camera as Surveillance Apparatus)
- **定义**：镜头不引导、不共情、不"讲述"，只是一台已经架好、被动记录的机器。观众必须自己扫描画框找信息。
- **出处**：Caché 开场把"客观静止广镜"数分钟后追认为**监视录像**(rewind/FF 线闪过画面)[转述, Ebert/ProjectedFigures]；风格综述"denies the audience guidance to key elements within the frame"[转述]。
- **分镜含义**：`locked-off tripod`，机器"在事件发生前就已到位"，中心不设视觉引导，人物是"经过"画框的小元素。

### MM-2 · 实时不可操纵(Real Time = Un-manipulated Time)
- **定义**：长镜的首要理由是**不篡改时间轴**，拒绝用剪辑加速/浓缩，让观众承受事件的真实持续。
- **出处**：Haneke [原话, 经 No Film School 转录]"First, you're not manipulating the timeframe. It's real time… you can eliminate this kind of manipulation."
- **分镜含义**：单镜 3–10 min 不切；日常/暴力前奏/事后余波全部实时走完，禁蒙太奇压缩。

### MM-3 · 让观众"完成"这部电影(Make the Spectator Finish the Film)
- **定义**：不给答案、不给闭合。信息、暴力、情绪都留白，逼观众用想象力补全——补全即卷入。
- **出处**：Haneke [原话]"Only bad films provide answers and explanations for everything."[Paris Review 2014]；[原话]"call on the imagination of the spectator… have them finish your film for you"[转述]。
- **分镜含义**：退到 MS/WS 而非特写；暴力移出画框只留声；关键对话可**故意静音**(Caché 结尾两少年，Haneke 写了台词但令演员保密)[转述]。

### MM-4 · 离场原则:展示最小值(The Off-Screen Principle / Show the Minimum)
- **定义**：暴力越藏越狠。直给暴力=色情化(pornography of violence)；把它推到画外，用声音承载冲击，画面留白。
- **出处**：Berger [原话]"provoke the violence… and to show the minimum from it… otherwise it's just pornography"；Haneke [原话]"I don't actually depict much physical violence."[Paris Review 2014]。
- **分镜含义**：机位不动、不 pan 向暴力、不切；只留画外枪声/尖叫 + 事后尸位空镜。

### MM-5 · 反情绪色情:拒特写做安慰(Anti-Pornography of Emotions)
- **定义**：不用大特写去榨取/贩卖情绪(哭戏、悲恸、死亡)。距离=尊重也=不适。特写被"节流"，专留给越界时刻。
- **出处**：Haneke 把哭戏特写称"pornography of emotions"[转述, Senses of Cinema/Medium]。
- **分镜含义**：母亲悲恸不给哭戏 ECU；用 MS/WS 静观；把特写额度存给 MM-8 的直视镜头。

### MM-6 · 观看即共谋(Spectatorship as Complicity)
- **定义**：观众看银幕暴力这一行为本身是道德对象。用画框套画框(监视器/取景器)、前景电视机、直视招募，把"你在看"这件事挑明并追责。
- **出处**：Benny's Video 杀戮只经**监视器画面**呈现，真实动作溢出内框[转述]；Funny Games 事后镜前景放**血溅电视机**播赛车/灾难新闻[转述]；下注台词 `"You're on their side, aren't you?"`[原话·台词]。
- **分镜含义**：frame-within-a-frame(低分辨率/时码 OSD)；前景媒介物与惨状并置；人物转头对镜头招募。

### MM-7 · 现实无配乐(Reality Has No Score)
- **定义**：现实生活没有背景音乐，因此写实电影也不能有。音乐只能来自画内声源。声音是主通道。
- **出处**：Haneke [原话]"I only use music diegetically. I never use scores, because I make realist films and there is no musical accompaniment to reality, unless… the radio is on."[Paris Review 2014]；[原话]"your ears are more sensitive than your eyes."[Electric Sheep 2012]。
- **分镜含义**：0 条 non-diegetic 配乐；环境同期声(room tone/苍蝇/麦浪/脚步)+ 沉默；音乐仅当画内有源(收音机/钢琴/唱片)。

### MM-8 · 元电影自反:戳破幻觉即控诉操纵(Meta-Cinema / Rupture as Indictment)
- **定义**：故意打破"这只是电影"的安全幻觉——直视、眨眼、遥控倒带——以此证明观众被操纵的程度，并夺走他们的宣泄。
- **出处**：Haneke [原话]"You're not supposed to break the illusion. What do I do? I break the illusion… I look at the viewer directly, I talk to him, I wink at him."；[原话]"First they think it's all an illusion, just a film, then I do this rewinding and suddenly you go back."[CinemaBlend 2008]。
- **分镜含义**：ECU 直视 + 眨坏笑，**压在暴行前一刻**；给观众爽点(反杀)后立即倒带撤销。

## 二、决策启发式(≥18条 if-then)

### A. 机位 / 运镜
1. if 任意场景 → then 默认 `locked-off tripod`，0 运镜；prompt 禁写 dolly/handheld/whip/zoom/push-in。
2. if 一整场戏 → then 用**场面调度(演员走位)替代剪辑**，一镜走完，不切正反打[转述 Berger:"replaces editing with mise-en-scène"]。
3. if 构图必须变化但要保持"静" → then 机位留原地，靠演员走位改变构图；若必须轻移，须"maximum of minimalism"且**与演员动作精确同步**[转述]，观感仍是静的。
4. if 要"隐藏摄像机/监控"感 → then 机器**在人物入画前就已运行** + 零运镜 + 滞留到超过舒适阈值。
5. if 唯一允许的"运动"(极少数) → then 用 Steadicam 极缓长镜 + 活光圈(见 #15)，仍克制(正例 Happy End 法国别墅)。

### B. 景别 / 焦距 / 构图
6. if 想用特写强化情绪 → then **退到 MS/WS**，让观众自己完成(MM-3/MM-5)；特写额度留给直视镜头。
7. if 一场戏 → then **锁一颗定焦**贯穿整场(Berger[转述]:"uses only one lens" per scene)，不切广角↔长焦，保持观众空间定位；Cooke 定焦 + Alexa。
8. if 构图 → then **正面(frontal)+对称**，但**故意破一点对称**(如沙发一侧有台灯另一侧空)制造不安[转述]。
9. if 交代关键情节/命案 → then 放**远景(distant long shot)**，人 < 空间，人占画高 ≤1/3。
10. if 血/尸必须在画内(事后镜) → then 构图上**移出视觉焦点或延迟辨认**(数秒才看见)，而非居中特写。

### C. 暴力调度(先分类再选模板,见判别式§三)
11. if E=可想象补全的极端伤害(枪杀/割喉/爆头) → then 藏起来(Type-A 声画分离 或 Type-B 事后空镜)。
12. if E 关乎"观看即共谋"母题(媒体暴力/偷拍) → then 只经监视器/取景框呈现(Type-C，画框套画框)。
13. if E 是全片道德支点、要观众无处可逃 → then **例外**：当众直拍且拒剪(Type-X，如 Caché 割喉自杀)。
14. if 拍杀戮当刻 → then 摄影机**离开现场**去拍施暴者做无关动作(做三明治)，惨剧在画外只给声。

### D. 光 / 曝光
15. if 镜头内主体从暗走入亮(或反之) → then 曝光**不锁死**，用活光圈让高光溢出/暗部下沉一次,模拟瞳孔适应(Happy End 遥控 iris T2.8–f/22)[转述]。
16. if 室内白天 → then 光**只从一扇窗来**，反射补面，**无第二可辨方向光**，no backlight/rim(MM-7 光版:"Nature never uses several lamps")。
17. if 夜/暗景 → then 火光(蜡烛/油灯/火把)motivate，**深黑高反差**，暗部留纹理不填死黑。
18. if 想要软光但怕拍平 → then 用**定向反射**不做全场漫射；保留脸上方向性明暗与房间纵深，避免"looks like you used milk or yogurt… everything is smoothed, flat"[原话 Berger]。

### E. 声音 / 音乐
19. if 有音乐需求 → then **必须画内给出声源**(收音机/钢琴/唱片)，否则删除该音乐(0 non-diegetic)。
20. if 要"离场暴力"生效 → then **必须同时关掉** 配乐 + 音效强化 + 反应镜快切；三者任一开启即破功。

### F. 元电影 / 打破
21. if 想让观众爽(反杀/救援成功) → then **紧接着撤销它**(倒带/角色否认)，夺走宣泄，制造共谋不适。
22. if 要打破第四面墙 → then **压在最血腥/最不忍看的节点**，用 ECU 直视 + 眨眼；不要放在轻松/搞笑段落。
23. if 全片都在给特写 → then 打破失效；**特写必须稀缺**(全片 MS/WS 静观)，才有落差。
24. if 要"距离感"/年代感 → then 用黑白(Haneke[原话]:"Black & white give immediately a distance")，且用**彩负拍摄后期去色**而非仿旧胶片。

## 三、判别公式(≥5个·可测)

```text
# F1 · 监控凝视判别(Surveillance Gaze)
Haneke_gaze = (机位锁死==True) AND (单镜时长 >= 3min) AND (主体==空间/物 NOT 人脸)
                                 AND (画面中心无视觉引导)
# → 全 True: 观众被迫自己扫框找信息 = Haneke 式静观。任一 False → 普通固定镜。
```

```text
# F2 · 冷峻疏离构图 6 条打分(命中 >=5 才算 Haneke)
score = sum([
    机位 == "static tripod (0 运镜)",      # 1
    景别 >= "MS" AND 人占画幅 < 空间占画幅,  # 2
    构图 == "frontal/对称 且 微破一点",      # 3
    一场戏 == 单一定焦贯穿,                  # 4
    non_diegetic_score == 0,               # 5
    暴力 in {"画外","远景"},                # 6
])
# score >= 5 → Haneke 冷峻疏离；否则普通固定镜。
```

```text
# F3 · 暴力三分时序(先分类再选调度)
def classify_violence(E):
    if E.正在发生 and 摄像机.看别处:        return "Type-A 声画分离"   # → 模板卡 C2
    if E.已结束   and 只拍现场/遗留/反应:    return "Type-B 事后空镜"   # → 模板卡 C3
    if E.只经监视器/取景框呈现:             return "Type-C 框内媒介"   # → 模板卡 C4
    if E.是道德支点 and 需观众无处可逃:      return "Type-X 当众直给"   # → 例外, 拒剪
```

```text
# F4 · "够不够 Haneke 事后镜"
Haneke_aftermath = (单镜不切==True) AND (视觉焦点 != 尸体) AND (前景有媒介物 如TV)
                                     AND (non_diegetic_score==0) AND (时长==真实实时)
# 全 True 才算；血/尸居中特写 + 配乐 = 直接失格。
```

```text
# F5 · Haneke 式元电影打破(命中 >=3 才算, 否则是普通打破/炫技)
meta_rupture = sum([
    直视镜头 落在 ECU 且 紧贴一场暴行的前一刻/进行时,   # ①
    打破 加重不适 且 指认观众为共犯 (非搞笑/卖萌/耍帅),  # ②
    打破前后 其余镜头 维持冷静静观 (形成落差),           # ③
    存在 "撤销宣泄" 动作 (倒带/否认受害者胜利),          # ④
]) >= 3
```

```text
# F6 · 单源光合规(CRLS 精神)
single_source_ok = (可辨识独立光源方向数 == 1) AND (单灯功率 <= 1200W)
                    AND (rim/backlight 存在 == False) AND (全场漫射柔化 == False)
                    AND (阴影塑形/纵深 保留 == True)
# 光比目标 1:7 ~ 1:10(强反差, 暗部有细节)。
```

## 四、标志性技法卡片(10张·五件套)

> 说明：以下技法**均非哈内克独创**(长镜头/自然光/离场暴力/深焦/打破第四面墙/黑白皆早于其存在)。本文写其**标志性运用/集大成**，不写"发明/首创/鼻祖"。

### 卡C1 · 监视器凝视开场镜(Surveillance Gaze Opener)
- **机制**：完全锁死的静止广镜长时间凝视一个平淡空间,数分钟后揭示是监视录像,把"客观"追认为"偷窥"。
- **参数**：机位 tripod locked-off,0 运镜；机高站立眼平 ~1.5–1.6m[推断]；焦段广角~标准,人占画高 ≤1/3,空间/门/街为主体；时长单镜 **3–5 min**[各源不一,见存疑]；环境音(鸟鸣/脚步)+1–2 微动作。
- **触发条件**：需要在片头/片中建立"被监视/观看即共谋"母题。
- **情感意图**：不安、被剥夺引导、观众成偷窥者。
- **正例**：**Caché(2005)** 开场 rue des Iris 住宅外墙 + 蓝路牌,静止数分钟后 rewind 线揭示是录像带；终镜复用同款静止广镜。

### 卡C2 · 声画分离·摄像机看别处(Off-Screen Kill, Camera Elsewhere)[Type-A]
- **机制**：暴力正发生但摄影机聚焦旁观者/无关动作,暴力主体完全出框,唯一证据是画外音。
- **参数**：固定三脚架 0 运镜,眼平 ~1.5m；MS/中近景聚焦旁观者(做三明治的凶手)；焦距 ~35–50mm 等效[推断]；暴力=画外枪声/尖叫,无配乐无音效强化；暴力瞬间不切。
- **触发条件**：极端可想象伤害(枪杀),要"藏起来更狠"。
- **情感意图**：想象补全>直给,拒绝暴力色情化。
- **正例**：**Funny Games(1997)** 儿子 Georgie 被猎枪打死时,**摄像机跟凶手 Paul 去厨房做三明治**,杀戮全程画外仅一声枪响。

### 卡C3 · 事后空镜·尸位长镜(Static Aftermath, Corpse Off-Focus)[Type-B]
- **机制**：暴力已结束,机器滞留现场实时长拍,尸体/血不在焦点(数秒才辨认),前景放电视机并置惨状。
- **参数**：单镜长镜 **≈8–10 min 不切**[口径,非帧级实测]；机位固定且事件前已到位；焦点非尸体；前景电视机播赛车/灾难新闻,屏幕血溅；0 配乐；呆滞/真实时间流逝的表演(爬行、解绑)。
- **触发条件**：要观众与后果长时间共处、直面自己与银幕暴力的关系。
- **情感意图**：难熬即目的(观众想快进=Haneke 要的自省)。
- **正例**：**Funny Games(1997)** Georgie 死后**约10分钟固定单镜**,母亲挣扎解绑,血在墙,电视仍开。

### 卡C4 · 框内媒介·画框套画框(Frame-within-a-Frame Violence)[Type-C]
- **机制**：暴力只经录像监视器/取景器/回放出现,真实动作溢出内框边缘,尖叫来自画外。
- **参数**：外层机位固定；内框=低分辨率家用摄像质感(可降采样/隔行/时码 OSD)；受害者爬出监视器画面外,杀戮主体不在内框可见；时长数分钟；可加"遥控倒带现实"母题。
- **触发条件**：暴力母题=媒体/偷拍/"观看即共谋"。
- **情感意图**：把"你在通过屏幕看"这件事挑明并追责。
- **正例**：**Benny's Video(1992)** 猎枪杀少女——只见 Benny 摄像机记录的**监视器画面**,动作大半溢出框外,痛苦仅靠尖叫,随后监视器显示她爬出画面、Benny 重新装弹补射。

### 卡C5 · 例外·当众直给拒剪(Direct, Un-cut Exception)[Type-X]
- **机制**：极少数关键暴力反而全程直拍且拒切走,恰因平时藏起来,此处"直给且不给解脱"最具冲击。
- **参数**：固定长镜,机器在人物进屋前已就位(隐藏/监控视角)；MS/中近景,人物入画后施暴,血喷上墙；**无预警、无配乐、无铺垫**——突发；事发后**拒绝切走**,滞留于尸体与呆立者;目击者背对尸体(不给宣泄)。
- **触发条件**：该暴力是全片道德支点,要观众无处可逃。
- **情感意图**：剥夺一切缓冲与宣泄。
- **正例**：**Caché(2005)** Majid 当着 Georges 面**割喉自杀**——直拍非画外(**纠错点:常被误列为离场暴力**),机器拒切,滞留呆立者。

### 卡C6 · 单源反射光(Single-Source Reflected Light / CRLS)
- **机制**：只用反射光绝不直打,1 个近日光平行光束 + 约 6–7 种反射板"分配"同一光源,模拟自然只有一个太阳。
- **参数**：单灯 ≤**1200W**(=吸尘器功率),总耗电约常规 **1/7–1/10**;硬件 Panibeam RLS-70(1.2kW)/RSL-40(800W)打向 Paniflector 反射板,光经反射落到脸/墙;**光比 1:7–1:10**(强反差暗部有细节);保留阴影塑形拒全局柔化。
- **触发条件**：任何要"自然感"且不拍平的场景(2001《钢琴教师》起,早期片不适用)。
- **情感意图**：写实、人物"以自己的光发亮,像最好的油画"[原话]。
- **正例**：**白丝带(2009)** 教堂戏室内零灯,仅窗外 Panibeam + 反射板打进来[转述 ICG]；**Happy End** 主光=一栋房子的反射[原话]。

### 卡C7 · 活光圈·眼睛适应(Live Iris / Eye Adaptation)
- **机制**：一镜内遥控光圈连续变化,模拟人眼从暗到亮的瞳孔适应,曝光不锁死。
- **参数**：Happy End 遥控 iris **T2.8–f/22** 一镜内连续变(Berger[原话]:"the iris never stops")；主体穿越明暗时让高光溢出/暗部下沉一次。
- **触发条件**：镜头内主体跨越明暗区(暗处走入亮处或反之)。
- **情感意图**：拟真人眼、拒"全程正确曝光"的机械感。
- **正例**：**Happy End(2017)** 法国别墅长镜,光圈 f2.8½→f22 随人眼适应连续变化(全片罕见的"运动"例子,仍极克制)。

### 卡C8 · 现代黑白·彩负去色(Modern B&W via Desaturated Color Negative)
- **机制**：数字/彩色负片拍摄→DI 后期抽色去饱和成黑白,非直接拍黑白片;目标是抽象间离而非旧胶片怀旧。
- **参数**：白丝带=35mm 1.85:1,日景 Kodak Vision3 **5207**(250D 日光),夜/暗内景 **5219**(500T 钨丝),Moviecam Compact,**Cooke S4 夜戏常全开 T2**,4K 扫描；调色 S→0(完全去饱和)、高反差深黑、暗部留纹理;参考 Good Night and Good Luck、Deakins《The Man Who Wasn't There》。
- **触发条件**：要年代感/距离感(Haneke:"Black & white give immediately a distance")。
- **情感意图**：即时距离、间离、"modern black and white / clear crisp contrast"。
- **正例**：**白丝带(2009)** 全片；室内只用 1914 实景光(壁炉/油灯/少量蜡烛),夜外景火把 motivate;Haneke 反复要求更暗(Berger[原话玩笑]:"Haneke would have wanted it darker")。

### 卡C9 · 零配乐·环境同期声(No Score / Diegetic Sound Only)
- **机制**：全片 0 条 non-diegetic 配乐,音乐只在画内有声源时存在;声音是主通道,沉默是素材。
- **参数**：`no musical score`;环境声=room tone/苍蝇嗡/麦浪/脚步/街噪/家电/呼吸;音乐 present ONLY if 画内源(radio/piano/record player);沉默用于放大情感距离。
- **触发条件**：所有写实场景(=全部)。
- **情感意图**：拒操纵、写实、把冲击交给声音与静默。
- **正例**：**Amour(2012)** 无配乐,钢琴音乐仅来自画内钢琴师(严格说有一处 sound-bridge 过渡例外,见存疑)；**Caché** 几乎无任何配乐,靠街噪与静默。

### 卡C10 · 直视镜头·恶意眨眼 + 遥控倒带(Direct-Address Wink + Rewind)
- **机制**：人物转头正对镜头轴线,眨眼/坏笑打破幻觉,压在暴行前一刻;给观众爽点后用遥控倒带撤销,证明"这只是电影"恰是最激怒人的一击。
- **参数**：**ECU**,人物转头正对镜头轴线,faint devious smile + 单次刻意 wink,静止画框,无音乐无音效强调;全片打破共 **5 次**(坐实:眨眼/下注/片尾坏笑 3 次 + 倒带,第 4/5 次动作存疑);下注台词 `"You're on their side, aren't you?"`;倒带用**真实录像带式回放感**(图像倒放),非转场特效。
- **触发条件**：观众快撑不住时把其抽离/要撤销刚给的宣泄。
- **情感意图**：指认观众为共犯、展示操纵程度、夺走宣泄。
- **正例**：**Funny Games(1997)** 第1次打破≈开场30分钟 Paul 转头 ECU 坏笑+眨眼[≈时点存疑]；下注戏 Paul 问观众 `"You're on their side, aren't you?"`；Anna 抢枪打死 Peter 后 Paul 用遥控器把影片倒回撤销反杀。

### 跨库对照(与库内其他大师区分,便于混用时定调)
- **vs 斯皮尔伯格**：斯氏用运镜/配乐/特写主动共情引导;哈内克反之——静止、零配乐、拒特写、拒引导。二者几乎互为镜像,勿混配乐轨。
- **vs 常规写实**：都用自然光,但哈内克**单源+保留硬阴影**,不做常规软光全局柔化(F6)。

## 七、禁忌清单 ❌

1. ❌ 任何 non-diegetic 配乐 / 情绪弦乐 / 打击乐煽情(F5/C9)——音乐无画内源即删。
2. ❌ 哭戏/悲恸/死亡的大特写("pornography of emotions")——退到 MS/WS。
3. ❌ 暴力慢镜 + 血浆 + 多机位剪辑;❌ 摄影机 pan 向暴力、切向暴力。
4. ❌ dolly / handheld / whip pan / zoom / push-in 等主动运镜(默认全禁)。
5. ❌ 一场戏内切换广角↔长焦多颗镜头——锁一颗定焦。
6. ❌ 三点布光 / rim light / backlight / 橙蓝对比 / 暖调 rim(单源反射,无第二方向光)。
7. ❌ 全局柔光把画面拍平("milk or yogurt… smoothed, flat")——保留硬阴影塑形。
8. ❌ 用剪辑压缩/加速时间(蒙太奇)——实时单镜不切。
9. ❌ 中心视觉引导 / 明确告诉观众看哪——留白让观众自己扫框。
10. ❌ 给观众干净的宣泄/胜利结局——给了要撤销(倒带/否认)。
11. ❌ 把打破第四面墙拍成搞笑/耍帅——必须加重不适、指认共谋、压在暴行前一刻。
12. ❌ 把 Caché 割喉当"离场暴力"正例——它是 Type-X 直拍例外(纠错点)。
13. ❌ **写"哈内克发明了 X"**(长镜头/自然光/离场暴力/深焦/打破第四面墙/黑白皆非其独创)——只写"标志性运用/集大成"。
14. ❌ 给 ECU / 机高 / 焦距编造精确 mm 数——一手无规格,用语义标签(ECU/eye-level ~1.5m[推断])。

### [存疑 / 纠错 / 推断] 明确标注
1. **[纠错·高优先]** **Caché 割喉自杀=直拍,非画外**。网上常被误列为"离场暴力"。它属**例外 Type-X**(卡C5)。分镜师勿当离场暴力正例。
2. **[纠错]** CRLS 首用片是《钢琴教师 The Piano Teacher》(2001,2000 起做原型),**非 Polanski《The Pianist》**(与 Berger/Haneke 无关)。早期片(Benny's Video/71 Fragments)非 CRLS,冷峻疏离构图成立但**布光模板不适用**。
3. **[存疑·时长]** Caché 开场时长各源不一("more than three minutes"[credits] / "about five minutes" / ~2.5′)——取 **3–5min 区间,勿写死单一数字**。
4. **[存疑·时长]** Funny Games 儿子死后长镜"≈10min"、钢琴教师"≈7min"、首次打破"≈开场30分钟"——均为影评口径,**非帧级/一手实测**,复用取区间勿当精确值。
5. **[存疑·计数]** Funny Games "5 次打破第四面墙":Criterion/Wiki 均记 5 次,但**第 4/5 次具体动作二手源未完整列出**;本文只坐实 眨眼/下注/片尾坏笑 3 次 + 倒带,**第 4/5 次内容存疑**。
6. **[推断·无一手规格]** **机高 ~1.5m、焦距 35–50mm、ECU 焦距、"冷灰"全片色调**：Haneke/Berger **一手访谈明确拒绝给** Kelvin/f-stop/焦距/机位精确数字(Berger 强调"观察非量化")。本文所有 mm/机高/色温均为按成片观测的**[推断]**,落地按此起手再微调,**非厂标参数**。
7. **[存疑]** 光比 1:7–1:10 是 Berger 谈 CRLS **通用值**[转述],非逐片实测;色温 Kelvin 具体值一手拒给。
8. **[存疑·例外]** Amour "0 配乐"有一处 **sound-bridge 过渡**(intra-diegetic 钢琴经声桥转 non-diegetic,学者分析 Studies in French Cinema)——严格说是声桥非传统配乐,摆 prompt 仍按"画内起源"处理。
9. **[取源边界]** Criterion 原页面 HTTP 403 未取全文,相关点经 WebSearch 摘要二手转引;Haneke 长镜原话仅得 No Film School 转录版(非 Criterion 一手)。**黑名单(知乎/公众号/百度百科)未采信**。
10. **[反伪造声明]** 本文所有技法(长镜头/自然光/离场暴力/深焦/打破第四面墙/黑白/day-for-night)**均非哈内克独创**,写作"标志性运用/集大成",全文无"发明/首创/鼻祖"表述。CRLS 由 Berger 与建筑光学家 Christian Bartenbach 2001 合作开发(非哈内克发明,哈内克的极简要求是动因)。
