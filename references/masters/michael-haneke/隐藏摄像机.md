## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. **监控式 locked-off 固定长镜（Surveillance Locked-off Long Take）**

- **物理参数**：三脚架**完全锁死**（无摇/移/推/变焦 · 全程 0 运镜）+ 机高**站立眼平 ~1.5–1.6m**（街面/房间高度 · 非俯非仰）+ 广角～标准 · **long shot/wide** · 人物占画高 **≤1/3**（建筑/门/街是主体 · 人是"经过"的小元素）+ **单镜 3–5 分钟**（Caché 开场 credits 压在画面上）+ 画面内"几乎无事发生"（环境音 + 1–2 个微动作）
- **物理实现**：机器在人物动作发生"之前"就已到位（隐藏/监控视角）+ 数分钟后用**快进/回带线闪过画面**揭示这是监视录像 → 把"客观静观"追认成偷窥 POV
- **情感意图**：中心无引导 → 观众被迫自己扫框找信息 = Haneke 凝视；分不清"现实"与"寄来的带子"= 偷窥焦虑

### 2. **一场一颗定焦（One Lens Per Scene）**

- **物理参数**：整场戏**只用一颗镜头**（Berger 转述 "uses only one lens" per scene）+ **禁切广角↔长焦** + Cooke 定焦（S4）+ ARRI Alexa 机身
- **物理实现**：prompt 里一场固定单一 `50mm`（或 `35mm`）贯穿全场 · 勿混焦段；靠**亮度→锐度**引导视线（观众先看最亮、再看最锐），不靠推拉
- **情感意图**：保持观众空间定位稳定 → 摄影机像一个不移动的旁观者/监视器，不"帮"观众看

### 3. **CRLS 单源反射光 + 冷灰低饱和（Single-Source Reflected Light）**

- **物理参数**：**只用反射光绝不直打**（Berger CRLS · Bartenbach 2001 合作开发 · 非 Haneke 发明）+ 单灯 **≤1200W**（"same as a vacuum cleaner"）+ **光比 1:7–1:10**（强反差 · 暗部留细节）+ 软光但保留调子/立体/硬阴影（拒常规柔光 "everything is smoothed, flat"）+ 冷灰低饱和 **S≈20–35%**（彩色片时 · 禁暖 rim/禁橙蓝对比）
- **物理实现**：1 个平行光束灯（近日光）打向离被摄体 7m+ 的约 6 反射板 · 布景无灯具阻挡 → 演员 360° 自由走位、机位可停任意处（长镜物理前提）
- **情感意图**：脸"以自己的光发亮，像最好的油画"；冷灰自然光 = 不打"电影感" · 拟监视器的平淡

### 4. **0 非源配乐 + 街噪/静默（No Non-Diegetic Score）**

- **物理参数**：全片 **0 条 non-diegetic 配乐**（Haneke [原话] "I only use music diegetically… I make realist films and there is no musical accompaniment to reality"）+ 音乐只在画内有声源时存在 + 环境声主导（街噪/脚步/呼吸/苍蝇）+ **静默 = 素材**
- **物理实现**：音效栏 `no musical score, ambient diegetic only`；暴力/揭示不加音效强化
- **情感意图**："ears more sensitive than eyes" · 静默放大情感距离 · 无配乐是离场暴力/监视感生效的必要条件

### 5. **突发离场自杀一镜不剪（Type-X · Sudden On-Screen Suicide, No Cut）**

- **物理参数**：**固定长镜**（机器在人物进屋前就已就位 · 隐藏/监控视角）+ 中景/中近景 · 人物入画后割喉 · 血喷上墙 + **无预警/无配乐/无铺垫**（突发）+ 事发后**拒绝切走**（滞留于尸体与呆立者）+ 目击者沉默、后退、转身背对尸体（不给宣泄）
- **物理实现**：`Locked-off long shot from a hidden-camera vantage already running before anyone enters; act happens suddenly mid-frame, camera REFUSES to cut away`
- **情感意图**：**关键澄清**——Caché 割喉是"直拍"的 · 恰因 Haneke 平时把暴力藏起来（离场），此处"直给且拒切"才最狠 · 让观众无处可逃（勿把它当"离场暴力"正例，它是例外 Type-X）

### 6. **拒情绪特写 + 中远景人 < 空间（Refuse Emotional Close-up）**

- **物理参数**：景别 **MS→WS/ELS 为主** + 关键情节点用 distant long shot 交代 + **拒特写做情感安慰**（Haneke 把哭戏特写称 "pornography of emotions"）+ 正面 frontal + 对称但**故意破一点**（一侧有台灯、一侧空）+ 人物占画幅小、建筑/空间占大（**人 < 空间**）
- **物理实现**：想用特写强化情绪 → 退到 MS/WS，让观众自己 "finish the film"（"call on the imagination of the spectator… have them finish your film for you"）
- **情感意图**：拒绝认同/拒绝情绪代入 → 观众是冷静的旁观者/共谋，不是被煽动的情绪对象

## 二、标志性场景逐镜分析（3 场 · 每场 ≥4 镜）

### 场景 A：开场 Rue des Iris 街道监控长镜（约 0:00:00 起 · 分不清现实/录像的偷窥凝视 · 静止到令人不安）

**戏剧功能**：Inciting（匿名监控带触发全片）
**视角主体**：伪"客观静观"→ 追认为偷窥者 POV（观众即窥视者）
**情感核心**：一条平淡的街被凝视太久，平淡本身成了威胁（≤25 字）

#### 镜 A-1：⭐ 街道住宅超远景 · 静止长镜（locked-off 数分钟）| 约 180–300s | 大远景/长镜

- **机位**：平视 0° / 机高 ~1.5m（街面眼平）/ 距主体 ~25m / 35mm / f8（深焦）/ **locked-off 三脚架 · 全程 0 运镜**
- **构图**：巴黎居民区街道正面 + Laurent 家外墙 + **蓝色 "Rue des Iris" 路牌** + 停放的车 + 门 + 人物占画高 **≤1/3**（建筑/街是主体）+ 正面对称微破（一侧多一棵树/一辆车）+ 深焦全清

- **运镜**：**locked-off 全程 0 运镜**（内部运动 = 一人出门走向车/一辆自行车穿框）+ credits 字幕压在画面上
- **表演**：（远景中渺小走动 · 无戏剧动作）Deadpan 10–30%（平淡到不安）
- **潜台词**：心想=（观众）为什么一直不切？；外泄=画面的"太静" = 有人在看

- **运镜**：图像倒放/快进（非转场特效 · in-world VHS 质感）
- **表演**：（无角色 · 画外 Laurent 夫妇声音开始议论"谁寄的"）
- **[声音]**：⚠️ 遥控器操作声 + 画外夫妇对话（物理声源 · 无配乐）
- **潜台词**：（机制外泄）= 你刚才"客观"看的一切，其实是有人偷拍的带子
- **🎯 大师指纹本镜体现**：指纹 1（后揭示录像 · 分不清现实/录像）+ 4（0 配乐 · 遥控声）

#### 镜 A-3：夫妇看录像带的客厅中景（一场一颗定焦）| 约 40s | 中景

### 场景 B：马吉德割喉自杀一镜不剪（约 1:20:00 · 突发直给 · 观众无处可逃）

**戏剧功能**：Climax（负罪的暴力清算 · Type-X 例外）
**视角主体**：伪监控静观（机器已在位）→ 逼观众直视
**情感核心**：一个被藏了一生的罪，用一刀突然还给你看（≤25 字）

> **关键澄清**：本场是 Haneke **例外 Type-X = 当众直给一镜拒切**，不是离场暴力。恰因全片把暴力藏起来（离场），此处"直给且拒切"才最具冲击。分镜师**勿把它当"离场暴力"正例**。

#### 镜 B-1：⭐ 公寓室内固定长镜 · 马吉德入画（机器已在位）| 约 60s | 中景 → 中近景

- **机位**：平视 0° / 机高 ~1.5m / 距主体 ~3.5m / 50mm / f4 / **locked-off 三脚架 · 机器在人物进屋前就已就位**（隐藏/监控视角）
- **构图**：马吉德的简陋公寓室内 + 一面空墙作主体 + Georges 站画面一侧 + 马吉德站另一侧 + 正面 frontal + **人物占画幅小、空墙/空间占大** + 门在画内
- **光影**：单窗光 5600K 从一侧 + CRLS 反射（无第二光/无 rim）+ 暗部 50% + 冷灰低饱和 S 22% + **空墙留白**（为血喷预留视觉空白）
- **运镜**：**locked-off 全程 0 运镜**（机位从马吉德入屋前就锁死 = 监视感）
- **表演**：马吉德平静说话 + Georges 戒备 + 两人克制对峙（= 克制 30–50% · 山雨欲来的平静 · **无预警铺垫**）
- **潜台词**：心想=（马吉德）我要让你亲眼看；心想=（Georges）他想干什么；外泄=平静对话下的紧绷
- **🎯 大师指纹本镜体现**：指纹 1（机器已在位 locked-off · 监控视角）+ 2（一颗 50mm）+ 5（无预警铺垫 · 空墙为血喷留白）+ 6（人 < 空间）

#### 镜 B-2：⚠️ 割喉瞬间 · 血喷墙（Type-X 直给 · 拒切）| 约 3s | 同机位不切

- **机位**：**同 B-1 机位完全不变**（locked-off · 拒绝切给反打特写）
- **构图**：马吉德**突然抽刀割喉** + **血喷上空墙**（B-1 预留的留白处）+ 身体倒下 + Georges 在画内 + 全程同一固定框
- **光影**：同 B-1 单窗光冷灰 + 血的红是画面唯一高饱和点（撞冷灰底 · 但**不给特写强化**）
- **运镜**：**locked-off · 拒切**（`camera REFUSES to cut away` · 无慢镜/无音效/无配乐）
- **表演**：动作突发、机械、无戏剧化前摇 · Deadpan → 大开大合的**动作幅度**但**镜头零反应**（暴力本身不表演化）
- **[声音]**：⚠️ 割喉的物理声 + 身体倒地声（无配乐/无音效强化 · 冷处理）
- **潜台词**：（机制外泄）= 你被藏起来的暴力，现在无处可逃地砸在你脸上
- **🎯 大师指纹本镜体现**：指纹 5（突发直给一镜不剪 Type-X · 拒切）+ 4（0 配乐/0 音效强化 · 冷处理）

## 三、镜头语法 DNA（What makes Haneke's "Caché" work）

1. **监控式 locked-off 固定长镜 3–5min + 后揭示录像**：三脚架锁死 + 0 运镜 + 眼平 ~1.5m + 人 ≤1/3 画高 + 空间是主体 + 数分钟后快进/回带线追认为录像带。判别式：`若(机位锁死 ∧ 时长≥3min ∧ 主体是空间非人脸 ∧ 中心无引导) ⇒ 观众被迫自己扫框找信息 = Haneke 凝视`。适用：监视/偷窥母题 / 分不清现实录像 / 冷峻惊悚。

2. **一场一颗定焦（Cooke + Alexa）**：整场只用一颗镜头，禁切广角↔长焦，保持空间定位；靠亮度→锐度引导视线，不靠推拉。适用：需要观众"稳定旁观"而非"被镜头牵着走"的场。

3. **CRLS 单源反射光 · 光比 1:7–1:10 · 冷灰低饱和**：单灯 ≤1200W + 只反射不直打 + 保留调子/硬阴影（拒 flat 柔光）+ S 20–35% + 禁暖 rim/禁橙蓝。适用：资产阶级室内 / 自然窗光 / 拟监视器平淡。与是枝的暖橙自然光相反——Haneke 是冷灰。

4. **0 非源配乐 + 街噪/静默承载**：全片 0 条 non-diegetic 配乐，音乐只在画内有声源时存在。判别：暴力/揭示/离场三件套的生效**必须同时关掉配乐 + 音效强化 + 反应镜快切**（任一开启即破功）。适用：写实/反煽情/道德寓言。

5. **突发离场自杀一镜不剪（Type-X）**：机器在人物入屋前已在位（监控视角）+ 无预警无配乐 + 血喷墙 + 拒切滞留 + 目击者背对不宣泄。判别式：`Haneke-X = 事件前机器已在位 × 突发无配乐 × 拒切away × 反应替代宣泄`。⚠️ 这是 Haneke 的**例外**（平时藏暴力），勿当离场暴力正例。适用：全片道德支点、要观众无处可逃的关键暴力。

6. **拒情绪特写 · "finish the film"**：想用特写强化情绪 → 退到 MS/WS，让观众自己补全。哭戏特写 = "pornography of emotions"，刻意不给。适用：拒绝认同/拒绝煽情的疏离叙事。与安东尼奥尼《放大》的疏离同属"冷静旁观"，但 Haneke 多一层"监视/共谋"焦虑。

7. **关键信息藏在画里 + 不引导（denies guidance）**：终镜关键会面被群演遮蔽 + 不切近 + 对话静音（台词写了但保密）→ 观众可能全程没注意到。适用：开放式结局 / 元电影 / 逼观众成为"看的人"。

8. **首尾同构 · 录像带闭环**：开场 credits 压静止街道广镜 = 终镜 credits 压静止台阶广镜 → 整部片被"框"成一盘寄出的带子。适用：元电影自反 / 监视母题闭环。

## 四、声音/音乐设计 DNA

1. **0 非源配乐（verbatim 原则）**：Haneke [原话]"I only use music diegetically. I never use scores, because I make realist films and there is no musical accompaniment to reality, unless… the radio is on." → Caché 几乎无任何配乐，靠街噪与静默。
2. **"耳朵比眼睛敏感"**：Haneke [原话]"your ears are more sensitive than your eyes" → 声音是主通道，画外声/静默承载冲击。
3. **环境声主导**：街噪、鸟鸣、脚步、呼吸、room tone、遥控器操作声、人群噪声——everyday background noise 是唯一"配乐"。
4. **静默 = 素材**：大量静默用于放大情感距离；暴力/揭示时冷处理（不加音效强化）。
5. **关键对话故意静音**：终镜两少年对话被人群噪声淹没/保密（Haneke 写了台词但不公开）——**不给声音 = 开放式手法**。

按表演分寸 4 级（Deadpan 10–30% / 克制 30–50% / 标准 50–70% / 大开大合 70–95%）：

- **本片主导分寸级别**：**克制 30–50%**（资产阶级的压抑不安 · 全片基调）+ 街道/终镜远景 **Deadpan 10–30%**（平淡到不安）+ 自杀镜的**动作幅度大但镜头零反应**（暴力本身不表演化）

## 八、本作"禁忌"清单（不要做什么）

Haneke 绝不会做的事——本作的反例：

- ❌ **情绪哭戏特写（close-up on grief）**——破坏拒特写原则 · Haneke 称之 "pornography of emotions" · 指纹 6 破坏（想强情绪 → 退 MS/WS 让观众 finish the film）
- ❌ **非源配乐煽情（non-diegetic score）**——破坏 "realist films 无配乐" · 指纹 4 破坏 · 且离场/监视/自杀三件套全部失效（配乐一开即破功）
- ❌ **暴力反打特写居中 + 慢镜 + 音效强化**——破坏 Type-X 突发拒切冷处理 · 指纹 5 破坏（自杀是"零反应零特写零音效"直给）
- ❌ **快切蒙太奇 / real-time 加速**——破坏 locked-off 3–5min 静观节奏 · 指纹 1 + 节奏 破坏
- ❌ **手持/dolly/whip pan 炫技运镜**——破坏监控静止 · 默认 `locked-off tripod`（动则 maximum of minimalism 且与演员同步）
- ❌ **暖调 rim + 橙蓝对比 + 高饱和**——破坏冷灰低饱和自然光 · 指纹 3 + 色彩心理学 破坏（血的红是唯一高饱和点且不给特写）
- ❌ **一场戏混切广角↔长焦**——破坏"一场一颗定焦"空间定位 · 指纹 2 破坏
- ❌ **死亡瞬间切走给反应镜 / 关键信息推轨居中指认**——破坏"拒切滞留"与"藏在画里不引导" · 指纹 5 + 7 破坏
- ❌ **把 Caché 割喉当"离场暴力"正例**——⚠️ 纠错：它是**例外 Type-X 直给拒切**，不是画外暴力（离场暴力正例见 Funny Games 做三明治场，属别片）
- ❌ **人物居中大占比 + 强中心引导**——破坏"人 < 空间 + denies guidance" · 指纹 6 + 空间方向情绪 破坏
