> **定位**：导演级方法论（跨作品 · 非单片拉片）——把德·西卡×柴伐蒂尼×蒙图奥里可迁移的意大利新现实主义"分镜操作系统"抽成可查表调用的参数与规则。
> **用途**：生成模型「分镜设计」知识库顶层调用文件。调用语法示例：`[大师参照：德·西卡方法论总纲.md §T2 个体渺小化 + masters/de-sica/偷自行车的人.md §场景 B 旧货市场]`

> **一手/权威语料**：柴伐蒂尼《对电影的若干看法》（Some Ideas on the Cinema · 1953）新现实主义理论纲领 · André Bazin《What Is Cinema?》论德·西卡与新现实主义 · De Sica 关于选角/实景的受访转述 · 调研时间 2026-07（可信度分级见 §九）

## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：德·西卡的分镜系统 = **"让真实自己浮现，摄影机做一个不评判的路人"**，六根支柱。① **实景实拍 ≥95%**：真实街道/当铺/市场/公寓，0 摄影棚，背景不清场（真实路人入画），自然天光为唯一主光——对好莱坞摄影棚的根本反叛。② **非职业演员本色**：选"身体记忆"（长茧的手/工人步态/忧郁眼神）而非演技；多机位抢不可重复的自然反应；笨拙=真实。③ **朴素自然光·光不表态**：阴天散射 6500K 大柔光 / 晴天硬光，暗部不补，不打轮廓光/眼神光/戏剧明暗——光不替导演评判。④ **中近景跟拍 + 长走动 take**：跟人不跟"事件"，长镜头逼观众"陪着走、陪着累"，回避好莱坞快剪。⑤ **孩子目光=道德之眼**：孩子机位 1.1m 仰视大人，大人的尊严"在孩子眼里被丈量"。⑥ **个体渺小化 + 悲悯开放结局**：人海/物海/雨幕吞没个体（占画 <15%），重复阵列的反讽（一辆车在一片车里），不给解决。表演极致克制 30-50%（部分 ≤30%）。

**适用情境**：社会现实 · 失业贫困 · 家庭生计 · 父子/亲子 · 都市底层 · 日常悲剧 · 纪实质感 · 不评判叙事 · 个体被时代淹没 · 反类型 · 反奇观 · 开放结局。**不适用/需改造**：奇观动作片、需明星魅力承载、需戏剧化布光/配乐煽情、需 happy ending 的商业类型。

## 一、核心心智模型（8 个镜片 · How De Sica sees a shot）

### M1 · 摄影机是不评判的路人（共情而非审视）
摄影机的态度是"街上一个跟着走、不审判的路人"：平视、跟随、不俯瞰、不英雄化。柴伐蒂尼纲领：电影应"跟随一个人穿过他生活的每一天"、发现"日常的真实"而非制造事件。
- **分镜含义**：先问"一个路人会怎么看这场戏"，再摆机位——平视 0°、中近景跟拍、不给英雄仰拍、不给上帝俯拍。→ 见 §M5/T4，0。

### M2 · 真实不可伪造（选身体，不选演技）
真实质感来自未被训练的身体：长茧的手、工人步态、疲惫、笨拙。选角看"那个人就是他"的身体本色，不看表演能力。
- **分镜含义**：写角色时锁"身体证据"（手/步态/衣着磨损/姿态）而非"表情戏"；用多机位抢不可重复的第一反应，避免"演"。→ 见 §H4/T7。

### M3 · 光不表态（朴素自然光 = 伦理立场）
布光的克制本身是伦理：不打戏剧化明暗，因为戏剧光=作者在"评判"或"煽情"。光只是如实照着这些人，像照着街上任何人。
- **分镜含义**：自然天光为唯一主光，暗部不补，"暗就让它暗"。想上戏剧光前先自问——这束光是不是在替我下判断？→ 见 §F3、3。

### M4 · 时间即徒劳（长走动 take 让观众陪着累）
"找不到车的徒劳"必须靠时间真实流逝才成立——不是靠台词说"我好累",而是让观众陪着走完那段路。长镜头在这里不是炫技，是身体经验的传递。
- **分镜含义**：徒劳/疲惫/等待的段落用长走动 take（不快剪），剪短即失去身体经验（Cut Test 剪不掉）。→ 见 §F2/T5、3。

### M5 · 孩子的目光是道德之眼
孩子机位低、仰视大人；大人的每一次挫败/失态因"孩子在看"而加倍沉重。孩子是观众的情感代入口与道德参照系。
- **分镜含义**：亲子戏把机位放到孩子眼高（0.9-1.2m），反复给"大人做某事→切孩子看着"的视线结构；大人的尊严通过孩子的眼睛被丈量。→ 见 §T4/F4。

### M6 · 个体渺小化（社会性悲悯）
把主角放进重复的物阵列/人阵列/雨幕，让他占画面 <15%——"一辆车在一片车里"意味着这不是一个人的悲剧，是一个阶层的。渺小化是社会凝视，不是构图花样。
- **分镜含义**：要表达"苦难在时代里毫不特殊"时，用宽景 + 重复阵列 + 人海吞没，个体占比压到 <15%。→ 见 §T2/F5。

### M7 · 戏在日常，激励事件藏在平凡瞬间
反"奇观开头"：钩子是日常 setup（得到一份活、一辆作为生计的车），灾难藏在最平凡的动作里（贴海报时车被偷）。柴伐蒂尼："不要虚构的故事，要日常本身。"
- **分镜含义**：把转折点埋进日常动作，不做类型片式的强 setup/预警；灾难来得突然、无音乐预告。→ 见 §H16、1。

### M8 · 环境声承载情绪（拒配乐煽情）
情绪的承重结构是环境声（街市/雨/人群嘈杂）+ 无言的微表情，不是配乐。人群鼎沸=个体呼救被城市盖过（听觉渺小化）。
- **分镜含义**：镜头表达 绝不写 BGM；情绪交给真实声场（雨/人群/静默）+ 表演。最重的几场几乎无台词。→ 见 §H19、3。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 实景 / 摄影机态度
- **H1** 要纪录片不可辩驳的真实 → 实景实拍 ≥95%（真实街道/市场/当铺/公寓），0 摄影棚，背景**不清场**（真实路人/车流入画）。
- **H2** 摆机位犹豫时 → 默认平视 0° + 中近景跟拍（"不评判的路人"视角），**不用**英雄仰拍、**不用**上帝俯拍。
- **H3** 要"陪伴"这组人物 → 背后/侧后跟拍 handheld，跟人物走动，不切碎动作（共情型态度的运镜实现）。

### B. 选角 / 表演（真实不可伪造）
- **H4** 要"那个人就是他"的真实 → 选身体本色（长茧的手/特定步态/未训练的脸），非职业面孔优先；表演分寸压到极致克制 30-50%（纪实感段落 ≤30%）。
- **H5** 要抢非职业演员不可重复的自然反应 → 多机位同时拍（据述本片用多达 6 台机 · 见 §九），避免他们"演"。
- **H6** 情感最重的一镜 → **不**给戏剧化爆发/嚎啕，给微表情（愣 0.5s / 喉结滚动 / 盈泪僵立 / 牵手），"憋"住比爆发更重。

### C. 光影（光不表态）
- **H7** 阴天/雨天 → 自然散射 6500K 大面积柔光作主光，暗部不补，暗就让它暗。
- **H8** 晴天街道戏 → 自然直射硬光 5500K，暗部 30-35% 不补，不追"电影感"低调光。
- **H9**（铁律）想上轮廓光/眼神光/戏剧明暗时 → 停下自问"这束光是不是在替我评判/煽情"，是则删掉（§M3/F3）。

### D. 景别 / 运镜 / 剪辑（时间即徒劳）
- **H10** 徒劳/疲惫/搜寻/等待 → 长走动 take（8-12s+），跟人不跟事件，**回避**好莱坞快剪（≤2s 碎切动作）。
- **H11** 慌乱/追逐/混乱 → handheld 颠簸跟拍 + 急摇 ~40°/秒（不平滑、纪实感），拒绝顺滑运镜。
- **H12** 静观徒劳的收束 → locked-off 静止长镜，让个体停在大空间里被压小。
- **H13** 景深选择 → 偏深 f/5.6-8 留住真实街道/物海/人海纵深；亲子近景 f/4 焦平面落在孩子眼睛。

### E. 孩子目光 / 渺小化 / 母题 / 声音
- **H14** 亲子戏 → 机位放孩子眼高（0.9-1.2m），孩子仰视大人；反复给"大人做事→切孩子看"的视线结构（道德之眼）。
- **H15** 要"个体苦难毫不特殊" → 宽景把主角放进重复阵列（一片自行车/一堵零件墙/人流/雨幕），占画 <15%，用失窃物的反讽（它和成千上万一样）。
- **H16** 激励事件/转折 → 埋进最平凡的日常动作里，无音乐预告、来得突然（§M7）。
- **H17** 角色弧线的悲剧反转（好人被逼成他憎恨的样子）→ 用**镜像呼应的运镜**（追贼者的跟拍/急摇 ↔ 被追者的同款跟拍/急摇）。
- **H18** 结局 → 不给解决，父子/主角牵手没入人群、个体越缩越小、画面不收束（悲悯开放）。
- **H19** 所有情绪高潮 → 交给环境声（雨/人群/街市）+ 静默 + 微表情，**绝不写 BGM**（§M8）。
- **H20** 好莱坞魅力 vs 现实贫困的反讽 → 让华丽符号（明星海报/橱窗/广告）与灰扑扑的贫困并置同框，不加评论台词。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · "是不是德·西卡式镜头"总判别**
```
满足以下 ≥4 项才算德·西卡式：
① 实景（真实地点 + 背景真实路人不清场）
② 平视 0° 的"不评判路人"视角（无英雄仰拍/上帝俯拍）
③ 自然光唯一主光（无戏剧化布光/轮廓光/眼神光）
④ 中近景跟拍或长走动 take（跟人不跟事件）
⑤ 表演极致克制 30-50%（无戏剧化爆发）
⑥ 情绪交给环境声 + 微表情（无配乐煽情）
```

**F2 · 长 take vs 快剪判别（时间伦理）**
```
要"徒劳/疲惫/等待被身体经历"（搜寻/走动/守候）→ 长走动 take 8-12s+，跟人不跟事件，剪不掉（Cut Test）
要"奇观/紧张类型片节奏"                        → 好莱坞快剪 —— 但那就不是德·西卡（破坏 M4）
判据：剪短后"徒劳感"是否消失？消失 = 必须保留长 take。
```

**F3 · 光是否"表态"判别（伦理布光）**
```
自然天光 + 暗部不补 + 无轮廓/眼神/戏剧明暗 → 合格（光不评判）
一旦出现低调"情绪光"/恶念光/英雄轮廓光      → 破坏 M3（光替导演下了判断）
反例设计判断：这束光是"如实照着他"还是"在告诉观众该怎么想他"？
```

**F4 · 孩子目光机位判别（道德之眼）**
```
亲子戏 → 机位高度 = 孩子眼高 0.9-1.2m 且孩子仰视大人 → 道德之眼成立
若机位在成人眼高俯看孩子 / 孩子平视 → 丢失"大人尊严在孩子眼里被丈量"的道德重量
必备：反复的"大人做事 → 切孩子看着"视线结构。
```

**F5 · 个体渺小化判别（社会性悲悯）**
```
主角占画面 < 15% + 被重复阵列（物海/人海/雨幕）包围 → 社会性渺小化成立
主角占画面 > 30% / 阵列不重复不密集 → 只是普通宽景，无"苦难毫不特殊"的社会凝视
关键：阵列必须"重复到无从分辨"（一辆车在一片一样的车里 = 反讽）。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 实景实拍·背景不清场** ｜机制：把摄影机搬到真实地点 + 真实路人入画 → 纪录片不可辩驳感｜参数：真实外景 ≥95%，0 摄影棚，平视 0°，自然天光唯一主光，背景真实车流/路人/建筑纵深｜触发：社会现实/底层/任何"真实不可伪造"题材｜意图：真实空间让虚构悲剧获得纪录片重量（对好莱坞摄影棚的反叛）｜正例：偷自行车的人 §场景 A 贴海报（真实罗马街道 · 边缘停着那辆车）、§场景 B Porta Portese 旧货市场。

**T2 · 个体渺小化（人海/物海/雨幕）** ｜机制：把主角放进重复阵列 + 压小占比｜参数：宽景，主角占画 <15%，重复到无从分辨的物阵列/人流/雨幕，50mm f/8 或 35mm 大景深留纵深，locked-off｜触发：表达"苦难在时代里毫不特殊"/社会性悲悯｜意图：这不是一个人的悲剧是一个阶层的｜正例：偷自行车的人 §A-4 停在人海（占画 <12%）、§B-1 一辆车在一片一样的车里。

**T3 · 中近景跟拍长走动 take** ｜机制：跟人不跟事件 + 时间真实流逝｜参数：背后/侧后 handheld 跟拍，35mm f/5.6，1.4-1.5m 高，8-12s 长 take，回避快剪｜触发：徒劳/疲惫/搜寻/陪伴｜意图：逼观众"陪着走、陪着累"（身体经验，非炫技）｜正例：偷自行车的人 §B-1 父子穿行市场 11s、§A-3 追贼跟跑 7s。

**T4 · 孩子目光·道德之眼** ｜机制：孩子机位仰视大人 + "大人做事→切孩子看"视线结构｜参数：机位高度 1.1m（孩子眼高），50mm f/4 焦平面落孩子眼睛，孩子面孔占画 45%，仰视画外/上方的大人，自然光无修饰｜触发：亲子戏/大人失态被孩子目睹｜意图：大人尊严"在孩子眼里被丈量"｜正例：偷自行车的人 §B-3 Bruno 雨中仰看父亲、§C-3 目睹父亲被羞辱（全片最重一镜）。

**T5 · 慌乱急摇纪实运镜** ｜机制：handheld 颠簸 + 不平滑急摇｜参数：急摇 ~40°/秒，颠簸跟跑/跟拍，35mm f/5.6，拒绝顺滑｜触发：追逐/混乱/慌乱瞬间｜意图：真实的手忙脚乱（非编排好的动作场面）｜正例：偷自行车的人 §A-2 贼蹿出急摇、§C-2 偷车被人群截住（与 A 追贼镜像）。

**T6 · 镜像呼应运镜（追者→被追者）** ｜机制：同款运镜跨场景复用形成道德闭环｜参数：开头"追贼"的跟拍/急摇参数 ≈ 结尾"被追"的跟拍/急摇，只换主客体｜触发：角色悲剧反转（好人被逼成他憎恨的样子）｜意图：让观众潜意识识别"他成了那个贼"，无需台词｜正例：偷自行车的人 §A-2/A-3 追贼 ↔ §C-2 自己偷车被追。

**T7 · 非职业本色·身体证据** ｜机制：选身体记忆非演技 + 多机位抢自然反应｜参数：长茧的手/工人步态/未训练的脸入镜，表演克制 30-50%（部分 ≤30%），多机位（据述达 6 台 · §九）抢不可重复第一反应｜触发：要"那个人就是他"的真实感｜意图：笨拙=真实，一张没被训练的脸比明星脸更接近本人｜正例：偷自行车的人 全片（Maggiorani 真实失业工人 · Staiola 8 岁孩子）。

**T8 · 朴素自然光·光不表态** ｜机制：自然天光唯一主光 + 暗部不补｜参数：阴天散射 6500K 大柔光 / 晴天直射 5500K 硬光，暗部 30-50% 不补，无轮廓/眼神/戏剧明暗，仅反光板微调｜触发：不美化贫困/不评判/纪录片质感｜意图：光如实照着他，不替导演下判断｜正例：偷自行车的人 §C-1 盯车（不打"恶念"低调光 · 仍朴素天光）、§B 雨天散射。

**T9 · 华丽符号 vs 贫困反讽并置** ｜机制：好莱坞/消费魅力符号与灰扑扑贫困同框，不加评论｜参数：华丽海报/橱窗/广告占画一角高饱和印刷色，工人贫困身影与灰街道形成反差，平视中景｜触发：批判性并置/社会凝视｜意图：奇观化的"美好生活"与真实贫困的静默对照｜正例：偷自行车的人 §A-1 工人贴 Rita Hayworth《吉尔达》巨幅艳照海报时车被偷。

## 七、禁忌清单（❌ 德·西卡式分镜绝不做的事）

- ❌ **摄影棚搭景 / 棚内布光**——破坏实景纪录片真实（新现实主义的反叛对象就是好莱坞摄影棚）（§T1/F1）。
- ❌ **职业明星脸 / 表演式演技 / 戏剧化爆发**——破坏"工人就是工人"的本色真实（§T7/H6）。
- ❌ **戏剧化三点布光 / 低调"情绪光" / 轮廓光眼神光**——光不该替导演评判（§M3/F3）。
- ❌ **好莱坞快剪（碎切动作 / ≤2s 大量短镜）**——破坏长走动 take 的"陪着走、陪着累"（§M4/F2）。
- ❌ **配乐煽情催泪（用 BGM 推情绪）**——情绪应由环境声 + 微表情承载（无配乐是本体系创作选项（音乐性靠物理声源））（§M8/H19）。
- ❌ **给明确解决 / happy ending（找回车 / 抓住贼 / 未来光明）**——破坏悲悯开放结局（§T10/H18）。
- ❌ **英雄主义仰拍 / 把主角拍成英雄 / 上帝俯拍审判**——破坏"不评判路人"的共情态度（§M1/H2）。
- ❌ **把贫困拍得唯美 / 浪漫化苦难**——破坏"如实呈现、不美化"的伦理（全片基调）。
- ❌ **让孩子哭闹卖惨 / 戏剧化嚎啕**——破坏孩子"道德之眼"的克制重量（§T4/H6）。
- ❌ **成人眼高俯看孩子 / 孩子平视**——丢失"大人尊严在孩子眼里被丈量"的道德机位（§F4）。
