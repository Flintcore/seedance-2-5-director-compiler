## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. **女性凝视（Female Gaze）**

- **物理参数**：互相注视的平等（画家看模特、模特也看画家）+ 反男性凝视的客体化 + 凝视即爱与认识 + 双向正反打对视
- **物理实现**：平等的对视构图 + 双向注视 + 不物化身体
- **情感意图**：凝视即爱与平等的认识 · 女性视角的爱情

### 2. **自然光油画质感（Natural Light Painterly）**

- **物理参数**：烛光/壁炉/天光的自然光 + 18 世纪油画般的肤质与布料质感 + 柔和层次 + 暗部细腻 + 无人工硬光
- **物理实现**：自然光为主（Claire Mathon）+ 烛光实拍 + 油画式布光
- **情感意图**：古典油画的质感与温度 · 美如画

### 3. **极简古典（Minimalist Classical）**

- **物理参数**：极简对称构图 + 古典绘画式构图（人物如油画）+ 海岛孤宅的极简空间 + 留白 + 古典服装
- **物理实现**：极简对称 + 绘画式构图 + 极简美术
- **情感意图**：古典的庄重与极简的纯粹

### 4. **几乎无配乐（Near-silence）**

- **物理参数**：几乎全片无配乐 + 环境声（海浪/风/壁炉/脚步）+ 唯一两处音乐（女声合唱/维瓦尔第）的爆发性力量
- **物理实现**：移除配乐 + 环境声 + 音乐稀少故爆发
- **情感意图**：静默中凝视的张力 · 音乐稀少故震撼

### 5. **冷暖对照（Cold-Warm Contrast）**

- **物理参数**：海岛冷蓝 #4A6478（户外/白天/海）vs 烛光壁炉暖橙 #C8823C（室内/夜/作画）+ 冷暖对照
- **物理实现**：户外冷调 + 室内烛光暖调
- **情感意图**：冷的孤独 vs 暖的亲密 · 情感的温度

### 6. **凝视特写 + 含蓄克制（Gaze Close-up & Restraint）**

- **物理参数**：眼神/手/颈/侧脸的细腻特写 + 表演含蓄克制 30-50%（压抑爱欲的暗涌）+ 微表情 + 眼神戏
- **物理实现**：细腻特写 + 含蓄内敛表演
- **情感意图**：压抑爱欲的暗涌 · 凝视承载千言万语

## 三、镜头语法 DNA（What makes this work）

1. **女性凝视**：互相注视的平等（画家看模特、模特也看画家）+ 反男性凝视的客体化 + 双向对视——凝视即爱与平等的认识，女性视角的爱情。
2. **自然光油画质感**：烛光/壁炉/天光的自然光 + 18 世纪油画般的肤质布料质感 + 暗部细腻——古典油画的质感与温度。
3. **极简古典**：极简对称 + 古典绘画式构图（人物如油画）+ 海岛孤宅极简空间——古典庄重与极简纯粹。
4. **几乎无配乐**：环境声（海浪/风/壁炉）+ 唯一两处音乐（女声合唱/维瓦尔第）的爆发性力量——静默中凝视的张力，音乐稀少故震撼。
5. **冷暖对照**：海岛冷蓝（户外/白天）vs 烛光暖橙（室内/夜/作画）——冷的孤独 vs 暖的亲密。
6. **凝视特写 + 含蓄克制**：眼/手/颈/侧脸细腻特写 + 30-50% 压抑爱欲暗涌——凝视承载千言万语。
7. **燃烧的肖像意象**：隔火对视、裙裾燃烧——爱燃烧成永恒画面的标志意象。
