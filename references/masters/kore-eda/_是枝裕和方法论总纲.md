## 一、核心心智模型（8 个镜片 · How Kore-eda sees a shot）

### M1 · 摄影机是家人，不是调查员（共情先于审视）
镜头的存在方式先于构图：摄影机以"陪伴者/家庭成员"的态度在场，不居高临下、不闯入私密、不冷眼旁观。即使角色在偷东西、拐儿童、说谎，镜头也不审视、不评判。
- **分镜含义**：先问"这台摄影机对角色是什么关系"，答案永远是"平起平坐的家人"。→ 决定机位高度（M2）、距离（保持 1.5–3m 不强逼大特写）、态度（§T1/T3）。共情型态度的库内代表性运用。

### M2 · 桌椅高度决定权力关系（平视 = 不审视）
机位高度不是构图选项，是伦理立场。榻榻米座姿高度 0.7–1.0m 让观众"和角色平起平坐"；平视 0° 拒绝上帝视角的审判，微仰 5° 是对儿童的轻微敬意。
- **分镜含义**：默认锁 0.7–1.0m 平视；想"审视/评判"就抬高俯拍——而是枝几乎从不这么做（禁忌 §七）。见 §F1/T1。

### M3 · 静止的摄影机 = 不打扰（长 take 让生活自然展开）
摄影机不动是一种克制：不动=不打扰角色、不引导观众。让角色在锁死的框内自由进出，而非镜头跟着人跑。长 take 让观众"被迫在场"而非"被剪辑推着走"。

### M4 · 省略即情感（不拍事件，拍事件的痕迹）
最戏剧化的瞬间放在画外——死亡、暴力、烟花绽放、生离——镜头只拍它的余波、反光、声音，或事后的空房间。观众补全的想象，比直接呈现更重。
- **分镜含义**：遇到"最该拍的高潮"时，反问"能不能把它移出画框"。想让观众记住 → 拍反应/反光/画外音，而非奇观本身。见 §M8/T5/F4。

### M5 · 细节累积 > 事件推进（日常仪式即叙事）
情感深度来自"吃饭/洗澡/晾衣/递碗"这类日常仪式的高密度累积，而非情节转折。一场戏的价值在于它积攒了多少可信的生活质感，不在于它推进了多少剧情。

### M6 · 让角色在框内自由运动（调度 > 运镜）
运动交给被摄者而非摄影机：多人围桌各自动作、儿童在静止框内奔跑穿越、递碗/盛饭的手部交接。摄影机静观，被摄世界自己流动。
- **分镜含义**：设计一个静止长 take 时，先设计"框内几个人各在做什么"（≥3–6 条独立行为线），而不是设计镜头怎么动。见 §T3/T2。

### M7 · 自然光 = 真实契约（放弃电影感换忘记摄影机）
光源要"可解释"——来自窗户、街灯、入画的钨丝灯具，而不是无源的三点布光。接受暗部沉、去饱和、偏色，为的是让观众忘记有摄影机在。
- **分镜含义**：定光前先找"这个空间里真实存在的光源"，把它当唯一主光；补光只用反光板抬暗部。见 §T4/H10-H12/F5。

### M8 · 色彩即温度坐标（不是风格，是冷暖情感）
颜色标记的是"家的温度 vs 外部的真实"：暖橙木屋（钨丝 3200K，拼凑家庭的温度）对位冷蓝外景（阴天散射 6500K，短暂而真实的幸福）。全片去饱和 −20% 拒绝鲜艳戏剧化。
- **分镜含义**：定一场戏色调前先定"这是家内的温度还是外部的真实"，再选暖橙或冷蓝。见 §T7/H8/F6。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 机位高度 / 摄影机态度
- **H1** 要"和角色平起平坐/不审视"（几乎所有日常戏）→ 镜头高度 0.7–1.0m（榻榻米座姿）+ 平视 0°，距主体 1.5–3m，35–50mm。
- **H2** 拍儿童且要"敬意/儿童主体"→ 降到儿童眼高 0.7m + 微仰 5–15°；跟拍时机位随儿童身高走。
- **H3**（铁律）要保持共情型 → **不俯拍 ≥30°、不仰拍 ≥30°、不贴脸大特写强逼**——俯即审判、仰即英雄化、贴脸即窥视，三者都破坏"家人"关系（§F1）。

### B. 运镜 / 时长 / 剪辑
- **H4** 日常戏 → locked-off 脚架锁死 + 单镜 8–30s，让角色在框内自由进出，镜头不跟人。
- **H5** 唯一允许运动的情境（儿童奔跑/追浪）→ 背后 handheld 跟拍，速度极缓 ≤0.5°/秒，机位保持儿童眼高。
- **H6** 一个长 take"剪不掉"的理由 → 靠框内 ≥3 条独立行为线 + 物件质感累积，而非事件（Cut Test 靠细节而非情节通过）。
- **H7** 节奏 → 极慢，8–30s/镜为常态；**禁大量 ≤3s 快剪**（破坏静观，§七）。

### C. 光影 / 色彩
- **H8** 家内戏 → 暖橙木屋：钨丝 3200K 入画灯具 + 窗户自然光，暗部 50%，去饱和 −20%，主色 #BB8A50 向。
- **H9** 外景/海边戏 → 冷蓝：阴天散射 6500K 不补暖，暗部 30–40%，主色 #5C7B8E 向，与家内暖橙形成温度对位。
- **H10** 室内布光 → 窗户作为唯一/主光源（室内戏 ≥70%），只用反光板抬暗部，**不打三点光/LED 大散光**。
- **H11** 现场光不足 → 让入画的钨丝灯具当光源符号 + 开大光圈 f/2–2.8 浅景深抠主体，接受暗部沉、偏暖、颗粒。
- **H12** 想要"电影感/鲜艳" → 反向操作：去饱和、压低对比、保留自然光的不均匀——真实质感优先于漂亮（§M7）。

### D. 省略 / 画外 / 留白
- **H13** 遇到最戏剧化瞬间（死/暴力/烟花绽放/离别）→ 移出画框，只拍反应脸 / 反光 / 空间余波 / 画外声（§F4）。
- **H14** 要"看不见的存在"→ 拍角色抬头看画外之物 + 画外物仅以偶发反光/闪光短暂照亮脸，物本身不入画（小偷家族烟花）。
- **H15** 死亡/离场后 → 给"人不在了"的空房间/空镜滞留数拍，用缺席表达存在。
- **H16** 情绪高点 → 用克制的日常动作外泄（慢嚼 + 闭眼 + 唇动 + 抚胸），**不给戏剧化哭喊**（表演 30–50%，§F7）。

### E. 调度 / 空间 / 仪式
- **H17** 拍"家/归属"→ 围桌几何：多人围矮桌，矮桌占画面下方约 30%，每人一条独立动作线（夹菜/盛饭/慢嚼/递碗）。
- **H18** 拍关系连接 → 手部交接特写（递碗/递物 A 左 B 右，焦平面落在交接处）+ 对视微笑点头，不靠台词点明。
- **H19** 空间调度 → 优先横向铺陈（围桌/并排/挤阳台），少用纵深冲突构图——横向 = 平等共处的拼凑家庭。
- **H20** 建立日常质感 → 在一场戏里塞 ≥1 个"真做"的仪式（真吃/真洗/真晾），细节密度决定可信度而非剧情（§M5）。

## 三、判别公式（7 个 · 可测 · 设计时当 要点）

**F1 · 桌椅高度静观判别（共情 vs 审视）**
```
镜头高度 0.7–1.0m + 平视 0°/微仰 5° + 距 1.5–3m 不贴脸 → 是枝式共情（家人在场）
镜头高度 ↑ 俯拍 ≥30° / 高位 crane                     → 审判/上帝视角（是枝几乎不做）
镜头 ↓ 仰拍 ≥30°                                       → 英雄化（是枝几乎不做）
铁律：整片锁在平视带内，俯仰越界即破坏共情签名。
```

**F2 · 静止长 take 判别（静观 vs 引导）**
```
locked-off 脚架锁死 + 8–30s + 角色在框内自由进出 + 镜头不跟人 → 是枝式静观
handheld 跟拍（唯一例外：儿童奔跑，≤0.5°/秒）           → 允许，但仍保持儿童眼高
dolly/pan/tilt 主动引导视线 + ≤3s 快剪                  → 非是枝（破坏"不打扰"）
```

```
一个 ≥6s 长 take 必须靠"框内累积"通过 Cut Test，而非事件：
  框内独立行为线 ≥3 条（多人各自动作）
+ 物件/食物/光的可读质感 ≥2 项
+ 微表情连续渐变（若有面部）
```

**F4 · 省略判别（画外决定论）**
```
一个瞬间越戏剧化（死/暴力/烟花绽放/生离）→ 越应移出画框
在画内保留的只允许是：反应脸 / 偶发反光 / 声音 / 事后空房间
判据：如果直接拍了奇观本身 = 破坏是枝式留白（观众想象 > 直给）。
```

**F5 · 自然光纪律判别**
```
光源可解释（窗/街灯/入画钨丝灯具）+ 自然光占比 ≥80% + 仅反光板补 → 是枝式真实光
三点布光 / 无源均匀高调 / LED 大散光                              → 非是枝（电影感 = 破坏契约）
暗部允许沉到 50–70%、允许偏色、允许去饱和 −20%，不追求干净均匀。
```

**F6 · 色彩温度判别**
```
家内 / 归属 / 拼凑家庭的温度 → 暖橙木屋 3200K（#BB8A50 向）
外部 / 短暂而真实的幸福      → 冷蓝外景 6500K（#5C7B8E 向）
全片统一去饱和 −20%，禁鲜艳高饱和（戏剧化 = 破坏平民质感）。
```

**F7 · 表演分寸判别（克制纪律）**
```
全片全角色基调 = 克制 30–50%，情感全部交给微表情 + 长 take 累积
儿童偶尔可到标准 50–70%（追浪大笑），但不夸张
老人极致克制 ≤30%（慢嚼/闭眼/唇动 = 尊严）
出现大开大合 ≥70% 哭喊爆发 = 破坏是枝签名。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 桌椅高度静观机位** ｜机制：把摄影机降到榻榻米座姿/儿童眼高 → 观众与角色平起平坐｜参数：镜头高度 0.7–1.0m；平视 0° 或微仰 5°；距主体 1.5–3m；35–50mm；f/2–2.8；脚架 + 助理跪姿操作｜触发：几乎所有家庭日常戏｜意图：共情=不审视、微仰=对儿童敬意、让观众"在场"｜正例：小偷家族 §场景 A 镜 A-1 全家围桌吃饭（0.8m 平视）。

**T2 · locked-off 静止长 take** ｜机制：脚架锁死、镜头不跟人，角色在框内自由进出｜参数：locked-off；单镜 8–30s（最长 ~60s）；无 dolly/pan/tilt；≥70% 镜头静止｜触发：日常仪式/生活流展开｜意图：不打扰角色、让生活自然发生、观众被迫在场｜正例：小偷家族 §A 镜 A-1（围桌 30s）、§B 镜 B-1（海边远景 12s）。

**T3 · 围桌几何 + 独立行为线** ｜机制：多人围矮桌、每人一条自足动作线，用调度代替运镜｜参数：矮桌占画面下方 ~30%；多人横向围坐；每人独立动作（夹菜/盛饭/慢嚼/递碗）；顶部留白 ~25%｜触发：拍"家/归属/拼凑家庭"｜意图：细节累积=真实温度，横向=平等共处｜正例：小偷家族 §A 镜 A-1（6 人围桌各自动作）。

**T4 · 自然光单一光源** ｜机制：以窗户/街灯/入画钨丝灯具为唯一主光，仅反光板补｜参数：自然光 ≥80%；钨丝 3200K 或阴天散射 6500K；暗部 50–70%；不打三点光；去饱和 −20%｜触发：室内日常戏（≥70%）｜意图：真实质感、让观众忘记摄影机存在｜正例：小偷家族 §A 全家吃饭（窗户 + 钨丝顶灯，暗部 50%）。

**T5 · 画外省略（Off-screen 决定论）** ｜机制：把最戏剧化瞬间移出画框，只拍其反光/反应/声音/余波｜参数：主体看向画外之物；画外物仅偶发反光短暂照亮脸；物本身不入画｜触发：死/暴力/烟花绽放/生离等高潮｜意图：观众想象 > 直给，留白即情感｜正例：小偷家族 §场景 C 夏夜烟花（全家抬头看画外烟花，仅反光照脸，烟花不入画）。

**T6 · 手部交接连接特写** ｜机制：用递物的手部交接把"关系连接"物理化｜参数：A 左侧递 / B 右侧接；焦平面落在两手交接处；矮桌前景；50mm f/2.8；locked-off ~8s；接对视微笑点头｜触发：表达血缘外的真情连接｜意图：不靠台词点明的情感纽带｜正例：小偷家族 §A 镜 A-3 信代递碗给阿初奶奶。

**T7 · 暖橙 / 冷蓝温度对位** ｜机制：色温标记"家内温度 vs 外部真实"｜参数：家内暖橙 3200K #BB8A50 向；外景冷蓝 6500K #5C7B8E 向；全片去饱和 −20%｜触发：家内戏 ↔ 外出戏对照｜意图：颜色=情感温度坐标，非装饰｜正例：小偷家族 §A 暖橙木屋吃饭 ↔ §B 冷蓝海边。

**T8 · 微表情克制外泄** ｜机制：把情感高点交给最小幅度的日常动作而非哭喊｜参数：慢嚼 + 闭眼回味 + 嘴角微扬 + 唇动（听不清）+ 抚胸；表演 30–50%，老人 ≤30%｜触发：情绪高点/临终/满足｜意图：克制=尊严，累积>爆发｜正例：小偷家族 §A 镜 A-4 阿初奶奶慢嚼闭眼、§B 镜 B-4 湿眶唇动。

**T9 · 儿童眼高跟拍** ｜机制：唯一允许的运动，随儿童身高、极缓背后跟拍｜参数：背后 handheld；机位 0.7m（儿童眼高）；≤0.5°/秒；35mm f/2.8；跟随奔跑/追浪｜触发：儿童纯粹幸福/自由奔跑｜意图：以儿童为主体的在场陪伴（非戏剧化）｜正例：小偷家族 §B 镜 B-2 凛追海浪。

**T10 · 缺席空镜（人不在了）** ｜机制：用空房间/空镜滞留表达离场者的存在｜参数：locked-off；离场后镜头停在原空间数拍；保留其物件/痕迹；自然光｜触发：死亡/离开后｜意图：以缺席写存在，反戏剧化告别｜正例：小偷家族（阿初奶奶死后仅剩房间的处理）(推断：具体镜秒待逐镜文件补录)。

## 七、禁忌清单（❌ 是枝式分镜绝不做的事）

- ❌ **俯拍 ≥30° 或仰拍 ≥30°**——破坏桌椅高度平视，俯即审判、仰即英雄化（§F1）。
- ❌ **贴脸大特写强逼 / 镜头闯入私密**——破坏"摄影机是家人不是调查员"的共情态度（§M1/H3）。
- ❌ **三点布光 / LED 大散光 / 无源高调均匀**——破坏自然光真实契约（§F5/H10）。
- ❌ **追求干净漂亮、拉高饱和/对比**——应去饱和、接受暗部沉与偏色（§M7/H12）。
- ❌ **大量 ≤3s 快剪 / 主动 dolly-pan 引导视线**——破坏 locked-off 静观"不打扰"（§F2/H7）。
- ❌ **直接拍最戏剧化的奇观本身（烟花绽放/暴力/死亡瞬间）**——应移出画框只留反光/反应/声音（§F4/M4）。
- ❌ **戏剧化大开大合爆发（哭喊 ≥70%）**——情感应交给微表情累积，克制 30–50%（§F7/H16）。
- ❌ **用"开头冲击力"事件钩子开场**——是枝以日常细节 hook（偷东西是生活细节非事件）替代类型片钩子。
- ❌ **跳过日常仪式直接推情节**——反戏剧化叙事靠仪式细节累积，不靠事件推进（§M5/H20）。
