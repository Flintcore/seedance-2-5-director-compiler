## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：波兰斯基的分镜系统 = **"把主观心理状态外化成可测的空间物理压迫"**，五根支柱。① **幽闭公寓引擎**：全片困在一个封闭空间（公寓/船/牢），用广角贴脸（<0.4m·墙面在背后逼近）+ 墙壁/门/走廊的几何压迫，让"空间收缩=精神崩溃"（冷血惊魂/怪房客/魔鬼圣婴）。② **绑定式主观视角**（判别铁律）：机位死锁在一个人物身上，观众只知道主角所知——门外脚步声只闻不见、镜外威胁靠声音存在、幻觉与现实同一镜内不切换标记。③ **窗内偷窥/被窥**：窗、门缝、猫眼、镜子=既向外窥看历史/邻居又被外部凝视，框中框=困守。④ **手持跟随的贴身焦虑**：跟随主角在逼仄空间移动，机位与身体同呼吸。⑤ **日常中的诡异（uncanny）**：正常物件（走廊、邻居、牙齿、裂缝）在稳定构图里悄然变形——恐怖来自熟悉而非奇观。母题→镜头：偏执→墙面逼近变形（推断）；困守→框中框+走廊纵深；历史创伤→隔窗无力见证。

**适用情境**：心理惊悚/幽闭恐惧、公寓/单一空间困守、偏执与精神崩溃、偷窥与被窥、历史创伤主观见证、日常诡异。**不适用/需改造**：需要开阔全知视角的史诗/战争群像、需要明快节奏的动作片、高调明亮均匀打光的喜剧。

## 一、核心心智模型（8 个镜片 · How Polanski sees a shot）

### M1 · 空间即精神状态（房间会随人物崩溃而收缩）
波兰斯基把"精神崩溃"外化为**空间的物理变形**——墙壁逼近、走廊拉长、天花板压低，而非靠演员演疯。空间是心理的可测坐标。
- **分镜含义**：想表现偏执/失控 → 让空间的几何"作恶"（广角逼墙、走廊纵深、低天花板），不是给崩溃表情特写。→ 见 §T1/T4/F1。

### M2 · 主观绑定（观众只能知道主角所知）
机位与信息死锁在单一主角身上：观众不比主角多知道一点。威胁常在**画外**（脚步声、门外阴影、镜外的手），靠声音与暗示存在。
- **分镜含义**：不切全知客观镜、不给"观众才看到的凶手"。威胁放画外/景深暗处，用声音承载。见 §M8/§T2/F2。

### M3 · 幻觉与现实无缝同框（不打标记）
主观幻觉不用叠化/变色/梦境滤镜标记，而是与现实**同一镜、同一光**里发生——观众和主角一样分不清真假。
- **分镜含义**：呈现幻觉/偏执时**不要**用梦境化处理；让诡异事件在写实镜头里"就这么发生"。见 §T5/F5。

### M4 · 日常的诡异（uncanny · 恐怖来自熟悉）
恐怖不来自怪物奇观，而来自**正常事物的轻微错位**——热心的邻居、公寓走廊、一颗牙、墙上裂缝。稳定写实构图里藏不安。
- **分镜含义**：要惊悚 → 先把场景拍得极其正常写实，再让一个细节"不对"。不靠 jump scare 或高对比恐怖光。见 §T6/H16。

### M5 · 框中框即困守（窗/门/镜/走廊）
门框、窗框、镜子、走廊不是构图花样，是把"被囚禁/被监视/无法逃离"物理化。人被"关"在画中画里。
- **分镜含义**：想让人物"困住/被监视" → 用门框/窗框/走廊二次切割画面，人落内框。见 §T3/H8/F3。

### M6 · 窗内视角（既向外窥看又被外部凝视）
窗（及门缝/猫眼/百叶）是双向的：主角透过它无力窥看外部世界（历史暴行/邻居），同时暴露在外部凝视下。
- **分镜含义**：隔窗/隔缝构图既做"受限的见证"也做"被监视的焦虑"。见 §M6→§T2/T3、钢琴家 §场景 A。

### M7 · 手持贴身与稳定压迫的分工（判别）
两种签名：**手持贴身跟随** = 焦虑/失控/主观混乱；**稳定固定/极缓运动的对称压迫** = 冷静的诡异/仪式感/被困的静。二者按情绪分工，不随意混。
- **分镜含义**：先定这场是"躁动焦虑"还是"冷静诡异"，再选运镜族。见 §F4。

### M8 · 声音承载画外威胁（听觉在场 · 视觉缺席）
关键威胁常**只闻不见**：门外脚步、隔壁争吵、镜外的人、街上的暴行。声音让画外空间"在场"，画面留空反而更恐怖。
- **分镜含义**：威胁不必进画。用画外声 + 主角对声音的反应镜承载。见 §T7/H19。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 空间压迫 / 幽闭
- **H1** 要精神崩溃/偏执 → 广角（24–28mm）贴脸 <0.4m，让背后墙面在广角里"逼近变形"，主体被空间夹住（冷血惊魂式）。
- **H2** 要"空间收缩"随剧情加剧 → 全片锁在一个封闭空间，随崩溃推进逐步压低机位/缩短拍摄距离/收窄可见空间（推断的渐进策略）。
- **H3** 要走廊/纵深的压迫 → 长走廊单点透视 + 尽头暗，人物走向或逃离纵深；可让墙面/门在两侧夹逼。

### B. 主观绑定 / 视角
- **H4**（铁律）机位与信息死锁主角 → 不给观众多于主角的信息，不切全知凶手镜（§F2）。
- **H5** 要威胁存在感 → 放画外（声音）或景深暗处（虚焦人影），不给正面清晰特写。
- **H6** 要幻觉/现实难辨 → 同一镜、同一光里发生，**不加**梦境滤镜/叠化/变色标记（§M3/F5）。

### C. 框中框 / 偷窥
- **H7** 要困守/被监视 → 门框/窗框/走廊/镜子二次切割，人落内框、被"关"进去（§F3）。
- **H8** 要偷窥/隔阂 → 隔门缝/猫眼/百叶/窗帘缝拍，遮挡失焦占 30–60%，主体落缝隙实焦（钢琴家 §A-1）。
- **H9** 要"被外部凝视"的焦虑 → 从窗外/门外向内拍主角（反打视角），暗示有人在看。
- **H10** 要分裂/自我怀疑 → 镜中反射拍人（镜里镜外双身 / 变形镜面），偏执者对镜。

### D. 运镜 / 光影 / 色彩
- **H11** 情绪=躁动/失控/主观混乱 → 手持贴身跟随，机位与身体同呼吸（怪房客/钢琴家躲藏）。
- **H12** 情绪=冷静诡异/仪式/被困的静 → 稳定固定或极缓 dolly/环绕（0.04–0.1 m/s），对称构图（魔鬼圣婴式）。
- **H13** 惊悚场景 → 自然光/低对比写实光为主，**不用**高反差恐怖打光；诡异藏在正常光里（§M4）。
- **H14** 历史/战争/萧瑟 → 去饱和灰冷（#6B7078 · -30~-40%）+ 自然光（钢琴家）。
- **H15** 幽闭偏执 → 中性偏冷、避免暖色安慰；室内暗部 60–70%，光从窗/门缝单向进入。

### E. 诡异 / 声音 / 节奏
- **H16** 要 uncanny → 先把场景拍得极正常写实，再让一个日常细节"不对"（邻居太热心、走廊多一扇门、墙裂缝渗出）。
- **H17** 要幽闭时间感 → 长镜/静默拉长困守的煎熬，静默即压力（钢琴家躲藏段）。
- **H18** 要"墙会动"的偏执 → 广角固定机位对着墙/天花板，让直线在边缘轻微弯曲变形（推断，冷血惊魂裂墙/手）。
- **H19** 威胁在画外 → 用画外声（脚步/争吵/门响）+ 主角听声的反应镜承载，威胁不进画（§M8）。
- **H20** 要人性/尊严的一丝暖 → 仅在关键释放点（如音乐段）让去饱和转微暖，其余严格克制（钢琴家 §C）。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 空间压迫判别（幽闭是否成立）**
```
满足 ≥3 项才算波兰斯基式幽闭镜：
① 封闭单一空间（公寓/船/牢/房间）不外扩
② 广角(24–28mm)贴脸<0.4m，背景墙面在广角里逼近
③ 框中框/走廊纵深/低天花板 至少一种几何压迫
④ 光单向从窗/门进入，暗部 60–70%
仅"室内戏"不算——必须空间在物理上"作恶"。
```

**F2 · 主观绑定判别（视角纪律）**
```
波兰斯基铁律：观众信息 = 主角信息，不多一分
✔ 威胁在画外(声音)/景深暗处/镜外
✔ 不切"观众才看到的凶手/全知客观"镜
✘ 给观众上帝视角的悬念镜 = 破坏绑定（这是希区柯克式，非波兰斯基式）
```

**F3 · 框中框占比判别**
```
门/窗/镜/走廊内框 只是背景装饰 → 无困守味
内框明确框住主体、主体落内框中心 → 困守/被监视（推荐）
多层框嵌套(门中门/框中框中框) → 强囚禁/迷宫
偷窥遮挡(门缝/百叶)须失焦、主体落缝隙实焦，否则挡脸穿帮。
```

**F4 · 手持 vs 稳定判别（两种恐怖）**
```
情绪 = 躁动/失控/主观混乱/求生 → 手持贴身跟随，机位随身体
情绪 = 冷静诡异/仪式/被困的静   → 稳定固定 / 极缓 dolly·环绕 + 对称构图
铁律：同一情绪基调内不混用。冷血惊魂躁动派 / 魔鬼圣婴冷静派。
```

**F5 · 幻觉无缝判别（诡异纪律）**
```
呈现主观幻觉/偏执时：
✔ 同一镜、同一写实光、无剪辑标记里发生
✘ 加叠化/梦境滤镜/变色/慢镜 = 破坏"分不清真假"（廉价化）
目的：观众与主角一样无法确认真假，恐怖来自不确定。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 广角逼墙幽闭** ｜机制：广角贴脸+背后墙面在畸变中逼近→空间夹住主体｜参数：24–28mm，机位<0.4m，背景墙/门/天花板入框，边缘直线轻微弯曲，暗部 60–70%｜触发：偏执/精神崩溃/幽闭恐惧｜意图：把"空间收缩=精神崩溃"物理化｜正例：冷血惊魂（Repulsion·公寓墙壁逼近/走廊变形）、怪房客（The Tenant·公寓）。

**T2 · 隔窗/门缝偷窥** ｜机制：隔实景障碍（窗帘缝/门缝/猫眼/百叶）拍主体或拍外部｜参数：遮挡贴镜头强失焦、遮 30–60%，主体落缝隙实焦，平视/略低，主体不看镜头｜触发：受限的见证/偷窥/被窥焦虑｜意图：把"隔着什么无力窥看"+"被外部凝视"双重物理化｜正例：钢琴家 §场景 A（窗帘缝窥看街头暴行）、魔鬼圣婴（隔门缝）。

**T3 · 框中框困守** ｜机制：门/窗/走廊/镜二次切割画面｜参数：内框占边缘、主体落内框中心；可多层嵌套（门中门）；深透视纵深｜触发：困守/被监视/无法逃离｜意图：景框=牢笼/迷宫｜正例：怪房客（公寓窗/庭院俯视）、魔鬼圣婴（公寓门廊）、钢琴家（窗框限制视野）。

**T4 · 走廊纵深压迫** ｜机制：单点透视长走廊+尽头暗｜参数：广角对走廊中轴，两侧墙/门夹逼，尽头暗或有威胁；人物走向/逃离纵深｜触发：逼近的威胁/幽闭移动｜意图：纵深=不可逃离的通道｜正例：冷血惊魂（公寓走廊·墙伸出手 推断锚点）、怪房客。

**T5 · 幻觉无缝写实** ｜机制：主观幻觉与现实同镜同光、无标记｜参数：写实自然光+稳定或手持，不加叠化/滤镜/变色，诡异事件"直接发生"｜触发：偏执幻觉/精神失常｜意图：观众与主角一样分不清真假｜正例：冷血惊魂（墙裂/伸手/腐烂兔肉）、怪房客（对面楼诡异）。

**T6 · 日常诡异（uncanny）** ｜机制：极正常写实场景里一个细节"不对"｜参数：稳定构图+自然光+日常物件，反常来自轻微错位（太热心的邻居/多余的门/裂缝）｜触发：不安/被围困的偏执｜意图：恐怖来自熟悉而非奇观｜正例：魔鬼圣婴（邻居 Castevets 的热心）、怪房客（前租客的痕迹）。

**T7 · 画外声威胁** ｜机制：威胁只闻不见+主角反应镜｜参数：画外声（脚步/争吵/敲门/街声）+ 主角听声的静止反应镜，威胁不进画，画面留空｜触发：不可见的威胁/被围困｜意图：听觉在场、视觉缺席=更恐怖｜正例：魔鬼圣婴（隔墙吟诵）、钢琴家（门外脚步/街头暴行声）。

**T8 · 镜中分裂** ｜机制：镜面反射拍人（镜里镜外双身/变形镜面）｜参数：镜中反射+主体，或变形镜面扭曲面部，偏执者对镜｜触发：自我怀疑/身份分裂/偏执｜意图：分裂的自我在场｜正例：冷血惊魂（镜中幻象）、怪房客（镜中变身前租客）。

**T9 · 手持贴身跟随** ｜机制：手持跟随主角在逼仄空间移动｜参数：手持微抖，机位贴身与身体同呼吸，逼仄室内/躲藏移动｜触发：焦虑/失控/求生的主观混乱｜意图：机位=主角的呼吸与恐惧｜正例：钢琴家（废墟躲藏移动）、怪房客（公寓内游走）。

**T10 · 稳定对称的冷静诡异** ｜机制：稳定固定/极缓 dolly·环绕+对称构图｜参数：三脚架固定或极缓 0.04–0.1 m/s，对称/居中构图，中性冷光｜触发：仪式感/冷静的诡异/被困的静｜意图：与手持躁动相反的"冷静逼近"｜正例：魔鬼圣婴（公寓仪式/餐桌）、水中刀（船上对称三角，与手持派互为反面）。

## 七、禁忌清单（❌ 波兰斯基式分镜绝不做的事）

- ❌ **给观众多于主角的全知信息 / 上帝视角凶手镜**——破坏主观绑定（§F2，那是希区柯克式悬念，非波兰斯基）。
- ❌ **用梦境滤镜/叠化/变色标记幻觉**——幻觉必须与现实无缝同镜（§F5/M3）。
- ❌ **用高反差恐怖打光 / jump scare 制造惊吓**——恐怖来自日常写实里的诡异（§M4/H13）。
- ❌ **把威胁全塞进画面**——关键威胁留画外用声音承载（§M8/H19）。
- ❌ **在同一情绪基调里混用手持躁动与稳定对称**——两种恐怖签名互斥（§F4）。
- ❌ **框中框内框只做背景装饰、主体不落内框**——则困守感失效（§F3）。
- ❌ **偷窥遮挡物实焦或挡住主体脸**——障碍须失焦、主体落缝隙实焦（§F3/H8）。
- ❌ **暴力煽情特写 / 英雄主义 / 高饱和**——克制旁观、渺小个体、去饱和灰冷（钢琴家 §八）。
