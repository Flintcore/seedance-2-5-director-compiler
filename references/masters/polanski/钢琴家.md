## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. **克制旁观纪实（Restrained Observational Realism）**

- **物理参数**：暴力以冷静客观中远景呈现（不强行特写煽动）+ 稳定机位 + 不主观渲染 + 让暴行"如实发生"
- **物理实现**：保持旁观距离 + 不剪辑煽情 + 暴力突兀但不放大
- **情感意图**：真实比煽情更有力 · 历史的暴行无需修饰

### 2. **个体幸存主观视角（Individual Survivor POV）**

- **物理参数**：全程跟随一个人 + 从窗口/门缝/阁楼窥看历史 + 观众只看到主角看到的 + 不切全局战场
- **物理实现**：限制视角在主角 + 大量"隔着障碍窥看"的构图
- **情感意图**：历史的宏大透过一个渺小个体的眼睛 · 无力的见证

### 3. **废墟孤独（Ruined City Solitude）**

- **物理参数**：被战火摧毁的华沙空城 + 一个人在巨大废墟中占画面 ≤10% + 断壁残垣 + 死寂
- **物理实现**：实景/重建废墟 + 渺小化构图 + 空旷死寂
- **情感意图**：文明毁灭后的孤独 · 一个人苟活于废墟

### 4. **去饱和灰冷 + 自然光（Desaturated Grey & Natural Light）**

- **物理参数**：去饱和灰冷 #6B7078（-30~-40%）+ 自然光为主 + 阴冷 + 战时萧瑟 + 偶尔暖光记忆
- **物理实现**：去饱和调色 + 少补光 + 阴天/室内自然光
- **情感意图**：战争的萧瑟与生命的褪色

### 5. **长镜跟随 + 静默（Long Take Following & Silence）**

- **物理参数**：长镜跟随主角的躲藏移动 + 大段静默（躲藏不能出声）+ 缓慢 dolly/手持微跟
- **物理实现**：跟随调度 + 静默作为生存压力
- **情感意图**：躲藏的漫长煎熬 · 静默即生存

### 6. **钢琴作人性火种 + 表演极致克制（Piano as Humanity & Restraint）**

- **物理参数**：钢琴/音乐作为人性与尊严的象征 + 表演极致克制 30-50%（从体面绅士到野兽般消瘦麻木）+ 不外放哭嚎
- **物理实现**：音乐关键处出现 + 演员身体性消瘦 + 麻木的克制
- **情感意图**：在非人的处境中，音乐是人性最后的火种

## 三、镜头语法 DNA（What makes this work）

1. **克制旁观纪实**：暴力以冷静客观中远景呈现、不强行特写煽动、保持旁观距离——真实比煽情更有力，历史的暴行无需修饰。
2. **个体幸存主观视角**：全程跟随一个人，从窗口/门缝/阁楼窥看历史，观众只看到主角看到的——历史的宏大透过一个渺小个体的眼睛。
3. **废墟孤独**：被摧毁的华沙空城 + 一个人占画面 ≤10% + 断壁残垣死寂——文明毁灭后的孤独苟活。
4. **去饱和灰冷 + 自然光**：去饱和 -30~-40% + 自然光为主 + 阴冷萧瑟——战争的萧瑟与生命的褪色。
5. **长镜跟随 + 静默**：长镜跟随躲藏移动 + 大段静默（不能出声）——躲藏的漫长煎熬，静默即生存。
6. **钢琴作人性火种**：音乐/钢琴作为人性与尊严的象征，在关键处出现——非人处境中人性的最后火种。
7. **表演极致克制**：从体面绅士到野兽般消瘦麻木 30-50%、不外放哭嚎、身体性消瘦——克制比哭嚎更有力。

## 四、声音/音乐设计 DNA

1. **肖邦钢琴作主题**：肖邦的钢琴曲作为人性与尊严的象征 · 关键处（弹琴段）出现 · 音乐即人性。
2. **静默作生存压力**：躲藏段大段静默（不能出声）+ 屏息 · 静默即生存。
3. **战时环境声床**：远处枪炮 / 街头喊叫 / 风穿废墟 / 碎石 · 克制不煽情。
4. **暴力声不放大**：枪声/暴行声以真实音量呈现 · 不用音效煽动。
