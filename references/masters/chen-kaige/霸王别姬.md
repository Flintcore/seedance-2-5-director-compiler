## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. 京剧戏曲美学（Peking Opera Aesthetics）

- **物理参数**：水袖/翎子/脸谱/蟒袍 + 程式化身段（兰花指/云手/亮相）+ 唱念做打 + 戏台一桌二椅 + 锣鼓点节奏
- **物理实现**：实拍京剧表演 + 戏服考究 + 程式动作
- **情感意图**：东方戏曲的极致仪式美 · 程式中的情感

### 2. 戏与人生互文（Stage-Life Mirroring）

- **物理参数**：台上戏文（虞姬别霸王）↔ 台下命运（蝶衣别段小楼）的镜像剪辑 + "不疯魔不成活" + 雌雄同体的身份
- **物理实现**：戏台与现实的平行蒙太奇 + 同一情感的双重呈现
- **情感意图**：人戏不分的痴绝 · 艺术与人生界限的消融

### 3. 半世纪史诗跨度（Half-Century Epic Sweep）

- **物理参数**：北洋军阀→抗战→内战→建国→文革（50 年）+ 时代节点用字幕/历史符号标记 + 个人命运随时代翻覆
- **物理实现**：跨时代置景 + 服化道时代变迁
- **情感意图**：个人在历史洪流中的渺小与无力

### 4. 浓墨东方色彩（Saturated Eastern Palette）

- **物理参数**：戏服红金（虞姬红 #C41E3A + 蟒袍金 #D4AF37）+ 戏台暖光 + **时代场景转冷峻灰蓝**（文革青灰）+ 高饱和对比
- **物理实现**：戏台暖调 vs 现实冷调的色彩二分
- **情感意图**：戏台的绚烂 vs 现实的冷酷

### 5. 顾长卫考究摄影（Composed Cinematography）

- **物理参数**：精确对称/框中框构图（戏台口/门洞/窗格）+ 暖调怀旧 + **烟雾光束氛围**（戏院烟雾中的光柱）+ 缓慢推拉 + 戏台调度长镜
- **物理实现**：精密布光 + 烟雾机 + 稳定运镜
- **情感意图**：时代的厚重质感 · 怀旧的氤氲

### 6. 情节剧浓烈情感 + 戏台长镜（Melodrama & Stage Long Take）

- **物理参数**：浓烈外放表演 70-90%（爱/恨/痴/绝）+ 关键戏曲表演用长镜完整呈现 + 情感不回避煽情
- **物理实现**：戏剧化表演 + 长镜调度
- **情感意图**：情节剧的浓情 · 痴绝的极致

## 四、设计维度与适用边界

| 原则 | 陈凯歌式体现 |
|------|-----------|
| **表演分寸** | 戏剧化 55-75% 为主 + 时代癫狂/背叛崩溃顶点 80-85%（**情节剧浓情 + 时代癫狂例外**）|
| **色彩** | ⭐ **浓墨东方色彩**（戏服红金 vs 时代冷峻灰蓝 · 色彩即戏台/现实二分）|
| **蒙太奇** | ⭐ **戏与人生互文叠化**（台上戏文↔台下命运平行）|
| **大师参照** | 戏曲程式美学 + 顾长卫考究构图 |
| **光影** | 烟雾光束 + 戏台聚光 + 火光氛围 |
| **声音（禁 BGM）** | 京剧锣鼓点/唱腔是物理声源（合法）· 时代配乐用环境声替代 |
| **画面动起来** | 戏台程式身段 + 时代群像调度 = 内部运动丰富（戏曲长镜靠身段，非死画面）|

> **适用边界**：陈凯歌语法适合**史诗情节剧 / 戏曲传统艺术 / 时代悲剧 / 浓烈情感**。**不适合**极简静观 / 冷峻克制 / 现代快节奏——它的浓墨重彩与情节剧浓情是反极简的。⚠️ 大开大合 80-85% 仅限时代癫狂/背叛崩溃顶点。
