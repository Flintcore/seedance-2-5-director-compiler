## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. 低调布光高反差阴影（Low-Key High-Contrast）

- **物理参数**：low-key 布光 + **百叶窗条状光影**（投在脸/墙）+ 暗部 ≥60% + 硬光单光源 + 明暗交界锐利 + 黑色阴影构图
- **物理实现**：硬光 + 百叶窗/格栅遮光 + 高反差曝光
- **情感意图**：道德的灰色地带 · 阴影里的危险与秘密

### 2. 死者倒叙旁白（Dead Man's Voiceover）

- **物理参数**：开场即结局（泳池浮尸）+ 死者第一人称画外音倒叙 + 宿命的反讽语调 + 旁白引导叙事
- **物理实现**：画外音 + 倒叙结构
- **情感意图**：一切早已注定的宿命感 · 黑色幽默的反讽

### 3. 好莱坞自反（Hollywood Self-Reflexivity）

- **物理参数**：过气默片女星 + 真实片场（派拉蒙）+ 默片明星本色出演 + 电影工业的自我解剖 + 对"明星"的祛魅
- **物理实现**：元电影设定 + 真实好莱坞元素
- **情感意图**：梦工厂的残酷 · 被时代抛弃的明星

### 4. 哥特式衰败豪宅（Gothic Decaying Mansion）

- **物理参数**：巨大空洞的旧豪宅 + 管风琴 + 蒙尘的辉煌（旧照片/旧物）+ 幽闭压抑 + 高大空间吞没人
- **物理实现**：哥特置景 + 衰败道具
- **情感意图**：被困在过去辉煌里的疯狂 · 时间的坟墓

### 5. 宿命悲剧倒叙结构（Fatalistic Flashback）

- **物理参数**：倒叙锁死结局（已知死亡）+ 一步步走向注定的毁灭 + 无可挽回
- **物理实现**：倒叙框架 + 宿命叙事
- **情感意图**：无力回天的宿命 · 黑色电影的悲观

### 6. 巴洛克疯癫表演 + 深焦纵深（Baroque Madness & Deep Focus）

- **物理参数**：女星夸张优雅的默片式表演（大幅手势/眼神）滑向疯狂 70-95% + 深焦纵深构图（前景人物 + 空旷纵深 = 孤独/权力）
- **物理实现**：默片式戏剧表演 + 深焦摄影
- **情感意图**：优雅与疯狂的一线之隔 · 空间里的孤独

## 四、设计维度与适用边界

| 原则 | 比利·怀尔德（日落大道）式体现 |
|------|-----------|
| **/ 光影景深** | ⭐ **low-key 高反差百叶窗条光**（film noir 标志 · 反 AI 味阴影范本）+ 深焦纵深 |
| **表演分寸** | 戏剧化 50-65% 为主 + 疯癫顶点大开大合 90%（巴洛克疯狂例外）|
| **视角 / 旁白** | ⚠️ **死者第一人称倒叙旁白**（黑色电影签名 · 创作思路中标注"旁白叙事/倒叙结构"）|
| **色彩** | 黑白高反差（film noir 经典）|
| **结构** | 倒叙锁死结局的宿命结构 |
| **声音（禁 BGM）** | 旁白人声 + 管风琴（物理声源）· 配乐用环境替代 |
| **画面动起来** | 深焦纵深 + 条光 + 巴洛克身段 = 静中有戏（locked-off 靠光影/表演，非死画面）|

> **适用边界**：日落大道语法适合**黑色电影 / 宿命悲剧 / 旁白倒叙 / 好莱坞自反 / 衰败豪宅 / 心理囚禁**。**不适合**明亮高调 / 高饱和 / 朴素自然光 / 大团圆。⚠️ 死者旁白 + 疯癫 90% 是强手法，须有黑色电影/悲剧意图。
