## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. **浴室谋杀蒙太奇（Shower Montage）**

- **物理参数**：70 个镜头 45 秒的快切 + 刀/尖叫/水/血/眼睛的碎片化剪辑 + 暴力靠剪辑节奏暗示（刀从未真正刺入画面）+ 极快切
- **物理实现**：碎片化快切 + 暗示性剪辑（不展示刀入肉）+ 节奏制造冲击
- **情感意图**：暴力靠想象比展示更恐怖 · 剪辑节奏即暴力

### 2. **黑白高反差惊悚（B&W High Contrast）**

- **物理参数**：Tri-X 黑白胶片 + 强对比 + 大面积阴影 + 暗部 ≥60% + 经济布光（电视剧组拍摄）
- **物理实现**：黑白高反差 + 阴影戏 + 低成本经济布光
- **情感意图**：黑白的经济与恐怖 · 阴影藏匿威胁

### 3. **叙事诡计反转（Narrative Trickery）**

- **物理参数**：前 1/3 跟随"女主角"（偷钱潜逃）→ 突然在浴室被杀 + 视角转移 + 颠覆观众预期 + 信息控制
- **物理实现**：误导观众认同"主角"→ 中途杀死 → 转移叙事
- **情感意图**：颠覆预期的震撼 · 没有人是安全的

### 4. **偷窥视角（Voyeur POV）**

- **物理参数**：窥视孔偷窥 + 主观偷窥镜头 + 让观众通过 Norman 的眼睛偷窥 + 观众成共犯
- **物理实现**：窥视孔遮罩构图 + 主观 POV + 偷窥的张力
- **情感意图**：观众成为偷窥共犯 · 道德的不安

### 5. **Herrmann 弦乐尖叫（Screeching Strings）**

- **物理参数**：Bernard Herrmann 全弦乐配乐 + 谋杀时小提琴尖锐刺耳的"尖叫"（高频刺击）+ 成为恐怖听觉符号
- **物理实现**：纯弦乐 + 尖锐高频 + 与快切同步
- **情感意图**：听觉的尖叫即恐怖 · 永恒的恐怖符号

### 6. **哥特母题 + 压抑诡异表演（Gothic & Uncanny）**

- **物理参数**：阴森老宅（垂直耸立）+ 标本鸟 + 楼梯 + 表演压抑诡异 40-70%（Norman 的温文尔雅↔疯狂）
- **物理实现**：哥特美术 + 演员的诡异双重感
- **情感意图**：哥特的阴森 · 温文下的疯狂

## 三、镜头语法 DNA（What makes this work）

1. **浴室谋杀蒙太奇**：70 镜 45 秒快切 + 刀/尖叫/水/血/眼睛碎片化（刀从不真正刺入画面）——暴力靠剪辑节奏与想象，比血腥展示更恐怖。
2. **黑白高反差惊悚**：Tri-X 黑白 + 强对比 + 大面积阴影 + 经济布光——黑白的经济与恐怖，阴影藏匿威胁。
3. **叙事诡计反转**：前 1/3 认同"女主角"→ 中途被杀 → 视角转移——颠覆预期的震撼，没有人是安全的。
4. **偷窥视角**：窥视孔遮罩 + 主观 POV——观众成偷窥共犯，道德的不安。
5. **Herrmann 弦乐尖叫**：纯弦乐 + 谋杀时小提琴尖锐高频"尖叫"——听觉的尖叫即恐怖，永恒符号。
6. **哥特母题 + 压抑诡异表演**：垂直老宅/标本/楼梯 + Norman 的温文↔疯狂 40-70%——哥特阴森，温文下的疯狂。
7. **安全感铺垫的反差**：最安全的浴室成最恐怖的屠场——日常安全的颠覆。
