## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：罗素兄弟 × Opaloch 的分镜系统 = **"用电视工业化的高效叙事节奏，把大 IP 群像与大场面 VFX 调度成一个可读的情感落点"**，五根支柱。① **可读性动作铁律**：广角/中焦拍动作 + 保持空间地理清晰（连贯的 180° 轴线 + wide master 建立几何）—— disciplined handheld，**反 "close-up and cut" 碎剪蒙混**（受《突袭 The Raid》影响）。② **纪实贴身运镜**：手持"随动作呼吸"、贴近人物、documentary 临场感，把超人打斗接地为真实肉搏。③ **群像调度守恒**：多线并进、每条线各有一个"读得懂的目标+地标"，用交叉剪辑收束（多线汇聚）。④ **奇观锚情感**：最大特效点必锚在最大情感点（牺牲/集结/重逢），奇观服务角色弧，非纯炫技。⑤ **能量特效物理律**：每种能量 = 材质类比 + 专属色 + 被动光源打人打环境 + 击中冲击波（缺被动光源 = 五毛）。节奏：电视式高信息密度 + 快速语气切换（悲壮↔幽默）；🔴 IMAX 数字路（clean digital · 非胶片做旧）。

**适用情境**：超级英雄/大 IP 群像、大规模 CG 群体战、可读的近身动作/肉搏、多线汇聚的商业史诗、传送门/能量/解体特效、奇观服务情感的高潮、紧凑高信息密度叙事、悲壮与幽默的快速切换。**不适用/需改造**：慢节奏文艺留白（本系统天生高密度）、需要主观混乱/抽象化打斗（本系统追求可读性，与王家卫 step-print 反可读性相反）、单人内心独白式作者电影、需要胶片颗粒做旧的复古质感。

## 一、核心心智模型（8 个镜片 · How the Russos see a shot）

### M1 · 动作的第一义是"可读"（Geography before spectacle）
一个动作镜头首先要让观众**读得懂谁在哪、朝谁、往哪打**；奇观是第二位。罗素兄弟受《突袭 The Raid》影响，反对"贴脸 + 碎剪"蒙混动作——他们用更宽的镜头、连贯的空间几何，让每一拳可追踪。（Opaloch/Russo 访谈·高）
- **分镜含义**：设计动作段先立 wide master 建几何、锁轴线，再切近景；不靠快切遮丑。→ 见 §F1/§T2。

### M2 · 镜头"随动作呼吸"（Camera as a participant, not a spectator）
手持不是为了抖，是为了让机器**和人物一起动、一起躲闪**——documentary 临场感，把超人打斗接地为真实肉搏。是"有纪律的手持"，不是懒惰的 shaky-cam。
- **分镜含义**：机位放进动作里（with the characters），跟着重心移动、随冲击顿挫，而非站远观看。→ 见 §M2/T1/H2。

### M3 · 群像即调度（Ensemble = traffic control）
出身电视群戏（Arrested Development / Community），把"管理大量角色、让每人都有清晰功能"变成核心技能。大场面里每条线、每个角色都要有**读得懂的目标 + 地标 + 视觉标识**，观众不迷路。
- **分镜含义**：多角色同场 → 给每条线一个空间地标/色标/朝向，用交叉剪辑分配注意力。→ 见 §M7/T6/H11。

### M4 · 奇观锚情感（Spectacle anchored to an emotional beat）
商业史诗引擎的第一原理：**最大的特效点必须落在最大的情感点上**（牺牲、集结、重逢），能量过载与角色命运同步。奇观不为炫技存在。
- **分镜含义**：设计高潮 VFX 前先问"这个奇观在为哪个情感 beat 服务"；把能量峰值对齐情感峰值。→ 见 §F4/T8。

### M5 · 能量即物理（Every power obeys light & material）
超能力特效不是贴上去的亮 blob——每种能量都有**材质类比 + 专属色 + 被动光源（打施法者/环境/反射）+ 击中冲击波火星**。缺被动光源就是五毛。
- **分镜含义**：任何发光/能量元素，必须同时写它"打亮了谁、照到了什么、反射在哪"。→ 见 §F2/T7。

### M6 · 尺度靠层次（Scale via depth, not just size）
大场面的"大"来自**多层景深 + 大气透视 + 个体 vs 军团对比**，不是单纯把东西做大。三层纵深（前景残骸 / 中景个体 / 远景军团海没入尘烟）卖尺度。
- **分镜含义**：要"史诗尺度" → 排三层景深 + 加体积尘烟大气透视 + 放一个可对比的渺小个体。→ 见 §T3/H7。

### M7 · 高密度电视节奏（TV-grade information density + tonal agility）
电视训练出的能力：**在有限时间塞进最多有效信息 + 快速切换语气**（悲壮↔幽默↔紧张）。剪辑高效、不拖泥带水，情绪转弯快而不突兀。
- **分镜含义**：一场戏可承载多个 beat；允许在史诗悲壮里插一个幽默拍子松弛，再收回。→ 见 §H15/T10。

### M8 · IMAX 数字·干净通透（Clean digital, photoreal, anti-plastic）
载体是 ARRI Alexa IMAX（终局之战为影史首部全程 IMAX 数字拍摄的好莱坞片），clean digital cinema + filmic color science，极轻 grain，**非胶片颗粒做旧**；photoreal 写实超英，反 AI 塑料感。
- **分镜含义**：调色走干净通透写实路线，保留 anti-AI 质感；不加胶片做旧、不卡通写意化。→ 见 §H14/禁忌。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 动作可读性 / 空间几何
- **H1** 要拍一段近身动作 → 先给一个 **wide master**（广角/中焦）建立空间几何 + 锁 180° 轴线，再切进近景；**不靠碎剪蒙混**（§F1）。
- **H2** 要"临场肉搏感" → 手持机位放进动作里、随人物重心移动/躲闪、随冲击顿挫（disciplined handheld，非无意义乱抖）。
- **H3** 要动作可追踪 → **广角/中焦 > 长焦特写**；反 "close-up and cut"；打斗中保持能看见发力全身与对手相对位置。
- **H4** 空间转场（换楼层/区域）→ 给一个可辨识地标 + 连贯运镜带过，让观众始终知道"打到哪了"（如电梯→走廊）。

### B. 群像调度 / 多线汇聚
- **H5** 多角色同场大战 → 每条线/每个角色配一个**空间地标 + 视觉标识（色/朝向/剪影）**，交叉剪辑分配注意力，观众不迷路（§M3）。
- **H6** 要"多线汇聚"高潮 → 各线各自铺垫读得懂的目标，最后用**同一事件/同一地标**把多线收束到一个画面（军团集结/传送门齐开）。
- **H7** 要卖史诗尺度 → 三层景深（前景残骸/中景个体/远景军团海没入尘烟）+ 体积尘烟大气透视 + 渺小个体对比（§M6）。
- **H8** 群体战调度 → 空中（飞行/能量束）+ 地面（近战）多层分离编排，横移扫过列阵 → 推进随冲锋。

### C. 能量 / 特效物理
- **H9**（铁律）任何能量/发光元素 → 必写**材质类比 + 专属色 + 被动光源（打施法者半脸+身后环境+反射）+ 击中冲击波火星**；缺被动光源 = 五毛（§F2）。
- **H10** 传送门/法阵 → 橙金旋转火花环自小放大张开 + 边缘卷曲能量须迸火星 + 环心透异空间纵深（非贴图）+ 门光打亮周围尘埃；军团级 = 数十门齐开铺满各景深层。
- **H11** 解体/消散 → 由边缘/末端碳化 → 灰烬层层剥离 → 随气流飘散（由实渐虚、由密变疏）+ 飘灰带余温微光上浮；**绝不瞬间消失无过程无余烬**。
- **H12** 能量束 → 核过曝白 + 外缘专属色（cyan/紫/金）体积光散入尘 + 发射反推使手腕后挫 + 击中迸火星冲击波。

### D. 色彩 / 光影 / 载体
- **H13** 战场/废墟基调 → 阴霾冷灰压抑天光 + 战场余火橙点（动机源=燃烧），冷灰底 + 暖橙点。
- **H14** 载体 → clean digital（IMAX 数字路）+ filmic color science + 极轻 grain；**不加胶片颗粒做旧**、不卡通写意化、保留 photoreal 写实 anti-AI 质感（§M8）。
- **H15** 情感高潮打光 → 发光源（弧光/能量石/反应堆）作**动机光源**打脸打手，并可让其"稳定→闪烁→渐熄"作生命隐喻。

### E. 节奏 / 情感落点 / 叙事
- **H16** 设计高潮 VFX → 先锚情感 beat：把**最大能量峰值对齐最大情感峰值**（牺牲/集结/重逢），能量过载与角色命运同步（§M4/F4）。
- **H17** 奇观再大也要**反应镜** → 插人物仰望传送门/目睹解体/见证牺牲的克制反应，让奇观有情感重量（§M4）。
- **H18** 史诗悲壮太满 → 插一个幽默/日常拍子松弛（tonal agility），再收回严肃（电视式语气切换 · §M7）。
- **H19** 静默 vs 奇观 → 高潮用"静默↔奇观"交替节奏（集结前的绝望静默 → 门光炸开），静默为奇观蓄势。
- **H20** 声音（🔴 禁 BGM）→ 史诗感靠**物理声**承载：传送门能量嗡鸣 + 军团脚步兵器海 + 能量束尖啸 + 解体沙沙灰落 + 弧光电流 + 战场尘爆 + 静默→号令。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 动作可读性判别（罗素式 vs 碎剪蒙混）**
```
罗素式动作 = wide master 建几何 + 锁 180° 轴线 + 广角/中焦追踪全身 + 手持随动作呼吸
反例（不是罗素式）= 长焦贴脸特写 + 高频碎剪 + 空间地理不明（"close-up and cut"）
判据：随机暂停任一帧，能否读出"谁在哪·朝谁·往哪打"？能=罗素式，不能=碎剪蒙混。
锚：受《突袭 The Raid》影响 · 冬兵 电梯打斗 / 内战莱比锡机场对决。
```

**F2 · 能量特效"不五毛"判别（被动光源纪律）**
```
一个能量镜要成立，必须同时满足 4 条（缺一即五毛）：
① 材质类比（这能量像什么材质：等离子/闪电/火/念力）
② 专属色（该能量的固定辨识色）
③ 被动光源（能量的光打在施法者半脸 + 环境 + 反射）
④ 击中冲击（击中点有冲击波/火星/焦痕/次级运动）
缺③被动光源 = 贴上去的亮 blob = 五毛根源。
```

**F3 · 尺度是否成立判别（层次 vs 单纯做大）**
```
史诗尺度 = 多层景深（≥3 层）+ 大气透视/体积尘烟 + 个体 vs 军团可对比的渺小锚
若只是把物体做大而画面单层平铺、无大气透视、无对比锚 → 尺度失败（平铺无尺度）
判据：画面里有没有一个"渺小的可对比个体"让军团显得海量？
```

**F4 · 奇观锚情感判别（奇观是否服务角色弧）**
```
最大特效点 是否落在 最大情感点 上？
是（牺牲/集结/重逢/角色弧收束）→ 罗素式商业史诗引擎
否（奇观独立于情感、纯炫技、无反应镜）→ 空洞奇观（非罗素式）
配套：奇观段必须有人物反应镜（仰望/目睹/见证）给情感重量。
```

**F5 · 多线汇聚判别（群像是否收束）**
```
多线并进 → 每条线是否各有【读得懂的目标 + 空间地标 + 视觉标识】？
高潮 → 多线是否被【同一事件/同一地标】收束进一个画面？
若多线各打各的、从不汇聚到一个共同点 → 调度失败（散乱群戏）
判据：观众能否在任一时刻说出"每条线现在要干嘛、彼此关系"？
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 纪实贴身手持（Disciplined participatory handheld）** ｜机制：机位放进动作里、随人物重心移动躲闪｜参数：手持 + 中广焦 + 与人物同高/贴身 + 随冲击顿挫（有纪律，非无意义乱抖）｜触发：近身肉搏/紧张追逐/临场感｜意图：把超人打斗接地为真实肉搏、观众"站在三维空间里"｜正例：冬兵 电梯打斗（受《突袭》影响）、内战莱比锡机场（🔴均待入库拉片 · 逐镜细节尚未落盘 · 见 §九）。

**T2 · 可读广角动作（Wide-lens readable action）** ｜机制：广角/中焦拍动作 + 保持空间地理｜参数：wide master 建几何 + 锁 180° 轴线 + 广角/中焦追踪发力全身与对手相对位置｜触发：任何需要"看得懂"的动作段｜意图：反 "close-up and cut"、每一拳可追踪｜正例：冬兵 高速路桥段、内战机场群战（🔴均待入库拉片 · 见 §九）（对照：碎剪蒙混动作=反例）。

**T3 · 三层景深史诗尺度（Three-layer epic scale）** ｜机制：多层景深 + 大气透视卖尺度｜参数：前景残骸 / 中景孤立个体 / 远景军团海没入尘烟 + 体积尘烟 + 大气透视 + 渺小个体对比｜触发：绝境/军团战/史诗全景｜意图：让"大"来自层次而非单纯做大｜正例：终局之战 §场景 A 镜 A-1（废墟绝境 establishing）、A-3 军团级。

**T4 · 军团级传送门集结（Army-scale portal convergence）** ｜机制：橙金旋转火花环 + 军团级齐开｜参数：sling-ring 橙金旋转火花环自小放大张开 + 边缘卷曲能量须迸火星 + 环心透异空间纵深（非贴图）+ 数十门铺满各景深层 + 门光打亮尘埃成光斑｜触发：援军降临/多线汇聚高潮｜意图：多线收束到一个尺度震撼画面｜正例：终局之战 §场景 A（"Avengers assemble" · Weta）。

**T5 · 解体消散灰飞（Disintegration to ash）** ｜机制：边缘碳化 → 灰烬剥离 → 气流飘散｜参数：由边缘/末端碳化 → 灰烬层层剥离随风飘散（由实渐虚、由密变疏）+ 飘灰带余温微光上浮｜触发：终极响指/大规模消散｜意图：由实变虚有过程有余烬、万众化尘的尺度｜正例：终局之战 §场景 B 镜 B-3（军团解体灰飞）。

**T6 · 群像调度地标法（Ensemble landmark blocking）** ｜机制：每条线配空间地标+视觉标识 + 交叉剪辑｜参数：每角色/线给一个地标（区域/建筑）+ 视觉标识（色/朝向/剪影）+ 交叉剪辑分配注意力｜触发：多角色同场大战｜意图：观众不迷路、群戏读得懂｜正例：内战机场 12 人混战调度（🔴待入库拉片 · 见 §九）、终局之战决战多线（源出电视群戏 Community 训练）。

**T7 · 能量被动光源打光（Energy as motivated light）** ｜机制：能量自发光作动机光源打施法者+环境｜参数：能量核过曝白 + 外缘专属色（cyan/紫/金）体积光 + 打亮施法者半脸/手 + 照环境 + 反射 + 击中冲击波火星｜触发：任何超能力/能量特效｜意图：能量成立不五毛、光有源｜正例：终局之战 §场景 B 镜 B-1（六色能量石打脸手）、能量束/闪电/念力各族。

## 七、禁忌清单（❌ 罗素式分镜绝不做的事）

- ❌ **用长焦贴脸 + 高频碎剪蒙混动作**（"close-up and cut"）——罗素式动作要广角/中焦 + 可读地理（§F1）。

- ❌ **奇观独立于情感、纯炫技、无反应镜**——最大特效点必锚最大情感点（§F4）。
- ❌ **多线各打各的从不汇聚**——群像必须收束到同一事件/地标（§F5）。

- ❌ **照搬钢铁侠战衣/灭霸长相等 Marvel IP**——只取特效物理+光色+调度可迁移方法。
