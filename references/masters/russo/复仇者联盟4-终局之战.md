## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

> ⚠️ **CG / IP 落地说明（关键）**：终局之战是 **photoreal 写实超英 CG**——写实类 AIGC 视频模型能对接其**特效物理**（能量材质/被动光源/传送门火花环/解体灰烬/量子隧道/群体尺度）。但**具体角色/战衣/灭霸造型 = Marvel 专有 IP**——落地时 🟢 取"**能量特效的物理呈现 + 光色 + 尺度调度**"，🔴 **不照搬钢铁侠战衣/灭霸长相/具体角色设计**（IP）。下文 🟢 标可抄、🔴 标 IP 专有。

### 1. **超大规模 CG 群体战（Massive CG Army Battle）** 🟢可抄尺度调度/🔴角色IP
- **物理参数**：万人级军团 vs 军团 + 空中（飞行单位/能量束）地面（近战）多层调度 + 尺度对比（个体英雄 vs 军团海）+ 大气尘烟填满战场纵深
- **物理实现**：大规模 CG 群体模拟 + 多层景深 + 体积尘烟 + 调度编排
- **🟢 可抄**：军团尺度 / 空地多层战场调度 / 个体 vs 海量对比 / 尘烟纵深

### 2. **标志性超能力能量特效（Signature Power VFX）** 🟢可抄能量物理/🔴角色IP
- **物理参数**：每种能量都有**材质类比 + 专属色 + 被动光源**——能量束 repulsor（核过曝白 → cyan 外缘）/ 雷神闪电（紫白分叉频闪 · Stormbreaker）/ 绯红女巫（红色念力能 · 物体被掀飞）/ 惊奇队长 binary（金橙能 · 高速穿透拖焰）+ 击中点冲击波/火星，🔴 **光打在施法者 + 环境 + 反射**
- **物理实现**：能量自发光材质 + 体积光散射 + 击中冲击模拟 + 动机源打光
- **🟢 可抄**：能量给材质类比 / 专属色 / 被动光源打脸环境 / 击中冲击波火星
- **🔴 IP**：具体角色的具体招式造型

### 3. **传送门集结（Sling-Ring Portals · 军团级）** 🟢可抄火花环物理
- **物理参数**：Doctor Strange sling-ring **橙金色旋转火花环** + 边缘**卷曲能量须 + 飞溅火星** + 环心**透出另一空间的景（有纵深·非贴图）** + Endgame 放大到**军团级一齐张开**（数十个同时铺满战场）
- **物理实现**：Weta 重建并放大原 Doctor Strange 火花环 + 旋转 spark 模拟 + 异空间纵深
- **🟢 可抄**：橙金旋转火花环 / 卷曲能量须迸火星 / 环心透异空间纵深 / 多门齐开尺度

### 4. **解体消散特效（Disintegration to Ash）** 🟢可抄
- **物理参数**：被终极响指击中的军团**由边缘/末端开始碳化 → 灰烬层层剥离 → 随气流飘散**（由实变虚、由密变疏）+ 飘灰**带余温微光上浮再被风带走**
- **物理实现**：粒子解体模拟 + 边缘碳化 shader + 气流场
- **🟢 可抄**：边缘碳化→灰烬剥离飘散 / 由实渐虚 / 飘灰带余烬微光上浮

### 5. **量子领域科幻（Quantum Realm Sci-fi）** 🟢可抄
- **物理参数**：subatomic **tron 式发光隧道/网格** + 漂浮几何碎片 + 量子战衣（红白发光线条）+ 时空穿越的**光带拉伸 + 失重**
- **物理实现**：抽象 CG 微观空间 + 发光线框 + 失重运镜
- **🟢 可抄**：发光隧道/网格纵深 / 漂浮几何 / 光带拉伸失重穿越

### 6. **情感史诗高潮（Emotional Epic · 超能力服务角色弧）** 🟢可抄
- **物理参数**：奇观高潮**服务情感**——钢铁侠夺石"I am Iron Man"夺石响指（弧光过载 → 军团解体 → 弧光渐熄牺牲）+ 角色十年弧收束 + 静默时刻穿插奇观
- **情感意图**：商业史诗引擎——最大奇观点在最大情感点（牺牲）
- **🟢 可抄**：奇观高潮锚在情感高潮 / 能量过载与角色命运同步 / 静默↔奇观节奏

## 二、标志性场景逐镜分析（3 场 · 每场 ≥4 镜 · 🟢取特效物理·🔴不搬角色IP）

### 场景 A：传送门大军集结（"Avengers Assemble" · 约 2:30:00）

**戏剧功能**：Climax 前的集结 ·（绝望 → 援军降临 → 反攻）· VFX：Weta Digital

#### 镜 A-1：废墟绝境 establishing | 5s | 大远景（多层景深）
- **叙述**：战后焦土废墟，三名英雄孤立面对灭霸军团海，尺度对比渺小
- **构图**：前景残骸 / 中景孤立英雄 / 远景军团海没入尘烟 三层纵深
- **光影**：阴霾天光压抑冷灰 + 战场余火橙点（动机源=废墟燃烧）
- **🟢 可抄**：绝境尺度对比 + 多层景深 + 余火橙点缀冷灰

#### 镜 A-2：⭐ 第一个传送门张开 | 3s | 中景
- **叙述**：身后空气一点橙光，旋转**火花环**自小放大张开，环心透出另一空间的景
- **构图**：火花环占画面、环心纵深透光
- **光影**：🔴 橙金火花环的光**打在英雄背影 + 周围尘埃**（动机源=传送门）
- **🟢 可抄**：橙金旋转火花环自小张开 + 边缘能量须迸火星 + 环心透异空间纵深 + 门光打亮周围

#### 镜 A-3：⭐⭐ 军团级传送门齐开 | 4s | 大全景
- **叙述**：战场各处数十个橙金火花环同时张开，各路大军自门中涌出列阵
- **构图**：火花环铺满战场各景深层 + 军团涌出
- **光影**：满场橙金门光在尘烟中形成可见光斑 + 大气透视卖尺度
- **🟢 可抄**：多门齐开尺度震撼 + 军团涌出 + 门光在尘烟里成光斑 + 大气透视

#### 镜 A-4：集结反攻冲锋 | 3s | 跟移
- **叙述**：英雄列阵，一声号令，两军海潮般对冲
- **运镜**：横移扫过列阵 → 推进随冲锋（镜头响应能量）
- **🟢 可抄**：列阵横移 + 冲锋推进 + 军团对冲调度

### 场景 B：钢铁侠终极响指与牺牲（约 2:50:00）

**戏剧功能**：Climax 最高点（牺牲收束十年弧 · 奇观锚情感）

#### 镜 B-1：夺石瞬间 | 2s | 近景特写
- **叙述**：英雄趁隙将六颗能量石转移到自己手套，石头嵌入迸发能量
- **光影**：六色能量石光**打亮他的脸 + 手**（动机源=能量石）· 手套过载灼烧
- **🟢 可抄**：能量石嵌入迸发 + 六色光打脸 + 过载灼烧（手套冒烟/皮肤灼伤）

#### 镜 B-2：⭐⭐⭐ "I am Iron Man" 响指 | 3s | 特写→反应
- **叙述**：他直视对手说出宣言，强忍剧痛打出响指，弧光与能量石全数过载爆亮
- **光影**：响指瞬间**能量过载白爆**打亮全场 + 物体投出长影（动机源=过载能量）
- **🟢 可抄**：响指瞬能量过载白爆全场 + 强忍剧痛的表演 + 弧光过载（🔴 IP=钢铁侠战衣造型）

#### 镜 B-3：⭐⭐ 军团解体灰飞 | 5s | 大全景→中景

- **构图**：军团海逐层解体 + 飘灰填满空气
- **🟢 可抄**：军团边缘碳化→灰烬剥离飘散 + 由实渐虚 + 飘灰带余温微光上浮 + 万众化尘的尺度

#### 镜 B-4：弧光渐熄 | 4s | 近景
- **叙述**：英雄瘫坐残骸，胸口弧光一明一暗、逐渐黯淡熄灭，战场静默
- **光影**：弧光从稳定蓝白 → 闪烁 → 熄灭（动机源=胸口反应堆 · 生命隐喻）
- **🟢 可抄**：发光源渐熄（稳定→闪烁→灭）作生命隐喻 + 牺牲静默
