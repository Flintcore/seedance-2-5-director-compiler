## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：阿巴斯的分镜系统 = **"用极简真实的凝视，把最重的存在命题托回观众"**，四根支柱。① **移动的忏悔室**（判别铁律）：车内 2-shot 经挡风玻璃/侧窗框住**单人**，司机与同车人**几乎不同框**，正反打靠车窗框切换、各望画外——边框=天然画框、分镜=各自封闭的孤独；单镜 30s–3min 极少切，人静背景横移（人静世界动）。② **远景人车渺小**：间插大远景，车/人 <5% 画面，之字盘山土路缓行——个体消融在亘古大地，远观=不介入的尊重。③ **留白即尊重**：最重的信息（死亡/动机）永不直给，绕着说、不展示，靠任务侧写与对方反应；黑屏吊住结局、拒给答案。④ **真实↔虚构边界**：非职业演员、各自单拍的真实交谈；结尾用 35mm→DV 画质断裂/戏中戏撕开虚构（元电影 coda）。调色=大地色赭黄 #B8895A + 尘土漫射柔光低对比；声景=引擎/碎石/风的近零配乐。

**适用情境**：极简对话长镜 · 车内移动对话/忏悔 · 生死存在哲思 · 公路漫游 · 大地色荒野 · 留白开放结局 · 含而不发的劝慰 · 陌生人交谈 · 元电影自反 · 儿童视角求索。**不适用/需改造**：需强情节钩子与快剪的商业类型、需明确闭合结局、需配乐煽情、需大特写榨取情绪、需饱和炫美风景片。

## 一、核心心智模型（8 个镜片 · How Kiarostami sees a shot）

### M1 · 汽车是移动的忏悔室（空间先于情节）
先把人放进一个"移动的封闭容器"，让日常的开车动作装最重的话题；情绪由**车窗景框 + 背景横移**承载，不靠演员挤表情。
- **分镜含义**：想让两人交心/交锋 → 先把他们关进车里、各自用车窗框住，再谈内容。→ 见 §T1/§F1。

### M2 · 远观 = 不介入的尊重（渺小感）
个体的困惑要放进巨大的大地里显得渺小，摄影机远远地看、不追、不逼近——距离本身是一种伦理姿态。
- **分镜含义**：情绪最重的转折反而拉最远（人跑远成小点、车爬过之字路），不用大特写。见 §T2/§H。

### M3 · 留白是给观众的位置（不直给）
最重的信息（自杀动机、生死结局）刻意不说穿、不展示，用委托任务侧写、用黑屏悬置——空缺不是缺失，是留给观众思考的座位。
- **分镜含义**：越是关键的东西越藏；把"为什么/结果"留成谜。见 §T3/§T4/§F3。

### M4 · 真实与虚构的边界可被撕开（元电影自反）
电影不假装自己是现实；用戏中戏、画质断裂（35mm→DV）、演员出戏，公开宣告"这是被拍出来的"——真实与虚构的接缝本身是内容。
- **分镜含义**：结尾/关键处允许打破第四面墙，让"拍摄"进入画面。见 §T5/§F4。

### M5 · 人物与对话者不同框（孤独的隔离）
车内正反打刻意让两人**不在同一镜**、各望画外的对话者，视线不交于同框——分镜结构本身就是"两个孤独个体无法真正抵达彼此"。
- **分镜含义**：要表达疏离/无法抵达 → 拆分镜、各自框住、不给同框对切。见 §T1/§F1。

### M6 · 之字/盘旋 = 困境的空间形状
反复上行的之字盘山土路、兜圈的路径，是"人在困境里绕不出去"的空间投影；路径的几何承载心理状态。
- **分镜含义**：主题是徘徊/两难 → 用盘旋、往复、之字的运动路径，而非直线抵达。见 §T2/§M6。

### M7 · 大地色 = 尘归尘的克制母题
赭黄土褐、飞扬尘土漫射柔光、几乎无饱和原色——颜色的克制呼应情绪的克制；尘土既是死亡母题也是"暖而荒"的生之底。
- **分镜含义**：先定情绪坐标（荒/死=大地色低对比 / 生=渐入绿）再定调色。见 §T6/§F5。

### M8 · 声音的"无"承载重量（近零配乐）
只用引擎/碎石/风/环境同期声，几乎不配乐——拒绝替观众决定该怎么感受，让对话与留白的重量自己沉下去。
- **分镜含义**：情绪最重处**撤掉**音乐、只留环境声与静默；唯一配乐留到最后的"生"。见 §T7。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 移动容器 / 车内对话
- **H1** 要两人交心/交锋且保持疏离 → 车内 2-shot，透挡风玻璃/侧窗框住**单人**（50–85mm f4），司机与乘客不同框，正反打靠车窗框切换、各望画外。
- **H2** 车内长镜要"沉静的漂移感" → 人物相对静、让车随路前行使背景**缓慢横移**（人静世界动），单镜 30s–3min 不切。
- **H3** 对话者不在场/难对戏（非职业演员）→ 各自单人逐一拍摄再剪成对话，天然形成"不同框、各望画外"，保留生疏与停顿。

### B. 远观 / 渺小 / 路径几何
- **H4** 情绪最重的转折 → 反而拉最远景（人/车 <5% 画面），远观不介入，不用大特写逼脸。
- **H5** 主题是徘徊/两难/绕不出 → 用之字盘山、往复兜圈的运动路径（车爬过画框），而非直线抵达。
- **H6** 要"个体消融在大地" → 极远景固定或极缓摇（0.02 m/s 跟车），让车成为土黄山坡上一个移动的小点。

### C. 留白 / 不直给
- **H7** 有最重的信息（死亡/动机/秘密）→ 永不直说、不展示过程，用委托任务侧写（"往坑里填二十铲土"），信息放在台词缝隙与对方反应里。
- **H8** 要开放结局 → 用**黑屏渐入并停留**吊住、拒给生死答案，靠声音（闷雷/雨/静默）维持黑屏。
- **H9** 要拍"值得活/值得留下" → 不用台词点明，用车窗外掠过的生机空镜（绿树/孩子/晾晒衣物）+ 景物从荒土渐入有树暗示。

### D. 真实↔虚构 / 元电影
- **H10** 要撕开虚构 → 结尾切 35mm→DV 画质断裂 / 戏中戏 / 演员出戏，让"拍摄"进入画面（元电影 coda）。
- **H11** 要"真实交谈质感" → 用非职业演员、引导即兴真实反应而非背台词，分寸 20–40%，让停顿与生疏留在成片。
- **H12** 想模糊纪录与虚构 → 让真实事件当事人扮演自己（Close-Up 式）/ 前作角色/演员在续作里现身（Koker 三部曲式自反）。

### E. 调色 / 声景 / 光影
- **H13** 荒野/死亡母题 → 大地色赭黄 #B8895A 低对比，飞扬尘土天然漫射柔化光线，无饱和原色，不打人工补光。
- **H14** 情绪最重处 → **撤掉**配乐，只留引擎/碎石/风/环境同期声；唯一乐曲留到结尾的"生"。
- **H15** 黄昏/收束段 → 暖橙暮光渐沉、暗部渐增（40%→60%），让暮色自然变暗承载等待。
- **H16** 儿童/求索母题 → 儿童视角平视或略俯跟随，之字上坡的执拗奔走（何处是我朋友的家式），环境同样渺小化个体。

### F. 剪辑 / 节奏 / 视线
- **H17** 车内对话剪辑 → 靠正反打与对话推进节奏，**不快剪打碎**长镜；一人说完切另一人（车窗框做切点）。
- **H18** 反打时 → 两人各望**画外**的对话者（视线不交于同框），强化"不同框=孤独隔离"。
- **H19** 场景过渡 → 可用黑屏 / 画质断裂 / 时间跳跃作硬过渡，而非流畅转场。
- **H20** 结尾 → 先黑屏悬置（问题），再用"生"（绿草/活着的演员/唯一配乐）作最温柔的反驳，而非给明确答案。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 车内 2-shot 是否"阿巴斯式"判别（不同框铁律）**
```
满足全部才算：① 透挡风玻璃/侧窗框住单人（车窗=画框）
             ② 司机与乘客几乎不同框、正反打切换
             ③ 两人各望画外的对话者（视线不交于同框）
             ④ 人物相对静 + 背景随车缓慢横移（人静世界动）
             ⑤ 单镜 ≥30s，靠对话与留白推进、不快剪
违反（频繁同框对切/看镜/快剪）= 破坏"孤独隔离"签名。
```

**F2 · 远观渺小判别（情绪重转折的镜头选择）**
```
情绪最重的转折（拒绝/离去/困惑/生死） → 拉大远景，人/车 <5% 画面，远观不介入
   （✗ 大特写逼脸 = 反阿巴斯）
路径 = 之字盘山 / 兜圈往复（困境的空间形状），而非直线抵达
```

**F3 · 留白纪律判别（不直给）**
```
最重的信息（自杀/动机/结局） → 永不直说、不展示过程
   用：委托任务侧写 + 对方反应 + 台词缝隙
结局 → 黑屏渐入并停留，拒给答案（靠声音维持黑屏）
一旦直说穿/展示过程/给明确答案 = 破坏留白纪律（观众失去座位）
```

**F4 · 真实↔虚构边界判别（元电影）**
```
要撕开虚构 → 引入至少一项：35mm→DV 画质断裂 / 戏中戏 / 演员出戏 / 当事人演自己
接缝必须"可见"（画质/景别/表演状态的公开断裂），而非无缝
目的：宣告"这是被拍出来的"，把判断托回观众
```

**F5 · 大地色 + 声景克制判别**
```
调色 = 赭黄/土褐 #B8895A 为主 · 无饱和原色 · 低对比 · 尘土漫射柔光（HSV 区间推断，需实机校准）
声景 = 引擎/碎石/风/环境同期声为底床 · 情绪最重处撤配乐 · 唯一乐曲留结尾
主题转向"生" → 景物从荒土渐入有树/绿草、声景渐起鸟鸣孩笑
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 车内移动忏悔室（2-shot 单人正反打）** ｜机制：透车窗框住单人、司机与乘客不同框、正反打靠车窗框各望画外｜参数：机位架车内/贴车外随车；50–85mm f4；距 0.8m；单镜 30s–3min；背景随车缓慢横移（人静世界动）｜触发：车内交心/交锋/移动忏悔/陌生人交谈｜意图：汽车=移动忏悔室，分镜=各自封闭的孤独｜正例：樱桃的滋味 §场景 A（载库尔德士兵）、§场景 B（巴格里讲桑葚）。

**T2 · 远观之字盘山（渺小如尘点）** ｜机制：极远景把车放进巨大土黄山坡、之字路承载困境几何｜参数：50mm f8；距 200m+（对面山坡）；车/人 <5% 画面；固定或极缓摇 0.02 m/s 跟车｜触发：情绪重转折/困惑/徘徊两难｜意图：个体消融在亘古大地、远观=不介入的尊重｜正例：樱桃的滋味 §镜 A-1（之字土路缓行）；（跨作品·推断）何处是我朋友的家 §之字坡奔走。

**T3 · 死亡/动机永不直给（任务侧写）** ｜机制：最重信息不直说不展示、用委托任务侧写｜参数：镜头停在请求/犹豫/对话；服药、死亡过程完全不拍；信息放台词缝隙与对方反应｜触发：自杀/秘密/沉重动机｜意图：不说的比说的重、动机成被尊重的谜｜正例：樱桃的滋味 §一.4（"死亡念头永不直给"指纹）+ §场景 A（车内绕着说的委托 · "明早六点若我没醒往坑里填二十铲土"侧写自杀）。

**T4 · 暧昧黑屏开放结局** ｜机制：关键结局处画面渐入全黑并停留、拒给答案｜参数：闪电/末镜后渐入纯黑并停留 ~12s；不交代生死；靠闷雷/雨/静默维持黑屏｜触发：生死/去留悬置、开放收束｜意图：把判断托回观众、空缺=座位｜正例：樱桃的滋味 §镜 C-3（躺进坑后渐入全黑）。

**T5 · 35mm→DV 元电影 coda（撕开虚构）** ｜机制：用画质/景别/表演状态的公开断裂宣告"这是电影"｜参数：手持 DV 粗粝低清色偏、中远景；同一地点已转生机（草转绿）；摄制组/器材/演员出戏入镜；唯一配乐响起｜触发：结尾自反、真实↔虚构边界｜意图：生命（绿草/活着的演员）反驳前段的死亡念头｜正例：樱桃的滋味 §镜 C-4（35mm→DV 草坡摄制组 coda）。

**T6 · 大地色尘土漫射调** ｜机制：飞扬尘土天然柔化光与色、无饱和原色｜参数：主导赭黄/土褐 #B8895A（HSV 推断）；低对比；尘土把直射阳光打成漫射柔光；不打人工补光、不做鲜艳调色；黄昏偏暖橙｜触发：荒野/死亡母题/公路漫游｜意图：尘归尘的克制、暖而荒的大地既是坟也是生｜正例：樱桃的滋味 §镜 A-1、§场景 C 黄昏土坑。

**T7 · 近零配乐的同期声景** ｜机制：环境同期声当唯一"配乐"、情绪重处撤乐｜参数：引擎/换挡/碎石碾压/远处工地机械/风/犬吠/鸟鸣为底床；全片近零配乐；唯一乐曲留结尾｜触发：任何需要"真实质感 + 反煽情"的场景｜意图：拒绝替观众决定感受、让对话重量自己沉下去｜正例：樱桃的滋味 §一.3（"极简自然声景"指纹 · 引擎/碎石/风底床）+ §镜 C-4（全片唯一乐曲出现在 coda）。

**T8 · 人静世界动（背景横移）** ｜机制：车随路前行使背景持续缓慢横移、前景人物相对静止｜参数：50mm；人物锁定于框内静止；背景土坡/景物横向移动；动静分离｜触发：车内对话长镜、沉静漂移感｜意图：让对话成为唯一焦点、制造漂移的沉静｜正例：樱桃的滋味 §镜 A-2/B-1（背景土坡缓慢横移）。

**T9 · 景物随主题悄然转向（荒土→生机）** ｜机制：环境而非台词暗示情绪走向｜参数：劝生/转向"生"时车窗外景物从荒土渐入有树、有孩子、绿坡；声景渐起鸟鸣/孩笑；画面渐亮渐暖｜触发：从死到生的情感转向、"值得留下"｜意图：用环境暗示"值得活的具体"、不靠台词点明｜正例：樱桃的滋味 §镜 B-3/B-4（背景渐入有树坡地 + 掠过生机空镜）。
