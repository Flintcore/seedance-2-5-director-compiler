**核心 DNA**：朴赞郁 × 郑正勋的分镜系统 = **"把命运的精密设计外化成几何构图与风格化暴力"**，四根支柱。① **对称即宿命**：中心透视对称构图（消失点居中·垂直/水平轴对齐·装饰性繁复巴洛克布景）= "一切都被安排好"的窒息（≠随意构图）。② **横向卷轴长镜暴力**（判别铁律）：侧面 90° 机位 + 缓慢横移 track + 一镜到底 + 平面化舞台，把打斗拍成 2D 横版格斗侧滚屏——暴力是残酷连续的舞蹈，**不快剪**。③ **风格化暴力 ≠ 写实**：锤斗/自残/仪式化处理 + 古典乐反讽对位（优雅配乐 × 残酷画面）+ 暴力声效写实以加冲击。④ **色彩即命运阶段**：紫红 #6B2D4A（欲望/暴力压抑）· 绿 #3E5A45（监禁病态停滞）· 冷白（屈辱/真相）——色调随命运曲线硬切。⑤ **垂直/俯视调度**：上帝俯拍 + 垂直穿层运动（楼梯/井/坠落）= 人被更高设计者俯视操纵。⑥ **表演大摆荡**：隐忍 30% ↔ 癫狂 95% 剧烈切换。方法：精密预设分镜（非即兴）、繁复美术先行、对称是骨架。

**适用情境**：复仇/暴力美学、心理惊悚、悲剧反转、几何对称构图、横向长镜打斗、命运窒息、癫狂表演、情欲张力（小姐/蝙蝠）。**不适用/需改造**：需要手持纪实随意感的题材、明亮均匀高调纪录片、需要客观中立零设计感的场景、要求快剪凌厉动作可读性优先的商业动作（本系统打斗是长镜卷轴）。

## 一、核心心智模型（8 个镜片 · How Park sees a shot）

### M1 · 对称即宿命（构图是命运的骨架）
先立对称轴与消失点，再放人；情绪由**几何秩序**承载。中心透视对称 = "这一切都被某人精密安排好了"的窒息感，人被锁在几何格子里。
- **分镜含义**：先问"这场戏的对称轴/消失点在哪"，再摆人。命运/操纵/仪式场景 → 强对称；混乱/失控 → 打破对称。见 §T2/F1。

### M2 · 暴力是编排的舞蹈，不是记录
暴力经过节奏与走位编排，风格化呈现（连续长镜、仪式化动作、优雅配乐反讽），视觉冲击与情感表达优先于写实血腥。
- **分镜含义**：拍暴力时先设计"它像什么舞蹈/游戏"（走廊 = 2D 横版格斗侧滚屏），而非追求纪实血浆。见 §T1/M6/F2。

### M3 · 色彩是命运的阶段刻度
颜色标记角色所处的命运阶段，不是装饰。紫红 = 欲望/暴力压抑；绿 = 监禁/病态/时间停滞；冷白 = 屈辱/真相/剥离。阶段转换用色调硬切。
- **分镜含义**：定一场戏主导色前先定"角色在命运哪一阶段"。监禁绿 → 自由刺白 → 复仇紫红 → 真相冷白，是可视化的命运曲线。见 §T5/F4。

### M4 · 垂直即权力落差（俯视/穿层）
摄影机的高度与垂直运动编码权力：上帝俯拍 = 角色被更高的设计者俯视/操纵；垂直穿层（楼梯/竖井/坠落）= 命运的下坠。
- **分镜含义**：想表达"被操纵/被俯视/命运下坠" → 上俯拍或垂直调度；平视/仰视留给对峙与尊严。见 §T6/M1。

### M5 · 精密预设，非即兴（分镜先行）
朴赞郁的现场是高度设计的：繁复美术、走位、对称机位事先算好；风格来自**控制**而非现场偶发。（与王家卫"将错就错"相反——对照判别用）
- **分镜含义**：设计时追求"每一格都被安排"的精确感，允许繁复装饰、几何对齐、可复现机位；不拥抱随机缺陷。见 §M1。

### M6 · 声画反讽对位（美 × 暴的落差）
优雅古典乐/华尔兹配残酷暴力画面，制造美与暴的强烈反差；同时暴力声效（锤击/刀插）写实化以加冲击。声与画不是加法，是对位反讽。
- **分镜含义**：残酷段落想要"审美化的残忍"→ 上优雅配乐 + 写实暴力声效；不用紧张惊悚配乐直给。见 §T7/F2。

### M7 · 框中框 / 窥视与阻隔（几何化的偷窥与隔离）
门框/窗框/走廊/镜面二次切割画面，把人锁进内框；玻璃/隔层暗示被观看、被隔离、被困。
- **分镜含义**：想要"被监视/被困/成双对照" → 框中框或镜面反射；对称门框强化仪式感。见 §T4/M1。

### M8 · 表演双极摆荡（隐忍 ↔ 癫狂）
表演在克制（30%）与爆发（95%）间剧烈切换，中间态少；情绪由几何构图压住，一旦释放即极端（嚎哭/狂笑/自残）。
- **分镜含义**：给情绪一个"压 → 爆"的落差曲线：压抑段用对称静止镜 + 克制表演，爆发段用手持微动 + 癫狂表演。见 §T8/H18/H19。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 对称 / 几何构图
- **H1** 要"命运被精密安排"的窒息 → 中心透视强对称：消失点居中，垂直/水平主体轴对齐，两侧元素镜像。
- **H2** 场景涉及仪式/操纵/秩序（审判/告解/机构/家宅）→ 对称机位 + 装饰性繁复布景（巴洛克壁纸/门框/家具对齐）。
- **H3** 角色进入混乱/失控/真相崩塌 → **打破**此前建立的对称（倾斜/偏心/手持），用失衡对照前面的秩序（§F1）。
- **H4** 要"被监视/被困/成双对照" → 框中框（门/窗/走廊/镜）或镜面反射把人锁进内框（§T4）。

### B. 暴力 / 长镜编排
- **H5** 一人对群殴 / 线性推进的苦战 → 横向卷轴长镜：侧面 90° 机位 + 缓慢横移 track 0.1–0.2 m/s + 一镜到底 + 平面化舞台（像 2D 横版格斗侧滚屏）。
- **H6** 要"暴力是舞蹈"而非血腥记录 → 编排走位节奏 + 长镜连续 + 仪式化动作，冲击优先写实（§T1/F2）。
- **H7** 暴力段落配乐 → 用优雅古典乐/华尔兹反讽对位，**不**用惊悚紧张乐直给（§M6/T7）。
- **H8** 暴力声效 → 写实化（锤击闷响/刀插/骨响），与风格化画面对位以加冲击。
- **H9** 单点残酷（拔牙/自残/仪式）→ 定格或升格**点缀**（非全程慢镜美化），锁定机位残酷凝视。

### C. 色彩 / 命运阶段
- **H10** 监禁/病态/时间停滞 → 绿调 #3E5A45 + 暗部偏高 + 冷电视光。
- **H11** 欲望/暴力/压抑复仇 → 紫红 #6B2D4A + 钨丝暖点 + 低饱和压抑。
- **H12** 屈辱/真相剥离/情感清算 → 冷白 / 雪白 / 高冷调，硬切对照此前暖紫红（§F4）。
- **H13** 命运阶段切换 → 色调**硬切**而非渐变，让色彩本身叙事（绿→刺白→紫红→冷白）。
- **H14** 情欲/禁忌张力（小姐/蝙蝠）→ 饱和暖色（红/金/湖绿）+ 精致质感光 + 装饰性对称，把欲望审美化。

### D. 高度 / 垂直调度
- **H15** 要"被操纵/被更高设计者俯视" → 上帝俯拍（正上方或高俯），人被压在几何图案里。
- **H16** 命运下坠/穿越层级 → 垂直调度（楼梯/竖井/坠落跟拍），机位随之升降。
- **H17** 对峙与尊严时刻 → 平视或略仰，把对称留给权力对等；一方跪地乞求时用微俯拍摄压制（老男孩雪地）。

### E. 表演 / 摄影机态度 / 运动
- **H18** 压抑蓄势段 → 对称静止/极缓 push in 0.05–0.08 m/s + 克制表演 30–40%。
- **H19** 崩溃/癫狂爆发段 → 手持微动 + 癫狂表演 90–95%（嚎哭/狂笑/自残），失稳对照前面的稳。
- **H20** 大摇臂/连续复杂运动（复仇集结/情绪高潮）→ 起重臂长镜连续调度穿越空间，不剪，运动本身即戏剧（推断，见 §九）。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 对称 vs 失衡判别（秩序 ↔ 崩塌）**
```
角色处于"被安排 / 仪式 / 操纵 / 秩序"状态 → 中心透视强对称（消失点居中 + 轴对齐 + 镜像布景）
角色进入"混乱 / 失控 / 真相崩塌"       → 打破对称（倾斜 / 偏心 / 手持失稳）
铁律：先建立对称，再在崩塌处打破它——失衡靠先有秩序才有意义。
```

**F2 · 横向卷轴长镜 vs 快剪打斗判别（两种暴力）**
```
要"暴力是残酷连续的舞蹈 / 一人苦战 / 线性推进" → 横向卷轴长镜（侧面90°+横移track+一镜到底+平面化舞台）
要"凌厉碎片 / 动作可读性优先 / 商业爽感"       → 快剪多机位（本系统不用于此）
判别：朴式打斗看得见"疲惫的连续"，不是"炫技的碎片"。老男孩走廊=卷轴派。
```

**F3 · 风格化暴力 vs 写实暴力判别**
```
朴式暴力 = 编排走位 + 长镜/仪式化 + 优雅配乐反讽 + 写实声效（画面风格化 / 声音写实）
写实纪实暴力 = 手持晃动 + 快剪 + 无配乐 + 血腥直给
判别：若配乐是华尔兹 / 古典乐且画面对称编排 → 朴式；若追求生理不适纪实 → 非朴式。
```

**F4 · 色彩命运阶段判别（色 = 阶段）**
```
绿 #3E5A45  → 监禁 / 病态 / 时间停滞
紫红 #6B2D4A → 欲望 / 暴力 / 压抑复仇
冷白 / 雪白  → 屈辱 / 真相 / 情感剥离
饱和暖(红金)→ 情欲 / 禁忌审美化（小姐 / 蝙蝠）
阶段切换用硬切；同一命运阶段内保持主导色纪律，混色即失去叙事价值。
```

**F5 · 垂直高度判别（机位高度 = 权力）**
```
上帝俯拍 / 高俯 → 角色被更高设计者俯视 / 操纵 / 压制
平视          → 对峙 / 权力对等 / 尊严
微俯拍下跪者   → 屈辱 / 被压制的顶点
垂直穿层运动   → 命运下坠 / 穿越层级（楼梯 / 竖井 / 坠落）
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 横向卷轴长镜打斗（side-scrolling long take）** ｜机制：侧面机位 + 缓慢横移跟随一镜到底，暴力平面化成 2D 横版格斗侧滚屏｜参数：侧面 90° / 28mm / f4 / 平视；横移 track 0.1–0.2 m/s 跟随主角推进；一镜到底 2–3min 不剪；狭长走廊平面化舞台，一人对群殴｜触发：一人苦战群殴 / 线性推进的暴力｜意图：把暴力拍成残酷连续的舞蹈，体现复仇的疲惫与坚持｜正例：老男孩 §场景 A（走廊锤斗 · 库内 A-2 · 该系统标志性运用）。

**T2 · 中心透视对称构图（central symmetry）** ｜机制：消失点居中 + 垂直/水平轴对齐 + 两侧镜像 = "被精密安排"｜参数：对称机位 + 中心透视 + 装饰性繁复布景（壁纸/门框/家具对齐）+ 主体居中或轴对称双人｜触发：仪式 / 操纵 / 秩序 / 命运设计 / 机构空间｜意图：命运精密安排的窒息、几何牢笼｜正例：老男孩 §场景 B（封闭房间巴洛克对称 · 库内 B-1）；跨片：小姐宅邸对称、斯托克家宅几何构图（推断锚点）。

**T3 · 风格化仪式暴力（stylized ritual violence）** ｜机制：暴力经编排 + 仪式化动作 + 定格/升格点缀，冲击优先写实｜参数：锤斗/拔牙/自残仪式化编排 + 单点定格或升格点缀（非全程慢镜）+ 锁定机位残酷凝视 + 写实暴力声效｜触发：极端残酷单点 / 自我惩罚 / 仪式化伤害｜意图：暴力作为情感与命运的极端外化、残酷的美｜正例：老男孩 §场景 C-3（剪舌自残 · 锁定残酷凝视）、§A-3（背插刀仍战）。

**T4 · 框中框 / 镜面阻隔（frame-in-frame & mirror）** ｜机制：门窗走廊镜二次切割画面把人锁进内框 / 镜面成双对照｜参数：门框/窗框/走廊/镜占据边缘，主体居中内框；镜面反射间接看 + 成双；常与对称叠用｜触发：被监视 / 被困 / 成双对照 / 隔离｜意图：几何化的偷窥与囚禁、身份成双｜正例：老男孩 §B（封闭房间铁门框）；跨片：小姐镜面/门廊构图（推断锚点）。

**T5 · 命运阶段色彩硬切（fate-stage color switch）** ｜机制：色调标记命运阶段，阶段切换硬切非渐变｜参数：绿 #3E5A45（监禁）→ 刺眼日光（自由/眩晕）→ 紫红 #6B2D4A（复仇）→ 冷白/雪白（真相/屈辱），硬切｜触发：命运阶段转换 / 今昔对照｜意图：色彩本身即命运曲线叙事｜正例：老男孩全片弧线（§B 绿→§B-4 刺白→§C 紫红→§C-4 雪白）。

**T6 · 上帝俯拍 / 垂直穿层（god's-eye & vertical staging）** ｜机制：机位高度与垂直运动编码权力落差｜参数：正上方/高俯拍把人压进几何图案；垂直调度随楼梯/竖井/坠落升降机位｜触发：被操纵/被俯视/命运下坠/穿越层级｜意图：人被更高设计者俯视操纵、命运的下坠｜正例：老男孩 §C-4（微俯拍雪地下跪 = 屈辱压制顶点）；跨片：上帝视角俯拍调度（推断锚点）。

**T7 · 古典乐反讽对位（elegant-score irony）** ｜机制：优雅古典乐/华尔兹配残酷画面，美 × 暴反差｜参数：优雅配乐（华尔兹/古典）叠残酷暴力画面 + 写实暴力声效（锤击/刀插）并存 + 对称编排画面｜触发：审美化的残忍段落｜意图：美与暴的强烈反讽、残酷的仪式感｜正例：老男孩 §四声音设计（古典/华尔兹配暴力 · 声画反讽）。

## 七、禁忌清单（❌ 朴赞郁式分镜绝不做的事）

- ❌ **用快剪拍朴式打斗**——它是横向卷轴长镜一镜到底，不是碎片凌厉快剪（§F2）。
- ❌ **随意/平淡构图**——命运感靠中心透视对称与几何秩序，装饰性繁复是骨架（§M1/F1）。
- ❌ **写实纪录式血腥暴力直给**——应编排 + 仪式化 + 古典乐反讽，冲击优先写实（§F3）。
- ❌ **暴力段配紧张惊悚乐**——应用优雅古典乐/华尔兹反讽对位（§M6/T7）。
- ❌ **全程慢镜美化暴力**——升格/定格只作点缀，主体是连续卷轴或写实声效（§T3/H9）。
- ❌ **全程冷静克制或全程癫狂**——应隐忍 30% ↔ 癫狂 95% 剧烈摆荡，落差才是戏；中间态少铺（§M8/H18/H19）。
- ❌ **色彩乱铺、随意混色**——色 = 命运阶段，同阶段守主导色，切换用硬切（§F4）。
- ❌ **把'将错就错'的随机缺陷当风格**——朴式是精密预设、可复现机位，与即兴美学相反（§M5）。
- ❌ **对峙/尊严时刻用俯拍压制**——俯拍留给"被操纵/屈辱"，对等对峙用平视（§F5）。
