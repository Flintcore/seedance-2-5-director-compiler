## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：黑泽明的分镜系统 = **"用运动、天气、几何把情绪外化"** 的四台引擎。① **运动引擎**：每一帧都有内部运动（临时演员/旗/尘/雨/衣袍作画面内持续运动，主体静止就让 BG 上风尘旗，至少两层异速运动）；"combine the right motion and the right emotion, you get something cinematic"；摄影机随演员动而动、演员停则停。② **多机位+长焦引擎**：A/B/C 三机同拍（正统/决定性/游击），长焦压缩纵深把人海叠成等大图形层（但基准叙事 35-50mm，超长焦是战场选择性武器）。③ **天气引擎**：选天气=选情绪（雨=秩序崩解/风尘=紧张前奏/雾=迷失被命运操纵/热浪=焦躁）；拍可见暴雨必造反差（浅背景掺墨压暗、深背景逆光显银线）。④ **几何+剪辑引擎**：三角站位/深焦分层表达权力；轴向跳切（同轴·破 30°·ELS→CU）造冲击；wipe（方向=运动方向·早中期签名·乱已弃）；动接动切在动作已启动后；静↔爆（长静蓄势→单一触发→极快连斩→骤停）。彩色期：军团色块+方向双编码（乱）、黑白单点色线索（天国与地狱）。

**适用情境**：史诗战争、武侠对决、群像调度、天气大戏、悲剧顶点、时代剧、都市惊悚。**不适用/需改造**：极简静观慢电影、亲密室内小品（黑泽明偏运动+规模+戏剧化）。

## 一、核心心智模型（8 个镜片 · How Kurosawa sees a frame）

### M1 · 一切皆动（每帧都有内部运动）
即使固定机位，画面里也必须有运动（人群/旗/尘/雨/衣袍）。Tony Zhou《Composing Movement》："combine the **right motion** and the **right emotion**, you get something cinematic."
- **分镜含义**：主体静止 → BG 强制上风/尘/旗；预算只够固定机位 → 至少两层异速运动。→ 见 §T1。

### M2 · 摄影机随演员（动而动·停则停）
黑泽明原话："The camera should **follow the actor as he moves; it should stop when he stops**. If this rule is not followed, the audience will become conscious of the camera."
- **分镜含义**：运镜由演员运动驱动，不无理由自走；演员停，镜头停。

### M3 · 多机位 + 长焦
A/B/C 三机同拍（正统基准/快决定性/游击贴身）；长焦压缩纵深把远近人叠成等大图形层。
- **分镜含义**：要图案化人海/等大群像 → 长焦压缩（禁广角）；要覆盖动作便于动接动 → 三机紧凑集群不同焦距。**基准叙事 35-50mm，超长焦只给战场/人群**（别全片长焦）。→ 见 §T2/F1。

### M4 · 天气即戏剧
天气是"active participant"，不是背景。Richie："Rain in Kurosawa's films is never treated neutrally… always a **frenzied downpour**."
- **分镜含义**：选天气=选情绪（§F3）；拍可见暴雨必造反差（掺墨/逆光银线）。→ 见 §T3/T4/T5。

### M5 · 轴向剪辑（同轴跳景别）
沿同一光轴、机位角度零变化，只裁切放大景别硬跳（故意破 30° 规则），制造冲击/强调。
- **分镜含义**：要冲击/敲重点 → 轴向跳切 ELS→中近→CU，每跳景别 ≥1 档。→ 见 §T6。

### M6 · 划像转场（方向=运动方向）
wipe 是他的中期签名：**擦除方向 = 画面主体运动方向**（左行左擦）。
- **分镜含义**：换段/跳时间/行进强调 → wipe。**年代律**：中期签名，晚期几乎消失（《影武者》基本无、《乱》全片 0 wipe）——写晚期片禁用 wipe。→ 见 §T7/F4。

### M7 · 几何调度（站位即关系）
用三角/几何站位、深焦纵深分层表达权力与关系。
- **分镜含义**：群像权力 → 几何站位（"三张脸"△）+ 前景遮挡逐格缩份额；深焦全实=平权，广角近大远小=等级。→ 见 §T9/F1。

### M8 · 色彩即叙事（彩色期）
《乱》军团**色块编码 + 方向编码**双轨；黑白片用**单点色**做线索爆点（《天国与地狱》粉红烟）。
- **分镜含义**：彩色军团 → 纯色编码 + 入画方向编码（仅凭调色板+方向读战局）；黑白要一个线索爆点 → 单点色。→ 见 §T10/F6。

## 二、决策启发式（20 条 if-then）

### A. 运动 / 节奏
- **H1** 主体静止 → BG 强制上风/尘/旗/远景人群，至少两层异速运动（前中后景异向异速）。
- **H2** 运镜 → 由演员运动驱动，演员停则镜头停（M2）。
- **H3** 要"电影感" → 组合"对的运动 + 对的情绪"，不是为动而动。
- **H4** 对峙戏 → 给双方**反相运动量**（一静一躁：蜘蛛巢城浅茅 terrifying stillness vs 三船 constantly in motion）。
- **H5** 静↔爆 → 长静（天气拉满 + 对切逐次推近 + 剪辑稀疏）→ 单一触发（掷刀/拔刀）→ 极快连斩（剪辑骤密）→ 骤停。

### B. 机位 / 镜头
- **H6** 要图案化人海/等大群像 → 长焦压缩纵深（禁广角）。
- **H7** 要覆盖一段动作便于动接动 → A/B/C 三机紧凑集群 + 不同焦距同拍；要空间描述 → 三机大距离散开（§F2）。
- **H8** 基准叙事 → 35-50mm；超长焦（数百 mm）只给战场/骑兵/人海的选择性图案化，别全片长焦。
- **H9** 长焦要前后皆锐（深焦悖论）→ 强布光 + 收小光圈（高 T-stop）。

### C. 天气
- **H10** 选天气 = 选情绪（雨=崩解 / 风尘=紧张 / 雾=迷失 / 热浪=焦躁 / 旗狂舞=动荡）（§F3）。
- **H11** 拍可见暴雨 → 浅背景**掺墨压暗**（罗生门·消防水管造雨）/ 深背景**逆光显银线**；长焦压景深；有暴雨必给泥（地面账单律）。
- **H12** 风 → 必给可见载体（尘/叶/旗/发/袍/烟）；尘从脚边小旋 → 裹身狂抽，对应情绪爬升。
- **H13** 雾迷失 → 让人**走进雾里消失、从别处走出**；黑背景（黑墙/黑甲/黑土）+ 浓白雾 = 水墨高反差；要"陷阱"则禁风、死寂静止。

### D. 剪辑 / 转场
- **H14** 要冲击/敲重点 → 轴向跳切（同轴·破 30°·ELS→中近→CU·每跳 ≥1 档）；也可对道具同轴跳进。
- **H15** 换段/跳时间/行进强调 → wipe（方向=主体运动方向）；**但晚期片（乱/影武者）不用 wipe**，改叠化/淡出。
- **H16** 动接动 → 切在**动作已启动之后**（非起幅），前后镜运动方向一致 + 前后景相似 = 切口隐形。

### E. 几何 / 色彩
- **H17** 群像权力 → 几何站位（三张脸△：下半两人互为侧脸=底边 + 上半中央正脸旁观者=顶点后退一层）；深焦全实=平权，广角近大远小=等级。
- **H18** 治→乱的转变 → 构图从中心对称 → 主体贴边失衡。
- **H19** 彩色军团 → 色块编码（纯色·禁串色）+ 方向编码（仅凭调色板+入画方向读战局）；混战三原色染成 muddy violet-brown = 秩序崩坏。
- **H20** 黑白要一个线索爆点 → 单点色（天国与地狱粉红烟）；悲剧顶点 → 消 diegetic 音、只留单一挽歌配乐（乱燃城）。

## 三、判别公式（6 个 · 可测 · 当 要点）

**F1 · 长焦 vs 广角（纵深的意义）**
```
长焦压缩 → 图案化 / 平权 / 人海叠等大（战场、骑兵、群像）
广角近大远小 → 权力等级 / 纵深穿行
深焦全实（收 T-stop）→ 平权（人物同等清晰）
```

**F2 · 多机位布阵**
```
要"动接动"覆盖 → 三机紧凑集群 + 不同焦距打同一动作
要"空间描述" → 三机大距离散开
A=正统基准 / B=快决定性 / C=游击贴身钻缝
```

**F3 · 天气 = 情绪（选天气 要点）**
```
雨+泥   → 秩序崩解为混沌      风卷尘/落叶横扫空街 → 紧张前奏·无主之地
浓雾吞吐 → 迷失/被命运操纵      旗幡狂舞           → 动荡/叛乱
热浪+对太阳拍 → 焦躁灼烧        死寂缠枝雾林       → 陷阱无出路
（先选情绪，再选天气；天气必须"可见"——见 H11/H12）
```

**F4 · wipe vs 叠化 vs 轴向切**
```
换段 / 跳时间(ellipsis) / 行进强调 → wipe（方向=运动方向）—— 仅早中期
需要情感重量 / 抒情过渡           → 叠化(dissolve)
要冲击 / 强调时长 / 敲重点         → 轴向跳切（同轴景别硬跳）
⚠️ 晚期片（乱1985/影武者1980）几乎不用 wipe
```

**F5 · 静↔爆节奏**
```
静（长·天气拉满·对切逐次推近·剪辑稀疏）
  → 单一触发（掷刀/拔刀/一声令下）
    → 爆（极快·剪辑骤密·如乱燃城约 30s/19cut·天气延续·换向）
      → 骤停
```

**F6 · 色彩双编码（乱）**
```
每个阵营 = (纯色, 入画方向) 二元组
  太郎=黄 / 次郎=红朱(永远左→右) / 三郎=蓝(永远右→左) / 秀虎=素白 / 守方=黑
铠甲+军旗+戎装全覆盖，禁串色 → 观众仅凭调色板+方向即可读懂战局
混战 = 三原色相染成 muddy violet-brown = 秩序崩坏
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 画面内运动分层** ｜机制：固定机位也让每层都动｜参数：BG(雨/尘/旗/远景人群·异向·慢-中·永不为0) + MG(次要人物/马队·反向交叉·中速) + FG(主体走位/甩袍·主向·快或极慢蓄势)｜触发：任何镜｜意图：画面永远活的｜正例：乱三军对阵、七武士(已在库)。

**T2 · A/B/C 多机位 + 长焦压缩** ｜机制：三机同拍 + 长焦压平纵深｜参数：A正统35-50mm/B长焦决定性/C游击超长焦；人海压成等大图形层｜触发：动作覆盖/人海图案化｜意图：真表演+动接动素材+图形化｜正例：乱骑兵军团、用心棒街道。

**T3 · 天气可见性（雨）** ｜机制：雨对背景造反差才可见｜参数：浅背景掺墨压暗(罗生门)/深背景逆光显银线·长焦压景深禁广角·必给泥｜触发：暴雨戏｜意图：秩序崩解为混沌｜正例：七武士终战(已在库)、罗生门檐下(已在库)。

**T4 · 风尘可见载体** ｜机制：风必附着可见物才成立｜参数：8台风机·尘/叶/旗/袍作载体·尘从小旋→裹身狂抽对应情绪爬升｜触发：紧张前奏/无主之地｜意图：不安/山雨欲来｜正例：用心棒空街。

**T5 · 雾迷失（走进消失）** ｜机制：黑背景+浓白雾=水墨；人走进雾消失从别处走出｜参数：黑墙/黑甲/黑土 + 浓白雾高反差·陷阱则禁风死寂｜触发：迷失/被命运操纵｜意图：suiboku-ga 命运感｜正例：蜘蛛巢城蛛网森林。

**T6 · 轴向跳切** ｜机制：同光轴零角度变化只裁景别硬跳｜参数：ELS(俯)→中近→CU+台词起·破30°·每跳≥1档·越极端冲击越强·可对道具跳进敲重点｜触发：冲击/强调｜意图：撞击感/强调｜正例：七武士(已在库)、蜘蛛巢城乱箭。

**T7 · wipe 转场（方向=运动·年代律）** ｜机制：横/竖擦切场·方向=主体运动方向｜参数：横擦=换景/时间·竖擦=垂直运动·中期签名·晚期(乱)弃用｜触发：换段/跳时间/行进｜意图：利落推进｜正例：用心棒、七武士(已在库)。

**T8 · 动接动（切在动作后）** ｜机制：多机位素材在动作中无缝剪｜参数：切在动作已启动之后(非起幅)·前后同向+前后景相似=切口隐形·拆一动作成两镜出情绪｜触发：动作戏｜意图：流畅或(反用越轴)惊吓｜正例：天国与地狱火车、七武士。

**T9 · 几何站位 + 深焦分层** ｜机制：三角/几何站位表达关系·纵深≥3平面各承叙事｜参数：三张脸△·前景遮挡逐格缩份额·深焦(收T-stop)平权/广角等级·中心对称→贴边失衡｜触发：群像权力戏｜意图：站位即关系｜正例：天国与地狱公寓、乱。

**T10 · 色块+方向双编码（+单点色）** ｜机制：色彩当叙事层｜参数：乱军团纯色编码(黄/红/蓝/白/黑·禁串色)+方向编码·混战染muddy-brown=崩坏；黑白单点色=线索爆点(天国与地狱粉红烟)·悲剧顶点消音留挽歌｜触发：彩色史诗/黑白线索｜意图：调色板即战报/线索｜正例：乱燃城、天国与地狱粉红烟。

## 七、禁忌清单（❌ 黑泽明式分镜绝不做的事）

- ❌ **让画面任何一层完全静止**——固定机位也要 BG 有运动（M1/H1）。
- ❌ **无理由自走的摄影机**——运镜由演员驱动、演员停则停（M2/H2）。
- ❌ **全片超长焦**——基准 35-50mm，长焦是战场选择性武器（M3/H8）。
- ❌ **暴雨不造反差**——普通雨对浅天空会消失，须掺墨或逆光（M4/H11）。
- ❌ **风不给可见载体**——光有风声无尘/叶/旗 = 没风（H12）。
- ❌ **晚期史诗（乱）用 wipe**——年代不符，改叠化/淡出（M6/F4）。
- ❌ **动接动切在动作起幅**——应切在动作已启动之后（H16）。
- ❌ **彩色军团串色/无方向编码**——破坏"调色板即战报"（M8/F6）。
- ❌ **把掺墨造雨写成《七武士》**——确证是《罗生门》（见 §九）。

## 九、来源与诚实边界（Doubt-Log · 引用前先看）

**可直接当原话引用（高置信）**：
- 黑泽明（多机位）："I put the camera A in the most orthodox positions, use the camera B for **quick, decisive shots** and the C camera as a kind of **guerilla unit**."（《蛤蟆的油》Bock 译）
