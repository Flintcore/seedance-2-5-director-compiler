## 一、整体风格指纹（Style Fingerprint · 5 项可量化特征）

### 1. **前景遮挡换装蒙太奇（Foreground-Wipe Costume Change）🔴 本片首要入库价值**

- **物理参数**：
  - **前景遮挡物**：路过行人 / 横驶的出租车（黄色 taxi）/ 街边廊柱 / 办公室挂衣架（成排衣服）/ 门框 / 被翻开举到镜头前的杂志页 —— 任选其一，**占画面 40-70%**
  - **滑过方向 & 速度**：**横向**（左→右或右→左）滑过，速度 **0.8-1.5 屏宽/秒**（够快盖住换装动作、又看得清是什么物）；或 Andy 自己横移走过定点前景（廊柱/门框）
  - **遮挡瞬间 = 剪辑点**：前景物**完全盖住主体的 1-3 帧**就是 cut/wipe 的藏针处——这一瞬完成换装（实拍靠剪辑、AI 靠这一帧切镜）
  - **滑开落幅**：前景滑开后 Andy **已是一身新造型**（新外套/新发型/新包/新姿态），落幅停在新造型 0.5-1s 让观众"读完"变身
- **物理实现**：50-85mm 中焦压缩 + 前景物贴近镜头制造大面积虚化/实体遮挡 + 卡前景物全盖的帧切 + 每个"挡→换→滑开"是一个独立可复制单元，串成行走蒙太奇
- **情感意图**：用前景物当 **wipe / cut-mask** 实现无缝变身——观众潜意识接受"她一直在走、衣服一直在变"，把"造型升级 + 时间流逝 + 越来越精致"压成几秒。**这是 §十五 前景遮挡引擎 M4 延迟揭示的"变身版"**：M4 原本是"前景挡→滑开 reveal 真相"，这里 reveal 的不是真相而是**新造型**

### 2. **杂志/办公冷峻高级灰 ↔ 家/真实生活暖光 双色温（Dual Color Temperature）**

- **物理参数**：
  - **杂志世界（Runway 编辑部 / 米兰达 / 时装秀）**：冷峻高级灰 **5600-6500K** + 去饱和 **-25~-35%** + 黑白灰 + 单点高级色（cerulean 蓝绿 / 正红口红）+ 暗部干净 ≤30%
  - **家 / Andy 朋友男友 / 真实生活**：暖光 **3000-3400K** + 饱和正常 + 暖橙木质 + 杂乱有生活痕迹
- **物理实现**：杂志世界冷调 LED/日光 + 高对比柔光打型 + 调色去饱和；生活戏钨丝暖光 + 实景杂乱
- **情感意图**：色温 = 两个世界。Andy 越深入杂志世界，画面越冷越高级；她每回家/见朋友，画面回暖。**色温是她内心拉扯的可视化**

### 3. **米兰达权力调度（Miranda's Power Blocking）**

- **物理参数**：
  - **低机位仰角 15-25°** 拍米兰达（让她俯视镜头/俯视下属）
  - **沉默压制**：米兰达台词极少、音量极低（克制 30-50% 分寸）、靠停顿与不看人施压；下属在她沉默里慌乱解释
  - **仆从环绕递物**：助理/编辑环绕在她身侧后方，**不断递上样书/咖啡/外套/手机**，她不接也不看（拿了就走 / 把外套大衣直接甩到 Andy 桌上）
- **物理实现**：50-85mm + 低机位仰拍米兰达 + 下属用平视或略俯（被她压着）+ 米兰达居画面权力位（中心/上 1/3）
- **情感意图**：权力不靠喊——靠**机位高度 + 沉默 + 别人围着伺候**。仰角 = 仰望权威 / 仆从环绕 = 她是太阳系中心

### 4. **换装造型作角色弧线可视化（Costume Arc）**

- **物理参数**：三段造型对应弧线——
  - **土气期（开场）**：宽松不合身蓝毛衣 + 廉价格纹裙 + 平底鞋 + 杂乱发 + 大背包（造型 = "我不属于这里"）
  - **精致期（中段，换装蒙太奇之后）**：合身剪裁黑大衣 + 高跟靴 + Chanel + 利落直发 + 名牌包（造型 = "我征服了这里"）
  - **反思期（结尾）**：素净知性 + 卸下浮夸 + 自然质感（造型 = "我选择做自己"）
- **情感意图**：观众**看衣服就知道她走到哪一步**——造型是不用台词的成长进度条

### 5. **快节奏职场任务奔走蒙太奇（Errand Sprint Montage）**

- **物理参数**：1.5-3s/镜 短切 + 电话夹肩 + 高跟鞋特写跑动 + 在人群/出租车流/电梯间冲刺 + 手提咖啡托盘/样书包；环境声（街声/高跟鞋 click/电话铃/电梯叮）顶满
- **物理实现**：手持微跟 + 快切 + 中近景为主 + 真实纽约街景人流
- **情感意图**：职场是连环任务的高速碾压——节奏本身就是压力。**节拍靠剪辑速度 + 物理环境声扛，不靠 BGM**（⚠️ AIGC 视频生成不写配乐）

## 三、镜头语法 DNA（What makes David Frankel's "Prada" work）

1. **🔴 前景遮挡 = 换装的天然遮罩/转场剪辑点（M4 变身版）**：前景物（路人/出租车/廊柱/挂衣架/门框/翻杂志）横向滑过遮住主体 40-70% → 完全盖住的 1-3 帧是 cut 藏针处完成换装 → 滑开落幅露新造型。**接 §十五 前景遮挡引擎 M4 延迟揭示**（前景挡→滑开 reveal），只是 reveal 的是新造型不是真相。适用场景：变身 / 造型升级 / 状态变化 / 时间流逝压缩

2. **双色温分两个世界**：杂志/办公冷峻高级灰 5600-6500K 去饱和 -25~-35% vs 家/真实生活暖光 3000-3400K · 色温 = 主角内心拉扯的可视化 · 适用：双世界对比 / 角色被环境改变

3. **米兰达式权力三件套**：低机位仰角 15-25° + 沉默压制（极低音量 + 停顿）+ 仆从环绕递物 · 权力不靠喊靠机位高度和别人伺候 · 适用：boss 戏 / 权力压制 / 等级差

4. **去饱和画面里的单点高级色**：高级灰画面 + 一抹 cerulean 蓝绿 / 正红口红 / 唯一亮色 · 时尚高级感 = 极致克制 + 一点睛色 · 适用：时尚 / 高级感 / 冷峻克制

5. **造型作不用台词的成长进度条**：土气宽松 → 精致剪裁 → 反思素净三段 · 看衣服就知道角色走到弧线哪一步 · 适用：成长弧线 / 蜕变 / 身份转变

6. **快切奔走蒙太奇靠剪辑速度 + 物理声扛节拍**：1.5-3s/镜 + 电话/高跟鞋/电梯叮/街声顶满 · 节奏即压力 · ⚠️ AIGC 视频生成不写配乐——节拍交给前景滑过节奏 + 环境声、不交给 BGM · 适用：高压任务 / 时间压缩 / 都市快节奏

## 四、声音/音效设计 DNA

> ⚠️ **声音设计注意：不靠配乐**。原片换装蒙太奇配 KT Tunstall《Suddenly I See》——但 AIGC 视频生成中**不写 BGM**。本片节拍**靠前景滑过的节奏 + 物理环境声**承载，下面只列可用的物理声源：

1. **高跟鞋 click 做节拍锚点**：高跟鞋踩地的急促节奏 = 奔走戏/换装步行的天然鼓点（替代 BGM 打节拍）
2. **街声纹理**：纽约街声（车流/人声/喇叭/出租车驶过）= 杂志世界的真实底噪 + 前景出租车横扫时的"嗖"声卡换装点
3. **翻杂志/挂衣架声**：杂志翻页"哗"、成排衣架金属杆滑动声 = 前景物滑过遮挡的物理音效（卡 cut 点）
4. **电梯叮 / 电话铃 / 键盘**：办公室任务流的声音节拍器
5. **米兰达极低音量 = 静默压制**：她的低声 + 停顿本身就是声音设计（声音先行：越低越压人）· 下属慌乱解释填满她的沉默

## 八、本作"禁忌"清单（不要做什么）

David Frankel《穿普拉达的女王》绝不会做的事——本作的反例：

- ❌ **换装靠硬切黑场/叠化转场**——放弃前景遮挡这一天然遮罩 · 风格指纹 1 破坏（前景物当 wipe 才是本片精髓）
- ❌ **前景物滑过太慢/太快**——慢于 0.8 屏宽/秒露馅看出换装、快于 2 屏宽/秒看不清是什么物 · 失去"无缝又可读"
- ❌ **遮挡瞬间没卡在前景全盖的 1-3 帧**——换装藏针点错位 = 穿帮跳变 · 风格指纹 1 破坏
- ❌ **杂志/办公世界用暖光**——破坏冷峻高级灰 vs 暖光双色温 · 风格指纹 2 破坏
- ❌ **米兰达用平视/俯拍/仰望她**——破坏低机位仰角权力调度 · 风格指纹 3 破坏
- ❌ **米兰达大喊大叫怒吼（70-95%）**——破坏"克制权力"高级感 · 沦为普通暴躁 boss · 风格指纹 3 + 表演分寸破坏
- ❌ **画面满饱和或多杂色**——破坏去饱和高级灰 + 单点色的时尚克制 · 风格指纹 2/4 破坏
- ❌ **Andy 全片一种造型**——弃用造型作弧线可视化 · 风格指纹 4 破坏
- ❌ **任务奔走用慢推长镜**——破坏快节奏快切 · 风格指纹 5 破坏
- ❌ **把换装/奔走的节拍交给 BGM**——不靠配乐 · 必须靠前景滑过节奏 + 高跟鞋/街声/电梯叮物理声扛节拍
