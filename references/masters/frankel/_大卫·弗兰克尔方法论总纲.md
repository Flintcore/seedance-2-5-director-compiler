## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：弗兰克尔×Ballhaus 的分镜系统 = **"把角色转变外化成可见的换装与色温坐标"**，四根支柱。① **前景遮挡换装引擎**（库内首要价值）：前景物（路人/出租车/廊柱/门框/挂衣架/翻开的杂志页）横向滑过遮住主体 40–70%、以 0.8–1.5 屏宽/秒的速度掠过，在**完全盖住的 1–3 帧**藏 cut，滑开后主体已是新造型——把"造型升级+时间流逝"压成几秒，reveal 的是新造型而非真相。② **双色温分两个世界**（判别铁律）：杂志/权力世界=冷峻高级灰 5600–6500K + 去饱和 -25~-35%；家/真实生活=暖光 3000–3400K——**同一世界内不可混色温**，色温=主角内心拉扯的可视化。③ **去饱和里的单点高级色**：高级灰底 + 唯一一抹 cerulean 蓝绿/正红——高级感=极致克制+一点睛。④ **权力靠调度不靠喊**：低机位仰角 15–25° + 沉默压制（极低音量+停顿）+ 仆从环绕递物。母题→镜头：蜕变→造型三段弧线（土气→精致→反思）；高压→快切奔走蒙太奇 1.5–3s/镜、物理声（高跟鞋/电梯叮/街声）扛节拍不配乐。

**适用情境**：时尚/职场/都市题材、变身与造型升级、状态变化、时间流逝压缩、权力压制戏、成长弧线、杂志质感高级感、快节奏商业片。**不适用/需改造**：需要粗粝纪实颗粒/自然主义的题材（本系统追求光鲜干净）、纯静态文艺长镜（本系统偏快切）、无造型/状态变化可写的戏（换装引擎无处发力）、需要满饱和暖调的温情题材（破坏高级灰纪律）。

## 一、核心心智模型（8 个镜片 · How Frankel/Ballhaus sees a shot）

### M1 · 转变优先于对白（衣服替角色说话）
角色走到弧线哪一步，用**造型/色温/机位**呈现，不靠台词交代。Andy 从缩肩宽松蓝毛衣到抬下巴合身黑大衣，观众看衣服就知道进度。
- **分镜含义**：先问"这场戏角色的状态变了没、怎么用可见的东西（造型/色温/姿态）标出来"，再摆镜头。→ 见 §T3/T6。

### M2 · 前景物 = 天然遮罩与剪辑点
横向掠过的前景物不是构图装饰，而是**换装/转场的藏针处**——完全盖住主体的 1–3 帧就是 cut 藏在哪里。
- **分镜含义**：想做无缝变身/时间压缩 → 让前景物横扫，在它满盖那一瞬切镜。这是"前景遮挡延迟揭示"的变身版：reveal 的是新造型不是真相。判别见 §F1、卡片 §T1。

### M3 · 色温即世界坐标
颜色温度是"哪个世界/什么心境"的量化坐标，不是打光偏好。冷高级灰=杂志/权力/被同化；暖光=家/真实/本我。
- **分镜含义**：定一场戏的色温前先定"这是哪个世界"。见 §F2 + §T4。

### M4 · 高级感 = 极致去饱和 + 一点睛色
时尚高级感靠"减法"：整体去饱和到近黑白灰，只留一个有意义的单点色（cerulean 蓝绿、正红口红）。
- **分镜含义**：想要杂志质感 → 去饱和 -25~-35% + 保留唯一一抹高级色，别让画面多杂色。见 §T5 + §F3。

### M5 · 权力是空间语法不是音量
权力靠**机位高度 + 沉默 + 别人围着伺候**呈现——仰角仰望权威、仆从环绕递物、极低音量+停顿压人，越平淡越狠。
- **分镜含义**：拍 boss/等级差 → 低机位仰拍权力者 + 下属被略俯压 + 环绕递物，而不是让 ta 大喊。见 §T7 + §F4。

### M6 · 节奏本身就是压力
高压职场用快切奔走蒙太奇（1.5–3s/镜）+ 物理环境声顶满，剪辑速度即压力感——不靠 BGM、不靠慢推抒情。
- **分镜含义**：拍"被任务碾"→ 缩短镜头时长、叠加多任务动作、让高跟鞋/电梯叮/街声当鼓点。见 §T8 + §F5。

### M7 · 横向 = 进程 / 纵向 = 权力
运动与机位方向承载叙事向量：**横向移动=时间流逝/进程推进**（换装蒙太奇靠横向滑过），**仰角向上=仰望权力**（米兰达）。
- **分镜含义**：进度/蜕变用横向调度，权力/等级用垂直机位角度。见 §T1/T7。

### M8 · 干净光鲜是刻意的美学纪律
画面追求光鲜、干净、构图讲究（杂志质感）不是"缺乏个性"，而是与角色所处的高端时尚世界同构——它本身在表达"这个世界的诱惑"。
- **分镜含义**：时尚世界的戏用柔光打型、去噪、构图对称/居中权力位；生活戏才允许杂乱有痕迹的实景。见 §M3/M8 与 §T4 的双世界对位。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 前景遮挡换装 / 变身
- **H1** 要变身/造型升级/状态变化/时间压缩 → 前景遮挡换装：前景物横向掠过遮主体 40–70%、速度 0.8–1.5 屏宽/秒，在**完全盖住的 1–3 帧**切镜换装，滑开落幅停 0.5–1s 让观众读完新造型。
- **H2** 街景有车流/人流 → 用横向遮挡物滑过型（出租车/路人从一侧横驶横走）；无车流的室内/小空间 → 用自体横移过定点遮挡型（主体自己走过廊柱/门框，被完整挡住那 2–3 帧换装）。
- **H3** 前景物滑过速度控制 → 慢于 0.8 屏宽/秒会露馅看出换装、快于 2 屏宽/秒看不清是什么物；用 50–85mm 中焦压缩 + 前景物贴镜头制造大面积遮挡。
- **H4** 每个"挡→换→滑开"当**独立可复制单元**串成行走蒙太奇，落幅新造型一级比一级精致（造型弧线可视化）。

### B. 色温 / 双世界
- **H5** 杂志/办公/权力/时装秀世界 → 冷峻高级灰 5600–6500K + 去饱和 -25~-35% + 黑白灰底 + 暗部干净 ≤30%。
- **H6** 家/朋友/男友/真实生活 → 暖光 3000–3400K + 饱和正常 + 暖橙木质 + 实景杂乱有生活痕迹。
- **H7**（铁律）同一世界内**不可混色温**——杂志世界打暖光即破坏双色温签名（§F2）。
- **H8** 角色跨世界移动（如街冷→咖啡店略暖）→ 允许色温微过渡（3400K 店内 vs 6000K 街外）标出空间切换。

### C. 高级感 / 单点色
- **H9** 要时尚高级感 → 去饱和 -25~-35% 到近黑白灰 + 保留**唯一一抹单点高级色**（cerulean 蓝绿 #4A9BB0 / 正红口红），别铺多杂色（§F3）。
- **H10** 单点色要有意义 → 让它落在叙事关键物上（被拈起的毛衣、口红、一件外套），成为画面唯一色点承载信息。

### D. 权力调度
- **H11** 拍权力者/boss → 低机位仰角 15–25° 仰拍（ta 俯视镜头/俯视下属）+ 居画面中心或上 1/3 权力位。
- **H12** 拍被权力压制者 → 平视或略俯 5°（被压视角）+ 边缘位/孤立，反应用微表情承接。
- **H13** 强化权力 → 仆从环绕身侧后方**不断递物**（样书/咖啡/外套/夹板），权力者不接不看（甩到对方桌上/拿了就走）。
- **H14** 权力的羞辱 → 用克制分寸 30–50%（极低音量+停顿+不看人+像讲常识地碾压），越平淡越狠；**绝不**大喊大叫（70–95% = 沦为普通暴躁 boss）。

### E. 节奏 / 造型弧线 / 声音
- **H15** 拍高压任务流 → 快切奔走蒙太奇 1.5–3s/镜 + 手持微跟 micro-jitter 0.3° + 多任务动作叠加（电话夹肩+拎咖啡+推门）。
- **H16** 奔走/换装节拍 → 交给**物理环境声**（高跟鞋 click / 电梯叮 / 电话铃 / 街声 / 前景物滑过的"嗖"声）+ 前景滑过的物理节奏，**不交给 BGM**（生成模型 禁配乐）。
- **H17** 拍成长弧线 → 造型三段（土气宽松→精致剪裁→反思素净）作不用台词的进度条，看衣服就知道走到哪一步。
- **H18** 换装蒙太奇运镜 → 用 locked 固定（让前景物自己横扫）或横移 pan 跟随主体（廊柱相对掠过）；**不用**慢推长镜。
- **H20** 前景遮挡物景深 → f/2.8 浅景深让前景物虚化但可辨（路人/衣架虚但认得出），主体清晰——浅景深让前景滑过的接缝更柔顺。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 前景遮挡换装成立判别（变身单元）**
```
成立需同时满足：
① 前景物横向掠过遮主体 40–70%（<40% 无遮罩力 / >70% 但需在满盖帧完成切换）
② 滑过速度 0.8–1.5 屏宽/秒（慢=露馅 / 快=看不清是什么物）
③ 在前景物完全盖住主体的 1–3 帧藏 cut（换装藏针点，错位=穿帮跳变）
④ 滑开落幅新造型停 0.5–1s 让观众读完变身
缺任一 → 不是弗兰克尔式换装蒙太奇，退化成普通遮挡或硬切。
```

**F2 · 双色温世界判别（铁律）**
```
杂志/办公/权力/时装秀/被同化 → 冷峻高级灰 5600–6500K + 去饱和 -25~-35% + 暗部 ≤30%
家/朋友/男友/真实生活/本我     → 暖光 3000–3400K + 饱和正常 + 暖橙木质 + 实景杂乱
铁律：同一世界内不混色温；跨世界移动才允许微过渡（街冷 6000K → 店内 3400K）。
```

**F3 · 高级感单点色判别（时尚克制纪律）**
```
弗兰克尔杂志世界调色板 = 去饱和近黑白灰（-25~-35%）
一旦引入亮色 → 必须是唯一一抹有意义的单点高级色（cerulean #4A9BB0 / 正红口红），落在叙事关键物上
（满饱和 / 多杂色 = 破坏纪律，失去杂志高级感）
```

**F4 · 权力调度判别（三件套）**
```
弗兰克尔式权力镜需三件套齐全：
① 低机位仰角 15–25° 仰拍权力者（下属被平视/略俯 5° 压着）
② 沉默压制：极低音量 + 停顿 + 不看人（克制分寸 30–50%）
③ 仆从环绕身侧后方递物、权力者不接不看
只有仰角没有沉默+环绕 = 半套，压迫感不足；权力者大喊 = 破坏"克制权力"。
```

**F5 · 快切奔走节拍判别（节奏即压力）**
```
高压任务流蒙太奇：镜头时长 1.5–3s/镜 + 手持微跟 + 多任务动作叠加
节拍锚点 = 物理环境声（高跟鞋 click / 电梯叮 / 电话铃 / 街声）+ 前景滑过节奏
铁律：不交给 BGM（生成模型 禁配乐）；不用慢推长镜（破坏快节奏）。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 前景遮挡换装蒙太奇（库内首要价值）** ｜机制：前景物横扫遮住主体、满盖帧藏 cut 完成换装、滑开露新造型（=前景遮挡延迟揭示的变身版，reveal 新造型非真相）｜参数：前景物（路人/黄出租车/廊柱/门框/挂衣架/翻开杂志页）占 40–70%，横向 0.8–1.5 屏宽/秒，满盖 1–3 帧切镜，落幅新造型停 0.5–1s；50–85mm f/2.8–4｜触发：变身/造型升级/状态变化/时间流逝压缩｜意图：把"越来越精致+时间流逝"压成几秒的无缝变身｜正例：穿普拉达的女王 §场景 A（第五大道换装步行蒙太奇 · 镜 A-1 黄出租车横扫 / A-2 路人横扫 / A-3 廊柱自体横移 / A-4 挂衣架收尾落幅）。

**T2 · 横向遮挡物滑过型** ｜机制：外部前景物从一侧横驶/横走扫过主体｜参数：黄出租车右→左占 60% 1.2 屏宽/秒 / 路人左→右占 45% 1.0 屏宽/秒；固定 locked 机位让前景物自己横扫｜触发：街景有车流/人流的变身｜意图：无缝换装且"看得清是什么物"｜正例：穿普拉达的女王 §场景 A 镜 A-1/A-2。

**T3 · 自体横移过定点遮挡型** ｜机制：主体自己横移走过固定遮挡物、被完整挡住瞬间换装｜参数：主体横移 0.8 屏宽/秒，廊柱/门框占 35% 竖向，主体被挡 2–3 帧，从另一侧露出已换装；pan 跟随主体｜触发：无车流的室内/小空间变身｜意图：不需"物体来扫"也能造换装藏针点｜正例：穿普拉达的女王 §场景 A 镜 A-3（廊柱横移换风衣墨镜）。

**T4 · 双色温分两个世界** ｜机制：色温=哪个世界/什么心境的坐标｜参数：杂志/权力冷高级灰 5600–6500K 去饱和 -25~-35% 暗部 ≤30% ↔ 家/真实暖光 3000–3400K 饱和正常暖橙；同世界不混、跨世界微过渡｜触发：双世界对比/角色被环境改变｜意图：色温=内心拉扯的可视化｜正例：穿普拉达的女王（Runway 编辑部冷 vs 家/男友戏暖 · 场景 C 镜 C-3 街冷→店暖过渡）。

**T5 · 去饱和高级灰单点色** ｜机制：整体去饱和近黑白灰 + 唯一一抹高级色点｜参数：去饱和 -25~-35%，单点色（cerulean #4A9BB0 蓝绿 / 正红口红）为画面唯一色点，落在叙事关键物上｜触发：时尚/高级感/冷峻克制｜意图：高级感=极致减法 + 一点睛｜正例：穿普拉达的女王 §场景 B 镜 B-3（cerulean 毛衣是去饱和画面唯一色点）。

**T6 · 造型弧线三段进度条** ｜机制：造型作不用台词的成长进度条｜参数：土气（宽松不合身廉价+杂乱发+大背包）→ 精致（合身剪裁黑大衣+高跟+利落直发+名牌）→ 反思（素净知性+卸浮夸+自然质感）｜触发：成长弧线/蜕变/身份转变｜意图：看衣服就知道角色走到弧线哪一步｜正例：穿普拉达的女王（Andy 三段造型全片弧线）。

## 七、禁忌清单（❌ 弗兰克尔式分镜绝不做的事）

- ❌ **换装靠硬切黑场/叠化转场**——放弃前景遮挡这一天然遮罩，本片精髓是前景物当 wipe（§F1/T1）。
- ❌ **前景物滑过太慢（<0.8 屏宽/秒）或太快（>2 屏宽/秒）**——慢=露馅看出换装、快=看不清是什么物，失去"无缝又可读"（§F1/H3）。
- ❌ **遮挡瞬间没卡在前景全盖的 1–3 帧**——换装藏针点错位 = 穿帮跳变（§F1）。
- ❌ **杂志/办公/权力世界用暖光**——破坏冷峻高级灰 vs 暖光双色温铁律（§F2）。
- ❌ **画面满饱和或多杂色**——破坏去饱和高级灰 + 单点色的时尚克制（§F3）。
- ❌ **权力者用平视/俯拍/仰望 ta**——破坏低机位仰角权力调度（§F4）。
- ❌ **权力者大喊大叫怒吼（70–95%）**——破坏"克制权力"高级感，沦为普通暴躁 boss（§F4/T9）。
- ❌ **主角全片一种造型**——弃用造型作弧线可视化的进度条（§T6）。
- ❌ **任务奔走用慢推长镜**——破坏快节奏快切（§F5）。
- ❌ **把换装/奔走的节拍交给 BGM**——生成模型 禁配乐，节拍必须靠前景滑过节奏 + 高跟鞋/街声/电梯叮物理声扛（§F5/H16）。
