## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：诺兰的分镜系统 = **"用真实物理换沉浸可信度"** 的四台引擎。① **大画幅实拍引擎**：IMAX 15-perf 65mm（1.43:1 近正方）拍动作/沉浸、5-perf 65mm（2.20:1 消音机身）拍同期对白；镜头**只用 50mm+80mm 两支甜点**（球面 spherical 非 anamorphic·T2.0），超 80mm→"压扁成平屏图形"、低于 40mm→"鱼缸 fishbowl"[原话 van Hoytema]；**"是否有台词"= 选格式第一开关**（非美学·IMAX 机 >36kg 且吵会污染同期声·Nolan 拒 ADR）；显式写 in-camera/practical 压塑料感。② **多线时间引擎**：三线不同尺度（陆一周/海一天/空一小时）**映时压到等长、非等时长**，交汇靠"动作镜像+情绪等价"而非同一物理事件对齐（敦刻尔克式）；OR 多层同刻嵌套 + 因果同步（上层货车翻滚→下层走廊旋转·盗梦式），比例现实 5min=梦 1hr、每深一层脑速≈×20。③ **Shepard tone 引擎**：叠八度上行、高音淡出+低音淡入=永不解决的升调；三线速率 1:2:4 收束同帧；诺兰怀表采样作滴答脉冲。④ **空间物理引擎**：旋转走廊（相机刚性锁旋转布景 0.1 RPM·重力矢量转 360°）实拍失重；折叠城市"像盒盖合上"必配"四个太阳"多向补光防几何塌黑。分层调色靠色相辨层（暖橙 H25-35° 酒店 / 冷蓝 H200-220° 现实）。

**适用情境**：大画幅沉浸、战争/生存、高概念科幻、多线/多层时间结构、失重/折叠超现实空间、永不松懈的张力、实拍优先反 CG。**不适用/需改造**：手持纪实小成本（IMAX 重机身不适合极限机动·盗梦为此弃 IMAX）、暖调小清新、配乐煽情有明确旋律高潮（诺兰是永恒上升张力）、慢节奏静观（诺兰偏结构张力·非凝视）。

## 一、核心心智模型（8 个镜片 · How Nolan sees a scene）

### N1 · 甜点焦距（50mm & 80mm）
IMAX 大画幅**只用两支球面镜**。van Hoytema：`the sweet spots with IMAX are **50mm and 80mm**`[原话]；更长→画面 `compressed and more graphic`（压扁/图形化·丢沉浸）、更广→`fishbowl`（鱼缸畸变）[原话]。50mm≈标准/略广（环境+人）、80mm≈"人像头"（大特写）。
- **分镜含义**：IMAX 镜头段只在 50/80mm 二选一；超出即"沉浸感掉"，删。→ 见 §T1/T2。

### N2 · 台词是选格式第一开关
`if 镜头有同期对白 → 用 5-perf 65mm 安静机（2.20:1）；if 无对白/纯视觉冲击 → 用 IMAX 15-perf（1.43:1）`。原因[转述]：IMAX 机身 >80lb（≈36kg）且噪音大污染同期声，Nolan **拒做 ADR/后期配音**，对白戏必须让位安静机（1.43:1 IMAX 还有电磁干扰致无线跟焦失效→靠目测）[原话]。
- **分镜含义**：把"是否有台词"设为选画幅的第一逻辑开关，而非美学偏好。→ 见 §T3/F1。

### N3 · 交汇靠情绪等价，非物理对齐（敦刻尔克式）
诺兰**不做"同一客观事件多视角重放"**。`The cut between the yacht and the mole is smooth and immediate…despite occurring minutes and miles apart`[原话 birthmoviesdeath]——采用**情绪/主题并置**（平行生死抉择），`foregoing the very need for them to line-up exactly so long as the experience is emotionally sound`[原话]。正例：柯林斯下沉的喷火座舱 ↔ 士兵舱内争论是否弃船（两组"困在进水舱体的生死决定"对切）[原话]。
- **分镜含义**：三线交汇用"动作镜像 + 情绪等价"对切，非"对同一爆炸切三个机位"。→ 见 §T4/F2。

### N4 · 因果同步（盗梦式必须满足）
多层同刻嵌套时，上层物理量→下层同步反应：`Every time the van swerves…Arthur's actions are effected in the dream…when the van spins out of control down a mountain, the hallway scene starts to spin`[原话 filmutopia]。`IF 上层货车翻滚 → THEN 下层走廊旋转/无重力`。
- **分镜含义**：剪辑锚点 = 上层物理事件发生帧 = 下层反应启动帧（倾角/失重/落水/落雪逐层传导）。→ 见 §T5/F3。

### N5 · Shepard tone = 只增不减的张力
叠多条**相隔八度**的上行音阶，爬升时高音渐弱淡出 + 低音渐强淡入 → 听感永远上升却不出频段（螺旋/理发店转柱）[转述]。Nolan：`I wrote the script according to that principle…interwove the three timelines…continual feeling of intensity`[原话]——**剧本层就按升调写**，非仅配乐。三线速率 1:2:4（士兵 1× / 海上 2× / 飞行员 4×）同奏、同点收束高潮。
- **分镜含义**：要"张力只增不减无解决感"→ 铺 Shepard 上行 + 怀表滴答脉冲；要释放→才断开叠层。→ 见 §T9/F4。

### N6 · 相机=布景同参考系（旋转失重）
"人贴地走、世界绕人翻"→ **相机刚性锁在旋转布景上**，二者同步转，画面里演员相对地板不动而重力矢量连续改变（墙/天花板轮流成"地面"），演员靠钢丝维持相对布景静止[转述 fxguide]。参数：走廊 ~100ft、7-8 环每 16ft、**0.1 RPM（6 圈/分）可正反转**、两台电机[转述]。
- **分镜含义**：`要"人贴地·世界绕人翻"→ T1 相机=布景同参考系；要"人失重飘·世界不动"→ T2 竖立走廊+相机在底`。→ 见 §T6/F5。

### N7 · 折叠空间必配多向补光
街道沿铰链上翻`closes like the lid of a box`[原话]，几何一折**太阳被挡→整城入阴影**，故人造**"四个太阳"**从多方向多时刻补光[原话]，防折叠面塌成死黑。折叠后留小窗口露蓝色虚空[转述]。
- **分镜含义**：拍折叠/翻转空间，先问光——若一折就阴间死黑，就是漏了多向补光，照 T3 加 3-4 个方向光源。→ 见 §T7/F5。

### N8 · 实拍优先（观众能分辨真伪）
Nolan：`观众某种层面总能分辨动画 vs 被拍摄之物`[原话]；团队 `try to do everything without them(VFX)`[原话]。判别：`if 实拍成本 ≤ CG 且能一镜到底 → 实拍；if 只为"看着真" → 实拍优先`（Tenet 撞真波音 747 因比微缩+CG 更便宜·Interstellar 真种 500 英亩玉米卖粮回本）[转述]。
- **分镜含义**：prompt 显式写 `in-camera / practical / photographed, no CGI look` 压制塑料感；主体实拍、CG 只补缝（漂浮碎屑/换头）。→ 见 §T10。

## 二、决策启发式（20 条 if-then · 分 5 类）

### A. 大画幅格式 / 焦距（N1/N2）
- **H1** 要"极致清晰纵深"→ 球面镜 spherical + 大画幅 + 大量对焦深度；prompt 写 `edge-to-edge sharp, spherical, no anamorphic flare/distortion`。
- **H2** IMAX 拍特写 → 焦距用 **80mm**、**禁长焦**（背景压缩=错·大画幅浅景深但 1.43:1 高幅上下仍露天/海/沙可辨环境）。
- **H3** IMAX 拍环境+人 → **50mm**（≈标准/略广）；焦距 >80mm 或 <40mm 一律删（压扁 or 鱼缸）。
- **H4** 镜头**有同期对白** → 换 5-perf 65mm 安静机（2.20:1）、牺牲最高分辨率；**无对白/动作/空境/大远景** → 上 IMAX 15-perf（1.43:1）。
- **H5** 主观/危险机位 → probe/潜望镜（可 pan/tilt 棱镜）**硬挂载体**（战机/船·似 GoPro），非稳定器，**允许震动**。
- **H6** 夜戏/烛光/低照 → 用改口大光孔（Sphero 65 / System 65 做到 T1.4·原生约 T4），少补光；否则默认 T2.0。
- **H7** 输出格式对齐：动作/沉浸→近正方 1.43:1；对白→宽条 2.20:1；流媒体/普通厅→2.39:1（为 2.40 构图·外圈 protect）。

### B. 多线 / 多层时间结构（N3/N4）
- **H8** 判别问句：镜头 A 的事件会**物理改变**镜头 B 吗？**会**→盗梦式（因果同步·上层动作→下层反应）；**不会、只情绪共振**→敦刻尔克式（情绪并置）。
- **H9** 敦刻尔克式 → 三线不同尺度（周/日/时）**映时压到大致等长、非等时长**；交汇用"动作镜像+情绪等价"对切，**禁**"对同一物理事件切三机位"。
- **H10** 盗梦式 → 剪辑锚点 = 上层物理事件帧 = 下层反应启动帧；越深层给越长时长与越慢帧（比例 现实 5min=梦 1hr、每深一层脑速≈×20·城市 10s→酒店 3min→第三层 1hr）。
- **H11** 给观众"我在哪条线/哪一层"定位 → 每线/每层**锁一个色相**（靠颜色秒辨），另配独立环境声床（雨/酒店/风雪随剪辑切换）。
- **H12** 三线趋近终点/收束信号 → 色温从冷蓝 → **落日金/舱内火光**（`warmer tones emerge…golden hues of a setting sun or the glow of firelight inside a ship`[原话]）。
- **H13** 深层慢镜对应上层常速 → 下层用高速升格（[推断]120–1000fps 回放·官方未公布具体值），上层货车 1 秒翻滚 = 下层走廊数秒失重。

### C. Shepard tone / 张力节拍（N5）
- **H14** 要"张力只增不减、无解决感"→ 铺 Shepard 八度叠加上行 drone + 怀表滴答 metric pulse；要释放→才断开叠层。
- **H15** 多线剪辑节拍 → 三线速率比 **1:2:4**（长线慢铺、短线快切），剪到**同帧汇合**同一高潮 hit。
- **H16** 剧本/结构层就按升调写（非仅配乐后期）→ 交织三线制造 `continual feeling of intensity`。

### D. 空间物理（旋转/折叠·N6/N7/N8）
- **H17** 要"人贴地走、世界绕人翻"→ **T1**：相机刚性锁旋转布景（0.1 RPM 可正反转）、演员钢丝维持相对布景静止、Technocrane/内置 dolly 跟转；要"人失重飘、世界不动"→ **T2**：走廊竖立、相机置底垂直朝上、钢丝控下降速率（越慢越无重力）。
- **H18** 拍折叠/翻转空间 → **必加 3-4 个方向光源（"四个太阳"）**防几何折面塌黑；折叠后留小窗口露蓝虚空；先做 previs 定街道弧线、Nolan 拍板后用 previs 现场给演员 eyeline。
- **H19** 高潮/关键碰撞 → 真车真人真爆实拍（可信度来自物理）；CG 只补漂浮碎屑/换头（≤2 名特技换头）、主体全实拍；prompt 显式 `in-camera/practical, no CGI look`。
- **H20** 要大量手持机动 → **别上 IMAX 重机身**（盗梦因手持是核心而弃 IMAX·改 35mm anamorphic）；要大画幅沉浸史诗 → 上 IMAX（可首次大规模手持 IMAX·80+lb 贴身跟，如敦刻尔克滩头主观/船舱进水）。

## 三、判别公式（6 个 · 可测 · 当 要点）

**F1 · 格式 / 焦距选择（第一开关=台词）**
```
镜头有同期对白        → 5-perf 65mm 安静机 · 2.20:1 · 允许牺牲最高分辨率
无对白/动作/空境/大远景 → IMAX 15-perf 65mm · 1.43:1
IMAX 焦距 ∈ {50mm(环境+人), 80mm(人像特写)}  // 二选一·球面 spherical·T2.0
焦距 >80mm → 压扁"平屏图形" → 删
焦距 <40mm → "鱼缸 fishbowl" → 删
夜/低照 → 改口 T1.4 大光孔少补光
输出：动作 1.43 / 对白 2.20 / 普通厅 2.39
```

**F2 · 时间结构分型（敦刻尔克式 vs 盗梦式）**
```
问：镜头A事件会「物理改变」镜头B吗？
不会·只情绪共振 → 敦刻尔克式（情绪并置）：
    三线不同尺度(周/日/时) · 映时压到等长非等时长
    交汇 = 动作镜像 + 情绪等价对切（禁同一物理事件切三机位）
会·上层动作→下层反应 → 盗梦式（因果同步）：
    剪辑锚点 = 上层物理事件帧 = 下层反应启动帧
    越深层 → 越长时长 + 越慢帧（现实5min=梦1hr·每层脑速≈×20）
辨层/辨线：每层锁一色相 + 独立环境声
收束信号：色温 冷蓝 → 落日金/火光
```

**F3 · 因果同步锚点（盗梦式必满足）**
```
上层物理量(倾角/失重/落水/落雪) 变化帧 = T
下层反应(走廊旋转/漂浮/进水/积雪) 启动帧 必须 = T
if 货车离桥腾空 → then 同帧下层走廊失重/起旋(90°/s)
剪辑点 = 因果传导瞬间（非任意情绪点）
※ 缺同步 = 盗梦式失败（退化成纯并置）
```

**F4 · Shepard tone / 三线速率**
```
要「张力只增不减」→ 叠八度上行·高音淡出+低音淡入·永不解决 + 怀表滴答脉冲
要释放          → 断开叠层（才允许下降/解决）
三线速率比 = 1 : 2 : 4（慢线慢铺 / 快线快切）
三线起点不同 → 收束到「同一帧」高潮 hit
剧本层即按升调写（非仅配乐）
```

**F5 · 空间物理（旋转/折叠 参考系判别）**
```
「人贴地·世界绕人翻」→ 相机=布景同参考系(T1)：刚性锁旋转布景·0.1RPM·钢丝定姿
「人失重飘·世界不动」→ 竖立走廊+相机置底垂直朝上(T2)：钢丝控下降速率(越慢越失重)
折叠/翻转几何 → 必配多向补光(≥3-4方向"四个太阳")防塌黑 + 留窗口露蓝虚空
大量手持机动 → 禁 IMAX 重机身(改 35mm anamorphic)
```

**F6 · 实拍 vs CG（Nolan Cut Test）**
```
实拍成本 ≤ CG 且能一镜到底 → 实拍
只为「看着真」          → 实拍优先（观众总能分辨动画 vs 被拍摄之物）
CG 仅补：漂浮碎屑 / 换头(≤2 特技) / 几何接缝
prompt 显式：in-camera / practical / photographed, NO CGI look
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 优先引库内片正例）

**T1 · IMAX 格式声明（镜头表达 起手句）** ｜机制：15-perf 65mm 大画幅 + 球面镜 = 极致纵深清晰边到边｜参数：1.43:1(近正方竖高)·50mm(环境+人)·T2.0·Kodak Vision3 250D 日/500T 夜·全画面对焦·available light·手持轻微呼吸感｜触发：动作/沉浸/大远景无对白｜意图：观众"在现场"的临场真实｜正例：**敦刻尔克 §A-1 海滩长队大远景**（IMAX 广角·海天一线·人渺小）。

**T2 · 大画幅甜点特写（80mm）** ｜机制：IMAX"人像头"·浅景深但高幅上下仍露环境｜参数：80mm·T2.0·人脸占 40-60%·背景保留可辨环境·眼神对焦·**无变焦压缩感**·禁 >80mm｜触发：人物大特写/抉择时刻｜意图：贴脸沉浸而不平面化｜正例：**敦刻尔克 §B-3 油量见底的抉择**（座舱特写·极缓 push in·飞行员的脸+油量指针指零）。

## 七、禁忌清单（❌ 诺兰式分镜绝不做的事）

- ❌ **IMAX 段用非 50/80mm 焦距**——超 80mm 压成平屏图形、低于 40mm 鱼缸畸变，沉浸感掉（N1/H2/H3）。
- ❌ **对白戏硬上 1.43:1 IMAX**——机身吵污染同期声、Nolan 拒 ADR、无线跟焦还会失效（N2/H4）。
- ❌ **anamorphic 横向拉伸炫光**——与"球面镜纯净清晰"矛盾（H1）。
- ❌ **三线交汇对同一物理事件切三机位**——诺兰是情绪等价并置、非同一客观事件多视角重放（N3/H9）。
- ❌ **盗梦式跨层剪辑没有因果同步锚点**——上层不动下层瞎旋 = 退化成纯并置、失去"同时性高潮"（N4/F3）。
- ❌ **折叠/翻转空间不加多向补光**——几何一折就阴间死黑（N7/H18）。
- ❌ **大量手持机动却硬扛 IMAX 重机身**——盗梦为此弃 IMAX 改 35mm，别本末倒置（N6/H20）。
- ❌ **梦境/超现实拍成柔焦朦胧**——诺兰的梦是"另一套清晰锐利物理"，不柔焦（盗梦 §八）。
- ❌ **配乐给明确旋律高潮/煽情**——诺兰是 Shepard tone 永恒上升不到顶 + BRAAAM 低频/怀表滴答（N5/H14）。
- ❌ **该实拍的高潮塞纯 CG**——观众总能分辨动画 vs 被拍摄之物、可信度崩（N8/H19）。
- ❌ **暖调小清新**——诺兰整体去饱和冷峻（分层色也是冷调主色·敦刻尔克海天灰蓝 #5C7080）。
