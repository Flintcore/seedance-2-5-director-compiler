## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：宫崎骏×吉卜力的分镜系统 = **"让世界活着地呼吸，让镜头有失重的自由"**，五根支柱。① **留白"间"(ma) 引擎**（判别铁律）：奇观/动作之间必插 4-8s+ 安静长镜、留白 50%+（天/水/雾）、主体小而静、几乎无对白靠环境声——宫崎骏原话"ma = 拍手之间的空"；**关键时刻反而放慢**（≠急切快切）。② **活着的自然**：画面里**永远有一处自然在慢流动**（草浪 0.1-0.3 屏宽/s、云 0.05-0.1、水波、发/衣被风掀）；风是看不见的角色；静止呆板 = 违约。③ **飞行失重诗意**：横向掠过 + 衣发上扬 + 身体轻盈 + 云海下掠 + 悬停→滑翔；飞行是自由不是特技。④ **渺小者 vs 繁复奇观**：24-35mm + 人 ≤10% + 繁密奇观占 50-75% + 暖灯火 → "瑰丽可居住"非阴森吞噬。⑤ **温暖水彩自然色**：暖黄绿主调 + 高饱和低对比 + 漫射柔光无死黑 + 柔焦繁密边缘；禁 3D PBR 金属玻璃反射。母题→镜头：跨界=冷暗→暖亮过渡；治愈=食物冒热气油润暖光；反派非脸谱（善恶孪生）。共情平视 0° 视高贴近儿童身高。

**适用情境**：温暖奇幻异世界 / 自然治愈 / 成长勇气 / 飞行失重 / 静谧忧伤留白旅途 / 想象力具象化 / 食物烟火气 / 黄昏诗意。**不适用/需改造**：需要冷硬写实 PBR 质感、快节奏炫技快剪、脸谱化纯恶反派、阴森恐怖化、高对比死黑冷调、无对白留白撑不起的强情节段落。

## 一、核心心智模型（8 个镜片 · How Miyazaki sees a shot）

### M1 · 留白"间"(ma) 是主动设计，不是空白
情绪张力来自"什么都不发生"的呼吸段，而非塞满动作。宫崎骏原话："We have a word for that in Japanese. It's called **ma**. Emptiness… The time in between my clapping is ma. If you just have non-stop action with no breathing space, it's just busyness."（Roger Ebert 访谈·高）
- **分镜含义**：奇观/冲突之后**必须**排一个 4-8s+ 的静镜留白，让情绪沉淀——不是"没镜头可拍才留白"，是主动让观众喘息。→ 见 §T3 / §F1。

### M2 · 世界是活的，永远在呼吸
自然不是静止背景板；画面里总有一处在慢慢动（草/水/云/发/衣/招幡）。运动的"连续与慢"承载"世界活着"，不靠特效炸裂。
- **分镜含义**：任何一镜，先问"这一帧里什么在轻轻动"。没有 = 死画面。风是看不见的主角。→ 见 §T2 / §F2。

### M3 · 飞行 = 失重的自由，不是特技动作
腾空/滑翔时重点是**失重感**（衣发上扬、身体轻盈、悬停停顿、云海下掠），而非速度炫技或激烈机动。飞行是角色内心自由的外化。
- **分镜含义**：飞行镜先给"轻"再给"动"——先悬停/漂浮再滑翔，衣发反重力上扬，机位跟飞而非追拍。→ 见 §T4 / §F3。

### M4 · 摄影机贴儿童/共情视高，鲜有入侵
多用平视 0°、镜头高度贴近主角身高（儿童 1.0-1.3m），观众"和角色一起看"世界；奇观也是被温柔凝视的，不俯视审判、不入侵刺探。
- **分镜含义**：默认平视 + 低机位视高。仰望奇观（渺小者）/ 俯瞰大地（飞行）是例外的"敬畏"与"自由"语义，不是压迫。→ 见 §M6 / §T1。

### M5 · 奇观是"可居住的瑰丽"，不是吞噬的恐怖
异世界/巨物/神灵造型再奇诡，也包裹在暖灯火 + 饱和色 + 繁华烟火里，神秘瑰丽而非阴森。恐怖元素也裹在奇趣中。
- **分镜含义**：设计宏大 reveal 时定"瑰丽可居住"基调——暖灯火点缀繁复结构，而非冷调压迫。（与今敏"被卷入/吞噬"的奇观正交对立）→ 见 §T1 / §F5。

### M6 · 尺度对比即情绪（渺小 vs 庞大）
人渺小（≤10%）反衬奇观巨大（50-75%）= 闯入者的敬畏/渺小；飞行俯瞰大地 = 自由辽阔。尺度是情绪的量化坐标。
- **分镜含义**：想要"敬畏/闯入" → 缩小人放大奇观 + 仰望；想要"自由" → 人腾空俯瞰辽阔大地。→ 见 §T1 / §T4。

### M7 · 温暖水彩色 = 世界有温度的庇护
主调暖黄绿自然 + 高饱和低对比 + 漫射柔光无死黑 + 柔焦繁密边缘。色彩本身传递"世界繁密而可爱、治愈来自画满细节的温柔"。
- **分镜含义**：定场先定暖调基底（暖黄绿自然 / 暖红金灯火），高饱和但压低对比、暗部温润 35-45% 不死黑；禁 3D PBR 金属玻璃锐利反射。→ 见 §T6 / §F4。

### M8 · 反派非脸谱、恶里有温（善恶孪生）
反派不纯恶、奇诡角色有温情面（贪婪却护短、吞噬者被驯服后安静、善恶双生孪生）。复杂性靠表演分寸与镜头分配，不靠脸谱化打光。
- **分镜含义**：拍"反派"时保留温情镜/克制反应，别用纯恶的阴森打光把角色钉死。→ 见 §五表演分寸 / §七禁忌。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 留白"间" / 节奏
- **H1** 奇观/冲突之后 → 排一个 4-8s+ 安静长镜留白：locked-off 或极缓 0.1-0.2 屏宽/s + 留白 50%+（天/水/雾）+ 主体小而静 + 环境声为主无对白（§T3）。
- **H2** 关键情绪时刻（离别/顿悟/旅途悬停）→ **放慢而非快切**——反直觉地降速、留白、让观众呼吸（海上铁道为范本，§M1）。
- **H3** 想要"静谧忧伤/已离开尚未抵达"的悬停感 → 极缓 lateral tracking 0.1 屏宽/s + faceless 群像剪影 + 黄昏暖灰青 + 近乎无对白（§T3/T7）。

### B. 活着的自然 / 环境运动
- **H4** 任何一镜（哪怕主体静止）→ 加一层慢连续环境动效：草浪/树梢 0.1-0.3 屏宽/s、云 0.05-0.1、水波缓散、发/衣/招幡被风掀（§T2）。
- **H5** 要"世界活着在呼吸" → 让风成为看不见的角色：吹动草/发/衣/幡的方向一致、连续、缓（§M2）。
- **H6**（铁律）自然元素**绝不静止呆板**——静止 = 死画面，违背签名（§F2）。

### C. 飞行 / 失重
- **H7** 飞行镜 → 先给"轻"（悬停/漂浮/停顿）再给"动"（滑翔），衣发反重力上扬、身体轻盈、云海/大地在下方掠过（§T4）。
- **H8** 飞行运镜 → 跟飞（tracking with）或缓 crane，机位随体漂移，**不追拍炫速**（飞行是自由不是特技，§M3）。
- **H9** 要"自由辽阔" → 高空俯瞰大地/海/云海 + 人小 + 柔光暖天空；要"腾空升华"（如净化/复活）→ crane up + 轻微环绕（§T4/T5）。

### D. 尺度 / 奇观 reveal / 构图
- **H10** 异世界/巨物登场 reveal → 24-35mm 广角 + 人 ≤10% + 繁复奇观占 50-75% + 暖灯火点缀 + 繁密细节填满（§T1）。
- **H11** 要"闯入者的敬畏/渺小" → 渺小人物仰望庞大奇观（仰角或平视 + 人 ≤8%，§M6）。
- **H12** 奇观基调 → "瑰丽可居住"非阴森：暖灯火 + 饱和色 + 繁华，恐怖也裹在奇趣里（§F5）。
- **H13** 通道/入口/跨界 → 框中框（隧道/门/拱）+ 纵深汇聚线 + 尽头光团（§T1 变体）。

### E. 色彩 / 光 / 视高 / 母题
- **H14** 定场底色 → 暖黄绿自然 #7BA05B/#C9A86A + 柔蓝天 #A8C8D8 + 高饱和低对比 + 漫射柔光无死黑（暗部 35-45%）+ 柔焦繁密边缘；禁 PBR 金属玻璃反射（§T6/F4）。
- **H15** 跨界/阈限时刻（入隧道/异世界苏醒）→ 冷暗（4500-6500K 蓝紫）→ 暖亮（3000-3500K 红金）的光过渡（§T6/H13）。
- **H16** 治愈/人间烟火 → 暖红金灯火 #D4733A 笼罩 + 暖反光 + 暗部温润不死黑（§T6）。
- **H17** 食物镜 → 冒热气 + 油润高光 + 暖橙顶光 3200K + 蒸汽袅袅（食物 = 诱惑陷阱 / 治愈 双义，§T8）。
- **H18** 默认机位 → 平视 0° + 镜头高度贴主角身高（儿童 1.0-1.3m），共情不入侵（§M4）。
- **H19** 净化/色彩叙事 → 污浊暗褐 #4A3B2A ↔ 清亮水蓝白 #C8E0E8 的色彩反转承载"脏→净"（§T5）。
- **H20** 拍反派/奇诡角色 → 保留温情镜与克制反应，禁纯恶阴森打光钉死角色（§M8/§七）。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 留白"间"合格判别（ma 要点）**
```
一个镜头算"宫崎骏式留白"须同时满足：
① 时长 ≥ 4s（呼吸够长） + ② 机位 locked-off 或 ≤0.2 屏宽/s（极缓）
③ 留白 ≥ 50%（天/水/雾/远景占半幅） + ④ 主体小而静（≤30%，几不动）
⑤ 无对白 / 近乎无对白（靠环境声）
满足 ①②③④⑤ = ma；缺一项 = 只是慢镜，非留白。位置铁律：排在奇观/冲突之后。
```

**F2 · "世界活着"判别（环境恒动）**
```
逐镜设计判断：这一帧里"什么在轻轻动"？
草浪 0.1-0.3 屏宽/s / 云 0.05-0.1 / 水波缓散 / 发-衣-幡被风掀 / 光影浮动
→ 至少命中 1 项，且运动=慢+连续（非抖动非炸裂）
命中 0 项 = 死画面（违背签名）。主体可静，但环境必动。
```

**F3 · 飞行"失重 vs 动作"判别（两种腾空）**
```
要"失重的自由/诗意"（宫崎骏式）→ 先悬停/漂浮再滑翔 + 衣发反重力上扬 + 身体轻盈 + 云海/大地在下掠 + 跟飞漂移机位
要"激烈机动/追逐炫速"（非宫崎骏）→ 快速追拍 + 剧烈甩镜 + 速度线
铁律：宫崎骏飞行 = 轻 > 快，自由 > 特技。加速动作段也要有失重悬停的"呼吸拍"。
```

**F4 · 温暖水彩色纪律判别**
```
宫崎骏默认调色板 = 暖黄绿自然 + 高饱和 + 低对比 + 漫射柔光 + 暗部温润 35-45%（不死黑）+ 柔焦边缘
违约信号（任一出现即偏离签名）：
✗ 3D PBR 金属/玻璃锐利反射高光  ✗ 高对比死黑（暗部 <25%）
✗ 冷硬阴郁主调  ✗ 锐利景深刀切写实
```

**F5 · 奇观基调判别（可居住 vs 吞噬）**
```
宫崎骏奇观 = "瑰丽可居住"：暖灯火 + 饱和色 + 繁华烟火 + 神秘但不阴森（恐怖裹在奇趣里）
反例（今敏式吞噬 / 恐怖片式）：冷调压迫 + 阴森 + 渺小者被吞没的绝望
判别：reveal 里有没有"暖灯火 + 可栖居的生活痕迹"？有=宫崎骏；纯冷压迫=偏离。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 渺小者 × 繁复奇观 reveal** ｜机制：广角收纳庞大异世界，人渺小反衬｜参数：24-35mm f/8 深焦 + 极缓 lateral pan 0.12 屏宽/s + 人 ≤10% + 多层木结构/巨像占 50-75% + 暮色冷 vs 暖灯火 #D4733A 对比 + 繁密细节填满｜触发：异世界登场/瑰丽奇观揭示/跨界入口｜意图：闯入者的敬畏 + 想象力可被居住｜正例：千与千寻·神隐镇全景 reveal（§场景 A 镜 A-3，已在库）；天空之城·拉普达浮岛现身；幽灵公主·麒麟兽森林。（跨片：库内首见于千与千寻）

**T2 · 活着的自然环境动效** ｜机制：环境层持续慢连续运动，风为看不见角色｜参数：草浪/树梢 0.1-0.3 屏宽/s + 云 0.05-0.1 + 水波缓散 + 发-衣-幡被风掀；主体可静环境恒动｜触发：任意场景（默认叠加）/ 治愈/自然诗意｜意图：世界活着在呼吸、静中有动的生命力｜正例：龙猫·雨中巴士站草木摇曳、风掀伞与发；风之谷·腐海孢子飘浮；千与千寻·海上铁道水面微波（§场景 C）。

**T3 · 留白"间"安静呼吸长镜** ｜机制：奇观/冲突之后插静镜，让情绪沉淀｜参数：locked-off 或 ≤0.2 屏宽/s + 4-8s+ + 留白 ≥50%（天/水/雾）+ 主体小而静 + 环境声无对白｜触发：情绪沉淀/静谧忧伤/旅途悬停/顿悟之后｜意图："间"= 东方留白、给情绪的呼吸（宫崎骏原话 ma）｜正例：千与千寻·海上铁道静谧之旅（§场景 C 镜 C-1/C-2，全片留白巅峰，已在库）；起风了·草原静观。

**T4 · 飞行失重诗意** ｜机制：腾空滑翔重"轻"不重"快"，跟飞漂移｜参数：先悬停/漂浮再滑翔 + 衣发反重力上扬 + 身体轻盈 + 云海/大地在下掠 + tracking-with 或缓 crane（不追拍炫速）｜触发：飞行/腾空/自由/升华瞬间｜意图：飞行=内心自由的外化、失重诗意｜正例：天空之城·希达飞行石缓降悬浮、滑翔机穿云；魔女宅急便·琪琪骑帚穿城掠海；红猪·水上飞机；千与千寻·骑白龙俯冲（**注：库内唯一落地锚点为 §七"模板 8"句式模板，非逐镜 shot——飞行尚无 §场景逐镜文件，引用原文时以模板 8 为准并注明"模板级锚点"**）。⚠️ 2D 质感难复刻，落地取"造型概念 + 失重运动"。

**T5 · 腾空升华 + 色彩反转** ｜机制：净化/复活/升华瞬间用 crane up + 色彩反转｜参数：crane up 0.4 m/s + 轻微环绕 + 污浊暗褐 #4A3B2A → 清亮水蓝白 #C8E0E8 自体透光 + 暗部由深转浅｜触发：净化/重生/神显真身/污→净叙事｜意图：色彩本身叙事（脏→净）+ 壮丽升腾｜正例：千与千寻·河神现真身腾空（§场景 B 镜 B-3，已在库，含垃圾喷涌→水蓝白反转）。

**T6 · 温暖水彩自然底 + 跨界光过渡** ｜机制：暖调水彩基底 + 阈限时刻冷→暖光过渡｜参数：暖黄绿 #7BA05B/#C9A86A + 柔蓝天 #A8C8D8 + 高饱和低对比 + 漫射柔光无死黑（暗部 35-45%）+ 柔焦边缘；跨界=冷暗 4500-6500K 蓝紫 → 暖亮 3000-3500K 红金｜触发：定场底色 / 入隧道/异世界苏醒等跨界｜意图：世界有温度的庇护 + 阈限仪式感｜正例：千与千寻·穿隧道走向尽头光（§场景 A 镜 A-1，冷暗→暖亮，已在库）；龙猫·夏日田野暖绿。

**T8 · 食物质感诱人** ｜机制：食物冒热气油润，暖光承载诱惑/治愈双义｜参数：50mm f/2.8 近景 + 暖橙顶光 3200K 油润高光 + 蒸汽袅袅 + 暖灯火背景｜触发：食物镜（诱惑陷阱 / 治愈慰藉）｜意图：食物=诱惑（贪食变猪）与温暖（喂饭团）的双义载体｜正例：千与千寻·空街市满桌冒热气食物（§场景 A 镜 A-2，父母贪食，已在库）；哈尔的移动城堡·培根煎蛋早餐；崖上的波妞·火腿泡面。

## 七、禁忌清单（❌ 宫崎骏式分镜绝不做的事）

- ❌ **奇观/冲突之后不留白、一路塞满动作**——破坏 ma，只剩 busyness；关键时刻应放慢留白（§F1/M1）。
- ❌ **自然元素静止呆板**——风/水/云/草必须慢而连续地流动，静止 = 死画面（§F2/H6）。
- ❌ **把飞行拍成激烈追逐炫速**——宫崎骏飞行是失重的自由，先"轻"再"动"，不追拍炫技（§F3/M3）。
- ❌ **3D 写实 PBR 质感 / 金属玻璃锐利反射高光 / 锐利景深刀切**——破坏温暖柔焦水彩（§F4/M7）。
- ❌ **高对比死黑冷硬阴郁调**——应高饱和低对比、暗部温润 35-45% 不死黑（§F4）。
- ❌ **阴森恐怖化奇幻**——奇观应"瑰丽可居住"（暖灯火+饱和+繁华），恐怖也裹在奇趣里（§F5/M5）。
- ❌ **脸谱化纯恶反派 / 用阴森打光把角色钉死**——反派非脸谱、善恶孪生、恶里有温（§M8）。
- ❌ **食物画得寡淡无质感**——食物必须冒热气油润诱人（诱惑/治愈的情感载体）（§T8/H17）。
- ❌ **配乐塞满不留白呼吸**（AIGC 视频生成不写 BGM）——情绪靠自然环境声 + 静默承载（§M1）。
- ❌ **主角全程夸张卖萌 / 情绪无时不外放**——应真实生活化克制为底，情感关键处自然涌出随即回落（§五）。
