## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）


### 1. **温暖饱和水彩自然背景（Watercolor Nature · 男鹿和雄式繁密柔和）**【✅ 色调/构图可抄 · ⚠️ 纯手绘平涂质感难复刻】

- **物理参数**：主调**暖黄绿自然**——青翠草木 #7BA05B + 暖土黄 #C9A86A + 天空柔蓝 #A8C8D8 + 整体 +10~+20% 饱和但**柔和不刺眼**（高光不爆、暗部不死黑 35-45%）· 自然细节**繁密但柔焦边缘**（草叶/云絮/木纹层叠丰富，但轮廓柔和、非锐利写实）· **禁 3D PBR 金属/玻璃反射高光**、禁锐利景深刀切。
- **物理实现**：可生成方向——暖调水彩质感（painterly / soft-edged）+ 繁密自然前景中景背景分层 + 漫射柔光（无强硬阴影）+ 高饱和但低对比 · **难复刻的是 2D 平涂赛璐珞角色与水彩背景的"贴合"质感**（角色硬边平涂 ↔ 背景柔水彩的吉卜力分层），生成模型 写实视频只能取其色调与构图倾向。
- **情感意图**：自然是有温度的庇护 / 世界繁密而可爱 / 治愈感来自"画满细节的温柔"而非空旷。

### 2. **宏大奇幻异世界（Grand Fantasy World · 想象力具象化）**【✅ 构图/概念可抄】

- **物理参数**：异世界场景**纵向繁复 + 想象具象**——汤屋多层木结构（飞檐/红栏/层叠窗格/烟囱）占画面 60-75% + 八百万神灵造型各异（萝卜神/蛙人/鸟首）+ 尺度对比悬殊（人渺小 ≤10% ↔ 建筑/神灵巨大）· 神秘瑰丽**不阴森**（暖灯火 + 饱和色 + 繁华喧闹，恐怖元素也包裹在奇趣里）。
- **物理实现**：大远景/全景 + 24-35mm 收纳宏大建筑群 + 暖红金灯火 #D4733A 点缀繁复木结构 + 人物小尺度反衬奇观 + 繁密装饰细节填满画面。
- **情感意图**：异世界的瑰丽与神秘 / 想象力可被居住 / 渺小者闯入庞大未知。

### 3. **自然元素诗意流动（Poetic Nature Motion · 风/水/云/草）**【✅ 运动方向速度可抄】

- **物理参数**：自然元素**慢而连续地流动**——风掀草浪/树梢（横向 0.1-0.3 屏宽/秒，连续起伏）+ 水面波纹与流水（缓慢扩散/流淌）+ 云霞漂移（极缓 0.05-0.1 屏宽/秒）+ 雨丝斜落 · **绝不静止呆板**——画面里总有一处自然在轻轻动（草/水/云/发丝/衣摆）。
- **物理实现**：环境动效层——草浪/水波/云移/落叶的缓慢连续运动 + 主体可静止但环境恒动 + 风作为"看不见的角色"（吹动草/发/衣/招幡）。
- **情感意图**：世界是活的、在呼吸 / 自然的诗意 = 慢流动的连续感 / 静中有动的生命力。

### 4. **空气感与留白"间"ma（Negative Space & Breathing · 安静呼吸时刻）**【✅ 节奏可抄】

- **物理参数**：奇观/动作之间插入**安静呼吸长镜**——固定或极缓机位 4-8s+ + 画面留大量"空"（天空/水面/远景占 50%+）+ 主体小而静 + faceless 群像（神隐镇/铁道乘客作半透明剪影背景）+ 几乎无对白（靠环境声）· **关键时刻反而放慢、留白、让观众喘息**（海上铁道是巅峰）。
- **物理实现**：长镜（4-8s+）+ locked-off 或极缓 0.1-0.2 m/s + 大面积留白构图（天/水/雾占半幅）+ 环境声为主无对白 + 群像作静默剪影。
- **情感意图**："间"= 东方留白 / 给情绪沉淀的空间 / 静谧忧伤 / 旅途中"已离开尚未抵达"的悬停感。

### 5. **食物质感与暖光治愈（Food Texture & Warm Lamplight）**【✅ 可抄】

- **物理参数**：食物画得**冒热气、油亮、丰盛诱人**——包子/烤物/红豆汤特写时高光油润 + 暖橙打光 3000-3500K + 蒸汽袅袅上升 · 汤屋内部**暖红金灯火**笼罩（#D4733A 灯笼/烛火 + 暖反光 + 暗部温润不死黑）。
- **物理实现**：食物近景 + 暖橙顶光/侧光 + 蒸汽动效 + 油润高光 + 汤屋暖灯火弥漫（暖色温 3000-3500K + 灯笼光斑）。
- **情感意图**：食物=诱惑与温暖（父母因贪食变猪 ↔ 千寻被白龙喂饭团哭泣的治愈）/ 暖光=人间烟火的慰藉。

### 6. **奇诡角色设计 + 飞行失重（Uncanny Character Design & Weightless Flight）**【✅ 概念可抄 · ⚠️ 2D 角色质感难复刻】

- **物理参数**：角色造型**奇诡而有分寸**——无脸男（半透明黑影身 + 白色能剧面具 + 无表情吞噬）/ 汤婆婆与钱婆婆（巨大头部 + 华服 · 孪生善恶两面）/ 锅炉爷爷釜爷（伸缩六长臂 + 蛛形）/ 坊宝宝（巨婴）· **飞行失重**：白龙（蜿蜒白色龙身腾空 + 失重漂浮）/ 千寻骑龙俯冲 · 飞行时**失重感**（衣发上扬、身体轻盈、云海下方掠过）。
- **物理实现**：角色设计概念可抄（半透明面具影身/巨头/多臂/龙形），但**2D 平涂赛璐珞角色质感 生成模型 难直接生成**——落地时取"造型概念 + 失重运动"（腾空 + 衣发上扬 + 云海掠过 + 漂浮悬停）。
- **情感意图**：奇幻角色的诡奇与温情并存 / 飞行=自由与失重诗意 / 反派也非纯恶（汤婆婆贪婪却护短）。

## 三、镜头语法 DNA（What makes Miyazaki's "Spirited Away" work）

**可量化技法规律 · 每条含具体物理参数 + 适用条件**：

1. **温暖水彩自然底色（柔和繁密 · 非写实 PBR）**：主调暖黄绿 #7BA05B/#C9A86A + 柔蓝天 #A8C8D8 + 高饱和低对比 + 漫射柔光（无强硬阴影）+ 繁密但柔焦边缘的自然细节 · **绝不锐利写实/金属玻璃反射** · 适用：自然/治愈/奇幻场景的色彩与质感基底（色彩心理学 + 景深的柔焦倾向）

2. **宏大奇幻 reveal = 渺小者 + 繁复奇观 + 暖灯火**：24-35mm 广角 + 人占 ≤10% + 多层木结构/神灵巨像占 50-75% + 暮色冷 vs 暖灯火对比 + 繁密细节填满 · 适用：异世界登场/瑰丽奇观揭示（与今敏游行洪流的"吞噬"相反——宫崎骏奇观是"瑰丽可居住"）

3. **自然元素恒动（风/水/云/草慢而连续）**：画面里总有一处自然在轻动——草浪/树梢 0.1-0.3 屏宽/秒、云霞 0.05-0.1、水波缓散、发丝衣摆被风掀 · **绝不全静止呆板** · 适用：让世界"活着、在呼吸"的生命力（风是看不见的角色）

4. **留白"间"ma = 安静呼吸长镜（关键时刻反而放慢）**：奇观/冲突之间插 4-8s+ 长镜 + 留白 50%+（天/水/雾）+ 主体小而静 + faceless 群像剪影 + 几乎无对白靠环境声 · 适用：情绪沉淀/静谧忧伤/旅途悬停 · **海上铁道是巅峰 = 全片最安静却最动人**（节奏 + 留白哲学：S 级不是每镜满，是张弛有度）

5. **冷暖光对比承载跨界与情绪**：冷暗（隧道/暮色/夜 4500-6500K 蓝紫）vs 暖灯火（汤屋/食物/窗灯 3000-3500K 红金）· 跨界（入隧道/异世界苏醒）= 冷→暖过渡 · 治愈/人间烟火 = 暖灯火笼罩 · 适用：阈限时刻 + 温暖时刻的光语义

6. **食物诱人质感（冒热气油润暖光）**：食物近景 + 暖橙顶光 3200K 油润高光 + 蒸汽袅袅 · 食物 = 诱惑（变猪）/ 治愈（饭团）双义 · 适用：需要"可口/温暖/烟火气"或"贪欲陷阱"的食物镜

7. **奇诡角色设计 + 失重飞行（造型概念可抄·2D 质感难复刻）**：半透明面具影身/巨头孪生/多臂蛛形/龙状水形 + 飞行时失重（衣发上扬/身体轻盈/云海掠过/漂浮悬停）· 适用：奇幻角色/腾空诗意 · ⚠️ 落地取造型概念 + 运动，**不强求 2D 平涂质感**

8. **反派非脸谱（善恶孪生 · 温情留白）**：汤婆婆贪婪却护短、钱婆婆是其温柔孪生、无脸男从吞噬到被驯服安静——**绝不纯恶纯善** · 适用：反派/复杂角色的分寸（恶里有温、奇诡里有怜）

## 四、声音/音乐设计 DNA

> ⚠️ **生成模型 禁配乐**：久石让配乐（《那一年的夏天》主题、海上铁道《第六站 The Sixth Station》）虽是本片灵魂，**但绝不把 BGM 写进 镜头表达**。情绪靠**自然环境声 + 留白静默**承载。
