> **用途**：生成模型「分镜设计」知识库顶层调用文件。调用语法示例：`[大师参照：杨德昌方法论总纲.md §T2 玻璃倒影叠画 + masters/yang-dechang/一一.md §场景 C]`

## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：杨德昌的分镜系统 = **"用建筑几何 + 理性距离把都市现代性的疏离外化成可测的构图"**，五根支柱。① **理性静观机位**（判别铁律）：三脚架锁定、中远景/全景为主、深焦、距主体 3–8m、极少特写、单镜超长、几乎不推拉——让观众在固定框里自己扫描、决定看什么（active viewing）。② **玻璃反射叠画**：人物站玻璃幕墙/落地窗/车窗前，城市街景/霓虹倒影叠合在人身上不擦除——"内景人 + 外景倒影同框"，人既在场又被城市穿透。③ **建筑几何框架**：门框/窗棂/隔断/柱/立交桥的水平垂直硬线条二次切割画面，把人物关进格子——都市即几何牢笼。④ **多线群像并置**：三代人/多角色平行编织，交叉剪辑，无单一主角，用结构而非戏剧冲突推进。⑤ **克制理性文戏**：长对话承载哲思，表演克制 25–45%，停顿多于宣泄，不外放。母题→镜头：疏离→玻璃反射叠画；渺小→大远景高楼吞没人物；真相之背面→拍后脑勺/倒影。方法：让摄影机当"审视者"而非"共情者"，让戏发生在纵深与画外。

**适用情境**：现代都市剧情/群像、都市疏离孤独、理性知性文戏、多线叙事、玻璃倒影美学、中产家庭、城市异化。**不适用/需改造**：需强特写煽情、手持贴身能量、快剪动作、情绪化配乐渲染、单一英雄戏剧冲突的题材（皆与其理性静观签名互斥）。

## 一、核心心智模型（8 个镜片 · How Yang sees a shot）

### M1 · 摄影机是审视者，不是共情者
先定"这场戏从多远、什么角度被冷静观察"，再放人；情绪由**距离/景框/建筑**承载，不靠特写挤情绪。Yang 惯于把机器架三脚架上、让故事自己讲（Notes on Film / Senses of Cinema · 高）。
- **分镜含义**：先问"这场戏该被审视到多冷"，默认中远景固定、拒推近煽情。→ 见 §T1/§F1。

### M2 · 观众是主动扫描者（信息藏在纵深与画外）
固定长镜内同时发生多件小事，"主事件"框在长镜里，观众自己扫描、自己决定看哪——active viewing（IU Establishing Shot · 高）。
- **分镜含义**：一个镜头里布置多层可读事件（前景/中景/画外声），不靠剪辑指定焦点。见 §T4/§M6。

### M3 · 建筑几何即心理牢笼
门框、窗棂、玻璃幕墙、柱、隔断、立交桥的水平垂直硬线条把人物切割、关进格子——都市结构本身承载异化。Taipei Story 用墙/门/镜/柱/窗框/玻璃/打击笼网构图（Academia 分析 · 高）。
- **分镜含义**：想表达都市异化/被结构压 → 用建筑线条二次切割画面、把人放进"格子"。见 §T3/§T5。

### M4 · 玻璃是"两个世界的叠合面"
玻璃窗被打光成"一块玻璃上同时看见内与外、前与后"——人物 + 城市倒影同框（A Rabbit's Foot / wolfcrow · 高）。反射不是穿帮，是主题。
- **分镜含义**：要"人在都市既在场又被穿透"→ 拍玻璃前的人、保留倒影叠层，不擦除。见 §T2/§F2。

### M5 · 人在城市里是"渺小的一部分"
宽镜 + 纵深把人物缩成庞大垂直都市里的小剪影，个体被城市规模吞没（Terrorizers / Yi Yi 分析 · 高）。
- **分镜含义**：要渺小/异化 → 大远景 + 高楼/车流填满画面 + 人占比极小。见 §T6/§F3。

### M6 · 结构叙事：并置而非冲突
多线群像平行编织、交叉剪辑，用"人生各阶段同时上演"的结构对位推进，而非单一主角的戏剧冲突。
- **分镜含义**：多角色戏 → 用交叉剪辑并置对照（同题不同龄/不同处境），拒集中于一个英雄。见 §T7。

### M7 · 真相只有一半（背面母题）
"人只能看见前面，看不见自己的后脑勺"——用拍后脑勺、拍倒影把"看不见的另一半真相"视觉化（STRAND Magazine 访谈转述 / 洋洋角色片中台词 · 高）。
- **分镜含义**：要哲思"被遮蔽的真相/另一面"→ 拍背影/后脑勺/镜像/倒影，而非正脸。见 §T8。

### M8 · 时间在固定框里自己流逝
不靠剪辑压缩时间；固定长镜让时间在同一画框内流走（人走出框、光线渐变、车流自己流动）——"让时间在场"（Yi Yi 长镜观察 · 工程化提法，非导演原话 · 中）。
- **分镜含义**：要时间感/生活流 → 锁定机位、让动作走完 / 让人走出框 / 让光渐变，不切。见 §T1/§F1。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 机位态度 / 距离（理性静观）
- **H1** 拍任何文戏/日常戏（默认）→ 三脚架锁定 + 中远景/全景 + 深焦 + 距主体 3–8m + 单镜超长（40–90s），拒推近特写。
- **H2** 想煽情/给情绪特写的冲动出现时 → **反向退远**，把情绪交给距离与画外声（§F1 铁律）。
- **H3** 需要运动 → 用极缓横移/固定让人物在框内运动，**不用**手持晃动、不用快速推拉（破坏理性签名）。

### B. 玻璃 / 反射叠画
- **H4** 要"人在都市既在场又被穿透"→ 拍玻璃幕墙/落地窗/车窗前的人，城市街景/霓虹倒影叠合全身，**不擦除倒影**。
- **H5** 要"一块玻璃看见内外前后"→ 打光平衡内景与外景反射，使二者在同一玻璃面共存（Yi Yi 窗镜法）。
- **H6** 要人际疏离 → 透过玻璃门/窗/隔断拍另一人（隔玻璃的"看"），玻璃既连接又隔离。

### C. 建筑几何 / 框架
- **H7** 要都市异化/被结构压 → 用门框/窗棂/柱/隔断的水平垂直线条二次切割画面（框中框），把人放进"格子"。
- **H8** 要渺小/被城市吞没 → 大远景 + 高楼/玻璃幕墙/车流填满画面，人占比 <1/6。
- **H9** 要冷硬现代性 → 选现成都市建筑几何（办公格子间/电梯/立交桥），保持水平垂直硬线、避免斜构图动感。

### D. 色彩 / 光影
- **H10** 都市外景/办公 → 冷青灰主调（约 #4A5A6A 区间）+ 低对比 + 均匀光，理性冷静，不打戏剧硬光。
- **H11** 家庭内景 → 暖钨丝点缀（暖窗/台灯）对位窗外冷都市 = 家的微温 vs 城市的冷。
- **H12** 夜景 → 城市霓虹/车灯当环境色块自然入画，**不**主动加彩色戏剧光；保持写实低饱和。

### E. 结构 / 表演 / 声音
- **H13** 多角色戏 → 交叉剪辑并置不同人生线（同题材不同龄/处境对照），拒单一主角冲突。
- **H14** 文戏对白 → 演员克制 25–45%、理性平静、停顿多于宣泄；情绪藏在苦笑与沉默里，不歇斯底里。
- **H15** 独处/疏离场景 → 城市环境声床（车流/空调/电梯低鸣）+ 静默，钢琴克制、仅情感处轻进，**不**煽情配乐。
- **H16** 拍"另一半真相/被遮蔽"→ 拍背影/后脑勺/镜像/倒影，而非正脸特写（§T8）。
- **H17** 要时间流逝/生活流 → 锁定机位让动作走完、人走出框、光线渐变，**不切**（§M8）。
- **H18** 群像开场 → 用日常聚合场景（婚礼/家宴/群像）作反 hook 的日常 hook，多人同框各行其是。
- **H19** 转场 → 用不同人生线的交叉剪辑作"结构对位"转场，而非情绪匹配剪。
- **H20** 需要留白 → 人出画后让空镜（空间/城市/倒影）滞留数拍，让观众在空框里回味。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 理性静观判别（是不是杨德昌式机位）**
```
是杨德昌式  ⇔ 三脚架锁定 + 中远景/全景 + 深焦 + 距 3–8m + 单镜 ≥40s + 极少/无推拉 + 极少特写
任一违反（手持晃 / 频繁特写 / 快速推拉 / 短镜快剪）→ 已偏离签名
判据口诀：能不能把特写退成中远景？能退就退。
```

**F2 · 玻璃反射叠画判别（是不是"叠合面"而非穿帮）**
```
合格叠画 ⇔ 内景人物 + 外景城市倒影 同框可辨 + 倒影未被擦除 + 两个空间语义共存
不合格   ⇔ 倒影只是杂光 / 遮住主体不可辨 / 为干净而消倒影
目的：人既在场（实体）又被城市穿透（倒影）——二义必须同时读出。
```

**F3 · 渺小化判别（人 vs 城市占比）**
```
人占画面 > 1/3   → 不够渺小（偏人物剧）
人占 1/6–1/3     → 都市中的个体（推荐区间）
人占 < 1/6 或无人 → 城市吞没个体 / 纯几何（渺小顶点）
需配：高楼/玻璃幕墙/车流/几何线条填满其余画面。
```

**F4 · 框中框几何判别（建筑切割强度）**
```
无框            → 纯长镜（可，但少了牢笼感）
单层门/窗框     → 隔离/框住（推荐）
多层框 + 硬线切割 → 强都市牢笼 / 被结构压
线条须水平垂直硬线（避免斜线动感），人被"关"在格内。
```

**F5 · 理性 vs 煽情判别（表演与镜头合规）**
```
杨德昌式 ⇔ 表演克制 25–45% + 中远景 + 无情绪特写 + 无煽情配乐 + 停顿多于宣泄
一旦出现：大特写挤泪 / 弦乐煽情 / 演员外放歇斯底里 / 快剪推情绪 → 破坏签名
情绪应"欠"不应"溢"：把强度收在苦笑、沉默、背影里。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 固定超长镜理性旁观** ｜机制：三脚架锁定 + 长时不切，让时间/动作在同一框内走完｜参数：中远景/全景，深焦(f4–f8)，35–50mm，距 3–8m，单镜 40–90s，极少/无推拉，极少特写｜触发：文戏/日常/生活流/时间流逝｜意图：理性冷静旁观、观众主动扫描、时间在场｜正例：一一（`masters/yang-dechang/一一.md` §场景 A 餐厅对坐 80s）、恐怖分子（长镜框住格子空间·库外参照）。

**T2 · 玻璃反射叠画（城市倒影叠人）** ｜机制：拍玻璃幕墙/落地窗/车窗前的人，城市街景霓虹倒影叠合、内外同框｜参数：人物贴玻璃或站窗前，打光平衡内外使倒影可辨，倒影不擦除，中远景固定｜触发：都市疏离/现代性孤独/人被城市穿透｜意图：人既在场又被城市穿透、两个世界同框｜正例：一一（§场景 A-3 窗边独白·霓虹倒影叠满全身 / §场景 C-1 玻璃幕墙城市灯火叠满画面）。

**T3 · 建筑框中框囚笼** ｜机制：用门框/窗棂/柱/隔断的硬线条二次切割画面，把人关进格子｜参数：门窗框占边缘、主体居中缝隙，水平垂直硬线，深焦，固定｜触发：都市异化/被结构压/人际隔离｜意图：都市几何=心理牢笼｜正例：青梅竹马 Taipei Story（墙/门/镜/柱/窗框/打击笼网构图·库外参照）、一一（§B-4 教室窗格）。

**T4 · 深焦多层可读长镜** ｜机制：一个固定长镜内前中后景同时发生多件小事，观众自扫描｜参数：深焦(f5.6–f11)，广/中焦，多平面调度，无剪辑指定焦点｜触发：群像日常/生活流/信息密度｜意图：active viewing、生活的同时性｜正例：一一（家宴/群像场景）、恐怖分子（多线并置·库外参照）。

**T5 · 都市几何硬线构图** ｜机制：以现成都市建筑的水平垂直硬线组织画面｜参数：办公格子间/玻璃幕墙/电梯/立交桥，水平垂直线主导，避斜构图，冷青灰调｜触发：冷硬现代性/秩序感的压抑｜意图：都市是冷硬结构，人被规训在线条里｜正例：恐怖分子（垂直都市 serried 楼群·库外参照）、一一（§C-2 立交桥车流几何）。

**T6 · 大远景渺小化** ｜机制：宽镜 + 纵深把人缩成庞大都市里的小剪影｜参数：大远景，广角(24–35mm)，高楼/车流填满画面，人占比 <1/6 或无人，固定俯/平｜触发：个体被城市吞没/异化顶点｜意图：人是庞大都市机器里渺小的一部分｜正例：一一（§C-2 立交桥车流如河人渺小）、恐怖分子（城市俯瞰·库外参照）。

**T7 · 多线群像交叉并置** ｜机制：多角色人生线平行编织、交叉剪辑对照｜参数：无单一主角，同题材不同龄/处境对位剪辑，各线独立节奏｜触发：家庭群像/世代对照/结构叙事｜意图：人生各阶段同时上演、结构而非冲突推进｜正例：一一（NJ 中年 / 婷婷少女 / 洋洋孩童 / 外婆衰老四线）、牯岭街（群像·库外参照）。

**T8 · 背面/倒影母题（另一半真相）** ｜机制：拍后脑勺/背影/镜像/水与玻璃倒影，把"看不见的一半"视觉化｜参数：拍主体背面或其倒影，中景固定，自然光｜触发：哲思"被遮蔽的真相/另一面"｜意图：人只能看见一半真相｜正例：一一（§B-1 洋洋拍大人后脑勺 / §B-2 后脑勺照片 / §B-3 水洼倒影）。

**T9 · 隔玻璃的"看"（人际疏离）** ｜机制：透过玻璃门/窗/隔断拍另一人，玻璃既连接又隔离｜参数：人物间置玻璃介质，透过它构图，玻璃带反光叠层，中景固定｜触发：家人/爱人间的隐性疏离｜意图：人与人隔着看不见的玻璃、看得见触不到｜正例：一一（§A-2 隔餐厅玻璃看二人 / §C-3 隔玻璃门看家人）。

**T10 · 冷暖都市色对位** ｜机制：窗外冷青都市 vs 室内暖钨丝家温｜参数：外景冷青灰(约 #4A5A6A 区间)+低对比均匀光；内景暖钨丝(约 3000–3200K)点缀；夜用霓虹/车灯写实入画不加戏剧光｜触发：城市的冷 vs 家的微温对照｜意图：冷都市中被珍视的一点人间暖｜正例：一一（§A-1 室内暖钨丝 + 窗外冷青 / §C-3 屋内暖 + 门玻璃反外景冷）。
