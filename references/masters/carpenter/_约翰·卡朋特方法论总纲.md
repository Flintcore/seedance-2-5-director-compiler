## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：Carpenter 的分镜系统 = **"把恐惧预置进空旷的宽银幕，让威胁在画面里先于事件到场"**，五根支柱。① **空旷 2.35:1 = 恐惧容器**：Panavision anamorphic 宽银幕留大片负空间，威胁被留在**画框一侧的暗部/景深处**，观众自己发现它（≠ jump scare 先行）。② **缓慢横移+固定长凝视**：locked-off 长镜或 0.3–1°/s 极慢横摇/横移扫过空间，节奏靠"等待"而非剪辑（The Thing 例外走短切失控）。③ **前景暗部藏物**：主体处画框中景实焦，前景/背景暗部占 ≥60% 留出"东西可以在那里"的位置——威胁常无预警滑入构图边缘（Halloween Myers 空景滑入）。④ **synth 配乐驱动节奏**：Carpenter 自作极简合成器循环（Halloween 5/4 钢琴动机 / The Fog / Assault）先定 BPM 与紧张曲线，画面剪辑跟音走——声音先行。⑤ **实用光/低照度**：光源在画内（南瓜灯/车灯/日光灯/雾中路灯），暗部 ≥60%、宽比例硬边阴影，人物半身没入黑。母题→镜头：不可见的威胁→空景滞留 + 边缘滑入；幽闭偏执→单一空间困死 + 长焦压缩人群互疑。

**适用情境**：慢烧恐怖/惊悚、slasher、幽闭围城、末日孤立、超自然入侵、80s 科幻反乌托邦、B 级类型片工业美学。**不适用/需改造**：需要密集剪辑动作可读性的现代动作（Carpenter 靠空旷与等待）、高调明亮均匀布光、多机位覆盖式电视剧节奏、CGI 奇观（Carpenter=实用光/实体）。

## 一、核心心智模型（8 个镜片 · How Carpenter sees a shot）

### M1 · 恐惧先于事件（Fear before the event）
恐惧不是靠怪物出现制造的，是靠"观众知道有东西、还没看见"的**空旷预置**制造的。Carpenter 反复自述：让观众在任何事发生前就害怕。
- **分镜含义**：先设计"威胁尚未到场的空景"这一拍——留足负空间与暗部，让观众的目光自己在画框里搜寻。→ 见 §T1/T3。

### M2 · 画框是"东西可以藏进来的空间"（The frame as a hiding place）
2.35:1 宽银幕不是为了壮阔，是为了在主体旁边留出一大块"可以有东西"的横向空区。
- **分镜含义**：构图时先问"威胁将从画框哪一侧/哪个景深进来"，把那一侧留空留暗。→ 见 §T2/T3 + §F1。

### M3 · 摄影机是耐心的旁观者（The patient camera）
默认 locked-off 长凝视或极慢横移，不追、不切、不解释——让威胁在观众注视下自己出现或消失。
- **分镜含义**：默认静止或 0.3–1°/s 慢移；剪辑克制。躁动短切是**特例**（The Thing 怪兽爆发段），不是基调。判别见 §F5。

### M4 · synth 是节奏发生器，不是背景（Score as the metronome）
Carpenter 自作合成器循环先于剪辑存在——极简动机（常 2–4 音符 / 非常规拍号）设定 BPM 与紧张斜率，画面跟着音走。
- **分镜含义**：先定 synth 循环的 BPM/拍号，再据此定镜头时长与切点密度。声音先行。→ 见 §H16 + §八「声音先行」。

### M5 · 实用光即真实即恐惧（Practical, motivated, low-key light）
光要有画内来源（南瓜灯、车前灯、日光灯管、雾中路灯、火焰），且低照度、大面积暗部——黑暗本身是藏匿处。
- **分镜含义**：定光先定"画面里的光源是什么"，再压暗部到 ≥60%，让人物半身没入黑。→ 见 §T6/T7 + §F3。

### M6 · 幽闭偏执（One space, no exit, everyone a suspect）
把角色困在单一封闭空间（科考站/警局/教堂/小镇/飞船），威胁可能是同伴——用构图把人物互相隔开、用长焦压缩把群体压成互疑的一团。
- **分镜含义**：围城戏用同一空间反复调度 + 长焦压缩 + 人物之间留隔离线（门框/桌/暗部分割）。→ 见 §T5 + §F4。

### M7 · 冷底 + 单点暖爆（Cold base, single warm punch）
基调压成冷调（蓝青/无色/雾白），把暖色（火焰/血浆/南瓜灯/爆炸）留成稀有的单点爆发 = 颜色即事件。
- **分镜含义**：默认冷，暖色一出即"有事发生"，不铺暖。→ 见 §M7 + §八「色彩心理学」。

### M8 · 反英雄式不解决（The unresolved / anti-catharsis ending frame）
结尾常拒绝闭合——威胁未消、真相未揭（谁是怪物 / Michael 消失 / 世界已沦陷），末镜留一个"空/静/未定"的画面。
- **分镜含义**：末镜设计成开放的空景或两人对峙不揭底，避免情绪释放大特写。→ 见 §T10 + §八「跨镜头情感弧线/场景过渡」。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 空旷预置 / 负空间
- **H1** 要"恐惧先于事件"（威胁尚未出现）→ locked-off 2.35:1 宽镜，主体偏画框一侧，另一侧留大片负空间 + 暗部，滞留 4–8s 让观众自己搜索（§T1）。
- **H2** 要威胁"到场感" → 让它**无预警滑入画框边缘/从景深暗处显形**，不给切镜提示、不给音效前置（Halloween 空景滑入）（§T3）。
- **H3** 空景不够慌 → 加极慢横摇/横移 0.3–1°/s 扫过空区（像在替观众找威胁），或前景过一个暗部遮挡物（§T2）。

### B. 运镜 / 节奏（默认耐心 · 特例失控）
- **H4** 基调段 → locked-off 长凝视或缓慢横移，剪辑克制、长镜时长 5–10s+，节奏靠等待（§M3）。
- **H5** 威胁爆发/怪兽实体段（仅此特例）→ locked-off → 突然 handheld 1.0–1.5°/s + 冲近 0.3–0.5m + 短切 1–3s/镜（The Thing 派 · §F5）。
- **H6** 要"跟踪/被跟踪"主观感 → 缓慢推进或 Steadicam 低速平移代入 stalker POV，保持匀速不急（Halloween 开场主观长镜）（§T4）。

### C. 前景暗部藏物 / 构图
- **H7** 要"东西可能在那里" → 前景或背景暗部占 ≥60%，主体半身没入黑，留出可容纳威胁的暗区（§T3/F1）。
- **H8** 要"它已经在画里而你没注意" → 威胁静立于背景暗部/失焦处、与主体同框但不被主体察觉，延迟观众发现（§T3）。
- **H9** 要幽闭困死 → 用门框/走廊/铁栏/舷窗做框中框，把角色关在内框（§T5/怪形笼栏）。
- **H10** 要群体互疑 → 长焦压缩把多人压进浅景深一团 + 人物间以暗部/家具切分隔离线（§F4）。

### D. 色彩 / 光影（实用光）
- **H11** 定光 → 先指定画内光源（南瓜灯/车灯/日光灯/雾中路灯/火焰/电视雪花光），再据此布低照度（§M5/T6）。
- **H12** 要孤立/寒冷/超自然 → 冷底（蓝青 / 雾白 / 无色），暗部 ≥60%，饱和 −15~−20%（§T7/M7）。
- **H13** 要"有事发生"的颜色事件 → 单点暖色爆发（火焰/血浆/爆炸/南瓜灯），冷底中稀有出现，不铺暖（§M7/F2）。
- **H14** 要 80s 科幻/噩梦质感 → anamorphic 横向 lens flare（强光源打镜头边缘产生横向光斑）+ 椭圆 bokeh（§T8）。
- **H15** 雾/烟 → 把光源藏进雾里做体积光柱（backlit 雾墙），威胁从雾中显影（The Fog）（§T6）。

### E. 母题 / 声音 / 结构
- **H16** 定节奏前 → 先写 synth 循环（2–4 音符 / 非常规拍号如 5/4 / 60–120 BPM），镜头时长与切点跟音（§M4/§八「声音先行」）。
- **H17** jump scare 前 → 必有 0.5–1s 短暂静默 + locked-off 静止铺垫，再爆发（§F5/怪形）。
- **H18** 威胁"无法被杀死/无处不在" → 复用同一空镜角度让它反复出现/消失（形式=宿命），不台词点明（§M8）。
- **H19** 末镜 → 开放不解决：空景滞留 / 两人对峙不揭底 / 威胁仍在，避正面情绪释放特写（§T10/M8）。
- **H20** 反乌托邦"真相在表象下" → 用视觉双读（They Live 眼镜=黑白真相层 vs 彩色伪装层）做同一画面的两种读法切换（§T9）。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 空旷藏物判别（负空间 + 暗部）**
```
负空间 < 1/3 画框         → 不成立（构图太满，无"恐惧容器"）
负空间/暗部 ≥ 1/2 且威胁位可留 → Carpenter 式空旷预置（推荐）
主体半身没入 ≥60% 暗部    → 前景暗部藏物成立
铁律：留空的一侧/景深必须是威胁能进来的位置，不是纯装饰留白。
```

**F2 · 冷底单暖判别（颜色即事件）**
```
基调 = 冷（蓝青/雾白/无色）+ 饱和 −15~−20% + 暗部 ≥60%
暖色（火焰/血浆/南瓜灯/爆炸）= 稀有单点爆发，画面占比小、时机=事件发生
暖色铺满 = 破坏纪律（暖失去"事件"信号价值）
```

**F3 · 实用光判别（光的合法性）**
```
每个光源必须画内可指认（南瓜灯/车灯/日光灯/雾中路灯/火焰/电视光）
低照度 + 暗部 ≥60% + 硬边阴影（宽比例拉长）
若光源无画内来源 / 全域高调平光 → 非 Carpenter 式（破坏 M5）
```

**F4 · 幽闭偏执判别（围城互疑）**
```
单一封闭空间反复调度（不逃离到开阔地）
+ 长焦压缩把群体压成浅景深一团
+ 人物之间有暗部/门框/家具的隔离线（构图上互相不安全）
目的：威胁可能是同伴 → 构图先制造互疑，不靠台词
```

**F5 · 耐心 vs 失控判别（两种节奏）**
```
基调 / 空旷预置 / 跟踪 → locked-off 长凝视 or 缓慢横移 0.3–1°/s + 长镜 5–10s+ + 剪辑克制（默认）
怪兽实体爆发 / jump scare（特例）→ locked-off → 突然 handheld 1.0–1.5°/s + 冲近 0.3–0.5m + 短切 1–3s/镜
铁律：失控是"预置好的静默"之后的爆发，不是全程躁动；基调段绝不短切失控。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 空旷宽银幕预置** ｜机制：宽比例留大负空间 + 长滞留让观众自己找威胁｜参数：Panavision anamorphic 2.35:1；locked-off；主体偏一侧、另一侧留 ≥1/2 空/暗；滞留 4–8s；平视/略低｜触发：威胁尚未出现、要"恐惧先于事件"｜意图：让观众在事发前就害怕｜正例：Halloween（郊区街道空景）、The Fog（海岸空镜）、怪形 §场景 A 镜 A-1（狗笼静态铺垫）。

**T2 · 缓慢横移/横摇扫场** ｜机制：极慢横向运动像替观众搜索空间｜参数：0.3–1°/s 横摇或横移（tracking/pan）；匀速无加速；常配空景或前景过暗物｜触发：空旷段要加压、或跟随/被跟随主观｜意图：把"搜索威胁"的动作交给摄影机｜正例：Halloween 开场（Steadicam 匀速主观）、Escape from New York 夜城横移（推断 · 见 §九）。

**T3 · 前景/背景暗部藏物** ｜机制：主体实焦居中景，暗部留出可容威胁的位置，威胁无预警显形/滑入｜参数：暗部 ≥60%、主体半身没入黑；威胁静立背景失焦暗处或从画框边缘匀速滑入；不给切镜/音效前置｜触发：要"它已经在画里"或"它正在进来"｜意图：延迟发现 = 观众自己撞见恐惧｜正例：Halloween（Myers 从背景/门后/画框边缘现身，无预警）。

**T4 · stalker POV 匀速潜行** ｜机制：主观镜头低速平移代入威胁视角｜参数：Steadicam / 手持稳定，匀速慢移，视线随门/窗/角色移动，长镜不切｜触发：跟踪/偷窥/被追｜意图：让观众被迫"当"威胁，或感到被注视｜正例：Halloween 开场长主观镜（面具 POV）。

**T5 · 框中框幽闭囚笼** ｜机制：门/走廊/铁栏/舷窗二次切割 + 封闭空间困死｜参数：门窗框占边缘、主体居中内框；前景栅格失焦覆盖；单一空间反复调度｜触发：围城/幽闭/无处可逃｜意图：景框=牢笼、空间即困境｜正例：怪形 §场景 A（狗笼铁栏前景）、Assault on Precinct 13（警局围困 · 推断）、Prince of Darkness（教堂封闭）。

**T6 · 实用光 + 体积雾光** ｜机制：画内光源低照度 + 雾中体积光柱｜参数：光源画内可指认（南瓜灯/车灯/日光灯/雾中路灯/火焰）；暗部 ≥60%；backlit 雾墙做体积光；硬边宽阴影｜触发：夜/雾/超自然入侵｜意图：黑暗=藏匿处、雾=威胁的显影介质｜正例：The Fog（雾中路灯与显影的鬼影）、Halloween（南瓜灯/街灯）。

**T7 · 冷底单暖爆** ｜机制：冷调压底 + 稀有暖色单点爆发｜参数：蓝青/雾白/无色底，饱和 −15~−20%，暗部 ≥60%；暖色（火焰/血浆/爆炸/南瓜灯）小占比、时机=事件｜触发：孤立/超自然基调 + 突发暴力｜意图：颜色即事件、冷=无援暖=爆发｜正例：怪形（蓝青 + 喷火器暖橙爆发）、The Fog（雾白 + 灯塔暖光）。

**T8 · anamorphic 横向 flare** ｜机制：宽变形镜头 + 强光边缘产生横向光斑｜参数：Panavision anamorphic；强光源（车灯/火焰/手电）打镜头边缘 → 横向蓝色 flare + 椭圆 bokeh；不后期添加｜触发：夜景强光源、要 80s 科幻噩梦质感｜意图：横向 flare 把强光源"拉长"占满宽画幅，给夜景加 80s 科幻/梦魇质感（非壮阔装饰 · 参 §M2）｜正例：怪形全片、Escape from New York 夜城（推断）。

**T9 · 视觉双读（真相层 vs 伪装层）** ｜机制：同一画面两种读法切换｜参数：一个视觉开关（如 They Live 墨镜）在彩色伪装层与黑白真相层间硬切；真相层高对比、去广告去伪装｜触发：反乌托邦"表象下的真相"母题｜意图：让观众看见"被隐藏的层"｜正例：They Live（墨镜黑白真相层 vs 彩色现实）。

**T10 · 反英雄空末镜** ｜机制：末镜拒绝闭合，留空/静/未定｜参数：末镜=空景滞留 or 两人对峙不揭底 or 威胁仍在；避正面情绪释放大特写；可配 synth 淡出｜触发：结尾、拒绝 catharsis｜意图：恐惧延续到片尾后、真相不解｜正例：怪形结尾（MacReady/Childs 互疑不揭底）、Halloween 结尾（Myers 消失 + 空房空景蒙太奇）。

## 七、禁忌清单（❌ Carpenter 式分镜绝不做的事）

- ❌ **构图塞满、没有负空间**——就没有"恐惧容器"，威胁无处预置（§F1）。
- ❌ **jump scare 靠音效/切镜提前预告**——威胁应无预警滑入/显形，观众自己撞见（§H2/T3）。
- ❌ **基调段用密集短切失控**——耐心是基调，失控只在预置好的静默之后爆发（§F5）。
- ❌ **暖色铺满 / 高调平光**——暖是稀有事件信号、光必须画内低照度（§F2/F3）。
- ❌ **光源无画内来源**——放弃实用光就丢了 Carpenter 的真实与黑暗藏匿（§M5/F3）。
- ❌ **CGI 奇观替代实体/实用光**——怪兽实体段坚持机械/乳胶/真火（怪形 · §八「反 AI 味」）。
- ❌ **围城戏逃到开阔明亮地、群体和睦同框**——破坏幽闭偏执与互疑（§F4）。
- ❌ **结尾给情绪释放大特写、把真相揭全**——末镜要开放不解决（§M8/T10）。
- ❌ **复杂管弦交响配乐**——应极简 synth 循环先行定节奏（§M4/§八「声音先行」）。
