# 伯格曼方法论总纲 · 面孔逼视与灵魂解剖（Ingmar Bergman's Transferable Shot-Design System）

> **定位**：导演级方法论（跨作品 · 非单片拉片）——归纳伯格曼与尼克维斯特（Sven Nykvist）跨作品中的面孔、凝视、自然光与心理空间方法。
> **配套逐镜案例**（库内 1 部）：`masters/bergman/` → 假面（Persona · 1966）。其余片名（冬日之光/沉默/呼喊与细语/野草莓/第七封印/犹在镜中/秋日奏鸣曲）仅作技法锚点引用，尚无逐镜文件。

---

## 索引摘要（用于快速匹配，不替代正文）

**核心 DNA**：伯格曼×尼克维斯特的分镜系统 = **"把人脸当成心理的风景，用光把灵魂的双面切开"**，六根支柱。① **面孔 ECU 逼视**：脸满框甚至溢框（85–100mm 长焦贴近），以较长持有让皮肤、眼和嘴的细微变化成为心理运动。② **说者/听者倒置**：一人长独白 + 另一人全程沉默，镜头可把更长的反应时间交给听者，沉默成为表演。③ **半脸雕塑光（明暗界过鼻梁）**：尼克维斯特单一柔和侧光/窗光，半脸明半脸暗 = 灵魂双面；反硬好莱坞三点光。④ **两张脸交融**：并置/前后重叠/**半脸拼合**（一人左半+另一人右半合成一张脸）/叠化——"我是谁"的瓦解。⑤ **黑白高级灰阶极简**（或呼喊与细语的血红例外）+ 排除一切干扰的空房/海岛留白。⑥ **自反性**：胶片烧断/放映机/过曝纯白，提醒"这是电影"。方法：locked-off 静止 + 微表情即运动、静默即声音。

**适用情境**：心理剧/存在主义、双人关系、沉默独白文戏、身份认同瓦解、内在崩解、极简空间对峙、信仰与虚无。**不适用/需改造**：动作/商业快节奏/奇观（半脸拼合、自反性是极端艺术手法，仅心理顶点用）、需信息堆砌的全景叙事、煽情配乐驱动的场面。

## 一、核心方法

### M1 · 脸即风景（人脸是心理戏的首要地形）
一场心理戏的信息载体不是环境、不是动作，是**人脸的微观地形**（毛孔/睫毛/湿润的眼/颤抖的嘴角）。先决定"这张脸此刻要暴露什么"，再谈别的。
- **分镜含义**：心理临界点 → 上 ECU 满框 + locked-off 长停，把脸当风景拍（§T1）。不要靠环境或走位交代内心。

### M2 · 光是灵魂的雕刻刀（半脸 = 双面）
光不是照明，是把一张脸切成"明的一半 / 暗的一半"来外化人格的矛盾。尼克维斯特哲学：单一自然光源、软而精确、明暗界线过鼻梁。
- **分镜含义**：定一场脸戏的布光前先问"这个人内心哪一半在暗处" → 单侧光半脸雕塑（§T2/F2），拒三点平光。

### M3 · 听者比说者重要（沉默是最大表演）
对白戏的重心可落在**接收方**：说者倾泻，听者吸纳；较长的听者反应镜让沉默凝视成为场面重心。
- **镜头作用**：独白戏不必一直切说者，可延长听者反应镜，让细微目光变化承担接收过程（§T3/H6）。沉默是一种声音。

### M4 · 身份是可瓦解的（两张脸能合成一张）
"我是谁"不是稳定的——两个角色可以并置、重叠、半脸拼合、叠化融成同一张脸。构图本身就是主题。
- **分镜含义**：主题是身份交融/镜像/吞噬 → 用并置/半脸拼合/叠化（§T4/T5），而非台词点明"我们变成一个人"。

### M5 · 减法到只剩灵魂（排除一切干扰）
空房、海岛、留白、黑白——刻意剥离环境、色彩、道具，让画面只剩人脸与心理，无处躲藏。
- **分镜含义**：置景做减法（单光源、空墙、大留白），别堆布景（§T7/H13）。丰富来自灰阶层次与微表情，不来自信息量。

### M6 · 有意图的静止（locked-off + 微表情即运动）
摄影机基本不动（locked-off / 极缓推），"运动"发生在脸上——一个眼神的湿润、一次呼吸的不匀就是一次运镜。
- **镜头作用**：心理特写可保持静观，让画面动感由微表情、光影变化与静默张力承载，而非依赖摄影机移动。

### M7 · 沉默与独白的双轨（言语的无力）
情绪走两条轨：长篇独白（言语暴露）与大段静默（言语失效）。真相往往落在静默里，独白反而是防御。
- **分镜含义**：独白段配听者沉默特写形成对位；关键真相时刻**抽掉对白**，只留脸与呼吸（§H7/H8）。

### M8 · 自反的现代自觉（提醒这是电影）
在心理崩解的顶点插入自反镜（胶片烧断/放映机/过曝纯白/角色看镜头），打破叙事幻觉——不是花招，是"人格边界崩溃"的形式对应物。
- **分镜含义**：仅在**心理崩解最高点**用自反插入（§T10），且极短、极稀。滥用即廉价（§禁忌）。

## 二、镜头决策启发式

### A. 面孔特写 / 焦段
- **H1** 要心理逼视/灵魂暴露 → ECU 脸满框甚至溢框，85–100mm 长焦贴近，f2 浅焦，locked-off 长停 8–30s，靠微表情连续渐变。
- **H2** 脸戏要"无处可藏" → 平视机位（非俯非仰）+ 主体不刻意回避镜头 + 背景全虚化到无信息，只剩脸。
- **H3** 要"生理级"真实反应 → 长镜 locked-off 逼出不匀呼吸、瞳孔湿润、嘴角颤抖等低外泄的微反应。

### B. 布光（半脸雕塑）
- **H4** 要"灵魂双面/内心分裂" → 单一柔和侧光（窗光/天光），明暗界线过鼻梁，半脸明半脸暗，暗部 50–60%（§F2）。
- **H5** 布光**禁**三点平光/好莱坞硬光 → 尼克维斯特单光源自然光哲学：软、精确、可数的一个主光，灰阶层次做足。
- **H6** 暗部越深 = 心理越沉 → 一般独白半脸暗部 50%；望向虚无/绝望顶点推到 60%，脸另一半近乎沉入黑。

### C. 说者 / 听者 / 静默
- **H7** 独白戏可把更长的反应镜给**沉默听者**的脸，使细微目光变化成为场面重心；说者可只闻其声或给较短特写（§M3）。
- **H8** 关键真相时刻 → 抽掉对白与配乐，只留脸 + 环境底噪 + 呼吸，让静默承载（§M7/1）。
- **H9** 想颠覆"谁在主导" → 同段独白重复两次、第二次全程切听者脸（假面重复蒙太奇），重点从"说什么"移到"如何承受"。

### D. 身份交融 / 双人构图
- **H10** 主题=身份并置/镜像 → 两张脸紧贴同框（一正一侧）共享单一光源，制造镜像感（§T4）。
- **H11** 主题=人格吞噬/合一 → 半脸拼合（一人左半+另一人右半，缝在中轴，两侧光刻意不对称）或一张脸缓慢叠化进另一张（§T5）。
- **H12** 双人权力关系 → 说者前景半侧虚 + 听者后景正面实（焦点在吸纳者），用景深分层表达"谁掌控"。

### E. 空间 / 极简 / 自反 / 例外色
- **H13** 要"无处躲藏的对峙" → 极简空房/海岛，单一窗光，留白 ≥50%，人物渺小或分坐窗光两侧。
- **H14** 要"渺小/存在孤独" → 背影面海/面窗 + 海平线或空墙留白 ≥50%，平光天光，人物占框极小。
- **H15** 心理崩解最高点（且仅此时）→ 自反插入：过曝纯白/胶片烧断闪现/放映机/角色直视镜头，极短 1–3s（§T10）。
- **H16** 若必须用彩色表现极端情绪（呼喊与细语路数）→ 以**饱和血红**做墙面/转场底色（红=灵魂内部/子宫/痛），其余极简，红是唯一强色（§F5）。

### F. 剪辑节奏 / 眼神 / 转场执行
- **H17** 脸戏想要"直逼观众" → 让主体在长停中**极缓抬眼扫向镜头轴线一次**（不必正视，掠过即可），其余时间视线略偏——一次对视=一次情绪冲击，不可全程瞪镜头（§M1/T1）。
- **H18** 剪辑基调 → **少切、切点压在情绪停顿而非动作上**；镜头平均时长长（脸戏单镜 8–30s），杜绝动作驱动的快切；节奏靠"停"而非"切"承载（§M6/1）。
- **H19** 独白想做"视角颠覆"蒙太奇 → 把同一段独白剪两遍：第一遍全程说者脸、第二遍逐字对齐全程切听者脸（机位/景别/焦段两遍完全一致，只换被摄对象），让观众第二遍只看"如何承受"（假面重复段 · §H9/2）。
- **H20** 身份交融转场执行 → 用**慢叠化**（overlap dissolve，非硬切）让一张脸在数秒内溶进另一张，两脸机位/景别/光位尽量对齐使五官缓慢重合；叠化时抽掉配乐只留呼吸（§T5/2）。

## 三、条件性判断

**F1 · "这是不是伯格曼式面孔镜"判别**
```
伯格曼式面孔逼视的主要线索：脸部满框或溢框，镜头持有足以让微表情成为运动，背景与外部动作被压低；半脸侧光是尼克维斯特的重要方案之一。《假面》85–100mm、f2 与 ≥8s 是库内单片复刻参考，不是四项准入条件。
```

**F2 · 半脸雕塑光判别（尼克维斯特单光源）**
```
尼克维斯特半脸雕塑光常以单一柔和侧光或窗光，让明暗交界经过鼻梁并保留丰富灰阶；《假面》暗部约占半脸是视觉样本。关键是光把心理双面写在脸上，而非固定光源数或百分比。
```

**F3 · 说者/听者时长判别（沉默权重）**
```
独白戏中：根据场面重心分配说者与听者镜长；若重点在接收过程，可让听者反应镜更长
最长的单个镜头可给沉默听者，但不是所有独白的固定配额
真相顶点 = 抽对白，只留脸+呼吸
若一直停在说者而忽略接收方，听者的心理变化会被削弱。
```

**F4 · 身份交融强度判别**
```
弱（并置）：两脸同框、共享光源、镜像感 → 界限"开始"模糊
中（重叠）：一前一后 / 叠化双重曝光 → 一个吞噬另一个
强（半脸拼合）：左半+右半合成一张新脸 → "我即是你"、身份已瓦解
按剧情崩解程度选强度，勿一上来就用半脸拼合（留给顶点）。
```

**F5 · 黑白 vs 例外血红判别（用色纪律）**
```
《假面》等黑白心理剧 = 高级灰阶排除色彩干扰
《呼喊与细语》等彩色作品 = 饱和血红可把墙面/转场变成心理内部
一旦用彩色 → 红必须是有意义的心理信号，其余仍极简
杂色/高饱和杂陈 = 破坏纪律。
```

## 四、技法卡片

**T1 · 面孔 ECU 逼视** ｜机制：长焦贴脸+满框+locked-off 长停，把脸当心理风景｜参数：85–100mm，f2 浅焦，平视，脸额到下巴满框甚至溢框，停留 8–30s，靠微表情连续渐变（呼吸/瞳孔湿润/嘴角颤抖）｜触发：灵魂暴露/心理临界/独白｜意图：强迫观众直面灵魂、无处可藏｜正例：假面（护士独白 ECU · §场景 A）、秋日奏鸣曲（母女对质长特写）、犹在镜中（女主精神崩解特写）。

**T2 · 半脸雕塑光** ｜机制：单一柔和侧光把脸切成明暗两半｜参数：单光源（窗光/天光），明暗界过鼻梁，暗部脸占 50%（常态）/60%（顶点），软过渡灰阶丰富，无补光｜触发：内心分裂/灵魂双面/道德矛盾｜意图：光=心理的雕刻刀，明暗=人格双面｜正例：假面（全片半脸）、冬日之光（牧师信仰动摇的窗侧光）、犹在镜中（尼克维斯特自然光标志作）。

**T3 · 沉默听者反应镜** ｜机制：独白时可把更长的反应时间给沉默接收方｜参数：听者 ECU，locked-off，全程无台词，以极细微眼神变化承载接收过程；镜长按独白结构确定｜触发：一人倾诉/告解/对质｜意图：让听者成为场面重心、沉默成为表演｜正例：假面（女演员沉默凝视 14s，比相邻说者镜更长 · §A-2）、秋日奏鸣曲（女儿控诉时母亲的脸）。

**T4 · 两张脸并置镜像** ｜机制：两脸紧贴同框共享单一光源制造镜像｜参数：85mm f2.8，两脸一正一侧紧贴，单光源跨两脸半明半暗，locked-off，双人极致克制凝视 ｜触发：身份/镜像主题、界限开始模糊｜意图："我是谁"松动的起点｜正例：假面（两脸并置 · §B-1）。

**T5 · 半脸拼合 / 叠化吞噬** ｜机制：一人左半脸+另一人右半脸合成一张新脸，或一脸叠化进另一脸｜参数：100mm f2，拼接缝在中轴，两侧光刻意不对称；或缓慢叠化短暂双重曝光｜触发：人格吞噬/合一的顶点｜意图：身份彻底瓦解、我即是你｜正例：假面（库内标志性半脸拼合 · §B-2；一脸叠化进另一脸 · §B-3）。（库内首见的极致身份交融手法；仅顶点用）

**T6 · 静默真相时刻** ｜机制：关键真相处抽掉对白与配乐｜参数：脸 ECU + 仅环境底噪/呼吸声，无音乐无对白，locked-off 长停｜触发：情感/真相的最深处｜意图：言语无力，静默承载｜正例：假面（无对白凝视段 · §A-2 沉默听者 14s 附近为库内锚点）、沉默（几近无对白的旅馆压抑 · 无逐镜文件）、冬日之光（沉默中的信仰空洞 · 无逐镜文件）。

**T7 · 极简空间对峙** ｜机制：剥离环境到空房/海岛只剩两个灵魂｜参数：50mm f4，空房单一窗光，留白 ≥50%，两人分坐窗光两侧或近距对视，locked-off｜触发：无处躲藏的双人对峙｜意图：减法到只剩心理｜正例：假面（海岛空房 · §场景 C）、沉默（异国空旅馆）。

**T8 · 渺小留白构图** ｜机制：人物置于大留白中显其存在渺小｜参数：50mm f5.6，背影面海/面窗，海平线或空墙留白 ≥50%，平光天光，人物占框极小，locked-off（海浪/风为内部微动）｜触发：存在孤独/面对虚无｜意图：人在天地/信仰前的渺小｜正例：假面（背影面海 · §C-3）、第七封印（海边与死神对弈的空旷剪影 · 存疑见 §九）。

**T9 · 双人景深权力分层** ｜机制：用前后景虚实表达谁掌控关系｜参数：85mm f2.8，说者前景半侧虚 + 听者后景正面实（焦点在吸纳者），窗光前后景明暗分离｜触发：不对称权力/施受关系｜意图：焦点=权力所在｜正例：假面（说者前景/听者后景在焦 · §A-3）。

**T10 · 自反性插入** ｜机制：心理崩解顶点打破叙事幻觉｜参数：过曝纯白 1–3s / 胶片烧断质感闪现 / 放映机镜 / 角色直视镜头；极短极稀｜触发：**仅**人格边界崩溃的最高点｜意图：形式对应"这是电影/边界崩溃"的现代自觉｜正例：假面（过曝纯白插入 · §B-4；开场胶片放映机段落）。（⚠️ 极端手法，滥用即废）

## 七、风格偏离与失真风险

- ❌ **用三点平光 / 好莱坞硬光打脸**——必须单一柔和侧光半脸雕塑（§F2/M2）。
- ❌ **独白戏一直切说者而忽略接收方**——应根据场面重心给听者足够反应时间，不设跨场固定时长关系（§F3/M3）。
- ❌ **真相顶点还铺配乐煽情**——该抽掉对白与音乐，让静默承载（§T6/M7）。
- ❌ **快切 / 移镜炫技**——伯格曼是 locked-off 有意图静止 + 微表情即运动（§M6）。引用须标"心理特写静观意图"。
- ❌ **一上来就用半脸拼合 / 叠化**——身份交融强度须匹配崩解程度，极致手法留给顶点（§F4）。
- ❌ **堆布景 / 塞环境信息**——减法到只剩人脸与心理、空房留白（§M5/H13）。
- ❌ **滥用自反性插入**——仅心理崩解最高点、极短极稀，否则廉价（§T10/M8）。
- ❌ **没有心理功能的高饱和杂色**——黑白作品以高级灰阶聚焦面孔；彩色作品可用血红等主导色承担心理空间（§F5）。
- ❌ **让脸躲开镜头 / 用中远景交代内心**——心理必须贴脸逼视，无处可藏（§H1/H2）。
