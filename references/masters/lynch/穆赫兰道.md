## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. **梦境逻辑叙事（Dream Logic）**

- **物理参数**：非理性的无缝衔接 + 身份流动（同一演员不同身份）+ 循环/重复意象 + 不解释的因果 + 时空跳跃
- **物理实现**：按梦的逻辑而非现实因果剪辑 + 让观众"在梦里"而非"看懂"
- **情感意图**：潜意识的真实 · 比理性叙事更接近恐惧与欲望的本质

### 2. **氛围恐怖（Dread, not Shock）**

- **物理参数**：不靠 jump scare/血腥 + 靠缓慢推近 + 低频嗡鸣 drone + "日常中的异常"（一个表情/一句话/一个角落不对劲）+ 长时间的不安累积
- **物理实现**：极慢节奏 + 声音设计的不安 + 让观众预感"有什么不对"却说不清
- **情感意图**：不可名状的恐惧 · 比直接吓人更深更持久

### 3. **红蓝暗调（Red & Blue Darkness）**

- **物理参数**：红窗帘/红灯罩 #8B1A1A + 蓝调暗部 #1A2A40 + 钨丝暖点 + 暗部 ≥65% + 高对比
- **物理实现**：红色织物/灯光 + 蓝调阴影 + 低照度
- **情感意图**：红=欲望/危险/潜意识 / 蓝=梦境/冷寂 · 好莱坞华丽下的黑暗

### 4. **缓慢诡异运镜（Slow Uncanny Movement）**

- **物理参数**：极缓 push in 0.03-0.08 m/s 逼近危险物/门后/暗角 + 缓慢摇向不该看的地方 + 主观的窥探
- **物理实现**：极慢推轨 + 朝向"不安源"逼近 + 制造"不想看又必须看"
- **情感意图**：把观众缓缓推向恐惧的核心 · 窥探禁忌

### 5. **Badalamenti 梦呓配乐（Dreamy Score）**

- **物理参数**：慵懒爵士 + 低频嗡鸣 drone + 突然的寂静 + 梦呓人声 + 不安的合成器
- **物理实现**：氛围配乐与画面的诡异错位 + 寂静作为恐怖
- **情感意图**：梦的质感 · 美与不安并存

### 6. **超现实意象 + 表演两层（Surreal Imagery & Dual Performance）**

- **物理参数**：蓝盒子/蓝钥匙/牛仔/墙后怪物/微缩老人等意象 + 表演分层（梦中明亮天真 50% ↔ 现实绝望崩溃 80%）
- **物理实现**：象征性道具/角色 + 同一演员演梦与现实两种状态
- **情感意图**：潜意识符号 · 梦的甜美与现实的残酷对照

## 三、镜头语法 DNA（What makes this work）

1. **梦境逻辑叙事**：非理性无缝衔接、身份流动（同一演员不同身份）、循环意象、不解释因果——让观众"在梦里"而非"看懂"，潜意识比理性更接近恐惧与欲望本质。
2. **氛围恐怖（dread not shock）**：不靠 jump scare/血腥，靠缓慢推近 + 低频嗡鸣 + "日常中的异常" + 长时间不安累积——不可名状的恐惧更深更持久。
3. **红蓝暗调**：红 #8B1A1A 欲望/危险/潜意识 + 蓝 #1A2A40 梦境/冷寂 + 暗部 ≥65%——好莱坞华丽下的黑暗。
4. **缓慢诡异运镜**：极缓 push in 0.03-0.08 m/s 逼近危险物/门后/暗角——把观众缓缓推向恐惧核心，"不想看又必须看"。
5. **Badalamenti 梦呓配乐**：慵懒爵士 + 低频嗡鸣 + 突然寂静——梦的质感，美与不安并存，寂静本身是恐怖。
6. **超现实意象**：蓝盒子/蓝钥匙/牛仔/墙后怪物/微缩老人——潜意识符号，不解释但确信其存在。
7. **表演两层对照**：梦中明亮天真 50% ↔ 现实绝望崩溃 80%（同一演员）——梦的甜美与现实的残酷对照。

## 四、声音/音乐设计 DNA

1. **低频嗡鸣 drone**：持续的低频不安嗡鸣 · 氛围恐怖的核心声音 · 逼近时加重。
2. **Badalamenti 梦呓爵士**：慵懒的爵士与梦呓人声 · 美与诡异并存。
3. **突然的寂静**：嗡鸣骤停的死寂 · 寂静本身制造恐怖（怪物现身瞬间）。
4. **声画分离**：Club Silencio 的"录音"揭示（歌者倒下歌声继续）· 梦境逻辑的听觉化。
