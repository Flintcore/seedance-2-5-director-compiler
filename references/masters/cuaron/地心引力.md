## 一、整体风格观察

### 1. **失重长镜（Zero-G Long Take）**

- **物理参数**：无重力的连续漂浮调度 + 开场 17 分钟一镜到底 + 摄影机无重力自由翻转/环绕/穿梭 + 物体/人漂浮旋转 + 无上下方向
- **物理实现**：CG + 灯光箱 + 精密运动控制 + 一镜到底的失重调度
- **情感意图**：失重的自由与失控 · 无依无靠的漂浮

### 2. **太空真空无声（Vacuum Silence）**

- **物理参数**：真空中无声音传播 + 只有无线电通讯 + 角色呼吸（头盔内）+ 配乐 + 物体撞击无声（只见不闻）+ 死寂
- **物理实现**：去除真空中音效 + 保留无线电/呼吸 + 配乐承载情绪
- **情感意图**：真空死寂的恐怖 · 无声的灾难更窒息

### 3. **主观 POV 沉浸（Subjective POV Immersion）**

- **物理参数**：无缝切入头盔内主观视角（看到头盔反光 + 地球倒影 + 呼吸雾）+ 观众=宇航员 + 旋转晕眩的主观
- **物理实现**：无缝切换客观↔头盔主观 + 头盔内 POV
- **情感意图**：观众沉浸为宇航员 · 身临其境的窒息

### 4. **地球为背景的渺小（Earth Backdrop Solitude）**

- **物理参数**：蔚蓝地球弧线为背景 + 人在太空中占画面 ≤10% + 浩瀚黑暗 + 渺小孤独
- **物理实现**：地球 CG 背景 + 渺小化构图
- **情感意图**：人在宇宙中的渺小孤独 · 美丽与致命并存

### 5. **极简色彩（Minimalist Palette）**

- **物理参数**：太空黑 #0A0C12 + 地球蔚蓝 #1B4D8C + 阳光白过曝 + 航天器银白 + 极简
- **物理实现**：太空黑 + 地球蔚蓝 + 强阳光
- **情感意图**：极简的纯粹 · 黑暗与蔚蓝的对照

### 6. **漂浮失重表演 + 重生母题（Weightless Acting & Rebirth）**

- **物理参数**：笨拙的无重力动作（漂浮/翻滚/抓握）逐渐转为求生恐惧 + 重生母题（胎儿姿态漂浮/破水浮出/重力站立）
- **物理实现**：失重表演 + 重生意象构图
- **情感意图**：求生的本能 · 从失重到重力的重生隐喻

## 三、镜头语法 DNA（What makes this work）

1. **失重长镜**：无重力的连续漂浮调度（开场 17 分钟一镜到底）+ 摄影机无重力自由翻转环绕 + 物体/人漂浮旋转——失重的自由与失控，无依无靠的漂浮。
2. **太空真空无声**：真空中无声传播 + 只有无线电/呼吸/配乐 + 撞击无声只见不闻——真空死寂的恐怖，无声的灾难更窒息。
3. **主观 POV 沉浸**：无缝切入头盔内主观视角（头盔反光/地球倒影/呼吸雾）+ 旋转晕眩——观众沉浸为宇航员。
4. **地球为背景的渺小**：蔚蓝地球弧线 + 人占画面 ≤10% + 浩瀚黑暗——人在宇宙中的渺小孤独，美丽与致命并存。
5. **极简色彩**：太空黑 + 地球蔚蓝 #1B4D8C + 阳光白——极简纯粹，黑暗与蔚蓝对照。
6. **漂浮失重表演 + 重生母题**：笨拙的无重力动作 + 求生恐惧 + 重生母题（胎儿姿态/破水/站立）——从失重到重力的重生隐喻。
7. **从失重到重力的弧线**：太空漂浮 → 坠落 → 破水 → 站立——结构本身即从死到生的重生。

## 四、声音/音乐设计 DNA

1. **真空无声**：真空中无声传播 · 撞击/爆炸只见不闻 · 死寂的恐怖。
2. **Steven Price 配乐承载**：因真空无声 · 配乐承担情绪与"声音" · 渐强的张力。
3. **无线电与呼吸**：无线电通讯（唯一对话）+ 头盔内呼吸 · 沉浸的主观声。
4. **声音的主观化**：通过身体接触传导的振动声 · 主观感知。
