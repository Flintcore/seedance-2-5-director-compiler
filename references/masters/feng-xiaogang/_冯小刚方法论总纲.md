## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：冯小刚的分镜系统 = **"用灰调纪实的克制，扛住历史与命运的重量"**，四根支柱。① **群像洪流引擎**：大规模群演的流民/灾民/难民洪流（推车挑担扶老携幼），28mm 大远景把个体压成"人如蝼蚁"，手持贴入洪流跟随单个家庭——宏观渺小与微观苦难交替（≠英雄独行）。② **灰调纪实纪律（判别铁律）**：去饱和土黄灰 #8A7A5E（-30~-40%）+ 自然光为主 + 手持微抖 + 不美化的褴褛尘土——历史正剧全程压饱和，暖只留给篝火/煤油灯的点光（≠高饱和奇观美化）。③ **去戏剧化厚重**：苦难日常化（死亡/饥饿成路边常态）+ 克制不煽情 + 表演麻木 30–50%——"克制比嚎哭更痛"，突发暴力瞬间才放到 60%。④ **黑色幽默底色**：绝境荒诞自嘲 / 喜剧片里的世俗反讽——冯氏幽默是悲凉与调侃的双面。多线交织（灾民/政府/记者/宗教多视角交叉剪辑）。形式实验：《我不是潘金莲》圆形/方形画幅遮罩 = 用画幅本身叙事。

**适用情境**：历史正剧 / 灾难群像史诗 / 逃荒饥荒 / 战争 / 苍凉纪实 / 苦难日常化 / 冬日萧瑟 / 世俗黑色幽默。**不适用/需改造**：需高饱和奇观美化的场面、需英雄主义仰拍崇高、需优雅稳定运镜的唯美抒情、需暖调温情的治愈系（灰调纪实与克制反其道）。

## 一、核心心智模型（8 个镜片 · How Feng sees a shot）

### M1 · 苦难先于个体（人是洪流里的一粒）
先建群像洪流、再落到个体；历史灾难的重量由**规模 + 渺小对比**承载，不靠主角挤悲情。大远景把逃荒队压成蝼蚁，再手持切进单个家庭。
- **分镜含义**：拍历史/灾难先问"这条洪流有多大、个体有多小"，再摆人。宏观大远景与微观手持成对出现。→ 见 §T1/T2。

### M2 · 灰是历史的底色（去饱和即厚重）
颜色不是装饰而是年代与苦难的坐标：历史正剧全程压饱和到土黄灰，暖色只作为点光（篝火/煤油灯/火光）稀疏出现。饱和度本身承载"沉重、褪色、往事"。
- **分镜含义**：定历史场景先定去饱和基调（#8A7A5E / -30~-40%），暖只当点缀不当主色。见 §T3/F2。

### M3 · 克制比嚎哭更痛（去戏剧化）
苦难不靠放大表演与煽情配乐，靠"日常化"：死亡成路边常态、卖儿卖女不嚎哭、麻木地拉过破被盖住亡者。信息更少的克制反而更重。
- **分镜含义**：想让观众更痛 → 降表演到 30–50% 麻木、去煽情配乐、把苦难拍成日常。判别见 §F3。

### M4 · 镜头是纪实的旁观者（手持跟随，不上帝视角）
摄影机是挤在人群里的记录者，不是编排美的上帝之眼。手持微抖跟随、平视/微俯、不追求稳定优雅——把观众放进洪流里而非看台上。
- **分镜含义**：历史/灾难段默认手持纪实旁观（§M4 摄影机态度），不给稳定 dolly 唯美感；稳定 dolly 只用于极缓的"目送"大远景。见 §T2/H4。

### M5 · 洪流即命运（空间方向承载历史）
绵延不断、方向一致的人流本身就是叙事——逃荒的方向 = 求生的方向 = 命运的方向。人流的绵延、拥堵、断裂都在说历史。
- **分镜含义**：要"民族苦难/时代裹挟" → 拍方向一致的绵延洪流；要"绝路" → 洪流断裂/停滞。见 §T1/H2。

### M6 · 黑色幽默是悲凉的双面（笑中带苦）
喜剧与正剧共用一个内核：世俗荒诞。喜剧片（甲方乙方/大腕）用世俗反讽逗乐，正剧（一九四二）用绝境自嘲消解苦难——冯氏幽默永远带一层悲凉。
- **分镜含义**：绝境戏可插"苦中作乐"对白镜（克制带苦涩 45%）作为情绪对冲，不是纯悲到底。见 §T6/H10。

### M7 · 多线交织拼全景（宏观冷 × 微观热）
历史灾难用多视角交叉剪辑呈现：灾民（微观苦难）× 政府/官僚（宏观冷漠）× 记者/外部旁观 × 宗教。个体苦难与体制冷漠对切，拼出灾难的全维度。
- **分镜含义**：大事件不单线 → 灾民热线（手持贴近苦难）与官僚冷线（稳定端正的会议构图）交叉，靠温差叙事。见 §T7/H16。

### M8 · 画幅即观点（形式作为叙事，谨慎用）
在《我不是潘金莲》里冯用圆形（乡村/主观困局）↔ 方形（北京/体制规整）↔ 宽银幕（结局释放）遮罩，让画幅本身表达"荒诞的规矩感"。形式实验服务主题，不炫技。
- **分镜含义**：当主题是"荒诞的规矩/困局"时可用非标准画幅遮罩作为叙事——圆=困守主观、方=体制规整。谨慎，仅主题需要时。见 §T8/F5。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 群像洪流 / 规模与渺小
- **H1** 要"民族苦难/时代洪流"建立 → 28mm 大远景 f8，绵延流民人流（推车/挑担/扶老携幼），平视/微俯，人如蝼蚁，冬日去饱和土路。
- **H2** 要"命运方向/裹挟感" → 人流方向一致、绵延出画；要"绝路/停滞" → 洪流断裂或原地滞留。
- **H3** 建完宏观洪流 → 立即手持切进单个家庭中景（35mm f4），宏观渺小 ↔ 微观苦难交替，不停留在纯奇观。
- **H4** 群像收束/"目送" → 极缓 dolly（唯一允许的稳定运镜）拉开大远景，人流继续绵延，克制 40%。

### B. 灰调纪实 / 光影调色
- **H5** 历史正剧任何场景 → 去饱和土黄灰 #8A7A5E（饱和 -30~-40%）+ 自然光为主，不打平不美化。
- **H6** 要暖 → 只给点光（篝火/煤油灯/火把/炉火），暖点落在冷灰底上，**不整体拉暖**（§F2）。
- **H7** 冬日萧瑟 → 加枯树/寒风/雪 + 冷清晨光去饱和，身体性消瘦褴褛真实质感。
- **H8** 要"真实粗粝" → 手持微抖 + 尘土/饥饿/破衣实拍质感，接受不干净，拒绝磨皮唯美。

### C. 去戏剧化 / 表演与剪辑
- **H9** 苦难场（卖儿卖女/死亡/分食）→ 表演压到麻木 30–50%，别过头不敢看、无泪的哀恸，**不嚎哭**（克制比嚎哭更痛，§F3）。
- **H10** 绝境太压 → 插一镜"苦中作乐"黑色幽默对白（50mm 中近景，克制带苦涩 45%）作情绪对冲。
- **H11** 死亡/饥饿 → 拍成路边常态（逃荒者麻木走过饿殍），苦难日常化，配乐克制或留白，**不上煽情弦乐**。
- **H12** 情绪高点 → 用"极致克制 + 环境声"（寒风/雪/远处咳嗽）代替特写嚎哭 + 音乐轰炸。

### D. 突发暴力 / 战争
- **H13** 突发人祸（轰炸/枪战）→ 手持剧烈骤动 + 28mm f8，表演从克制升到大开大合 60%，本能奔逃。
- **H14** 战争群像（集结号/芳华战场）→ 手持贴地跟随 + 尘土硝烟去饱和 + 血污泥泞真实（推断）；不做优雅慢镜英雄美化。
- **H15** 暴力后 → 回落到"尘埃中麻木寻找亲人"手持跟随（35mm f4，克制绝望 50%），暴力—克制的节奏对比。

### E. 多线 / 形式 / 世俗喜剧
- **H16** 大历史事件 → 多线交叉剪辑：灾民热线（手持贴近）× 官僚冷线（稳定端正对称会议构图 · 冷漠），靠温差叙事。
- **H17** 主题是"荒诞的规矩/体制困局" → 可用画幅遮罩叙事（圆=乡村主观困守 / 方=北京体制规整 / 宽=释放），仅主题需要时（§F5）。
- **H18** 世俗喜剧（甲方乙方/大腕/非诚勿扰）→ 明亮平实自然光 + 中景对话为主 + 京味方言对白抖包袱，镜头让位于台词，**不炫技运镜**（推断）。
- **H19** 喜剧的讽刺高潮 → 荒诞情境正经拍（一本正经的荒唐），反差出笑点，机位保持写实不夸张。
- **H20** 大场面回归个体 → 灾难/战争的宏大最终落到一个家庭/一个人的具体命运特写，宏观—微观闭环。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 冯氏历史正剧判别（灰调纪实厚重）**
```
满足以下才算"冯小刚历史正剧式"：
① 去饱和土黄灰基调（#8A7A5E / 饱和 -30~-40%）+ 暖仅点光
② 手持纪实微抖 + 平视/微俯（旁观者视角，非上帝视角）
③ 表演克制麻木 30–50%（苦难日常化，不嚎哭）
④ 群像洪流（大规模群演）or 至少宏观渺小 ↔ 微观苦难对比
缺 ①③ = 不成立（是奇观/煽情，不是冯氏厚重）。
```

**F2 · 去饱和灰调 vs 暖点判别（色彩纪律）**
```
历史正剧默认 = 去饱和土黄灰冷底（#8A7A5E）
暖色（篝火/煤油灯/火光）= 只作点光，落在冷灰底上，占比 < 20%
一旦整体拉暖 / 高饱和 → 破坏年代厚重，变温情奇观（失效）
对照：世俗喜剧才用明亮平实自然光（非去饱和苦难调）。
```

**F3 · 克制 vs 煽情判别（去戏剧化铁律）**
```
苦难高点 → 表演麻木 30–50% + 环境声（寒风/雪/咳嗽）+ 配乐克制/留白 = 冯氏"克制比嚎哭更痛"
苦难高点 → 特写嚎哭 + 煽情弦乐轰炸 + 表演 80%+ = 反冯氏（廉价催泪）
唯一例外：突发暴力瞬间可升 60%（本能奔逃），暴力过后立即回落克制。
```

**F4 · 宏观 vs 微观镜头分工判别（群像洪流）**
```
要"民族苦难/时代裹挟" → 28mm 大远景，人如蝼蚁，稳定极缓 dolly 或平视
要"个体苦难/共情"     → 35–50mm 手持中景/中近景，贴入洪流跟随一个家庭
铁律：二者交替出现，不可只有宏观奇观（无共情）或只有微观（无历史重量）。
```

**F5 · 画幅遮罩叙事判别（形式实验，谨慎）**
```
仅当主题 = "荒诞的规矩 / 体制困局 / 主观 vs 客观" 时启用非标准画幅：
圆形遮罩 = 乡村 / 主观 / 困守其中（我不是潘金莲乡村段）
方形遮罩 = 北京 / 体制 / 规整冷漠
宽银幕   = 释放 / 结局松绑
非主题需要 → 不用（炫技即失效）。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 流民洪流大远景** ｜机制：大规模群演绵延人流 + 广角压成蝼蚁｜参数：28mm f8，平视/微俯，绵延方向一致的逃荒人流（推车/挑担/扶老携幼），冬日去饱和土黄灰 #8A7A5E，极缓 dolly 或手持微跟｜触发：民族苦难/时代洪流建立与收束｜意图：个体在历史灾难中渺小如蝼蚁｜正例：一九四二 §场景 A-1（逃荒长队大远景）/ A-4 收束洪流。

**T2 · 手持贴入群像跟随** ｜机制：从宏观洪流手持切进单个家庭｜参数：35mm f4，手持微抖跟随，平视，去饱和自然光，主体挤在人流中｜触发：宏观渺小后落到微观个体共情｜意图：把观众放进洪流而非看台｜正例：一九四二 §A-2（老东家一家随流）、§C-3（尘埃中寻找亲人）。

**T3 · 去饱和土黄灰灰调** ｜机制：全程压饱和作年代/苦难底色｜参数：#8A7A5E，饱和 -30~-40%，自然光为主，不打平不磨皮，冬日冷底｜触发：历史正剧任何场景｜意图：饱和度本身承载沉重褪色往事｜正例：一九四二全片基调 / §A-1。

**T4 · 篝火煤油灯点光暖** ｜机制：冷灰底上稀疏暖点光｜参数：篝火/煤油灯/火把暖点（占比 <20%），落在去饱和冷底上，大光圈浅景深抠人｜触发：难民营夜/室内苦难｜意图：暖=残存的生机与希望，不整体拉暖｜正例：一九四二 §B-1（难民营篝火暖点）、§B-3（分食）。

**T5 · 苦难日常化克制** ｜机制：把死亡/饥饿拍成路边常态｜参数：50mm 中景 f2.8，逃荒者麻木走过饿殍，手持微移，表演麻木 35%，配乐克制/留白，环境声（寒风/乌鸦/静）｜触发：死亡/饥饿/卖儿卖女｜意图：克制比嚎哭更痛——把苦难降到"日常路过"的信息量，靠减法施压｜正例：一九四二 §A-3（路边饿殍）、§B-2（卖儿卖女不嚎哭）、§B-4（冻饿而亡）。

**T6 · 绝境黑色幽默对白** ｜机制：苦中作乐对冲纯悲｜参数：50mm 中近景 f2.8，锁定/手持微抖，去饱和自然光，方言对白，克制带苦涩幽默 45%｜触发：绝境太压需情绪对冲｜意图：冯氏幽默的悲凉变体，苦难中的人性韧性｜正例：一九四二 §A-4（苦中自嘲对白）。

**T7 · 多线冷热交叉剪辑** ｜机制：微观苦难热线 × 宏观官僚冷线对切｜参数：灾民线=手持贴近去饱和苦难；官僚线=稳定端正对称会议构图，冷调规整；靠温差叙事｜触发：大历史事件多维呈现｜意图：个体苦难 vs 体制冷漠｜正例：一九四二 §六「场景过渡」（灾民/政府/记者多线交叉，推断具体镜）。

## 七、禁忌清单（❌ 冯小刚式分镜绝不做的事）

- ❌ **历史正剧用高饱和/美化调色**——应去饱和土黄灰 #8A7A5E，饱和度承载年代厚重（§F2）。
- ❌ **整体拉暖调温情**——暖只作点光（篝火/煤油灯）落在冷灰底上，占比 <20%（§F2/H6）。
- ❌ **苦难高点用特写嚎哭 + 煽情弦乐轰炸**——应克制麻木 30–50% + 环境声，克制比嚎哭更痛（§F3）。
- ❌ **把死亡/饥饿拍成戏剧化奇观**——应苦难日常化（路边常态、麻木走过）（§M3/H11）。
- ❌ **英雄主义仰拍崇高 / 优雅慢镜美化战争**——冯是苦难群像无英雄，手持纪实不唯美（§M1/H14）。
- ❌ **优雅稳定的唯美运镜**——历史/灾难段默认手持纪实微抖，稳定 dolly 只留给极缓"目送"（§M4/H4）。
- ❌ **只有宏观奇观、无微观共情（或反之）**——宏观渺小与微观苦难必须交替（§F4）。
- ❌ **画幅遮罩当炫技用**——非"荒诞规矩/体制困局"主题不用非标准画幅（§F5）。
