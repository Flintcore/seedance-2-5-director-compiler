## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. **色彩分章节叙事（Color-coded Chapters）**

- **物理参数**：同一故事的不同版本各用一种饱和主色 · 红 #C8102E（嫉妒/激情版本）/ 蓝 #1B4D8C（想象/克制版本）/ 白 #F0EDE5（真相版本）/ 绿 #2D5F3E（回忆版本）/ 黑灰（现实秦宫）· 大面积纯色铺满
- **物理实现**：每章节统一主色调 + 服装/场景/光全统一 + 色彩作为叙事层标记
- **情感意图**：色彩即叙事层与情感 · 不同版本不同心境

### 2. **大场面对称写意（Symmetric Epic Scale）**

- **物理参数**：万箭齐发/旗海/秦军方阵 + 极致对称构图 + 大规模群演 + 整齐划一 + 写意而非写实战争
- **物理实现**：大规模调度 + 对称机位 + 整齐的视觉冲击
- **情感意图**：帝国的宏大威严 · 个体在洪流中渺小

### 3. **武侠写意诗化（Poetic Wuxia）**

- **物理参数**：水上对决/胡杨林落叶飞舞/书法与剑意相通 + 武打如诗如画 + 升格 + 长镜展示 + 意念交锋（闭眼想象对决）
- **物理实现**：写意武打编排 + 自然环境融入 + 升格诗化
- **情感意图**：武打是诗与画 · 东方写意的境界

### 4. **极致饱和色块（Saturated Color Blocks）**

- **物理参数**：大面积纯色铺满画面 + 高饱和 +40-60% + 服装/帷幔/落叶/旗帜的纯色 + 色块对撞
- **物理实现**：美术统一纯色 + 高饱和调色
- **情感意图**：视觉的极致冲击与东方装饰美

### 5. **自然元素升格（Natural Elements Slow-mo）**

- **物理参数**：水滴/落叶/沙尘/帷幔的升格慢动作 + 诗意点缀 + 自然与武打交融
- **物理实现**：升格高速摄影 + 自然元素特写
- **情感意图**：诗化的瞬间 · 武打中的禅意停顿

### 6. **大远景渺小 + 庄重写意表演（Epic Scale & Stylized Acting）**

- **物理参数**：大远景把人放进山水/沙漠/宫殿 + 人渺小 + 表演庄重写意 40-60%（克制中的张力）+ 古典戏剧感
- **物理实现**：渺小化大远景 + 庄重内敛表演
- **情感意图**：天地的辽阔 · 英雄的庄重与牺牲

## 三、镜头语法 DNA（What makes this work）

1. **色彩分章节叙事**：同一故事不同版本各用一种饱和主色（红=嫉妒激情/蓝=想象克制/白=真相/绿=回忆/黑=现实），色彩即叙事层与情感——不同版本不同心境的视觉化。
2. **大场面对称写意**：万箭齐发/旗海/秦军方阵 + 极致对称 + 大规模群演——帝国的宏大威严，个体在洪流中渺小。
3. **武侠写意诗化**：水上对决/胡杨林落叶/书法剑意/意念交锋 + 升格——武打是诗与画，东方写意的境界。
4. **极致饱和色块**：大面积纯色铺满画面 + 高饱和 +40-60%——视觉极致冲击与东方装饰美。
5. **自然元素升格**：水滴/落叶/沙尘/帷幔的升格慢动作——诗化的禅意瞬间。
6. **大远景渺小 + 庄重写意表演**：人放进山水/沙漠/宫殿渺小 + 庄重内敛 40-60%——天地辽阔，英雄的庄重牺牲。
7. **色彩转化叙事**：金黄落叶被血染红、不同版本色彩切换——色彩本身承载情节与情感的转折。
