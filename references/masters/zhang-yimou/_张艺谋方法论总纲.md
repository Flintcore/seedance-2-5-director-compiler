## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：张艺谋的分镜系统 = **"把情感/权力/命运翻译成可测的色彩、几何与自然元素"**，五根支柱。① **单色场分段引擎**：一整场戏只用一种高饱和主色铺满（服装+美术+光+环境统一），色彩本身当叙事层与情绪坐标（红=激情/嫉妒/婚俗，蓝=想象/克制，白=真相/死亡，绿=回忆，黑灰=帝国/现实），换段=换色（硬切）。② **几何人海调度**（判别铁律）：大规模群演按网格/方阵/环形整齐排列 + 极致对称机位 + 大远景压渺个体——写意而非写实，追求图案化而非混乱真实。③ **自然元素升格诗化**：旗/叶/雨/沙/水滴/尘用高速升格悬停，做写意点缀与禅意停顿，武打亦写意（水上、落叶中、意念交锋）。④ **对称仪式构图**：中轴对称 + 正面机位 + 大面积单色块对撞，把日常拍成仪式。⑤ **大远景渺小 + 庄重写意表演 40-60%**：靠姿态气场而非面部细节。方法：美术先行、色彩即结构、宁图案不写实。

**适用情境**：古装史诗/武侠、色彩叙事、大场面群戏、仪式/民俗、写意武打、东方诗化、极致饱和色、开幕式级几何调度。**不适用/需改造**：需要粗粝写实/纪实质感的题材（张式反自然主义）、需要低饱和灰调冷峻的现代都市（需切到其《秋菊》《一个都不能少》纪实变体，本总纲不覆盖）、需要碎剪快切的动作可读性（张式偏写意长镜）。

## 一、核心心智模型（8 个镜片 · How Zhang sees a shot）

### M1 · 美术/色彩先于表演（先定色场，再放人）
先定这一整场戏"是什么颜色"，色彩不是打光装饰而是叙事结构本身；情绪由**主色 + 景框 + 调度**承载，演员在既定色场里做庄重克制的姿态。
- **分镜含义**：进任何一场戏先问"这场是什么色、色说什么"，再摆人摆机位。→ 见 §T1/§F1。

### M2 · 色彩即叙事层（换段 = 换色）
颜色是可量化的情绪/叙事坐标，不是氛围。同一事件的不同版本/不同章节各配一种饱和主色，观众靠色彩识别"这是哪一层叙事/哪一种心境"。
- **分镜含义**：多段落结构 → 给每段锁一个主色 HSV 区间，段间硬切换色（非渐变），色彩承担分章功能。见 §T2/§F2。

### M3 · 几何人海（人是排布成图案的单元）
大规模群演不是背景，是可编排的图案材料；按网格/方阵/环形/波浪整齐排列，追求视觉秩序与规模冲击，而非写实的混乱人群。
- **分镜含义**：有群演 → 先想"排成什么几何图案"，再定对称机位与俯角。写意图案化 > 写实真实。见 §T3/§F3。

### M4 · 对称即仪式（中轴 + 正面）
中轴对称构图 + 正面机位把日常/战争/民俗抬升为仪式；对称=威严、秩序、命运的不可抗。
- **分镜含义**：想要庄重/威压/仪式感 → 上严格中轴对称 + 正面平视或俯角，主体居中。见 §T4/§F4。

### M5 · 自然元素是写意的笔（旗/叶/雨/沙/尘/水滴）
自然/物质元素用升格悬停做"写意的一笔"——既是情绪外化，也是武打诗化的媒介与禅意停顿，而非环境真实。
- **分镜含义**：要诗意/禅意/情绪高点 → 插入单一自然元素升格特写（一片叶、一滴水、一面旗），悬停 2-3 拍。见 §T5/H。

### M6 · 大远景压渺小（天地 vs 个体）
把人放进辽阔山水/沙漠/宫殿/人海的大远景里压到极小，表达个体在天地/帝国/命运前的渺小与庄重牺牲。
- **分镜含义**：主题涉及命运/牺牲/帝国/苍茫 → 用大远景 + 广角把人压渺小，靠姿态而非表情。见 §T6/M8。

### M7 · 单色块对撞（大面积纯色相邻）
用大面积纯色块相邻并置（红对绿、红对金黄、黑对红）制造视觉冲击与东方装饰美，色块本身是画面主角。
- **分镜含义**：要极致视觉冲击 → 让两三块大面积高饱和纯色在同一画面对撞，减少杂色。见 §T7/H12。

### M8 · 庄重写意表演（气场 > 面部细节）
表演走庄重克制 40-60%，古典戏剧感，情绪交给姿态、衣袂、站位、凝神，而非面部挤表情——尤其大远景里靠身体轮廓与气场。
- **分镜含义**：大远景/仪式/武打场 → 表演压到 40-60% 庄重写意，反应克制，让景框和色彩说话。见 §T8/H。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 色彩 / 单色场
- **H1** 要"色彩即情绪坐标" → 整场锁一种高饱和主色铺满（服装+美术+环境光统一），大面积纯色，饱和 +40-60%，不要杂色分散。
- **H2** 多版本/多章节结构 → 每段配一主色（激情/婚俗=红、想象/克制=蓝、真相/死亡=白、回忆=绿、帝国/现实=黑灰），段间**硬切换色**、非渐变。
- **H3** 要"情节转折的色彩化" → 让主色在场内被"染"或"转"（金黄落叶被血染红 / 白转红），色彩渐变承载剧情转折点。
- **H4** 要东方装饰性视觉冲击 → 大面积纯色块对撞（红对绿/红对金/黑对红），减少中间色与杂色。

### B. 几何人海 / 大场面
- **H5** 有大规模群演 → 排成网格/方阵/环形/波浪等几何图案 + 整齐划一，追求图案化秩序（写意），不追写实混乱。
- **H6** 要帝国威压/规模震撼 → 俯角大远景 + 广角（24-28mm）+ 极致对称方阵 + 漫山遍野铺满画面。
- **H7** 群演动作 → 整齐同步（万箭齐发/击鼓/挥旗），同步齐动比个体差异更有张力。
- **H8**（铁律）大场面群戏用**对称 + 图案化**，绝不用手持晃动/碎剪写实——那会破坏张式仪式感（§F3）。

### C. 对称 / 构图
- **H9** 要仪式/威严/命运感 → 严格中轴对称 + 正面机位（平视或俯角）+ 主体居中。
- **H10** 要个体渺小 → 大远景 + 广角把人压到画面 <1/8，放进山水/沙漠/宫殿/人海。
- **H11** 建筑/空间戏 → 利用宫殿长廊/城墙/院落的既有对称几何做纵深，人走中轴。

### D. 自然元素 / 写意 / 武打
- **H12** 要诗意/禅意高点 → 单一自然元素升格悬停（一片叶/一滴水/一面旗/一把沙），特写 + 高速升格，悬停 2-3 拍。
- **H13** 武打 → 写意诗化编排：融入自然环境（水上飞掠/落叶剑舞/胡杨林），升格 + 流畅跟随长镜，可含"意念交锋"（闭眼想象对决）。
- **H14** 要情绪外化 → 让自然元素与情绪同步放大（风起衣袂猎猎 / 落叶纷飞 / 旗海翻涌），元素动作 = 内心动作。

### E. 表演 / 大远景 / 节奏
- **H15** 大远景/仪式/武打场 → 表演压到庄重写意 40-60%，靠姿态/衣袂/站位/气场，反应克制。
- **H16** 大远景里表情不可读 → 用身体轮廓 + 服装色 + 站位构图传情，不依赖面部。
- **H17** 运镜 → 极缓 dolly / 升降 展示大场面与色场，或流畅跟随写意武打；避免快速晃动手持。
- **H18** 节奏 → 写意长镜 + 升格展示（信息更少的凝滞诗意），慎用快剪碎片。
- **H19** 开场 → 用"美"当钩子（对称威严的单色场 / 大场面几何），Aesthetic hook 先声夺人。
- **H20** 声画 → 大场面配磅礴声床（鼓/号角/军阵脚步）↔ 写意/意念段落配留白与单乐器（古琴/大提琴/小提琴），张弛对比。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 单色场判别（色彩即叙事）**
```
一场戏是否满足：① 一种高饱和主色铺满（服装+美术+环境光统一）② 饱和 +40-60% 大面积纯色
③ 该主色对应一个明确情绪/叙事标记（非随意）→ 才算张艺谋式单色场
反例：多杂色分散 / 低饱和灰调 / 色彩仅作打光无叙事功能 → 不是。
```

**F2 · 换段换色判别（分章纪律）**
```
多段/多版本结构 → 每段锁定一主色 HSV 区间，段与段之间硬切换色（非渐变过渡）
色彩必须承担"这是哪一层叙事/哪一种心境"的识别功能
（同一结构层混用多主色 = 破坏分章纪律，色彩失去叙事价值）
```

**F3 · 几何人海判别（图案化 vs 写实）**
```
大场面群戏是否满足：① 群演排成可识别几何图案（网格/方阵/环形/波浪）② 极致对称构图
③ 整齐同步动作 ④ 俯角/大远景压渺个体 → 才算张艺谋式几何人海
铁律：写意图案化 > 写实混乱；用手持晃动/碎剪 = 破坏签名。
```

**F4 · 对称仪式判别**
```
要仪式/威严/命运感 → 严格中轴对称 + 正面机位（平视或俯角）+ 主体居中 + 大面积单色块
对称度越高 = 仪式感/不可抗命运感越强
（打破对称 = 转向日常/失序，需有意为之）
```

**F5 · 自然元素写意判别**
```
诗意/禅意高点 → 单一自然元素（叶/水滴/旗/沙/尘）升格悬停 2-3 拍 + 特写
元素动作与情绪同步（风起=心动 / 落叶=离散 / 一滴水落=胜负定）
铁律：一次一种元素、写意点缀，不堆砌；升格是"信息更少的凝滞"，非炫技。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 单色场铺满** ｜机制：整场戏服装+美术+环境光统一到一种高饱和主色，色彩当叙事层｜参数：单一主色铺满画面、饱和 +40-60%、大面积纯色（如红 #C8102E / 蓝 #1B4D8C / 白 #F0EDE5 / 绿 #2D5F3E）、光统一不打散｜触发：需要色彩即情绪/叙事标记的段落｜意图：色彩本身承载情绪坐标与章节身份｜正例：《英雄》胡杨林红衣对决（§场景 A · 满屏红）、棋馆水上蓝调段（§场景 B）。

**T2 · 换段换色（分章叙事）** ｜机制：同一事件不同版本/章节各配一主色，段间硬切换色｜参数：每段锁一 HSV 区间，段与段硬切（非渐变），色彩=叙事层识别｜触发：多版本/多章节的重述结构｜意图：观众靠色彩识别"哪一层叙事/哪种心境"｜正例：《英雄》红=嫉妒激情版 / 蓝=想象克制版 / 白=真相版 / 绿=回忆版 / 黑灰=现实秦宫（全片结构）。

**T3 · 几何人海调度** ｜机制：大规模群演排成网格/方阵/环形几何图案 + 整齐同步｜参数：俯角/大远景 + 广角 24-28mm + f11 深景深 + 极致对称 + 群演同步动作 + 漫山遍野铺满｜触发：帝国/军阵/规模震撼｜意图：秩序与规模的视觉威压、个体渺小｜正例：《英雄》秦军万箭齐发方阵 + 旗海（§场景 C 镜 C-1/C-2）。

**T4 · 中轴对称仪式** ｜机制：严格中轴对称 + 正面机位把场景抬为仪式｜参数：中轴对称构图 + 正面平视或俯角 + 主体居中 + 大面积单色块 + 建筑对称纵深｜触发：威严/命运/仪式/民俗｜意图：秩序=威严、对称=命运不可抗｜正例：《英雄》黑甲秦宫长廊无名走中轴（§场景 C 镜 C-4）。

**T5 · 自然元素升格悬停** ｜机制：单一自然元素高速升格悬停做写意点缀｜参数：叶/水滴/旗/沙/尘特写 + 高速升格（悬停 2-3 拍）+ 元素动作与情绪同步｜触发：诗意/禅意高点、武打停顿｜意图：情绪外化 + 禅意停顿｜正例：《英雄》一滴水从剑尖落下定胜负（§场景 B 镜 B-4）、落叶被剑气卷起纷飞（镜 A-2）。

**T6 · 大远景压渺小** ｜机制：大远景 + 广角把人压到极小放进天地｜参数：大远景 + 广角（24-35mm）+ 人占画面 <1/8 + 山水/沙漠/宫殿/人海背景 + 极缓 dolly/升降｜触发：命运/牺牲/苍茫/帝国主题｜意图：个体在天地前渺小庄重｜正例：《英雄》金黄胡杨林两红衣女子立落叶中人渺小（§场景 A 镜 A-1）、秦宫长廊渺小赴死（镜 C-4）。

**T7 · 单色块对撞** ｜机制：大面积纯色块相邻并置制造冲击｜参数：两三块大面积高饱和纯色对撞（红对绿/红对金黄/黑对红）+ 减少中间色杂色｜触发：极致视觉冲击/东方装饰美｜意图：色块本身是画面主角｜正例：《英雄》红衣 #C8102E 对金黄胡杨（§场景 A）、黑甲对红（现实↔红章节对照）。

**T8 · 庄重写意表演** ｜机制：表演压到庄重克制、情绪交给姿态｜参数：表演分寸 40-60% 古典戏剧感 + 靠衣袂/站位/凝神/身体轮廓 + 大远景不依赖面部｜触发：仪式/武打/大远景/赴死｜意图：气场 > 表情、克制中的张力｜正例：《英雄》无名意念交锋凝神（§场景 B 镜 B-2）、书生箭雨中岿然执笔（镜 C-3）、赴死从容（镜 C-4）。

**T9 · 写意诗化武打** ｜机制：武打融入自然环境 + 升格长镜 + 可含意念交锋｜参数：流畅跟随长镜 + 升格 + 自然环境（水上/落叶/胡杨林）+ 闭眼想象对决（意念段）+ 35mm f4｜触发：武侠对决段｜意图：用环境+升格降低动作可读性、把打斗转成情绪与图案节奏（写意 > 招式清晰）｜正例：《英雄》水上飞掠雨滴升格（§场景 B 镜 B-3）、意念对决起势（镜 B-2）。

**T10 · 色彩转化叙事** ｜机制：主色在场内被"染/转"承载剧情转折｜参数：主色渐变（金黄→红 / 白→红）+ 升格 + 触发点对准剧情转折瞬间｜触发：情感/情节的转折点｜意图：色彩本身叙事、转折可视化｜正例：《英雄》如月中剑鲜血染红金黄落叶、整片林转红（§场景 A 镜 A-3）。

## 七、禁忌清单（❌ 张艺谋式分镜绝不做的事）

- ❌ **在同一叙事层/单色场里混用多种杂散主色**——破坏"色彩即叙事层"纪律，色彩失去识别价值（§F2）。
- ❌ **低饱和灰调 + 色彩仅作打光无叙事功能**——张式色彩是结构不是氛围（§F1）。（注：《影》的黑白灰是有意的反饱和单色场，仍遵循"单一色系铺满"逻辑，非杂色低饱和。）
- ❌ **大场面群戏用手持晃动 / 碎剪写实**——应几何图案化 + 对称 + 整齐同步（§F3）。
- ❌ **群演排成写实混乱人群**——张式追求网格/方阵/环形的图案化秩序（§M3）。
- ❌ **打破对称去拍"随意日常"却无意图**——对称=仪式/命运，破坏需有意为之（§F4）。
- ❌ **自然元素堆砌 / 一次多种元素乱插**——应一次一种、升格悬停、写意点缀（§F5）。
- ❌ **武打快剪碎片化 + 写实血腥**——应写意诗化 + 升格长镜 + 自然环境融入（§T9）。
- ❌ **大远景里靠面部特写挤表情**——大远景靠姿态/衣袂/站位/气场，表演压 40-60%（§M8/T8）。
- ❌ **色彩转折用渐变糊过 / 段间软过渡**——分章色彩应硬切，转折染色应对准剧情点（§F2/T10）。
