## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：韦斯·安德森的分镜系统 = **"把画面当平面版式来排，用几何秩序反衬内容荒诞"**，五根支柱。① **正面平面对称**（判别铁律）：镜头轴精确对正主体面部中线、主体/建筑/道具 100% 居中（±5%）、左右镜像、单点透视消失点落画面正中——摄影机永远垂直/平行于墙面，从不斜切（≠斜角透视立体感）。② **玩具屋纵深**：前/中/后景平行分层像舞台布景，25–50mm 中焦、避长焦压缩与广角畸变，人是"版式里的格子"。③ **几何运镜四轨**：横向 whip pan（90°/0.5s 代剪辑）+ 90° 直角 dolly（只走正交直线/0.1–0.3 m/s）+ 原地 180°/90° 旋转切视角 + locked-off——运动只走正交轴，禁自由斜线手持漂移。④ **Deadpan 反差喜剧**：面无表情 + 120–180 词/min 快速念词 + 不变声调（音高变化 ≤30%），越严肃越荒诞（Deadpan 10–30% 典范）。⑤ **色彩即版式**：糖果色分块（粉紫/米黄/红铜/蓝绿各归一区），单一主导色/场，去自然色。附加：画幅比切换标时代/叙事层、章节卡结构、微缩模型拍外景与"玩具机械"运动。

**适用情境**：风格化喜剧/童话剧/黑色幽默、严肃面对荒诞、装饰主义、复古怀旧、群像速写、视觉游戏、章节嵌套叙事。**不适用/需改造**：需临场真实感的纪实/手持/自然主义、需连续动作可读性且拒几何化的商业动作、需去饰化的写实惊悚、依赖大特写情绪爆发的剧情片（Deadpan 反此）。

## 一、核心心智模型（8 个镜片 · How Wes sees a shot）

### M1 · 画面先是平面版式，其次才是空间（Frame-as-layout）
先把画面当"一页对称印刷版式/绘本插画"来排：定中轴、定镜像、定分层，再放人。人物是"版式格子里的元素"，情绪由**几何秩序**承载，不靠演员挤表情或摄影机偏角制造张力。
- **分镜含义**：先问"这一帧的对称轴/消失点/分层在哪"，再摆人与道具。→ 见 §T1/T2。

### M2 · 摄影机只走正交轴（Orthogonal camera）
机位角度、运镜方向、道具排列全部锁在正交坐标系：0°正面 / 90°侧面 / 俯 / 仰，运镜只走横、纵、原地旋转。**从不斜切、从不自由漂移**。斜角与手持漂移在库内不属于此签名。
- **分镜含义**：任何运镜先分解到"横/纵/旋"三条正交轴之一；斜线 dolly、自由手持 = 破签名。见 §T4/T5/H6。

### M3 · 秩序反衬荒诞（Order-vs-absurd contrast）
极致的构图/表演秩序不是为了美，是喜剧引擎：越对称越工整越 Deadpan，内容越荒诞越动人。秩序是"直"，内容是"歪"，落差即效果。
- **分镜含义**：设计一场戏先定"秩序层"（对称+Deadpan+糖果色）与"荒诞层"（内容/事件）的落差；两者都拉满，不折中。见 §M6/F5。

### M4 · 色彩是分区版式，不是打光（Color-as-blocking）
颜色按"区块/角色/场景"分配，一场一主导色，色块之间界线清晰（制服一色、墙一色、道具一色）。糖果色是童话装饰坐标，不是自然照明的副产物。
- **分镜含义**：定场先分配"这一区是什么色块"，避免自然杂色渐变。见 §T7/F4。

### M5 · 运动即机械动画（Motion-as-mechanism）
运镜与场景内运动都追求"玩具/机械/翻页"感：dolly 匀速像轨道车，whip pan 像翻页，微缩模型里的缆车/滑雪像发条玩具，物件开合（电梯门/抽屉）当几何动画演。
- **分镜含义**：想让一次运动"有 Wes 味" → 让它匀速、正交、可预期，像机械装置而非有机漂移。见 §T5/T6/T9。

### M6 · Deadpan = 把情绪冻结进构图（Deadpan interiority）
演员面无表情、快速念词、不变声调，把本该外放的情绪压回构图与事件里。情绪不在脸上，在"严肃地做荒诞事"这一落差里。
- **分镜含义**：上情绪戏时**不要**给自然反应大特写；用居中 Deadpan 单人框 + 快速念词，情绪交给内容与秩序。见 §T3/H11/F3。

### M7 · 画幅比是叙事层标记（Aspect-ratio-as-marker）
不同画幅比（1.33 / 1.85 / 2.35）对应不同时代/叙事层/视角层，观众靠比例瞬间识别"我现在在哪一层故事里"。比例是结构信号，不是随意选择。
- **分镜含义**：多时间线/多叙事层脚本 → 给每层锁一个画幅比，全程一致，切层即切比。见 §T8/H16。

### M8 · 章节化 + 微缩 = 绘本仪式感（Storybook framing）
章节标题卡、目录式结构、微缩模型外景，把影像框成"一本被翻阅的绘本/玩具屋"，制造抽离的观看仪式——观众知道自己在看一个被讲述、被制作的东西。
- **分镜含义**：要抽离/仪式/童话感 → 上章节卡分段、外景用微缩模型 + 玩具机械运动。见 §T9/T10/H17。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 构图 / 对称（版式先行）
- **H1** 要 Wes 式仪式秩序 → 主体面部中线对正镜头轴，主体 100% 居中（±5%），左右镜像布景，单点透视消失点落画面正中。
- **H2** 有主副两人 → 主体居中，副体置画面一侧约 30% 处、小一号身位，保持整体仍读作对称版式（非把两人平分左右破坏单中心）。
- **H3** 要童话/绘本插画感 → 前/中/后景平行分层排列（舞台式），机位正对分层平面，25–50mm 中焦，禁长焦压缩与广角透视。
- **H4** 拍物件（门/抽屉/餐盘/信件）→ 物件正对镜头 100% 居中 + 图案自身左右对称，当"几何静物版式"拍。

### B. 运镜 / 摄影机（只走正交轴）
- **H5** 要"翻页式"场景/主体切换 → 横向 whip pan 90°、约 0.5s 完成，切换瞬间画面动态模糊，对话不停顿接续（whip pan 代剪辑）。
- **H6**（铁律）任何 dolly/track → **只走正交直线**（横向或纵向）、匀速 0.1–0.3 m/s；**禁斜线 dolly、禁自由手持漂移**（破 §M2 签名）。
- **H7** 要"用旋转代替反打/切视角" → 摄影机原地旋转 180°（或 90°）约 0.5s，主体保持居中，同一空间给出双视角。
- **H8** 静态叙事镜 → locked-off 锁死机位，靠构图/表演/念词承载信息，节奏由剪辑而非运镜给。

### C. 表演 / 节奏（Deadpan 反差）
- **H9** 全片全角色 → Deadpan 10–30%：面无表情 + 不变声调（音高变化 ≤30%）+ 几乎不眨眼 + 极少身体晃动。
- **H10** 台词密集 → 快速念词 120–180 词/min（正常对话约 2 倍）+ 不允许停顿；反派/配角同样 Deadpan（凶狠也用 Deadpan）。
- **H11** 需要一点情绪爆发 → 只给 ≤0.3s 极短表情爆发瞬间，随即回落 Deadpan（反差点睛，不铺开）。
- **H12** 整体节奏 → 2–4s/镜快切 + whip pan 切换；**避免** ≥10s 长 take 大量堆叠（破快节奏签名）。

### D. 色彩 / 光影（色即版式）
- **H13** 定场色 → 每场一主导糖果色，色块分区清晰（如粉紫外墙 / 米黄室内 / 红铜装饰 / 蓝绿冷酷段 / 白雪）；一区一色，禁自然杂色渐变。
- **H14** 室内基调 → 暖黄钨丝约 3200K + 暗部约 30%（偏明亮均匀）；装饰性照明，非戏剧性强反差侧光。
- **H15** 冷酷/机构段落（监狱/权力）→ 切冷白 6500K 或蓝绿分区，与暖糖果色段落形成"色块章节"对照。

### E. 结构 / 画幅 / 微缩（绘本层）
- **H16** 多时代/多叙事层 → 每层锁一画幅比（如 1.33 过去 / 1.85 中层 / 2.35 现在），切层即切比，全层内一致。
- **H17** 外景（建筑/雪山/城镇）→ 优先 1/4 比例微缩模型 + 玩具机械式匀速运动（缆车/滑雪/车），而非实景航拍。
- **H18** 要绘本仪式感/分段 → 插章节标题卡（衬线字体 + 目录式）分割叙事，配木琴/节拍标记。
- **H19** 群像速写 → 每角色给一个居中 Deadpan 单人"名片式"镜头（出场 ≤2 min 也要标志性一帧）。
- **H20** 想抽离/后设 → 让画面自我暴露"被制作"（微缩、平面布景、直接对镜、章节卡），拒绝沉浸式写实。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 正面平面对称判别（核心签名）**
```
是否满足以下全部才算 Wes 式对称镜：
① 镜头轴对正主体面部中线（0° 正面，无斜角）
② 主体/建筑 100% 居中，偏移 ≤ 画面宽 5%
③ 左右镜像（布景/道具/建筑两翼可镜像折叠）
④ 单点透视，消失点落画面正中
缺任一 → 只是"大致居中"，非 Wes 签名。
```

**F2 · 正交运镜判别（摄影机纪律）**
```
运镜方向 ∈ {横向平移, 纵向推拉, 原地旋转} → 合法（whip pan / 直角 dolly / 180°旋转）
运镜方向 = 斜线 / 弧线 / 自由手持漂移       → 破签名（改造或剔除）
匀速性：dolly 恒速 0.1–0.3 m/s，whip pan/旋转恒速 ~0.5s；忌加减速有机感。
```

**F3 · Deadpan 判别（表演分寸）**
```
面部表情变化幅度 ≈ 0（面无表情）
声调音高变化 ≤ 30%（不变声调）
念词速度 120–180 词/min（≈正常 2 倍，无停顿）
眨眼/身体晃动 极少
允许：单次 ≤0.3s 表情爆发瞬间（反差点睛）
以上不满足 = 自然表演 = 非 Wes（破风格指纹 2）
```

**F4 · 色块版式判别（色彩纪律）**
```
每场 → 单一主导糖果色 + 清晰分区色块（角色/道具/墙各归一色）
禁：自然杂色、脏底渐变、去饱和写实色调
糖果色 ≠ 高对比戏剧光；是均匀装饰性铺色（暗部 ~30%）
（此判别区分 Wes 糖果色 与 王家卫脏底霓虹 / 是枝去饱和自然色）
```

**F5 · 秩序—荒诞落差判别（喜剧引擎）**
```
秩序层（对称 + Deadpan + 糖果色 + 正交运镜）拉满 = 1
荒诞层（事件/内容/台词的荒谬度）拉满 = 1
两层同时拉满且不互相稀释 → Wes 式反差喜剧成立
若秩序层松（构图随意）或荒诞层被"演出来"（演员大开大合）→ 落差消失，失效
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 正面平面对称构图** ｜机制：镜头轴对正面部中线 + 单点透视居中 + 左右镜像｜参数：平视 0°、35mm、f/2.8、镜头精确对正主体中线；主体 100% 居中 ±5%；消失点落画面正中；顶部留白约 25%｜触发：仪式/秩序/严肃面对荒诞的任何主镜｜意图：几何秩序承载情绪、为反差喜剧铺底｜正例：布达佩斯大饭店 §场景 A 镜 A-1（古斯塔夫指导 Zero，1.33:1 居中正面）。

**T2 · 玩具屋平面化纵深** ｜机制：前/中/后景平行分层 + 机位正对分层平面｜参数：25–50mm 中焦、避长焦压缩/广角透视；角色站位 90° 直角平行；f/4 保前后景可读｜触发：要绘本插画/舞台/玩具屋感｜意图：与电影立体感反向、平面版式感｜正例：布达佩斯大饭店 §场景 B 镜 B-1（监狱牢房铁栅栏前景 + 五人横向平行排列）。

**T3 · Deadpan + 快速念词** ｜机制：面无表情 + 不变声调 + 高速念词把情绪压回构图｜参数：表情变化≈0、音高变化 ≤30%、120–180 词/min 无停顿、几乎不眨眼；允许 ≤0.3s 爆发瞬间｜触发：全片全角色对白/反应｜意图：严肃面对荒诞的反差喜剧核心（Deadpan 10–30% 典范）｜正例：布达佩斯大饭店 §场景 A 镜 A-1（古斯塔夫 150 词/min）、§场景 C 镜 C-3（反派凶狠 Deadpan）。

**T4 · 横向 whip pan 切换** ｜机制：快速横扫代替剪辑做主体/场景切换｜参数：横向 90°、约 0.5s 完成、切换瞬间动态模糊、对话不停顿接续｜触发：同空间主体切换/翻页式转场｜意图：视觉游戏、翻页节奏｜正例：布达佩斯大饭店 §场景 A 镜 A-2（古斯塔夫→Zero whip pan 接话）、§场景 C 镜 C-1（雪山追逐）。

**T5 · 90° 直角 dolly** ｜机制：dolly 只走正交直线的几何跟拍｜参数：横向或纵向、匀速 0.1–0.3 m/s、禁斜线、主体在移动中轮流被居中｜触发：横向群体调度/跟拍｜意图：玩具轨道车般的机械秩序｜正例：布达佩斯大饭店 §场景 B 镜 B-2（五人隧道横向 dolly 0.2 m/s，五人轮流居中）。

**T6 · 原地 180°/90° 旋转切视角** ｜机制：摄影机原地旋转代替反打｜参数：原地旋转 180°（或 90°）约 0.5s、主体保持居中、同一空间双视角、含旋转前后定格｜触发：要几何化视角反转｜意图：用旋转动画代剪辑、后设机械感｜正例：布达佩斯大饭店 §场景 B 镜 B-4（古斯塔夫正面→背面）、§场景 C 镜 C-3（反派视角反转）。

**T7 · 糖果色分区版式** ｜机制：一场一主导糖果色 + 清晰色块分区｜参数：粉紫 #E8B4D8（外墙/制服）/ 米黄 #F4E4BC（室内/奶油）/ 红铜 #B85450（电梯/行李）/ 蓝绿 #6FA8B5（监狱/冷酷）/ 白 #FFFFFF（雪）；暖黄 3200K 室内、暗部约 30%；一区一色禁杂色渐变｜触发：定场调色｜意图：色彩=童话装饰坐标+角色/场景符号化｜正例：布达佩斯大饭店 §场景 A 镜 A-4（粉紫外墙）、§场景 B（蓝绿监狱段）。

**T8 · 画幅比标叙事层** ｜机制：不同画幅比对应不同时代/叙事层｜参数：1.33:1（过去/内层主线）/ 1.85:1（中层）/ 2.35:1（现在/外层）；实拍 35mm 后期遮幅、切层即切比、层内一致｜触发：多时间线/多叙事层脚本｜意图：观众靠比例瞬识时代与叙事层级｜正例：布达佩斯大饭店（1932/1968/1985 三层三比例，见 §场景 A 用 1.33:1）。

**T9 · 微缩模型 + 玩具机械运动** ｜机制：外景用微缩模型 + 场景内运动做发条玩具感｜参数：1/4 比例模型、外景约 70% 是模型；缆车/滑雪/车匀速直线滑动、玩具人偶机械动作；模型机位仰/俯锁正交、f/8 大景深｜触发：建筑/雪山/城镇外景｜意图：童话玩具屋美学、抽离的绘本仪式感｜正例：布达佩斯大饭店 §场景 A 镜 A-4（饭店外观+缆车）、§场景 C 镜 C-1（玩具滑雪追逐）。

**T10 · 章节卡绘本结构** ｜机制：章节标题卡 + 目录式分段框住叙事｜参数：衬线字体标题卡、章节间硬分段、配木琴/节拍标记；可嵌套多层叙事｜触发：要绘本仪式感/多层嵌套/抽离感｜意图：制造"翻阅一本书"的后设观看仪式｜正例：布达佩斯大饭店（五章 chapter 结构 + 标题卡，见 §场景 B 越狱 chapter）。

## 七、禁忌清单（❌ 韦斯·安德森式分镜绝不做的事）

- ❌ **偏离居中 ≥10% / 斜角机位**——破坏正面平面对称核心签名（§F1）。
- ❌ **斜线 dolly / 弧线运镜 / 自由手持漂移**——运镜必须走正交轴，斜切与漂移是相反签名（§M2/F2）。
- ❌ **自然表演（眨眼/停顿/表情变化/大开大合爆发）**——破坏 Deadpan 反差（§F3）。
- ❌ **长焦压缩 / 广角透视做立体纵深**——破坏玩具屋平面化，改用 25–50mm 中焦平行分层（§T2）。
- ❌ **自然杂色 / 去饱和写实色调 / 脏底渐变**——破坏糖果色分区版式（§F4）。
- ❌ **全片单一画幅比**（当脚本本有多时代/多叙事层时）——浪费画幅比这一叙事标记（§M7/H16）。
- ❌ **≥10s 长 take 大量堆叠 + 慢节奏**——破坏 2–4s 快切 + whip pan 的节奏签名（§H12）。
- ❌ **让演员"演出"荒诞/情绪**——荒诞交给内容与秩序落差，不交给表演（§F5）。
- ❌ **实景航拍外景替代微缩**（当追求童话玩具屋美学时）——丢掉发条玩具质感（§T9/H17）。
- ❌ **沉浸式无缝写实**——Wes 要后设仪式感（章节卡/微缩/平面布景暴露"被制作"）（§M8/H20）。
