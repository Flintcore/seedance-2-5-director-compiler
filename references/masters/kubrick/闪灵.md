## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. **Steadicam 丝滑低角跟拍（Floating Steadicam）**

- **物理参数**：离地 0.3-0.5m 低机位 + 匀速漂浮 0.8-1.2m/s + 跟随主体（丹尼三轮车/奔跑）保持恒定距离 + 0 抖动绝对平稳 + 转角顺滑划过
- **物理实现**：Garrett Brown Steadicam 贴地跟拍 + 长走廊连续运动 + 地毯/木地板交替的声音节奏（轮子声忽闷忽响）
- **情感意图**：丝滑漂浮 = 一种"被无形之物跟随/注视"的不安 · 越平稳越诡异（与手持的"临场"相反，这是"超自然的冷静"）

### 2. **极致对称单点透视（One-Point Perspective Symmetry）**

- **物理参数**：走廊/房间正中轴对齐 + 灭点居中 + 左右镜像元素 + 广角（18-28mm）强化纵深 + 水平正对
- **物理实现**：精密机位对中 + 对称布景（门/灯/图案）+ 主体居中
- **情感意图**：完美对称 = 人造的秩序感被恐惧侵入 · 整齐到诡异 · 灭点像把观众吸入深处

### 3. **缓慢 zoom-in 推焦（Slow Zoom）**

- **物理参数**：极慢光学 zoom in（焦距渐变 · 数十秒一推）+ 主体不动相机不动只 zoom + 常用于开场航拍跟车、杰克打字机、谈话
- **物理实现**：光学变焦缓慢拉近 + 机位锁定
- **情感意图**：缓慢压近 = 不可阻挡的厄运逼近 · 比 dolly 更"冷"（空间被压缩而非穿越）

### 4. **冷暖人工光分区 + 高对比（Cold/Warm Zoning）**

- **物理参数**：Gold Room 暖金 2700-3000K（鬼魅派对）vs 走廊/浴室冷绿惨白 4000-5000K + 高对比 + 实用光源（壁灯/吊灯均匀但冷）+ 暗部硬调
- **物理实现**：大量实用光（practical）均匀打亮 + 冷暖场景分区调色
- **情感意图**：均匀明亮的恐怖（不是黑暗里的恐怖，是大白光下的诡异）· 暖金的虚假温情 vs 冷绿的死寂

### 5. **对称恐怖意象（Symmetrical Horror Icons）**

- **物理参数**：双胞胎（Grady 姐妹）并立走廊正中对称 + 血电梯门缝倾泻洪流 + 树篱迷宫俯瞰对称 + 237 房 + 字幕时间卡（"Tuesday"）
- **物理实现**：对称构图 + 缓慢揭示 + 招牌意象重复
- **情感意图**：把"整齐/秩序"变成恐惧的容器 · 母题反复积累 dread

### 6. **Penderecki 不谐和弦 dread（Dissonant Dread）**

- **物理参数**：不谐和弦乐 + 低频嗡鸣 + 心跳脉冲 + 长时间无明确旋律 + 突然的弦乐尖刺（极少 jump，多是持续压迫）
- **物理实现**：现代古典乐（Penderecki/Bartók）+ Wendy Carlos 合成 + 声音先行（声音预告未现之物）
- **情感意图**：dread（缓慢累积的恐惧）而非 jump scare（瞬间惊吓）· 声音让空旷变得有"东西"

## 三、镜头语法 DNA（What makes this work）

1. **Steadicam 丝滑 = 不安而非临场**：与手持的"纪实抖动"相反，绝对平稳的漂浮跟拍制造"被超自然之物冷静注视"的诡异。低角跟孩子尤甚。
2. **对称单点透视 = 秩序被侵入**：走廊/大厅正中轴 + 灭点居中 + 镜像，整齐到诡异，灭点像吸入深处的洞。
3. **缓慢 zoom = 不可阻挡的逼近**：极慢推焦把空间压缩在脸/物上，比 dolly 更"冷"——厄运不穿越空间而是压缩空间。
4. **大白光下的恐怖**：均匀实用光 + 冷绿惨白，恐怖发生在明亮里（反"黑暗藏鬼"套路），更无处可逃。
5. **暗示 > 展示**：双胞胎尸体只闪 2s、暴力靠破门探脸与表演——恐惧来自联想而非血浆。
6. **声音先行的 dread**：Penderecki 不谐和弦 + 低频 + 轮子声节奏，让空旷"有东西"；恐惧是累积不是瞬吓。
7. **对称意象母题**：双胞胎/血电梯/迷宫俯瞰反复——把"整齐"积累成不祥。

## 四、声音/音乐设计 DNA

1. **Penderecki / Bartók 不谐和弦**：现代古典的刺耳弦乐 + 长持续 = dread（缓慢恐惧），极少用于 jump。
2. **轮子声节奏**：三轮车碾过地毯（闷）→ 木地板（响）→ 地毯（闷）的循环节奏 = 空间的"心跳"。
3. **声音先行**：声音预告未现之物（拐角前先有不祥音）。
4. **空旷回响**：巨大空间的脚步/击键回响 = 孤立与空。
5. **禁配乐式煽情**：用物理声 + 现代古典制造压迫，不抒情。
