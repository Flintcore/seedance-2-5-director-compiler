## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：主创团队的分镜系统 = **"把权力关系外化成可测的身体调度与摄影机行为"**，五根支柱。① **调度即权力**（判别铁律）：谁站中心/前景/更高、谁被挤向边缘/后景/被前景遮挡，全是权力实时可视化——每次权力转移 = 一次走位变化（起身/走近/背对/离场），不靠台词说"我赢了"。② **多机手持纪实跟拍**：多机同拍（主谈+反应），handheld 持续微动(约 0.3–0.8°/s)、角色一动就 reframe，像纪录片摄影师追真实发生的事，拒绝预设完美构图。③ **长焦 zoom 当剪辑**：85–200mm + snap zoom-in 抓某人听到关键信息的微表情——用 zoom 而非切镜"发现"反应，信息在脸上不在嘴上。④ **绕桌/绕房间权力走位**：移动者边说边绕行，静止众人被动转头跟随=权力辐射全场。⑤ **反完美松散构图 + 冷调商务自然光**：留不规整头顶空间、人物偏置、抓拍感；去饱和冷青 5600–6500K；对话戏**无配乐**（配乐仅片头/转场），张力全靠调度。母题→镜头：权力宣示→绕行；摊牌→逼近/后退到无路可退；信息扩散→zoom 反应链。

**适用情境**：对话戏/权力博弈/商战/家族/谈判/多人群戏调度、办公室会议室/游艇/豪宅、需要"每秒不无聊"的纯文戏、用走位代替动作。**不适用/需改造**：需要精确对称美感的仪式/宣传镜头、需要配乐煽情的情节剧高潮、动作可读性优先的商业动作戏、明亮暖调浪漫光题材。

## 一、核心心智模型（8 个镜片 · How the Succession team sees a shot）

### M1 · 调度先于台词（权力由身体位置承载）
先问"这场戏谁上谁下"，再让身体在空间里说出来；权力由**站位/走动/朝向/被挤出画框**承载，不靠台词报出胜负。
- **分镜含义**：设计一场权力戏，先画出人物位移线与相对位置，再写对白。→ 见 §T1/T2/T4。

### M2 · 摄影机是纪录片跟拍者，不是布景师
镜头不预设完美构图，而是"追"正在发生的表演——角色一动就持续 reframe，允许松散、留不规整头顶空间。
- **分镜含义**：不锁机位摆拍。手持微动 + 追着表演 reframe = 临场偷窥感。见 §M6/§T3/F2。

### M3 · zoom 是一种剪辑（用推拉"发现"反应）
长焦 snap zoom 不是运镜装饰，是把观众注意力"切"到该看的脸上——不切镜也能切注意力，等价于一次剪辑点。
- **分镜含义**：想让观众看某人的反应，别切近景——用 zoom 突袭抓瞬间微表情。见 §T5/F3。

### M4 · 空间即筹码（距离/走位=谈判权重）
逼近、后退、退到无路可退、离场——人物间的物理距离与位移是谈判筹码的物理化，空间用尽=筹码用尽。
- **分镜含义**：摊牌戏用"逼近→后退→抵墙/栏杆→转身离场"的走位序列，而非台词升级。见 §T6/F4。

### M5 · 移动者掌控空间（绕行=权力辐射）
在一群静止的人中移动的人掌控话语权；静止者被动转头跟随移动者轨迹=被他牵着走=服从。
- **分镜含义**：谁该主导这场戏 → 让他边说边绕桌/绕房间行走，其余人坐定转头追随。见 §T1/F1。

### M6 · 反完美即真实（松散构图=纪实可信）
故意的不规整（偏置人物、头顶空间不匀、偶被前景虚化物挡一下）是可信度来源，不是失误——"被设计感"会杀死临场偷窥味。
- **分镜含义**：拒绝对称/居中/干净构图。允许"抓拍感缺陷"作为美学。见 §M2/§T7/F2。

### M7 · 冷调自然光让权力自己说话（去浪漫化）
玻璃会议室/游艇/豪宅的去饱和冷青自然光（5600–6500K），拒绝暖调浪漫化——冷峻中立，让权力博弈本身成为焦点。
- **分镜含义**：定光前先去掉一切煽情暖调；冷青商务自然光 = 权力剧默认底色。见 §T8/H12。

### M8 · 无配乐留白（戏中静默放大调度张力）
对话戏中**不铺配乐**（Britell 配乐仅用于片头/转场），只留环境声+人声；张力来自身体调度而非音乐煽动。
- **分镜含义**：权力对话戏静音处理——空调嗡鸣/海风/玻璃混响为底，让走位与沉默做功。见 §M4/H13。

## 二、决策启发式（20 条 if-then · 落到镜头/调度/剪辑）

### A. 调度 / 权力可视化
- **H1** 要宣示某人掌控全场 → 让他边说边绕桌/绕房间行走(步速约 1.0m/s)，其余人坐定被动转头跟随其轨迹；镜头同步横移跟拍。
- **H2** 要表现权力转移 → 用一次走位变化触发（谁起身/谁走近/谁背对/谁离场），而非台词或剪辑（§F1/M1）。
- **H3** 要驱逐/贬低某人 → 让权力者占画面中心/前景/更高位，失势者被构图挤到边缘只剩半肩、微后靠侧身退让。
- **H4** 要孤立某人 → 让其他人全部离场，把他单独留在画框中央，镜头停留不切（被遗弃=孤立）。

### B. 摄影机 / 跟拍
- **H5** 拍对话戏 → 多机手持同拍（主谈机 + 反应机），handheld 持续微动(约 0.3–0.8°/s)，角色一动就 reframe，永不锁机位站桩。
- **H6** 角色行走 → 镜头速度同步其步速跟拍横移(Steadicam/handheld)，保持相对构图稳定、背景滑动。
- **H7** 要临场偷窥感 → 保留手持微抖 + 松散构图，不追求丝滑稳定（丝滑=丢纪实味，§M2/M6）。

### C. zoom / 抓反应
- **H8** 要观众看某人反应 → 长焦 85–200mm 突然 snap zoom-in(约 0.5s)抓其听到关键信息的瞬间微表情，等价一次剪辑。
- **H9** 一句话在多人间引发连锁反应 → 连续多次 snap zoom-in 抓不同人反应(震惊/盘算/窃喜)，每次 1.5–2s，zoom 当剪辑串起反应链。
- **H10** 抓的微表情要"信息在脸上" → 表演克制 30%，权力低者强忍(抿嘴/眼神闪躲/假笑)，外露即失态。

### D. 空间 / 构图 / 光色
- **H11** 摊牌/逼近 → 走位序列 A 逼近(间距 0.6→0.3m)→B 重心后倾退让→B 退到墙/栏杆无路可退→A 转身离场；长焦压缩两脸。
- **H12** 定光 → 玻璃/自然光空间，去饱和冷青 5600–6500K，拒暖调浪漫光（§M7）。
- **H13** 权力对话戏 → 戏中不铺配乐，只留环境声(空调嗡鸣/海风/玻璃混响)+人声，张力靠调度（§M8）。
- **H14** 要抓拍真实感 → 故意留不规整头顶空间、人物偏置、偶尔被前景虚化物挡一下（§M6/F2）。

### E. 剪辑 / 节奏 / 结构
- **H15** 对话戏要"每秒不无聊" → 每个镜头人物站位/走动/朝向都在做功，用调度而非台词/音乐撑张力（§M1）。
- **H16** 想"切"注意力又不想切镜 → 用 zoom 代替剪辑（§M3/H8）。
- **H17** 权力戏收尾 → 用离场走位作句号（撂话+突然转身大步走向画面深处），比台词更狠（§T6/H4）。
- **H18** 多人群戏 → 用相对位置分层（中心/前景=强，边缘/后景/被遮=弱），一个镜头交代全场权力秩序（§T4）。
- **H19** 配乐要出现 → 只放在片头/场景转场(Britell 钢琴+古典+hip-hop)，绝不进对话戏内部（§M8/H13）。
- **H20** 走位假和谐→真对峙 → 先并肩同步走(间距 0.6m 表面平和)，再由一方停下转向进逼打破节奏（§T6）。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 绕行权力判别（谁掌控空间）**
```
移动者(边说边绕行) + 静止众人被动转头跟随其轨迹 → 移动者掌控话语权
铁律：权力辐射靠"一人动、众人头随他转"实现，不靠台词点明。
只允许一个主导移动者；两人同时绕行 = 权力秩序失焦。
```

**F2 · 纪实跟拍 vs 摆拍判别（构图态度）**
```
要"临场偷窥·真实发生" → 手持微动(0.3–0.8°/s) + 持续 reframe + 松散构图(偏置/头顶空间不匀/偶被前景挡)
要"仪式·中立记录"       → 才用固定机位/对称构图（但那已非本剧签名）
铁律：本剧永不锁机位站桩拍对话；一旦对称居中干净 = 丢签名。
```

**F3 · zoom 当剪辑判别（推拉的功能）**
```
zoom 用于"把注意力切到某人反应" → snap zoom-in 0.5s 抓瞬间微表情，等价一次剪辑点
zoom 若只是慢推抒情/美化               → 非本剧用法（本剧 zoom 是抓拍工具，不是运镜装饰）
铁律：信息在脸上不在嘴上——zoom 落点必须是一个可读的微反应。
```

**F4 · 空间即筹码判别（走位序列）**
```
谈判摊牌 → 必须有物理距离变化序列：逼近(间距缩小) / 后退(退让) / 抵墙栏杆(无路可退=筹码用尽) / 离场(宣告)
若两人全程等距不动只升级台词 → 未把权力物理化（非本剧）
铁律：空间用尽 = 筹码用尽；离场 = 权力宣告。
```

**F5 · 无配乐张力判别（戏中声场纪律）**
```
对话/权力戏内部 = 无配乐（仅环境声+人声），张力靠调度
配乐(Britell) 只允许出现在：片头 / 场景转场蒙太奇
铁律：配乐一旦铺进对话戏 = 破坏冷峻纪实纪律，权力博弈被音乐替演。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 绕桌/绕房间权力走位** ｜机制：移动者边说边绕行，静止众人转头跟随=权力辐射｜参数：handheld 跟拍 0.6°/s + 50mm + 移动者步速约 1.0m/s(门口→桌首→桌侧) + 镜头同步横移 + 众人坐定转头追轨迹｜触发：权力宣示/主导全场｜意图：移动者掌控空间=掌控话语权｜正例：继承之战 §场景 A-2 会议室权力绕行。

**T2 · 调度即权力（构图驱逐）** ｜机制：相对位置=权力秩序｜参数：权力者占中心/前景/更高位；失势者被挤到画框边缘只剩半肩、微后靠侧身退让；handheld + 40mm｜触发：权力转移/贬低某人｜意图：不用台词说"我赢了"，用身体位置说｜正例：继承之战 §场景 A-4 被挤出画框。

**T3 · 多机手持纪实跟拍** ｜机制：多机同拍+运动中持续 reframe｜参数：handheld 微动 0.3–0.8°/s + 多机位(主谈+反应)同时拍 + 角色一动镜头跟调 + 留松散头顶空间｜触发：所有对话戏｜意图：真实临场"偷窥正在发生的权力斗争"｜正例：继承之战 §场景 A-1 众人落座微动。

**T4 · 长焦压缩逼近走位** ｜机制：物理距离变化=谈判筹码｜参数：handheld + 75mm 中近景 + A 转向 B 进逼间距 0.6→0.3m + B 重心微后倾(退让信号) + 长焦压缩两脸贴近｜触发：摊牌/逼近｜意图：逼近与后退=筹码物理化｜正例：继承之战 §场景 B-2 甲板逼近。

**T5 · snap zoom 抓反应（zoom 当剪辑）** ｜机制：长焦突袭抓瞬间微表情｜参数：长焦 135mm + snap zoom-in 约 0.5s 抓听到威胁/坏消息的瞬间(抿嘴/眼神闪躲) + handheld 微抖 + 克制 30%强忍｜触发：要观众看某人反应｜意图：信息在脸上不在嘴上，注意力被"切"过去｜正例：继承之战 §场景 A-3 长焦抓反应。

**T6 · 空间用尽=退到无路可退** ｜机制：后退抵物理边界=筹码用尽｜参数：B 后退到甲板栏杆/墙无路可退 + 手扶栏杆(绝境身体语言) + A 正面压迫 + 海平面/空墙背景｜触发：摊牌绝境｜意图：空间用尽=筹码用尽｜正例：继承之战 §场景 B-3 退到栏杆。

**T7 · 反完美松散构图** ｜机制：故意不规整=抓拍可信度｜参数：留不匀头顶空间 + 人物偏置离心 + 偶被前景虚化物挡一下 + 手持微抖｜触发：要纪实真实感｜意图：拒"被设计感"，强化临场偷窥｜正例：继承之战 §场景 A-1（与所有场景通用底色）。

**T8 · 冷调商务自然光** ｜机制：去饱和冷青去浪漫化｜参数：玻璃会议室/游艇/豪宅自然光 + 去饱和冷青 5600–6500K + 无暖调补光｜触发：所有权力空间｜意图：冷峻中立让权力自己说话｜正例：继承之战 §场景 A/B/C 全片底色。

**T9 · 离场走位=权力宣告** ｜机制：突然转身离场作句号｜参数：全景 + A 撂话后突然转身大步走向画面深处(位移：栏杆/桌首→纵深) + B 独自留原地 + 镜头停留其孤立｜触发：权力戏收尾/羞辱｜意图：离场比台词更狠=权力宣告 + 被留者孤立｜正例：继承之战 §场景 B-4 转身离场。

**T10 · zoom 反应链（多人连锁）** ｜机制：连续 zoom 串起一桌人反应｜参数：宣布者主谈位画面一侧平静抛消息(其余焦外) + 长焦 135mm 连续多次 snap zoom-in 抓不同人反应(震惊/盘算/窃喜) 各 1.5–2s + handheld 微抖｜触发：一句话在多人间炸开｜意图：信息扩散的连锁微反应｜正例：继承之战 §场景 C-2~C-4 反应链（C-1 宣布者=信息源）。

## 七、禁忌清单（❌ 继承之战式分镜绝不做的事）

- ❌ **固定机位站桩拍对话**——本剧永远手持跟拍 + 持续 reframe（§F2/M2）。
