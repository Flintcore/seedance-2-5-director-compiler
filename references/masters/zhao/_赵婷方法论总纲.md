## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：赵婷×Richards 的分镜系统 = **"用自然光的短暂窗口与荒野的巨大尺度，把克制的情绪外化成可测的影像"**，六根支柱。① **magic hour 抢拍**（日出/日落暖侧逆 5500→3200K · 拒棚光 · 只用天光/篝火/车头灯 · 暗部任其压暗）= 温暖而短暂的慰藉。② **人渺小化铁律**（14-35mm 广角 + 大远景 · 人/车占比 <8% 贴画面边 · 公路灭点纵深）= 人在天地/时代前的渺小。③ **克制置换**（判别铁律）：高潮处**反而**用动作/空镜/凝视代替台词宣泄 + 配乐在情绪高点**退场**到自然声——哀而不伤。④ **手持贴身跟随**（半步之遥呼吸感 · 不甩不快摇不炫技 · 游移到手/物/远景）= 纪录式亲密在场。⑤ **素人本色**（真实人物用真名讲真实经历 · 不化妆不柔焦 · 职业演员藏进真实社群即兴）= 半纪录可信度与尊严。⑥ **情绪压进日常动作**（刷碗/修车/握方向盘承载内心 · 非表情外放）。母题→镜头：告别→"不告别"（点头+浅微笑代落泪）；孤独→极远景剪影 + Einaudi 极简钢琴只在过场浮起。

**适用情境**：现实主义/公路/游牧迁徙/当代西部荒野/自然光美学/素人纪录质感/孤独告别/劳动者/哀而不伤。**不适用/需改造**：需强戏剧冲突与情节反转的类型片、需棚光可控光比的商业广告/时尚、需明星美颜柔焦、需煽情催泪配乐、室内高调打光戏。

## 一、核心心智模型（8 个镜片 · How Zhao/Richards sees a shot）

### M1 · 光是被"抢"的，不是被"造"的
不打棚光、不补硬光；每天只抢 magic hour（日出/日落前后）的短暂自然光窗口，暗部任其压暗、不强行提亮面孔。光是天时，剧组围着光排戏，不是围着戏造光。
- **分镜含义**：先问"这场戏在一天的哪个光里"，再摆调度。→ magic hour = 默认情绪光（§T1）。夜戏用现场光源（篝火/车头灯/加油站灯）当唯一光（§T7）。

### M2 · 空间大 → 人小 → 情绪出（尺度即情感）
情绪不靠面部特写喊，靠人与荒野的尺度对比外化。人越小、天地越大，孤独/渺小/坚持越强。
- **分镜含义**：想表达渺小/自由/孤独 → 拉极远景把人压成占比 <8% 的点、贴画面边（§F2/T2），而非推近脸。

### M3 · 克制置换（该煽情处沉默）
情感高潮点**反向操作**：不给宣泄的台词/哭嚎/配乐轰鸣，而是用日常动作、空镜、凝视、留白承接。悲伤是底色不是表演。
- **分镜含义**：识别"这里传统会煽情" → 改上克制置换（动作/空镜/沉默），配乐在此**退场**到自然声（§F3/M6）。判别见 §F3。

### M4 · 摄影机与人同呼吸（贴身而不侵入）
手持半步之遥跟随真实动作的自然节奏，轻微晃动是"在场"不是"炫技"；跟随中允许游移到手、物件、远景等环境细节。
- **分镜含义**：日常/劳动/独处 → 手持贴身跟随（§T4），运动质感来自人物动作而非镜头设计；禁甩镜/快摇。见 §M8。

### M5 · 被拍者自己说话（素人本色 · 不消费苦难）
真实人物用真名、讲自己活过的经历，面孔不化妆、保留风霜；职业演员藏进真实社群做即兴互动。可信度来自"这是真的"，尊严来自"让他自己说"。
- **分镜含义**：群像/社群/底层题材 → 用素人本色（§T5），自然光下不美颜不柔焦；机位平视、不俯视审判。

### M6 · 配乐是留白工具，不是情绪扩音器
Einaudi 极简钢琴（单一动机、缓慢、不铺满）只在过场/公路/独处浮起；情绪高点**反而退到自然声**（风/篝火/发电机/引擎）。
- **分镜含义**：定一段的声音前先定"这里该响还是该静"——高潮多选静（§M3/M6 联动）。钢琴用作 Sound Bridge 过场（§T10）。

### M7 · 情绪压进日常动作（物化的内心）
内心状态由具体劳动动作承载：刷碗、修轮胎、整理车厢、独自吃饭、握方向盘。动作可信、有尊严，替代台词/表情外放。
- **分镜含义**：内省/孤独/克制段落 → 给一个具体动作做载体（§T6），拍动作细节（手/物）而非拍脸表演。

### M8 · 路与地平线是叙事结构（不是背景）
公路灭点、地平线剪影、天地各半的构图不是取景花样，是把"在路上/无尽/迁徙"物理化。房车是流动的"家"母题。
- **分镜含义**：迁徙/出发/未完 → 用公路灭点纵深 + 人/车贴地平线剪影（§T8/T9），出发即上路、不作大团圆收束。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 自然光 / 色彩
- **H1** 要"温暖而短暂的慰藉" → magic hour 抢拍：日出/日落前后暖侧逆光 5500K（晨）→3200K（暮）+ 长投影 + 低角度阳光 + 允许 lens flare；暗部压暗不补。
- **H2** 夜戏 → 只用现场光源当唯一光（篝火暖橙 2000-2200K 自下往上 / 车头灯 / 加油站灯 / 路灯），背景近全黑，**不打棚光补脸**。
- **H3** 要冷暖情绪坐标 → 受光暖金面（岩壁/车身/发丝金边）对沟壑深蓝阴影；清晨用 5500K 冷暖交界，黄昏用 3200K 暖沉。

### B. 尺度 / 构图（人渺小化）
- **H4** 要渺小/自由/孤独/坚持 → 14-35mm 广角大远景/极远景，人或车占比 <8% 是地景里的点，贴画面边或压在画面下 1/3。
- **H5** 要"永恒面前失去变小" → 巨大地貌（岩壁/山）占满后景压在人头顶，人居画面下三分之一仰望。
- **H6**（铁律）要辽阔感时**少用长焦压缩**，用广角强调纵深与空旷；长焦只留给篝火近景浅景深抠面孔（§F2）。

### C. 运镜 / 跟随
- **H7** 日常/劳动/独处/进出车厢 → 手持贴身跟随，半步之遥（距主体 1.2-2m），呼吸感轻晃随步伐，**不甩不快摇**。
- **H8** 凝视/停驻/敬畏 → 手持几乎静止 + 极缓推近（≈0.05 m/s），几乎不可察觉的运动。
- **H9** 荒野极远景 → 手持极缓微移/几乎静止凝视 + 偶尔游移到炊烟/草浪等自然细节。
- **H10** 空镜收束 → 手持极缓微移 + 极轻升降，人出画/车驶远后镜头滞留看天地。

### D. 克制 / 情绪
- **H11** 传统会煽情处（告别/丧亲/独处崩溃）→ 克制置换：用日常动作/空镜/凝视代替台词宣泄，配乐退场到自然声。
- **H12** 告别 → "不告别的告别"：不拥抱不落泪，点头 + 浅淡微笑 + 一句轻描淡写的话（如"路上见"），克制 30%。
- **H13** 丧亲/失去 → 不哭嚎，用仰望 + 深呼吸 + 抚过自然（岩石/草）+ 出神代替，敬畏非悲伤。
- **H14** 内心戏 → 把情绪压进一个具体劳动动作（刷碗/修车/握方向盘/整理），拍动作细节（手/物）不拍表演脸。

### E. 素人 / 声音 / 母题
- **H15** 社群/群像/底层 → 素人本色出演：真名 + 真实经历 + 不化妆保留风霜 + 平视机位不俯审，职业演员藏进真人即兴。
- **H16** 素人念白 → deadpan-克制 30%，平静诚恳、有停顿口语、非戏剧化，自然光下不柔焦。
- **H17** 过场/公路/独处 → Einaudi 极简钢琴单一动机缓慢浮起；情绪高点**退到**风/篝火/引擎自然声。
- **H18** 转场 → 公路行驶/空镜 + Einaudi 钢琴 Sound Bridge + 日常动作硬切，**不做戏剧化转场**。
- **H19** 迁徙/出发 → 公路灭点纵深 + 房车/人贴地平线剪影驶向灭点，出发即"又一次上路"不作团圆收束。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · magic-hour 自然光判别（是不是赵婷式的光）**
```
光 = magic hour 抢拍暖侧逆(5500晨→3200暮) + 长投影 + 暗部压暗不补 + 现场光源(天光/篝火/车头灯) → 赵婷式
光 = 棚光/硬光补脸 / 均匀高调 / 明星美颜柔焦 / 拉高整体亮度  → NOT 赵婷式（破坏纪实诗意）
铁律：暗部任其黑、面孔任其半明半暗，不为"好看"提亮。
```

**F2 · 广角人渺小 vs 长焦近景判别（尺度分工）**
```
要辽阔/渺小/孤独/迁徙 → 14-35mm 广角大远景，人占比 <8% 贴画面边，公路灭点纵深
要面孔/篝火/聆听的亲密 → 50mm 浅景深近景，半脸火光，风霜不柔焦
铁律：辽阔段少用长焦压缩（会丢空旷感）；两者分工不混淆。恶地极远景=广角派 / 篝火聆听=长焦近景派。
```

**F3 · 克制置换判别（该不该煽情）**
```
此处传统类型片会"上台词宣泄 + 配乐轰鸣 + 面部大特写哭戏" → 赵婷式一律反向：
  → 改用【日常动作 / 空镜 / 凝视深呼吸 / 沉默留白】承接
  → 配乐在此【退场】到自然声（风/篝火/引擎）
判据：若一个镜头靠台词或哭嚎才成立 = 不是赵婷式；靠动作/环境/微表情成立 = 赵婷式。
```

**F4 · 素人本色判别（可信度纪律）**
```
真实人物 → 用真名 + 讲自己真实经历 + 不化妆保留风霜 + 平视不俯审 + 即兴口语有停顿
职业演员 → 藏进真实社群、去表演化、自然光不柔焦
红线：不把被拍者拍成"可怜的样本"（俯视/煽情/卖惨）= 破坏尊严纪律。
```

**F5 · 人渺小占比判别（构图强度）**
```
人占比 > 15%   → 尺度感不足（只是普通远景）
人占比 8–15%   → 渺小感初现
人占比 < 8%（推荐）→ 强渺小：人是地景里的点，贴画面边 / 压画面下 1/3
配合：低/高水平线压人 + 公路灭点 + 巨大地貌占后景压头顶。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · magic-hour 抢拍暖侧逆** ｜机制：只用日出/日落短暂自然光窗口，不造光｜参数：暖侧逆光 5500K(晨)→3200K(暮)+长投影+低角度阳光+暗部压暗不补+偶有 lens flare｜触发：任何要"真实却诗意"的外景／慰藉时刻｜意图：辽阔天地里一束温暖而短暂的光、孤独中的诗意｜正例：无依之地 §场景 B 恶地晨金侧逆（B-1/B-2）、§场景 C 房车驶公路暮金（C-3）。

**T2 · 广角人渺小化** ｜机制：广角大远景把人压成地景里的点｜参数：14-35mm+大远景/极远景+人或车占比 <8%+贴画面边或压画面下 1/3+低/高水平线压人｜触发：渺小/自由/孤独/迁徙｜意图：人在自然与时代洪流中的渺小，自由与孤独同体｜正例：无依之地 §B-1 恶地岩脊小点(<5%)、§C-3 房车驶向灭点。

**T3 · 巨物压顶仰望** ｜机制：巨大地貌占满后景压在人头顶｜参数：50mm/中景+岩壁/山占满后景+人居画面下 1/3 仰望+magic hour 暖金侧光｜触发：永恒面前失去变小/敬畏｜意图：把个人失去放进地质尺度而消解｜正例：无依之地 §B-3 岩壁前凝视停驻。

**T4 · 手持贴身跟随** ｜机制：半步之遥跟随真实动作的呼吸感手持｜参数：距主体 1.2-2m+35mm/f2.8+呼吸感轻晃随步伐+背景虚化流动+不甩不快摇+游移到手/物/远景｜触发：日常/劳动/独处/进出车厢｜意图：与人物同呼吸的纪录式亲密在场｜正例：无依之地 §B-2 荒野跟随行走、§C-2 上车动作跟拍。

**T5 · 素人本色出演** ｜机制：真实人物演自己+职业演员藏进真人社群｜参数：真名+真实经历+不化妆保留风霜+平视机位不俯审+即兴口语有停顿+自然光不柔焦+deadpan-克制 30%｜触发：社群/群像/底层/劳动者｜意图：半纪录可信度与尊严，不消费苦难｜正例：无依之地 §A-2 Bob Wells 篝火布道本色出演。

**T6 · 情绪压进日常动作** ｜机制：具体劳动动作承载内心，替代台词/表情｜参数：刷碗/修轮胎/整理车厢/握方向盘/上车关门+拍动作细节(手/物)不拍表演脸+克制 35%｜触发：内省/孤独/克制的关键情绪点｜意图：可信有尊严的内在情绪｜正例：无依之地 §C-2 利落上车握方向盘把情绪压进动作。

**T7 · 现场光源夜戏** ｜机制：夜戏只用画面内现场光源，不打棚光｜参数：篝火暖橙 2000-2200K 自下往上+面部摇曳火光+背景近全黑+火星飞溅+车头灯/加油站灯/路灯｜触发：夜/营地/社群取暖｜意图：现场光=情绪与真实质感，非照明｜正例：无依之地 §A-2/A-3 篝火夜围坐、§A-4 火星升向星空。

**T8 · 公路灭点纵深** ｜机制：笔直公路灭点把"在路上/无尽"物理化｜参数：24-35mm+笔直公路向灭点延展+天地各半+房车/人贴路边或驶向灭点｜触发：迁徙/出发/在路上母题｜意图：路即无尽、家在轮子上｜正例：无依之地 §B-4 公路尽头车与人、§C-3 房车驶上公路远去。

**T9 · 克制置换（不告别/空镜代结语）** ｜机制：情感高潮反向用动作/空镜/凝视代替宣泄｜参数：告别不拥抱不落泪+点头+浅淡微笑+轻描淡写台词；或人出画/车驶远后空镜滞留+自然声；配乐退场｜触发：告别/丧亲/独处高潮｜意图：哀而不伤、尊严而非可怜｜正例：无依之地 §C-1 "See you down the road" 不告别、§C-4 荒原最后空镜。

**T10 · Einaudi 极简钢琴 Sound Bridge** ｜机制：极简钢琴只在过场/公路/独处浮起，情绪高点退到自然声｜参数：单一钢琴动机缓慢不铺满+公路行驶/空镜时浮起做 Sound Bridge 过场+高潮退到风/篝火/引擎｜触发：过场/公路/独处/收束｜意图：克制的温柔、不催泪｜正例：无依之地 §C-3 房车远去钢琴浮起、§C-4 空镜钢琴尾音。
