# 维伦纽瓦方法论总纲（Denis Villeneuve · 跨作品方法论 · 非单片）

> **性质**：导演级「方法论总纲」——把散落在库内两部逐镜（`降临.md` / `银翼杀手2049.md`）与一手调研（British Cinematographer / No Film School / ARRI Rental / frame.io / rogerdeakins.com / Hazlitt / premiumbeat / StudioBinder / Neil Oseman）中的**可复现硬参数**收拢成一张跨片调用图。
> **合作 DP 谱系**：Bradford Young（《降临》）· Roger Deakins（《银翼杀手2049》· 奥斯卡）· Greig Fraser（《沙丘》1/2）。三人手法各异，但都服从维伦纽瓦的**同一套构图/运镜/节奏心智**——本纲提炼的是**导演层不变量**，DP 层差异在技法卡片里分列。
> **反伪造声明**：对称/长镜/IMAX/bleach-bypass/红外拍摄/单光源入黑/frame-within-frame 均**非维伦纽瓦或其 DP 发明**——本纲一律写「标志性运用/集大成」，不写「首创」。引文无一手出处者标〔存疑〕；参数无 DP/colorist 一手数字者标〔推断〕。
> **库内交叉引用锚点**：`降临.md`（安静·情感·容器构图·母性凝视）↔ `银翼杀手2049.md`（巨构·霓虹·单色·疏离凝视）。二者是维伦纽瓦光谱的**两极**：情感极 vs 体制极。《沙丘》调研数据在本纲用于补第三极（**自然/尺度极**），但库内暂无逐镜，凡引《沙丘》均注明"调研转述、库内待建"。

## 索引摘要（≤300 字 · 快速匹配 · 不替代实读）

维伦纽瓦 = **「让人类在不可理解的他者面前渺小、安静、被框住」**。六条跨片不变量：① **巨构渺小化**——主体占画幅 ≤8%（BR2049）/ ≤5%（降临飞船内壁），大画幅（ALEXA 65/XT/Mini LF）+ 宽画幅（IMAX 1.43 或 2.39）打底。② **负空间/极简**——主体贴边或居中，负空间 ≥70%，清空四角（Fraser 铁律），Deakins「敢让画面其余入黑」。③ **单色调环境**——一场一主色相，杀死天空蓝（Fraser：天不蓝、石不红、沙不金），大气用 haze 当深度计。④ **缓慢庄严运镜**——dolly 0.03–0.08 m/s，locked-off ≥6–8s，"若动必有由"（Deakins），反炫技。⑤ **雾/haze 几乎每场**——volumetric fog/dust 兼作硬光柔化器。⑥ **去饱和安静科幻**——低频 30–80Hz drone + 对白 ≤30% + 表演克制 20–50%（面无表情下暗涌）。匹配情境：安静科幻/巨构/母性/沟通隔阂/反乌托邦/顿悟。**决定用哪一极**：情感私密→引降临；体制巨构霓虹→引 2049；自然尺度→用沙丘调研（库内待建）。

## 一、核心心智模型（8 个 · 名称 + 定义 + 出处原话/来源 + 分镜含义）

### M1 · 「他者渺小化」The Sublime Other（尺度不是炫技，是压迫）
- **定义**：环境（飞船/建筑/雕像/沙丘/深空）被拍成**不可理解、超越人类的他者**；人不是主角而是尺度参照物，占画幅极小。
- **来源**：BR2049「用建筑硬几何造 frame within frame，主角被压得越发渺小」〔转述, StudioBinder〕；Fraser「65mm 移除限制」〔原话, No Film School〕。库内锚点：`银翼杀手2049.md` 指纹 2「人占画面 ≤8%」；`降临.md` 镜 B-3「飞船内壁占 80% · 人占 5%」。
- **分镜含义**：只要出现巨物，先问"要它像他者还是像布景？"要像他者 → 人 ≤8%、大画幅、宽画幅、雾做深度。

### M2 · 「一场一色」Monochrome-Per-Scene（色彩即空间，不是装饰）
- **定义**：整场向**单一主色相**弯曲（阴影/高光/皮肤/天空全部染同一色），无叙事理由不给互补色。
- **来源**：Deakins「色彩总是有理由的……我不用色彩来好看」〔原话〕；Fraser「我们的天不蓝、石不红、沙不金」〔原话〕。库内锚点：`银翼杀手2049.md` 指纹 3（橙黄/冷蓝/灰白/暗红各自成场）。
- **分镜含义**：镜头表达 的色彩字段**只写一个主色相 HSV**；第二个抢戏色 = 违规。判别见公式 F2。

### M3 · 「敢让其余入黑」Courage of the Single Source（负空间是纯黑或纯单色，不是浑浊灰）
- **定义**：软光只擦过脸/物体边缘一条，其余不补光，负空间 = 死黑或单一 HSV 雾，绝不浑浊发灰。
- **来源**：Deakins「有勇气依赖单一光源、让画面其余入黑」（"courage to rely on a single source and let the rest of the frame go black"）〔转述, British Cinematographer〕。库内锚点：`银翼杀手2049.md` 镜 A-3「侧光勾轮廓 + 暗部 + 负空间」。
- **分镜含义**：负空间发灰 → 减补光/加旗板，逼它到纯黑或单 HSV。见公式 F3。

### M4 · 「简化画框·清空四角」Clean the Corners（信息点唯一）
- **定义**：画框四角不留可停留的信息；用布光压暗边缘，只留中央/贴边一个主体信息点。
- **来源**：Fraser「你不会想让观众在画框角落停留太久……我尽量把画面简化，布光也一样简化」〔原话, frame.io/premiumbeat 摘要〕。库内锚点：`降临.md` 指纹 2「窗户作前景框 + 主体被框」。
- **分镜含义**：镜头表达 描述 ≤2 个信息点（1 主体 + 1 框/引导线），四角 empty/dark。

### M5 · 「若动必有由」Motion Must Be Motivated（举证责任在"为何动"）
- **定义**：默认静止（locked-off tableau）；只有**视角改变**或**揭示新信息**才允许运动，且慢到几乎不可觉。
- **来源**：Deakins「若摄影机移动，必须有理由」（"If the camera moves it's got to be for a reason"）〔原话, Hazlitt〕；「去看布列松！他找不到移动的理由就不动，我们凭什么动？」〔原话〕。库内锚点：`降临.md` 指纹 4「dolly 0.03–0.08 m/s + locked-off ≥6s」；`银翼杀手2049.md` 指纹 5「极缓 0.03–0.08 m/s」。
- **分镜含义**：写运镜前先填"动机"字段；填不出 → 改 locked-off。见启发式 H8/H9、公式 F4。

### M6 · 「大气即深度计」Atmosphere as Depth Gauge（雾/haze 是尺度与柔光的双重工具）
- **定义**：雾/尘/霾几乎渗入每一场，既给巨物**层叠纵深**（越远越淡），又当**硬光柔化器**降饱和。
- **分镜含义**：几乎每个户外/巨构镜的 镜头表达 必带 `volumetric fog / atmospheric haze / drifting dust`；越想显大越加雾。

### M7 · 「庄严→纪实解体弧」Formal-to-Documentary Arc（运镜承载控制权流失）
- **定义**：影片/段落**开场庄严锁死**（三脚架、对称、tableau），随角色世界失控**逐步松绑到手持**——运镜本身叙事。
- **来源**：Villeneuve〔原话〕开场"more formal, classical look… very solid tableaus"，随剧情"camera left the tripod… became like a documentary… much more handheld"；"As Paul's world gets stripped away, the camera gets freer"〔转述, Cinematography World〕。
- **分镜含义**：判断此刻角色是"掌控/受仪式约束"还是"被剥离/失控"，前者 T1/T2 锁死，后者才 handheld。降临镜 B-2 已用 micro-jitter 0.5° 做轻度松绑。

### M8 · 「摄影是欧米伽不是阿尔法」Cinematography as Omega（越大场面越克制）
- **定义**：摄影是**收尾**而非起手；题材本身已极端时，炫技只会暴露其不可能，故最大场面反而最克制。
- **来源**：Fraser「cinematography = the omega, not the alpha」；题材极端时"showy camerawork might just have highlighted the impossibility"〔转述, frame.io〕。库内锚点：`银翼杀手2049.md` 巨构场全用极缓/锁定，无炫技运镜。
- **分镜含义**：场面越大 → 运镜越简（locked-off 或 0.05 m/s 单推），把张力交给尺度+雾+声，不交给运镜花活。

## 二、决策启发式（if-then · ≥18 条 · 分类）

### A｜尺度与构图
- **H1** IF 要表达"环境是不可理解的他者（飞船/异物/深空）" → THEN 广角（28mm 级）贴近人物置于巨物脚下，广角畸变让巨物在画框边缘拉伸压顶〔降临 90% 用 28/35mm, British Cinematographer〕。
- **H2** IF 要表达"大地/沙漠本身是角色、层叠纵深压迫" → THEN 长焦压缩（58–135mm）把远景巨物"拉近"贴到人物背后包夹〔沙丘 2 人物戏 58/85/135mm, ARRI Rental；库内待建〕。
- **H3** IF 要表达"人被冷酷几何/权力建筑碾压" → THEN 建筑硬边做 frame-within-frame，主体缩到框内一点，规则对称 + 留白〔BR2049, StudioBinder〕。
- **H4** IF 想表达"个体渺小/被吞没" → THEN 主体占画幅高 ≤1/3、负空间 ≥70%、主体只留剪影不打光〔降临/2049 通例〕。
- **H5** IF 画框四角有杂物/纹理抢戏 → THEN 清空四角、布光压暗边缘，只留 1 主体 + 1 框（M4）。
- **H6** IF 巨物需要"显得更大" → THEN 加雾（越远越淡）+ 降机位/仰拍，而非拉更广或加更多元素（M6）。

### B｜色彩与光
- **H7** IF 一场戏 → THEN 只定一个主色相，阴影/高光/皮肤/天空全弯向它，无叙事理由禁互补色（M2）。
- **H8** IF 主角地点要"异质/敌意" → THEN 剥掉天空蓝（吹成纸白或场景色）+ 硬太阳单光源，绝不软金黄时刻〔沙丘, frame.io〕。
- **H9** IF 一片里两地点 → THEN 各给一个对立单色相（Vegas 橙 ↔ LA 冷蓝），场内绝不混〔BR2049〕。
- **H10** IF 要暖空气又怕发浑 → THEN 灯打**绿**、镜前加暖/琥珀滤镜（绿+琥珀抵消成黄），不要琥珀灯配琥珀滤镜〔Vegas, 原话〕。
- **H11** IF 负空间发灰浑浊 → THEN 减补光/加旗板，逼到纯黑或单一 HSV（M3）。
- **H12** IF 要去饱和 → THEN 优先 bleach-bypass/胶片输出颗粒（吹白天空、留纹理），而非平板数字降饱和〔沙丘, 原话〕。
- **H13** IF 场景有霓虹（2049 类） → THEN 霓虹只作主色调内的克制点缀，绝不让它打破单色（M2）。

### C｜运镜与节奏
- **H14** IF 本镜无"视角转移"且无"新信息揭示" → THEN 不给运动，locked-off，故意超长持有攒张力（M5）。
- **H15** IF 角色视角改变 OR 需揭示新信息 → THEN 才允许 push/move，且慢到"货运列车"级（0.03–0.08 m/s）、禁手持/禁 steadicam 抖动。
- **H16** IF 严肃/仪式/对峙场景 → THEN 强制水平找平 + 近对称（Deakins 黄房"camera was level"）〔原话〕。
- **H17** IF 角色处于"掌控/受仪式约束" → THEN T1/T2 锁死庄严；IF 角色世界被剥离/失控 → THEN 逐步松绑到手持（M7）。
- **H18** IF 场面越大/题材越极端 → THEN 运镜越简（locked-off 或单一 0.05 m/s 推），把张力交给尺度+雾+声（M8）。
- **H19** IF 想加任何"装饰性"运镜（甩、旋、炫 crane） → THEN 删（Deakins「我对炫耀式运镜和多余移动有意见」）〔原话〕。

### D｜表演与声音
- **H20** IF 重大情感（失去/顿悟/崩溃） → THEN 用 ≤2mm 微表情 + 时差 + 闭眼 + 单泪，绝不大哭大喊（降临克制 30–50% / 2049 克制 20–40%）。
- **H21** IF 科幻/庄严场 → THEN 对白 ≤30%、静默 ≥40%、铺 30–80Hz 低频 drone 给身体压迫，反"配乐填满"。
- **H22** IF 前中景可实拍 → THEN 机内完成，勿全交 VFX（Deakins「前中景尽量 in-camera」）〔原话〕；单机位精摆，非多机广撒〔Deakins 拒二组, IndieWire〕。

```text
# F3 · 负空间纯净度判别
negative_space_ok(frame):
    ns_ratio  = 负空间占画幅比例
    ns_purity = 负空间是否 (纯黑 OR 单一HSV)   # 非浑浊灰
    subject_pct = 主体占画幅比例
    if ns_ratio < 0.70:              return "加大留白 / 主体贴边"
    if ns_purity == False:           return "减补光+旗板 → 纯黑或单HSV (M3)"
    if subject_pct > 0.33:           return "推远/换广角 → 主体≤1/3 (H4)"
    if 巨构渺小场 and subject_pct>0.08: return "人再缩小 (M1)"
    return OK
```

## 四、技法卡片（10 张 · 五件套：机制 + 参数 + 触发 + 情感意图 + 正例）

### 卡01 · 广角贴脚·他者压顶（Wide-at-the-Base）
- **机制**：广角贴近人物立于巨物脚下，畸变让巨物在边缘拉伸压顶。
- **参数**：28mm（Ultra Prime）/ 35mm（Super Speed）· 低眼平或略仰 · f/8 深景深 · 球面 · 重 volumetric fog。
- **触发**：H1（他者/飞船/深空）。
- **情感意图**：人类面对不可理解他者的渺小但勇敢。
- **正例**：`降临.md` 镜 B-3（仰角 80° · 24mm f/4 · 极慢 crane 0.05 m/s · 内壁占 80% · 人占 5%）；镜 B-1 飞船远景（35mm f/8 · 200m · locked-off 12s · 占 30% · 严重 haze）。

### 卡02 · 长焦压缩·大地包夹（Telephoto Compression）
- **机制**：长焦压缩景深，把远处巨物"拉近"贴到人物背后，多层地景叠压。
- **参数**：58/85/135mm（沙丘 2；Part One 55/75mm）· IMAX 1.43 高画幅 · heat-haze + drifting sand · 暖沙 HSV≈H35 S40 V70〔推断〕。
- **触发**：H2（大地/沙漠层叠纵深）。
- **情感意图**：大地本身是角色，人被巨物包夹。
- **正例**：沙丘 2 人物戏改 58/85/135mm"更强烈"、长焦"压缩背景让地景更贴近人物"〔ARRI Rental / theASC 转述；**库内暂无逐镜，待建**〕。可暂参 `银翼杀手2049.md` 镜 B-3（50mm f/2.8 废墟对峙 · 尘光束）迁移压缩感。

### 卡03 · frame-within-frame·建筑碾压（Architectural Frame）
- **机制**：建筑硬几何做画中画，主体缩到内框一点，规则对称 + 留白。
- **参数**：Master Prime 常规焦段 · 2.39:1 · ALEXA XT Studio · 对称机位 + 水平找平 · 主体 ≤8%。
- **触发**：H3（权力建筑碾压）。
- **情感意图**：个体在体制/权力前渺小孤独。
- **正例**：`银翼杀手2049.md` 镜 A-3（35mm f/2.8 · 极简对称 + 大量负空间 + 侧光勾边 · 克制 25%）；镜 B-2（24mm f/8 仰角 · 巨型残破雕像俯视渺小人）。

### 卡04 · 主体贴边·巨型留白（Edge Subject + Void）
- **机制**：主体压到画框左/右 1/6–1/5 或边缘线，4/5–5/6 留给空场（雾墙/混凝土/沙漠）。
- **参数**：2.39:1（2049）/ IMAX 1.43（沙丘）· 主体占高 ≤1/3 · 背光成剪影 · 负空间 ≥70–80%。
- **触发**：H4（个体渺小/被吞没）。
- **情感意图**：孤独 / 被环境吞没。
- **正例**：`银翼杀手2049.md` 镜 B-4（35mm f/8 · 两人橙黄霾中成剪影 · 大量负空间）；Sapper 农场开场 K 剪影贴边混凝土巨墙〔转述〕。

### 卡05 · 单光源入黑·负空间纯净（Single Source, Rest Black）
- **机制**：软光只擦边缘一条，其余不补，负空间 = 死黑或单 HSV 雾。
- **参数**：主光单源侧/逆 · 无补光 · 旗板压边 · 负空间纯黑或单相；Wallace 办公室 256×Arri 300W Fresnel 排两同心圆"宽度换柔光"〔转述, premiumbeat〕。
- **触发**：M3 / H11（负空间发灰时）。
- **情感意图**：庄严孤独，光作雕塑。
- **正例**：`银翼杀手2049.md` 镜 A-3 侧光勾轮廓 + 暗部；`降临.md` 镜 A-4（85mm f/1.4 · 暗部 50% · 仅颧骨与泪光高光）。

### 卡06 · 极缓 creeping dolly（Imperceptible Push）
- **机制**：慢到观众几乎不觉的 track/dolly/crane 推，让画框"呼吸"。
- **参数**：0.03–0.08 m/s · locked-off 段 ≥6–8s · 14ft 分段 jib + Power Pod 遥控头（Deakins BR2049）· 禁手持/禁 steadicam 抖。
- **触发**：H15（视角改变 OR 揭示新信息）。
- **情感意图**：时间凝固 / 缓慢接近真相。
- **正例**：`降临.md` 镜 B-4（dolly 极慢推 0.05 m/s · 7s · 玻璃前景七肢桶）；`银翼杀手2049.md` 镜 A-1（极缓 dolly 0.05 m/s 雨夜街道）；Sicario 边境车队 push-in 匹配车队推进〔转述〕。

### 卡07 · 庄严静态 tableau（默认基态）
- **机制**：三脚架锁死、眼平或略仰、水平严格找平、近对称、主体压小、超长持有。
- **参数**：中长焦主拍 · 2.39 spherical（2049）/ IMAX 1.43（沙丘）· locked-off ≥6–12s。
- **触发**：H14（无视角转移且无新信息）/ H16（仪式/对峙 → 强制水平）。
- **情感意图**：庄严静默 / 孤独渺小。
- **正例**：`降临.md` 镜 B-1（35mm f/8 locked-off 12s）；`银翼杀手2049.md` 镜 B-1（28mm f/8 locked-off 橙黄全景）；Sicario 士兵剪影没入橙色夕阳超长静态攒张力〔转述〕。

### 卡08 · 单色雾环境·杀死天空蓝（Monochrome Haze）
- **机制**：全场向单一主色相弯曲，天空吹白或染场景色，空气填雾再打光出光轴。
- **参数**：**橙红场（Vegas）** 镜前定制暖包（Lee 790 Moroccan Pink + 105 Orange + 134 Golden Amber + 020 Medium Amber）+ 侧面 Maxi-Brute 打绿 + Black Pro-Mist 1/8；目标 HSV H15–30 S55–75 V中、低反差。**沙场（Arrakis）** bleach-bypass + 滤镜切蓝绿留红 + LUT"去天空蓝"；黑地板抬升、饱和降 40–60%、天空吹纸白〔以上原话+转述〕。**冷蓝场（LA）** H200–215 S15–30 V低中、重雾、Pro-Mist 低反差〔转述〕。
- **触发**：H7–H9（一场一色 / 两地对立 / 异质敌意）。
- **情感意图**：色彩即情绪空间，沉浸单色世界。
- **正例**：`银翼杀手2049.md` 镜 B-1（橙黄单色 #C8822E 沙尘弥漫）、镜 A-1（蓝粉紫 #2A4A6B/#C8508C 湿街）；`降临.md` 指纹 1（去饱和雾灰 #6B7B8B）。

### 卡09 · 硬太阳单光源·非黄金时刻（Hard Sun as Weapon）
- **机制**：单一硬光当"太阳"，锐利光轴，无软补，太阳"powerful and abrasive, not beautiful"。
- **参数**：42× Aputure LS 1200d 当一个"太阳"（沙丘）· 硬边光轴 · 无软 fill〔原话；无 Kelvin/diffusion 公布, 存疑〕；对比"等黄金时刻不打灯"（Dune 日外景 Fraser"just waited for dawn and dusk"）〔原话〕——二者按"敌意 vs 自然"择一。
- **触发**：H8（地点要异质/敌意 → 硬太阳）；反之自然场 → 等黄金时刻。
- **情感意图**：敌意/严酷（硬光）或自然庄严（黄金时刻）。
- **正例**：沙丘 Arrakis 硬光单源〔原话；库内待建〕；`银翼杀手2049.md` 镜 B-3 橙黄光透尘尘光束（迁移硬光轴感）。

### 卡10 · 容器/玻璃构图·镜面分裂（Containment / Mirror-Split）
- **机制**：玻璃/窗/隔板/外壳作前景框，主体被"框"在内；玻璃反光叠加主体倒影 = 镜面分裂。
- **参数**：玻璃反光占 20–30% 画幅 · 主体在玻璃后雾中隐约（掩盖 ≥60%）· 5600K 反光偶生 lens flare · 50mm f/2.8。
- **触发**：M4 / 沟通隔阂/隔绝主题。
- **情感意图**：隔绝 / 沟通的不可能 / 虚实并置。
- **正例**：`降临.md` 镜 B-4（玻璃墙前景 + 七肢桶雾后隐约 + Louise 反射玻璃上镜面分裂）、指纹 2（80% 镜有窗/玻璃/隔板）；`银翼杀手2049.md` 镜 C-2（Joi 全息叠合真人半透叠层 = 虚实版容器）。

## 七、禁忌 ❌（跨片一律违规）

- ❌ **主角占满画面/正面平视看镜头**——破坏巨构渺小化与容器构图（M1/卡10）。
- ❌ **高饱和杂色 / 一场两主色相竞争**——破坏单色调（M2/F2）。
- ❌ **天空拍成蓝色**——应吹白或染场景色（H8/F2）。
- ❌ **负空间浑浊发灰**——应纯黑或单一 HSV（M3/F3）。
- ❌ **画框四角堆信息 / 一镜 >2 信息点**——违 M4/F6。
- ❌ **无动机运镜 / 装饰性甩·旋·炫 crane / slam zoom / 快变焦**——违 M5/H19/F4。
- ❌ **手持剧烈乱抖（非 M7 失控弧内）**——庄严基态禁抖。
- ❌ **快剪 ABC 远→中→特循环**——破坏极慢节奏（H14）。
- ❌ **配乐填满 / 流行音乐 / 直白旁白解释剧情**——破坏极致沉默 + 30–80Hz drone（H21）。
- ❌ **大哭大喊 / 外放煽情**——破坏克制 20–50%（H20）。
- ❌ **琥珀灯配琥珀滤镜（发泥）**——应绿灯配暖滤镜（H10/F5）。
- ❌ **平板数字降饱和**——应 bleach-bypass/胶片颗粒（H12）。
- ❌ **多机广撒 / 二组代拍尺度镜**——单机位精摆（H22）。
- ❌ **把对称一点透视当成维伦纽瓦签名硬套**——他更偏"贴边+框+引导线"，纯居中对称证据弱（见 DL）。

## 九、Doubt-Log（分级：可引用 / 纠错 / 存疑）

### ✅ 可引用（一手/权威原话，出处明确）
- Deakins「若摄影机移动必须有理由」「去看布列松」「对炫耀式运镜有意见」「有勇气依赖单光源让其余入黑」〔Hazlitt / rogerdeakins.com / British Cinematographer〕。
- Fraser「天不蓝石不红沙不金」「cinematography=omega not alpha」「等黄金时刻不打灯」「65mm 移除限制」「简化画框/不让观众停留四角」〔frame.io / ARRI Rental / No Film School / cinematography.world〕。
- Villeneuve「formal classical tableaus → 相机离开三脚架变纪实手持」「Paul 世界被剥离相机变自由」〔Cinematography World〕。
- Vegas 暖包滤镜配方（Lee 790+105+134+020）+ 侧面 Maxi-Brute 打绿 + Black Pro-Mist 1/8；沙丘 bleach-bypass + LUT 去天空蓝 + IR 拍摄（除 IR-cut 加可见光屏蔽）〔原话/转述, StudioBinder/frame.io〕。
- 器材：降临 Ultra Prime 28 + Super Speed 35（约 90%）；2049 ALEXA XT Studio + Master Prime 2.39 spherical；沙丘 ALEXA 65 + Mini LF spherical，长焦段〔多源一手〕。

### ⚠️ 纠错（防止以讹传讹 / 已知误区）
- **"居中对称一点透视"多归 Kubrick，非维伦纽瓦签名**。维伦纽瓦更偏"贴边 + 框（窗/走廊/霓虹条）+ 引导线拉小主体"，纯对称居中证据弱——勿把 Kubrick 手法硬贴到本导演〔判别, 02-negative-space〕。
- **对称/长镜/IMAX/bleach-bypass/红外拍摄/单光源入黑/frame-within-frame/交叉剪辑 均非本导演或其 DP 发明**——写"标志性运用/集大成"，不写"首创/发明"。
- **色彩色值 hex/HSV（#6B7B8B / #C8822E / #2A4A6B / #C8508C 等）来自库内逐镜与分析站，非 DP/colorist 官方公布**——作 镜头表达 起手锚点可用，但勿宣称"官方数值"。

### ❓ 存疑（无一手数字，勿伪造）
- **精确焦段与机位高度/俯仰角**：各源均未给单镜数值（如某沙虫镜=Xmm/俯Y°）；theASC.com 一手文多篇 403 未取证。
- **精确色温 K**：Deakins/Fraser 未公布 Vegas/Arrakis 的 Kelvin；Aputure LS 1200d 页无 Kelvin/diffusion。
- **极缓运镜精确速度**：各源仅定性"几乎不可觉/货运列车级"；0.03–0.08 m/s 系库内逐镜设定值，非 DP 公布 in/sec。
- **BR2049 外景快门角度 ≈45°**：仅二手摘要（flickside），未取到 Deakins 原话——**存疑，勿引为定论**。
- **饱和降幅 40–60% / 抬黑量**：〔推断〕的 bleach-bypass 仿真目标，非引用数字。
- **帧率**：均默认 24fps，未见 DP 明确声明——存疑。
- **沙丘逐镜（卡02/卡09 正例）库内暂无**：现引自调研转述，标"库内待建"；建库前勿把沙丘当已验证逐镜锚点引用。
