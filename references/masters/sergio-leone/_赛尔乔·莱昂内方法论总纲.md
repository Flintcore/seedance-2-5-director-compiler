## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：莱昂内的分镜系统 = **"把决斗拉长成一场仪式、把面孔放大成地形"**，四根支柱。① **极端景别两极引擎**（判别铁律）：极端大特写（眼睛/汗珠/枪柄占满画面 · 100–200mm 长焦）↔ 极端大远景（人占画面 ≤3% · 广角纳天地）**几乎跳过中景**——宏大与私密对撞，同一段落两极交替剪辑。② **仪式化时间**：对峙不是快剪，是**长凝视累积**（Mexican standoff 三方循环切镜：眼→手→全景，≥2–3min），爆发压到最后 0.5s；节奏被刻意拉长（缓慢推近 zoom/dolly 0.05–0.15 m/s）。③ **音乐驱动剪辑**：莫里康内主题**先谱后拍**、现场放乐让演员踩节拍，口哨/人声/电吉他=角色符号，配乐渐强与切镜同步推升张力——剪辑跟着乐走，不是乐配剪辑。④ **面孔地形学**：脸被当风景拍——皱纹/汗孔/胡茬/帽檐硬阴影如荒漠沟壑，眯眼+雪茄冷峻 40%，对白极简，眼神与配乐说话。母题→镜头：宿命对决→standoff 循环切；渺小→地平线留白；登场→专属主题+极端特写符号化。色：黄沙 #C2914A + 强日光 5600K 硬阴影 + 暖调。

**适用情境**：西部 / 对决对峙 / 史诗荒漠 / 仪式感决斗 / 音乐驱动叙事 / 江湖宿命 / 男性冷峻 / 紧张悬念 / 时间被拉长的悬置。**不适用/需改造**：需要快节奏动作可读性的现代动作（长凝视反节奏）、话痨对白剧、明亮均匀高调打光、中景为主的电视剧式覆盖、无配乐的写实纪录。

## 一、核心心智模型（8 个镜片 · How Leone sees a shot）

### M1 · 决斗是仪式，不是动作（时间要被拉长）
莱昂内看一场对决，先问的不是"怎么打"而是"怎么把爆发前的等待拉到极限"。物理动作只占最后 0.5s，之前是数分钟的悬置仪式。
- **分镜含义**：遇到冲突/对峙 → 先设计"漫长的凝视累积"再设计爆发，把张力放在等待里而非交火里。→ 见 §T1/§F2。

### M2 · 景别只有两极（大到只剩眼睛，远到人如尘）
莱昂内的镜头尺度是**二值**的：要么极端大特写（器官占满画面），要么极端大远景（人 ≤3%），中景被视为"信息平均、无戏剧性"而回避。
- **分镜含义**：设计一个镜头先做二选一——私密（怼脸）还是史诗（纳天地），不要落在中景舒适区。判别铁律见 §F1。

### M3 · 面孔是地形（脸当风景拍）
一张沉默的脸就能定义一个角色。皱纹、汗孔、胡茬、帽檐硬阴影被当作荒漠的沟壑与山脊来打光和构图，靠"读脸"而非表演动作叙事。
- **分镜含义**：想建立/定义角色 → 极端大特写脸 + 侧硬光刻画肌理 + 演员冷峻克制，让景别和光承担表演。→ 见 §T3/§M8。

### M4 · 音乐先行，剪辑跟乐走
莫里康内的主题**先谱后拍**，现场大声播放让演员踩着节拍表演、让莱昂内按乐句切镜——是**音乐驱动剪辑**，不是后期配乐（拍摄流程事实，非风格标签）。
- **分镜含义**：设计段落先定"主题动机"，再让运镜速度、切点、凝视时长踩乐句；每个角色配专属音色作符号。→ 见 §T5/§F3。

### M5 · 逼近感靠"缓慢推"，不靠剪辑
张力用**缓慢 zoom in / dolly in**（0.05–0.15 m/s）一点点收紧景框制造压迫，而不是靠快切累积。观众被镜头"推"向爆发点。
- **分镜含义**：要"越来越紧" → 极缓推近脸/眼，配合配乐渐强，禁止用抖动快剪替代。→ 见 §T4。

### M6 · 环形/三角空间几何（对峙的调度语法）
终极对峙用**几何站位**（三方三角、圆形墓地中心）+ 宽银幕横向排布，让空间本身编码"三方制衡/无处可逃"，环绕镜头建立完整地理关系。
- **分镜含义**：多人对峙 → 先建立几何站位与完整空间地理（大远景锁定），再切入器官特写循环。→ 见 §T6/§F4。

### M7 · 极简对白 / 沉默是信息（留白即张力）
长段落无台词，靠眼神交锋、环境声床（风、蹄、鸦鸣）与配乐推进；爆发前用**极致静默**与配乐高潮形成呼吸。
- **分镜含义**：能用眼神/配乐说的，不给台词；对峙顶点插入静默（环境声抽空）再骤然爆发。→ 见 §M4/§T1。

### M8 · 强日光硬阴影 = 严酷的世界观（光即命运）
黄沙 #C2914A + 自然强日光 5600K + 不补阴影的高对比硬光，把西部拍成被命运炙烤的严酷之地；帽檐阴影遮眼是标志性遮光。
- **分镜含义**：定光前先定"严酷/炙烤"的世界情绪 → 硬顶光/侧光、不填暗部、暖调；帽檐阴影半遮眼制造神秘。→ 见 §T7/§F5。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 仪式化时间 / 对峙节奏
- **H1** 要对决张力（决斗/对峙/摊牌）→ 拉长成仪式：长凝视累积 ≥2–3min，循环切"眼→手→全景"，爆发压到最后 0.5s，**禁止**全程快剪。
- **H2** 要"越来越紧" → 缓慢 zoom in / dolly in 0.05–0.15 m/s 逼近脸/眼，配乐同步渐强，切点跟乐句，**不用**抖动快切替代压迫。
- **H3** 爆发瞬间 → 前面越静越慢，爆发才越猛：静默（抽空环境声）→ 配乐高潮 → 0.5s 闪电拔枪 + 全景/特写快切开火。

### B. 景别族选择（两极铁律）
- **H4** 要私密/紧张/角色符号 → 极端大特写（眼睛/汗珠/手按枪柄占满画面，100–200mm，f4 浅景深），器官充满取景框。
- **H5** 要史诗/渺小/命运尺度 → 极端大远景（人占画面 ≤3%，广角 24mm，f11 大景深纳荒漠天地）。
- **H6**（铁律）**回避中景**——同一戏剧段落在两极间跳切，中景只作必要过场，不作情绪承载（§F1）。

### C. 面孔地形 / 表演分寸
- **H7** 建立/定义角色 → 极端大特写脸 + 帽檐硬阴影半遮眼 + 眯眼 + 嚼雪茄 + 冷峻克制 40%，让脸的肌理（皱纹/汗孔/胡茬）当风景。
- **H8** 表演分寸 → 冷峻寡言 40%，靠眼神游移/汗珠滚落/手指微抽承载内心，**不挤表情**；爆发瞬间才大开大合。
- **H9** 侧硬光刻脸 → 单侧强光 + 不补阴影，让皱纹/汗孔投出深阴影（地形化），暗部留黑。

### D. 音乐 / 声音驱动
- **H10** 段落设计 → 先定莫里康内式主题动机（口哨/人声"啊呀啊"/电吉他/排箫/口琴），再让切点与凝视时长踩乐句（乐驱动剪）。
- **H11** 角色登场 → 给专属音色主题作符号（如口哨=某镖客），主题反复出现即"这个人来了"，配极端大特写/大远景登场。
- **H12** 对峙推升 → 配乐渐强渐快与切镜同步加速，把张力推到爆发；顶点前一拍抽空成静默。
- **H13** 荒漠声床 → 风卷尘 / 鸦鸣 / 远蹄声 / 远炮声铺底，衬托死寂与广袤，**不填满**声音。

### E. 空间几何 / 光影 / 母题
- **H14** 多人对峙 → 几何站位（三角/圆形中心）+ 宽银幕横向排布 + 环绕镜头先建立完整空间地理（大远景锁定），再切器官特写循环。
- **H15** 拍渺小/史诗 → 地平线构图 + 大面积天空/沙地留白 + 人如点，极缓 pan 跟随，暮光暖橙或强日光。
- **H16** 定光 → 强日光 5600K 硬阴影高对比、不补暗部；帽檐阴影半遮眼；黄沙 #C2914A 暖调。
- **H17** 暴力处理 → 干净利落、无渲染快感：从大特写骤切大远景，枪响后荒漠中倒下的人（景别落差=冲击），不做血浆特写堆砌。
- **H18** 宿命/宿怨闪回 → 用同一母版镜头（角度+景别+主题音乐）在关键处复现，让观众识别"这一刻的根源"（如西部往事口琴闪回结构 · 推断该结构逻辑，具体逐镜待拉片核）。
- **H19** 拍等待/悬置日常（等火车/等对手）→ 拉长实时时间 + 环境细节特写（苍蝇/关节/滴水）+ 极简动作，让"无事发生"本身成戏。
- **H20** 转场 → 两极景别硬切（大特写↔大远景）或配乐 Sound Bridge 跨越时空，**不用**平淡溶接。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 景别两极判别（是否莱昂内式尺度）**
```
镜头尺度必须落在两极之一：
  极端大特写 = 单个器官(眼/汗珠/嘴唇/手/枪柄)占满画面 (100–200mm · f4)
  极端大远景 = 人占画面 ≤3% · 广角纳天地 (24mm · f11)
中景 = 回避区（仅作必要过场，不承载情绪）
铁律：同一戏剧段落必须在两极间跳切，才算 Leone 式。全片中景平均化 = 不合格。
```

**F2 · 对峙仪式判别（是否拉成了仪式）**
```
✅ 长凝视累积 ≥2–3min（循环切 眼→手→全景）
✅ 配乐渐强推升 + 缓慢推近逼迫
✅ 爆发前极致静默（抽空环境声）
✅ 爆发压到最后 0.5s（快切拔枪开火）
四项齐 = 仪式化对峙；缺"长凝视累积"或"爆发前静默" = 沦为普通快剪决斗。
```

**F3 · 音乐驱动判别（乐驱剪 vs 剪配乐）**
```
Leone 式 = 先有主题动机 → 切点/凝视时长/运镜速度踩乐句 → 每角色专属音色作符号
判据：抽掉配乐后，剪辑节奏是否"失去骨架"？若是 → 音乐驱动（正确）
若配乐只是背景垫底、剪辑自成节奏 → 非 Leone 式（错误）
```

**F4 · 对峙空间几何判别**
```
多人对峙 → 站位必须是可读几何（三角制衡 / 圆形中心 / 宽银幕横排）
必须先用大远景/环绕镜头建立完整空间地理（谁在哪、朝向、距离）
再切器官特写循环——观众才能在特写时脑补全局
缺"几何站位"或"空间建立" = 对峙失去张力地基
```

**F5 · 强日光硬阴影判别（严酷世界观）**
```
色温 5600K 自然强日光 · 高对比 · 暗部不补光（留黑）
黄沙主色 ≈ #C2914A · 整体暖调
帽檐/物体投硬阴影，脸部可半遮（帽檐遮眼）
❌ 柔光均匀 / 冷调写实 / 高调明亮 = 破坏严酷世界观
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 对峙仪式循环切镜（Standoff Ritual）** ｜机制：多人对峙循环切不同器官景别累积张力，长凝视后骤然爆发｜参数：三方循环 眼(150mm f4)→手/枪柄(100mm f4)→全景(24mm f11)；长凝视 ≥2–3min；配乐渐强；爆发前静默；最后 0.5s 快切拔枪｜触发：决斗/对峙/摊牌/宿命对决｜意图：让戏剧重心从"谁赢"转移到"等待本身"——观众被凝视时长与配乐推升绑住，而非等结果｜正例：黄金三镖客 §场景 A 终局墓地三方对峙（Mexican standoff）。

**T2 · 极端景别两极切换（Extreme Scale Polarity）** ｜机制：极端大特写↔极端大远景直接跳切，跳过中景｜参数：大特写器官占满(100–200mm f4)↔大远景人 ≤3%(24mm f11)；两极交替剪辑｜触发：宏大与私密对撞、暴力冲击、命运尺度对比｜意图：私密紧张 vs 史诗渺小的强烈撞击｜正例：黄金三镖客 §场景 C 镜 C-4（大特写脸骤切大远景荒漠倒下的人）。

**T3 · 面孔地形学大特写（Face-as-Landscape）** ｜机制：脸当风景拍，肌理当地形｜参数：极端大特写(150mm f4)脸占满；侧硬光刻皱纹/汗孔/胡茬；帽檐阴影半遮眼；眯眼+雪茄；冷峻 40%；极缓 push in 0.05 m/s｜触发：角色登场/符号建立/读脸叙事｜意图：用景别+侧光的肌理承担角色塑造，省掉台词与表演解释——脸即信息载体｜正例：黄金三镖客 §场景 C 镜 C-2（镖客登场脸部极端大特写）。

**T4 · 缓慢推近逼迫（Slow Push-in）** ｜机制：缓慢 zoom/dolly 收紧景框制造压迫｜参数：zoom in 或 dolly in 0.05–0.15 m/s 逼近脸/眼；配乐同步渐强；切点跟乐句｜触发：对峙升温/悬置升级/逼近爆发｜意图：逐渐收紧的张力，把观众推向爆发点｜正例：黄金三镖客 §场景 A 镜 A-2（每个眼睛缓慢 zoom in 0.05 m/s）。

**T5 · 音乐驱动剪辑（Score-Driven Cutting）** ｜机制：先谱后拍、现场放乐、切点踩乐句、角色专属音色｜参数：主题动机(口哨/人声/电吉他/排箫/口琴)先行；凝视时长与切点踩乐句；配乐渐强同步切镜加速｜触发：段落设计/角色登场/对峙推升｜意图：让切点/凝视时长/运镜速度由乐句决定（乐驱剪），主题动机复现即角色符号——抽掉配乐则剪辑失去骨架｜正例：黄金三镖客 §场景 C 镜 C-1（口哨主题伴角色登场）+ §四声音设计。

**T6 · 对峙空间几何（Standoff Geometry）** ｜机制：几何站位 + 宽银幕横排 + 环绕建立空间地理｜参数：三方三角/圆形中心站位；宽银幕横向排布；平视 24mm f11 大远景锁定；缓慢环绕建立地理｜触发：多人对峙/制衡关系｜意图：空间本身编码"三方制衡/无处可逃"｜正例：黄金三镖客 §场景 A 镜 A-1（圆形墓地中心三人三角站位）。

**T7 · 强日光硬阴影荒漠（Sun-baked Desert）** ｜机制：自然强日光硬阴影高对比 + 黄沙暖调｜参数：黄沙 #C2914A；强日光 5600K；不补暗部（留黑）；高对比；尘土热浪；帽檐硬阴影｜触发：西部荒漠/严酷世界观/命运炙烤｜意图：被命运炙烤的严酷之地｜正例：黄金三镖客 §场景 B 荒漠行军全场。

**T9 · 极简对白与静默呼吸（Minimal Dialogue / Silence）** ｜机制：靠眼神+配乐+环境声推进，爆发前极致静默｜参数：长段落无台词；环境声床(风/鸦/蹄/远炮)铺底；顶点前抽空成静默 ↔ 配乐高潮｜触发：对峙/悬置/沉默交锋｜意图：把叙事负载从台词转到眼神+环境声+配乐；顶点前抽空环境声制造"呼吸落差"放大爆发｜正例：黄金三镖客 §场景 A 爆发前静默 + §四音乐设计"静默与配乐的呼吸"。

## 七、禁忌清单（❌ 莱昂内式分镜绝不做的事）

- ❌ **中景平均化**——景别必须落在极端两极，中景只作过场（§F1）。
- ❌ **把对峙拍成快剪决斗**——它是长凝视仪式，只有爆发那 0.5s 才快（§F2）。
- ❌ **抖动快切替代逼近感**——压迫靠缓慢推近，不靠剪辑频率（§M5/§T4）。
- ❌ **让配乐只当背景垫底**——音乐驱动剪辑，切点踩乐句，抽掉乐剪辑应失去骨架（§F3）。
- ❌ **话痨对白**——能用眼神/配乐/环境声说的绝不给台词（§M7/§T9）。
- ❌ **爆发前不给静默**——顶点必须抽空环境声再骤然爆发，没有静默就没有呼吸（§F2/§T9）。
- ❌ **柔光均匀 / 冷调写实 / 高调明亮**——破坏强日光硬阴影的严酷世界观（§F5）。
- ❌ **对峙不建立空间几何就切特写**——先用大远景/环绕交代站位地理，否则特写失去张力地基（§F4）。
- ❌ **血浆特写堆砌渲染暴力**——暴力要干净利落、用景别落差冲击，不用感官快感（§H17）。
- ❌ **平淡的角色登场**——用专属配乐主题 + 极端景别符号化登场（§H11/§T3）。
