## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：斯科塞斯的分镜系统 = **"让观众被角色收买/住进角色脑子"这一目的下的两副面孔 + 一条工程铁律**。① **热面（好家伙式·带入世界）**：流动 Steadicam 从卑微入口（后门/厨房/服务通道）一镜不切穿到中心（VIP 桌/舞台），观众与主角同步"被款待"= 被黑帮生活收买；第一人称旁白贴脸讲述 + freeze frame 只冻结"自我美化瞬间"（VO 继续、随后打脸）+ 流行金曲**片场外放、每镜对一乐句**、操作员踩拍走位 + whip pan 双甩转场。② **冷面（出租车司机式·住进脑子）**：主观 POV + 慢推凝视 + 慢动作观看他人（把厌恶/嫉妒内化）+ 招牌"移开的镜头"（被拒时摄影机不忍地横摇离开人到空走廊）+ 去饱和红血腥 + 俯拍 crane 撤离审判。铁律 = **"先设计切点再拍、只拍动作中段"**（The action is pulled out of the middle of the scene）+ **运动升级曲线**（越接近堕落/失控日，运镜越失控，像整片要 spin off the edge）。可迁移产物：8 心智模型 + 18 启发式 + 5 判别式 + 10 技法卡 + 10+ 落地句式。

**适用情境**：黑帮/犯罪/传记、都市孤独/异化、反英雄堕落、旁白驱动叙事、长镜炫技、年代金曲卡点、主观代入、压抑到爆发的暴力、公众形象 vs 真人拆解。**不适用/需改造**：需上帝俯拍旁观的疏离戏（他多贴身入侵）、暴力慢镜唯美化（好家伙暴力谈笑间突发无慢镜；出租车司机暴力是绝望非爽感）、无配乐留白的极简（他多需 needle-drop 或旁白填充）。

## 一、核心心智模型（8 个镜片 · How Scorsese sees a scene）

> 每个模型 = 一副"看戏的镜片"，回答"这场戏的镜头/剪辑该怎么想"。

### M1 · 摄影机=共谋者，不是旁观者（带入世界引擎）
最标志性的一镜（Copacabana）的目的不是炫技本身，而是让观众**被收买**：Henry 撩 Karen ＝ Scorsese 撩观众（joblo/screenrant 转述其二重目的原话大意 · 中）。摄影机保持在主角**身后/侧后**流动跟随（over-the-shoulder），不给上帝俯拍——让观众=同谋/偷窥者而非旁观者。
- McConkey [原话]："I wanted a flurry of activity, trays, people crossing the frame, just to confuse people"——用托盘、穿帮人流横过前景既藏灯藏接力，又强化"内部世界"密度。（01 · 中）
- **分镜含义**：要观众"上钩认同一个人"→ 用不切的 Steadicam 从**卑微入口穿到尊贵中心**，摄影机贴主角背后走；入口越卑微、到达越尊贵，落差=那个世界的诱惑力。→ §T1。

### M2 · 旁白×画面只有两种耦合态（第一人称共谋引擎）
第一人称 VO 与画面**只有两种耦合态**，逐镜择一（04/S5 转述 · 中）：**态A 冻结态**——画面 freeze frame，VO 描述/补充/**反驳**刚冻结的动作（叙述者跳出故事直视观众）；**态B 连续态**——动作继续运动，VO 叠在上面评论（只做信息补充、不打断动势）。
- **分镜含义**：每个带旁白的镜头，先判"要不要打断动势"：要点名/记住/反转→态A(freeze)；只补信息→态B(continuous)。需"局内人+半局外"双视角→引入第二 VO 声轨（Karen 模型），制造 stereo：一个从里面讲、一个退一步讲。→ §T2/§T3。

### M3 · freeze frame 只冻"自我神话"瞬间（定格判别引擎）
只冻结"角色自我美化/最风光"的一帧（入伙/首活/婚礼/得逞/被接纳），VO **继续**说话，随后剧情揭穿其虚假 → 定格 = "artificial and transitory"的自我神话（ScreenRant 转述 · 中）。私生活/崩溃段落**不冻**、保持流动（愤怒的公牛只 freeze 拳赛名场面，家暴/崩溃全程流动 → 对比"他不止是好拳"）。
- **分镜含义**：拿到一场戏先问"这一帧是不是主角在自我加冕？"是→freeze+VO 继续+后续打脸；否→别冻。传记片拆"公众形象 vs 真人"，只冻公开战绩。→ §T3/§F3。

### M4 · needle-drop = 每镜对一乐句（音乐即分镜引擎）
选定歌曲**在片场用音响外放**，"Every shot was designed to a different phrase of the music"（每镜对应音乐的一个乐句），操作员"dance to the music"踩拍走位，剪辑须让每镜精确落在预定乐点（The Ringer + No Film School [原话/转述] · 高）。情绪反差（怀旧撞暴力）时用金曲**下半段/coda**、砍掉观众熟悉的高能前奏——观众潜意识察觉"缺失"=不安（好家伙全程只用 "Layla" Piano Exit 第二乐章，"energetic first half is never heard"，Wikipedia/Ringer · 高）。
- **分镜含义**：不是"配乐"而是"分镜骨架"。切点必须压在乐句转折（鼓/riff/chord）那一帧，否则不是 needle-drop 只是背景乐。→ §T4/§F4。

### M5 · 主观 POV + 慢动作 = 把内心状态物化（住进脑子引擎）
当角色"病态观察/无法参与"某场景（他人的性交易/快乐）→ 用**慢动作 POV**把厌恶/嫉妒/隔绝**内化**（03 转述："the sex he observes…shown in slow motion, fills him with loathing";"his gaze lingers" · 中）。异化的抽象情绪用一个**主观特写物件**物化（水杯里泡腾片翻腾=精神溶解/抽离）。
- **分镜含义**：要观众"入戏但察觉异常"→ 只降速 + 一个怪异动作/物件提示"这是他脑内主观"；不解释。→ §T5 / 出租车司机 §场景 A（泡腾片 A-3）。

### M6 · "移开的镜头"= 用机位表达情绪，不拍表情说明（运镜外化引擎）
把角色内心状态**外化成镜头运动**，而非拍他挤表情。招牌：Travis 打电话被拒时，摄影机**不忍地从他身上缓缓横摇移开**到空荡走廊——连摄影机都不忍看=影史最孤独运镜之一（03 转述 · 中）。同理：失败/无力时刻镜头缓慢向右 dolly 离开人物、落定空长走廊固定镜。
- **分镜含义**：角色努力落空/被抛下 → 让**镜头主动离开**主体、停在空景，用运镜承载"被世界抛下"，而非给一个悲伤特写。→ §T6/§H10。

### M7 · 先设计切点再拍、只拍动作中段（剪辑工程铁律）
Scorsese [原话]："The shots are designed so that I know where the cut's going to be. The action is pulled out of the middle of the scene."（Gavin Smith 1990 · 高）摆机位前先定切点；只拍动作**中段**（掐头去尾），入点=动作已在进行、出点=动作未完成 → 天然可跳切压缩时间。VO 能承载信息时，场景拍到一半即切、用 VO 桥接下一场（[原话]"Do it on the voiceover… then just jump the scene together"）。
- **分镜含义**：分镜是**设计**出来的。剪辑师 Schoonmaker [原话]故意保留剪辑"bumps"（不平滑接口）→ 加 grittiness/reality，好莱坞不会留；if 平滑会削弱粗粝真实感 → **保留**可见接口别磨平。→ §H13/§F5。

### M8 · 运动升级曲线（整片调度弧）
目标：throughout 全片"even more movement than usual"，用图像+信息 overwhelm 观众（Scorsese [原话]·Gavin Smith · 高）。可操作弧线：主角越接近堕落/失控日 → 运镜越失控，"像整部片要 **spin off the edge**"。
- **分镜含义**：结尾段落的推轨速度/手持抖动/whip pan 频率应**显著高于开场**；给"要飞出画框"的失控感。这是一条跨镜的调度设计，不是单镜参数。→ §H15。

## 二、决策启发式（18 条 if-then · 落到镜头/剪辑的操作规则）

> 用法：设计一个镜头/段落时，按类别快速比对，命中即套用。

### A. 流动长镜/带入世界类
- **S1** IF 剧情=外来者/新人第一次进入某封闭圈子（黑帮/名利场/权力场）且需让观众"被收买"→ THEN 用不切一镜从**边缘入口（后门/厨房/服务通道）**穿到**中心（VIP 桌/舞台前）**，观众与主角同步被款待。（M1 · 好家伙 §场景 A）
- **S2** IF 想让观众=共谋/偷窥者而非旁观 → THEN 摄影机保持主角**身后/侧后**流动跟随（over-the-shoulder），**不给上帝俯拍**。（M1）
- **S3** IF 空间狭窄+人多（夜店/后厨）→ THEN 广角端 + 大光孔（Copa 用 Zeiss Super Speed **全开 T1.3**）+ 靠**实用光（practical）**照明，**禁架破沉浸的大灯**。（01 · 高）
- **S4** IF 长镜要"落地"不穿帮 → THEN 让沿途人物**主动上前打招呼/握手/让路**给摄影机（"给演员事做"），每次转向都被动机化、不空走；狭窄段可走"延长的圆"（同一口进出、靠换群演+改陈设掩盖）。（01 · 中）
- **S5** IF 起幅要立主题 → THEN 用**大特写一个动作**而非人脸开场（Copa 起幅=递钱/小费的 ECU → "钱开路=特权"母题优先于人物）。（01 · 中）
- **S6** IF 同一长镜内要承载心理弧 → THEN 用 **lead↔follow 切换**：摄影机倒退走在主角前方(lead)=介绍/迎接感；狭窄处切到身后(follow)=穿越——lead↔follow 切换即"被世界接纳"的心理弧。（01 · 推断+转述）

### B. 旁白/freeze frame 类
- **S7** IF 镜头需"叙述者跳出故事直视观众/点名转折"→ THEN 用**态A 冻结**（freeze frame + VO 覆盖），冻结点=动作最高潮/后果显现帧（非静止帧）。（M2/M3）
- **S8** IF VO 只做信息补充、不该打断动势 → THEN 用**态B 连续**（动作继续+VO 叠加、动势不减速）。（M2）
- **S9** IF 这一帧是主角"高光自述/自我加冕"（入伙/首活/婚礼/得逞）→ THEN freeze + VO 继续 + 后续反转打脸；IF 是私生活/崩溃 → **不冻**、保持流动。（M3 · 好家伙 §A-4/§B-4）
- **S10** IF 只是转场、不需点名 → THEN **不用 freeze，改跳切**（jump cut）。（M3/M7）
- **S11** IF 需"局内人+半局外"双视角（夫妻/主副角）→ THEN 引入**第二 VO 声轨**（Karen 模型），一个从里面讲、一个退一步讲。（M2）

### C. needle-drop / 音乐卡点类
- **S12** IF 要"一镜到底+卡点"→ THEN 片场外放定版音轨，操作员按乐句编舞（Copa 一镜 3 分钟同步 "Then He Kissed Me"，8 条过关）。（M4 · 好家伙 §场景 A）
- **S13** IF 情绪反差（怀旧撞暴力/悲剧）→ THEN 用金曲**下半段/coda**、砍掉熟悉的高能前奏，让"缺失"制造潜意识不安。（M4）
- **S14**（判别式）切点是否压在乐句转折（鼓/riff/chord/滑棒吉他进入）那一帧？否 → 不是 needle-drop，只是背景乐、重设切点。（M4/F4）

### D. 主观 POV / 慢推 / 慢动作类
- **S15** IF 角色病态观察他人的亲密/快乐（无法参与）→ THEN 降速（慢动作 POV）+ 持续不切 = 嫉妒/厌恶式凝视凝固。（M5 · 出租车司机 §A）
- **S16** IF 抽象情绪（异化/抽离）需外化 → THEN 用一个**主观特写物件**物化（泡腾片翻腾=精神溶解），极缓 push 入。（M5 · 出租车司机 §A-3）
- **S17** IF 角色努力落空/被抛下/被拒 → THEN 让**镜头主动离开**主体、缓横摇/缓 dolly 到空景固定镜（"移开的镜头"），用运镜承载孤独。（M6 · 出租车司机 §A-4）

### E. 剪辑工程 / 调度弧 / 暴力类
- **S18** IF 要跨镜维持并升级失控感 → THEN 结尾段推轨速度/手持抖动/whip pan 频率显著高于开场（运动升级曲线）；且暴力**不给慢镜**（好家伙谈笑间突发无慢镜）——除非暴力主题是"绝望"，则用去饱和红+俯拍 crane 撤离审判（出租车司机 §C，非爽感）。（M8/M7 · 好家伙 §C / 出租车司机 §C）

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 热面/冷面二分式**（先定这场戏属哪副面孔，再选整套语法）
```
问：这场戏要"把观众收买进一个世界"还是"让观众住进一个孤独者的脑"？
收买进世界 → 热面：流动 Steadicam over-shoulder + 旁白共谋 + needle-drop + freeze 自我神话 + 暖调 + whip pan
              → Read 好家伙.md
住进孤独脑 → 冷面：主观 POV + 慢推凝视 + 慢动作观看 + "移开的镜头" + 霓虹雨夜/去饱和红 + crane 撤离
              → Read 出租车司机.md
（同一片可两面并用：如公众形象=热面、私下崩溃=冷面）
```

**F2 · 带入世界一镜触发式**（Copa 型长镜该不该用）
```
成立条件（需同时满足）：
  ① 剧情 = 外来者/新人首次进入封闭圈子（黑帮/名利场/权力场）
  ② 需要观众"被收买/被款待"而非旁观
  ③ 存在"卑微入口→尊贵中心"的空间落差（后门/厨房 → VIP 桌/舞台）
→ 全部成立：用不切 Steadicam over-shoulder 一镜，起幅=一个"特权动作"ECU（递钱），沿途人物主动迎接
→ 否则：改用常规剪辑，别为炫技而长镜
```

**F3 · freeze frame 判别式**
```
问：这一帧是不是主角"自我美化/自我加冕"的公开高光？
是 → FREEZE + VO 继续（描述/补充/反驳）+ 后续剧情打脸；hold ≈ 0.8–3s[推断]
否（私生活/崩溃/转场）→ 不冻：崩溃段保持流动、转场改跳切
（判据 = "这一冻是否在把角色的自我神话钉成'artificial and transitory'"）
```

**F4 · needle-drop 卡点判别式**
```
一段音乐是"needle-drop 分镜"还是"背景乐"？
片场外放定版音轨 ∧ 每镜对应一个乐句 ∧ 切点压在乐句转折(鼓/riff/chord)那一帧 → needle-drop（成立）
任一不满足 → 只是背景配乐，重设切点或改用 coda（砍高能前奏制造"缺失"不安）
```

**F5 · "中段截取+保留 bumps"剪辑式**
```
每个镜头设计前：先定切点（cut point 已知）
拍摄取样 = 动作的中段：入点 = 动作已在进行中，出点 = 动作尚未完成
→ 天然可跳切压缩时间；VO 可承载信息时，场景拍一半即切、用 VO 桥接下一场
接口处理：if 平滑会削弱粗粝/真实感 → 保留可见"bumps"（别磨平）；if 需硬转场藏接口 → 插过曝闪光白帧+crackle 音掩盖
```

## 四、标志性技法卡片（10 张 · 每张可操作 · 附正例锚点）

> 每卡：机制 → 物理参数 → 触发条件 → 情感意图 → 正例（优先引库内片某场）→ 见 §六 对应 落地句式。

**T1 · 带入世界一镜（Bravura Immersion Oner）**
- 机制：不切 Steadicam over-shoulder 从卑微入口穿到尊贵中心，观众与主角同步被款待。
- 参数：Arriflex 35 BL4S / 35mm 胶片 / Zeiss Super Speed **全开 T1.3** / 广角端[推断] / 1.85:1 / ≈3min / 速度 0.5–1.5 m/s（好家伙.md 记 0.8–1.0 m/s）/ 顶部加小监视器供倒退走时看构图 / 8 条过 / 24fps·180°[推断]。
- 触发：F2 三条件全满足（外来者进封闭圈+需被收买+卑微→尊贵落差）。
- 情感意图：把"那个世界的诱惑力"变成观众亲身经历的沉浸。
- 正例：**好家伙 §场景 A**（Copa 一镜 A-1 侧门→A-2 后厨→A-3 前排落座→A-4 freeze）。见 §六 句 1。

**T2 · 旁白连续态（VO Continuous · 态B）**
- 机制：动作继续运动、第一人称 VO 叠加评论、动势不减速；只补信息不打断。
- 参数：`[主体持续运动/推轨]，第一人称 VO 叠加，画面动势不减速`。
- 触发：VO 只做信息补充、不需点名转折时（M2 态B）。
- 情感意图：让观众持续"贴着主角脑子"听他讲述，认同其视角。
- 正例：**好家伙 §A-2**（穿后厨 + 旁白"在这里我是有头有脸的人"）。见 §六 句 2。

**T3 · freeze frame 自我神话（Freeze the Myth · 态A）**
- 机制：动作最高潮/后果帧定格，VO **继续/反驳**，随后剧情打脸；只冻自我加冕、私生活不冻。
- 参数：hold ≈ 0.8–3s[推断，无权威秒数] / freeze 后 hard-cut 回运动画面 / 50mm 平视（好家伙.md）。
- 触发：F3=是（主角公开高光/入伙/首活/婚礼/得逞）。
- 情感意图：把角色的自我神话钉成"artificial and transitory"。
- 正例：**好家伙 §A-4**（入座笑看演出 freeze+旁白）/ **§B-4**（命运转折 freeze 点题）。见 §六 句 3。

**T4 · needle-drop 卡点（Beat-Matched Needle-Drop）**
- 机制：片场外放定版音轨，每镜对一乐句，操作员踩拍走位，切点压乐句转折帧；反差用 coda。
- 参数：`Song=[曲名] 从 [X:XX] 段进入（piano coda/副歌/riff）；SHOT_A 落在[第一乐句]；切点=[鼓/贝斯/滑棒吉他进入的那一帧]；片场外放、beat-matched`。
- 触发：S12（一镜卡点）/ S13（情绪反差→coda）。
- 情感意图：音乐成为分镜骨架与时代/情绪载体；"缺失"的前奏制造潜意识不安。
- 正例：**好家伙 §场景 A**（Copa 同步 "Then He Kissed Me"）/ 全片 "Layla" Piano Exit（coda 用法）。见 §六 句 4。

**T5 · 主观慢动作凝视（Subjective Slow-Mo Gaze）**
- 机制：慢动作 POV 观看他人亲密/快乐，把厌恶/嫉妒内化；持续不切、几乎不可察的漂移。
- 参数：wide-angle（夸张透视=既开阔又窒息）/ 慢动作约半速[存疑具体 fps，常传约 36–48fps 可试·推断] / 透过雨湿挡风玻璃当滤镜（smeared neon + rain-streaked glass）/ 35mm f2 车内代入（出租车司机.md）。
- 触发：S15（角色病态观察、无法参与）。
- 情感意图：把隔绝/嫉妒凝固成可见的凝视。
- 正例：**出租车司机 §场景 A**（挡风玻璃霓虹雨主观 A-1）/ 泡腾片物化 A-3。见 §六 句 5/6。

**T6 · 移开的镜头（The Look-Away）**
- 机制：被拒/落空时摄影机不忍地缓横摇/缓 dolly 离开主体，停在空荡长走廊固定镜。
- 参数：50mm f2.8 / 缓横摇离开主体到空走廊 / 惨白走廊+暗（出租车司机.md）。
- 触发：S17（角色努力落空/被抛下/被拒）。
- 情感意图：用"镜头主动移开"表达孤独——连摄影机都不忍看。
- 正例：**出租车司机 §A-4**（电话被拒→镜头移开到空走廊·招牌）。见 §六 句 7。

**T7 · whip pan 双甩转场（Double-Whip Transition）**
- 机制：whip pan 做动态转场（桌到桌"double-whipping"）+ 制造焦虑节奏；可作 needle-drop 切点的运镜载体。
- 参数：快速甩镜（whip）/ 可与快速变焦 push-in 快推近脸提速组合 / 暖调多场景（好家伙.md §B-3 甩镜）。
- 触发：S18（升级失控感）/ 快切蒙太奇内的桌间转场。
- 情感意图：亢奋、焦虑、节奏提速；把两个空间"甩"成同一情绪流。
- 正例：**好家伙 §B-3**（旁白闪回快切+甩镜）。见 §六 句 8。

**T8 · 拳赛变速帧率（Emotional Frame-Rate · 主观暴力）**
- 机制：不同心理状态=不同 fps；平复/黏滞用高帧率慢放，爆发用正常/欠帧率；机位=拳台**内部**/主角 POV，弃客观广角体育机位。
- 参数（愤怒的公牛，No Film School/SlashFilm [原话/转述] · 中）：角落回合（喘息）**over-crank 48fps**、出角落回正常 → 时间黏滞；泼水镜头 **96–120fps** 极慢；微妙情绪 **30 或 36fps**；Mean Streets 醉态=摄影机绑演员身上+**under-crank 欠帧**=摇晃醉感。拳台尺寸随情绪物理改变（孤独→放大空场；窒息→收缩绳距·广传但缺 Scorsese 逐字·存疑）。
- 触发：主观暴力/生理极限状态需外化。
- 情感意图：把内心状态（平复/窒息/眩晕/醉）变成可见的时间畸变。
- 正例：（库内暂无拳击单片；出租车司机 §C 手持近战为绝望暴力对照）。见 §六 句 9。

**T9 · flash-pop 闪光武器（Flashbulb as Cut/Exposure Weapon）**
- 机制：闪光灯白帧兼作剪辑武器（遮蔽难剪转场）+ 曝光武器（极端过曝只剩瞳孔）；每次闪光音由 5–6 声叠成、用**真枪声(gunshot)**做闪光音。
- 参数（SlashFilm/No Film School [原话] · 中）：拳台镁光灯≈$90,000–$91,000；单帧过曝 highlight clip（愤怒的公牛参考·**~+11 stops** 单源·存疑待核）；The Aviator 红毯频闪"11 stops overexposed"只剩瞳孔；Weegee 1940s 黑白高反差过曝观感；SFX=gunshot-layered / crackle 音匹配 40s–50s 闪光灯声。
- 触发：需硬转场藏接口，或红毯/公众之眼的侵略性曝光。
- 情感意图：aggressive public eye 的攻击性；白帧掩盖接口。
- 正例：（库内暂无·参数备用）。见 §六 句 10。

**T10 · 俯拍 crane 撤离审判（God's-Eye Retreat）+ 去饱和红过审**
- 机制：暴力高潮后 crane 极缓垂直拉升俯瞰惨状=上帝视角冷峻抽离、无英雄；血过红判 X 时**降饱和**把血调成 burgundy(暗酒红)非鲜红、未剪一格即降到 R（手法抄自 Huston《白鲸》1956，副产颗粒感可全片统一加 grain）。
- 参数：28mm f4 / 俯 90°→升 / crane 极缓垂直拉升 / 去饱和红+昏暗（出租车司机.md §C-3）；血 S 值局部降到暗酒红。
- 触发：暴力主题=绝望/审判（非爽感）；或过审需降血又不剪镜头。
- 情感意图：冷峻审判、抽离、无英雄。
- 正例：**出租车司机 §C-3**（血泊现场 crane 缓升俯瞰·招牌）+ §C 去饱和红。见 §六 句 11/12。

## 七、禁忌清单（❌ 斯科塞斯式分镜绝不做的事）

- ❌ **带入世界一镜给上帝俯拍/离主角太远**——必须 over-the-shoulder 贴身跟随，观众才成同谋（M1/S2）。
- ❌ **Copa 型长镜架大灯破沉浸**——狭窄暗场用 practical + 全开 T1.3，不布破沉浸的大灯（S3）。
- ❌ **长镜空走、转向无动机**——每次转向要被沿途人物的迎接/让路动机化（S4）。
- ❌ **freeze frame 冻在私生活/崩溃/静止帧**——只冻自我加冕的高潮/后果帧（M3/F3/S9）。
- ❌ **把金曲当"背景乐"、切点没压在乐句转折帧**——那不是 needle-drop（M4/F4/S14）。
- ❌ **情绪反差处用金曲熟悉的高能前奏**——该用 coda/下半段制造"缺失"不安（S13）。
- ❌ **孤独/被拒时给一个悲伤特写**——应让镜头主动移开到空景，用运镜外化（M6/S17）。
- ❌ **暴力慢镜唯美化（谈笑间突发暴力）**——好家伙暴力无慢镜、突兀不预警（S18/好家伙 §C-4）。
- ❌ **把绝望暴力拍成爽感英雄化**——出租车司机式暴力=去饱和红+俯拍 crane 审判、无英雄（S18/T10）。
- ❌ **磨平所有剪辑接口**——粗粝真实处保留可见 "bumps"，别抹成好莱坞的顺滑（M7/F5）。
- ❌ **整片运镜恒定**——越接近堕落/失控日运镜越失控，运动升级曲线（M8/S18）。
