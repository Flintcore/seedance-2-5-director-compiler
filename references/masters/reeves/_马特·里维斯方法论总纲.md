# 马特·里维斯方法论总纲 · 受限视点与画外威胁（Matt Reeves's Transferable Shot-Design System）

> **定位**：导演级方法论（跨作品 · 非单片拉片）——把马特·里维斯可迁移的"分镜操作系统"抽成可查表调用的参数与规则。跨作品覆盖：科洛弗档案（found footage）→ 生人勿进（Let Me In）→ 猩球崛起：黎明/终结之战 → 新蝙蝠侠（The Batman）。
> **用途**：生成模型「分镜设计」知识库顶层调用文件。调用语法示例：`[大师参照：马特·里维斯方法论总纲.md §T1 受限视点绑定 + masters/reeves/科洛弗档案.md §场景 C 地铁夜视]`
> **配套逐镜案例**（库内现有 1 部）：`masters/reeves/科洛弗档案.md`（其余片目在 §五 标"待补拉片"）
> **红线**：本文件只收"能直接拿去摆机位/调色/写 prompt"的硬知识——不收形容词赞美、氛围空话、剧情复述。每张卡片必带**机制+参数+触发条件+情感意图+正例**五件套。可信度分级见 §九。

## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：里维斯的分镜系统 = **"把摄影机绑死在一个角色的受限视点上，让威胁始终在画外或部分可见，用不完整信息制造恐慌"**。四根支柱。① **视点绑定（POV lock）**：机位=某一角色的头/肩/持机手，观众只知道该角色知道的——found footage 全片持机（科洛弗），或叙事片里把镜头贴在主角肩后跟拍（新蝙蝠侠开场地铁跟拍）。② **画外威胁 / 少即是多**：怪兽/凶手 80% 时间不完整出现——远景、遮挡、黑暗、部分窥见（30–50%），恐惧来自"没看全"（科洛弗怪兽、生人勿进 Abby 攻击多在暗处/画外）。③ **临场恐慌运镜**：业余手持 1.5–4.0°/s + 业余急推 zoom + 镜头被现实击中（遮挡/碰撞/掉落）——运动质感=角色的生理恐慌，非平滑专业运镜。④ **主观声场 / 无配乐或极简配乐**：科洛弗全片无配乐仅环境音；到新蝙蝠侠转为 Michael Giacchino 沉重主题+雨声主观混音。母题→镜头：不完整信息→部分窥见/画外音源；沉浸恐惧→第一人称+失真质感（DV 噪点/夜视绿）；侦探凝视（新蝙蝠侠）→主观 POV+雨帘遮挡+红黑高反差。

**适用情境**：伪纪录片/found footage、怪兽灾难、都市末日、恐怖惊悚、第一人称沉浸、noir 侦探、雨夜、受限视点悬疑、画外威胁恐怖。**不适用/需改造**：需要清晰全景动作可读性的商业动作、需要上帝视角客观调度的群戏、明亮均匀高调打光的轻喜剧。

## 一、核心心智模型（8 个镜片 · How Reeves sees a shot）

### M1 · 摄影机 = 一个角色的眼睛（视点先于场面）
先问"这个镜头是谁在看、他能看到多少"，再摆机位。里维斯不做无主的上帝调度——摄影机永远归属某个在场意识（found footage 里是持机者 Hud；叙事片里是紧贴主角的第三人称受限 POV）。
- **分镜含义**：定机位前先定"视点主体 + 他的信息边界"。观众获知的信息 ≤ 该角色获知的信息。→ 见 §T1/T2。

### M2 · 威胁在画外（不完整信息 = 恐惧引擎）
恐怖不来自展示怪物，来自"知道它在但看不全"。默认把威胁放在画外、遮挡后、黑暗里、远景处，只给部分窥见。
- **分镜含义**：设计恐怖镜时先问"这次能露多少"，答案通常是 30–50% 而非全展示。见 §T3 + §F1。

### M3 · 运镜 = 角色的生理状态
手持抖动量、zoom 的粗暴程度、镜头是否被撞掉，都是角色恐慌/喘息/奔跑的外化，不是摄影美学装饰。业余=真实生理反应；平稳=角色平静。
- **分镜含义**：先定角色此刻的生理状态（走/跑/被袭/屏息），再据此设抖动率与 zoom 行为。见 §F2/T4。

### M4 · 失真即真实（反完美质感）
DV 噪点、自动白平衡漂移、时间码、夜视绿、焦点跟丢——这些"缺陷"是"这是真录像"的凭证。里维斯拥抱不完美质感作为可信度来源（found footage 尤甚）。
- **分镜含义**：found footage / 沉浸恐惧场景，主动加失真而非清除。见 §T5/M4 与 §F4。

### M5 · 声音先于画面（威胁先被听见）
怪兽吼、爪声、脚步、喘息先到，画面后到或永不给全。无配乐（科洛弗）或极简主观混音（雨声压过对白）把观众耳朵绑进角色的感知。
- **分镜含义**：恐怖/悬疑镜设计时，声源方向优先于视觉揭示；威胁的"听见"早于"看见"。见 §T8。

### M6 · 从"手持真实"到"设计化 POV"（跨作品演化）
里维斯不是只会 found footage：从科洛弗的业余持机，演化到新蝙蝠侠里高度设计化的主观第三人称（贴肩跟拍、主观雨帘、汽车追逐里绑在角色身上的机位）。核心不变的是"绑视点"，变的是"业余 vs 精致"。
- **分镜含义**：选风格时先判"要业余临场感还是精致沉浸感"，这决定手持是否上稳定器、失真是否保留。见 §F3。

### M7 · 环境即压迫（把角色关进空间）
黑暗地铁隧道、雨夜哥谭、废墟纽约、雪林（猩球）——环境不是背景，是把角色/观众困住的封闭腔体。方向、纵深、遮挡都用来收窄逃生感。
- **分镜含义**：恐惧场景优先选封闭/低可见度空间，用前景遮挡与低照度收窄视野。见 §T7/M7。

### M8 · 高反差低照度里的"看不清"（noir 与恐怖共用）
无论 DV 夜视还是新蝙蝠侠的红黑 noir，里维斯偏好把大量画面压进暗部（暗部 70–95%），让主体半隐于黑，观众和角色一起"看不清"。
- **分镜含义**：想要威胁感/侦探压迫感 → 大面积欠曝 + 少量硬光边缘/实用光源，主体部分沉入黑。见 §T6/F5。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 视点绑定 / POV
- **H1** 要沉浸式第一人称恐惧 → found footage 模式：机位=角色持机手（高度 1.6m）+ 持机者本人是故事角色 + 观众信息 ≤ 角色信息（科洛弗全片）。
- **H2** 要"精致沉浸"而非"业余"→ 第三人称受限 POV：镜头贴主角肩后/头侧跟拍，不给全景解答，但用稳定器让运动可控（新蝙蝠侠开场地铁跟拍 · 推断参数需实机校准）。
- **H3** 揭示信息时 → 让观众"和角色同时发现"，禁止提前给上帝视角的答案镜（切镜也要留在角色能感知的范围内）。

### B. 画外威胁 / 揭示纪律
- **H4** 拍怪兽/凶手/威胁体 → 默认只露 30–50%：远景（≥100m）/ 楼宇/黑暗遮挡 / 灰尘 / 部分肢体窥见，禁 ≥80% 全展示（§F1）。
- **H5** 要 jump scare → 威胁从画框边缘（右/上/画外）0.3–0.5s 突入 + 焦平面被扑近物糊死 0.2s + 角色后退（科洛弗小怪兽扑出）。
- **H6** 威胁在暗处 → 先给声音（爪声/吼声/水声）+ 只给剪影/部分轮廓，让"听见早于看见"（§M5/T8）。
- **H7** 要"更恐怖" → 不是加特写，是减信息：拉远、加遮挡、降照度、切断视频信号（§T5）。

### C. 临场恐慌运镜
- **H8** 角色常规走动 → 手持 micro-jitter 1.5–2.0°/s；紧张/跑动 → 2.5–3.0°/s；被袭/甩动 → ≥4.0°/s（科洛弗全谱）。
- **H9** 业余记录者反应 → zoom 急切粗暴：瞬间 35mm→80mm 猛拉 0.3–0.5s + 中途卡顿，禁平滑变焦（§T4）。
- **H10** 要极致临场冲击 → 让镜头被现实击中：被人群/衣服/手遮挡 0.2–1s，或被撞摇晃 ≥10°，或掉落地面（1.6m→0.1m 0.5s，视角转地面仰拍）（§T5）。
- **H11** 要"精致追逐"（叙事片）→ 机位绑在角色/载具上（车内/摩托后），运动来自被拍对象的物理运动而非摄影机漂移（新蝙蝠侠公路追逐 · 推断）。

### D. 失真质感 / found footage
- **H12** found footage → 叠加 DV 失真：数字噪点（暗部 ≥80% 时明显）+ 自动白平衡漂移（偏绿/紫/蓝）+ 屏上时间码"HH:MM:SS REC ●"+ 电池图标（§T5）。
- **H13** 完全黑暗中要拍到东西 → 切 DV 夜视模式：绿调 #2D5F3E 附近 + 极大噪点 + 暗部 90–95% + 屏上"NIGHT VISION ON"（科洛弗地铁 §场景 C）。
- **H14** 要"录像被损坏"的中断感 → 偶发信号损坏 0.3–1s：屏黑 / 倒带 / 噪点暴雨 / 静电，兼作场景过渡（§T5/H20）。

### E. 光色 / 空间 / 声音
- **H15** 恐怖/威胁场景 → 大面积欠曝，暗部 70–95%，主体半沉入黑，仅少量硬边缘光/实用光源（手电/招牌/火光）（§T6）。
- **H16** noir 侦探基调（新蝙蝠侠）→ 红黑双色：琥珀/血红实用光源 + 深黑阴影 + 雨帘前景遮挡，主体逆光半剪影（§T6 · 推断参数）。
- **H17** 封闭腔体压迫 → 选低可见度封闭空间（隧道/雨夜/废墟/雪林）+ 前景遮挡收窄视野（§M7）。
- **H18** 恐惧/末日基调 → 无配乐，仅环境音（爆炸/吼声/尖叫/喘息），让观众"听见真实"（科洛弗全片 · §T8）。
- **H19** 叙事片沉浸 → 极简主观混音：让雨/环境音压过对白、威胁声源定位在画外方向（新蝙蝠侠 · 推断）。
- **H20** 伪 1-take 连续感 → 剪辑点伪装成"录像中断/倒带/信号损坏"，不用戏剧化标准 cut（§F4）。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 画外威胁揭示比例判别（少即是多）**
```
威胁露出 ≥ 80%（全展示）      → 破坏里维斯式恐惧（禁）
威胁露出 30–50%（部分窥见）   → 里维斯推荐区间（远景/遮挡/黑暗/部分肢体）
威胁露出 = 0%（纯画外+声音）  → 更强悬念（先声后形，见 M5）
铁律：恐惧强度与"看清程度"成反比；加恐怖 = 减信息，不是加特写。
```

**F2 · 手持抖动率判别（生理状态映射）**
```
角色状态 = 常规走动/持机日常   → 1.5–2.0°/s（业余 micro-jitter）
角色状态 = 紧张/跑动/搜索      → 2.5–3.0°/s
角色状态 = 被袭/甩动/掉落      → ≥4.0°/s（极致）
抖动率 = 角色生理恐慌的读数，不是随机；平稳(<1.0°/s)=角色平静/精致 POV。
```

**F3 · 业余 vs 精致 POV 判别（跨作品分档）**
```
要"这是真录像"的临场业余感 → found footage 档：无稳定器 + DV 失真 + 时间码 + 业余 zoom（科洛弗）
要"精致沉浸"的设计化 POV    → 叙事片档：贴身跟拍 + 稳定器可控 + 保留主观受限 + 无 DV 失真（新蝙蝠侠·推断）
两档共享"视点绑定"内核，区别只在是否保留业余失真与手持是否上稳定。同一场景不混档。
```

**F4 · 伪 1-take 剪辑点判别（连续感纪律）**
```
需要剪辑但要保连续录像感 → 剪辑点伪装为：信号损坏 / 倒带 / 屏黑 / 噪点暴雨
禁用：戏剧化标准 cut / 匹配剪辑 / 交叉剪辑（破坏"一台机器连续记录"的幻觉）
镜头被遮挡/掉落也不剪——让"事故"留在画面里（科洛弗）。
```

**F5 · 低照度欠曝判别（看不清纪律）**
```
恐怖/威胁/侦探压迫场景 → 暗部占比 70–95%，主体半沉入黑
照明 = 少量硬边缘光 + 实用光源（手电/招牌/火光/雨反光），禁平打补光
判据：观众应"和角色一样看不清"；若主体全亮可读 = 失去里维斯式压迫。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 视点绑定第一人称持机（POV lock · found footage）** ｜机制：机位=角色持机手，持机者本人是故事角色，观众信息≤角色信息｜参数：机位高度 1.6m（持机高度）+ 35mm f/2.8 + DV 失真 + 全片伪 1-take｜触发：沉浸式第一人称恐惧/灾难记录｜意图：持机者=角色=观众三位一体｜正例：科洛弗档案全片（§场景 A 派对/§场景 C 地铁夜视）。

**T2 · 贴身受限第三人称跟拍（设计化 POV）** ｜机制：镜头贴主角肩后/头侧跟拍，不给上帝全景，信息随角色移动｜参数：贴身跟拍 + 稳定器可控 + 保留受限视野 + 无 DV 失真（推断参数需实机校准）｜触发：叙事片精致沉浸/悬疑跟随｜意图：既沉浸又可控的"和角色同行"｜正例：新蝙蝠侠开场地铁跟拍 / 侦探勘查（待补拉片核校）。

**T3 · 画外威胁部分窥见（少即是多）** ｜机制：威胁体只露 30–50%，其余靠远景/遮挡/黑暗/灰尘藏住｜参数：远景 ≥100m 或部分肢体窥见 30–50%，暗部 80%，黑色剪影｜触发：怪兽/凶手/威胁体出现｜意图：不完整信息=恐惧引擎｜正例：科洛弗怪兽尾巴扫桥（§场景 B 镜 B-2 露 30%）、地铁小怪兽（§场景 C 镜 C-3 露 50%）。

**T4 · 业余急切 zoom（amateur zoom pull）** ｜机制：业余记录者的粗暴推拉，非平滑变焦｜参数：35mm→80mm 猛拉 0.3–0.5s + 中途卡顿 + 到位后过冲回拉；搜索时 35→70→35mm 反复｜触发：业余者对突发事件的反应/黑暗搜索｜意图：真实记录者的应激｜正例：科洛弗派对急推（§场景 A 镜 A-1）、地铁夜视搜索（§场景 C 镜 C-2）。

**T5 · 镜头被现实击中 + 失真 + 信号损坏（Camera Hits Reality）** ｜机制：镜头被遮挡/碰撞/掉落 + DV 失真 + 视频中断，把"事故"留在画面｜参数：遮挡 0.2–1s（衣服/手/人群）/ 撞摇 ≥10° / 掉落 1.6m→0.1m 0.5s 转地面仰拍；DV 噪点+自动白平衡漂移+时间码"REC ●"；信号损坏 0.3–1s（屏黑/倒带/噪点暴雨）｜触发：混乱/奔跑/被袭/伪 1-take 过渡｜意图：沉浸式真实+反 AI 味｜正例：科洛弗镜头掉地面（§场景 B 镜 B-3）、人群遮挡（§场景 A 镜 A-4）。

**T6 · 低照度红黑高反差（noir/恐怖共用）** ｜机制：大面积欠曝，主体半沉入黑，少量硬光/实用光源勾边｜参数：暗部 70–95% + 实用光源（手电/招牌/火光/雨反光）+ noir 档加血红/琥珀点光 + 逆光半剪影｜触发：威胁场景/侦探压迫/雨夜｜意图：观众与角色一起"看不清"｜正例：科洛弗地铁黑暗（§场景 C 暗部 90%）；新蝙蝠侠红黑雨夜（推断·待补拉片）。

**T7 · 封闭腔体环境压迫** ｜机制：把角色关进低可见度封闭空间，方向/纵深/遮挡收窄逃生感｜参数：隧道/雨夜/废墟/雪林 + 前景遮挡收窄视野 + 纵深消失点被黑暗吞没｜触发：追击/逃生/悬疑压迫｜意图：环境=困住角色的腔体｜正例：科洛弗地铁隧道（§场景 C）；猩球雪林伏击、新蝙蝠侠雨夜哥谭（推断·待补拉片）。

**T8 · 声音先行 · 无配乐主观声场** ｜机制：威胁先被听见后被看见；无配乐或极简主观混音｜参数：无配乐仅环境音（爆炸/吼声/尖叫/喘息）；或极简混音让环境音/雨声压过对白，威胁声源定位画外方向；低频 30Hz 怪兽吼｜触发：恐怖/末日/悬疑｜意图：耳朵绑进角色感知｜正例：科洛弗全片无配乐（§场景 A–C）；新蝙蝠侠 Giacchino 沉重主题+雨声主观混音（推断·待补拉片）。

**T9 · DV 夜视模式（black-out 恐惧）** ｜机制：完全黑暗中切夜视，绿调失真里露出威胁｜参数：绿调 #2D5F3E 附近 + 极大噪点 + 暗部 90–95% + 屏上"NIGHT VISION ON" + 焦点频繁跟丢 + 血液显黑色｜触发：全黑环境必须拍到东西｜意图：黑暗中看见也比看不见更恐惧｜正例：科洛弗地铁夜视全段（§场景 C 镜 C-1 至 C-4）。

**T10 · 手持抖动率生理映射（恐慌调音台）** ｜机制：用抖动率量化角色生理状态，全程动态调节｜参数：走动 1.5–2.0°/s → 跑/搜索 2.5–3.0°/s → 被袭/甩动 ≥4.0°/s（≥30°/s 剧烈甩）；平静/精致 POV <1.0°/s｜触发：任何 POV 场景的情绪起伏｜意图：运动质感=角色恐慌读数｜正例：科洛弗全谱（派对 1.8 → 跟拍 2.5 → 摔落 4.0，§场景 A–C）。

## 七、禁忌清单（❌ 里维斯式分镜绝不做的事）

- ❌ **完整展示威胁体（≥80%）**——破坏"少即是多"，恐惧与看清程度成反比（§F1）。
- ❌ **上帝视角/无主机位**——摄影机必须归属某个在场意识，观众信息不得超过视点角色（§M1/H3）。
- ❌ **平滑专业 zoom（found footage 档）**——应是业余急推卡顿，非渐变（§T4/F3）。
- ❌ **Steadicam 平稳 + 干净高清（found footage 档）**——破坏业余临场感与失真可信度（§F3/M4）。
- ❌ **把 found footage 档的 DV 失真塞进精致叙事片档**——两档不混，选档前先判业余 vs 精致（§F3）。
- ❌ **恐怖场景平打补光、主体全亮可读**——应大面积欠曝，主体半沉入黑（§F5/T6）。
- ❌ **威胁先给全景视觉再补声音**——反了：声音先行，威胁先被听见（§M5/T8）。
- ❌ **戏剧化标准 cut 破坏伪 1-take**——剪辑点应伪装成信号损坏/倒带（§F4）。
- ❌ **随意堆配乐煽情**——科洛弗档=无配乐；叙事片档=极简主观混音，不铺情绪弦乐（§H18/H19）。
