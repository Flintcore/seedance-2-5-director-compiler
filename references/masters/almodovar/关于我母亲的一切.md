## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. **浓烈饱和色块（Saturated Color Blocks）**

- **物理参数**：大面积纯红 #C8102E（墙/沙发/服装/出租车）+ 钴蓝 #1B4D8C + 暖黄 #E8B84B + 高饱和 +30-50% + 色块对撞
- **物理实现**：美术刻意用大面积纯色 + 高饱和调色 + 色彩作为情感符号
- **情感意图**：浓烈的情感被色彩外化 · 红=激情/生命/血/爱

### 2. **情节剧浓情（Melodrama Embrace）**

- **物理参数**：不回避煽情 + 巧合/重逢/秘密/母爱/死亡的通俗剧元素 + 情感直接强烈 + 泪与拥抱
- **物理实现**：拥抱情节剧传统 + 强烈情感不克制 + 命运的戏剧性巧合
- **情感意图**：通俗剧的真诚能量 · 情感的浓度即力量

### 3. **女性群像（Female Ensemble）**

- **物理参数**：多个女性（及变性人/修女/演员）角色彼此扶持 + 围坐对话 + 群像调度 + 情感联结
- **物理实现**：多女性角色编织 + 彼此支撑的情感网络
- **情感意图**：女性/边缘群体的相互扶持与坚韧

### 4. **流畅优雅运镜（Fluid Elegant Movement）**

- **物理参数**：缓慢 dolly / 环绕 track / 升降 crane 0.1-0.3 m/s + 优雅流畅（非纪实手持）+ 跟随情感
- **物理实现**：精心设计的优雅运镜 + 平稳流畅
- **情感意图**：情感的流动与优雅 · 作者的精致掌控

### 5. **互文致敬（Intertextual Homage）**

- **物理参数**：戏中戏（《欲望号街车》《彗星美人》）+ 经典电影/戏剧引用 + 表演与现实的镜像
- **物理实现**：嵌套戏剧/电影段落 + 互文呼应主线
- **情感意图**：艺术与人生的镜像 · 表演即真实

### 6. **暖调室内光 + 表演浓烈外放（Warm Interior & Expressive Acting）**

- **物理参数**：暖钨丝室内光 3000-3200K + 表演分寸 60-80% 浓烈外放 + 情感直接 + 泪/笑/拥抱
- **物理实现**：暖光烘托 + 演员充分外放情感
- **情感意图**：情节剧式的情感浓度 · 真诚不掩饰
