## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：PTA 的分镜系统 = **"用运动的摄影机把权力与孤独物理化"**，五根支柱。① **斯坦尼康/推轨长镜权力引擎**：极少静止，机身以 0.05–0.3 m/s"呼吸般"跟随人物身体穿越空间（进屋、沿管道、穿走廊），流动 = 欲望推进（≠炫技滑镜）。② **广角贴人物（Man vs Space 判别）**：小空间用 24–35mm 贴近人物制造压迫与畸变亲密；大空间用同族广角把人压成 ≤15% 渺小化——同一签名两种用法。③ **压迫配乐反抚慰**：Greenwood 式不解决不谐和弦乐在"看似无事"时拉满生理张力，与画面情绪错位施压（非情绪指引）。④ **表演分寸两极**：长时克制低语 30–40% ↔ 单点爆发 85–95%，峰值前留 ≥3s 停顿；一句台词定生死。⑤ **自然光硬阴影 + 单一母题色**：Elswit 少补光、硬阴影、真实火光逆光剪影；每片锁一个 dominant 色温母题（土褐金/病态荧光绿/勃艮第红）。母题→镜头：孤独→渺小化广角 + 空旷负空间；失控→旋转/加速斯坦尼康；对峙→静默正反打 + 弦乐戛然。

**适用情境**：美国史诗/character study · 权力与贪婪寓言 · 男性孤独 · 缓慢压抑张力 · 长对白文戏 · 荒原/工业拓荒 · 群像交错（木兰花式）· 沉默对峙。**不适用/需改造**：需要快剪动作可读性的商业动作、需要客观中立记录的纪实、明亮均匀高调广告打光、依赖手持纪实晃动的题材（PTA 常态是稳定流动 · 手持是例外）。

## 一、核心心智模型（8 个镜片 · How PTA/Elswit sees a shot）

### M1 · 摄影机永不完全静止（流动 = 权力/欲望的推进）
默认状态是缓慢 dolly/track/斯坦尼康微动，而非固定机位剪辑；机身"跟着"人物身体走。流动本身承载"一步步陷入"的推进感，不靠切镜制造节奏。
- **分镜含义**：先问"这场戏摄影机跟随谁的身体、往哪个欲望推"，再定运镜。静止是需要理由的特例。→ 见 §T1/T2。

### M2 · 构图为人物在空间里的位置服务（Man vs Space）
情绪由**人物占画面的体量 + 空间体积**承载，不靠演员挤表情。人小 = 孤独/被环境碾压；人贴满 = 压迫/无处可逃。
- **分镜含义**：先定"这场戏人物是渺小还是被逼到墙角"，再选景别与占比。判别见 §F1。

### M3 · 广角贴人物（贴近却疏离的悖论）
偏好 24–40mm 广角，机位常贴近人物；广角 + 贴近 = 既物理靠近又轻微畸变疏离。既能在小空间制造压迫，也能在大空间把人压成一粒。
- **分镜含义**：想要"逼近的不适感"或"渺小的孤独"，都从广角族里选——区别在机位距离与空间体积（§F1）。

### M4 · 配乐施压不抚慰（张力不解决）
配乐（Greenwood 弦乐不谐和音 / 打击脉冲 / 持续低频）制造生理不安，与画面情绪刻意错位——平静画面配焦虑音，让观众始终处于"要出事"的预感。
- **分镜含义**：情绪张力靠声音先行铺设，而非画面煽情；"看似无事"的镜头正是拉满配乐张力之处。见 §T7/H16。

### M5 · 表演克制↔爆发的峰值反差
长时间压低声调与节奏（克制低语 30–40%），在单一时刻释放（爆发 85–95%），峰值前留长停顿。反差本身是冲击力来源。
- **分镜含义**：设计一场戏时先定"低气压时长"与"爆点位置"，别让角色全程外放。见 §T5/F3。

### M6 · 沉默与一句台词定生死
大段沉默 + 环境音压制对白；台词稀少，故关键一句（"I drink your milkshake"/"I'm finished"）成为情绪炸点。静默是乐器。
- **分镜含义**：文戏顶点用 ≥3s 静默 + 配乐戛然承接关键台词，别用连续对白稀释。见 §T6。

### M7 · 单片单一色温母题（自然光硬阴影）
Elswit 少补光、偏自然光硬阴影、用真实光源（火光 1800K / 荧光 / 钨丝）。每部片锁一个 dominant 色语义母题，全片贯穿。
- **分镜含义**：定场景色调前先定这部片的"母题色"是什么语义（被榨取的土地=土褐金 / 焦虑压抑=荧光绿 / 情欲控制=勃艮第红），再让每场落在母题内。见 §T8/F4。

### M8 · 群像交错与失控加速（另一副签名）
早期 PTA（不夜城/木兰花）有另一副面孔：快速冲刺型斯坦尼康、多线群像、同一时刻多空间平行。运动会加速甚至失控（旋转、冲刺），表达狂热/崩溃。
- **分镜含义**：拍狂热上升或集体崩溃 → 用加速/冲刺/旋转斯坦尼康 + 平行剪辑，与晚期 PTA 的缓慢流动是**同一工具的两个速度档**（§F2）。

## 二、决策启发式（20 条 if-then · 落到镜头/调色/剪辑）

### A. 运镜 / 摄影机运动
- **H1** 要"跟着人物陷入"的权力推进 → 斯坦尼康/dolly 0.05–0.3 m/s 跟随人物身体穿越空间（进屋/沿管道/穿走廊/上下楼），不切镜。
- **H2** 要狂热上升/崩溃/失控 → 加速或冲刺斯坦尼康 + 旋转，运动幅度随情绪升级（早期 PTA 档，§M8/F2）。
- **H3** 要"缓慢逼近"的压迫 → 极缓 push in 0.05 m/s（几乎察觉不到的推近特写），配长停顿。
- **H4** 要"抽离/道德俯视" → 结尾用 crane up / 升镜 0.1 m/s 拉远，把人留在大面积空旷里。
- **H5**（铁律）静止机位是特例，需有理由（静默对峙/让体量自己说话）——默认给微动"呼吸感"。

### B. 景别 / 广角族（Man vs Space）
- **H6** 空间大、要孤独/被碾压 → 广角 24–35mm 大远景，人物占比 ≤15%，压地平线，天/地大留白。
- **H7** 空间小、要压迫/无处可逃 → 广角 24–35mm 贴近人物（<1m），人物贴满或被墙三面包围。
- **H8** 要"一句定性"的微表情 → 跳到 85mm 浅景深特写（与渺小化广角形成两极，少用中景平均值）。
- **H9** 群像多线 → 用运动长镜在同一空间内串联多人，而非碎切正反打（不夜城/木兰花档）。

### C. 光影 / 色彩
- **H10** 默认 → 自然光硬阴影、少补光，接受暗部厚重与粗粝（Elswit 质感）。
- **H11** 有真实强光源（火/荧光/钨丝）→ 用它做逆光剪影或母题色，人物纯剪影 + 暗部 60–75%。
- **H12** 定场景色前 → 先定这部片的 dominant 母题色语义（§M7/F4），让每场落在母题内，不跳色。
- **H13** 拍焦虑/病态 → 荧光冷绿 + 日光灯硬顶光（推断：木兰花/大师室内档），非暖调美化。
- **H14** 拍情欲/控制/资产阶级压抑 → 深勃艮第红 / 富贵暖调 + 精致布光（魅影缝匠档），克制而非华丽。

### D. 表演 / 声音 / 节奏
- **H15** 文戏顶点 → 长时克制低语 30–40% 蓄势 → 单点骤升咆哮 85–95% → 峰值前留 ≥3s 停顿。
- **H16** "看似无事"的镜头 → 上不谐和弦乐/低频持续张力，与画面错位施压（不抚慰）。
- **H17** 关键对峙/决定 → ≥3s 静默 + 配乐戛然 + 环境音压制对白，让台词落在死寂中。
- **H18** 对白 → 低音量含混 60–70dB，迫使观众凑近听，增强压迫（DDL/文戏档）。

### E. 结构 / 母题 / 开场
- **H19** character study / 拓荒 / 孤独主题开场 → 10–15 min 零对白纯动作 + 环境音 + 不谐和弦乐，不用旁白/字幕（血色将至档）。
- **H20** 表达权力差 → 正反打站坐高低差 + 静默锁定；表达命运抽离 → 结尾升镜俯视留白。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 渺小化 vs 压迫 判别（Man vs Space 两种用法）**
```
空间大 + 人占 ≤15% + 大留白 → 渺小化广角（孤独/被碾压）      · 血色将至荒原、保龄球道
空间小 + 人贴满/被墙三面围     → 压迫广角（无处可逃/畸变亲密）· 血色将至坑内
同用 24–35mm 广角族，区别只在【机位距离 + 空间体积】，不换镜头哲学。
```

**F2 · 缓慢流动 vs 加速冲刺 判别（斯坦尼康两个速度档）**
```
沉稳权力推进 / 缓慢陷入 / 史诗孤独 → 缓慢流动 0.05–0.3 m/s（晚期 PTA：血色将至/大师/魅影缝匠）
狂热上升 / 群像交错 / 崩溃失控     → 加速·冲刺·旋转斯坦尼康（早期 PTA：不夜城/木兰花）
同为"跟随身体的运动长镜"，区别在【速度与幅度随情绪升降】。
```

**F3 · 表演峰值反差判别（克制↔爆发）**
```
基底 = 克制低语 30–40%（缓慢/含混/控制）· 时长要足够长以蓄势
爆点 = 单点骤升 85–95%（咆哮/暴力）· 全片仅少数几次
峰值前必留 ≥3s 停顿；事后可归于死寂 20%。全程外放 = 破坏反差 = 失败。
```

**F4 · 单片母题色纪律判别**
```
每部片锁一个 dominant 色语义母题，全片贯穿、不随场景跳色：
  被榨取的土地 = 土褐金 #9C6B3F（血色将至）
  焦虑/病态/体制  = 荧光冷绿（推断：木兰花/大师室内）
  情欲/控制/资产阶级 = 勃艮第红·富贵暖（魅影缝匠）
定场景色前先问"落在母题内吗"；跳出母题需有叙事理由（如火光橙红=财富即毁灭）。
```

**F5 · 配乐施压判别（张力是否解决）**
```
PTA/Greenwood 式 → 弦乐不解决 / 高频摩擦 / 打击脉冲 / 持续低频，与画面情绪错位
                   → 平静画面配焦虑音、看似无事时拉满、关键点戛然
传统情绪配乐（解决和声 / 抒情推动感动）= 反 PTA，破坏"要出事"的持续预感。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 斯坦尼康/推轨权力跟随长镜** ｜机制：机身跟随人物身体穿越空间、不切镜｜参数：斯坦尼康或 dolly 0.05–0.3 m/s"呼吸感"微动；跟人进屋/沿管道/穿走廊/上下楼；广角 24–35mm 球面为主｜触发：权力推进/缓慢陷入/带观众"跟着走"｜意图：流动 = 欲望与权力的推进感｜正例：血色将至（跟随 Plainview 爬行沿地平线 §镜A-4 track 0.1m/s、抱伤者流动 §镜B-4 track 0.2m/s）、不夜城/木兰花（长跟拍串场·PTA 标志性运用·推断/无逐镜文件）。

**T2 · 加速/冲刺/旋转斯坦尼康** ｜机制：运动长镜随情绪加速甚至失控｜参数：斯坦尼康冲刺·旋转·手持微晃升级；速度随狂热/崩溃上升；多线群像平行剪辑串联｜触发：狂热上升/集体崩溃/失控段落｜意图：把情绪的加速度物理化｜正例：不夜城（俱乐部冲刺跟拍·推断代表段）、木兰花（群像交错高潮）。与 T1 是同工具的两个速度档。

**T3 · 渺小化广角（Man Dwarfed by Land）** ｜机制：广角大远景把人压成一粒｜参数：24–35mm；人物占比 ≤15%；压/抬地平线；天空或土地大留白；纵深拉极远｜触发：孤独/被环境碾压/资本主义空洞｜意图：人在版图里渺小而孤独｜正例：血色将至开场荒原挥镐（占比 ≤10%）、结尾保龄球道独坐负空间。

**T4 · 压迫广角贴人物** ｜机制：广角 + 贴近机位制造压迫与畸变亲密｜参数：24–35mm；机位 <1m；人物贴满或被墙/土壁三面包围；暗部 70%｜触发：无处可逃/逼近的不适/贴近却疏离｜意图：物理靠近⇄心理压迫的悖论｜正例：血色将至井下坑内劳作（土壁三面包围幽闭·§镜A-2）。与 T3 同镜头族、相反用法（§F1）。

**T5 · 表演克制↔爆发峰值反差** ｜机制：长时克制低语后单点释放｜参数：基底克制低语 30–40%（缓慢含混），单点骤升 85–95%（咆哮/暴力），峰值前留 ≥3s 停顿，事后归死寂 20%｜触发：文戏顶点/权力摊牌｜意图：低气压里被突然击穿｜正例：血色将至保龄球道"I'm finished"（§镜C-3 从低语35%骤升咆哮90%）。

**T6 · 沉默 + 一句台词定生死** ｜机制：大段静默压制对白、关键一句成炸点｜参数：≥3s 静默 + 配乐戛然 + 环境音压制对白；台词低量含混 60–70dB｜触发：对峙/决定/摊牌｜意图：静默作为乐器、每句台词千钧｜正例：血色将至保龄球道对峙静默（§镜C-2）、"I drink your milkshake"。

**T7 · 压迫配乐反抚慰** ｜机制：不谐和/不解决配乐与画面情绪错位施压｜参数：弦乐高频摩擦 / 不解决和声 / 打击脉冲 / 持续低频；平静画面配焦虑音；看似无事时拉满、关键点戛然｜触发：全片张力维持/"要出事"预感｜意图：配乐施压不抚慰、不做情绪指引｜正例：血色将至全片 Jonny Greenwood 弦乐、大师（推断同类不谐和处理）。

**T8 · 自然光硬阴影 + 真实光源母题色** ｜机制：少补光 + 用真实强光源做逆光剪影/母题色｜参数：自然日光 5600K 硬阴影 / 火光 1800–2000K 逆光剪影 / 钨丝 3200K / 荧光冷绿；暗部 60–75%；低饱和粗粝｜触发：史诗荒原/焦虑室内/情欲压抑｜意图：拒绝美化、单一色语义母题贯穿｜正例：血色将至土褐金 #9C6B3F + 油井火光逆光剪影（§镜B-2）。

**T9 · 极缓 push in 逼近特写** ｜机制：几乎察觉不到的推近至面部定性｜参数：85mm 浅景深；push in 0.05 m/s；面部微表情（嘴角极微上扬/眼神映火）｜触发：一句/一个表情定人物本性｜意图：与渺小化广角形成两极、微表情定性｜正例：血色将至火光舔面特写（§镜B-3 映火瞳孔+微笑=贪婪满足）。
