## 索引摘要（≤300 字超浓缩 DNA · 用于快速匹配 · 不替代实读）

**核心 DNA**：小津×厚田的分镜系统 = **"用一套高度自律、近乎仪式化的固定语法，让时间与留白承载情绪"**，六根支柱。① **榻榻米机位**：机高≈跪坐视线 0.3-0.9m、略仰 0-10°、固定三脚架、几乎只用 50mm——观众是"在场者"非"审视者"。② **正面轴线对话**（判别铁律）：角色近乎直视镜头（偏轴 ≤10°），对话双方分给正面单人镜且**故意朝画面同侧**（有意越 180° 轴线），反标准连戏。③ **枕头镜头 pillow shot**：人物完全离场的静物/空间空镜（屋瓦/走廊/晾衣/列车/水壶）2-6s，插在段落转换处让时间流过。④ **极简固定 locked-off**：晚期彻底放弃推拉摇移，100% 锁死，靠构图与剪辑而非运镜。⑤ **纵深门框层叠**：和室拉门/廊柱/窗格多重框中框、纵深≥3 层、严格水平垂直线。⑥ **匀速剪辑 + 物哀克制**：不靠快切制造节奏、靠时间沉淀；表演克制 20-40%（微笑下的悲伤）。母题→镜头：物是人非→人离场后空镜滞留；代际隔阂→身体朝向 + 正面机位的疏离；无常释然→望窗留白 + 极轻叹息。

**适用情境**：家庭剧/代际隔阂、告别与失去、日常诗意、东方含蓄文戏、慢电影节奏、时间沉淀、反戏剧化。**不适用/需改造**：需要动作可读性与强节奏的商业动作（零运动会呆板）、奇观/强冲突爆发、标准越肩正反打连戏叙事（正面机位+越轴会破坏连戏）、需要运镜情绪推动的场面。

## 一、核心心智模型（8 个镜片 · How Ozu/Atsuta sees a shot）

### M1 · 时间与留白承载情绪（不靠运镜不靠配乐）
情绪由**时间的沉淀 + 空间的留白**承载，而非运镜、配乐、表演爆发。一个镜头"多待几拍""让时间流过"本身就是情感语言。
- **分镜含义**：先问"这场戏要沉淀多久、留白多少"，而不是"怎么切怎么运动"。→ 见 §T3/T6。

### M2 · 摄影机是一位安静的家人（在场而不审视）
机位取跪坐者视线高度、略仰、平等——观众被放进榻榻米房间"在场"，而不是俯视/审视人物。摄影机谦卑、不入侵。
- **分镜含义**：定机高时先问"我是否与人物平坐"。低机位不是风格花样，是伦理姿态。见 §T1/F1。

### M3 · 正面即亲密与违规（对着观众说话）
角色近乎直视镜头说话，把观众拉进对话；同时对话双方故意不做标准对视（都朝同侧），构成小津签名式"有意越轴"。亲密与疏离同框。
- **分镜含义**：文戏对话上正面单人镜 + 偏轴 ≤10°，反打时保持同侧朝向。这是**有意图违规**，常规叙事仍守轴线。见 §M8/F2/T2。

### M4 · 枕头镜头 = 段落呼吸与物哀余韵
人物离场的静物/空间空镜不是转场花样，是"让时间流过"的呼吸口，承载物是人非的余韵与东方"间"（ma）。
- **分镜含义**：段落转换、情绪顶点后 → 插 2-6s 人物完全离场的静物空镜。见 §T3/F3。

### M5 · 极致静止是美学核心（有意图的零运动）
locked-off 不是"没钱运动"或偷懒，而是主动选择——稳定、仪式、时间的客观流逝。晚期彻底放弃移动镜。
- **分镜含义**：小津式静止须在 设计意图 标注"有意图的静观静止"，区别于"无意图偷懒静止"。见 §M1/H。

### M6 · 构图即秩序（几何框定人）
和室建筑的拉门/廊柱/窗格天然形成多重框中框；人被嵌进礼仪空间的几何深处。严格水平垂直、精确对齐。
- **分镜含义**：先用建筑框架定纵深层叠（≥3 层）与水平垂直线，再放人。见 §T4/F4。

### M7 · 物哀 mono no aware（微笑下的悲伤）
情绪藏在克制的微表情、台词的"言外"、停顿里；对无常温柔接受，不哭不闹的深悲。表演幅度 20-40%。
- **分镜含义**：情绪顶点反而更克制——礼貌微笑、极轻叹息、望窗涣散，把悲伤压进留白。见 §T7/H。

### M8 · 反连戏视线 = 结构性疏离（同侧朝向）
故意让对话双方朝画面同侧看、"错误"的视线匹配，制造微妙的不对位——代际、隔阂、各自的心事都藏在这不对视里。
- **分镜含义**：要"表面礼貌、内里疏离"→ 反打时不做标准对视，双方朝同侧。见 §M3/F2/T2。

## 二、决策启发式（20 条 if-then · 落到镜头/构图/剪辑）

### A. 机位 / 视线高度
- **H1** 拍家庭/日常文戏 → 榻榻米机位：机高 0.3-0.9m（跪坐视线）+ 略仰 0-10° + 固定三脚架 + 50mm（全片统一焦段）+ 中等景深。
- **H2** 人物站立/走动的和室戏 → 仍保持低机位不抬高，宁可让人物上半身入框、头部接近画顶，也不俯视。
- **H3** 要"观众在场感/平等" → 机位置于对话轴线上、与人物同坐姿高度，绝不用俯拍或高机位审视。

### B. 对话 / 视线（正面机位与反连戏）
- **H4** 文戏对话单人镜 → 角色近乎正面直视镜头（视线偏轴 ≤10°）+ 居中 + 背景和室纵深虚化。
- **H5** 反打第二人 → 给正面单人镜但**朝画面同侧看**（故意不做标准对视）——小津签名式有意越轴（§F2）。
- **H6**（铁律）此越轴/正面机位仅用于刻意营造静观/正面亲密；**常规动作叙事仍须守 180° 轴线**，否则连戏崩坏（§F2）。

### C. 枕头镜头 / 过渡
- **H7** 段落转换 / 情绪顶点后 → 插 2-6s 人物完全离场的静物空镜（屋瓦/走廊/晾衣/水壶/列车/远山），locked-off。
- **H8** 要"物是人非余韵" → 人物出画后让空镜滞留在刚才有人的空间（空走廊/空屋），2-6s。
- **H9** 空镜要"活" → 只保留极微内部运动（风中衣物、缓移云、横过列车、烟囱之烟），其余全静。
- **H10** 地理/时间转场 → 远景空镜（列车横过 + 城市/田野留白），不用运镜转场、不用叠化炫技。

### D. 构图 / 光影
- **H11** 要秩序/礼仪框定 → 用和室拉门/廊柱/窗格做多重框中框、纵深 ≥3 层、人物嵌深处，严格水平垂直线。
- **H12** 要留白/呼吸 → 天空/墙面/空地留白 ≥40%，构图对齐、不塞满。
- **H13** 室内自然光 → 纸窗漫射柔和（黑白柔和灰阶 / 暗部 40-45%），不打硬光、不做戏剧化明暗。
- **H14** 望向窗外的告别镜 → 窗光逆向勾轮廓 + 窗框外远山/城市留白。
- **H15** 全片影调 → 匀质、克制、无高饱和；黑白片守中灰调、彩色期（晚期）守低饱和柔和色。

### E. 表演 / 节奏 / 母题
- **H16** 剪辑节奏 → 匀速，不靠快切制造紧张；单镜可 4-8s（长镜可 8-15s），靠时间沉淀而非切点。
- **H17** 情绪顶点 → 反而更克制（表演 ≤30%）：礼貌微笑掩失望、极轻一声叹息、望窗目光涣散——物哀（§M7）。
- **H18** 代际隔阂 → 用身体朝向（子女朝门口/低头忙事）+ 正面机位疏离，而非台词吵架。
- **H19** 无常释然 → 独坐空屋长镜（8s+）+ 大量留白 + 极慢摇扇/绵长呼吸的生理静态。
- **H20** 收尾 → 枕头镜头收束（空屋 + 窗外城市/海留白 + 仅光影极缓变化），不给情绪大特写。

## 三、判别公式（5 个 · 可测 · 设计时当 要点）

**F1 · 榻榻米机位判别（在场 vs 审视）**
```
机高 = 0.3-0.9m（跪坐视线）+ 略仰 0-10° + 固定三脚架 + 50mm → 小津式"在场者"机位
机高 > 站姿视线 / 俯拍 / 摇臂高机位            → 非小津（审视/奇观视角）
铁律：全片焦段统一 50mm、机高统一低位，不因景别改变机高逻辑。
```

**F2 · 正面机位 + 反连戏判别（有意越轴）**
```
文戏对话 + 要"正面亲密⇄结构疏离" → 正面单人镜（偏轴 ≤10°）+ 反打双方朝画面同侧（不对视）
需要清晰动作连戏 / 商业叙事      → 守标准 180° 越肩正反打，勿套小津越轴
关键：小津越轴是"有意图签名"，必须在 设计意图 标注意图；误用于普通叙事 = 连戏事故。
```

**F3 · 枕头镜头判别（呼吸 vs 转场花样）**
```
人物完全离场 + 静物/空间空镜 + 2-6s locked-off + 仅极微内部运动 → 合格枕头镜头
含人物 / 有运镜 / 有叙事动作                                  → 不是枕头镜头（是普通空镜/转场）
位置：插在段落转换处或情绪顶点后，作"间"（ma）与物是人非余韵。
```

**F4 · 纵深门框构图判别**
```
纵深 ≥3 层框中框（拉门/廊柱/窗格）+ 严格水平垂直线 + 人物嵌几何深处 → 小津式秩序构图
单层平面 / 斜线倾斜 / 塞满无留白                                → 非小津
留白建议 ≥40%，人物可渺小于礼仪空间。
```

**F5 · 静止意图判别（静观 vs 偷懒）**
```
locked-off + 有意图静观（构图密度/留白/时间沉淀承载情绪）+ 设计意图 标注 → 小津式有意图静止
locked-off 但画面空洞无信息 / 无留白设计 / 只是不想动           → 无意图偷懒静止（禁）
判据：静止镜必须靠"构图 + 留白 + 内部微动 + 时间"至少提供 2 项信息。
```

## 四、标志性技法卡片（10 张 · 五件套齐全 · 附正例锚点）

**T1 · 榻榻米机位** ｜机制：机高降到跪坐视线、略仰、固定→观众"在场"｜参数：机高 0.3-0.9m + 略仰 0-10° + 固定三脚架 + 50mm（全片统一）+ 中景深｜触发：家庭/日常文戏｜意图：平等谦卑静观、观众如同榻榻米上的家人｜正例：东京物语 §场景 A 镜 A-1（和室全景纵深）。

**T2 · 正面机位对话 + 反连戏视线** ｜机制：角色近乎直视镜头 + 双方故意朝同侧不对视｜参数：视线偏轴 ≤10° + 居中 + 反打双方朝画面同侧（有意越 180° 轴线）+ 背景纵深虚化｜触发：要"正面亲密⇄结构疏离"的文戏对话｜意图：把观众拉进对话、同时用不对视藏隔阂｜正例：东京物语 §A 镜 A-2/A-3（父母正面单人镜同侧朝向）。

**T3 · 枕头镜头（pillow shot）** ｜机制：人物离场的静物/空间空镜作段落呼吸｜参数：无人物 + 2-6s locked-off + 仅极微内部运动（风/云/列车/烟）+ 插段落转换或情绪顶点后｜触发：过渡/物是人非/"间"｜意图：让时间流过、留白余韵｜正例：东京物语 §场景 B（屋瓦/空走廊/晾衣/列车四连空镜）。

**T4 · 纵深门框层叠构图** ｜机制：和室建筑框架做多重框中框｜参数：拉门/廊柱/窗格纵深 ≥3 层 + 人物嵌几何深处 + 严格水平垂直线 + 留白 ≥40%｜触发：礼仪空间/秩序/人被空间框定｜意图：秩序规整、人渺小于礼仪空间｜正例：东京物语 §A 镜 A-1、§C 镜 C-1。

**T5 · 极简固定 locked-off（有意图静止）** ｜机制：彻底放弃推拉摇移、靠构图与剪辑｜参数：100% locked-off + 单镜 4-8s（长镜 8-15s）+ 无运镜｜触发：几乎所有场景（美学核心）｜意图：稳定仪式、时间客观流逝、摄影机=安静家人｜正例：东京物语全片；§C 镜 C-1（父亲独坐 8s 长镜）。

**T6 · 物哀克制表演（顶点更克制）** ｜机制：情绪顶点反而降幅、藏进微表情与停顿｜参数：表演幅度 20-40% + 礼貌微笑掩失望 / 极轻叹息 / 望窗涣散 + 长停顿 + 台词言外之意｜触发：告别/失去/隔阂顶点｜意图：物哀——对无常温柔接受、不哭不闹的深悲｜正例：东京物语 §C 镜 C-1/C-3（父亲丧偶后的平静空茫与释然叹息）。

**T7 · 匀速剪辑（时间沉淀节奏）** ｜机制：不靠切点制造节奏、靠时间沉淀｜参数：剪辑匀速 + 镜长匀称（多 4-8s）+ 慢电影节奏、不快切｜触发：日常/文戏全程｜意图：让节奏来自时间本身而非蒙太奇｜正例：东京物语 §A 四镜匀速推进。

**T8 · 纸窗漫射自然光** ｜机制：纸窗把自然光柔化为均匀漫射｜参数：纸窗侧前漫射 + 黑白柔和灰阶 / 暗部 40-45% + 无硬光无戏剧明暗｜触发：和室室内文戏｜意图：柔和、日常、不修饰的真实光｜正例：东京物语 §A 镜 A-1/A-2、§C 镜 C-1。

**T9 · 空间留白（间 ma）** ｜机制：天空/墙面/空地大面积留白作呼吸｜参数：留白 ≥40% + 构图对齐 + 不塞满 + 人物可渺小于空间｜触发：过渡/告别/沉淀｜意图：东方"间"、余韵、让画面呼吸｜正例：东京物语 §B 镜 B-1（屋瓦 + 天空留白）、§C 镜 C-3（窗框远山留白）。

**T10 · 望窗告别镜（逆光留白收束）** ｜机制：人物侧身望窗 + 窗框外远景留白 + 逆光勾轮廓｜参数：低机位 + 人物侧身望窗 + 窗光逆向勾轮廓 + 窗框外远山/城市留白 + 极轻叹息｜触发：无常释然/告别顶点｜意图：把释然交给留白与目光、不给情绪特写｜正例：东京物语 §C 镜 C-3（父亲望远山释然）。

## 七、禁忌清单（❌ 小津式分镜绝不做的事）
