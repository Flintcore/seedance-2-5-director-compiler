# 模式、参数与证据边界

核对日期：2026-10-25。用户提供的独立元模板与完整手册①—⑥是当前写作 SOP 的主要来源，项目经验保留〔项目观察〕身份，不当成已验证的所有平台规律。

## 模式事实
官方 API 区分首帧、首尾帧和全模态参考输入用途；首帧/尾帧图片使用 first_frame/last_frame，普通参考使用 reference_image 等。全模态参考可用文字引导关键画面，但严格对齐指定起止图时应选首尾帧场景。本 skill 默认全能参考不承担硬首帧接缝；用户要求硬对齐则给平台槽位提醒，不仅改一句提示词。参见 [创建任务 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)。

2.5 当前支持4–30秒常规生成；图片/视频/音频数量分上限为30/10/10。首尾帧、编辑和延长有各自参数条件，API首尾帧/编辑/延长采用自适应画幅，编辑时长随源片而非任意新时长。平台操作以当前实际入口为准，文本中的@本身不完成上传绑定。参见 [2.5能力与限制](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=en)。

官方写法资料明确支持同主体多视角，参考用途需逐一说明，也建议粗几何白模与明确的文字内容相配。官方还描述2.5的整数时间戳响应；本用户仍采用标题预算、镜内事件触发，不据此恢复逐秒表演控制。参见 [2.5提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)。

## 平台设置速查（不混入每镜正文）
当前方舟2.5设置含480p/720p/1080p；比例为16:9、4:3、1:1、3:4、9:16、21:9或adaptive。常规任务可指定4–30整数秒或由模型自动选择，编辑模式按源片；标题剪辑预算仍可用小数切点。首帧/首尾帧、编辑与延长的API比例采用adaptive并继承相应输入。参见上方能力文档；实际网页开放项可能不同，先核对当前入口。

本手册的480p同长试结构建议保留；若平台提供Draft任务转定稿，沿原草稿任务进入高质量成片。普通低清重新生成与该专用流程不同，不承诺逐帧复现。2.5当前规格不含4K；4K需求先确认目标平台后期放大或其他模型选择，不自动把用户的2.5任务切换到2.0。参见 [方舟视频规格与样片流程](https://docs.volcengine.com/docs/ark/video-generation-tutorial?lang=en)。

## 条件经验，不升格硬限制
- 一人一张三视图、环绕半圈以内、6秒以上长镜难、延长三次退化、2K分镜图、运镜视频3–8秒、风格最多三个形容词：可解释具体失败的经验，非统一能力门槛。
- 30秒6–10镜、每镜一个回合、每秒3–4或4–5字、10秒25–30字：都是估算案例；不能据此改对白、强分镜或拖慢打斗。
- “草稿价/草稿定稿按钮”和“换分辨率保持同一次结果”取决于平台；未确认时只建议低清同长测试，不承诺价格/确定性，不自动换到2.0。
- 空场景图不意味着结果必然空，未声明参考也不意味着必然僵住；明确职责和环境是减少歧义的方法，不作唯一病因。
- 音画一起生成不意味着删除某画面就必然删除其声音；编辑清楚列保留层。

## 影视口径修正
SOP保留真实空间、接触、轴线可读性、动作连续和对白归属；条件惯例按 [适用边界](../../modules/film-rule-scope.md) 判断。动接静先停、同景别一定跳帧、每镜必须新事件、节拍数等于镜数下限、主角越静越强、顶拍就是全知、固定机位变焦改变透视、双方动作不同时发生，都不作为普适规则执行。相关写法转成具体用途，详见 [摄影剪辑](camera-editing.md) 与 [变体](variants.md)。

手册中“七块顺序固定”与“对白声音上移”采用默认七块+明确V3例外；“台词都在画内”由明确画外/L切/J切范围修正；“一句一镜”不覆盖句中反应设计。新用户锁优先，旧批准只覆盖对应设计版本。
