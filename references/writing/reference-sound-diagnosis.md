# 参考分工、声音与失败诊断

本页是既有摘要/适配补充，不代替[②参考句库全文](handbook/02-reference-space-timeline.md)、[⑤全文和完整速查](handbook/05-sound-dialogue-diagnosis.md)。先按 [原文SOP读取](../../modules/prompt-writing-sop.md#原文-sop-读取) 获得正文，差异见 [适配表](handbook-adaptation.md)。

本页在涉及对应问题时读取；主流程始终执行 [SOP](../../modules/prompt-writing-sop.md)。表达清楚来源职责，不声称一句提示词可保证模型结果。

## 参考职责句库
正式素材编号只在【参考绑定】各出现一次，以下用“该素材”说明职责，粘贴时换规范@与统一名称。优先级由用户明确锁和任务目标决定：身份/道具/原文、几何与状态、顺序、动作/运镜、声音、风格各管自己的领域；声音原文锁不因“风格优先”被覆盖。冲突不能仅靠一个总权重表消失。

| 素材 | 继承与范围 |
|---|---|
| 人物单图/三视图 | 同一姓名的脸、体形、发型和服装；本段站姿、背景、光照按剧情；只排除图中实际会污染的拼版/棚拍底等 |
| 排除鞋等局部 | 身份服装照参考，脚部按用户已定赤足；用正向替代事实，不列身体错误长清单 |
| 场景空镜 | 建筑、材质、通路与选定光向；本段人数/活动按环境，不继承“空堂”这一状态 |
| 同场景反打图 | 写明从哪个地标看向哪个地标，与主图同一几何，不当第二个房间 |
| 道具多角度 | 同一件物的形状/材质与持有者，多视图不是多件复制 |
| 风格板 | 色调、光质、颗粒或成像，不借用其中陌生人物与构图，若构图也被授权则明确职责 |
| 服装图 | 只改变已指定服装，不重新定义脸 |
| 分镜宫格 | 格子→镜号/关键事件，箭头边框为示意；人物由身份参考确定 |
| 运镜视频 | 相机路线/观看节奏；其中人物、场景与灯光不自动继承 |
| 动作视频 | 指定角色借用指定主体的动作与节奏；相机是否借用单独说清 |
| 白模 | 世界尺度、分色角色站位/走位、遮挡和相机；精细表演/材质/光按正文与其他资产 |
| 绿幕表演 | 指定人的动作表演；加入目标空间后建立脚底接触、比例、光向和投影，不悬空 |
| 节拍音频 | 仅在明确任务下提供节奏依据；本项目直出不复制为配乐，也不无意复制参考人声，后期音乐另行交付 |
| 音色音频 | 仅指定人的声线/说话质感，台词取本段原文，不影响其他角色或复制音乐 |
| 台词录音 | 原录音对白与口型对应；与文字不同先指出来源冲突，不自行合成第三版台词 |
| 待编辑/延长源片 | 明确源片角色，而不是泛运镜参考；编辑列替换与保留，延长列新增与边界 |

多视角能否用一张拼版或多图取决于主体数量、清晰度和职责，见 [模式证据](modes-and-evidence.md)。不把“一人只能一张三视图”变成禁止保留已有面部/服装分图的规则。

## 声音八层
原手册八层用于理解声音分工；当前直出先按[SOP同期声交付](../../modules/prompt-writing-sop.md#sync-sound-delivery)选关闭项、实际环境声、背景人声、动作物理声、角色声线及跨切延续，配乐和非现场情绪音效留后期。剧情已有的现场演奏或播放声按其真实来源处理；音乐案例不自动授予直出混音范围。背景人群若不是可辨台词，可说明低声各聊各的、字句听不清、不齐声复述主对白；不把它用于应有明确集体台词的场景。

重要声音和对白在发生镜写清，声音块只汇总稳定声层、角色音色和延续规则，避免复制对白两次。同一场连续底声也可因遮挡/距离/主观听觉改变，静默要说明何种声层变低而不是凭空换世界。画外声源有方向和身份，设备声/旁白不交给画内听者配口型。表演语气/重音默认在引号外，原文和标点不动，跨镜片段分配见 SOP。

## 诊断与最小修复
下表是候选原因，不凭一个症状宣布唯一根因；先看输入和实际输出，保留已经正确的部分。

| 症状 | 优先查什么 | 最小修复方向 |
|---|---|---|
| 参考被忽略/换脸/衣服变 | 编号映射、同人多图冲突、风格图抢身份、脸是否可读 | 明确名字和职责，修冲突素材/一句描述，不把多图本身定罪 |
| 人物僵住 | 误把姿态当锁、缺持续行为、细白模约束 | 按模式区分首帧/身份参考，补具体行动；若图是真首帧就保留首态 |
| 应满的大堂空了 | 空场景状态被继承、环境缺活动 | 环境补实际人群任务，在相关镜就地点名；空场项目不套此修法 |
| 台词归错人/口型错 | 原声源没点名、跨镜余句缺失、音频职责冲突、时长 | 写当镜原声源与原文续句，试读安排；不擅自减词 |
| 该连被切 | 镜号误标、路线含瞬移/不相容机位 | 同镜改事件阶段，写阶段交接与连续范围；改硬切需用户意图允许 |
| 该切没切 | 新镜边界模糊 | 明确硬切及目标镜号/新起幅，不加一堆额外镜 |
| 摇变推、固定在晃 | 相机位移与转向混写、全段默认冲突 | 改相机位置/朝向的单一职责；固定镜例外覆盖手持默认 |
| 左右跳/人物跳位 | 把屏幕左右当世界坐标、切后未继承末态 | 固定世界基准，按新机位重算构图，保留走位后的状态 |
| 背景齐声 | 未定义背景人声/任务 | 说明独立活动与不可辨背景声；真实集体台词保留 |
| 多余音乐/字幕 | 开关或文字职责不清 | 声音/致命项写对应开关，剧情实物字与字幕区分 |
| 动作含糊/软慢 | 主受体不明、关键连接省略、每击停稳 | 保具体路径、接触、惯性接力、环境后果；不只堆“猛烈” |
| 运镜打架 | 多个运动无阶段/同步解释 | 选主要观看动作，合理复合按先后或同步关系表达 |
| 尾帧不到位 | 模式不对、中间过渡不足、末尾事情过多 | 先确认真尾帧槽，再调整过程与收拢，不拿参考图宣称硬锁 |
| 后段漂移 | 持物/方向/接触/损坏没有继承 | 当镜末态与后镜起态接续，不重回开场 |
| 局部编辑牵动别处 | 源区间与保留层不清、音画联动 | 列清保护对象/声音和区间，必要时按可分离问题分轮 |

修复时先列已正确的内容，选择主要失败点、定位相关句或参考，保持模式/参考顺序/时长等无关变量。一个因果冲突可能涉及几句，一起修其必要部分；不是每次只准改一个字。看结构先于质感，低清与高清测试边界见 V18。

## 检查的运行位置
模式、参考职责、世界轴、对白归属、切/连、起末态、默认与例外冲突等在写作过程中解决。手册检查清单落实为这些决定及维护测试，不向用户额外打印每镜自检表，不添加compiler自审循环；原版既有独立环6仍保留。
