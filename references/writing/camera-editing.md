# 摄影与剪辑写法词典

本页是既有摘要/适配补充，不代替[③全文及完整模板/案例](handbook/03-camera-editing.md)、[独立手册③/⑨/⑩](handbook/00-independent.md)。先按 [原文SOP读取](../../modules/prompt-writing-sop.md#原文-sop-读取) 获得正文，差异见 [适配表](handbook-adaptation.md)。

先执行 [SOP](../../modules/prompt-writing-sop.md)。此页解决怎样把已定摄影写成可见动作；新摄影选择仍读 [视点](../cinema/视点体系与镜头运动地基.md)、[运镜正文](../cinema/超详细运镜规格参考库.md)、[机位/光学](../cinema/机位技术规格详细参数库.md)，不只看词典就重新导演。

## 全段摄影默认与局部例外
全段交代支持方式/稳定性、运动强度、景深倾向（镜头焦距逐镜明确）、剪辑节奏和例外；这是摄影默认，不是相机品牌或焦距的同义词。可选：手持纪实（呼吸性调整）、古典稳定（固定与稳定移动）、混合（行动手持/明确落点固定）、递进（随具体冲突从稳到乱或反向）。不把四套都写进成稿。混合时具体镜头明示固定/手持即可；稳定器、轨道也可按实际加入。单镜明确选择覆盖默认，全段措辞先给例外留空间。

## 运镜词典
每项都写主体、起点、路径/方向、速度或触发、终点与可见变化；“慢/平稳/快速”是简洁选词，不禁止更具体的已定速度变化。

| 选择 | 可执行写法 | 易混处与局部修复 |
|---|---|---|
| 固定 | 三脚架锁定该构图，人物在画内行动 | 先删全段无例外手持冲突；确有漂移再补相机位置/朝向稳定，不每镜强抄三句 |
| 推近 | 摄影机沿过道向甲靠近，中景收为近景 | 写清终点距离/景别和背景视差，不误称变焦 |
| 后拉 | 摄影机后退，露出甲身旁的乙和门口 | 拉开后新增什么必须明确 |
| 横移 | 机身朝向保持，沿桌边向左平移 | 位移与转向分开，别只写“向左” |
| 原地摇 | 机位不移动，原地向右转向乙 | 起幅和终点在这台相机的可见扇区；避免凭转向穿过物体 |
| 远人→近人摇 | 近人先在画边虚化，原地摇到近人并转移焦点 | 景别变化来自两人距离不同；把机位放在能见近人脸的侧前方，不靠摇镜改变拍摄距离 |
| 甩摇 | 快速转向造成运动模糊，落到门口来人 | 说明落点和它是否是转场剪辑；模糊不是自动跨空间许可 |
| 侧后跟拍 | 从甲左侧后齐腰高跟随，保持可读距离 | 明确跟谁、哪侧、路径以及画幅位置 |
| 倒退前跟 | 摄影机在甲前方后退，甲朝摄影机走来 | 相机与人物行进方向分开描述 |
| 环绕 | 围绕甲沿已定圆弧移动，甲是构图中心 | 写真实通道、遮挡与终点；半圈不是普适上限，面部参考按需要补 |
| 弧移 | 沿桌边小弧移动，从甲侧面露出乙 | 角度按理解所需，不强填数值 |
| 升/降 | 从桌高升到回廊视点，或从梁下落到眼高 | 终点建筑和遮挡要在同一世界成立 |
| 随动作摇 | 甲起身时摄影机随甲上摇 | “同一瞬间”说明事件耦合，不是单独秒数命令 |
| 手持 | 轻微呼吸感调整；追逐中幅度加大 | 晃动服务跟随与信息，不自动全片狂晃 |
| 移焦 | 焦点由前景甲转到后景乙，甲逐渐失焦 | 相机可固定；景深与主体距离需支持，不把移焦写成移动机位 |
| 深焦 | 前景道具、中景人物、后景门口都清楚可读 | 只要求本镜关键层，必要时调整距离/光圈/照度，不把焦距当唯一开关 |
| 变焦 | 相机位置固定，变焦改变取景范围 | 固定机位单变焦不改变几何透视；别用“透视压缩”代替画幅变化 |
| 推拉变焦 | 后退同时拉长焦距，维持人物占幅，背景关系改变 | 两个同步变化写清；有技术难点时先说明和试验，保留用户锁 |
| 一镜多景别 | 相机固定，甲沿明确路线走近，由全身到近景 | 景别变化由谁造成写清，不让相机也无故跟进 |
| 穿行长镜 | 从门口绕过桌角跟到柜台，遇人让行后接乙 | 路线/注意力交接分阶段，同一镜内不插硬切编号 |

## 景别、方位与视角
大远景看人物与世界；远景看环境关系；全景完整身体；中景看姿态与交互；近景看说听细节；特写看脸/手/道具；大特写强调局部。各命名边界可按项目约定，焦距不自动决定景别。前/侧前1/4/正侧/后侧3/4/背面说明相对人物的方位；机身高低和光轴俯仰分别表达。过肩写肩属于谁、看谁；真正POV写角色目光方向及可见身体/倒影，非所有POV都排除身体。顶拍是摄影角度，不自动等于全知视角；仰俯的权力效果来自关系，不是情绪硬映射。荷兰角、桌沿低位和前景遮挡按本场意义使用。想遮脸，先设计实际背面/遮挡几何。

## 切与连
硬切明确目的镜号；动作切在同一行动相位接续；视线切交代看者与所见；匹配切明确形/色/运动关系；J切先听后见；L切旧声延续到新画面；甩摇/遮挡转场明确遮挡前后是否同一空间；有意跳切用于省略/焦躁；交叉剪辑明确两处同时或并行关系。连续镜用同一镜中的阶段，不把节拍当镜号。

顺接保世界位置、手位、道具、目光目标和动量，从新视点推出起幅。180度与30度是连续性常用手段而非所有风格的禁令；明确重新建轴、跟随跨轴或故意跳切可成立。同景别反打并非天然错误。声音桥可承担切点，但不强迫每切都有桥。

## 动静衔接四种选择
- 动接静：可让运动落入稳定构图，再切固定；也可用骤停反差。选择应与人物/观众落点相合。
- 静接动：可从起幅等待事件再启动，也可直接切到已在运动的跟拍；不自动加等待一拍。
- 动接动：看运动方向、主体动量、视觉重心和叙事因果；方向相容时连续冲势，相反时要有理由。上摇接横跟不是字面同方向。
- 静接静：以观看重点、角度/景别和人物反应组织，不必机械变焦段。

手册的“壶落桌同时停稳→固定近景”“食指点桌触发摇到江渡”“跟拍停在侧前方再摇”都是事件带相机的有效例子，见 [案例与来源边界](source-case-mai-long.md)。它们不把每个镜头末态都变成静止姿势。剪辑选择继续读 [切镜](../cinema/切镜时机学.md)、[组接意义](../cinema/蒙太奇与组接意义库.md)。

当前独立生成段的切口按[SOP段间合同](../../modules/prompt-writing-sop.md#segment-boundary)执行；不以全片语言中的焦段倾向省掉每镜焦距，也不以同段动作匹配推成跨生成无缝。
