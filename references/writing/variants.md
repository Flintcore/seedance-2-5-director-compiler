# 18种结构变体：在同一 SOP 内切换

先执行 [必读 SOP](../../modules/prompt-writing-sop.md) 与 [七块模板](../../modules/prompt-template.md)。这不是18套互相竞争的元模板；选择当前任务对应的一节，未改动职责仍沿七块。时间段为粗略预算，不把例子秒数变成动作指令；例句均是写法片段，不是已生成验证的成片。

## V1 多镜头叙事
用于一条内完成连贯戏。七块齐备，时间线按 `【0:00-0:04】镜头1 机位名。` 排序；每镜起幅、事件、反应、落幅清楚，在实际剪辑处明确“硬切到镜头2”或具体切法。镜数由叙事/表演/观看收益决定，不用30秒6–10镜作为门槛。尾态只交付当前状态，不写下一场尚未发生的剧情。知识： [镜组](../cinema/戏点选择与主镜框架法.md)、[节奏](../cinema/节奏与时长编排库.md)。

## V2 一镜到底 / 长镜头穿行
时间线开头声明单一连续镜头，阶段只写时间节点，不编号为新镜头。路线写起点、途经障碍、人物交接、终点与注意力转移，例如“跟随甲越过桌角；甲停下时摄影机继续侧移接住乙”。关键阶段用事件衔接，末尾再确认连续范围，避免描述一面要求不剪切一面硬切。景别可由人物距离、相机移动或已定变焦改变；复杂度看路线和遮挡，不以6秒作能力上限。用户明确长镜时先修路线表达，改切镜需尊重锁。知识： [运镜](../cinema/超详细运镜规格参考库.md)、[调度](../cinema/角色调度与走位参考库.md)。

## V3 对白 / 正反打
可把【声音】移到【空间】后，先明确音色/声源，再接环境和时间线。通常仍用同一七块。对白与听者行动共同推进，不机械一句一镜或说谁拍谁。过肩要写谁的肩、看向谁、世界目光目标；也允许单人景、同框、移动或听者反应镜。跨镜每镜写实际听到的原文片段与画内/画外归属，句中切镜也不断声、不重念。试读判断时长，保原词而非按固定每秒字数删减。知识： [文戏](../cinema/文戏编排参考库.md)、[对白](../cinema/对白情绪表达参考库.md)、[视线](../cinema/人物视线与目光设计参考库.md)。

## V4 动作 / 打斗
一个动作组讲清来势、意图、出手路径、接触、受力、下一次机会；一个镜头可覆盖多次快速组合，同一动作也可跨切。明确双方、武器/左右手、距离与地形。预备/恢复是因果，不要求每击完整停稳再起；双方可同时攻击、防守和失衡补救。常速为叙述基线，既定变速明确范围，不凭空加慢镜。大景别读路线，小景别读冲击；声响、材质形变、破坏残留和环境前后对比共同表现力量，特效有触点方向与后果。知识： [动作模块](../../modules/action-design.md)、[武指](../cinema/动作设计与武指体系参考库.md)、[力量](../cinema/速度与力量量化标准.md)、[破坏](../cinema/物理交互与破坏效果参考库.md)。

## V5 群像 / 多人同框
空间先区分每人的世界位置、朝向、持物和关系，画幅位置随镜头推导。身份素材逐一明确，多图可属于同一个人；不强制所有人先各出一个单人镜再同框。主线人物争取目标，背景人物有独立任务和不同接收时机；确有因果的群体反应仍可发生。知识： [群像行动](../cinema/角色行为与动作叙事参考库.md)、[构图](../cinema/构图设计参考库.md)。

## V6 空镜 / 蒙太奇 / 匹配剪辑
用物象、环境变化和镜间关系承载信息、情绪或时间，不只堆漂亮风景。可一镜一个意象、光与微动，但有意静止保持静止；2秒快切是示例节奏，不是配额。匹配切交代具体形状、运动或颜色落点；片名/logo按用户交付安排，通常后期，剧情实物字不误删。知识： [空镜](../cinema/空镜素材库.md)、[蒙太奇](../cinema/蒙太奇与组接意义库.md)。

## V7 音乐 / 节拍驱动
在参考绑定一次定义音频负责节奏、旋律或实际配乐，声音块说明是否继承人声。关键动作/剪辑点对准确认的乐句/重拍，不自动每小节都切；无对白或唱段原文按用户锁。本分支显式音乐要求覆盖默认无BGM，而非同时写相反开关。知识： [声音](../cinema/声音与音效叙事决策库.md)、[节奏](../cinema/节奏与时长编排库.md)。

## V8 运镜 / 动作迁移
在绑定中分别界定路径与表演职责，正文仍讲清角色动作；两种参考若兼有运镜/动作就说明取哪一层。使用清楚、少干扰的参考段，长度按实际可用素材与平台限制，不设3–8秒硬门槛。主体与场景各有权威，风格简洁但不设“三形容词”计数规则。知识： [摄影表达](camera-editing.md)、[动作模块](../../modules/action-design.md)。

## V9 白模预演 → 成片
仅明确白模任务或提供白模才读 [白模模块](../model/previs-reference.md)。白模提供世界尺度、站位/走位、遮挡、摄影机路径与粗节奏，分色代理逐一映射原角色；服装、材质、光、细动作、面部和对白按正文/其他素材重建。已有稿只新增一次视频绑定，保留原素材与表演，不把“有白模”当作删除动作正文的理由。默认球/圆柱等粗代理，确有指定肢体动作才局部加骨架；不自动做精细人物或渲染。门/通路/比例与前后遮挡照既有几何，不发明新的出口。

## V10 分镜图驱动
绑定中说明宫格是顺序/机位示意，格子对应哪些镜头，箭头/边框/文字仅为示意；角色身份仍取角色素材。逐镜补齐图里没有的行动、对白、光声与接续，不把宫格铺成视频静帧。画面应可读，2K是素材准备建议而非所有平台硬门槛；关键格和严格首尾画面分别处理。知识： [构图](../cinema/构图设计参考库.md)、[连续性](../cinema/镜头衔接与连续性参考库.md)。

## V11 首尾帧
平台选首尾帧模式，将图片置于对应槽位。参考绑定改写为首帧/尾帧职责，删除普通参考模式的“并非首尾帧”声明；时间线从实际首态经过有因果的中间状态到尾态。身份/服装、构图、光与持物差异要有过渡理由，不靠结尾一句跳到目标。需要拼接时核对真实末态与首态；图片对齐不等于声音和动量已经无缝。知识： [模式证据](modes-and-evidence.md)、[连续性](../cinema/镜头衔接与连续性参考库.md)。

## V12 图生视频 / 首帧
一张图就是起点。简要交代图中关键初态后，只写接下来发生的行动与相机变化，不复述整张图、不无意移动开场人物。没有尾图不写硬尾帧已锁定。连续镜或剪辑仍按用户意图说明；图生视频并非天然一镜到底。

## V13 文生视频
参考绑定写“无外部参考素材”。用主体、可见特征、场景、光源、镜头和事件因果建立画面；可以做叙事，不局限空镜。但缺身份参考时跨生成一致性风险须说明，不编造已绑定素材。具体光源比空泛“电影感”更可执行。知识： [设定](../cinema/角色与场景设定参考库.md)、[光影](../cinema/光影设计参考库.md)。

## V14 延长
绑定真实源片，明确向前/向后和新增时长，写出边界的朝向、持物、动作相位、相机、光与持续声；只写新增内容，不重开场。多次延长后出现漂移时比较回到较好基线或重新接续，不把“三次”当统一上限。优先保声画连续，格式/参数以平台为准。知识： [模式证据](modes-and-evidence.md)、[连续性](../cinema/镜头衔接与连续性参考库.md)。

## V15 局部编辑
七块中的本段目标直接写编辑目的；时间线写替换内容、源片区间与保护对象，不强迫重新编一场戏。声音块明确保留或修改的声轨。替换物承接原物入画、遮挡和出画；需要时间映射时用源时间→输出时间，区分编辑坐标和表演秒控。画面与声音联合生成意味着可能联动，不保证去掉雨画面就必然去掉雨声；需要保留就明示，复杂联动可分轮。实际 API 编辑时长/画幅限制见模式证据。

## V16 口播 / 台词主导
明确说话人、视线对象或看镜头、面部可见范围，动作服务说话任务而非定时眨眼。音频是台词录音还是音色参考要分清，录音与文本冲突先处理，不自动改词。可用持续单镜，时长按实际句子和表达试读，不设10秒25–30字普适硬限。声音按需要只保底噪/人声或允许音乐。知识： [对白](../cinema/对白情绪表达参考库.md)、[微表演](../../modules/micro-performance.md)。

## V17 志怪 / 超自然变化
按起点、传播、接触、改变状态、消散写效果；边界、受体和结果明确，身份保持或变形按剧情决定。风沙遮挡、能量裂口、瞬移等若已设定，说明作用区、结束位置和环境痕迹，不把所有变化变成泛光污染。知识： [特效](../cinema/特效真实感引擎.md)、[光影](../cinema/光影设计参考库.md)、[物理反馈](../cinema/物理交互与破坏效果参考库.md)。

## V18 低清试结构 → 正式输出
用户要实际测试时，以同长、同参考、同提示词在可用低清档试结构，先看剪辑、台词归属、身份/空间和动作，再调质感。仅平台明确提供草稿定稿功能时沿该按钮/接口；普通改变分辨率再生成存在随机性，不承诺完全保留镜头。把旧片作为参考再生成是参考生视频，不自动叫延长；延长是增加源片时间范围。报价、模型切换、真实生成与付费另按用户授权，不自动为短片降到2.0。

## 组合
V3+V4、V6+V3、V2+V17等可合用；保持一个生成模式、一套素材映射、一份世界状态和一个声音方案。镜头边界与过渡由戏决定，不要求对白转打斗必动接动、空镜转对白必静接静。复合任务只读命中的分支和相关影视正文。
