# 用户完整手册：原文与阅读入口

这里保存的是用户整条手册消息的完整内容，不是主题摘要。范围包含独立元模板十一节、完整手册①—⑥，以及该消息末尾的作者要求。原文是本 skill 的写作来源；执行时同时看上层 [适配说明](../handbook-adaptation.md)，避免把示例项目限制或与现有用户锁相冲突的句子直接移入别的影片。

## 三层边界

1. **逐字档案**：[source-verbatim.md](source-verbatim.md) 与收到的该条用户消息 UTF-8 字节一致，保留原粘贴转义、表格连排和原有说法。
2. **分册阅读版**：下表八份是按原消息连续区间分开的完整正文。只修复独立手册粘贴转义及显示字符，不删条目、例句、模板或清单，不在原文内改结论。原粘贴表格缺少列分隔的地方保留全部连排文字，不猜测或补造单元格。
3. **运行适配**：[handbook-adaptation.md](../handbook-adaptation.md) 明确哪些地方沿当前用户锁、怎样使用模式/剪辑例外。适配内容与原文分开，旧摘要词典只作索引和补充，不能代替下面的正文。

## 如何实际调用

正式任务的读取顺序由 [写作 SOP](../../../modules/prompt-writing-sop.md#原文-sop-读取) 规定：手册是必读写作基础，电影/大师库才是按问题选择；已读的同版本正文在当前上下文复用。完整新设计/大改/编译不得只看旧摘要或七块骨架就写。局部问题读取相关完整节与完整示例，不把其它章节反复重读。原版六环各自获得职责相关原文，不因主线程已读而空领目录。

找范例时：镜头语言四套模板和衔接 A—D 看③；独立手册还有第十节完整案例1—5；十八变体直接看④的相应整节；从剧本到分镜的逐步推演看⑥ 6.4。另一条用户提供的完整婉-2成稿见 [成稿范本](../handbook-gold-mai-long.md)，它不是这六份手册的替代。

## 保真与维护

`manifest.json` 记录原消息哈希、分册连续字符/字节区间、各分册哈希、全部章节位置与代码块数。开发脚本从原消息重算阅读版并逐字比较，另检查章节/18变体/44代码块。它证明本地保留和连接，不证明手册观点全部是模型硬限制，也不证明视频生成效果。
