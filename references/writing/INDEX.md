# 提示词写作资料：何时读哪一份

完整来源在 [独立元模板与①—⑥原文库](handbook/INDEX.md)，与 [来源适配记录](handbook-adaptation.md) 分开保存。当前有效写法由唯一运行SOP执行；下表提供专项完整单元的入口，需追溯来源独有例子时再取得相应原文章节，不把目录当正文。

实际读取沿 [编写 SOP](../../modules/prompt-writing-sop.md#原文-sop-读取)：新设计读 [内置导演基础](../../modules/runtime-foundation.md)；正式写稿取得 [完整成稿范本](handbook-gold-mai-long.md) 与 [唯一元模板](../../modules/prompt-template.md)，同上下文同版本正文直接复用。局部修订取受影响的完整节/例，咨询和末检不新启完整写作读取。范本承担连贯文风校准，不与电影案例取材混淆；下表资料按当前缺口选用，不形成第二个全读清单。

| 当前任务或问题 | 读取正文 | 用途 |
|---|---|---|
| 长镜、对白、动作、白模、首尾帧、编辑等结构选择 | [18种变体](variants.md)对应节 | 保持七块职责，在当前模式内改变时间线写法 |
| 推摇移混淆、摄影默认打架、剪辑/声桥接不顺 | [运镜与剪辑](camera-editing.md)对应运动/衔接节 | 把相机、注意力和切点写成可执行关系 |
| 素材职责、台词归属、背景活动、声音或具体生成故障 | [参考、声音与最小诊断](reference-sound-diagnosis.md)对应表/节 | 明确来源范围和声源，保留正确部分做最小修复 |
| 平台模式、首尾帧接续、当前参数或经验阈值有疑问 | [模式与证据](modes-and-evidence.md) | 分开平台事实、项目观察和用户写作约定 |
| 要设计表演、空间、光影、调度或选大师方法 | [知识调用地图](knowledge-map.md) → 当前相关正文 | 真正读取影视和具体作品，模板不代替取材 |
| 要看从戏核到镜头的完整推演，或遇到满堂/面罩/背景任务/画外角色等同类问题 | [《卖龙》来源案例](source-case-mai-long.md)相关段 | 学会因果和分工，不移植人物、台词与项目限制 |
| 维护本 skill、检查吸收范围和旧规则裁决 | [手册覆盖清单](handbook-coverage.md) | 审计覆盖；普通出稿不额外读此维护表 |
