## 1. 先选生成模式，再解释素材

先分清创作任务模式与平台生成模式，二者不是同一件事。平台选择在提示词外给简短操作说明；以下职责也要反映到参考绑定与时间线。

| 平台模式 | 素材的职责 | 编写和接续边界 |
|---|---|---|
| 全能参考（默认） | 图片/视频/音频提供身份、造型、空间、动作、运镜或声音依据 | 本流程不把任一参考图当硬首帧，不声称图片已锁定起始像素。按角色/场景等职责绑定，明确本任务不沿用的背景、拼版或站姿。开场仍用文字写清当前空间与行为 |
| 首尾帧 | 指定图片分别承担真正首帧与尾帧 | 平台必须选择对应模式/首尾输入槽；API 为 first_frame / last_frame。写清起态、中间过程和收拢尾态，不套“仅作参考、不作为首帧” |
| 图生视频/首帧 | 一张图承担真正首帧 | 从图中已有状态继续行动，不重造开场；无尾图时不伪称尾帧已锁定 |
| 文生视频 | 无外部素材 | 本段内仍可讲故事；跨生成的人物外观缺少参考锚，不承诺身份一致。不是只能生成空镜 |
| 编辑 | 源片为被修改对象，其他素材提供替换依据 | 分清替换和保留，原动作/遮挡/声画边界逐项承接。源片时间映射可精确写，不混成普通生成的逐秒表演命令 |
| 延长 | 实际源视频与其末态/首态是接续对象 | 仅写新增内容和接续方向；描述真实边界的姿态、动量、镜头、光与声音，不重新开场 |

全能参考可继承参考中的身份和场景状态，但不当硬首帧。本项目独立生成段默认设计为明确剪辑，不自动以首尾帧复刻来追求无缝；用户明确选真正首尾帧或源片延长时才进入相应模式。首尾输入也不保证跨次生成的曝光、色彩与动作无缝。模型能力与用户制作合同分开，见 [模式与证据](../references/writing/modes-and-evidence.md)。

<a id="segment-boundary"></a>
### 独立生成段的接点

本制作默认：先在内部比较前段末镜与新段首镜，保持人物/道具/动作相位及世界光位，摄影机在同一轴侧相对共同主体或场景基准实质换向至少30°，并得到明确不同的取景；仅换焦距、裁切、机身滚转或换主体名字不算。可配合景别变化，但不以景别变化替代本项目跨段换视角要求。它是为降低独立生成差异显眼程度的制作约定，不是宣称所有电影或首尾帧一律遵循同一限制。此处的前段末镜是选用成片实际切出的镜头，而非设计末镜。关键机位/构图/动作相位无从判定时，按[分段路由](orchestration.md#生成段边界闸门)只补必要证据，先停下段执行，不以“待核”放行。内部边界资料供设计与末检，不写“接上一段”让视频模型猜。

## 2. 先当导演，再当写手：按手册从戏出发

1. 一句话戏核：谁想要什么，被什么挡住，结果怎样。先分清用户要的效果和给的做法；明确锁定的故事、台词、摄影与已确认 L1 保持。
2. 拆节拍：看力量、关系或注意力在哪儿改变，不按台词句数平均切镜。
3. 给人物动作线：人物用什么具体行为争取目标，对手怎样接；背景人物忙自己的事。心理和性格用直白话说明，用行动兑现，不给所有人配同一套小动作。
4. 选观看立场：观众此刻站在谁身边、先看谁、暂时看不到什么。先定观看，再定机位。
5. 定空间与构图：先用固定观察基准放清世界站位，再按观看目的选择构图组织；每镜从实际机位推出起始画面的左右、前中后景、裁切与通路，动作和运镜决定它怎样变化，切镜不搬人物。
6. 选镜头：这一镜让观众看见什么，人物关系怎样变化，摄影机为什么需要移过去。前景、中景、后景可以同时讲戏；保留有用的反应、暗示和等待，不只轮流拍说话人。
7. 分时长：按行动和台词的重量分配，不平均切；标题给预算，镜内靠“当……时”、动作和气口推进。连续戏在4–30秒内优先一条生成。
8. 接上下场：内部核对边界；成稿直接写本段开场事实与本段终点，不出现依赖其他生成段的指代。跨独立生成段按上方接点合同设计明确切口。

这些决定进入已有设计稿；按 [决策驱动读取与交接](knowledge-routing.md#决策驱动读取与交接) 将未决的观看、表演和空间问题接入知识正文。思考时先定意图和观看，落笔时仍可先写焦段与起始画面，两种顺序不混用。纯编译直接继承确认设计，不重新导演。【本段目标】把戏核、人物做法和风格讲清即可，不把八步答案、镜组四问或观众感受的分析逐项抄进成稿。

## 3. 参考、空间、环境各司其职

实际素材只在【参考绑定】各出现一次规范 @imageN/@videoN/@audioN，后文用稳定姓名。图、视频、音频各写清继承什么、不继承哪些会污染当前任务的内容；不在人物绑定里续写表演分析。全能参考的图只作身份/场景依据，真实首尾帧另用对应模式。缺素材不造引用；用户已有编号保持。具体句库见 [参考与声音](../references/writing/reference-sound-diagnosis.md)。

【空间】写固定观察方向、建筑方位、人物开场位置/朝向与关键道具；【环境】写人群、杂物、独立任务、景深和共享光向。满堂场面把生活写出来，空场保留空场。环境里给背景角色常态任务，拍到关键背景时点名当下在做什么，不让人群齐刷刷陪演。

## 5. 逐镜写戏：摄影机看到什么，人物就在里面做什么

改写旧稿时，保留的是事实、对白、事件顺序、镜头与摄影决定，不是旧句型。以批准设计中已经成立的连续画面为底稿，而非把摄影、表演、状态等字段逐条串接；同一决定在多个字段出现，只表达一次。人物在具体构图里怎样行动、怎样说、另一人怎样接，按发生顺序连着写。抽象措辞有既定场面依据就直接译清；需要另选姿势、观看对象或拍法才能成立时，回到受影响的设计决定，不在正文加保证句。

标题只命名镜头，例如“【0:00-0:02】镜头1 房梁顶拍。”，不加剧情职责或寓意。正文先给必要摄影定位与下节所述的具体起始构图，随后让人物动作、对白、对手反应和运镜连着发生。每镜正文写该镜的焦距、景别、相对方位/高度/俯仰；已定值保留，开放值在设计层逐镜选定，不把焦距放本段目标统一管全段。简洁不等于省掉画面左右、层次和关键可见范围。

手册的机位、运动、层次、动作、台词、反应、落幅是需要组织的内容，不是七项都要逐句报到的口令。普通动作一句写清；关键动作把路线、接触和结果讲透。表演细节用在态度变化、听到某句话、行动被打断等真正有意味的地方；不逐部位清点，不把呼吸、手指和重心都写成慢动作。

一个主要运动统领一镜：由哪件事带起，摄影机相对哪个主体或实体沿什么方向走，原来与落幅分别看见什么；快慢服从这个观看变化。复合运动写清阶段，已定同步复合则说明关系。“跟移”“自然调焦”“保持同侧”只命名方法，仍需交付已选的跟随对象、焦点交接或本机位取景。幅度小可以成立，但不以“小幅”代替路径与落幅；固定镜以画内调度、表演或有意等待成立。全片默认与单镜例外相容，写法查 [运镜与剪辑](../references/writing/camera-editing.md)。

切点直接写“壶落桌的同时，硬切到镜头2”或“硬切到镜头2”。后镜接同一世界状态，不必复述一遍“状态保持正确”；同一镜内连续阶段不另编镜号。手册的停稳落幅用于需要平顺的动静交接，冲击剪辑与已定连续攻防保留实际动势。长镜头不借切镜省略路线。

对白直接融入行动：谁朝谁说，带着什么语气，原文用中文双引号。跨切时把实际听到的连续原词分到各镜，并点明原角色画外/画内续说；不把整句提前放首镜，反应镜只写“声音继续”。J切先听后见，L切画面已换而前声续；不因切镜添字、停顿或换说话人。表演默认引号外，长句确需定位变化才插非发声说明。原词、标点、拟声词均保持。

正文讲具体画面，不夹“这一镜承担……”“让观众理解……”“保持各自归属”等设计解说和验收结论。动机在目标里可以直说，镜内以动作兑现；并非删掉心理、微表演或连续性。必要接触、视线和后果写出后，不再解释自己遵守了哪些规则。“清楚可见”“一气呵成”可作强调，但不替代可见的取景关系与动作连接；这是语义取舍，不是禁词表。人物名称清楚，同句连续谓语共用姓名，换主体或起新句再点名；对白中的代词不动。

<a id="scene-first-handoff"></a>
### 交接信息的三种用途

- **发生的画面与声音**：已定起始构图、人物行动、对白、接收反应、运镜与显露时机进入时间线。这是编译主干；不因精简删掉决定理解的动作或暗示。
- **持续有效的世界状态**：共同身份、几何、伤势、掉落物等由绑定/空间/环境及已发生的事件建立，后镜持续继承。仅在本镜看见、发生变化或影响当前动作时局部写出；画外事实可继续存在，不强行入画或逐镜报数。下一镜也不凭未重述就重置。
- **设计理由与纠错意见**：来源、验收结论、被排除的错误动作留在设计/诊断层。返修要把原来的错误画面换成成立的画面，而非保留含糊正文、再在末尾叠加一遍纠错意见。【不可出错】只保少量仍值得独立强调的致命条件，不重讲动作流程。

这三种用途在现有字段中区分，不新增交付表、文件或自检轮。保真是决定和事实不丢，不是每个字段原句都输出；已有稿只修表达时也不借去重删除用户锁或另造动作。

<a id="standalone-readable-prose"></a>
### 无上下文也能执行的正文

本项重点是生成输入自足，不是禁止专业词或禁止思考。Agent能访问的剧本、聊天历史、项目记忆、L1、座位图和声线档案，不等于视频模型收到这些内容。每个独立segment只依赖本次实际提交的完整提示词和真实上传/绑定的素材；没有提交的前段、草图、音频和内部编号均不作为已知条件。

在现有编译步骤中按这个顺序转译，不新增交付表：

1. **确定实际输入集合**：本段提示词、真正提交的图片/视频/音频及其职责。项目曾上传过、文件在磁盘、上轮用过，不等于本次实际输入；来源事实未知就保留待核，不编造绑定。
2. **解析内部指代**：逐块识别依赖项目上下文的“同前段”“按此前位置”“A1座位”“LOOK-01”“同原声线”。从已定设计取得这些符号代表的实体、世界位置、朝向、状态与光声依据；不是把符号直接交给模型。
3. **展开成当前可辨事实**：例如“A1”若只是未上传草图编号，写“从教室门口朝黑板看，靠窗第一排临过道的座位”；相似位置仍有歧义时结合本次实际场景参考和固定观察方向明确。若A1本就是本次素材中可见标牌，或本段已明确“贴有A1标牌的座位在靠窗第一排”，可以保留；不是全局禁掉字母数字。
4. **七块共同自足**：目标直接给当前开场事实；绑定只说明实际素材；空间/环境展开位置与光源；时间线写人物行动及当镜声画；声音给本段可执行音色说明或实际音频绑定；末栏只留当前风险。设计动机可用直白心理词，内部来源/版本和未经提交的历史不进入正文。

已定角色姓名仍可稳定使用，但姓名本身不携带前段外观、位置或音色；本段必要特征和声音要有实际输入依据。需要交代的事实在本段内建立，不以删掉信息换简短；不把未知位置或声线凭空补全。

| 内部或抽象说法（仅作反例） | 当前决定已经明确时的可读写法 |
|---|---|
| 沿LOOK-01承接上一段光影 | 北墙画外房间灯照亮桌旁浅墙，墙面返光擦过佳佳朝墙一侧的脸颊；门外是弱冷月光 |
| 佳佳坐在A1，沿用此前位置 | 从教室门口朝黑板看，佳佳坐在靠窗第一排临过道的座位，面朝黑板 |
| 停在两人的关系上 | 佳佳站画左，手按桌沿；琳琳停在画右门框旁，两人之间露出一张空椅 |
| 完成情绪升级，让观众理解她受伤了 | 琳琳说完，佳佳提起的杯子停在嘴边，佳佳放回杯子，转开视线 |
| 保持道具正确归属，不出现上一场的东西 | 老钱左手握刀柄，江渡右手攥住刀身；纸包留在两人之间的台面 |

以上是表达转译例，不许可编译者凭空补杯子、椅子、月光或新动作。批准设计缺这些决定就回具体缺口；已经有了才写出来。故事对白中的“上一回”“明天”“A1”、本段明确镜头间的接续、有效心理动机和摄影术语照留，不按关键词机械删除。镜头标题只命名镜头，不写“揭示筹码”“形成压迫”等分析；【本段目标】用直白动机讲戏，镜内用可观察行为兑现；【不可出错】不放“不出现上一段的某人/某物”等历史纠错日志。当前人员确有约束则直接写本段实际人员/状态，没有新增真实风险就保持最少表达，不凑3–6条。

此项属于现有编写过程，末端沿基础检查的段落自足核对，不新增可读性审查环、词数阈值或禁词脚本。

<a id="screen-composition"></a>
### 构图落笔与去重

【空间】给真实站位，不代替逐镜起始构图。每镜起笔用连贯自然语言交代当前机位看到的布局：主体在画左、画右或中央的哪一层，前景是谁的哪一部分或哪个物件，后景实际看见什么，关键手脚、道具、接触和遮挡落在哪条画缘或画内区域。已有的前中后景都写具体；特写只写实际可见范围，没有独立前景就不添物凑层。三分、对角线等在设计时选，成稿落实为人和物的位置，不只报构图名称，也不打印逐项构图表。

随后让人物在这幅画面里行动：从哪一侧/哪一层，经什么路线到哪里，谁遮住或露出谁；摄影机随什么事件怎样移动后，画面关系如何变化。跟拍让主体留在同一画幅位置时，写背景滑移或新的显露，不再要求主体同时从画左跑到画右。固定镜也可由人物移动改变构图；无需变化的构图照留。下一个真实镜头按前镜结束世界状态与新机位重新推出左右、层次和裁切，不复制旧屏幕位置。

画框范围与所写行动相容。要从上半身看到脚下，就要有已有设计中的重取景路径、主体入画或切镜；仅听到的声音标清画外。若锁定拍法容不下关键画面，沿既有设计判断说明具体冲突，不偷偷改景别或补一刀；只缺文字定位而原设计足以推出时，直接把位置说清。开放构图选择按需读[构图投影](../references/cinema/构图设计参考库.md#frame-projection)，纯编译继承已定排列。

共享身份、整套服装、房间布局与持续身体条件各在所属块交代一次。镜内写当下可见的必要参照、状态变化及具体承托/接触，不反复背人物卡；关系刚换角度或关键身体条件决定当前动作时，局部复现仍保留。末尾致命项只留真正易错的关系，不把每镜再摘要一遍。减少的是重复证明，不是起始构图、人物行动或因果细节。

<a id="world-lighting"></a>
### 世界布光与逐镜受光

<a id="project-flat-light-ban"></a>
**本项目布光硬约束**：禁止以正面均匀补亮把全脸明暗、形体与空间层次抹平的直播式人像大平光。表情可读、黑衣细节、漂亮皮肤或历史范本不触发恒定补平。导演已允许迎面车灯等有明确来源、扫入与离开过程的短暂正面暴露：变化由实际事件带动，光离开后回到原光场，不借“有逻辑来源”替常亮美颜面光开例外。柔光不等于大平光，高调也不等于廉价，仍按本场来源、遮挡与反差保留方向和层次。这是当前项目的风格合同，不把所有场景强制压暗、统一月光或伦勃朗；其它明确风格变更沿用户当前要求。

【环境】先定整体照度、亮暗面积与人物在哪些位置显露或消失，再解释光从哪里来。逻辑光源不等于灯具必须入画：画外房间灯、窗外月光或天空散射、已有表面反射均可成立。用固定实体或世界方向锚定来源、照射方向、遮挡边界、冷暖、软硬与相对强弱；有必要时才给高度或距离，不把主光、填充、轮廓和背景灯列成必须补齐的套餐。只有场面与取景确实需要才让灯具出现，不为证明有来源新增壁灯、檐灯或光点。色调/调色与真正光源颜色分清，光源是否入画与受光是否成立分开。

<a id="scene-video-lighting"></a>
**场景光场与导演受光，两层都交付**：场景图或场景设计提供世界来源、环境亮暗分布、材质与遮挡；它不预先完成演员的脸部塑形和运动照明。【参考绑定】说明该图承担哪些依据，【环境】用本段可读文字交代实际来源的世界方位、照向、强弱、光色及背景亮暗；【时间线】仍按每镜或连续镜内阶段写人物相对光源的站位/头身朝向、摄影机实际看见的受光面/暗面/剪影，以及走位、转头或遮挡造成的变化。稳定阶段保留稳定关系，不凑光变。没有场景图时，环境照样建立这些世界事实；有场景图时也不以“按图打光”跳过逐镜设计，不强制所有任务先出场景图。场景光向与已定人物拍法有冲突，回受影响的光路或机位选择，不同时保留两套矛盾方向。

布光有未决选择时按当前缺口实读完整节：塑形与光路取[光影知识](../references/cinema/光影设计参考库.md)，墙顶返光取[反射光路](../references/cinema/光影设计参考库.md#bounce-light-path)，光随事件改变取[动态光](../references/cinema/光影设计参考库.md#motivated-dynamic-light)；画面仅有叙事功能而缺少光的组织时，取[光影美学构图](../references/cinema/光影设计参考库.md#light-aesthetic-composition)，结合[构图](../references/cinema/构图设计参考库.md)所需章节；光色选择未定取[来源色与成像关系](../references/cinema/色彩调性参考库.md#source-color-design)。这是一组条件入口，不是每次全读的套餐；同版结论复用，纯编译和末检不重新取材。先确定观看重点与藏露，再结合来源、几何和调度选择，不从光型名称倒推剧情。

夜景先保住已定夜间照度和暗区，不把白天的均匀脸光染蓝来冒充月光。月光按世界方向与门窗、屋檐、树影等遮挡进入；角色离开室内光区时，原有面光可衰减直至消失，转头也可使半脸或整张脸暂时难辨。低照度不等于全片都黑：暖亮区可以成立，但相对于周围亮，不自动提成明亮室内。用户锁定的月光或画外室内光沿用，不改造成另一盏实景灯；其它场景仍按实际来源设计，不把所有夜外景统一成月光。

人物身份与叙事可读，不等于每时刻五官、双眼、肤质或黑衣细节都清楚。剪影、暗侧失去纹理、人物融入背景可以是已定画面；按观看意图选择短暂显露、身形、动作或声音承载表演，不为展示微表情或分离黑衣自动加填充、眼神光、轮廓灯或墙面返光。光源稳定不等于人脸亮度恒定；人物走位、转脸与遮挡带来亮暗起伏时不追光或用曝光补偿消除变化。

选用剪影时正文写清“什么暗外形，衬在哪一块较亮背景上，哪段边缘或动作还能辨认”；暗脸配局部亮背景、半剪影与允许局部融合均可，整图压黑不等于剪影。主体受光与背景气氛各有职责，背景亮形不必把主体正面照亮。若已定补光，交代它补回的必要动作/表情局部、可信的直射或反射来源与范围，其余暗面照留；多个实际灯模拟同一逻辑源可以成立，不把“辅助灯”当禁用品。是否补、补哪里由观看需要决定，不用“可读”把整张脸抬成均匀亮面。

导演锁定极暗起步时，保留“身体也只剩微弱明度差”的起点，不偷换成身体清楚、只把脸压暗。若已定逐步显露，则由人物穿过既定光区依次出现局部轮廓、半脸等信息，不在开头补齐亮边或五官；具体次序仍由当前设计决定，不把这一显露曲线套给所有场景。

<a id="lighting-design-transfer"></a>
**把光影知识落实到场面**：有来源只说明光有出处，“半脸亮/另一半暗”只说明明暗分区，都不等于塑形已经设计完成。对当前需要解决的光影，沿已读知识在同一场面里确定光源与遮挡、人物头身朝向、摄影机观察侧，以及由此实际看见的亮面、阴影边界与背景亮暗面积；光源的相对尺寸/距离、墙面反射和材质按影响结果的程度取舍。光的亮度、面部反差和冷暖分别决定，不用整体压暗或染蓝代替形体。已有决定直接复用，不新开配光表或再读一轮全库。

已定可控光色的 L1 转成稿时，【环境】只写一次共享的源色温、白平衡和白物或肤色的呈色基准（饱和彩光写色相与作用范围）。把有意义的姿态和对比对象留在首次可读处，明确亮暗约差几档、哪处纹理显出或退去；随后【时间线】只随动作、遮挡或换机位写实际可见关系。用户要数值时，保留对应的设计近似值和它造成的画面，不退成“清冷、高反差”，也不逐镜抄参数或新增字段。

人脸塑形要从摄影机所见的脸面推导：想突出暗面时，可选择从人物背光侧观察，把较小的受光面留在远侧；这不是所有场景的暗侧机位规则。伦勃朗光是可选塑形方法，不是默认或必选项；采用时交代侧前上来光与人物朝向怎样形成鼻影接颊影、暗侧眼下局部亮面，以及明暗交界的软硬，而非仅印光型名称。人物转头或摄影机换侧后，这些形状可以收窄、消失或改变；按同一世界光源推导，不为复制三角亮区搬灯或强转脸。开场塑形说明其对应姿态，后续只写对观看有意义的变化，不反复要求鼻尖、下巴、嘴角和阴影保持开场关系；看向目标的动作自然成立，受光侧不决定哪边嘴角笑。有意先眼后头仍按人物策略选用，人物与摄影机可同时运动，只需区分各自造成的变化。侧光、半明半暗、逆光、柔光或高调仍在上方项目约束内按本场选择，不给所有人套同一脸光。

设计把上述关系放进现有光色策略和连续画面主干：起始看见多少，哪次走位/转头/遮挡使哪些受光面或背景区域发生变化；稳定画面则保留其稳定关系，不凑变化次数。既有知识应用记录只交接“来源机制与适用条件→当前关系与可见结果→对应镜头”，不是另抄禁令。编译保住这些具体关系，不压缩成“有层次/半边脸暗/电影光”；若关系未定或与已锁机位相冲突，只退回相关设计选择。来源说明留设计层，提示词用人物、光落点、阴影和动作直接写画面，末栏不替正文补设计。

光参与构图而非仅把主体照亮：围绕本镜观看重点，选择亮区的形状、面积和位置，暗区怎样包围或切开画面，人物与背景哪些部分分离、哪些允许融合；色光落在具体墙面、衣物或皮肤上，明度与饱和度有主次，避免所有亮点同时抢眼。来源色、相机白平衡与材质一起决定所见冷暖；一般场景可给相对关系；已选定数值控制则沿上文保留设计值，Kelvin不代替红蓝等色相、实际落点或精确生成保证。上述选择随原行动、遮挡或光源变化发展，成稿直接写光区和实体，不写寓意解说；稳定构图也成立，不为美感每镜集齐全部技巧。正暖邪冷、普遍红蓝对打或全员伦勃朗都不是默认；切镜重推投影，不让光色跟着人物标签搬家。

背景可用高窗或背侧灯在既定薄雾/尘埃里形成丁达尔可见束，写清颜色、入射路线、落到哪片墙/地面与遮挡；无介质时只写投影/光斑，不凭名称加满场雾。光的变化挂在人物、遮挡、灯具或介质的实际运动上。

每镜在起始构图或行动中写当前照度与显露结果：可以是局部亮面、门口溢光，也可以是脸退入暗处、只余身形或人物与背景合暗；不要求每镜都有漂亮脸光和轮廓分离。连续镜内交清人物穿过哪条光区或遮挡边界，何处变暗、何处局部显露，不仅在终点贴冷暖标签。换机位依据同一世界来源重推投影，不搬光源；共享来源不逐镜复抄，不另增光影字段或固定尾句。

例如已定设计为门内暗人、门外微亮墙面，可写：“佳佳停在门内暗区，头肩在门外浅灰墙面上形成暗轮廓，脸仍藏住；佳佳伸出的手越过门沿，指节接住侧方房间灯照来的窄光，琳琳看向这只手。”这是把背景分离、局部必要显露与行动写在一起；若本场没有门、浅墙或此动作，按本场已定实体表达，不套例子添物。机制出处按需见 [电影布光来源](../references/writing/film-lighting-sources.md)，不在末栏重复解释。

<a id="standalone-segment"></a>
### 单段自足与末栏选择

正式提示词面向没有项目上下文的视频模型：本段目标直接写当前地点、起始行为、冲突与本段结果；空间/环境重述当前必需的开场位置、持物及光位。“沿用上一段/下一段再发生/别出现前段某物”留在内部交接，改成当前段可见事实或直接删去无关事项。已有本段内镜号的承接可以使用；对白中的回忆/未来时原字保留。

【不可出错】先落实本段[直出交付约定](#sync-sound-delivery)，再保留已成立的身份、动作、道具等场景锁。交付开关不计入场景锁条数，也不挤掉已有锁；场景锁不设条数下限。没有场景锁就只留交付开关，不复制每镜摘要或罗列其他段剧情。历史返修先改正文，不靠末栏否定词修补场面。

## 6. 按七块交稿

顺序为【本段目标】→【参考绑定】→【空间】→【环境】→【时间线】→【声音】→【不可出错】。

这是默认完整交付。用户明确要4—8秒单镜精简稿时，允许按原文①1.7的紧凑模板，将空间/环境融入镜内；仅时长短不自动触发精简。该明确例外沿 [适配表](../references/writing/handbook-adaptation.md)，不套七块专用维护校验器。

- 本段目标：场次、时长、镜头结构、当前世界与起态、冲突、人物做法、质感与全片镜头语言（不设全段固定镜头焦距）。一段讲明这场戏，不写“本段完成的核心变化是/结尾观众应理解或感受到”套话。
- 参考绑定：每份素材只管明确职责，不在后文反复@。
- 空间：固定方位轴与人物/道具位置。
- 环境：独立生活、杂物、纵深与固定世界光位/照向/颜色/强弱；逐镜再写实际受光。
- 时间线：每镜一个连续自然段，按可见的行动、反应与运镜连写，不拆字段表，不写操作说明。
- 声音：按下方[同期声交付](#sync-sound-delivery)写关闭项、实际环境声、背景人声、动作物理声、角色音色和声音桥。事件旁可写必要声音，共享层不逐镜复抄。
- 不可出错：依下方约定写本段文字叠加开关；仅追加本段真正致命的场景锁，不凑数。

对白密集可按V3把声音块移到空间后；单镜、动作、白模、首尾帧、编辑和延长按 [18种变体](../references/writing/variants.md) 改相应部分，非当前分支不加载。镜数、机身和节奏按当前剧本与已定拍法选。

<a id="visible-texture"></a>
### 首段质感：让人看出这是哪一场

【本段目标】开头给出本场可见的整体观感。可以从场景美术、人物动作或已定成像风格起笔，哪个最能区分本场就先写哪个。把“电影感、细腻”等泛词落到已有东西上：同一道窗光，玻璃杯沿只有一点白亮，果肉边缘却透着暖色；若病床前的人一直攥着衣角，松手后衬衫上还留着那团皱褶。两种细节各回答自己的戏，不是每场都添玻璃、水果或褶皱。

整体只写一次；材质随动作改变时才在那一镜写变化，不重复整段风格，也不新增道具、光源或转色来证明质感。当前锁和批准设计优先；已明确选用的外接方法有用就落实到当前对象，无外接照样能写。具体成像介质、光色数值如已定就保留，未定不硬填；不固定首词、技法、形容词、项目数或句数，也不把库名塞进正文。

<a id="sync-sound-delivery"></a>
### 本项目直出声音边界

每条不超过30秒的直出视频视为已粗剪素材，声音按同期声范围交付：角色对白与实际发声、场景中可录到的环境声、动作接触产生的物理声。在【声音】先写“无BGM（无配乐）”，再写清当前实际声源、远近、遮挡和随动作的变化；环境自然安静时保留安静，不为了氛围硬凑声层。

普通剪辑素材的每条独立提示词都在可复制正文的【声音】写“无BGM（无配乐）”，在【不可出错】写“无字幕、无文字叠加。”。只写“同期声”或只在围栏外总述不算。完整稿、明确要求的精简单镜、各生成模式以及优化/返修后重交的成稿逐条执行；多镜共用一条提示词就写一次。只做设计、等确认或只交诊断替换句时，不为此提前交整稿。

配乐、情绪性氛围铺底、升调、惊吓撞击和脱离现场来源的强化音效留后期，不进入这份视频生成提示词。用户讨论“音乐/氛围”本身不等于要求视频直出混音；另行提出后期声音设计时在提示词外交付，不混回同期声素材。用户明确要直出配乐、字幕或指定叠字时，只替换有冲突的一项，其他开关照留。例如只要片名卡时写“无字幕，只叠加指定片名。”；只要配乐时仍写“无字幕、无文字叠加。”。编辑/延长时，明确要求保留的源片声轨、字幕或叠字也按其范围保留，不再写相反指令。节拍或风格参考本身不算要直出配乐；这不是模型能力限制或所有影视作品的通则。

剧本原有的现场演奏、收音机/电视声等依真实发声设备与空间成立，按现场声处理，不与片外配乐混同；不为绕开无配乐约定新造播放设备。有剧情依据的画外对白、旁白和声音先行/延续照实保留；不把无配乐写成静音、无对白或无旁白。无字幕与叠字指后加文字，不抹掉场景原有的招牌、纸条或屏幕字。历史手册及声音库中的配乐案例仍可用于后期研究，普通直出不自动读取或套用。

## 7. 交付和实测反馈

交付前按 [基础检查](delivery-check.md) 看成稿本身：compiler并入编译末次，原版由既有独立环6完成。此时不重新读手册/影视/大师库，不开审美重设计或额外自检轮；只修具体基础错误，保批准边界。平台模式/槽位提醒留提示词外。

看片先看剪辑、台词归属、身份、空间与动作，再看质感。记录已对的部分，只改主要失败点对应的句子或参考；对白仅导演允许才改。同长低清试结构是制作建议，当前平台是否支持草稿直接定稿以实际功能为准，重生不等于已保留原结果。

手册推演见 [来源案例](../references/writing/source-case-mai-long.md)，吸收范围见 [覆盖清单](../references/writing/handbook-coverage.md)。它们用于回查手册的因果与来源，不规定今天的文风。
