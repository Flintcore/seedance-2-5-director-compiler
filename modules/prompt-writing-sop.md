# Seedance 2.5 提示词编写 SOP · 手册写法

本 SOP 是用户独立元模板与完整手册①—⑥的执行入口，不是原文的替代摘要。完整来源见 [手册原文库](../references/writing/handbook/INDEX.md)。设计/编译/正式改稿先读本文件；真正写最终提示词前，完整读 [婉-2成稿范本](../references/writing/handbook-gold-mai-long.md)，然后用 [七块骨架](prompt-template.md)。已读且版本未变可复用；独立子 Agent 要实际获得正文。手册决定写作思路和表达方式，旧元模板、旧编译措辞和旧金标准不再并行生效。既有轻量流程或六环/L1确认门保留，影视知识负责帮助作决定，不另定义成稿文风。

## 原文 SOP 读取

读取复用以当前上下文实际取得的正文与版本为准，不以目录存在、搜到文件名或父级一句“已读”作为证据。普通任务只在既有 IR/L1 的来源应用中记录必要路径与取舍，不另写读书清单。一次长读取返回截断时，按章节或连续行段补齐未取得部分；已完整取得的部分不重读。小修只读相关完整节，首次完整任务的原文全册要求保持。

**完整手册是运行基础，不再由本页摘要代替。** 新设计、整段重写或首次正式编译时，单执行者/编排器先实际读 [独立元模板全文](../references/writing/handbook/00-independent.md) 及下面①—⑥全文，含表格、围栏模板、例句、案例和清单；再用当前骨架写稿。不是只读INDEX、覆盖表或旧词典。同一上下文已经读过且版本未变可复用，不为每镜重复读；明确的小范围修订、咨询或故障只读命中的完整节及完整示例，不重跑新设计。

多Agent时，编排器获得全册后，把各环的实际原文读取任务随派发交清；子Agent必须自己读取，或在派发中收到相同完整章节正文，不能以“主线程已读”代替内容：

- 环1解析：①、⑥全文。
- 环2场景：②全文；当前模式再取①1.2、④对应完整变体。
- 环3镜头：②、③、⑥全文，④当前完整变体；涉及跟摇/动静衔接时读独立元模板③/⑩的对应完整案例。
- 环4风格声音：⑤全文、③3.2—3.4完整节；音乐等按④相应整节。
- 环5装配：①—⑥全文和成稿范本；已锁设计只保真翻译，不重新导演。例子不只读开头，跨镜/复合运动等要读完整前后关系。
- 环6独立审查：只读当前 [基础检查合同](delivery-check.md)、本环职责与当前L2，必要时核对批准L1/锁及前段末镜；不读手册、范本、影视或大师知识。设计/编写取材留在环1—5。

固定bundle含本读取路由，不等于已内嵌以上原文；缺正文就沿链接读。电影/大师库仍按下表的当前决策需要选正文，不因手册全量接入而整库加载。日常不新增读库日志；开发行为验证才记录实际读取证据。

## 1. 先选生成模式，再解释素材

先分清创作任务模式与平台生成模式，二者不是同一件事。平台选择在提示词外给简短操作说明；以下职责也要反映到参考绑定与时间线。

| 平台模式 | 素材的职责 | 编写和接续边界 |
|---|---|---|
| 全能参考（默认） | 图片/视频/音频提供身份、造型、空间、动作、运镜或声音依据 | 本流程不把任一参考图当硬首帧，不声称图片已锁定起始像素。按角色/场景等职责绑定，明确本任务不沿用的背景、拼版或站姿。开场仍用文字写清当前空间与行为 |
| 首尾帧 | 指定图片分别承担真正首帧与尾帧 | 平台必须选择对应模式/首尾输入槽；API 为 first_frame / last_frame。写清起态、中间过程和收拢尾态，不套“仅作参考、不作为首帧” |
| 图生视频/首帧 | 一张图承担真正首帧 | 从图中已有状态继续行动，不重造开场；无尾图时不伪称尾帧已锁定 |
| 文生视频 | 无外部素材 | 本段内仍可讲故事；跨生成的人物外观缺少参考锚，不承诺身份一致。不是只能生成空镜 |
| 编辑 | 源片为被修改对象，其他素材提供替换依据 | 分清替换和保留，原动作/遮挡/声画边界逐项承接。源片时间映射可精确写，不混成普通生成的逐秒表演命令 |
| 延长 | 实际源视频与其末态/首态是接续对象 | 仅写新增内容和接续方向；描述真实边界的姿态、动量、镜头、光与声音，不重新开场 |

全能参考可继承参考中的身份和场景状态，但不当硬首帧。本项目独立生成段默认设计为明确剪辑，不自动以首尾帧复刻来追求无缝；用户明确选真正首尾帧或源片延长时才进入相应模式。首尾输入也不保证跨次生成的曝光、色彩与动作无缝。模型能力与用户制作合同分开，见 [模式与证据](../references/writing/modes-and-evidence.md)。

<a id="segment-boundary"></a>
### 独立生成段的接点

本制作默认：先在内部比较前段末镜与新段首镜，保持人物/道具/动作相位及世界光位，摄影机在同一轴侧相对共同主体或场景基准实质换向至少30°，并得到明确不同的取景；仅换焦距、裁切、机身滚转或换主体名字不算。可配合景别变化，但不以景别变化替代本项目跨段换视角要求。它是为降低独立生成差异显眼程度的制作约定，不是宣称所有电影或首尾帧一律遵循同一限制。前段资料缺失就针对末镜机位/构图/状态补一个必要问题或标记待核，不编造已完成衔接。内部边界资料供设计与末检，不写“接上一段”让视频模型猜。

## 2. 先当导演，再当写手：按手册从戏出发

1. 一句话戏核：谁想要什么，被什么挡住，结果怎样。先分清用户要的效果和给的做法；明确锁定的故事、台词、摄影与已确认 L1 保持。
2. 拆节拍：看力量、关系或注意力在哪儿改变，不按台词句数平均切镜。
3. 给人物动作线：人物用什么具体行为争取目标，对手怎样接；背景人物忙自己的事。心理和性格用直白话说明，用行动兑现，不给所有人配同一套小动作。
4. 选观看立场：观众此刻站在谁身边、先看谁、暂时看不到什么。先定观看，再定机位。
5. 定空间与构图：先用固定观察基准放清世界站位，再按观看目的选择构图组织；每镜从实际机位推出起始画面的左右、前中后景、裁切与通路，动作和运镜决定它怎样变化，切镜不搬人物。
6. 选镜头：这一镜让观众看见什么，人物关系怎样变化，摄影机为什么需要移过去。前景、中景、后景可以同时讲戏；保留有用的反应、暗示和等待，不只轮流拍说话人。
7. 分时长：按行动和台词的重量分配，不平均切；标题给预算，镜内靠“当……时”、动作和气口推进。连续戏在4–30秒内优先一条生成。
8. 接上下场：内部核对边界；成稿直接写本段开场事实与本段终点，不出现依赖其他生成段的指代。跨独立生成段按上方接点合同设计明确切口。

这些决定进入已有设计稿；按 [决策驱动读取与交接](knowledge-routing.md#决策驱动读取与交接) 将未决的观看、表演和空间问题接入知识正文。思考时先定意图和观看，落笔时仍可先写焦段与起始画面，两种顺序不混用。纯编译直接继承确认设计，不重新导演。【本段目标】把戏核、人物做法和风格讲清即可，不把八步答案、镜组四问或观众感受的分析逐项抄进成稿。

## 3. 参考、空间、环境各司其职

实际素材只在【参考绑定】各出现一次规范 @imageN/@videoN/@audioN，后文用稳定姓名。图、视频、音频各写清继承什么、不继承哪些会污染当前任务的内容；不在人物绑定里续写表演分析。全能参考的图只作身份/场景依据，真实首尾帧另用对应模式。缺素材不造引用；用户已有编号保持。具体句库见 [参考与声音](../references/writing/reference-sound-diagnosis.md)。

【空间】写固定观察方向、建筑方位、人物开场位置/朝向与关键道具；【环境】写人群、杂物、独立任务、景深和共享光向。满堂场面把生活写出来，空场保留空场。环境里给背景角色常态任务，拍到关键背景时点名当下在做什么，不让人群齐刷刷陪演。

## 4. 知识在决定处接入，元模板不代替导演

## 5. 逐镜写戏：摄影机看到什么，人物就在里面做什么

改写旧稿时，保留的是事实、对白、事件顺序、镜头与摄影决定，不是旧句型。以批准设计中已经成立的连续画面为底稿，而非把摄影、表演、状态等字段逐条串接；同一决定在多个字段出现，只表达一次。人物在具体构图里怎样行动、怎样说、另一人怎样接，按发生顺序连着写。抽象措辞有既定场面依据就直接译清；需要另选姿势、观看对象或拍法才能成立时，回到受影响的设计决定，不在正文加保证句。

标题只命名镜头，例如“【0:00-0:02】镜头1 房梁顶拍。”，不加剧情职责或寓意。正文先给必要摄影定位与下节所述的具体起始构图，随后让人物动作、对白、对手反应和运镜连着发生。每镜正文写该镜的焦距、景别、相对方位/高度/俯仰；已定值保留，开放值在设计层逐镜选定，不把焦距放本段目标统一管全段。简洁不等于省掉画面左右、层次和关键可见范围。

手册的机位、运动、层次、动作、台词、反应、落幅是需要组织的内容，不是七项都要逐句报到的口令。普通动作一句写清；关键动作把路线、接触和结果讲透。表演细节用在态度变化、听到某句话、行动被打断等真正有意味的地方；不逐部位清点，不把呼吸、手指和重心都写成慢动作。

一个主要运动统领一镜：由哪件事带起，摄影机相对哪个主体或实体沿什么方向走，原来与落幅分别看见什么；快慢服从这个观看变化。复合运动写清阶段，已定同步复合则说明关系。“跟移”“自然调焦”“保持同侧”只命名方法，仍需交付已选的跟随对象、焦点交接或本机位取景。幅度小可以成立，但不以“小幅”代替路径与落幅；固定镜以画内调度、表演或有意等待成立。全片默认与单镜例外相容，写法查 [运镜与剪辑](../references/writing/camera-editing.md)。

切点直接写“壶落桌的同时，硬切到镜头2”或“硬切到镜头2”。后镜接同一世界状态，不必复述一遍“状态保持正确”；同一镜内连续阶段不另编镜号。手册的停稳落幅用于需要平顺的动静交接，冲击剪辑与已定连续攻防保留实际动势。长镜头不借切镜省略路线。

对白直接融入行动：谁朝谁说，带着什么语气，原文用中文双引号。跨切时把实际听到的连续原词分到各镜，并点明原角色画外/画内续说；不把整句提前放首镜，反应镜只写“声音继续”。J切先听后见，L切画面已换而前声续；不因切镜添字、停顿或换说话人。表演默认引号外，长句确需定位变化才插非发声说明。原词、标点、拟声词均保持。

正文讲具体画面，不夹“这一镜承担……”“让观众理解……”“保持各自归属”等设计解说和验收结论。动机在目标里可以直说，镜内以动作兑现；并非删掉心理、微表演或连续性。必要接触、视线和后果写出后，不再解释自己遵守了哪些规则。“清楚可见”“一气呵成”可作强调，但不替代可见的取景关系与动作连接；这是语义取舍，不是禁词表。人物名称清楚，同句连续谓语共用姓名，换主体或起新句再点名；对白中的代词不动。

<a id="scene-first-handoff"></a>
### 交接信息的三种用途

- **发生的画面与声音**：已定起始构图、人物行动、对白、接收反应、运镜与显露时机进入时间线。这是编译主干；不因精简删掉决定理解的动作或暗示。
- **持续有效的世界状态**：共同身份、几何、伤势、掉落物等由绑定/空间/环境及已发生的事件建立，后镜持续继承。仅在本镜看见、发生变化或影响当前动作时局部写出；画外事实可继续存在，不强行入画或逐镜报数。下一镜也不凭未重述就重置。
- **设计理由与纠错意见**：来源、验收结论、被排除的错误动作留在设计/诊断层。返修要把原来的错误画面换成成立的画面，而非保留含糊正文、再在末尾叠加一遍纠错意见。【不可出错】只保少量仍值得独立强调的致命条件，不重讲动作流程。

这三种用途在现有字段中区分，不新增交付表、文件或自检轮。保真是决定和事实不丢，不是每个字段原句都输出；已有稿只修表达时也不借去重删除用户锁或另造动作。

<a id="screen-composition"></a>
### 构图落笔与去重

【空间】给真实站位，不代替逐镜起始构图。每镜起笔用连贯自然语言交代当前机位看到的布局：主体在画左、画右或中央的哪一层，前景是谁的哪一部分或哪个物件，后景实际看见什么，关键手脚、道具、接触和遮挡落在哪条画缘或画内区域。已有的前中后景都写具体；特写只写实际可见范围，没有独立前景就不添物凑层。三分、对角线等在设计时选，成稿落实为人和物的位置，不只报构图名称，也不打印逐项构图表。

随后让人物在这幅画面里行动：从哪一侧/哪一层，经什么路线到哪里，谁遮住或露出谁；摄影机随什么事件怎样移动后，画面关系如何变化。跟拍让主体留在同一画幅位置时，写背景滑移或新的显露，不再要求主体同时从画左跑到画右。固定镜也可由人物移动改变构图；无需变化的构图照留。下一个真实镜头按前镜结束世界状态与新机位重新推出左右、层次和裁切，不复制旧屏幕位置。

画框范围与所写行动相容。要从上半身看到脚下，就要有已有设计中的重取景路径、主体入画或切镜；仅听到的声音标清画外。若锁定拍法容不下关键画面，沿既有设计判断说明具体冲突，不偷偷改景别或补一刀；只缺文字定位而原设计足以推出时，直接把位置说清。开放构图选择按需读[构图投影](../references/cinema/构图设计参考库.md#frame-projection)，纯编译继承已定排列。

共享身份、整套服装、房间布局与持续身体条件各在所属块交代一次。镜内写当下可见的必要参照、状态变化及具体承托/接触，不反复背人物卡；关系刚换角度或关键身体条件决定当前动作时，局部复现仍保留。末尾致命项只留真正易错的关系，不把每镜再摘要一遍。减少的是重复证明，不是起始构图、人物行动或因果细节。

<a id="world-lighting"></a>
### 世界布光与逐镜受光

【环境】先把灯放在世界里：例如东墙高窗、柜台后西侧灯具，而非只有“画左打光”。逐个交代主光、必要弱填充/反射与背景光的实体位置/高度、照向谁或哪片空间、暖白/冷蓝/红等颜色、软硬及相对强弱；稳定灯位贯穿本段。色调/调色与真正光源颜色分清，红蓝双色各有源和作用区域。

人物可见脸部默认优先伦勃朗式塑形：侧前上方主光形成鼻影与颊影相接、暗侧颧部小三角亮区，暗侧仅弱反射填充，保留明暗层次而非大平光。把灯相对人物和固定实体的位置说清，不只报光型名；已锁剪影、背脸、藏眼或其它明确风格保留。人物转头/换观察角后按真实受光变化，不为每镜都看见同一个三角而搬灯或强转脸。

背景可用高窗或背侧灯在既定薄雾/尘埃里形成丁达尔可见束，写清颜色、入射路线、落到哪片墙/地面与遮挡；无介质时只写投影/光斑，不凭名称加满场雾。光的变化挂在人物、遮挡、灯具或介质的实际运动上。

每镜在起始构图或行动中加入当前可见的受光事实，即使灯稳定也写亮侧/暗面/轮廓或背景光斑落在哪个可见实体；共享灯具清单不逐镜复抄。换机位依据同一世界灯位重新推出正/侧/逆光及屏幕光影，绝非每次反打都“画左暖光”。不另增光影字段，不强制尾句。

<a id="standalone-segment"></a>
### 单段自足与末栏选择

正式提示词面向没有项目上下文的视频模型：本段目标直接写当前地点、起始行为、冲突与本段结果；空间/环境重述当前必需的开场位置、持物及光位。“沿用上一段/下一段再发生/别出现前段某物”留在内部交接，改成当前段可见事实或直接删去无关事项。已有本段内镜号的承接可以使用；对白中的回忆/未来时原字保留。

【不可出错】从已成立的本段画面挑真正致命且值得独立强调的少量条件，或用户明确的无字幕/无BGM等开关；不设条数下限，不复制每镜摘要、不罗列未发生的其他段剧情，不靠否定词修补正文。没有额外条件时写“无额外限制。”。历史返修意见先改到正文，不自动积累成永久末栏。

## 6. 按七块交稿

顺序为【本段目标】→【参考绑定】→【空间】→【环境】→【时间线】→【声音】→【不可出错】。

这是默认完整交付。用户明确要4—8秒单镜精简稿时，允许按原文①1.7的紧凑模板，将空间/环境融入镜内；仅时长短不自动触发精简。该明确例外沿 [适配表](../references/writing/handbook-adaptation.md)，不套七块专用维护校验器。

- 本段目标：场次、时长、镜头结构、当前世界与起态、冲突、人物做法、质感与全片镜头语言（不设全段固定镜头焦距）。一段讲明这场戏，不写“本段完成的核心变化是/结尾观众应理解或感受到”套话。
- 参考绑定：每份素材只管明确职责，不在后文反复@。
- 空间：固定方位轴与人物/道具位置。
- 环境：独立生活、杂物、纵深与固定世界光位/照向/颜色/强弱；逐镜再写实际受光。
- 时间线：每镜一个连续自然段，像成稿范本那样边看边发生，不拆字段表，不写操作说明。
- 声音：关闭项、持续底声、背景人声、关键音效、角色音色、声音桥。事件旁可写必要声音，共享层不逐镜复抄。
- 不可出错：只选本段实际致命事项或明确交付开关，允许零条，不以3–6条诱导补齐；没有额外条件写“无额外限制。”。

对白密集可按V3把声音块移到空间后；单镜、动作、白模、首尾帧、编辑和延长按 [18种变体](../references/writing/variants.md) 改相应部分，非当前分支不加载。题材和人物风格取自当前剧本，不照搬范本的客栈、九镜或全手持。

## 7. 交付和实测反馈

交付前按 [基础检查](delivery-check.md) 看成稿本身：compiler并入编译末次，原版由既有独立环6完成。此时不重新读手册/影视/大师库，不开审美重设计或额外自检轮；只修具体基础错误，保批准边界。平台模式/槽位提醒留提示词外。

看片先看剪辑、台词归属、身份、空间与动作，再看质感。记录已对的部分，只改主要失败点对应的句子或参考；对白仅导演允许才改。同长低清试结构是制作建议，当前平台是否支持草稿直接定稿以实际功能为准，重生不等于已保留原结果。

手册推演见 [来源案例](../references/writing/source-case-mai-long.md)，吸收范围见 [覆盖清单](../references/writing/handbook-coverage.md)。它们用于查因果和维护，不代替成稿范本，也不每次重复全读。
