# Seedance 2.5 提示词编写 SOP

这是进入设计、编译或正式改稿时的必读执行流程，不是可选知识。当前输出以本 SOP 的七块结构为主；具体模板见 [元模板](prompt-template.md)，模式变体见 [18种变体](../references/writing/variants.md)。同一上下文已经完整读过且版本未变可以复用；独立子 Agent 必须实际获得本 SOP，不以“主线程读过”代替。咨询只读涉及的部分。原有设计确认、真实六环或轻量编排各按宿主入口执行，本 SOP 不增设一环。

## 1. 先选生成模式，再解释素材

先分清创作任务模式与平台生成模式，二者不是同一件事。平台选择在提示词外给简短操作说明；以下职责也要反映到参考绑定与时间线。

| 平台模式 | 素材的职责 | 编写和接续边界 |
|---|---|---|
| 全能参考（默认） | 图片/视频/音频提供身份、造型、空间、动作、运镜或声音依据 | 本流程不把任一参考图当硬首帧，不声称图片已锁定起始像素。按角色/场景等职责绑定，明确本任务不沿用的背景、拼版或站姿。开场仍用文字写清当前空间与行为 |
| 首尾帧 | 指定图片分别承担真正首帧与尾帧 | 平台必须选择对应模式/首尾输入槽；API 为 first_frame / last_frame。写清起态、中间过程和收拢尾态，不套“仅作参考、不作为首帧” |
| 图生视频/首帧 | 一张图承担真正首帧 | 从图中已有状态继续行动，不重造开场；无尾图时不伪称尾帧已锁定 |
| 文生视频 | 无外部素材 | 本段内仍可讲故事；跨生成的人物外观缺少参考锚，不承诺身份一致。不是只能生成空镜 |
| 编辑 | 源片为被修改对象，其他素材提供替换依据 | 分清替换和保留，原动作/遮挡/声画边界逐项承接。源片时间映射可精确写，不混成普通生成的逐秒表演命令 |
| 延长 | 实际源视频与其末态/首态是接续对象 | 仅写新增内容和接续方向；描述真实边界的姿态、动量、镜头、光与声音，不重新开场 |

全能参考可用文字要求向参考关键画面靠拢，但不等于首尾帧模式的强约束。本项目若要求匹配上一条末帧，优先把实际末帧放入首帧槽；需要声画与运动接续时比较原视频延长。首尾图一致也不自动证明整段拼接无缝，仍看动作相位、曝光、镜头与声音。模式能力与参数核证见 [模式与证据](../references/writing/modes-and-evidence.md)。

## 2. 明确这段戏，而不是先填镜头参数

分开用户要的效果、提出的做法和明确锁定的做法。效果是判断目标；开放做法可提出更合适的设计，明确锁定或已确认 L1 则保留，实质矛盾走现有设计判断流程。

在已有简报/L1/IR里想清：谁想从谁那里得到什么、眼前阻力、采取什么行动、怎样接收对方、结尾关系或处境怎样改变；并明确观众这组镜头应看懂、感到或暂时不解什么。纯编译继承确认内容，不新编动机。世界事实、角色误判与观众所知分开。既有心理可以用直白话给模型讲戏，随后落实成看得见的行动，不把“表演只写可见”误读为删除动机。

按力量/关系/注意力变化拆节拍，节拍不是句数，也不是镜数下限。给每个有关角色一条动作线：持续任务、注意对象、接收刺激、策略调整与余态；背景人物有自己的工作，不齐刷刷配合主角。有意静止、隐藏心理或空镜沿原意，不凑眨眼、小动作和新事件。

## 3. 参考、空间和环境先成立

每份实际素材只在【参考绑定】出现一次规范 `@imageN/@videoN/@audioN`，沿上传编号逐一映射到稳定名称。正文一律用姓名/稳定称谓，重新起句或换主体继续点名；手、目光对象、武器和画外声也点明归属。原对白里的代词逐字保留。占位符便于粘贴，是否已选中平台素材另行确认。

每个参考给一个明确职责组：继承哪些内容、哪些容易污染本场的元素不沿用。身份与服装可以同属一组；多个视角也可以属于同一个人，不把一人一图当硬限制。全能参考的普通身份图不当静帧或首尾帧；首尾帧、关键帧分支按实际职责例外。已有素材不重编号；旧来源合并职责，不重复@；缺素材就诚实写“无外部参考素材”。绑定句与声音职责见 [参考/声音/诊断](../references/writing/reference-sound-diagnosis.md)。

用固定的世界观察基准交代建筑方位：门、窗、桌、柱、通路；给出人物开场位置、朝向、关键持物/接触与相容比例。固定的是世界几何，不是人物全段脚位，也不是每镜恒定的画左画右。每镜从前镜世界末态经过新机位重新推出可见构图；走位后更新状态，切镜不搬人。

环境补足本场实际需要的人、杂物、独立活动与层次。满堂客栈要有人气，空房或隔离特写则保留空与静；不把“背景永远有人”推广到所有项目。共享常态在【环境】说清，重要背景活动在发生镜就地写，不靠全局一句替代镜内事件。仅要求实际需要读清的层次清楚，景深由空间/光学条件支持。

## 4. 知识在决定处接入，元模板不代替导演

新设计、重做或开放的表演/摄影问题，必须沿下表实际读相关正文；已锁纯编译只读本 SOP、模板与当前模式所需规则。按需不是可随意跳过，也不是所有知识全读。完整知识覆盖见 [知识调用地图](../references/writing/knowledge-map.md)，具体写法见 [写作资料索引](../references/writing/INDEX.md)。细节沿原有 [知识路由](knowledge-routing.md)；单一问题读对应完整章节，跨域才扩读，读过且仍适用的可复用。大师知识按当前设计需要选具体作品，不以索引当作品全文。

| 决策点/症状 | 实际读取入口 | 决定要落到哪里 |
|---|---|---|
| 戏核、镜组重点与叙事视角 | [镜组四问](../references/cinema/戏点选择与主镜框架法.md)、[导演体系](../references/cinema/导演体系/导演判断总纲.md)、[视点](../references/cinema/视点体系与镜头运动地基.md) | 本段目标、镜组职责、知情与藏露，不逐镜新增事件 |

## 5. 从人物事件选择摄影与衔接

先选择观众依附谁、知道多少、看什么，再定景别、焦段、相对机位/高度/俯仰、构图与运动。摄影参数开头简洁，随后马上交代画面里谁在何处、正在做什么。一个主要观看运动统领镜头；合理复合运动写清阶段、同步关系、路径和终点，不把“只能一运动”变成摄影禁令。

镜内按“起态→触发/意图→可见行动→接触/变化→反应→末态”组织连贯叙述，不机械填六格；人物动作、对白、运镜和反应可以并发。高速动作允许连续多击、双方同时攻防与恢复中反攻；大景别讲路线，小景别读冲击，保持关键接触和环境反馈；不让每招都重新蓄力、停稳。

每处真正剪辑声明切到哪一镜，并在需要时说明动作切、视线切、匹配切或声桥。同一连续镜内部用事件阶段，不给阶段另编镜号。末态是世界状态和动作相位，不一定静止；后镜从新角度接住它，不要求像素构图相同。动静衔接可用停稳落幅，也可为冲击/反差直接切，依据戏，不每次强制停一拍。前后屏幕运动或视觉重心需可读，不把“上摇接右跟”说成方向天然一致。

跨镜同句：每镜点名真实声源和画内/画外，写本镜实际听到的连续原文片段；按顺序拼回原句原标点。反应镜也写续句，不把整句塞第一镜后只写“声音继续”。J切先听后见，L切先换画面而前声继续；不因切镜添加省略号、句号或重念。单镜边说边运镜保持自然连续。对话并非轮到谁说就只能看谁。

标题时间是整体预算与顺序，采用【0:00-0:04】；不平均分配，不在镜内再按秒排眨眼、气口和动作。可响应时间戳不等于帧级保证；对白可说性按原句试读/语气/动作判断，不用统一汉字率改台词。4–30秒内的连贯戏优先一次生成；镜多、动作复杂或换内外景本身不是自动拆条理由，必要超过30秒或用户明确要求再分。

## 6. 七块装配：每块只写它负责的事

默认顺序固定：【本段目标】→【参考绑定】→【空间】→【环境】→【时间线】→【声音】→【不可出错】。对白密集且需先交代音色/声源时，可按 V3 明确将【声音】移到【空间】之后，其余顺序不变。短单镜的精简表达也保留这些职责，不暗中混回旧六部分。18种变体按当前任务读取，不全量灌入。

- **本段目标**：场次、时长、结构、世界地点；角色要什么/做什么/结果是什么，必要的心理与观众落点；成像质感和全段摄影默认。直接讲人话，不输出 IR 字段、锁号、抽象评价术语。只写本段实际承接与交付的状态，不预演下一场情节。
- **参考绑定**：只讲来源分工及明确范围；使用本地@占位符，不照搬手册双花括号。每份实际素材一次。
- **空间**：世界基准、固定地标、开场站位/朝向/持物与比例。动态变化由时间线接续。
- **环境**：人群与物件的独立持续活动、实际层次、共享光向；按场景需要写，安静空场如实说明。
- **时间线**：每镜自然段，摄影定位→起始可见画面→人物行动与说听反应→运动/光声变化→落幅与切点。七要素是组织依据，不输出①②拆项表。具体光和音效就地发生，不再强制每镜附同样的“光影/现场声”两句，也不把关键事件拆到别栏。稳定光声在共享块说一次，局部变化仍在镜内。
- **声音**：关闭项、持续声层、背景人声、角色音色、画内音乐/配乐/旁白区别、静默与跨剪辑延续。台词原文仍在当镜发生处，不复制一整套到声音块。
- **不可出错**：最后选少量致命事项，通常3–6条；若只有一两项就如实写，不凑数。优先具体肯定句和正向关系；字幕/BGM等开关按用户要求，实际剧情文字和声音不误删。能由机位、动作、参考职责解决的先在正文成立，尾部不修补矛盾。

全段摄影默认描述支持方式/稳定性、运动强度、景深焦段倾向、剪辑节奏与例外；混合或递进时明确各自范围，局部明确选择覆盖默认，不同时保留全片无例外手持与固定镜。姓名、服装关键特征一致，但不每镜复写人物档案。

## 7. 交付与按结果修订

直接交当前段完整可复制提示词，平台模式/槽位提醒放围栏外。正文无路径、内部角色代号、读库日志、推理或自检表。原版环6仍按既有独立审查职责执行，compiler 不新加复核循环；一致性在组织时解决，维护脚本只在改 skill 或用户明确诊断时运行。

看实际成片先看结构、声源与身份、空间和动作连续性，再看质感。保留已正确的部分，针对主要失败点最小修改；因果相连的几句可一起修，但不要同时换模式、参考、时长与整段表达以致失去对照。用户对白逐字保留，时长冲突用节奏/镜头/用户批准的时长解决，只有导演允许才改词。低清同长试片可节省结构试错成本；是否有草稿转高清按钮以平台为准，普通低清重生不保证同一镜头，不把再次参考生成叫延长或定稿。

完整覆盖与已修正边界见 [手册吸收清单](../references/writing/handbook-coverage.md)。这份清单是维护证据，日常不额外加载。
