# 内置导演地基：从创作意图到连续画面

本页是新设计的常驻基础正文，不是任选专题。设计者实际取得本页后作决定；同上下文同版本已有正文可复用，纯编译直接继承已定设计。执行路径见 [编排](orchestration.md)，唯一写作规则见 [SOP](prompt-writing-sop.md)，专题由 [知识路由](knowledge-routing.md) 选择。本页负责共同因果，详细技法/作品按具体缺口加载；并非把全部知识压成几句原则。

## 1. 戏核与观看先于摄影

先分清角色想要的、用户希望观众获得的，以及用户建议的手段。用“谁争取什么、受什么阻碍、怎样应对、结果怎样”提炼当前戏核，保留剧本留白，不替角色编不存在的动机。一个节拍是行动、关系、信息或力量的实际变化，不等于一句台词，也不自动等于一个镜头。

镜头组先回答四问：呈现什么剧本信息；产生什么观众情绪；台词和表演怎样塑造人物；观众看懂/解读什么。继而选观看立场：观众靠近谁，知道多少，何时知道，暂时见不到什么。主观、旁观、全知不是固定角度套餐；顶拍不自动全知，主观也不一定晃动。摄影服务这次观看，不为炫技加无用事件；固定镜、等待、隐藏反应也能有表达收益。

## 2. 人物先行动，再体现性格

每个人有当前任务、对象与策略。写清实际收到的刺激、理解/误解、试图改变对方的行动，以及对方怎样接。听者可在说话过程中改变目光、手上任务或距离，不等整句说完才摆表情。沉默也需要对象和情境，角色只对已感知信息反应；画外发生、角色知道、观众知道分别成立。

七力四感用于当前目标、处境和可观察行动，不逐镜点名训练术语或规定眉眼动作配额。普通动作围绕对象和完整应对写明，回看让眼、头与肩颈自然协同；有意掩饰、僵住或视线先行才细分部位，不为微表情数量拆动作。真正态度变化再写具体接收、阻碍、延续或换策略。持续任务失常可以比新增表情更有力；有意克制和看不见脸照留。详细定义与条件在 [人物行动](../references/cinema/角色行为与动作叙事参考库.md)，局部精细问题再取 [微表演](micro-performance.md)。

动作和身体遵循承托、重心、接触、动量与后果；攻防/对话反应可重叠，不把每步变成停稳动作。动作主语、对象、路径和结果明确，失去的武器、疲劳与破坏残留不在切镜后重置。持续搏斗再进入动作专项，不用普通文戏的慢停顿覆盖连招。

## 3. 世界、机位与屏幕构图分开

先给世界固定基准：门窗/桌子/通路、人物开场位置和朝向、关键持物/支撑、实际可见与可走条件。再从选定机位推导画左/画右、前中后景、遮挡和裁切。世界位置不因反打搬动；“窗边”不等于每个视角都在画右。切镜承接世界状态和动作相位，不复刻像素构图。

构图先有观看重点：谁占主要面积，亮暗/色块/线条把注意引到哪里；人物间距离、负空间、前景遮挡表达什么关系。三分、对角线、框中框只提供组织方式，成稿要落成人物和物件的位置。已有前中后景写具体，特写没有独立前景就不添物凑数。构图可演变：人物从左前景走向中景门边，或摄影机越过前景后显露后方听者；变化原因和终点取景都说清。

景别决定看多少，机位/距离决定透视关系，焦距与画幅影响取景，焦点和景深选择注意层；变量相互约束，不能用一个焦距词代替空间设计。逐镜选焦距、景别、相对方位/高度/俯仰；全片质感中的35mm胶片不等于所有镜头35mm。

## 4. 光色和声音参与设计，不在结尾贴标签

先定此刻必须读到的信息与可以隐藏的部分，再安排主体亮暗和背景亮形。剪影不是曝光失败：选择人物后方的局部亮墙、窗外天色或路面等实际背景，让暗的头肩外形、两人之间的负空间或手势在其上成立；有意融合的边缘可继续融入暗处，不靠全周轮廓灯把人物描一圈。需要读到表情的节拍再显出必要眼神、口角或侧脸，观众不必同时看全五官。无人场景只设计背景与可行动空间，不画人形占位。

主体塑形与背景气氛分别分配任务：哪片鼻颧/衣褶迎光，哪片颊面/躯干保留连续阴影；背景哪个亮形引导注意，哪些区域退后。高反差来自这些局部关系，不靠把亮面和暗面一起压低。直射检查“原始源 → 人物/物体”；借反射或扩散时再检查“原始源 → 实际受照墙顶或扩散面 → 人物/物体”，最后从摄影机观察侧推导可见结果；每段路径考虑遮挡、材质色染和强度损失。光源可在画外，不为解释来源插入灯具。软硬由主体看到的有效光源视角尺寸决定，大小和距离共同作用；柔光不等于高亮、低反差或正面补平。控制多余返光可以保留暗侧，并非向脸投黑光。

补光先回答“当前究竟缺哪一点必要信息”：若手势已能讲清，就保留暗脸；若关键接收全被藏住，才从现有来源或可信的反射路径给该局部最低必要亮度，保留周围暗面与主光方向。多个拍摄灯可以共同模拟一个可信逻辑来源，灯数不等于画面来源数；问题是无依据的均匀追亮，不是辅助灯这一类别。补光不是自动动作，也不是一律省略；纯编译仅保留已定方案，不自行添灯。

明确固定世界灯位/方向、照向、有效发光面、冷暖和相对强弱；人物转身/移动/遮挡改变受光，换摄影机只改变观察关系，不搬灯。固定的是世界光源，不是移动脸上的鼻影、亮斑或表情侧别；先让视线目标和身体行动成立，再推导各相位受光，不为保住开场亮面限制转头或让眼球代偿。脸、衣服、墙与金属的反射形态不同。色温与白平衡共同影响近白光呈色，饱和彩光另写色相、范围和落点；没有实测资料不把猜测Kelvin当作品事实。主色/辅色、暗面、负空间和背景亮面共同组织画面，不把所有地方染成同一种颜色。

**需要可控光色或反差时**（含明确选用这类布光方法），在 L1 主动定本场的设计近似值并说出肉眼结果，不等用户逐项报数。对有意义的近白来源，分别定世界源位、光源色温（CCT）和相机白平衡（WB）：说明已有白物或肤色在该光区呈什么颜色、哪里保留本色。饱和彩光定色相、范围和受染材质，不硬换算 K；明确要色相数值可用近似色相角，若指调色软件的绿–洋红偏移则注明所用标尺。反差取同一姿态、同一曝光下具体的亮面和暗面，定相差约几档，以及哪处还读得出纹理；再决定原动作或遮挡怎样改变显露。选值随戏，不把别处的数字当默认，更不是从参考成片反推实测参数。

总体暗度先于人像光型：夜景可让身形难辨、眼睛无光、暗侧纹理消失；不为看清脸补出恒亮人像层。伦勃朗只是特定方向形成的塑形结果，不是每镜贴同一三角亮斑。动态光要有实体来源、扫入/经过/离开、恢复原光场；人物走位、转头、摄影机换侧及光源/遮挡移动分别说明，别把观察角变化误写成灯在追人。可见光束需要光路和介质。当前项目的明确布光约定见 [SOP](prompt-writing-sop.md#project-flat-light-ban)，有方向与层次的柔光仍可成立。

场景图的静态光场与导演的逐镜布光都要设计，互不替代：前者交代世界来源、空间亮暗和材质，后者决定演员站在何处、朝向光源哪一侧、此机位见到什么亮暗及动作怎样改变它。沿 [场景与视频双层交接](prompt-writing-sop.md#scene-video-lighting) 把世界依据写进环境、实际受光写进各镜或连续镜内阶段；已有图不免写，无图也可用文字完成世界光场，不强制每段先生成场景图。

这些常驻方法可直接使用，不以读获奖片访谈为前置；需查出处或迁移边界时才读 [电影布光来源](../references/writing/film-lighting-sources.md)。学习的是具体机制，不是奖项标签、全片色调或未披露的灯距/色温。

直出声音按[本项目同期声交付](prompt-writing-sop.md#sync-sound-delivery)分为持续环境、可辨对白与实际动作接触；配乐及非现场情绪音效留后期，不因风格案例主动加入。远近/遮挡/听点与空间相容；声桥写具体哪层声跨切。背景人物有自己的活动，不齐声复述主对白。画外发声注明角色和方向，无对白/无配乐是不同开关。声音可以先于显露或延续余韵，不为营造情绪捏造剧情声源。

## 5. 摄影、节奏与连续性共同收束

一个主要观看变化统领一镜：由什么事件触发，摄影机相对谁沿什么路线走，起幅和落幅分别看见什么。复合运动分清先后/同步；推移、原地摇和变焦的几何区别清楚。不动也有选择，不默认每镜微推。

切点来自行动、接收、信息或情绪，不按台词数量平均切镜。保持轴侧和目光/运动关系，普通接镜避免小角度且近似构图的无意跳切；有意越轴/跳切须由设计建立。独立生成段遵守当前30度制作约定，首尾帧和全能参考不是同一模式。时码只是标题预算，镜内按事件/原词/气口推进；原对白完整且归属明确，跨切每镜保本镜实际听到的原词。

## 6. 从决定到可读正文：完整微型示例

这是教学重建，不是作品逐帧记录，也不是默认剧情。设计目的：被撤换的演员以停止交接物品拒绝对方的安慰；观众先看到手上变化，再看到克制的接收。空间固定：窗在西墙、门在北墙，桌沿南北延伸。唯一房间光来自东侧画外房间灯照到北侧浅墙后的返光，西侧没有补光。示例只演示本镜，不代表完整七块交付。

> 镜头1 桌沿侧拍。50mm中景，摄影机在桌南端、与两人胸口平齐。佳佳在画左中景，琳琳在画右中景；前景是桌角，后景是北墙门口。北墙返来的柔光擦过佳佳朝墙一侧的额角和颧骨，佳佳近镜头的脸颊留在暗处。佳佳将胸牌推向琳琳。琳琳伸手接近胸牌，轻声说：“我今天才知道。”佳佳按住胸牌，抬眼看琳琳；琳琳伸出的手停在桌沿，手指慢慢收回。摄影机沿桌南侧向琳琳一侧移动，转向佳佳，琳琳的肩背滑入右前景，佳佳仍在左中景，门口从两人之间露出。佳佳松开胸牌，转身走向门口，脸离开墙面返光，只剩衣领短暂接住一线亮度。

这里是按设计写具体对象、位置、行为和受光，不写“加强压迫”“按LOOK-01”“延续上一段光影”或“确保观众理解”。表达已定事实时不新造机位/动作；尚未决定的拍法留在设计层解决。完整成稿语感仍取 [手册范本](../references/writing/handbook-gold-mai-long.md)，本例不替换原范本。

## 自然L1与扩读边界

本页就是普通设计的完整共同地基，不是引向另一套必读基础的目录。先用本页及本次已选知识的完整单元完成当前决定；足以选择并落实画面时直接交设计。未知问题尚未解决才扩读，不能为证明认真而重新读总纲、表演基础、影视索引、完整IR或镜头设计全篇。正文内的出处链接提供疑难深读，不自动串成调用链；本页并未取代专项的独有案例。

普通L1用自然语言即可完整交付：先用短段说明戏核、人物策略、观看立场和本段声画方向；再按镜序给镜号/时长预算、具体连续画面与原对白。每镜包含实际起幅的左右/前中后景、人物如何行动与接收、摄影从哪里怎样响应、当前受光和声音、结束时留下的状态与切连；参数只为已选画面服务，心理原因留在设计说明。来源确实改变选择时，简短说明“哪个机制及适用条件→本场具体用法”，无需逐镜引用或新增应用表。用户锁、素材映射与确认状态沿已有简报保存，不把自然L1改成整份schema填表。

按既定编排交出完整L1：单体CREATE_AUTO同轮以此设计快照编译，DIRECTOR_CHECKPOINT等待；多Agent仍以真实六环职责和L1确认交接，不因此省略环。采用结构化持久项目时才查IR对应字段；未决的覆盖、相对调度、复杂听说或光学条件才查镜头设计的相关完整节。设计中的实际冲突触及用户锁或目标时，才进入设计判断的对应处理节，未触发不预读。基础、已读专项与当前输入已能解决的问题不重新建研究任务。
