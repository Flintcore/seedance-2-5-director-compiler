# Seedance 2.5 手册写法编译

把确认 L1 或用户给定分镜写成手册七块成稿，不把旧字段逐项翻译成说明书。读取范围沿 [当前路径](orchestration.md)：实际取得 [唯一运行 SOP](prompt-writing-sop.md)、[婉-2完整范本](../references/writing/handbook-gold-mai-long.md) 与 [元模板](prompt-template.md)；同上下文同版本已完整取得的正文直接复用。明确局部修订只取所涉完整手册节/例和编译局部，不因进入本页重读全册；咨询/诊断未要求成稿时不进入完整编译。原文与历史差异可按需查 [原文库](../references/writing/handbook/INDEX.md) 和 [适配说明](../references/writing/handbook-adaptation.md)，它们不再叠加成首次全册读取门槛。纯编译不读取导演基础或外接包重做设计。[模型索引](../references/model/INDEX.md)与[能力表](../references/model/capability-registry.yaml)只在当前能力/素材问题需要时查。

## 1. 保留当前对象

先沿 [输入自足转译](prompt-writing-sop.md#standalone-readable-prose) 区分Agent可用设计上下文与本段视频模型的实际输入集合。对七块中的内部位置号、历史指代、未上传参考和仅凭姓名继承的音色，用已定实体/位置/状态/声音展开；不是删除它们所承载的信息，也不是编造缺失决定。本页中“承接/继承”指编译者保真取得设计，不是让生成模型自行读取前段。

用户锁、已确认 L1、逐字对白、事件顺序、镜头、素材、时长、入场与结束状态照原稿。纯编译改变表达，不重做导演。新出现的实质设计矛盾沿 [设计判断](design-judgment.md) 最小协商；已接受的取舍直接保留。有开放表演需要设计时先走 [微表演](micro-performance.md) 对应知识，不借格式修改发明剧情。

普通单段在内存整理人物、台词、资产和状态，不写新账本或自证日志。4–30秒内的连续戏保留一条；复杂或镜多不是拆生成段的理由。长片也只编译当前可执行段；有前段依赖时，先按[分段路由](orchestration.md#生成段边界闸门)取得实际切出状态，不把暂定全片预案批量转成提示词。原有 [IR](director-ir.md#段级策略与逐镜执行) 是设计供料，不是 L2 文风或填空表。

接单时承接当前自然L1或已有IR中的观看与声画决定，不只抽取镜号和摄影参数；既有IR的局部字段确需解释才查 [段级策略与逐镜执行](director-ir.md#段级策略与逐镜执行)，不默认读整本IR。关键内容若仅有“形成压迫/体现关系”而没有已定场面依据，按 [决策驱动交接](knowledge-routing.md#决策驱动读取与交接) 的对应节退回具体未决选择；若拍法已清楚，只是旧句抽象，就直接译成可见动作与取景。纯编译不以重新取材改导演。

## 2. 七块内容，按手册各写其事

本段目标直接讲当前场次、开场事实、世界、冲突、人物怎么做、质感和镜头语言，不写上接下交或统一镜头焦距；不粘贴镜组四问或逐项心理分析。参考绑定写素材职责；空间给固定方位与开场站位；环境给背景独立活动与光向；时间线逐镜演戏；声音给共享声层和音色；不可出错留下真正致命事项。

先选正确 [模式和变体](../references/writing/variants.md)：全能参考不当硬首帧，真实首尾帧用指定输入；白模只在 [已有预演/制作任务](../references/model/previs-reference.md) 触发，保留原人物表演。已有 `reference_assets[].output_placeholder` 与来源映射原样继承，包括空号；同一来源合并职责，仅新素材按本类型最高已有编号续号，不从 L1 的展示顺序重排。一个素材只在参考绑定中写一次 @imageN/@videoN/@audioN，正文用统一姓名或已定稳定称谓，无姓名不造ROLE_A。新句和换主体继续点名，同句连续谓语可共用主语，动作对象、肢体归属与声源明确；原对白中的代词保留。路径和文件名不代替素材绑定。

## 3. 镜头级连续画面叙事

从批准设计的连续画面主干编译，不逐字段串接，也不沿旧说明书逐句打补丁。按 [信息用途](prompt-writing-sop.md#scene-first-handoff) 分清实际画面、持续世界状态和设计/纠错说明：保留人物、事件、原词与拍法；相关参数补进同一过程，已在动作中交付的状态不在段尾再报一遍。场面决定已全、只是分散在字段中时直接组织成稿；确有关键拍法未定才回设计，不把含糊处改成“清楚可见”交差。

标题只写“房梁顶拍”“柜台中景”“穿行跟拍”等机位/景别/运动名，不加剧情任务、解读或口号。正文按手册成稿：摄影机在哪、起始画面看见谁和什么，随后人物做什么、朝谁说原话、别人怎样接，摄影机随事件怎样移动，最后停在哪个画面或动作上。

按[构图落笔与去重](prompt-writing-sop.md#screen-composition)保留“摄影机定位 → 具体起始排列 → 行动/摄影机导致的画面变化”。保留已定焦段、景别、方位/高度/俯仰；不是统一参数口令，但每镜都应看得出主体在画面哪里、哪些实际前中后景可见。写清布局便马上演事，镜内保关键接触与变化，不重抄全套服装、持续身体设定或正确性说明。

按戏的轻重写细节：普通放碗、转头、松手简洁写；改变人物态度、控制关系或攻防结果的动作写清过程。微表情、眼神和呼吸跟着听到的话、手上任务和应对发生，不为每项都有描述而慢放全身。心理在目标里直说，镜内让行为兑现；不夹“让观众看到……”“保持各自归属”之类设计解说或正确性证明。

运镜用一个主要观看动作统领，写清触发、路径、速度与落点；复合的已定运动按阶段或同步关系说清。人物起身带上摇、穿过人群带跟拍、点桌带摇向听者，摄影机实际改变注意力与关系，不默认把一切运镜缩成小幅缓移。固定镜保留已定调度。纯编译照确认设计执行，开放摄影才回 [镜头设计](shot-design.md)。

连续性用具体事实保证：人物看谁、刀在哪只手、东西落在哪里、未完动作怎样接。已建立的画外对象继续存在，但只在本镜显露、改变或影响动作时重述；不为“完整”把所有倒地者、伤势、道具逐镜报数。切点写事件加“硬切到镜头N”，不追加教学解释；换机位重新得到画左/右，世界状态继续。[镜头与节拍](director-ir.md#镜头与节拍边界) 只识别实际切点，不要求每拍补一镜。

动作场面保留连招的借力、路线、接触、受力与环境后果，前招余势接后招，攻防可以重叠；不把具体组合压成“激烈交锋”，也不把每击改成蓄力—命中—停稳。已定身法、顺序、对白、变速和摄影照留；重复机制可概括，关键变化仍具体。按需读 [动作设计](action-design.md)，而非套范本的文戏速度。

按[SOP世界布光](prompt-writing-sop.md#world-lighting)把已定光源方位、光路和照度关系写进环境；来源可在画外，不擅自补造可见灯具。逐镜保留实际亮暗、曝光变化与有意看不见的部分，不把“光影具体”翻成处处照亮。既定月光不替换成工作灯，暗面不补成“仍清楚可见皮肤纹理”，人物离光时不另添正面或轮廓补光。前景、反射、光暗和声音暗示保留具体载体，不把潜台词解释给观众。共享光向/底声分别在环境/声音写一次，局部遮挡、声源距离和接触声留在发生处，不强制每镜光影与现场声尾句。背影、藏眼、有意静止照设计保留，不强补脸部表演。

按[SOP光影设计交接](prompt-writing-sop.md#lighting-design-transfer)读取已定的光源/遮挡、人物朝向和摄影机观察侧，将其造成的亮暗面积与形状、软硬边缘、色光和材质落点按对应动作相位保留在连续正文；继承光场与反差，不冻结脸光图案或把受光侧写成表演侧别，不能把设计中的鼻颊阴影、可见暗面或进出光区压成“半边脸暗/光影有层次”。只有光型名或相互矛盾的关系时，退回受影响设计选择；已定关系只需表达清楚，不搬机位或补灯。光影交付另守 [SOP 项目布光禁令](prompt-writing-sop.md#project-flat-light-ban)：已定的身形难辨、局部轮廓和半脸显露按顺序保留，不将其润色成从开场就看清五官或全身；本段没有的显露阶段也不补造。知识示例与旧批准中的一般美化措辞不覆盖当前用户禁令。

按[场景与视频双层合同](prompt-writing-sop.md#scene-video-lighting)，有场景图也将已定世界光场写进【环境】，演员在该光场中的朝向、可见明暗/剪影和变化写进【时间线】；不把两层压成“沿用参考图光影”。剪影保住所衬背景和可读的外形/动作；已定局部补光保住具体信息、来源和有限范围，而非只输出“不平光”。这些内容融入原自然段，不增加字段或读取轮次。

## 4. 原词和声画归属

对白直接接在人物开口处，例如：老钱压低嗓子：“原文。” 表演和语气默认在双引号外；长句确有中途转折才插【非发声说明】，去掉说明仍逐字保持原词、标点和拟声词。没有对白就只写动作，不造占位。

跨镜同句按当镜听到的连续原文分放：先写前半句，切到听者后写原说话者从画外继续说后半句。每个有对白声的镜头都有具体原词和声源，不只说“声音继续”；片段拼回等于原句，不重念、不借切镜添停顿或省略号。说话中运镜不需要切碎对白。纸面文字、引述和非发声说明与真正说话分开，详见 [对白绑定](../references/model/dialogue-binding.md)。

## 5. 轻量交付

默认每段完整七块放一个可复制围栏，最后以【不可出错】收尾。只有用户明确要4—8秒精简单镜时，按手册①1.7和元模板的明确例外交紧凑稿，空间/环境融入镜内；不套七块维护校验器。标题时码只是粗略预算，镜内按事件与台词气口衔接；保留原对白里的时间数字，不安排逐秒动作或固定半秒区。角色、比例和接触按 [正向空间关系](../references/model/positive-spatial-constraints.md) 在正文成立，负面清单不兜底。

OPTIMIZE交完整修订稿；DIAGNOSE按 [诊断模块](diagnosis.md) 处理当前问题。交付前在现有编译末尾按[基础检查](delivery-check.md)只核当前稿与必要批准锁/邻段边界；不查影视/大师/手册知识、不启动额外角色或反复自检。无字数门、读库日志或质量宣告。维护脚本只用于维护或用户明确要求的检查，文字验证不冒充生成成片。
