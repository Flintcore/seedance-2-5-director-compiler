# Native Shot Prompt Compiler · seven-block-event-prose

把锁定L1、现有分镜或用户创意编译为七块Seedance 2.5提示词。编译是保真翻译，不是第二次导演。每次完整编译先读 [必读 SOP](prompt-writing-sop.md)，再读`references/model/INDEX.md`、[主模板](../references/model/nine-layer-schema.md) 和 [能力注册表](../references/model/capability-registry.yaml)，其他模型文档按当前问题读取。

编译前沿 [设计判断](design-judgment.md) 的入口原则识别新出现的实质冲突：锁定设计约束改动权，但不消除提示问题的责任。发现时实读相关章节、先说明后果与最小修正，用户决定前不静默重导演或照单交付相互排斥结果；已接受的同一取舍直接沿用。无问题直编译，不创建例行报告。用户只给关键动作且允许完善开放表演时，先走相关微表演章节细化该处，再冻结为当前设计；纯格式/素材转写不走此分支。

## 1. 保留当前对象

接受已确认L1、用户锁、逐字对白、世界设定、素材职责、单段时长及进入/退出状态。已有提示词直接增补，不重建整套L1；Blender粗预演按 [previs-reference.md](../references/model/previs-reference.md) 接入。动作合同仍回到本镜正文。

普通单段只在内存整理必要来源账本：故事人物、用户锁、对白原文、资产、时长和活跃状态。不自动写日志、项目文件、读库记录或额外表格。一个4–30秒连贯场景内的切镜和节拍都留在一个生成段；只有明确分段要求或叙事最低时长超过30秒才走边界政策。

正式叙述沿用参考绑定/用户设定的角色统一名称：新句、跨镜、开口声源继续点名，视线对象、动作接受者及肢体/持物归属也明确到角色，不换用“他、她、它、自己、对方”或新别名。同句同主体的连续谓语可共享主语；无姓名用既定稳定称谓，不将有名人物改成ROLE_A内部编号。实际对白/画面文字逐字保留其中代词，新增非发声括注仍按姓名化叙述；完整范围见 [角色统一名称与动作归属](../references/model/nine-layer-schema.md)。路径、源文件名、上传标签只在内部来源账本使用。区分实体本体、反射、影像和影子；只记录影响本段的位置、朝向、视线、持物、接触、可见性和未完成动作。

## 2. 七块装配

当前最终格式只由 [编写 SOP](prompt-writing-sop.md) 与 [七块元模板](prompt-template.md) 规定。【本段目标】→【参考绑定】→【空间】→【环境】→【时间线】→【声音】→【不可出错】。共享几何和开场状态进入空间，持续背景/光向进入环境，共用声轨进入声音，少量致命事项放末尾；动态行动仍在发生镜连贯叙述，不用一个全局栏兜底。

先选全能参考、首尾帧、首帧、文生、编辑或延长，再按 [18种变体](../references/writing/variants.md) 选实际分支。已确认 L1、参考职责、逐字对白、镜头组的信息/情绪/人物塑造/观众落点与叙事视角保真；导演策略与逐镜执行沿 [既有 IR 分层](director-ir.md#段级策略与逐镜执行)，不在编译时重新选择。迁移旧输入保留信息但撤销旧容器。

## 3. 镜头级连续画面叙事

先在内部形成 **causal spine**，再将`image_action`、`camera`、`staging`、`performance`、`sound`、`end_state`织回同一可想象画面，而非逐字段翻译：

`人物正在做什么/想推进什么 → 阻力或信息到达 → 动作、听说与对方接收 → 调整及环境反馈 → 余态`，由相容的首帧空间关系与摄影机响应承载。

这条关系按当前设计跨镜成立，不是每镜必须从刺激演到结果的清单；编译不为补齐链条新增反应、转折或对白。它是内部承接逻辑，不是成稿的文字顺序。正式正文按 **摄影参数开头 → 起始画面 → 连续人物事件与运镜 → 结束状态及必要切镜衔接** 组织：先以“85mm近景，摄影机在……平视”等简洁定位开头，随即让读者看见谁/什么已经在画面哪里、处于什么姿态与接触关系，再按时间展开人物正在做什么、动作/表情/对白怎样发生及对方怎样回应，最后交代切点当下的状态，运动可继续。参数开头不等于冗长参数清单，人物事件为重点也不等于先写动作再补镜头。仍是一段自然叙述，不增加“起始画面/人物表演/切镜”字段；局部光影和声音仍在发生处，共享层集中到环境/声音；对白与其表演不拆到正文之外。

观察、停留、暗示镜头可持续状态与注意力，不增造转折。精炼冗余参数和装饰，不压缩锁定的目标、互动、对白接收、动作路径/接触/反馈及结果。已有切镜在本镜结束或下一镜开头清楚承接即可，不重复命令，不给长镜插切，也不让末镜悬接不存在的下一镜。结束状态是切点那一刻的状态，不要求动作做完或台词说完才切；未完成动作与同一句声音按既定设计跨镜继续。

动态锚点按需重述：人物在哪里、看谁、哪只手持物、接触/动作相位、背景还在进行什么。用“看到后、同时、随后、话音落下”等自然连接说明因果与同步；共享事实可简写，承担表达价值的稳定反射、遮挡、明暗差仍保留。只去重措辞，不删除具体载体。

人物事件是正文的可读主干：沿统一名称讲清谁正在对谁或什么做什么、动作或台词怎样被接收、先后与同时怎样成立，以及画面留下的可见结果。主语与动作对象落在具体人物、物件或环境上；心理、情绪和招式名称以已定的行为、注意力或视听载体承接。纯景物、有意静止、观察与暗示沿原设计写清持续状态，不为凑事件新增动作或揭露潜台词。这一原则在写本镜时落实，不另加审查环节、字数比例或输出栏。

每镜用简洁定位保留景别与焦段、相对主体的方位/高度与平仰俯、必要占幅和实际纵深。运镜用足够明确的起点、路径/速度、终点及有意义的焦点变化承载事件；固定镜一句说明所持画幅即可。信息可合并，精度随设计需要，不为每项另写冗长句、未给出的厘米值或固定光学套配。可见光学结果只解释当前选择要保留什么/隐去什么，不伪装成平台控制保证。纯编译不为填字段改视点、轴线或创造镜头；新增设计沿 [镜头导演法](shot-design.md#按观看需要选择镜头组) 按观看目的选择，具体项目的明确摄影锁另行保留。

镜头术语配合上述人物事件使用。生僻、含义含混或承担关键变化的术语，补清观察对象和实际画面变化：移焦交代清晰度从谁或什么转到哪里，横摇交代摄影机跟随或揭示的对象，前景遮挡交代谁遮住什么及何时露出。通识术语已经清楚时保持简洁，固定镜可直接描述所持画幅；具体变化取自已确认设计，不凭术语推演新事件或改动动作。

前镜结束世界状态就是后镜开始状态。切换机位重新表达投影，不让人物无因换脚、换手、转脸或回到起势。剪在动作中从同相位继续，惯性、反应和恢复落实在动作镜头。起始构图按“前镜结束世界状态→本镜机位与取景→可见位置/纵深/遮挡”推导，画外人物仍在已定位置；已经发生的走位进入新状态，不回开场基准。开场和结束状态在相应正文中清楚成立，不分配固定停留时长，末态在当镜表达，末尾【不可出错】不重述剧情。

已确认打斗保留组合的连接条件：上一击的余势、落脚、握持、失衡或位移怎样接出下一击，正在逼近的压力怎样与当前攻防重叠，接触又怎样落到具体人物和场景实体。摄影参数可精炼，不能把连招缩成“激烈连续交锋”，不能只留下击飞结果，不能将连续动作拆成每招停稳重置。长镜保留链中的实时注意力转交；跨镜保留切点动作相位。已定局部变速照原节奏意图转写，不新增倍率、招式、配乐、人物习惯或结尾姿势。

同类动作反复出现时，可概括已说明的共同机制，把具体篇幅留给改变攻防的路径、关键接触、防守突破、身法与落点，以及已定的受击和环境后果。各动作组仍点明参与者、对象和连续关系，保留锁定招式及顺序；压缩重复发力措辞，不压掉连招连接，也不将整组行动概括成空泛形容词。这是详略选择，不设每个时间块只含一个动作或一种运镜的配额。

镜号按 [镜头与节拍边界](director-ir.md#镜头与节拍边界) 表示连续摄影镜头；同镜的多个行动阶段用自然时序衔接，依确认 L1 保留实际切点，不把节拍编号自动编译成硬切，也不把已定多镜挤回一个镜号。

### 表演、视线与表达保真

保留导演已定的持续行为底流及其触发后变化：人物一直在做、听、看或控制什么，信息如何改变其节奏/行动，对方怎样接收，结束后留下什么。按景别用姿态、距离、目光、呼吸、手/物件或脸部信号承载，不把活人感缩成一句“自然微动”，也不补无因抖动、重复手势和同步反应。普通对话明确对象及眼神落点；回避、共同任务、走神照原意保留。反打按世界目标重映射屏幕方向，过肩对手不等于摄影机。

有意藏眼、反射遮脸、背影和固定凝视保留心理不透明；不补光、移遮挡或新增泄露心理的小动作。部位不在画内就不编造可见细节。按需读 [micro-performance.md](micro-performance.md)，深化既有表演，不自动加特写。表演分寸和注意力时机服务叙事，不暴露全部内心。

### 光影与声音的落位

共享光向与背景常态进环境，持续声层与音色进声音；局部受光、遮挡、接触声和距离变化仍在发生镜，保持物理声光来源与时间关系。静默、画外声音、画内音乐与配乐分清；没有固定数量或尾句配额。

## 4. 内联对白与素材

正文在开口动作处直接嵌入中文双引号对白，情绪、表情、动作、语气与时机默认在引号外。以下是局部写法，不是额外字段：

```text
父亲看着女儿，停一拍，语气放缓地说：“门没有锁，是我们一直没推。”女儿听完才转向门。
画外旁白平缓地说：“那天以后，钟再也没有走过。”画内人物延续既定动作，不对旁白配口型。
```

普通对白保持引号内纯原文；长对白也优先在外部描述表演，仅中途确有必须定位的变化时，才在引号内插入 `【非发声表演说明】`。剥离说明后的台词含标点逐字保留，不设长度门槛或标注配额。人物、旁白与设备各有明确声源；纸条上的文字等普通引文不自动成为发声。无对白就沿原动作继续，不新增对白占位。多句和重叠按原锁顺序及时机表达，不因多说话者自动切镜；说话中运镜、动作和句中听者反应仍按事件推进。跨切同一句按实际切点把连续原文片段写入各自镜头，后镜点名原说话者和画内/画外来源并写本镜续说原文；保留L1已定的逐镜范围。完整原句只作内部来源，不前置到首镜替代后镜正文，不用“声音继续”省略续句。各片段拼回逐字原文，不因切镜添停顿或标点，也不重启发声或把画外话塞给画内嘴。声线身份与当场速度/气息/重音分别承接。见 [dialogue-binding.md](../references/model/dialogue-binding.md)。

素材只放素材节，如`@image1=父亲外观与服装；@image2=夜街空间与光色；@video1=起身动作参考。`正文使用父亲、夜街等语义名称。新提示词按类型与首次使用从1编号；增补保留规范编号与职责，新来源追加，旧来源增加职责不新增@。同一来源的角色/预演映射职责合并，详见 [reference-assets.md](../references/model/reference-assets.md)。占位符为粘贴记号，不声称平台已绑定。

## 5. 轻量交付

保留4–30秒、混合50素材合同；镜头标题时码仅作粗略剪辑预算，正文及光声/表演说明按事件、语义与情绪推进，不输出逐秒命令或定长稳定区。内部测量时间不进入正文，原台词/画面文字含时间则逐字保留；当前双引号与条件表演标注是用户写作偏好，不是平台保证，不补造字符/token上限、权重、平台控制开关或模型保证。空间控制用相容的尺寸、承托、路径和构图正文，不把矛盾留给负面词尾表；按需读 [positive-spatial-constraints.md](../references/model/positive-spatial-constraints.md)。本段目标里的情绪对照只界定表达方向，不承担尺寸否定补丁。

完整提示词每个生成段放一个可复制代码围栏，只输出当前段；最终以少量【不可出错】收尾。无字符限额，无额外自检、评分、报告、候选轮次或读库日志。OPTIMIZE默认交完整修订稿并保留锁定创意，用户只要某块则交该块；DIAGNOSE依诊断模块给最小修补。开发脚本只做维护回归，不成为生成提示词的强制运行环节。
