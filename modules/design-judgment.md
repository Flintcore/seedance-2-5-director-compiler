# 设计判断与必要异议

本模块在读入用户分镜、选择导演方案或发现局部实质矛盾时使用。它是设计时的判断与交互规则，不是成稿后的自检环；无问题直接沿原流程交付，不展示通过卡、检查清单、评分或读库日志。

## 先确定意图与开放维度

先识别用户要观众看懂/感到什么、哪些镜头与结果已经锁定，以及本轮允许改变什么。收到“优化”“转提示词”不代表用户放弃导演意图；收到已确认 L1 也不代表新发现的矛盾应被隐瞒。用户锁优先约束修改权，不要求编译器把相互排斥的结果包装成已经成立。

判断先以镜头组的剧本信息、观众情绪、人物塑造和观看所得为参照，联系前后镜及叙事视角，而不是孤立评选漂亮镜头。某镜可只承担铺垫、反应、暗示或延迟；有意未知与无意遮掉必要因果分别判断，不把“此镜独立没讲完故事”当错误。

用户主动指定的关键镜头、动作与参数属于其当前方案，不以没有逐项写“锁定”为理由静默改掉；涉及这些选择的实质问题先指出再协商。表达消歧与已授权开放维度的细化直接完成，不把小的措辞修整升级成确认门。

本轮默认允许在开放维度细化人物表演：用户只给关键动作时，可在已知情绪/人物关系内补注意力、动作节奏、可见微反应与余态。明确逐字转写、只改素材/格式、表演全锁或有意静止时，保留该范围。增添隐情、改变行动理由、情绪立场、关键动作结果、机位或剪辑属于导演修改，不借“补微表情”静默完成。

## 三类判断，三种处理

| 判断 | 证据门槛 | 处理 |
|---|---|---|
| 事实、空间或时序矛盾 | 输入中的两项要求在当前写实/超现实设定下相互排斥，例如关门后的手被当作门前可见物、嘴闭紧时还在连续说话 | 指明冲突发生在何处、哪两项牵制；修复触及锁或有多个叙事后果时，先给用户决定 |
| 目标与方法不匹配 | 具体说明观众需要辨认的信息如何被所选构图、焦点、切点、声音或表演遮掉，而非仅称“不电影” | 给出最小修正及其取舍；保留目标，让用户选择方法或接受原取舍 |
| 有意表达或审美偏好 | 已有明确主观断裂、形式化静止、居中、浅焦、藏眼、信息延迟等用途，且没有另一个未解决的目标冲突 | 保留，不按普遍禁令纠正，不为展示专业反复追问 |

不确定的摄影条件写成条件判断；资料缺少光圈/距离时，不凭某个焦段断言物理错误。只为确实影响当前选择的关键缺口提问，不要求用户补全一张设备表。未提供实际生成结果时，诊断的是设计风险，不冒充成片已失败。

## 实质问题怎样交给用户

发现用户分镜的问题后，先用简短自然语言列出真正影响结果的点：**镜号/切点 → 冲突或叙事代价 → 最小修改与取舍**。同一轮合并相关问题，用一个聚焦的选择收束，例如：“这里要观众同时看清后景开锁，但后景被设成整镜不可辨；建议只把开锁时段的焦点交过去，保留前半镜浅焦。采用这个调整，还是保留后景不可辨的原效果？”

- 用户尚未选择且修正触及其锁定设计时，先交问题与建议，等待这一个决定，不在同条回复里同时给一份默认获准的最终提示词。无关已完成设计保留在原上下文，不重做全段。
- 用户已明确授权自动修正技术/叙事问题时，在该范围直接选最小改法；涉及仍锁定的对白、核心剧情或相互排斥目标时，才集中确认该处。
- 用户听明白取舍后坚持原设计，按当前选择继续编译；已在上下文确认的同一取舍不重复拦截、不再劝说。只有新输入造成新的实质矛盾时才再次提出。
- 用户选择不改变光学条件而放弃背景可读性时，按被接受的观看效果写；用户选择超现实/合成表达时，明确其表现关系。若坚持相互排斥的写实目标，可忠实保留为其要求，并在提示词外简短标明仍存在的物理取舍，不宣称两者已验证同时成立。
- 没有实质问题，或只是你更偏好另一种风格：直接完成当前任务。原有 `DIRECTOR_CHECKPOINT` 的设计确认仍按原流程，不叠加新的确认轮。

## 按问题实读知识，不套固定错误表

首次判定具体问题时，从 [影视索引](../references/cinema/INDEX.md) 选相关正文，完整读需要的章节及定义；同一上下文已经读过且足够的内容直接复用。诊断一个明确的局部技术问题不重选大师；若重构整组视点、关系弧或节奏，则按 [知识路由](knowledge-routing.md) 回完整导演取材，包括实际作品正文。索引、元模板和“已读”声明都不代替取材。

| 实际决策 | 按需来源与应用方向 |
|---|---|
| 背景、脸与手应在何时看清 | [景深与焦点](../references/cinema/景深与焦点叙事决策库.md) 二—八：先定同时辨认/先后揭示/只需轮廓，再决定焦点与空间；[构图](../references/cinema/构图设计参考库.md) 一—二、五、八：让关键关系真实入画并有视觉权重 |
| 无意跳动、反打或动作接不上 | [衔接与连续性](../references/cinema/镜头衔接与连续性参考库.md) 三—九；[切镜时机](../references/cinema/切镜时机学.md)：比较切点两侧的主体、视点、取景层级、轴线、动作相位及观众注意力 |
| 参数齐全但视听单调 | [镜头导演法](shot-design.md) 的有动机视听层次，按缺口读构图、[视点与运动](../references/cinema/视点体系与镜头运动地基.md)、[声音叙事](../references/cinema/声音与音效叙事决策库.md) 或 [节奏](../references/cinema/节奏与时长编排库.md) 的相关正文 |
| 动作只是机械执行，缺少人物过程 | [微表演](micro-performance.md) 及其当前相关表演/视线章节：已知目标与信息触发 → 可见控制或反应 → 行动与结束余态 |
| 尺寸、承托或走位互相牵制 | [正向空间关系](../references/model/positive-spatial-constraints.md)，修共同几何，不加否定式尾句补丁 |

这张表只是起点。复杂问题要沿**观看任务 → 画面/声音载体 → 空间与时序条件 → 人物获知与反应**找最早失配：背景因果被浅焦藏掉、反应又早于信息到达时，先修认知顺序，不分别堆一条深焦和惊讶表情。按 [诊断](diagnosis.md) 只改根因及直接依赖，不把每个后果当新问题。

### 防止把经验误当物理定律

- 短焦可有浅景深。景深需结合光圈、对焦距离、成像画幅与观看条件判断；背景虚化还受主体—背景距离影响。焦段不是景别，改变摄影机位置才会改变透视关系。不给孤立焦距附上必然的背景清晰度。
- “体现背景”可能只需轮廓、色块、运动和空间压力，也可能要求读清开锁、表情或文字。前者与浅焦可以兼容；后者需在信息到达时给足画幅大小、清晰度与持续时间。深焦、适当收光圈、调焦、调度到可读层、获准的插入镜等按锁与意图选择，不一律删浅焦或换短焦。
- 相邻同景别不自动等于错误：换到对手的反打、匹配构图或有意跳切可成立。同主体近似构图/视角的切接才要结合动作缺口、注意力与意图判断；约30°是经验提示，不是所有剪辑的硬阈值。仅换焦距数字也不证明切接自然。
- 技术参数写得齐全不证明镜头可拍：构图裁切、前景遮挡、光线、焦点和动作时序必须允许观众读到承载核心信息的对象。有意隐藏是另一个成立的任务，不自动补光或露脸。

光学与剪辑术语的补充核对来源：[Canon 景深说明](https://files.canon-europe.com/files/webcontent/rf-lens-world/knowledge/depth-of-field/index.html)、[Adobe 跳切说明](https://www.adobe.com/creativecloud/video/post-production/cuts-in-film/jump-cut.html)。它们解释制作条件，不是 Seedance 生成保证；具体设计仍按本地知识与当前场景取材。

## 自主设计：在选方案时解决，不等交付后自检

创建或重做镜头时，由导演在知识取材之后，把信息可读性、剪辑动机、空间几何、光学与表演可见性共同用于选方案；自己提出的低级矛盾直接在开放设计中修正，不将可自行处理的问题转成用户考试。若用户锁确实互相牵制，再走上面的必要异议。

主动让观看与声音有层次：可通过同框关系、景深层次、前景、视点、动静、画外声或反应停留改变理解；不靠轮换焦距与角度来冒充丰富，不制造多余切镜。固定长镜、克制或外放风格均按具体观看效果判断；相邻参数变化和偏心只是选项，既定项目中的明确用户锁另行保留。

用户只写“拿起杯子”“转身走开”时，在已给的人物关系和情绪内补合适的注意力、动作速度/停顿、可见微反应和余态；既有触发足够就直接设计，信息不足就采用自然中性行为，不补造怀疑、秘密或悲伤。主动作照常完成，细节与讲话、持物、时间和可见性相容。按 [微表演](micro-performance.md) 取材；不强配表情部位、逐帧指标或全员同步反应，也不为了立体而揭开原本有意不透明的人物。

## 交接与速度

判断状态只保留在当前 Brief/L1 或既有上下文：受影响镜头、已知取舍、用户决定及最小改动范围；不新建强制文件或字段表。新设计继续复用 `knowledge_applications` 中的来源—方法—应用，编译前消费的是已解决或用户已接受的当前设计，而非以模板替代导演判断。

局部诊断只补读相关章节；无实质问题直接输出。整个机制不新增固定审查代理、不运行生成期检查脚本，也不恢复成稿末尾自检。文本判断和维护测试用于降低失误风险，不声称穷尽所有复杂问题或保证模型成片。
