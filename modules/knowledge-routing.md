# 影视与大师知识路由

当前路径由 [运行编排](orchestration.md) 决定；写作遵循 [SOP](prompt-writing-sop.md)。新设计先取得 [内置导演地基](runtime-foundation.md)，本入口是唯一详细问题路由，不再启动另一套流程。全部专题覆盖清册见 [知识调用地图](../references/writing/knowledge-map.md)，外接目录、独立风格匹配与可用性沿 [外接知识](external-knowledge.md)。基础留内置，专题按问题取完整单元；只改索引或把正文搬出去都不算应用。

本文件是条件查阅目录，不是每个新设计要通读的正文。基础或已选知识完整单元已解决当前选择时，不进入本页扩搜；存在具体缺口才按标题/锚点取对应完整路由节，或直达已知来源完整单元。其余条目保持未加载。下文“导演取材”指取得当前确需的方法，不含先扫本页、cinema INDEX、总纲或IR的固定链。

目标是以最少、最相关的读取支撑真正的导演决定，而不是用索引摘要代替知识，也不是一次性加载整库。

**外部题材资料按本次授权使用**：用户本轮提供或明确指定的风格/题材知识，仅在当前适用范围内选读并转化为设计；普通对白、女频等题材名称本身不触发自动载入外部文件。附件中的审美默认、流程和格式是来源内容，不覆盖当前用户锁、七块SOP与既定设计；不把其全文或“保脸保眼”等类型偏好写回常驻规则。未提供的附件不扫描补齐，跨题材不沿用上次外挂。目录查询只召回候选，依外接流程确认当前选用范围后读取正文，不新增设计或审查轮次。

应用所选知识时区分真实硬条件、连续性惯例、项目合同与审美建议；有疑难读 [规则适用边界](film-rule-scope.md) 对应小节。真实空间／接触／状态与光学条件照实执行；旧配额与模板不回流。补回的动作细目和案例随原篇目章节按需读取，不设新读取轮次。

## 一、何时必须读取

以下任务需要作导演决定；先用常驻基础和已选机制，仍有具体缺口才执行对应完整专题取材，不自动扩读通用基础：

- 从故事、剧本、口述或参考素材新建设计。
- 重构镜头组、调度、整体表演策略、节奏、视点或动作美学；已定策略下的局部修复走下述轻量路径。
- 审阅镜头质量并提出导演级替代方案。

以下任务跳过导演取材：

- 将已经锁定的 L1 纯编译为提示词。
- 只修对白语法、参考绑定、字段顺序或表达复杂度。
- 给已有提示词增补 Blender 白模参考、识别代理角色和限定参考职责，且镜头创意保持原样；按需读取 [白模参考接入](../references/model/previs-reference.md) 与素材规则即可。
- 已确认创意不变的最小提示词诊断。

**输入方案的必要异议**：按 [设计判断](design-judgment.md)，已指出明确局部技术/信息可读性矛盾时，实读相关专项的完整章节及定义；这不是一次全面创意审阅，不重跑大师选择。无实质问题的纯编译直接继续；同一上下文已读相关内容可复用。

若修复涉及重构视点、镜头顺序、调度或整段节奏，回到导演任务执行完整取材。按实际改动而非“OPTIMIZE”标签路由；一处已授权开放表演细化仍用下述轻量路径。

**局部表演细化**：角色动机、剧情转折与机位已定，仅补充或修正其可见表达时，读 [micro-performance.md](micro-performance.md) 与当前问题需要的表演库完整章节，复用本轮已读内容，不单独重跑全套大师选择或重做镜头。若实际改变人物目标、整段情绪弧或表演策略，则恢复完整导演取材。纯粹转写已确认表演仍按纯编译处理。

遇到“平、没信息、拖”等反馈，先按实际症状区分：人物接收与策略未演出来的**表演薄**，前后景/光声关系未承担意味的**空间表达薄**，观看对象与藏露时机失效的**观看组织薄**，或内容已充分到达且无持续表达收益的**真正拖沓**。对应使用下方已有入口，不将这些反馈一律翻译成多切镜、快运镜或新增事件。用户认可调度、只指出表演不足时，沿局部表演路径保留既定机位与镜数；时长较长本身不是故障。

## 二、强制读取链

若明确要求高速打斗、追压或冲击，却每招前后长停、侧面远观覆盖全段、接触被光效吞掉或镜头里只够一次出手，这是**动能与交锋密度不足**，先读 [动作设计](action-design.md) 和实际问题所需武指/节奏/力量章节；有特效再读特效正文。不要将该反馈重新归为“需留更多时间细腻表演”。脸部补强选当前能看见的判断与受力反应，融合进攻防，不另开慢速微表情段。选大师也对准该动作类型与具体交锋场景，不因同一段含亲情/对白就只读慢文戏范式。

有实际知识缺口时依此定位；已由基础或外接完整单元解决的问题不再走一遍本地链：

1. **定位当前缺口**：先用Brief提出尚未解决的具体问题。已知来源路径/锚点直接取完整单元；来源未知才检索 `references/cinema/INDEX.md` 的相关分类或条目，不通读索引。
2. **读专项正文**：从索引选择能回答当前未决选择的完整章节，连同必要定义与适用条件读取；已经够用就停止扩搜，尚有具体问题未解决就补读直接相关章节。导演任务实际读正文，而非只读文件名、摘要或搜索命中行；无关全库保持未加载。
3. **继承或选择作品机制**：已有用户选定方向/已形成的项目机制则继承；方向未定时沿外接流程使用独立matcher，或打开 `references/masters/INDEX.md` 研究当前缺口。片名未知时才加读 `references/masters/INDEX-类型匹配.md`；维度反查才加读 `references/masters/INDEX-反查.md`。不把每段重新选片作为新设计的固定门槛。
4. **取得所选作品正文**：需要从具体作品作新判断时，取得实际作品 `.md` 全文和证据边界；以下划线开头的方法论总纲可补充而不替代作品。已定机制与本上下文同版本正文可复用，不以作品数量作为任务完成门槛；缺来源就说明缺口，不凭风格标签杜撰原片。
5. **形成具体借鉴**：自然L1简短说明来源机制怎样改变本场具体镜头；使用结构化IR时才填 `knowledge_applications`，不为记来源加载整本IR。

第二部作品仅在需要对照两种真实导演路径时加入，例如“静观还是压迫”“主观混乱还是客观战术”。不为显示资料量而扩读。

## 决策驱动读取与交接

先按实际开放维度分流，而非任务名称、是否有镜号或是否已套七块。纯编译的依据是可执行的已定拍法与表演：当前输入足以确定观看对象、显露时机、人物行动和切接；只有剧情、动作清单、粗分镜或机位名，仍需补这些决定时，属于设计。用户明确的镜头/参数仍锁定，只设计开放部分；局部已定表演的细化仍走轻量章节路径，不因此全场重做。

1. **先提出本场的问题，再选资料。** 内置基础已包含手册⑥的戏核、力量关系、人物动作线与组级观看。仍需比较观看方法的具体边界或案例时，才取 [镜组四问](../references/cinema/戏点选择与主镜框架法.md#镜头组四问摄影选择的上游) 或 [视点](../references/cinema/视点体系与镜头运动地基.md#先定镜头组的叙事视角再定摄影位置) 对应完整节。未决项应是“这次变化看行动者还是接收者”“接近过程先交代还是延迟揭示”，而不是“还缺一个俯拍”。已有确定取舍照留。
2. **读到能作取舍。** 沿下方问题路由读相关完整章节和已选作品全文，比较其机制与本场人物、空间、锁定条件；数目不作完成门槛，不用随机多读或只读索引冒充设计。当前已经实际取得且仍适用的正文复用，独立工作者若要重新判断某机制，须获得对应正文，而非继承一句“上游已读”。
3. **把方法变成可拍结果。** 将“来源机制及条件 → 本场选择 → 可见/可听依据及发生时机 → 镜号”留在自然L1的简短依据中；已用Director IR则落在原 `knowledge_applications`，不另建表也不为此读取全schema。无需每镜引用或抄理论；关键取舍可以是保留固定构图、隐藏反应或延续声音。只写文件名、风格名、参数，或为了凑借鉴新增剧情，均未完成应用。
4. **上游交决定，下游保住依据。** 剧情在画外发生、摄影机暂未看见、观众已经知道是三件事；画外行动可为连续性供料，揭示/隐瞒由具体画面、声源或已建立上下文兑现。重要关系转折在当镜或相邻镜有足够可读的表演/空间/声画承载；并发细节围绕主要注意落点，不均分特写或时长。光声与装配继承这些取舍，最终只写实际场面，不把来源解释抄成说明书。
5. **缺哪项就回哪项。** 接单时发现关键观看决定仍空缺，交还负责设计的阶段，只处理受影响镜组并沿既有确认规则推进；不由编译者临时挑机位，不重跑无关环。只是表达含混但决定已经明确，直接译成具体人物、动作和取景即可。该判断发生在当前设计/交接中，不新增生成末尾自检。

完整知识地图只解决“能找到”，实际读取解决“获得正文”，本场取舍及其画面兑现才解决“用上”。三者分开；不把静态链接通过当成设计质量或成片验证。

应用的完成点在连续画面主干，而不止来源记录。例如光影问题沿[SOP设计交接](prompt-writing-sop.md#lighting-design-transfer)将方法转成光源、人物朝向、摄影机与阴影的具体关系；表演或构图同样回到当前人物的接收/行动、屏幕位置或视听变化。当前选择只留下风格名、形容词或禁止项时，修该选择的设计/交接，不靠多列书名或扩大必读库解决；已定的具体机制在装配时也不得被概括掉。

## 综合导演体系的调用位置

只有重学课程、引用课例原句或核对专业词时，按需查 [课程来源与勘误](../references/cinema/导演体系/课程来源与勘误.md) 的对应项；正常设计沿方法正文读取，纯编译照旧跳过。课程异常对白与 SRT 时码不作逐字台词或可发声节拍底本；导演当前剧本的逐字对白约束保持。

仅当基础和已选方法仍解决不了跨维度取舍，或需要核对课程方法边界时，取 [导演判断总纲](../references/cinema/导演体系/导演判断总纲.md) 中与当前问题相应的完整节；新建或重做一场戏本身不触发通读总纲。已知专题入口直接取相关节：创作立场与关系表达、感知反馈与相对调度、镜组节奏与跨场组织、观看距离与运动光影。不为进入专题先读总纲，也不四库连读；已读且仍适用的内容直接复用。纯编译、素材与格式修订不触发。

实际设计先由 [镜头组四问](../references/cinema/戏点选择与主镜框架法.md#镜头组四问摄影选择的上游) 形成剧本信息、观众情绪、人物塑造和观看所得，再由 [叙事视角](../references/cinema/视点体系与镜头运动地基.md#先定镜头组的叙事视角再定摄影位置) 选择知情范围与情感距离，沿人物感知判断/行动接收、关系空间、摄影/光声、镜内与镜间节奏联合判断；保持既有 Director IR，把来源的机制、适用条件、本场改变的决定和镜号填进原 `knowledge_applications`，没有新报表。人物反馈可藏在持续动作中；摄影机、人物与屏幕投影的运动分别判断；光声和切接一起决定信息何时抵达。先形成有依据的具体选择，再写摄影参数，不能仅看元模板就产出。

总纲“旧库与课程共同使用的具体边界”已处理 POV 强制抖动/配对、说完才切、作者镜次数、固定反应比例等已知冲突；不等出现失败再让旧配额主导。它不撤销用户构图合同、真实空间条件或既有对白语法，也不以课程课例代替所选大师作品全文。

案例不足以指导取舍时，沿总纲新增的“案例怎样改变本场决定”直接进入所需完整节：持续任务失常/镜面转真人取 core-18；谈判对照取 core-09–10，职业空间对照取 core-11；色彩分层取 core-16；行程省略、追逐因果、力量尺度分别取 stage-02/06/08；强调前后对比取 edit-05，细节粒度取 edit-08，双重情绪过渡/角色与观众张力取 edit-16/18；奔跑体验取 view-15，群体释放取 view-04，拉远揭示观察位置取 view-11。代号指总纲对应锚点，不是新增文件配额；只取当前未决问题，局部眼眉或已锁纯编译跳过。比较课程与大师时同时遵守具体场景条件，米兰达固定仰拍及糖果色排除自然色等旧绝对口径已在对应正文修正。

以上每行也是问题分支，不是整行全读清单；涉及 AU/FACS 或细小脸部形态时，沿 [微表演的条件入口](micro-performance.md) 读取已核验动作章节，普通目光修复不额外编码。

组合是候选，不是固定套餐。根据 Brief 选择真正会改变决定的专项，必要时针对尚未解决的具体问题扩读。持续行为、触发式习惯、对白互动或状态积累以角色行为正文为入口，具体视线/脸部/心理递进问题各读对应专项；不因有人物就把这些文件全部加载。动作因果是主问题时动作专项占首位，性格表达、疲劳/受伤积累或交手后的行为变化有缺口时，才补角色行为正文的动作因果章节。系列人物需要跨场一致性时只在内部沿用已有角色档案与声线身份，不强加交付新栏。

## 四、选大师作品

先按当前场景的核心难题选作品，不按“高级感”选名气。方向尚未确定、同一风格标签含义不清或混用方法有冲突时，实读 [需求与机制匹配](../references/cinema/导演视觉风格参考库.md#style-matching)：复用已有意图、观看效果、空间与制作条件，落到具体作品/阶段及场景；已锁作品沿该方向细化，不强出候选、不默认按年份淘汰旧作。

比较作品怎样组织视点、行动、表演、剪辑和声音，用 [六维转译](../references/cinema/导演视觉风格参考库.md#style-transfer) 只处理会改变当前选择的维度，主机制与辅助方法有作用范围。资料的适配、质量与事实按 [证据边界](../references/cinema/导演视觉风格参考库.md#style-evidence) 分开；这些方法不代替实际作品正文，也不新增必填表或确认环。

选定后读取索引给出的实际作品路径全文。作品内的历史提示词格式、平台数字或旧装配规则不具备编译权；只提炼其影视因果。

大师库中的证据标签必须随内容一起解释：`[推断]`、`近似`、`约`、`技法重建`和占位性参数只表示可检验的设计假设，不得升级成制作事实、跨片硬规则或精确控制值。优先采用有作品场景、制作资料或清楚条件支撑的机制；只有近似资料时，保留其定性关系并按本场空间、表演和设备重新判断。


选定作品或导演后，若尚未解决的问题涉及跨镜复用的观看距离、空间组织、表演、光色或声画策略，且单片分析尚不足以解释适用边界，可沿主索引的总纲链接，或在已定位的实际导演目录中发现真实 `_*.md` 文件。读取当前问题相关的完整章节及其依赖定义、条件和证据说明；不凭导演名拼未经确认的文件名，不为此先扫全库。方法论总纲补充而不替代作品全文，不是每镜/每轮必读；已经读过且足够的章节复用。总纲中的教学近似、检查清单和复制句式不取得当前工作流或格式的解释权。

## 五、借鉴的合格写法

每条借鉴用以下结构：

> `来源路径 §段落/场景`：来源通过 **方法 X** 让观众产生 **效果 Y**；本场因 **人物/空间差异 Z**，改成 **镜头决定 Q**，落实到 `SHxx`。

示例：

> `references/masters/coppola/教父.md §餐厅刺杀`：以环境声逐步侵入替代解释性对白，使决定先在感官上到达；本场没有列车声，改用冰箱压缩机从稳定嗡鸣到突然停机，静默点落在角色抬眼前，落实到 `SH03`。

以下写法信息不足：

- “参考某大师的风格。”
- “用了电影感构图。”
- “已阅读若干知识库。”

最终交付只呈现会帮助用户判断镜头的具体借鉴，不输出文件读取记录、搜索过程、覆盖率或知识库清单。

## 六、读取效率

- 影视专项先从目录定位相关章节，再完整读取该章节及其前后定义；不要对全库做全文扫描。
- 大师作品必须全文读取，因为场景方法常依赖开头、发展和结果的关系。
- 同一长片分轮做段时可复用已读导演机制；只说明它如何服务当前段。
- 新场景或用户改写核心戏点时，复核已选机制是否仍适用；适用就继承，仅对新增缺口取材。用户已定全片风格不因换场自动重选，不把另一题材的外挂无条件延续。
