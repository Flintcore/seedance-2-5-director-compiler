# 影视与大师知识路由

目标是以最少、最相关的读取支撑真正的导演决定，而不是用索引摘要代替知识，也不是一次性加载整库。

应用所选知识时区分真实硬条件、连续性惯例、项目合同与审美建议；有疑难读 [规则适用边界](film-rule-scope.md) 对应小节。真实空间／接触／状态与光学条件照实执行；旧配额与模板不回流。补回的动作细目和案例随原篇目章节按需读取，不设新读取轮次。

## 一、何时必须读取

以下任务每次都执行完整导演取材：

- 从故事、剧本、口述或参考素材新建设计。
- 改镜头、重排调度、改变表演、节奏、视点或动作美学。
- 审阅镜头质量并提出导演级替代方案。

以下任务跳过导演取材：

- 将已经锁定的 L1 纯编译为提示词。
- 只修对白语法、素材绑定、字段顺序或表达复杂度。
- 给已有提示词增补 Blender 白模参考、识别代理角色和限定参考职责，且镜头创意保持原样；按需读取 [白模参考接入](../references/model/previs-reference.md) 与素材规则即可。
- 已确认创意不变的最小提示词诊断。

**输入方案的必要异议**：按 [设计判断](design-judgment.md)，已指出明确局部技术/信息可读性矛盾时，实读相关专项的完整章节及定义；这不是一次全面创意审阅，不重跑大师选择。无实质问题的纯编译直接继续；同一上下文已读相关内容可复用。

若修复涉及重构视点、镜头顺序、调度或整段节奏，回到导演任务执行完整取材。按实际改动而非“OPTIMIZE”标签路由；一处已授权开放表演细化仍用下述轻量路径。

**局部表演细化**：角色动机、剧情转折与机位已定，仅补充或修正其可见表达时，读 [micro-performance.md](micro-performance.md) 与当前问题需要的表演库完整章节，复用本轮已读内容，不单独重跑全套大师选择或重做镜头。若实际改变人物目标、整段情绪弧或表演策略，则恢复完整导演取材。纯粹转写已确认表演仍按纯编译处理。

## 二、强制读取链

每次导演任务按此顺序：

1. **读影视索引**：打开 `references/cinema/INDEX.md`，把 Brief 归结为 1-3 个真正的导演问题。
2. **读专项正文**：通常从索引选择 1-3 个专项文件中与问题相关的完整章节。单一问题读 1-2 个，真正跨域时读 2-3 个；数目是起始选择建议，不是阅读上限，尚有具体问题未解决就补读直接相关章节。导演任务实际读正文，而非只读文件名、摘要或搜索命中行；无关全库保持未加载。
3. **读大师索引**：打开 `references/masters/INDEX.md`。片名未知时才加读 `INDEX-类型匹配.md`；要按摄影机态度、空间、表演、声音等维度反查时才加读 `INDEX-反查.md`。
4. **读作品全文**：从索引选出至少一部具体作品，读取对应作品 `.md` 从开头到结尾。以下划线开头的方法论总纲可作补充，但不替代作品全文。
5. **形成具体借鉴**：写入 Director IR 的 `knowledge_applications`，落实到镜头 ID。

第二部作品仅在需要对照两种真实导演路径时加入，例如“静观还是压迫”“主观混乱还是客观战术”。不为显示资料量而扩读。

## 三、从问题到专项

以下是选择入口，具体文件说明和完整 44 项清单见 [影视知识索引](../references/cinema/INDEX.md)。

| 当前导演问题 | 优先组合（从中选 1-3 个） |
|---|---|
| 找戏点、搭主镜、控制信息 | `戏点选择与主镜框架法`、`分镜设计知识库_十三讲`、`信息素控制参考库`、`动态分镜决策树` |
| 对白场的权力变化与潜台词 | `文戏编排参考库`、`潜台词与言外之意设计参考库`、`角色调度与走位参考库`、`人物视线与目光设计参考库` |
| 表演过满、两态同屏、情绪跳变 | `表演弧线与情绪阈值参考库`、`表演分寸场景映射库`、`表演细节参考库`、`面部表情四部位参考库` |
| 活人感、微反应、视线不对位、角色站桩 | `表演细节参考库`、`人物视线与目光设计参考库`、`角色调度与走位参考库`（情绪转折明显时可换为 `表演弧线与情绪阈值参考库`） |
| 对话或整段视听太平、镜头只是参数轮换 | `视点体系与镜头运动地基`、`构图设计参考库`、`景深与焦点叙事决策库`、`声音与音效叙事决策库`、`节奏与时长编排库`（按实际缺口从中选1—3项，不全读） |
| 事件讲清但意味薄、光影/前景/反射的潜台词或有意藏露 | `光影设计参考库`、`构图设计参考库`、`创意镜头与记忆点设计库`、`潜台词与言外之意设计参考库`（按主问题选相关章节，复用已读内容，具体疑难才补读） |
| 视点、机位和镜头运动缺乏动机 | `视点体系与镜头运动地基`、`机位情绪决策参考库`、`超详细运镜规格参考库`、`构图设计参考库` |
| 节奏、切点、长镜或蒙太奇 | `节奏与时长编排库`、`切镜时机学`、`镜头衔接与连续性参考库`、`蒙太奇与组接意义库` |
| 画面漂亮但没有戏或记忆点 | `创意镜头与记忆点设计库`、`反平庸案例库`、`大师层视觉语言`、`视觉创意词典` |
| 氛围、悬疑、恐怖或留白 | `类型片镜头语法库`、`声音与音效叙事决策库`、`光影设计参考库`、`静默时刻与留白设计参考库` |
| 动作、追逐、武戏 | `动作设计与武指体系参考库`、`武戏动作模板库`、`速度与力量量化标准`、`物理交互与破坏效果参考库` |
| 特效与超现实画面可信度 | `特效真实感引擎`、`光影设计参考库`、`物理交互与破坏效果参考库`、`特殊镜头与视角参考库` |
| 多段连续、人景漂移或方位混乱 | `镜头衔接与连续性参考库`、`角色与场景设定参考库`、`角色调度与走位参考库`、`视点体系与镜头运动地基` |

| 口述“电影感、狠一点、快一点”含义未定，或反馈与根因混在一起 | `讲戏口语解析参考库` 一—二定位意图，六定位反馈；涉及对白/改写权限才读四—五，不把口语直接等同某技法 |
| 对白只有情绪副词，重音/气息缺少策略，或时长与说话动作冲突 | `对白情绪表达参考库` 一说话动作，四声音维度，六—七可演时长/打断/停顿；按缺口取章，保留逐字台词 |
| 机位、焦段、景别和焦点组合相互牵制 | `机位技术规格详细参数库` 一变量依赖；坐标问题读二，透视/画幅/景别读五—七，光圈/焦点读八—九；按实际矛盾选章，不套固定情绪参数 |
| 颜色像套滤镜、缺少场景来源，或特效跨镜串色 | `色彩调性参考库` 二/四色源与叙事职责，五动作特效连续，六阴影与高光色偏；保留已锁身份色与世界规则 |
| 已定空镜只有美感填充，人物痕迹、缺席或声桥没有承接 | `空镜素材库` 一—二功能/语境，九前后关系；声音承载主要事件才加读七，不因取库自动新增空镜 |
| 构图、光色、运动、声音各自好看却缺少统一策略 | `导演视觉风格参考库` 一/三—四主导维度、项目风格及组合边界；具体组织方式未解才读二对应小节，不照搬整套预设 |
| 小动作有形无意，或交手后身体条件、理解与战局状态被重置 | `表演意义化与武戏状态影响` 一/三—四行为意义与关系后果，五—六武戏状态与人物弧；新增动机/战局结果属于导演改动，不由执行引擎编造 |
| 跨镜只靠表情加码、多人同步反应或转折后没有余韵 | `镜头心理变化与情绪递进参考库` 一/三心理命题与递进，五多人关系，六暂停余韵；局部既定反应仍走微表演轻量路径 |

以上每行也是问题分支，不是整行全读清单；涉及 AU/FACS 或细小脸部形态时，沿 [微表演的条件入口](micro-performance.md) 读取已核验动作章节，普通目光修复不额外编码。

组合是候选，不是固定套餐。根据 Brief 先选通常 1-3 个真正会改变决定的专项，必要时针对尚未解决的具体问题扩读。表演、视线或活人感是主问题时，优先保留 `表演细节参考库` 与视线/调度项；动作因果是主问题时，动作专项占首位，再补最贴合的一项表演或视线专项。明确要求脸部控制时，将相关表演项换为 `面部表情四部位参考库`；心理递进才换为情绪弧线库。

## 四、选大师作品

先按当前场景的核心难题选作品，而不是按“想要高级感”选名气：

- 找到与本场相似的**戏剧机制**：权力交接、关系破裂、等待、发现、追逐、群战、空间困局等。
- 对照相似的**空间条件**：狭长走廊、桌面谈判、开放荒野、拥挤人群、垂直阶级空间等。
- 对照需要的**摄影机态度**：共情、审视、隐瞒、压迫、迷失、见证。
- 对照作品中具体场景如何组织视点、调度、切点、表演和声音。

选定后读取索引给出的实际作品路径全文。作品内的历史提示词格式、平台数字或旧装配规则不具备编译权；只提炼其影视因果。

大师库中的证据标签必须随内容一起解释：`[推断]`、`近似`、`约`、`技法重建`和占位性参数只表示可检验的设计假设，不得升级成制作事实、跨片硬规则或精确控制值。优先采用有作品场景、制作资料或清楚条件支撑的机制；只有近似资料时，保留其定性关系并按本场空间、表演和设备重新判断。


选定作品或导演后，若尚未解决的问题涉及跨镜复用的观看距离、空间组织、表演、光色或声画策略，且单片分析尚不足以解释适用边界，可沿主索引的总纲链接，或在已定位的实际导演目录中发现真实 `_*.md` 文件。读取当前问题相关的完整章节及其依赖定义、条件和证据说明；不凭导演名拼未经确认的文件名，不为此先扫全库。方法论总纲补充而不替代作品全文，不是每镜/每轮必读；已经读过且足够的章节复用。总纲中的教学近似、检查清单和复制句式不取得当前工作流或格式的解释权。

## 五、借鉴的合格写法

每条借鉴用以下结构：

> `来源路径 §段落/场景`：来源通过 **方法 X** 让观众产生 **效果 Y**；本场因 **人物/空间差异 Z**，改成 **镜头决定 Q**，落实到 `SHxx`。

示例：

> `references/masters/coppola/教父.md §餐厅刺杀`：以环境声逐步侵入替代解释性对白，使决定先在感官上到达；本场没有列车声，改用冰箱压缩机从稳定嗡鸣到突然停机，静默点落在角色抬眼前，落实到 `SH03`。

以下写法信息不足：

- “参考某大师的风格。”
- “用了电影感构图。”
- “已阅读若干知识库。”

最终交付只呈现会帮助用户判断镜头的具体借鉴，不输出文件读取记录、搜索过程、覆盖率或知识库清单。

## 六、读取效率

- 影视专项先从目录定位相关章节，再完整读取该章节及其前后定义；不要对 44 项做全文扫描。
- 大师作品必须全文读取，因为场景方法常依赖开头、发展和结果的关系。
- 同一轮多段属于同一导演机制时可共享已读知识，但每段仍需明确它具体应用在哪里。
- 新场景或用户改写了核心戏点时，重新按问题选材，不默认沿用上一场的作品。
