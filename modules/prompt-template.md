# 手册七块提示词元模板

先按 [手册 SOP](prompt-writing-sop.md#原文-sop-读取) 实读 [完整手册原文](../references/writing/handbook/INDEX.md)，同时应用 [明确适配](../references/writing/handbook-adaptation.md)，再读 [完整成稿范本](../references/writing/handbook-gold-mai-long.md)，再用本骨架。填进去的是一场能看见、能听见的戏，不是设计稿摘要或执行检查单。七块职责保持，摄影与表演详略跟着当前戏走。

```text
【本段目标】
《片名》场次，X秒一条连续生成，N个镜头。当前开场事实……，本段结束于……。
世界/时代/地点一句。本场谁想得到什么、怎样试、被谁挡住，最后怎样。
A的性格与本段做法；B的性格与本段做法。
画面质感、色调、画幅、速度。全片镜头语言：机身默认、运动强度、景深倾向、剪辑节奏、例外；镜头焦距逐镜写，不在此统一指定。胶片幅面/颗粒是质感，不是镜头焦距。

【参考绑定】
@image1 = A的身份与服装：（具体特征）。只继承人物，不继承背景、拼版、站姿。
@image2 = 场景的建筑与光向：（具体布局）。只继承建筑、材质、光向；本段人群按环境描述。
以上图片只是参考，不作为首帧、尾帧或静帧出现。

【空间】
方位以（固定观察方向）为准：门、窗、桌子、柜台各在哪。A和B各在哪里、朝哪边，手边有什么。

【环境】
背景有哪些人，各自在做什么，哪里堆着什么；前中后景怎样组织，哪些需要显露、哪些保留暗度。整体照度、亮暗面积及人物经过的明暗区域；实际光源相对场景的世界方向或位置、照向、冷暖、软硬、强弱与遮挡。逻辑光源可在画外，不为交代来源补入可见灯具或成套填充；人物可退入暗处，不以五官和黑衣细节始终清楚为目标。伦勃朗只是选项；丁达尔束按实际介质与光路选用，切镜不搬光源。

【时间线】
【0:00-0:04】镜头1 （机位/景别/运动名）。
（本镜焦距、景别与摄影机相对方位/高度/俯仰）。（起始画面：谁或什么在画左/画右、前景/中景层/后景，关键身体部位、道具及遮挡在取景中怎样排列；只写实际可见的层次）。（人物从这个位置怎样行动、看向谁，带着什么语气说：“原文”；另一人怎样接。人物由哪一侧/哪一层移到哪里，或摄影机随哪件事沿什么路径移动，显露什么、留下怎样的新画面）。（同一世界光源在本镜造成的显露或隐没、主体与背景受光；走入亮区或退入暗处怎样随实际行动发生）。（动作结果或切点中的进行状态）。硬切到镜头2。

【0:04-0:08】镜头2 （机位/景别/运动名）。
（本镜焦距、景别与相对方位/高度/俯仰；从新机位写画左/画右、实际前中后景、裁切及遮挡，承接本段前镜的世界状态）。（在这幅构图中继续行动；跨镜发声写原角色从画外继续说：“本镜听到的原词”。写到实际落幅或动作相位；按世界光位交代这一视角下的主体/背景受光）。

【声音】
无BGM、无旁白（按本场要求）。持续环境声。关键音效和声源远近。各角色音色；跨切时哪层声音继续。

【不可出错】
只留本段真正致命、正文已成立的关系或明确交付开关，不凑条数；没有额外条件写“无额外限制。”。不引用未提供的上/下一生成段。
```

起笔中的“起始画面”是供填稿的说明，不是另加成稿标签；详见[构图落笔与去重](prompt-writing-sop.md#screen-composition)。

## 标题和正文的实际写法

标题像“房梁顶拍。”“柜台中景。”“穿行跟拍。”“江渡背后斜侧反打。”；只保留最能识别这一镜的名称；其余方位、高度和运动细节交给正文，不把技术标签串成标题。不附“继续谈生意”“揭示筹码”等剧情功能解释。正文第一句交代摄影机相对人物/物件的位置和起始画面，随即让人物行动、对白与反应连着发生。景别、焦段、方向、运镜按需要准确保留，不把每镜都填成相同参数表。

人物心理在本段目标中直接讲清，例如“老钱一路换手段，碰了软钉子后转去找婉娘”。镜内写老钱怎么笑、怎么递杯、怎样等不到回应；不写“这一镜体现策略调整”，也不在切镜后解释下一镜要让观众理解什么。起幅和落幅是画面承接，不是每镜必须打印的两段说明；末句已经写清落点就直接切。

光、环境和声音参与行动时就地写，稳定共性放共享块。人物名字沿素材绑定，连续谓语可共用一个姓名，换主体或起新句再点名；原对白中的代词保持。细节写在戏的关节上，普通放碗、松手等动作不拆成受力操作说明；真正关键的刀手归属、接触、尺度和伤侧照实写清。

## 模式与接续

七块是默认完整稿；用户明确要求4—8秒单镜精简时，用 [原文①1.7](../references/writing/handbook/01-overview.md) 的紧凑模板，保留风格、一次绑定、单镜因果、声音与致命项，空间环境在镜内说清。这不是恢复旧字段，也不自动对所有短片删栏目。七块专用维护脚本不用于该例外。

七块是默认参考模式。无素材如实说明。首尾帧/首帧模式把参考职责换成真实首尾输入，撤去“不是首帧”的句子；编辑、延长、一镜到底等选 [18变体](../references/writing/variants.md)。一镜到底用连续事件节点，不把每个阶段编号成新镜头。

标题时码是粗略预算；镜内用人物动作、台词气口与情绪变化衔接。每个真实接点说明硬切或连续；上一镜落幅与下一镜起幅接同一人物/物件状态，不要求构图像素相同。跨镜台词分放各镜实际听到的连续原文，声音不断，反应镜仍写具体续词。正文双引号收逐字对白；表演在引号外，长对白确有中途变化才用【非发声说明】。完整句按片段拼回时原词和标点保持。

执行重点见 SOP 的[单段自足](prompt-writing-sop.md#standalone-segment)、[世界布光](prompt-writing-sop.md#world-lighting)与[独立段接点](prompt-writing-sop.md#segment-boundary)。最终按[基础检查](delivery-check.md)读当前成稿，不在末轮重查知识库。
