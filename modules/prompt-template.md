# 手册七块提示词元模板

先读 [手册 SOP](prompt-writing-sop.md) 和 [完整成稿范本](../references/writing/handbook-gold-mai-long.md)，再用本骨架。填进去的是一场能看见、能听见的戏，不是设计稿摘要或执行检查单。七块职责保持，摄影与表演详略跟着当前戏走。

```text
【本段目标】
《片名》场次，X秒一条连续生成，N个镜头。上接……，下交……。
世界/时代/地点一句。本场谁想得到什么、怎样试、被谁挡住，最后怎样。
A的性格与本段做法；B的性格与本段做法。
画面质感、色调、画幅、速度。全片镜头语言：机身默认、运动强度、景深倾向、剪辑节奏、例外。

【参考绑定】
@image1 = A的身份与服装：（具体特征）。只继承人物，不继承背景、拼版、站姿。
@image2 = 场景的建筑与光向：（具体布局）。只继承建筑、材质、光向；本段人群按环境描述。
以上图片只是参考，不作为首帧、尾帧或静帧出现。

【空间】
方位以（固定观察方向）为准：门、窗、桌子、柜台各在哪。A和B各在哪里、朝哪边，手边有什么。

【环境】
背景有哪些人，各自在做什么，哪里堆着什么；前中后景怎样分开，哪几层需要清楚。共享光源与光向。

【时间线】
【0:00-0:04】镜头1 （机位/景别/运动名）。
（摄影机在哪、看见谁和什么，保留已定焦段与景别）。（人物正在做什么；发生什么以后，人物怎样做、看向谁，带着什么语气说：“原文”；另一个人怎样接。摄影机随哪件事、怎样移动，停到什么画面）。（最后谁在哪里、拿着什么，或动作正在进行到哪里）。硬切到镜头2。

【0:04-0:08】镜头2 （机位/景别/运动名）。
（从新机位接住上一镜的人物状态，继续写这一镜发生的戏。跨镜发声直接写原角色从画外继续说：“本镜听到的原词”。结尾写清最后画面）。

【声音】
无BGM、无旁白（按本场要求）。持续环境声。关键音效和声源远近。各角色音色；跨切时哪层声音继续。

【不可出错】
本场真正致命的身份、道具、关键动作和交付要求，通常3–6条，具体写清。
```

## 标题和正文的实际写法

标题像“房梁顶拍。”“柜台中景。”“穿行跟拍。”“江渡背后斜侧反打。”；只保留最能识别这一镜的名称；其余方位、高度和运动细节交给正文，不把技术标签串成标题。不附“继续谈生意”“揭示筹码”等剧情功能解释。正文第一句交代摄影机相对人物/物件的位置和起始画面，随即让人物行动、对白与反应连着发生。景别、焦段、方向、运镜按需要准确保留，不把每镜都填成相同参数表。

人物心理在本段目标中直接讲清，例如“老钱一路换手段，碰了软钉子后转去找婉娘”。镜内写老钱怎么笑、怎么递杯、怎样等不到回应；不写“这一镜体现策略调整”，也不在切镜后解释下一镜要让观众理解什么。起幅和落幅是画面承接，不是每镜必须打印的两段说明；末句已经写清落点就直接切。

光、环境和声音参与行动时就地写，稳定共性放共享块。人物名字沿素材绑定，连续谓语可共用一个姓名，换主体或起新句再点名；原对白中的代词保持。细节写在戏的关节上，普通放碗、松手等动作不拆成受力操作说明；真正关键的刀手归属、接触、尺度和伤侧照实写清。

## 模式与接续

七块是默认参考模式。无素材如实说明。首尾帧/首帧模式把参考职责换成真实首尾输入，撤去“不是首帧”的句子；编辑、延长、一镜到底等选 [18变体](../references/writing/variants.md)。一镜到底用连续事件节点，不把每个阶段编号成新镜头。

标题时码是粗略预算；镜内用人物动作、台词气口与情绪变化衔接。每个真实接点说明硬切或连续；上一镜落幅与下一镜起幅接同一人物/物件状态，不要求构图像素相同。跨镜台词分放各镜实际听到的连续原文，声音不断，反应镜仍写具体续词。正文双引号收逐字对白；表演在引号外，长对白确有中途变化才用【非发声说明】。完整句按片段拼回时原词和标点保持。
