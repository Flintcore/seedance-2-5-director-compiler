# 七块提示词元模板

先完整执行 [编写 SOP](prompt-writing-sop.md)，再填本模板；模板不替代影视取材。模式见 [模式边界](../references/writing/modes-and-evidence.md)，非默认结构见 [18种变体](../references/writing/variants.md)。以下尖括号是填写说明，成稿替换成有依据的人、物和事件。标题时码是粗略预算，镜内用事件触发。

```text
【本段目标】
<片名/场次>，<总时长>秒，一条生成，<N个镜头剪辑或一个连续镜头>。<本段开始承接的实际状态，结尾交付的状态；无前后段则省略>。
<时代、地点、谁想得到什么、被什么挡住，如何推进，结尾观众理解或感到什么>。<真正影响表演的角色目标、顾虑/认知和策略，简单段合并讲清>。
<摄影机/胶片或数字成像目标、颗粒、色调、画幅与正常速度或已定变速>。<全段摄影默认：支持/稳定性、运动强度、景深倾向、剪辑节奏和明确例外>。

【参考绑定】
@image1 = <角色统一名称>的<身份与服装等明确职责>；继承<可见特征>；本段<姿态/背景>按下文，不沿用<确有污染风险的元素>。
@image2 = <场景名称>的<建筑/材质/光向职责>；本段人群与活动按环境和时间线。
<全能参考的普通身份/场景图只作依据，本任务不把这些图用作首帧、尾帧或拼版静帧。首尾帧任务换成“首帧图/尾帧图”职责并在平台对应槽位选择，删去这句参考模式声明。无素材写“无外部参考素材”。>

【空间】
<以一个固定世界视角描述门窗桌柱和通路>。<人物开场站位/朝向/持物和必要比例、接触；后续走位按时间线更新>。

【环境】
<实际背景人群在做什么、杂物放哪里、前中后哪些层次需要可见、已有光向>。<空场/静默按意图写空与静，不凭空塞满>。

【时间线】
【0:00-0:04】镜头1 <机位/景别简称>。
<焦段与景别，摄影机相对人物/地标的方位、高度、俯仰和起始支持方式>。<起始可见画面，主体位置、体态、目光、持物及正在做的事>。<刺激到达，角色具体行动，语气/动作在引号外，角色说：“本镜实际听到的原文片段”；对手如何接收，运镜被何事带动、沿何路径到哪儿，光/环境/声音产生什么具体变化>。落幅：<世界末态、注意力、接触或仍在进行的动作相位>。<当触发事件发生，硬切到镜头2；单镜到底则不加切镜>。
【0:04-0:08】镜头2 <机位/景别简称>。
<必要摄影定位，新角度的起幅承接同一世界状态>。<本镜发生的完整事件与反应；跨镜台词写原声源的画外/画内续句，不用“声音继续”代替原词>。落幅：<本段结束的可见状态或动作相位，不预写下一段事件>。

【声音】
<按用户要求关闭BGM/旁白等，保留实际剧情声源>。<持续底声、背景人声是否清晰及范围>。<各角色音色与稳定身份，关键声音在对应镜头已经落位，跨切如何延续，台词不重复抄录>。

【不可出错】
<少量本段真正致命的身份、关键物件、动作或模式边界；优先具体肯定句，不用错误身体清单补丁>。
<无字幕/无文字叠加等仅在符合用户要求时写；不删剧情必需实物文字。>
```

## 一、可读性的底线

摄影参数用于建立观看位置，人物行动与说听互动是正文重心。每镜单独读也应知道谁在何处做什么、为什么发生变化、变化给谁带来什么结果；省略共享风格不等于省略人物行动。既定心理用直白话保留，具体动作不被“克制、压迫、电影感”等词代替。叙述继续用统一姓名，原对白中的代词照原文。

## 二、模式与变体

全能参考默认以上七块。首尾帧、首帧、编辑、延长等保留清晰的职责但按 [变体](../references/writing/variants.md) 改写参考与时间线。对白密集时允许将【声音】整体移至【空间】后；一镜到底时间节点不编新镜号，写明连续范围和阶段连接。短单镜可以每块仅一句，不靠删掉模式/空间职责来精简。4秒、8秒范例时长不是镜长配额。

## 三、对白与声桥

双引号里的原文、标点、方言、拟声词保持。表演默认在引号外；长句中途有必要变化才用【非发声表演说明】，去掉说明后仍逐字一致。跨镜按当镜听到的片段分配；原文“门一直关着，直到钟响。”可在“关着，”后切听者，后镜写“原说话者画外继续说：‘直到钟响。’”对应的双引号格式，听者不配口型。实际成稿使用中文双引号，不添加引用示范里的单引号。不要为了切镜额外添省略号、句号或让听者提前知道后半句。

## 四、状态和节奏

落幅与起幅接的是世界状态，不是相同像素构图。轴线、视线、道具和动量按真实关系接续；有意跳时/跳空明确表达。动作中切镜、持续观察、反应镜和有意空白均可承担镜组价值。每次变镜不要求换焦距，每次动接静也不要求停顿。锁定台词不按字数公式删改，镜内不用秒表排班。
