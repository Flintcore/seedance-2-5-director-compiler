# L1 镜头导演法

本模块把 Brief 与知识取材转成可确认的 L1。目标是让每个镜头承担清晰的戏剧变化，并为原生分镜提示词编译留下无歧义的画面、表演、声音和连续状态。

## 一、先导演变化，不先堆镜头

依次回答：

1. **戏点**：本段最值得被看见的冲突、变化或转折是什么？
2. **落点**：观众在段尾应该知道、感到、期待什么？
3. **视点**：摄影机与谁同知、比谁先知、对谁隐瞒？
4. **空间**：人物、关键物、出入口、障碍、视线和轴线怎样组织？
5. **状态变化**：哪一个可见动作或反应，让开场状态变成结尾状态？

先确定这些，再选择长镜、切镜、景别和运动。镜头数量服务于变化，不按固定数量拆分镜头；多个镜头应优先留在同一个生成段内，生成段边界只在边界闸门通过后决定。

### 镜头级连续叙事单元

每个镜头或镜内段落先作为一个完整的可视化因果单元来设计：从当前构图和人物关系起步，经由可见触发进入动作过程，再落到同场反应、对白/声音、摄影机响应和新的稳定状态。先写出这条连续画面脊柱，再把 `camera`、`staging`、`performance`、`sound` 和 `transition` 映射进去；这些字段是校准工具，成片描述仍应是一段顺着时间流动的画面叙事。

单看一个镜头正文，读者应能复原画面中谁在哪里、谁在看什么、事件为何发生、动作怎样推进以及结尾留下什么。切镜后的首个画面重新建立必要的左右/前后关系、持物和动作相位；这些动态锚点可以按需重复。静态外观或技术基线只在发生变化或影响理解时重复。一个镜头内部可以用“此时、同时、看到后、就在这时、随后”连接多个节拍，保持同一空间中的背景人物和未完成动作继续可见。

## 二、建立主镜骨架

从以下骨架中选最能承载戏点的一种，也可组合：

- **单一主镜**：空间关系持续变化，摄影机在同一镜内重构信息。
- **主镜 + 插入**：主镜维持关系，少量细节镜揭示决定性信息。
- **正反打递进**：每次切换都改变权力、距离或认知，不做机械轮流讲话。
- **观察 → 主观 → 反应**：先建立事实，再进入感知，最后把后果落在人身上。
- **平行/对照组接**：两条动作或意义互相改写，切点由关系而非节拍器决定。
- **逐级逼近/撤离**：景别或距离随人物心理真正变化。

为每镜写 `function`。若去掉一镜后观众的理解、情绪、空间或因果没有变化，优先合并。

## 三、逐镜设计顺序

### 1. 可见事件

先写当前构图里谁在做什么、什么触发了动作、环境如何响应、谁看见了什么，再把动作从起始状态写到结果。抽象词必须落成行为：不写“他很恐惧”，写呼吸停顿、视线避开出口、手指在杯沿失去节奏等可观察事实。

### 2. 调度与空间

写清人物相对位置、朝向、距离、视线落点、关键物所属、入画/出画方向。权力变化优先通过谁占据中心、谁被遮挡、谁迫使谁移动来表达。

先确定画面内人物正在看的具体对象、人物或空间位置；默认让视线、头部和身体朝向彼此可解释地对齐。若有意错开，写清是回避、余光监视、过渡中的延迟，还是被新信息牵引，并保留可见的注意力落点。

### 3. 摄影机态度

先选择视点，再决定：

- 景别是让观众读空间、读身体还是读微表情。
- 机位高度与侧向关系让人物显得掌控、受困、亲密或疏离。
- 镜头运动由主体、信息或情绪变化触发；没有动机时保持稳定。
- 焦点变化只在注意力或认知发生转移时使用。
- 构图和遮挡用来管理信息，不只用于“好看”。

### 4. 表演与潜台词

把人物目标、公开行为和真实意图区分开。每个表演拍只选最有证据力的身体部位、节奏和反应，不让多个互相冲突的情绪同时满格出现。对白前后要有动作、停顿或视线结果，逐字对白保持原文。

### 4.1 活人感表演基线

当人物在镜头中可见并承担本镜变化时：

- 先给注意力一个落点：角色看向谁、什么物件、哪个出口或画外方向，以及发生在动作前、动作中还是动作后。眼睛不可见时，用头部、身体朝向或空间目标承接。
- 再按戏剧需要选最能让角色保持活性的自然变化：手上任务短暂停顿或改抓握、呼吸节奏、重心、姿态、距离、习惯性整理、未完成动作或听者反应都可承载表演，不要求每镜配齐。优先选择能由人物习惯、当前任务或道具关系解释的载体，避免无触发的抖动、整理和重复手势。
- 让这个变化由触发引起并产生后果；情绪通过视线、控制和行为关系被读到，不以情绪形容词代替。
- 只有在景别和光线支持、且面部变化确实改变观众理解时，才写眉、眼、鼻、嘴等微表情。一个主信号通常足够，其他部位只作必要支持，不排成清单。
- 普通站定也要呈现正在看什么、等待什么、控制什么，或身体如何维持平衡；有意静止时，把静止的注意力和张力写出来。

用户锁、人物既定习惯、类型语法和有意的形式化静止优先于这套默认；活人感来自有依据的注意力和行为，不等于持续运动。

连续性承接的是注意力、控制和身体轨迹，不是反复同一手势；小动作只在自然持续或再次被触发时延续。

### 5. 声音与静默

为声音指定叙事作用：建立空间、预告威胁、遮蔽信息、触发记忆、放大接触或制造静默。声音变化应与画面事件形成因果；不为填字段添加泛化配乐。

### 6. 切点或镜内段落（不等于生成段切换）

这里的“镜内段落”只指同一生成段内的叙事节拍或注意力转移，不是新的平台生成段。

切在信息改变、动作传递、视线确认、情绪压住、表演/注意力状态改变或反应完成的时刻；切点前写清上一状态的结果，切点后写清新视点首先看到的状态。长镜也要写内部段落，但优先把连续节拍留在同一段自然叙事中：人物调度、焦点或声音变化只有在改变观众注意力或因果关系时才推动新的切换。

### 7. 交接状态

每镜结尾记录下一镜必须继承的状态。只有边界闸门确认需要多段时，段尾才额外整理为下一段 Brief 的进入状态；普通单段在 `【收尾约束】` 收束。

若下一镜仍承接人物表演，交接状态带上最后的注意力/视线落点、头身相位、未完成的小动作或呼吸节奏；只有发生可见原因时才改写这些状态。

## 四、时长与稳定区

- 单段总时长保持在已确认的 4-30 秒范围内。
- 一个生成段可以包含多个镜头和多个戏剧节拍；镜头切换本身不产生新的生成段。
- 只有用户明确要求多段，或用户给定时长/锁定事件的最低必要时长确实超过 30 秒时，才设计段间边界。
- 开头 0.5 秒用于清楚建立主体与初始状态，结尾 0.5 秒用于保留可读的结果状态。
- 开场钩子与硬结尾也要在这两个稳定区内形成清楚、可复现的状态，不挤占安全区。
- 为镜头分配时间时优先保障转折、反应和结果，不平均切块。

## 五、动作条件分流

- 普通拿取、转身、行走等留在逐镜可见事件中，写清方向和结果；若动作同时承担表演，补上视线/注意力落点与自然的小动作或身体节奏。
- `ACTION_LITE`：读取 [action-design.md](action-design.md)，补齐起因、方向、接触、惯性和恢复，再嵌回对应镜头。
- `ACTION_FULL`：导演先定动作的叙事意义、人物风格、观众视点和节奏形状；动作模块再展开战术目标、逐拍时间、空间向量、受力与连续性。

动作模块的结果必须回写镜头 `end_state`，避免动作链和镜头表成为两套互不相认的设计。

## 六、多段连续（仅在边界闸门通过后）

仅当任务模式为 `SEQUENCE` 且边界闸门已确认多段时，为每段建立简短交接条目：

```yaml
handoff:
  character_pose: "人物姿态、朝向、位置"
  held_objects: "持有物和左右手"
  environment_change: "门窗、破坏、天气、烟尘、光源等"
  camera_relation: "下一段需要继承或有意改变的轴线/视点"
  unresolved_motion: "尚未结束的动作及运动方向"
  audio_tail: "需要延续的对白尾音、环境声或静默"
```

后段开场先承接事实，再发展新动作。若有意跳轴、跳时或匹配剪辑，写明其叙事收益。

## 七、L1 交付格式

L1 使用以下轻量结构，不混入成片提示词标题：

```markdown
## L1 · S01 · v1 · draft/turn_locked/user_approved

**核心意图与落点**
一句话说明戏点、转折和观众落点。

**锁定事实**
逐字对白、素材的语义绑定、世界事实和用户锁；不展示来源路径、文件名或 `@` 占位符。

**进入 / 退出状态**
本段开场事实，以及结尾供下一段继承的事实。

**导演策略**
视点、主镜骨架、节奏、表演、光色和声音的统领选择。

**具体借鉴**
来源中的具体方法 → 本场变形 → 对应镜头。

| 时间 | 镜头 | 画面与调度 | 摄影机 | 表演与声音 | 切点 / 结尾状态 |
|---|---|---|---|---|---|
| 00:00.0-00:04.0 | SH01 | ... | ... | ... | ... |

**动作链**（仅 ACTION_LITE / ACTION_FULL）
战术与逐拍因果，以及它落入哪些镜头。
```

“具体借鉴”是用户可判断的创意依据，不展开读取过程。锁定事实为空时省去空项；动作模式为 `NARRATIVE` 时省去动作链。

## 八、锁定与编译交接

- 用户确认后，L1 版本状态改为 `user_approved`；修改任何创意字段都递增版本。
- 自动模式将本轮 L1 标记为 `turn_locked`，编译器仅使用这份快照。
- 交给编译器的内容包括：镜头顺序、时间、画面事件、摄影机、表演、声音、动作链、逐字对白、素材绑定、进入/退出状态。
- 素材源 ID 仅在内部交接；L1 用角色/场景/动作/声源等语义标签，正式 `@` 占位符由编译器统一生成。
- 最终提示词由编译器重新组织为原生分镜格式；导演域不输出内部追踪字段、装配样板或检查表。
